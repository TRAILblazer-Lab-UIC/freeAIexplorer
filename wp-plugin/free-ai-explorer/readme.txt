Embed the Local AI Field Guide static site in any page.

== Usage ==
1. Upload the free-ai-explorer folder to wp-content/plugins and activate it.
2. Add the shortcode to a page: [homegrown_ai src="https://trailblazer-lab-uic.github.io/freeAIexplorer/"] (the older [free_ai_explorer] shortcode still works)
3. Optional attributes: title="..." and height="1200" (starting height in pixels).

The explorer resizes itself to fit. It loads nothing from third parties.
