About Free AI Explorer

Free AI Explorer is an AI-assisted experiment by Jeremy Riel, PhD, from the UIC TRAILblazer Lab. Learn more about the lab at trailblazerlab.org.

The site helps K-12 teachers find computing, AI, and robotics tools for class. Many of these tools keep student data inside the school. Some run with no internet at all. Others are paper activities with no device.

A note on AI-generated content

Generative AI helped research, sort, and describe the tools on this site. AI can make mistakes. Some facts may be wrong or out of date. Prices, privacy terms, and features change often. Please check every detail with the provider before you use a tool with students. Nothing on this site is legal advice. Your district's privacy rules come first.

How we built it

The project ran in three stages.

  1. Research. AI research agents searched the web in four rounds. They looked for software, hardware, kits, lessons, and unplugged activities. Each item got a fact sheet with cited sources. Search stopped once new rounds found few new items.
  2. Classification. Python rules sorted each item by facts such as cost, internet need, and where student data goes. AI agents scored judgment calls such as ease of use. A second AI coder scored a random sample on its own. We measured how often the two agreed and tightened the rules until agreement passed our target.
  3. Writing. AI agents wrote each tool page from the fact sheets. A style checker reviewed every page.

What the privacy labels mean

  • Stays on the device. The tool runs on the computer, tablet, or robot. Student work stays there.
  • Stays on a school server. The school runs the tool on its own server.
  • Local with optional cloud or accounts. The main features run locally. Some extras use a company's servers.
  • Sends student data to a company. Student work or account details go to an outside company.
  • No device needed. The activity uses paper, cards, or movement.
  • Unverified. The materials do not say which tools or accounts students need. Check before class.

What is not here

We did not test each tool in a classroom. We did not measure learning gains. Few of these tools have strong research behind them. The classroom evidence label on each page shows what we found.

Privacy on this site

This site loads nothing from other companies. It has no ads, trackers, or analytics. My List lives only in your own browser. Links to tool websites leave this site.
