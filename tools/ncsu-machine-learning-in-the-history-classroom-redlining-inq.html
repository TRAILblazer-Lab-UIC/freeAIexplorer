NCSU Machine Learning in the History Classroom redlining inquiry

A high school unit where students use AI text mining to study redlining.

AI

The privacy details for this item are unverified. Check which tools and accounts students will use before class.

Overview

This high school social studies unit comes from the NC State Friday Institute. Students use AI modeling software to look for patterns across a large set of primary source texts about redlining. The aim is to understand how historical discrimination worked as a system. The unit builds on a 2021 project in five high school history classrooms that used StoryQ.

Benefits

For students

  • Students study a real history topic with primary sources.
  • Students use text mining to find patterns they could not read through by hand.
  • Students see how AI modeling can support historical questions.

How this can be used for Social Studies
  1. Read primary source texts about redlining and note the language used.
  2. Use text mining to find words that appear often in redlining documents.
  3. Compare patterns across sources and explain what they show.
  4. Discuss how redlining affected families and neighborhoods over time.
  5. Write a short report on what the patterns say about systemic discrimination.
How this can be used for Computer Science
  1. Describe how a text mining tool counts and groups words.
  2. Test a model on a new source and check whether it finds the same patterns.
  3. List features the model uses and discuss which ones matter most.
  4. Explain where the model could be wrong about a source.
  5. Compare what a person finds in a text with what the model finds.
