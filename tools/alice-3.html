Alice 3

A free desktop tool where students drag tiles to build 3D animations.

Computing

Overview

Alice 3 is an object-based programming language with an integrated environment. Students build 3D computer animations by dragging and dropping tiles that represent programming structures. It was developed at the University of Virginia and at Carnegie Mellon. Alice 3 can move students on to Java.

Benefits

For students

  • Students build 3D animations with drag and drop tiles.
  • Students learn programming structures through stories and scenes.
  • Students can move to Java later.

For teachers

  • It is aimed at beginners including middle school students.
  • It is used in introductory programming courses.
  • It runs on Windows, macOS and Linux per Wikipedia.

For schools

  • Alice 3 is a free download from alice.org.
  • Sources disagree on whether the code is open source.
  • IT needs to install it, and the internet is used only for setup.

Getting started checklist

Where is the AI in this product?

Alice 3 has no AI. Students build skills in sequencing, loops and objects as they program characters. They then move toward text code in Java.

Privacy and safety

No account is needed and projects are saved as local files. The research read no privacy policy and the official site returned an error. The materials do not say what data the software collects. Privacy and license terms are unconfirmed. The internet is used at setup. A teacher should check the install on a test machine and decide where students save files.

How this can be used for Computer Science
  1. Build a short animation where a character walks and speaks.
  2. Use a loop to repeat a movement.
  3. Write a method that makes a character wave.
  4. Add a second character that responds to the first.
  5. Compare tile code with Java code for the same action.
