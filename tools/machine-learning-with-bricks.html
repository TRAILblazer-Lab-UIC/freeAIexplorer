Machine Learning with Bricks

A free web platform that teaches machine learning with LEGO SPIKE Prime robots.

FREEAIRoboticsStays on the deviceGood for AI beginners

Overview

Machine Learning with Bricks is a free open-source web platform that pairs LEGO Education SPIKE Prime robots with interactive visualisations. It teaches K-nearest neighbors, linear regression, and Q-learning. Students build three robots, a Fruit Detector, a Pitcher, and a Crawler. The platform needs no programming and connects to the SPIKE hub through Bluetooth in Chrome or Edge.

Benefits

For students

  • Students learn machine learning by training real LEGO robots.
  • Students see each method in a visualisation.
  • Students need no coding.

For teachers

  • The platform has tutorials and a video course.
  • It works in English and German.
  • A two-day makerspace workshop with ages 12 to 17 tested it. The sample was small and self-reported.

For schools

  • The platform is free. A LEGO SPIKE Prime hub and kit are needed, and the price was not checked.
  • The platform runs in the browser and no account is needed.
  • The internet is needed at all times. Chromebook use is likely but was not confirmed.

Getting started checklist

Where is the AI in this product?

The AI is K-nearest neighbors, linear regression, and Q-learning. It runs in the web browser on the local computer. Students train each robot with their own examples and watch the visualisation change. They then test how well the robot has learned.

Privacy and safety

No account was mentioned. The README says everything runs in the browser. The site is hosted on GitHub Pages and needs the internet to load each time. The research found no privacy policy, and the paper does not describe platform data storage. The paper is a preprint that has not been peer reviewed. A teacher should check that school computers allow Bluetooth connections in Chrome or Edge, and check what the page loads from outside servers.

Ideas by subject

Select a subject to see five classroom ideas.

How this can be used for Computer Science
  1. Train the Fruit Detector with K-nearest neighbors and test it on new pieces.
  2. Change the number of neighbors and describe the effect.
  3. Let the Crawler learn by trial and error with Q-learning and note when it improves.
  4. Compare the three robots and name the learning method each one uses.
  5. Explain one method to a classmate with the visualisation.
How this can be used for Math
  1. Plot the Pitcher's data and find the line that links force and distance.
  2. Predict a new distance from the line and test the prediction.
  3. Measure the distance between points in the Fruit Detector's plot.
  4. Compare the predicted line with the actual results and find the error.
  5. Describe how the Q-learning reward numbers change over time.
How this can be used for Engineering and Design
  1. Build the Fruit Detector from the SPIKE Prime kit.
  2. Build the Pitcher and tune its arm.
  3. Redesign the Crawler's legs and test how far it moves.
  4. Test each robot three times and record the results.
  5. Document a build step with a photo or sketch.
