HamiltonBuhl 4-Axis STEAM Robo-Arm Kit

An Arduino robot arm kit that stores and repeats up to 100 movements.

ComputingRobotics

Overview

This is an Arduino UNO based four-servo robot arm kit for students ages 13 and up. It includes a servo expansion board, a remote control board and four potentiometers. The arm can be controlled by hand or programmed, and it can store and repeat up to 100 movements. Students assemble it with a screwdriver and program it with Arduino and Rollarm software on a Windows PC.

Benefits

For students

  • Students build a robot arm with four joints.
  • Students control the arm by hand with potentiometers.
  • Students record a movement and watch the arm repeat it.

For teachers

Getting started checklist

Where is the AI in this product?

This kit has no AI. The arm repeats the movements that students record or code. Students build skills in sequencing, which means putting movements in the right order.

Privacy and safety

No account is needed and the internet is used at setup to get the software. The kit is a local Arduino device and no cloud service was found. The research did not review the software download sources or a privacy policy. A teacher should check where the Rollarm and Arduino software come from. A teacher should also supervise the assembly and the moving servos, and check that classroom PCs run Windows.

How this can be used for Engineering and Design
  1. Assemble the arm and name each of the four joints.
  2. Test how much weight the arm can lift.
  3. Design a small object for the arm to pick up.
  4. Compare the arm to a human arm and list the differences.
  5. Improve the arm's reach and test the change.
How this can be used for Computer Science
  1. Record a sequence of movements with the potentiometers and replay it.
  2. Write an Arduino program that moves one servo.
  3. Program the arm to move an object from one spot to another.
  4. Change a program value and note how the movement changes.
  5. Write a plan of movements on paper before coding them.
