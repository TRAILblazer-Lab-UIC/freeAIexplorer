text-generation-webui

A free app for running large language models on your own computer.

AI

Overview

text-generation-webui is an open source desktop app and web interface for running large language models locally. Its README now calls it TextGen. It supports several backends such as llama.cpp, Transformers, and ExLlamaV3. It is aimed at hobbyists and advanced users. It suits a teacher or older student with technical skill.

Benefits

For students

  • Students chat with a language model that runs on the school computer.
  • Students can try different models and compare the answers.
  • Advanced students can explore fine tuning and image generation.

For teachers

  • The app has chat and instruct modes and can attach files and images.
  • Portable builds exist for Windows, macOS, and Linux.
  • A local API lets teachers connect other tools.

For schools

  • The software is free and open source.
  • A full install needs about 10 GB of disk, and a GPU helps. CPU only builds exist.
  • IT will likely need to help, and Chromebooks are not supported.

Getting started checklist

Where is the AI in this product?

The AI is a large language model that runs on the device. It chats, follows instructions, calls tools, and can make images. Model size sets how much memory is needed. Students ask questions and judge the answers against their own knowledge.

Privacy and safety

No account is needed. The README calls the app 100% offline and private with zero telemetry. That is the project's own claim and the research did not verify it. Installing the app and downloading models needs the internet. The research found no student safety features, and local models may give unfiltered or wrong answers. Check which models are used and review their licenses. Ask IT to test the app for network activity.

How this can be used for Computer Science
  1. Load two models of different sizes and compare their answers to one question.
  2. Change the temperature setting and describe how the replies change.
  3. Ask the model to explain a code snippet and test whether it is right.
  4. Time how long a reply takes on the CPU and on the GPU.
  5. Write a short report on why model size affects memory needs.
