Modeling Commons

A free web site for sharing and downloading NetLogo simulation models.

Computing

Overview

Modeling Commons is a free web site for sharing and downloading NetLogo simulation models. Visitors without an account can view and download models. Registered users can upload, fork, update, and comment on models. Models are run in the NetLogo desktop program.

Benefits

For students

  • Students browse models of natural and social systems.
  • Students fork a model and change it.
  • Students comment on and discuss models.

For teachers

  • Registered users set visibility or edit permissions, including by group.
  • Each model has a page with version history and a forum.
  • Search snippets say classroom sharing is supported.

For schools

  • The site is free for personal, research, and class use.
  • NetLogo desktop is needed to run downloaded models.
  • IT may need to install NetLogo.

Getting started checklist

Where is the AI in this product?

This site has no AI. It builds skills in modeling and simulation. Students learn how simple rules lead to larger patterns.

Privacy and safety

Visitors can view and download models without an account. Registered accounts collect an email and password, uploaded models, and comments. By default anyone can view, fork, and update an uploaded model unless the owner restricts it. The privacy and cookie policies were not read. A teacher should read the policies and set visibility before any student uploads.

How this can be used for Science
  1. Download a model of predator and prey and describe what happens over time.
  2. Change one setting and write what changes.
  3. Compare two models of the same system.
  4. Fork a model and add a new rule.
  5. Write a comment that asks a question about a model.
How this can be used for Computer Science
  1. Fork a model and read its code.
  2. Update a fork and record the change in the version history.
  3. Explain what each procedure in a model does.
  4. Upload a class model to a private group.
  5. Share a model with a partner and ask for feedback.
