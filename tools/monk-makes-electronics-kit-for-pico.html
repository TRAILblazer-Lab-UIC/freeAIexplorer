Monk Makes Electronics Kit for Pico

A low-cost kit with ten projects for learning electronics with a Raspberry Pi Pico.

$ComputingRoboticsStays on the device

Overview

This kit teaches electronics and coding with a Raspberry Pi Pico. It includes a custom breadboard with Pico pin names, jumper wires, a servomotor, resistors, LEDs, push switches, a phototransistor, a buzzer and a variable resistor. It covers ten projects such as a touch switch, thermometer, light meter and lie detector. The Pico is not included and its headers must be soldered on.

Benefits

For students

  • Students build ten working circuits.
  • Students see their code control real lights, sounds and a motor.
  • Students learn from a free 68-page book by Simon Monk.

For teachers

  • The instruction book is a free download.
  • The projects run in order and give a clear path.
  • The kit covers both circuits and code.

For schools

  • Retail listings show about 21 USD in the United States. The Pico costs extra.
  • The kit works on Windows, Mac, Linux and Chromebook computers.
  • The internet is needed only at setup.

Getting started checklist

Where is the AI in this product?

The kit has no AI. Students build skills in sensors, logic and data. They read values from a light sensor and a thermometer and decide what the code should do.

Privacy and safety

The kit is passive parts that work with a Pico that the school supplies. No account or software from Monk Makes is needed, and programs stay on the board. The materials document no student data collection. The programming tool is chosen separately, and the research did not review one. A teacher should check which programming tool the school allows and plan soldering safety for the headers.

  2. Program the buzzer to play a simple tune.

  4. Add a condition to the lie detector project.
