Utah State Scratch repeat loops for multiplication and exponents (Cache Code Math)

Fifth grade lessons that link Scratch repeat loops to multiplication and exponents.

Overview

Cache Code Math is a set of fifth grade lessons from Utah State University. The lessons connect Scratch repeat loops to repeated addition, multiplication, and exponents. Computer lab lessons run alongside classroom math lessons. The exact document could not be opened in this research. Details are unconfirmed.

Benefits

For students

  • Students see multiplication as repeated addition in code.
  • Students see exponents as repeated multiplication.
  • Students practice both math and coding in one unit.

For teachers

  • Computer lab and classroom lessons are paired.
  • The math lessons cover exponents, including fractions.
  • A search summary says a version exists that needs no Scratch login.

For schools

  • The lesson PDFs are free.
  • Scratch is a free tool.
  • The unit can split work between the classroom teacher and the computer lab teacher.

Getting started checklist

Where is the AI in this product?

The materials describe no AI. Scratch runs the blocks students arrange. Students build sequencing and logic skills as they use repeat blocks to model math.

Privacy and safety

The materials do not state which accounts students need or what data is collected. A search summary says a version exists without Scratch logins. A teacher should choose that version and check the school rules for Scratch.

How this can be used for Math
  1. Use a repeat block to show 4 times 3 as repeated addition.
  2. Predict the total after a repeat loop and check it in Scratch.
  3. Show an exponent as repeated multiplication in a script.
  4. Write the exponent form for a repeat loop result.
  5. Explain in words how a loop and a multiplication fact match.
How this can be used for Computer Science
  1. Build a script that uses a repeat block to move a sprite.
  2. Change the number in the repeat block and observe the result.
  3. Nest one repeat block inside another.
  4. Debug a loop that runs too many times.
  5. Share a script and describe how the loop works.
