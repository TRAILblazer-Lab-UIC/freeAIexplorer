Learn Like a Computer (Canada Learning Code)

A 30-minute lesson with two games that model how computers learn from examples.

FREEAIUnpluggedNo device neededGood for AI beginners

Overview

Learn Like a Computer is a 30-minute lesson from Canada Learning Code. It is mostly unplugged. Learners play a picnic rule-guessing game to model supervised learning. They then play Hot or Cold to model reinforcement learning. They watch a video on how Amazon uses AI for deliveries and write a short reflection. The page lists the level as For Everyone, and a search snippet says grades 1 to 8.

Benefits

For students

  • Students feel how a computer learns from examples by playing games.
  • Students see the difference between two ways that machines learn.
  • Students write a short reflection about what they learned.

For teachers

  • The lesson has worksheets and a paired assessment.
  • The lesson is short and easy to fit into a day.
  • Extensions cover AlphaGo, Google Teachable Machine, and AI careers.

For schools

  • The lesson is free.
  • The download is a Google Doc.
  • The games need no devices, although the video needs a screen.

Getting started checklist

Where is the AI in this product?

The lesson has no running AI program. The picnic game models supervised learning, where a machine learns from labeled examples. Hot or Cold models reinforcement learning, where a machine learns by trial and error. Students practice both ideas by playing them. The extensions point to real tools such as Google Teachable Machine.

Privacy and safety

The games run on paper and in the room, and the materials describe no student data collection. The page mentions no account. A computer with the internet is needed for the remote version of Hot or Cold, which uses a public Scratch project, and for the optional Teachable Machine extension. The research did not review the terms of those tools. A teacher should preview the video and check that the extension tools suit the school before using them.

Ideas by subject

Select a subject to see five classroom ideas.

How this can be used for Computer Science
  1. Guess the picnic rule from examples and name what clue helped most.
  2. Play Hot or Cold and tell how feedback guided the guesser.
  3. Compare the picnic game and Hot or Cold and say which models which type of learning.
  4. Explain trial and error to a partner using the game.
  5. Write a reflection on how Amazon might use AI for deliveries.
How this can be used for Science
  1. Test a rule by gathering examples that fit and examples that do not.
  2. Record each guess in a table and look for a pattern.
  3. Make a hypothesis about the picnic rule and revise it as evidence grows.
  4. Compare how a computer learns with how a young child learns.
  5. Discuss how scientists use trial and error in experiments.
How this can be used for Math
  1. Count how many guesses it takes to find a hidden number.
  2. Use higher and lower hints to narrow the guess range.
  3. Compare two guessing strategies and tell which uses fewer guesses.
  4. Graph the number of guesses over several rounds.
  5. Explain why a good hint saves guesses.
