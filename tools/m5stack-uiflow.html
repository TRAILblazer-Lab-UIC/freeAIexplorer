M5Stack UiFlow

A web IDE for programming M5Stack ESP32 devices with blocks or MicroPython.

FREEComputingRoboticsSends student data to a company

Overview

UiFlow is M5Stack's web IDE for programming its ESP32 devices with blocks or MicroPython. The hosted version is cloud based. M5Stack also released a local server version of UiFlow 1.0 for Windows 11, macOS, Ubuntu 22.04 and Linux Arm, which runs the IDE at localhost:8800 on the school network. UiFlow 2.0 is not available in the local server. Firmware is flashed with M5Burner, which provides an API key to run programs.

Benefits

For students

  • Students program real devices with blocks.
  • Students can move to MicroPython.
  • Students see code run on a device.

For teachers

  • The tool is free to use.
  • A local server keeps the IDE on the school network.
  • Chrome or Edge work best for flashing through WebUSB.

For schools

  • UiFlow is free, but the M5Stack devices cost extra.
  • The hosted version needs the internet and sends data to the vendor.
  • A local server needs IT help.

Getting started checklist

Where is the AI in this product?

The vendor does not describe any AI in UiFlow. It turns blocks or MicroPython into programs for the device. Students build skills in logic and sensors.

Privacy and safety

The hosted IDE runs on M5Stack servers. Student programs go to the vendor. It needs the internet all the time. The materials do not say whether accounts are needed or what data is collected. The research read no privacy policy. A local server avoids the hosted service but supports only UiFlow 1.0, based on a 2023 article. A teacher should read the privacy terms and consider the local server. A teacher should also check that the school network allows the tools.
