MeerK40t

Free control software that runs K40, GRBL, and other laser cutters.

FREEComputingStays on the device

Overview

MeerK40t is open source control software for K40, GRBL, and fiber lasers. It supports controllers such as Lihuiyu K40, GRBL, EZCAD2-compatible galvo lasers, and Ruida. It has a graphical interface, a console, and a command line. The README describes the project as low maintenance.

Benefits

For students

  • Students send a design to a laser cutter or engraver.
  • Students learn a real fabrication workflow.
  • Students see how software controls a machine.

For teachers

  • The tool works with many laser controllers.
  • It is a hackable Python framework.
  • Laser safety is a real issue for classrooms.

For schools

  • The software is free but needs a compatible laser cutter.
  • It runs on Windows, macOS, Linux, and Raspberry Pi.
  • IT approval may be needed.

Getting started checklist

Where is the AI in this product?

MeerK40t has no AI. The vendor describes no AI features. Students build skills in sequencing and precise instructions as they plan cuts and engraves.

Privacy and safety

The software runs on the device and needs no account. The internet is used for setup. The research found no privacy policy. The wiki does not mention telemetry or data collection. It lists a Web Interface and Telnet as optional remote control options. These would open a network service on the school machine if enabled. A teacher should keep those options off and check the laser safety plan, ventilation, and who may run the machine.
