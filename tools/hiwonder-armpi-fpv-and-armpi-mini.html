Hiwonder ArmPi FPV and ArmPi mini

A Raspberry Pi robotic arm with a camera and Python AI vision tutorials.

$$$AIComputingRoboticsStays on the device

Overview

ArmPi FPV is a 6 degree of freedom robotic arm driven by a Raspberry Pi with a wide-angle camera. ArmPi mini is a smaller version. Vendor material lists color, tag, and face recognition, object sorting, and target tracking using OpenCV. The vendor does not state a grade range. The kit suits advanced high school students.

Benefits

For students

  • Students program an arm that finds and moves objects.
  • Students learn Python with OpenCV tutorials.
  • A phone app lets students try AI modes quickly.

For teachers

  • Tutorials cover OpenCV, ROS, and MoveIt.
  • The phone companion app is the easiest first step.
  • The Raspberry Pi Magazine review rated the FPV 9 out of 10.

For schools

  • Raspberry Pi Magazine lists the reviewed FPV kit at 300 USD. Kit tiers differ.
  • The AI runs on the device and the internet is needed at setup only.
  • The reviewer noted a loose camera cable. Plan time for repairs.

Getting started checklist

Where is the AI in this product?

The AI uses OpenCV to recognize colors, tags, and faces and to track objects. It runs on the Raspberry Pi. Students use the phone app or write Python to tell the arm what to do with what it sees. They can sort objects by color.

How this can be used for Engineering and Design
  1. Assemble the arm and test each joint.
  2. Check the camera cable and secure it.
  3. Set up a sorting station with colored blocks.
  4. Measure how often the arm picks up an object on the first try.
  5. Compare the FPV and the mini and list the design differences.
How this can be used for Computer Science
  1. Run an AI mode from the phone app and describe what the arm does.
  2. Read the Python color recognition tutorial and explain each step.
  3. Change the code so the arm sorts a new color.
  4. Use tag recognition to make the arm do a different task for each tag.
  5. Record how lighting affects recognition and write a short report.
