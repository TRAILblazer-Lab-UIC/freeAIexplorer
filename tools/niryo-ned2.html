Niryo Ned2

A six-axis desktop robot arm with block coding, Python and simulation.

ComputingRoboticsUnverified

The privacy details for this item are unverified. Check which tools and accounts students will use before class.

Overview

Ned2 is a six-axis desktop robot arm that Niryo describes as open-source by design and built on a Raspberry Pi. NiryoStudio is the free software with block coding, Python and simulation. NiryoAcademy offers over 150 hours of lesson plans. Niryo markets to K-12, technical colleges and universities.

Benefits

For students

  • Students program an arm that works like an industrial robot.
  • Students move from blocks to Python in the same software.
  • Students can test in simulation before they run the arm.

For teachers

  • NiryoAcademy claims over 150 hours of lesson plans.
  • The arm works with ROS and ROS 2 for advanced classes.
  • Teachers can plan automation lessons around one device.

For schools

  • The page lists no price. Retailers showed about 3,990 EUR excluding VAT.
  • Classroom packs of 5, 10 or 15 are quoted on request.
  • IT must connect the computers to the same network as the arm.

Getting started checklist

Where is the AI in this product?

Ned2 has no AI. It builds skills in sequencing, logic and automation. Students plan the exact moves of an arm and test them.

Privacy and safety

The page describes the software as running on the robot and the computer, and it says the internet is needed at setup. The page does not address data handling or cloud features, and the research reviewed no privacy policy. The materials do not clearly state whether NiryoAcademy needs accounts. A teacher should check NiryoAcademy's account and data terms and keep hands clear of the arm while it moves.

How this can be used for Computer Science
  1. Use NiryoStudio blocks to move the arm along a path.
  2. Rewrite the same program in Python with PyNiryo.
  3. Run a program in simulation and then on the arm.
  4. Use a loop to repeat a task five times.
  5. Debug a program that sends the arm to the wrong spot.
