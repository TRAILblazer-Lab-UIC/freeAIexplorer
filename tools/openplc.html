OpenPLC

Open source software for programming industrial logic controllers.

FREEComputingRoboticsStays on the device

Overview

OpenPLC is an open source programmable logic controller platform with two parts. OpenPLC Editor is the programming software. OpenPLC Runtime executes the program and handles input and output. It uses the IEC 61131-3 languages. The Sites page describes use in an undergraduate industrial controls course.

Benefits

For students

  • Students learn the languages used in factory automation.
  • Students can run programs on a Raspberry Pi.
  • Students work with real control logic.

For teachers

  • The software is free and open source.
  • It fits industrial controls and career and technical courses.
  • A browser simulator exists in the web editor.

For schools

  • The software costs nothing. Controller hardware is bought separately.
  • The Editor runs on Windows and Linux, with macOS described as beta.
  • Chromebooks are not supported per the pages read.

Getting started checklist

Where is the AI in this product?

OpenPLC has no AI. It builds skills in logic, sequencing and control. Students write programs that decide what a machine does from its inputs.

Privacy and safety

The Editor and Runtime run on local machines, and the pages read describe no accounts or cloud service for them. The internet is used at setup. The research found no privacy policy. The web editor needs an Autonomy platform account, and its docs mention analytics that exclude names, emails, and program text. The research did not assess that account for student privacy. A teacher should read the web editor's terms before use. Students should wire hardware only under teacher supervision.

How this can be used for Engineering and Design
  1. Wire a switch and a lamp to the controller and test the logic.
  2. Draw a ladder diagram for a simple machine.
  3. Test what happens when an input fails.
  4. Add a safety stop to a design.
  5. Document the wiring for another team.
How this can be used for Computer Science
  1. Write a ladder logic program for a light with a button.
  2. Use a timer in a program and describe the effect.
  3. Compare two IEC 61131-3 languages for the same task.
  4. Run the program in the browser simulator.
  5. Debug a program that never turns the output off.
