BlueJ

A free beginner Java environment that also supports the Stride language.

Computing

Overview

BlueJ is a free Java development environment designed for beginners. King's College London creates it, and Oracle supports it. It supports Java and the frame-based Stride language, and projects can mix both. It runs as a desktop application on Windows, macOS, and Linux.

Benefits

For students

  • Students can see objects in their programs.
  • Students can try Stride, a frame-based language, before text Java.
  • Students use a tool built for beginners.

For teachers

  • The object view makes it easier to show how classes work.
  • Teachers can mix Java and Stride in one project.
  • The tool suits teachers who are ready to teach Java.

For schools

  • The software is free under GPLv2 with Classpath Exception, as the site states.
  • A standalone Windows zip can run from a USB drive.
  • IT approval may be needed for the install.

Getting started checklist

Where is the AI in this product?

BlueJ has no AI. It builds the skills of logic and object thinking, as students design classes and test them. It also builds debugging habits.

Privacy and safety

BlueJ runs on the device, and no account is needed. The internet is needed for setup. The Blackbox research project collects source edits, compilation results, and tool use from opted-in users. Researchers at recognized institutions can request that data. The research did not confirm whether Blackbox is on by default. A teacher should ask IT to check the Blackbox setting. Network administrators can opt out in the bluej.defs file.

How this can be used for Computer Science
  1. Create a class and make an object from it, then look at the object in the workbench.
  2. Write a method that returns a greeting.
  3. Try a short Stride program and compare it to Java.
  4. Fix a compile error and explain the message.
  5. Build a small program that models a pet or a bank account.
