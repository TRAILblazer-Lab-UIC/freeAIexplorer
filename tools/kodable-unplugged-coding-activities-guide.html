Kodable unplugged coding activities guide

A free guide with 13 unplugged coding activities for grades K-5.

FREEComputingUnpluggedNo device needed

Overview

This free elementary guide from Kodable lists 13 unplugged activities across sequence, conditions, loops, functions, and properties. It adds three multi-day capstone projects. Core activities run 5 to 30 minutes, and most need little or no materials. Examples include Code a Friend, A Loopy Routine, and Beaded Bracelets.

Benefits

For students

  • Students learn core coding ideas through short games and crafts.
  • Students link coding to art, music, and science.
  • Older students can build a board game or a choose-your-own-adventure story.

For teachers

  • Printable worksheet packs exist for K-1, 2-3, and 4-5.
  • Capstones are for grade 3 and up.
  • A Rock Paper Scissors handout helps students track conditions.

For schools

  • The guide and worksheets are free.
  • The Kodable app is a separate product with paid plans.
  • Materials include paper, origami paper, string, and beads.

Getting started checklist

Where is the AI in this product?

This guide has no AI. It builds sequencing, conditions, loops, and functions. Students practice each idea with a hands-on task and then name the idea.

Privacy and safety

The activities run on paper and simple materials, and the guide says they need no account. The guide invites teachers to create a free Kodable account for the app lessons, which is a separate product. The research did not read the privacy policy. The guide is written by the vendor, and no independent study of it was found. A teacher should check the separate Kodable app terms before students use it.

Ideas by subject

Select a subject to see five classroom ideas.

How this can be used for Computer Science
  1. Play Code a Friend and give a partner step-by-step directions.
  2. Follow a Treasure Obstacle Course with a written sequence.
  3. Use the Rock Paper Scissors handout to track a condition.
  4. Write a loop for A Loopy Routine and count the repeats.
  5. Build a board game or an adventure story as a capstone.
How this can be used for Visual Arts
  1. Play If This Then Art and make a drawing from a set of conditions.
  2. Roll a die and add a shape based on the number.
  3. Trade rules with a partner and compare the art.
  4. Change one rule and see how the picture changes.
  5. Display your art with its rules.
How this can be used for Music
  1. Use Lyrical Function Finder to find the repeated parts of a song.
  2. Name the repeated part as a function.
  3. Write a new verse that reuses the function.
  4. Compare two songs and list their repeated parts.
  5. Sing a song and point to each function as it repeats.
How this can be used for Science
  1. Go on a Nature Scavenger Hunt and sort objects by their properties.
  2. Describe an object with three properties.
  3. Find two objects that share a property.
  4. Make a rule that sorts nature objects into groups.
  5. Draw a chart of the properties you found.
