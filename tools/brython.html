Brython

A Python 3 implementation that runs in the browser for web programming.

FREEComputingStays on the device

Overview

Brython is a Python 3 implementation for client-side web programming. Python code goes in a script element of type text/python and runs in the browser. It can reach page elements and events. The site offers an online console for trying code.

Benefits

For students

  • Students can use Python to change a web page.
  • Students can try code in the online console.
  • Students connect Python to the web.

For teachers

  • Teachers can teach web pages and Python together.
  • The online console needs no setup.
  • The project says speed is similar to CPython for most operations.

For schools

  • The software is free and open source.
  • It is a developer tool and not a ready classroom product.
  • Reviews report slower load times than precompiled tools.

Getting started checklist

Where is the AI in this product?

Brython has no AI. It builds the skills of logic and event handling, as students make a web page respond to a click. Students also practice reading Python.

Privacy and safety

No account is needed, and the code runs in the browser on the student's machine. The internet is needed for setup, and pages that load the library from a CDN contact that CDN each time. The research found no privacy policy. The vendor materials list no student data collection. A teacher should check where students host any pages they make and whether those pages load Brython from a CDN.
