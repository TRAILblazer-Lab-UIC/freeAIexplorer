Florida Poly Counting M&Ms OpenCV lesson

A computer vision lesson where students write Python to count M&Ms by color.

Overview

This is a computer vision outreach lesson from Florida Polytechnic University. Students write Python with OpenCV to count M&M candies by color in a video feed. They use color conversion, masking, dilation, and thresholding. Search results say the lesson comes with Colab notebooks, an answer key, a vocabulary sheet, and sample images.

Benefits

For students

  • Students use code to count real objects on camera.
  • Students learn how a computer separates colors.
  • Students practice Python with a fun, hands-on example.

For teachers

  • The lesson includes an answer key and a vocabulary sheet.
  • Notebooks run in Google Colab with sample images.

For schools

Getting started checklist

Where is the AI in this product?

The lesson teaches computer vision with OpenCV, a classic image processing tool. The vendor does not describe any trained AI model. The code runs in a Colab notebook in the cloud. Students write code that finds shapes and colors in a video and then build on it to count and sort.

Privacy and safety

The materials do not state which tools or accounts students need. The lesson runs in Google Colab, and the research notes that code and images then go to Google. How this can be used for Computer Science
  1. Convert an image to a different color space and describe what changed.
  2. Write a mask that finds only the red candies.
  3. Count the candies of each color and print the results.
  4. Change a threshold value and note how the count changes.
  5. Test the code on a new video and fix one error.
How this can be used for Math
  1. Count candies by color and make a bar graph.
  2. Compare a hand count with the program's count and find the difference.
  3. Estimate the share of each color and check it with the program.
  4. Test how a threshold value changes the answer and record the numbers.
  5. Predict the count in a new bag and compare it with the result.
