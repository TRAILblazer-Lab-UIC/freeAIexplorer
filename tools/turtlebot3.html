TurtleBot3

A small customizable ROS-based robot for advanced students in navigation and mapping.

ComputingRoboticsStays on the device

Overview

TurtleBot3 is a small, affordable, customizable ROS-based mobile robot made by ROBOTIS with Open Robotics. It supports SLAM, navigation, and manipulation. The standard single-board computer is a Raspberry Pi 4. Models include Burger and Waffle Pi.

Benefits

For students

  • Students work with the same robot software used in university labs.
  • Students map a room and make the robot navigate it.
  • Students write real code on Linux.

For teachers

  • The ROBOTIS e-Manual guides assembly and setup.
  • ROS 2 support is listed, with Humble prioritized.
  • The GitHub license is Apache-2.0.

For schools

  • The e-manual lists no price. Launch academic pre-order prices were 499 USD for Burger and 1599 USD for the Waffle.
  • Hardware and code are open source.
  • Setup takes days and needs IT and staff with Linux and ROS skills.

Getting started checklist

Where is the AI in this product?

TurtleBot3 has no AI of its own. It runs ROS software that students configure and program. Students build skills in sensing, mapping, and programming.

Privacy and safety

No account is needed. The robot runs on local hardware with ROS. Package installation needs the internet. The pages read describe no cloud service. The robot and the PC must talk to each other on the local network. Check network settings with IT. The original Waffle was discontinued. Confirm which model is for sale.

How this can be used for Engineering and Design
  1. Assemble the Burger from the manual and test each part.
  2. Drive the robot in a simple course and note how it handles.
  3. Compare the Burger and the Waffle Pi in a short report.
  4. Use the robot's sensors to map a classroom corner.
  5. Plan a navigation task and judge how well the robot did it.
How this can be used for Computer Science
  1. Write a short ROS program that moves the robot.
  2. Configure the network between a PC and the robot.
  3. Read the code of a basic navigation example and explain it.
  4. Change a setting and observe the effect.
  5. Debug a connection problem between the PC and the robot.
