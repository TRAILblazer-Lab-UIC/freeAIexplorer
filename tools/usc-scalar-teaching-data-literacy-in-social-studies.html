USC Scalar Teaching Data Literacy in Social Studies

A Scalar website that helps teachers teach data visualization in social studies.

FREEComputingUnverified

The privacy details for this item are unverified. Check which tools and accounts students will use before class.

Overview

This is a Scalar website that supports teachers in teaching data visualization literacy in social studies. It has sections on a taxonomy of visualizations, visualizations as primary sources, and how students learn from them. It also offers short tool guides called minimal manuals and an index of lesson plans by school level. The site is an unfinished teacher professional development tool.

Benefits

For students

  • Students learn to read maps and charts as primary sources.
  • Students study historical data such as Civil War maps.
  • Students can later build their own data based projects.

For teachers

  • Lesson plans are grouped by school level for fourth grade, middle school, and high school.
  • Minimal manuals give short guides for student data tools.
  • The taxonomy helps teachers name types of visualizations.

For schools

  • The site is free to read online.
  • It needs only a browser, including on Chromebooks.
  • Some pages still hold placeholder text.

Getting started checklist

Where is the AI in this product?

The materials describe no AI. The site is a set of readable pages and guides. Students build data skills as they read, compare, and question visualizations.

Privacy and safety

The research read the public pages without signing in. The site needs no account and the internet is always needed. The pages name no student data collection. The student tools in the minimal manuals were not named. Where their data goes is unknown. Check the privacy terms of each student data tool before class.

How this can be used for Social Studies
  1. Read four John Formby maps of the Civil War from 1861 to 1864 as data visualizations.
  2. Compare two maps and list what each one shows.
  3. Ask who made a visualization and why.
  4. Write a caption that explains a map to a younger student.
  5. Build a short timeline using data from a visualization.
How this can be used for Library and Media Literacy
  1. Sort a set of charts using the taxonomy.
  2. Check the source of a chart and rate how trustworthy it is.
  3. Compare two charts that use the same data.
  4. Practice citing a visualization as a primary source.
  5. Create a guide that helps classmates read charts.
