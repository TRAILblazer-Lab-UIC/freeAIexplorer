Logisim-evolution

A free desktop tool for designing and simulating digital logic and processors.

FREEComputingStays on the device

Overview

Logisim-evolution is a free, open source logic design tool made for education. It is a community fork of the original Logisim. It adds a timing diagram view, FPGA board integration, VHDL components, and a large component library. It is a desktop Java application that needs Java 21 or newer.

Benefits

For students

  • Students design and simulate digital logic and processors.
  • Students see signals over time in the timing diagram.
  • Students can link designs to FPGA boards.

For teachers

  • The tool offers many interface languages.
  • The release v5.0.0 came out on 2026-09-12 and the project is active.
  • The tool suits advanced high school courses, and teachers need some experience.

For schools

  • The software is free.
  • It runs on Windows, macOS, and Linux.
  • IT must install Java 21 or newer. It is not intended for Chromebooks unless Linux apps are enabled.

Getting started checklist

Where is the AI in this product?

Logisim-evolution has no AI. It builds logic and sequencing skills. Students trace how inputs flow through gates and change an output over time.

Privacy and safety

The tool runs on the device and needs no account. The internet is used for the download. The repository page does not mention telemetry. The research found no privacy policy. A teacher should check where students save designs and that the school allows the unsigned macOS app and Java.

How this can be used for Computer Science
  1. Build an adder from basic gates and test it with several inputs.
  2. Design a one-bit memory cell and watch it hold a value.
  3. Use the timing diagram to see how a clock signal changes the circuit.
  4. Build a simple counter and explain how it counts.
  5. Combine parts into a small processor design and describe each part.
How this can be used for Engineering and Design
  1. Write a short VHDL component and add it to a design.
  2. Connect a design to an FPGA board if the lab has one.
  3. Use the component library to build a circuit faster.
  4. Compare two designs for the same task and judge which is simpler.
  5. Document a design with labels so a classmate can follow it.
