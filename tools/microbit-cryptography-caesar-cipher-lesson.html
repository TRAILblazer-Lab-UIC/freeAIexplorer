micro:bit Cryptography Caesar cipher lesson

A lesson where students build a paper Caesar cipher and then code it.

ComputingUnplugged

The privacy details for this item are unverified. Check which tools and accounts students will use before class.

Overview

This is Lesson 2 of 3 in the micro:bit Introduction to cryptography unit, made with Nominet for ages 11 to 14. Students first build and use a paper Caesar cipher with cards to encrypt and decrypt messages. They then write, test, and debug encryption and decryption algorithms in code. The page lists a lesson plan, slides, and a Caesar cipher worksheet.

Benefits

For students

  • Students send and crack secret messages with a paper cipher.
  • Students write and debug real encryption algorithms.
  • Students use letter shifting, which builds number sense.

For teachers

  • A lesson plan, slides, and a worksheet are ready to use.
  • A Tes listing says the unit runs about 60 minutes per lesson.
  • The lesson sits between What is cryptography and Ciphers and text-based programming.

For schools

  • The downloads are free.
  • The paper part needs only printed cards.
  • The coding part uses MakeCode or Python in a browser.

Getting started checklist

Where is the AI in this product?

This lesson has no AI. It builds algorithm design, testing, and debugging. Students write steps that scramble and unscramble a message.

Privacy and safety

The paper part runs in the room. The page lists MakeCode and Python as tools and does not mention accounts. The materials do not say how student code is stored. The research did not review MakeCode editor data practices and read no privacy policy. A teacher should check the editor terms and decide where students save their work.

Ideas by subject

How this can be used for Computer Science
  1. Build a paper Caesar cipher and encrypt a short message.
  2. Decrypt a partner's message with the same cipher.
  3. Write an encryption algorithm in code and test it.
  4. Debug a decryption algorithm that gives the wrong letters.
  5. Compare the paper cipher with the coded version.
How this can be used for Math
  1. Shift each letter by a set number and write the new message.
  2. Find the shift that a partner used by testing all options.
  3. Describe what happens when a shift goes past the letter Z.
  4. Map letters to numbers and add the shift.
  5. Compare two shift values and describe the pattern.
