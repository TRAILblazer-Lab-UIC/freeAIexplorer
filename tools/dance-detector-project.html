Getting started checklist

Where is the AI in this product?

Students train a machine learning model from accelerometer data. The model is built in the browser through CreateAI and used with the micro:bit. Students record dance moves, train the model, and test how well it tells them apart.

How this can be used for Computer Science
  1. Record two dance moves and train a model to tell them apart.
  2. Test the model with a classmate and list where it fails.
  3. Add more samples and see whether accuracy improves.
  4. Explain what the accelerometer measures in a dance move.
  5. Make the micro:bit show a symbol for each move it detects.
