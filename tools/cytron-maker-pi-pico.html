Cytron Maker Pi Pico

A starter board with LEDs, buttons, and a buzzer that a Raspberry Pi Pico plugs into.

$ComputingStays on the device

Overview

Maker Pi Pico is a starter board from Cytron. A Raspberry Pi Pico plugs into it. The board adds indicator LEDs, programmable buttons, a piezo buzzer, an audio out jack, a micro SD card socket, and an ESP-01 socket for an optional WiFi module. It is programmed in MicroPython or C and C++ over USB.

Benefits

For students

  • Students get buttons, lights, and a buzzer on one board.
  • Students program real inputs and outputs.
  • Students can write MicroPython or C and C++.

For teachers

  • The board has a reset button and a debugging port breakout.
  • Teachers can start with simple projects such as a button and a buzzer.
  • Example code on the Cytron GitHub is MIT licensed.

For schools

  • Search snippets list a version with a Pico soldered on at 13.90 USD at RobotShop.
  • The base board does not include a Pico.
  • No account is needed, and no internet is needed.

Getting started checklist

Where is the AI in this product?

This board has no AI. It builds skills in logic and sensors. Students read button presses and control lights and sound with code.

Privacy and safety

No account is needed, and the board works without the internet. Programs load over USB from a local computer. No privacy policy was reviewed. The optional ESP-01 socket allows a WiFi module, which would add network traffic if used. A teacher should confirm that the Maker Pi Pico is the right board. Cytron also sells a different Maker Pi RP2040.
