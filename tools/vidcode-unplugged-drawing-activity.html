How this can be used for Computer Science
  1. Draw a simple picture and write directions that let a partner copy it.
  2. Follow a partner's directions exactly and compare the result with the original.
  3. Find the direction that caused a difference and fix it.
  4. Give directions to the whole class and see how many drawings match.
  5. Rewrite your directions using shorter and clearer steps.
