NetLogo

Free agent based modeling software where students program simulations.

Computing

Overview

NetLogo is a free agent based modeling environment. Students program turtles, patches, and links to run simulations. A large models library spans art, biology, chemistry and physics, earth science, math, psychology, and social science. Students run models, change settings, and write their own rules in the NetLogo language.

Benefits

For students

  • Students see how simple rules lead to complex patterns.
  • Students can start by running models and then write code.
  • HubNet lets each student control an agent in a class simulation.

For teachers

  • Curricular model sets such as CT-STEM and Connected Chemistry tie to classroom units.
  • BehaviorSpace runs experiments across many settings.
  • A one hour CT-STEM lesson, Intro to NetLogo Programming for Educators, covers turtles, procedures, and patches.

For schools

  • The software is free and open source.
  • Java 17 is bundled. No separate Java install is needed.
  • Chromebooks and mobile devices are not supported. NetLogo Web is the browser option.

Getting started checklist

Where is the AI in this product?

This tool has no AI. It runs simulations from rules that students write. Students build skills in modeling, logic, and pattern spotting.

Privacy and safety

No account is needed, and models and data stay on the local computer. The internet is used at setup. The research reviewed no privacy policy and could not verify telemetry. HubNet activities use the local school network. A teacher should ask IT to check network activity after install and preview models from the social science set before use.

Ideas by subject

How this can be used for Science
  1. Run the Evolution of Populations model and describe how traits change.
  2. Use the Ideal Gas Laws model and change the temperature.
  3. Compare two models of the same system and note the differences.
  4. Run a BehaviorSpace experiment and graph the results.
  5. Write a prediction before each run and check it.
How this can be used for Computer Science
  1. Follow the Intro to NetLogo Programming lesson and write a procedure.
  2. Program a turtle to move in a random walk.
  3. Change the rules for patches and watch the result.
  4. Add a slider and use it in a rule.
  5. Debug a model that does not run and explain the fix.
How this can be used for Social Studies
  1. Run the Sugarscape model and describe how wealth spreads.
  2. Run the Prisoner's Dilemma model and discuss choices.
  3. Change one rule and predict the effect on the society.
  4. Compare the model to a real community.
  5. Write about what a model leaves out.
