Kaplan Cooper STEM Robot classroom set

A set of four screen-free coding robots with cards and lesson plans.

ComputingRobotics

Overview

This classroom set has four Cooper the STEM Robot units and a ball. Kaplan Early Learning sells it as item 302761, and Learning Resources makes it. Children place coding cards to build sequences that make Cooper move, make sounds and react. The set includes 40 coding cards and 20 teacher lesson plans. The NAPPA Awards page gives the age as 5 and up, and Kaplan recommends kindergarten and early elementary.

Benefits

For students

  • Students code without a screen.
  • Students build sequences with coding cards.
  • Students can link robots for small-group challenges.

For teachers

  • The set includes 20 lesson plans and a quick start guide.
  • Four robots allow small-group work.
  • The set charges with one 4-way cable.

For schools

  • Kaplan lists the set at 329.95 USD, and the NAPPA Awards page lists 299.99 USD.
  • The robots are rechargeable and need no batteries.
  • The listing describes the set as screen free with no app.

Getting started checklist

Where is the AI in this product?

Cooper has no AI. It follows the sequence of cards that children place. Children build the skill of sequencing, which means putting steps in the right order.

Privacy and safety

The product is described as screen free with no app, and the listing describes no data collection. The robot's data practices are not documented. The research did not confirm whether any account or internet is used. A teacher should keep the set away from children under 3 because of small parts. A teacher should also supervise charging.

How this can be used for Computer Science
  1. Place coding cards in a row and watch Cooper follow the sequence.
  2. Change one card and predict how Cooper's path will change.
  3. Work with a partner to guide Cooper to the ball.
  4. Link two robots and solve a small-group challenge.
  5. Tell a story by building a sequence of moves, sounds and reactions.
