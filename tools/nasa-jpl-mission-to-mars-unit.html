NASA JPL Mission to Mars Unit

A free set of Mars lessons for grades K to 9 with some coding and robotics.

FREEComputingRoboticsUnverified

The privacy details for this item are unverified. Check which tools and accounts students will use before class.

Overview

The Mission to Mars unit is a collection of lessons for grades K to 9 on Mars exploration. Lessons run in six stages, from learning about Mars to surface operations. Many are hands-on science and engineering activities. Several involve coding in Scratch, and some robotics lessons need a programmable rover or microcontrollers.

Benefits

For students

  • Students explore Mars through hands-on science and engineering.
  • Students code Mars games in Scratch.
  • Students make paper and craft rockets and rovers.

For teachers

  • Teachers can pick lessons from six clear stages.
  • Each lesson page lists its materials.
  • Only a few lessons need programming. Teachers can choose their level of coding.

For schools

  • The lessons are free.
  • Everyday materials cover most lessons. Some robotics lessons need extra hardware.
  • No IT work is expected for most lessons.

Getting started checklist

Where is the AI in this product?

The unit has no AI. It builds skills in sequencing and logic through Scratch coding. The Heat Flow Programming Challenge also gives students practice with sensor data.

Privacy and safety

The materials do not state what data is collected or whether accounts are needed. The Scratch lessons use the Scratch website, and the research did not review its account or data practices. The only privacy link on the page covers JPL image use. The unit works in a browser and on paper. A teacher should check the Scratch settings and the school's rules for student accounts before class.

Ideas by subject

Select a subject to see five classroom ideas.

How this can be used for Science
  1. Learn about Mars in the first stage and write three facts to share.
  2. Explore Mars with Scratch and describe what the game shows about the planet.
  3. Compare the conditions on Mars with those on Earth.
  4. Run the Heat Flow Programming Challenge and discuss the data.
  5. Plan the surface operations of a mission and explain each step.
How this can be used for Engineering and Design
  1. Design and build a paper rocket and test how far it flies.
  2. Make a Moon or Mars rover game and then design a rover on paper.
  3. Change a rover design after a test and record the result.
  4. Build a craft rover that can cross a small obstacle.
  5. Present a design to the class and answer questions.
How this can be used for Computer Science
  1. Code a Mars helicopter video game in Scratch.
  2. Explore Mars with Scratch and add a new sprite.
  3. Make a Moon or Mars rover game with simple controls.
  4. Fix a bug in a classmate's game.
  5. Write the steps of a rover task in plain words and then in code.
How this can be used for Math
  1. Measure the distance a paper rocket flies and find the class average.
  2. Chart data from a Mars lesson.
  3. Use measurement to scale a rover model.
  4. Compare numbers about Mars and Earth.
  5. Count the points in a Scratch game and graph the scores.
