Robot Turtles

A board game where young children program turtles with code cards.

$ComputingUnpluggedNo device needed

Overview

Robot Turtles is a board game by Dan Shapiro, published by ThinkFun. It teaches programming logic to children ages 4 and up. Children play code cards to move turtles to a gem while an adult acts as the computer. Play adds walls and crates, then written programs and a Function Frog card.

Benefits

For students

  • Students learn to plan a path before they move.
  • Students find their own mistakes when the turtle goes the wrong way.
  • Students meet programs and functions in later levels.

For teachers

  • The box holds four decks of 44 code cards, a board, turtle tiles and obstacle tiles.
  • One adult acts as the Turtle Mover and runs each game.
  • A game takes about 15 minutes.

For schools

  • The game costs about 25 to 35 USD per set, based on press and retailer prices.
  • It needs no devices or internet.
  • It collects no student data.

Getting started checklist

Where is the AI in this product?

This game has no AI. It builds an AI-related skill, which is sequencing. Children plan a list of commands and the adult follows them exactly.

Privacy and safety

The game is a physical board game. No accounts are needed. No student data is collected. A teacher should check that the adult acting as the computer follows the cards exactly. The research did not confirm whether the game is still in print.

How this can be used for Computer Science
  1. Play code cards to move a turtle to the gem while a teacher acts as the computer.
  2. Add walls and crates and plan a new path around them.
  3. Write a full program on cards before the adult runs it.
  4. Find a mistake in a card list and debug it.
  5. Use the Function Frog card to reuse a short set of moves.
