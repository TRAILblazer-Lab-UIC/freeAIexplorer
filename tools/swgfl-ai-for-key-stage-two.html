SWGfL AI for Key Stage Two

A 5 page lesson plan that teaches how machine learning works and where it fails.

FREEAIUnverifiedGood for AI beginners

The privacy details for this item are unverified. Check which tools and accounts students will use before class.

Overview

This lesson plan from SWGfL is for Years 3 to 6, ages 7 to 11. Pupils start with a duck or not duck game. They then use Google Teachable Machine to teach a machine to tell inputs apart. They test how flawed inputs give wrong outputs and finish with a trust continuum.

Benefits

For students

  • Students train a simple model and see how it learns.
  • Students see how poor training data leads to wrong answers.
  • Students practice deciding how far to trust AI.

For teachers

  • The plan is short and has a slide deck.
  • It lists extension ideas in art, music, English, and history.
  • It maps to England KS2 Computing, the Welsh Digital Competence Framework, and Scotland's Curriculum for Excellence.

For schools

  • The plan is free to download.
  • Pupils need tablets or laptops with internet access.
  • IT involvement is minimal.

Getting started checklist

Where is the AI in this product?

The AI is a machine learning model that pupils train in Teachable Machine. It sorts images by what it learned from their examples. Pupils see how bias in the examples changes the answers. Teachable Machine runs in the browser.

Privacy and safety

Pupils need internet-connected devices for Teachable Machine. The plan does not describe data handling. The research did not review the Teachable Machine privacy terms or confirm whether an account is needed. One extension idea uses DALL-E 2, which requires a login. Check how Teachable Machine handles images before pupils use cameras. Use sample images and avoid faces.

How this can be used for Computer Science
  1. Play the duck or not duck game and explain how you decided.
  2. Train a model to tell two classroom objects apart.
  3. Add a bad example to the training set and describe the change.
  4. Place your trust in AI on the continuum and explain why.
  5. Test the model with a new object and record the result.
