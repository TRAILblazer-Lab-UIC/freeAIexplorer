micro:bit lessons hub

A library of 26 free micro:bit lesson collections for ages 7 to 16.

AIComputing

Overview

This is a library page listing 26 lesson collections for the micro:bit. Collections are labeled as units of work or design challenges. Age bands run from 7-11 up to 14-16. Topics include MakeCode, Python, data handling, electrical conductors, cryptography, cyber security, and AI literacy.

Benefits

For students

  • Students learn coding with a small physical device.
  • Students try many topics from music to cryptography.
  • Students can explore AI literacy and machine learning.

For teachers

  • Each collection has 2 to 8 lessons.
  • Teachers can pick by age and topic.
  • Lessons download as a zip file.

For schools

  • The lessons are free.
  • Boards are a paid purchase.
  • Several units link to national curricula and to CSTA and Code.org standards.

Getting started checklist

Where is the AI in this product?

The AI is optional. The hub lists a Developing AI literacy collection and CreateAI units on machine learning. The vendor does not say where all the AI runs. Students explore how a model learns from data and then use it in their own projects.

Privacy and safety

The hub page does not state accounts or privacy terms. The pages read do not state any student data collection. The research did not check where the CreateAI tool trains and runs models. Units use other tools that have their own terms. The internet is used at setup. A teacher should check each unit for extra tools or sign ins and for the CreateAI data flow.

How this can be used for Computer Science
  1. Complete the First lessons with MakeCode and share a program.
  2. Build a Musical micro:bit project that plays a tune.
  3. Try the Developing AI literacy collection and explain one idea.
  4. Write a short Python program in the Python editor.
  5. Make a simple code and decode a message in a cryptography unit.
How this can be used for Science
  1. Test which materials conduct electricity with a micro:bit circuit.
  2. Log a temperature over a day and chart it.
  3. Use the Being active collection to track movement.
  4. Compare readings from two sensors.
  5. Write a conclusion about what your data shows.
