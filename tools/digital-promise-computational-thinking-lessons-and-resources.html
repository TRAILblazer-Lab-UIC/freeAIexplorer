Digital Promise Computational Thinking lessons and resources

Overview

Digital Promise hosts a Computational Thinking Lesson Library. It had 132 results at the time of reading. It gives educators examples of lessons that bring computational thinking into math, science, ELA, arts, social studies, and STEM. Users filter by subject, grade band, and resource type. Many entries link to outside providers such as Barefoot Computing and CS Lessons.

Benefits

For students

  • Students meet computational thinking inside the subjects they study.
  • Students try plugged and unplugged activities.
  • Students practice ideas such as algorithms and patterns.

For teachers

  • Teachers can filter by subject and grade band.
  • Example lessons are meant to be adapted.
  • Example titles include Creating Algorithms, Patterns in Text, and Write a Flowchart.

For schools

  • The library is listed openly and the cost is free.
  • The page states no license, and linked resources may differ.
  • Some lessons need printing or an outside tool.

Getting started checklist

Where is the AI in this product?

This library has no AI. It builds skills in algorithms, patterns, and decomposition. Students practice thinking step by step as they break a problem into parts. The library itself runs no software of its own.

Privacy and safety

The library is a set of web pages, and many lessons link to outside providers. The materials do not state which tools or accounts students need. Individual lessons may use tools such as Scratch, which have their own data practices. The research did not review lessons one by one. A teacher should check each linked resource for its own account and privacy terms before students use it.

Ideas by subject

Select a subject to see five classroom ideas.

How this can be used for Computer Science
  1. Write a flowchart for a daily routine.
  2. Create an algorithm to sort a set of cards.
  3. Break a big task into smaller steps with a partner.
  4. Find a pattern in a set of instructions.
  5. Debug a set of instructions that a partner has written.
How this can be used for Math
  1. Find a pattern in a number sequence and write a rule.
  2. Write an algorithm for a long multiplication problem.
  3. Break a word problem into steps.
  4. Compare two methods for the same problem.
  5. Explain a rule to a partner.
How this can be used for Science
  1. Write an algorithm for a simple experiment.
  2. Find a pattern in a set of observations.
  3. Break a science question into smaller questions.
  4. Model a cycle with a flowchart.
  5. Compare a model with real data.
How this can be used for English and Language Arts
  1. Find a pattern in a short text.
  2. Write steps that describe how a story unfolds.
  3. Break a text into parts and name each one.
  4. Use a flowchart to plan an essay.
  5. Trade steps with a partner and test them.
How this can be used for Social Studies
  1. Break down the causes of a historical event into steps.
  2. Write a flowchart for how a law is made.
  3. Find a pattern in a set of dates or places.
  4. Compare two timelines.
  5. Explain a process to a partner in order.
