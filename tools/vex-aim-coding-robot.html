VEX AIM Coding Robot

A coding robot with a built-in AI vision sensor that recognizes objects and AprilTags.

AIComputingRoboticsGood for AI beginners

Overview

VEX AIM is a coding robot with a built-in AI Vision Sensor, a screen that shows emojis, and a Kicker for sports balls. Students code in VEXcode AIM with Blocks, Switch, or Python. They can also use button coding and drive mode with no code. The sensor recognizes pre-trained objects such as sports balls and barrels and reads AprilTags.

Benefits

For students

  • Students code a robot that can see and kick a ball.
  • Students move from blocks to Switch to Python.
  • Students can start by driving the robot with no code.

Getting started checklist

Where is the AI in this product?

The AI is an on-device vision sensor with pre-trained models. It recognizes objects such as sports balls and barrels and detects AprilTags. Students write code that uses what the sensor sees to steer, aim, and kick. The robot also navigates on its own.

Privacy and safety

No account is needed for the robot. The VEXcode install, web or desktop, may need the internet at setup, and offline use was not confirmed. VEX says images stay on the device and no personally identifiable data is collected. These are vendor statements that have not been audited by others. A teacher should read the VEX privacy policy before use.

How this can be used for Computer Science
  1. Follow the VEX course to code the robot to find and kick a sports ball.
  2. Use AprilTags to tell the robot where to drive next.
  3. Change a block program into Switch and then into Python.
  4. Record how often the robot misidentifies an object in different light.
  5. Write a program that shows a different emoji for each object seen.
How this can be used for Engineering and Design
  1. Design a field with barrels and balls for the robot to cross.
  2. Test the Kicker at three distances and record the results.
  3. Tune the robot's turns until it reaches a target.
  4. Plan a team challenge and set scoring rules.
  5. Document what changed after each test run.
