Bootstrap Reactive

A Bootstrap module where students code animations and games in Pyret.

FREEComputingSends student data to a company

Overview

Bootstrap:Reactive is a computer science module that builds on Bootstrap:Algebra and teaches Pyret. Its core units cover data structures, animation design, and event-driven programming, and then students design a game. In the Structures, Reactors and Animations lesson, students model animation state and run a reactor on a starter file in code.pyret.org. The Bootstrap hub lists a Game Design course for grades 8-12 under the reactive path.

Benefits

For students

  • Students build an animation and a game.
  • Students learn how a program responds to events.
  • Students use a workbook and starter files.

For teachers

  • One Idaho school runs Algebra and Reactive as a single senior course.
  • Some schools use it as a module for the Create task in AP CS Principles.
  • Optional features such as scoring and Pong add extra choices.

For schools

  • The materials are free.
  • Students use a browser editor, and Chromebooks are listed.
  • The materials do not state what student data is collected.

Getting started checklist

Where is the AI in this product?

Bootstrap:Reactive has no AI. It builds the skills of logic and event handling, as students write rules for how a game reacts. Students also practice data structures.

Privacy and safety

Students code in code.pyret.org, a cloud editor. The internet is needed throughout. Accounts are optional. Saving through Google Drive is stated in batch notes, but the research did not verify it. An offline Pyret install is also mentioned and not verified. The materials do not say what student data is collected, and no privacy policy was read for this module. A teacher should check the privacy terms and decide whether students sign in.

How this can be used for Computer Science
  1. Model the state of an animation with a data structure, as in the Structures lesson.
  2. Write a draw-state function and a next-state-tick function.
  3. Run a reactor from a starter file and change the speed.
  4. Build your own animation of a moving object.
  5. Design a small game with scoring and play test it with a partner.
