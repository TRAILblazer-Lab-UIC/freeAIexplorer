micro:bit Being Active lessons

A micro:bit design challenge on exercise, heart health, and wearable devices.

Computing

Overview

This is a design challenge on the micro:bit site about why regular exercise helps prevent heart disease. The page lists three activities. Students build a Fitness friend reminder, a heart rate monitor, and a Walking for water step counter. The code is written in MakeCode.

Benefits

For students

  • Students learn why exercise matters for the heart.
  • Students build a wearable prototype.
  • Students use sensors and write algorithms.

For teachers

  • The page maps to England KS2 and KS3 computing, Code.org, CSTA grades 3-8, and Scotland health and wellbeing.
  • A lesson zip can be downloaded.
  • The page lists age ranges of 7-11, 9-12, and 11-14.

For schools

  • The lessons are free. A micro:bit board is a paid purchase.
  • The editor runs in a browser.
  • Chromebook use of the editor was not confirmed on the page read.

Getting started checklist

Where is the AI in this product?

These lessons have no AI. The heart rate is estimated from accelerometer movement with no machine learning. Students build skills in sensors, algorithms, and input and output.

Privacy and safety

The pages read do not discuss data handling, and they did not require a sign in. The code runs on the micro:bit, and the MakeCode editor runs in a browser or the offline app. The heart rate and step activities involve health style data. It stays on the board unless a teacher exports it. The research did not read the site privacy policy. A teacher should check the MakeCode privacy terms. A teacher should also remind students that the prototype is a class project and gives no medical advice.

Ideas by subject

Select a subject to see five classroom ideas.

How this can be used for Health and PE
  1. Explain why regular exercise helps the heart.
  2. Wear a step counter for a day and log the steps.
  3. Compare resting and active heart rate readings from the prototype.
  4. Set a weekly activity goal and track it.
  5. Design a reminder that encourages friends to move.
How this can be used for Computer Science
  1. Write an algorithm for a step counter in plain steps.
  2. Use input from the accelerometer to count a movement.
  3. Display the count on the LEDs.
  4. Test the program and fix any mistakes.
  5. Compare two algorithms and choose the better one.
How this can be used for Engineering and Design
  1. Sketch a wearable device and list what it needs.
  2. Build a prototype from a micro:bit and a strap.
  3. Test it while walking and note how well it works.
  4. Improve the design after testing.
  5. Present the final prototype to the class.
