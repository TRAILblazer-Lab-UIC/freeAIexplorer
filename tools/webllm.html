WebLLM

A library that runs large language models inside the web browser.

AIComputing

Overview

WebLLM is an in-browser language model engine that uses WebGPU for speed. Models run inside the browser with no server-side processing. It is a developer library with OpenAI API compatible calls. Educators would normally use it through an app built on the library.

Benefits

For students

  • Students can chat with a model that runs on their own computer.
  • Students can build web pages that use a language model.
  • Students learn how a model loads and answers.

For teachers

  • It supports models such as Llama, Phi, Gemma, Mistral, and Qwen.
  • The calls match the OpenAI API. Examples are easy to find.
  • Model files are cached in the browser.

For schools

  • The library is free.
  • The site says chat stays in the browser. No server is needed.
  • The first model load can be large and slow. Plan the network use.

Getting started checklist

Where is the AI in this product?

The AI is a large language model that generates text. It runs in the browser on the student device. Students type prompts and read the answers. Developers can also write code that calls the model from a web page.

Privacy and safety

No account is needed. The internet is used for the first model download, and the browser then caches the model files. The site says everything runs inside the browser with no server support. No WebLLM privacy policy was found, and an app built on the library may behave differently. A teacher should check the privacy terms of any app built on WebLLM and review the answers before students rely on them.

How this can be used for Computer Science
  1. Open a WebLLM demo and ask it three questions.
  2. Compare the answers from two different models.
  3. Write a short web page that sends a prompt and shows the reply.
  4. Measure how long a model takes to load and explain why.
  5. Test where the model gives a wrong answer and describe the pattern.
