LabsLand

A network of real remote labs that students run through a web browser.

FREEComputingRoboticsSends student data to a company

Overview

LabsLand is a remote laboratory network where users operate real physical equipment through a web browser. The home page lists 74 public labs, including an Arduino robot, electronics, a microscope and kinematics labs. LabsLand Teach lets a teacher pick a prepared lesson and share a class code. Students run the experiment and submit evidence for the teacher to review.

Benefits

For students

  • Students use real equipment from a school computer.
  • Students join a lesson with a class code.
  • Students submit evidence of what they found.

For teachers

  • Teachers choose from prepared lessons and review student evidence.
  • Filters sort labs for elementary, middle and high school.
  • Whole-class labs are listed as ultraconcurrent.

For schools

  • Schools request pricing from LabsLand, and some free labs are described.
  • The labs need only a standard browser and no drivers, per the vendor.
  • The platform needs the internet all the time.

Getting started checklist

Where is the AI in this product?

LabsLand has no AI. Students control real equipment that sits in a vendor lab. Students build skills in data collection by gathering evidence from a live experiment.

Privacy and safety

Accounts are required, and the work runs in the vendor's cloud. The vendor collects name, email, passwords, lab usage, IP address, device and browser data, and location. Instructors and administrators of a student's institution can see personal data and lab activity. Chat and social login providers such as Google, Microsoft, Facebook, and LinkedIn may receive data. The policy does not mention COPPA or FERPA, has no separate provisions for minors, and does not honor Do Not Track. A teacher should read the privacy policy and ask LabsLand about student data.

How this can be used for Science
  1. Run the Will it float buoyancy lesson and record what floats.
  2. Use the microscope lab to observe a sample and sketch it.
  3. Predict an outcome before running a lab and compare the result.
  4. Repeat a lab and check whether the evidence matches.
  5. Write a short report with the evidence submitted.
How this can be used for Engineering and Design
  1. Control the Arduino robot lab and record its path.
  2. Use a kinematics lab to measure motion.
  3. Compare two electronics lab runs and describe the difference.
  4. Plan a change to a lab setup and explain the reason.
  5. Present the data from a real lab to the class.
How this can be used for Computer Science
  1. Send a program to the Arduino robot lab and watch the result.
  2. Change one command and run the robot again.
  3. Write a sequence of moves on paper before sending it.
  4. Debug a program that sends the robot the wrong way.
  5. Explain how a remote lab differs from a simulator.
