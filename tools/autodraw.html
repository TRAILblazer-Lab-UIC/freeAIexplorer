AutoDraw

A free web drawing tool that suggests clean artwork for rough doodles.

FREEAIUnverifiedGood for AI beginners

The privacy details for this item are unverified. Check which tools and accounts students will use before class.

Overview

AutoDraw is a free web drawing tool from Google Creative Lab. Machine learning guesses what a rough doodle is meant to be. It then suggests clean drawings made by artists. It runs in a browser on phones, tablets, and computers with nothing to install.

Benefits

For students

  • Students can sketch quickly and swap in a clean picture.
  • Students see how a computer guesses what a doodle shows.
  • Students can use the tool on a phone, a tablet, or a computer.

For teachers

  • The tool is very simple to demonstrate.
  • No account is needed.
  • Teachers can use it for quick visuals in slides and posters.

For schools

  • The tool is free.
  • Nothing needs to be installed.
  • Schools should check that the web filter allows the site.

Getting started checklist

Where is the AI in this product?

The AI is a sketch recognition model that guesses what a doodle shows. It uses the same technology as the Quick, Draw! experiment. The vendor does not say where it runs. Students draw, see the suggestions, and decide whether to swap their sketch for an artist's drawing.

Privacy and safety

No account is needed and the site needs an internet connection. The research found no AutoDraw privacy policy. The official site did not load for the research tool. Neither Google's announcement nor the review says how drawings are stored or used. The research did not confirm where inference runs. A teacher should check the current Google privacy terms and the school filter before class.

How this can be used for Visual Arts
  1. Doodle a simple animal and see which pictures the tool suggests.
  2. Draw the same object three ways and note which one the tool understands.
  3. Make a poster by swapping rough sketches for clean drawings.
  4. Compare a sketch with the artist's version and discuss the style differences.
  5. Draw a picture with your own style and decide when to keep the original.
