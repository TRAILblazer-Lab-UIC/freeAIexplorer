Digital Technologies Hub Introduction to Ozobot

A lesson where students draw color codes to control an Ozobot robot.

FREEComputingRoboticsStays on the device

Overview

This is a Years F to 2 lesson where students learn that drawn lines and colour codes can control an Ozobot robot. Students predict how the robot behaves at a junction. They draw paths with colour codes and test them in pairs or small groups. Groups present their paths and the class agrees on rules for line thickness and code size.

Benefits

For students

  • Students draw code that a robot reads.
  • Students predict, test and debug paths.
  • Students share results and agree on class rules.

For teachers

  • A printed colour code sheet and activity sheets are included.
  • A rubric covers algorithms, codes and vocabulary.
  • The lesson was produced by the CSER Group at the University of Adelaide per search results.

For schools

  • The lesson is free. Ozobot robots and markers must be supplied.
  • No account, internet or device is needed.
  • Tablets are optional for drawing paths digitally.

Getting started checklist

Where is the AI in this product?

This lesson has no AI. Ozobot reads the colour codes that students draw and follows them. Students build skills in algorithms and debugging.

Privacy and safety

The core activity uses a robot that reads drawn lines with no app, and the lesson page does not mention accounts or data. The research found no student data collected. The lesson works on paper with no internet. Optional tablet drawing apps would have their own policies, and the research did not review them. A teacher should check the marker colors, test each robot before class, and review any tablet app.

How this can be used for Computer Science
  1. Predict what Ozobot does at a junction and then test it.
  2. Draw a path with colour codes and watch the robot follow it.
  3. Debug a path that the robot reads the wrong way.
  4. Present a path to the class and explain each code.
  5. Agree with the class on rules for line thickness and code size.
