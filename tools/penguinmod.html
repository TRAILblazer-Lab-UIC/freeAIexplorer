PenguinMod

A block coding platform built from Scratch and TurboWarp with extra blocks.

AIComputing

Overview

PenguinMod is a block-based coding platform built off Scratch and TurboWarp. It adds extra blocks and extensions. Students create projects in an online editor and browse community projects. It is not affiliated with Scratch, TurboWarp, or the Scratch Foundation.

Benefits

For students

  • Students use familiar blocks and gain extra blocks and extensions.
  • Students can share projects and browse what others make.
  • A packager tool lets students bundle a finished project.

For teachers

  • The editor opens in a browser and needs no install.
  • An account is optional.
  • Teachers who know Scratch can start in minutes.

For schools

  • The platform is free.
  • It runs on Chromebooks, Windows, Mac, and Linux.
  • Community projects are public and may include unmoderated content.

Getting started checklist

Where is the AI in this product?

PenguinMod has an optional chat extension named PenguinGPT. It runs in the vendor's cloud. Students can use it to ask for help and then write their own blocks. The editor itself has no AI.

Privacy and safety

Students can use the editor without an account. Accounts may collect a username, an email, a date of birth, and a country. The site logs IP addresses for about one week when projects are viewed. Uploaded projects and profile details are public, and moderation data goes to Discord. Third parties may set cookies, and some extensions such as PenguinGPT call outside services. The policy sets no minimum age. A teacher should read the privacy policy and review community content before use.

How this can be used for Computer Science
  1. Build a simple game with the standard blocks and test it with a partner.
  2. Add one extension and describe what new blocks it gives.
  3. Use a loop block to draw a pattern on the stage.
  4. Browse one community project and explain how its code works.
  5. Package a finished project and share it with the class.
