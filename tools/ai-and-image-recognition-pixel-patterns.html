AI and image recognition (pixel patterns)

A lesson on how AI sees images as pixel patterns, on paper or in a spreadsheet.

FREEAIUnpluggedUnverifiedGood for AI beginners

The privacy details for this item are unverified. Check which tools and accounts students will use before class.

Overview

This is a lesson from the Australian Digital Technologies Hub for Years 5 and 6. It shows how AI recognizes what it sees. Students learn that images are made of pixels with colour values. They code a 5 x 7 grid for a partner to recreate and then draw an object as a pixel pattern on paper or in a spreadsheet.

Benefits

For students

  • Students learn that pictures are made of numbers.
  • Students code a grid for a partner to copy.
  • Students compare black and white, greyscale, and colour versions.

For teachers

  • A teacher can choose paper or a spreadsheet.
  • The lesson links to the Australian Curriculum Digital Technologies content on binary data.
  • Excel files and a pixel viewer are available.

For schools

  • The lesson is free.
  • Paper needs no devices.
  • The spreadsheet path needs computers with a spreadsheet program.

Getting started checklist

Where is the AI in this product?

The lesson has no software that runs AI. It explains image recognition by showing that images are grids of numbers. Students build skills in representing data and in thinking about how a computer finds features. The lesson names image recognition, feature extraction, and classification.

Privacy and safety

The paper option needs no software. The spreadsheet option uses Excel, Numbers, or Google Sheets. The terms of the chosen spreadsheet apply. The lesson also shows videos and an online pixel viewer. The materials do not state whether an account is needed. The lesson page does not discuss student data. A teacher should check the spreadsheet tool and the pixel viewer with IT before class.

Ideas by subject

How this can be used for Computer Science
  1. Code a 5 x 7 grid with numbers and trade it with a partner to redraw.
  2. Draw a simple object as a pixel pattern and ask a classmate to name it.
  3. Change one pixel and see if the object is still easy to recognize.
  4. Compare a black and white picture with a greyscale version of the same grid.
  5. Explain in a short note how a computer might tell two pictures apart.
How this can be used for Math
  1. Write the colour value for each cell of a small grid as a whole number.
  2. Count how many cells a 5 x 7 grid has and explain the pattern.
  3. Use conditional formatting in a spreadsheet to color cells by number.
  4. Compare the numbers for black, grey, and white cells.
  5. Build a pattern that repeats across the grid and describe the rule.
