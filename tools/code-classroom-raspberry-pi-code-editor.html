Code Classroom (Raspberry Pi Code Editor)

A free browser editor for Python, HTML, CSS, and JavaScript with optional school classes.

FREEComputingSends student data to a company

Overview

The Raspberry Pi Code Editor is a free browser editor for text-based coding. Students write Python, HTML, CSS, and JavaScript. The Code Editor for Education adds school accounts, where teachers create student accounts, group them into classes, share projects, and give feedback. Python runs in the browser through Pyodide.

Benefits

For students

  • Students move from block coding to real text code.
  • Students can run Python, HTML, CSS, and JavaScript in one place.
  • Student accounts need no email address.

For teachers

  • Teachers create student accounts and sort them into classes.
  • Teachers can share projects and leave feedback on student work.
  • An embeddable web component lets teachers place the editor on a web page.

For schools

  • The Foundation says the editor and its features will be free forever.
  • It runs in a browser on Chromebooks, Windows, Mac, and Linux.
  • Signed-in work is stored by the vendor. The school should review the terms.

Getting started checklist

Where is the AI in this product?

This tool has no AI. It runs the code that students write. Students build skills in sequencing and logic as they write programs.

Privacy and safety

Accounts are optional for the open editor, and the internet is needed at all times. Signed in users have minimal account data and saved projects stored by the vendor in its cloud. The announcement says the Foundation minimises student data collection and follows GDPR and the ICO Children's Code. Education accounts are designed for students aged 9 and up. The research did not fetch the privacy policy. It also did not verify a data processing agreement or guest coding without an account. A teacher should read the Foundation privacy information before creating student accounts.
