Bootstrap Data Science (Pyret)

A full-year Bootstrap data science course for grades 9-12 in Pyret.

Computing

Overview

Bootstrap offers a full-year Data Science course for grades 9-12 in the Pyret language. The course adds advanced analysis, function definition, and modeling with linear, quadratic, exponential, and periodic functions. A Data Literacy course for grades 5-12 is offered in Pyret and in CODAP. Students program with tables in the Pyret editor at code.pyret.org.

Benefits

For students

  • Students program with real data tables.
  • Students model data with several kinds of functions.
  • Students use a student workbook to keep notes.

For teachers

  • Teachers can mix and match modules.
  • Standards alignment pages are available.
  • The Intro to Pyret lesson takes about 55 minutes.

For schools

  • The materials are free.
  • Students use a browser editor, and Chromebooks are listed.
  • Students sign in with Google to save work to Drive, which matters for districts that restrict Google accounts.

Getting started checklist

Where is the AI in this product?

The course has no AI. It builds data skills, as students program with tables and models. It also builds pattern spotting as they fit functions to data.

Privacy and safety

Students use the Pyret editor in a browser, and the internet is needed throughout. Accounts are optional. A student who signs in with Google saves files to Google Drive, and Google holds that work. The research did not read the privacy terms of the Pyret editor or of Bootstrap, and the materials do not say what else is collected. A teacher should confirm that the school allows Google accounts for students.

Ideas by subject

Select a subject to see five classroom ideas.

How this can be used for Computer Science
  1. Open the Pyret editor and examine a data table of animals, as in the Intro to Pyret lesson.
  2. Write a function that filters a table.
  3. Build a chart from a table and describe it.
  4. Define a function and test it with two examples.
  5. Find and fix an error in a short program.
How this can be used for Math
  1. Fit a linear model to a small data set and describe the slope.
  2. Compare a linear and an exponential model of the same data.
  3. Test a quadratic model on a set of points.
  4. Describe a periodic pattern from real data.
  5. Explain which model fits best and why.
