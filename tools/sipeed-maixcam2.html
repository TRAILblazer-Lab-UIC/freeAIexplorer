Sipeed MaixCAM2

A powerful camera board that runs vision models and small language models.

AIComputingRobotics

Overview

MaixCAM2 is a Sipeed camera board with an Axera AX630C chip. Its NPU is rated at 12.8 TOPS INT4 and runs convolutional and Transformer models, including LLMs and VLMs. It takes camera input up to 8 MP and has a 2.4 inch touchscreen. Older students program it in MaixPy, MaixCDK, and MaixVision.

Benefits

For students

  • Students run vision models on a board that fits in a hand.
  • Students try vision language models and LLM inference on the device.
  • Students write Python code and see results on the touchscreen.

For teachers

  • The wiki lists the board for teaching, STEM education, and university research.
  • The MaixPy docs name teachers and students as an audience.
  • The vendor mentions teaching only as a marketing point. Lessons may be limited.

For schools

  • The wiki pages list no price. They link to Taobao and AliExpress stores.
  • The MaixPy wiki lists an Apache-2.0 license. GitHub does not confirm it.
  • The AI runs on the board. IT will need to help with setup.

Getting started checklist

Where is the AI in this product?

The AI runs on the board using its 12.8 TOPS NPU. It handles object detection, vision language models, and LLM inference. Students write MaixPy code that calls these models. They then compare the answers the models give.

Privacy and safety

An account is optional and the internet is used at setup. The AI runs on the device. Network use depends on the code a teacher writes. The research reviewed no privacy policy, and the materials do not state what data is collected. A teacher should check any online model download or sign in, and should review what students ask the language model.

How this can be used for Computer Science
  1. Write a MaixPy script that detects objects in the classroom and prints their names.
  2. Run a vision language model on a photo and judge whether its description is correct.
  3. Ask a small language model three questions and compare its answers with a trusted source.
  4. Compare detection speed for two different models.
  5. Display detection results on the touchscreen with labels.
How this can be used for Engineering and Design
  1. Mount the board and camera in a simple housing and test the view.
  2. Connect the board to a sensor or motor and trigger it from a detection.
  3. Measure the board temperature during a long model run.
  4. Compare the 1 GB and 4 GB versions and list what each can run.
  5. Write setup notes that another team can follow.
