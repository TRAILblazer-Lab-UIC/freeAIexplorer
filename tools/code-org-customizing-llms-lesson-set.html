Code.org Customizing LLMs lesson set

Code.org lessons where students customize a chatbot with prompts and retrieval.

AIGood for AI beginners

Overview

This is Unit 2 of Code.org's Exploring Generative AI course. Students use the AI Chat Lab to pick language models, write system prompts, and add retrieval information to customize a chatbot. Lesson 2, Interacting with Language Models, runs about 45 minutes. Teachers can view student chats and give feedback on them.

Benefits

For students

  • Students shape how a chatbot behaves.
  • Students learn how retrieval gives a model facts.
  • Students practice careful prompt writing.

For teachers

  • Teachers can view student chats and give feedback.
  • The chat moderation guidance helps with class management.
  • The course page lists grades 8-12 and Chromebook support.

For schools

  • The lessons are free.
  • They run in a browser on Chromebooks.
  • Student prompts reach an outside model provider. Review the district data agreement.

Getting started checklist

Where is the AI in this product?

The AI is a set of large language models that students choose and customize. They run in a company's cloud and the model provider is not named. Students write system prompts, add retrieval information, and then test the chatbot. They use the results to understand how prompts shape answers.

Prompt

Third party
A third party is an outside company that is neither you nor the tool's maker.

Privacy and safety

Prompts and chats are free text entries that Code.org may process and store, and they could contain personal data. Teachers can view them. Student prompts reach a third party language model provider, and the policy does not name the providers or describe their retention. The research did not confirm the model for this unit or the account rules. A related course page says a verified teacher account unlocks AI Chat Lab. The internet is needed at all times. A teacher should review the district data agreement before class. A teacher should also tell students not to enter names, addresses, or other personal details.

How this can be used for Computer Science
  1. Write a system prompt for a homework helper and test it with three questions.
  2. Compare the answers from two language models on the same prompt.
  3. Add retrieval information about the school and ask the bot about it.
  4. Find a prompt that breaks the chatbot and explain why.
  5. Revise the system prompt to fix the problem and test again.
