CS Frontiers AI/ML

A nine-unit machine learning module in NetsBlox with Teachable Machine and TensorFlow Playground.

AIComputingGood for AI beginners

The privacy details for this item are unverified. Check which tools and accounts students will use before class.

Overview

CS Frontiers AI/ML is a machine learning module guided by the AI4K12 framework. The page lists nine units. They range from classifying Twitter accounts and drawing with code to search algorithms, sentiment analysis, bias in datasets, deep neural networks, and real-world uses. NetsBlox, a block-based environment, is the main platform, and Python is an option for units 4 and 5.

Benefits

For students

  • Students build classifiers and test them on real social media data.
  • Students study bias in datasets.
  • Students use TensorFlow Playground and Teachable Machine to see neural networks at work.

For teachers

  • The module follows the AI4K12 framework.
  • Teachers can pick units in order or by topic.
  • Python is an option for units 4 and 5.

For schools

  • The page states no price.
  • It runs in a browser.
  • A NetsBlox sign-in is linked for stand-alone use.

Getting started checklist

Where is the AI in this product?

Students classify data, study sentiment analysis and dataset bias, and look at neural networks. The materials do not say where each AI tool runs. Students build and test models in NetsBlox and the other tools and then discuss the results.

Privacy and safety

The materials do not state which accounts students need or where data goes. A NetsBlox sign-in is linked for stand-alone use. The units use NetsBlox, Teachable Machine and the Genius API, and the research did not read their data handling. Where the AI runs is not confirmed. A teacher should check the terms of each tool before students sign in. A teacher should also keep personal images out of Teachable Machine projects.

How this can be used for Computer Science
  1. Use NetsBlox to classify a set of accounts and describe your rule.
  2. Test a sentiment analysis program on five sentences and note the errors.
  3. Change a dataset and see how bias shows up in the results.
  4. Explore a neural network in TensorFlow Playground and change one setting.
  5. Train a Teachable Machine model on two objects and test it.
