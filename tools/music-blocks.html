Music Blocks

A visual programming language where students snap blocks to compose music.

FREEComputingStays on the device

Overview

Music Blocks is a visual programming language and set of manipulative tools for exploring music and math. It runs as an interactive web app and produces audio, graphics, and artwork. It builds on Turtle Blocks, which is available through the same codebase. Students snap blocks to compose music.

Benefits

For students

  • Students compose music by connecting blocks.
  • Students see the link between music and math.
  • Students can switch to a Turtle Blocks graphics mode.

For teachers

  • Lesson plans by teachers at MAP Family Learning Center and others are reported.
  • An optional Planet lets students share and remix projects.
  • The tool runs in a browser with no account.

For schools

  • The tool is free and open source.
  • It works on Chromebooks.
  • It can run locally with npm or Docker, according to the README.

Getting started checklist

Where is the AI in this product?

The vendor does not describe any AI. The code has a file named for an AI debugger widget, but the README does not describe it. Students build skills in sequencing and pattern spotting.

Privacy and safety

No account is needed. The README says session information is saved in the browser only to restore the session and is never shared with third parties. The optional Planet shares projects anonymously. The research read no separate privacy policy and did not confirm offline use. A teacher should decide whether students may share work on the Planet and check the school's internet setup.

How this can be used for Music
  1. Snap blocks together to play a short melody.
  2. Change the note values and compare the rhythm.
  3. Repeat a phrase with a loop and describe the effect.
  4. Compose a piece with two voices.
  5. Perform the piece for the class and explain the blocks.
How this can be used for Math
  1. Use blocks to play a pattern of whole, half, and quarter notes and add up the beats.
  2. Build a rhythm with fractions and test that the bars add up.
  3. Make a pattern that repeats every four beats.
  4. Draw a shape in Turtle Blocks with angles and distances.
  5. Change one number and predict the result.
How this can be used for Computer Science
  1. Build a program in blocks and describe the order of steps.
  2. Use a loop to repeat a musical pattern.
  3. Fix a program that plays the wrong notes.
  4. Make a custom block that plays a favorite phrase.
  5. Remix a classmate's project and explain what changed.
