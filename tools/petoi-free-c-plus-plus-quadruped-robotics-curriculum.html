Petoi Free C++ Quadruped Robotics Curriculum

A free C++ curriculum for the Bittle robot dog using the Arduino IDE.

ComputingRobotics

The privacy details for this item are unverified. Check which tools and accounts students will use before class.

Overview

This free project-based curriculum teaches C++ with the Arduino IDE using the Petoi Bittle robot dog. Topics cover Arduino IDE basics, LED and buzzer demos, C++ syntax and robot sensing and decision making. It ends with integrating functions into a complex system. Teachers receive lesson plans and student workbooks.

Benefits

For students

  • Students learn real C++ on a robot.
  • Students see sensor data guide decisions.
  • Students finish with a larger project.

For teachers

  • Lesson plans and student workbooks are included.
  • The curriculum covers middle school, high school and college.
  • A search snippet says the C++ track suits students with coding experience.

For schools

  • The curriculum is free, but the robot must be bought.
  • Bittle is 289 USD and Bittle X V2 is 319 USD on the page.
  • IT needs to install the Arduino IDE.
