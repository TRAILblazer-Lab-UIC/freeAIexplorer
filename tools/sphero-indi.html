Sphero Indi

A small robot car for PreK-2 that reads color tiles and needs no screen.

$ComputingRoboticsStays on the device

Overview

Sphero indi is a small robot car for early learners in PreK to 2nd grade. An onboard color sensor reads color cards and silicone tiles. Children program it by laying out a path with no tablet, phone, or computer. A free Sphero Edu Jr app adds block coding for children who have learned the color cards.

Benefits

For students

  • Children program a car by laying out color tiles.
  • Children practice paths, counting, and sequences with their hands.
  • Children can move on to block coding in the app.

For teachers

  • The Class Pack includes a standards-aligned Educator Guide Book with 20 lessons aligned to CSTA.
  • The final five lessons use block programming in the Edu Jr app.
  • Teachers can run the first lessons with no devices.

For schools

  • The educator guide alone costs 45 USD. Robot and class pack prices were not confirmed.
  • The Student Kit has 20 silicone color tiles and the Class Pack has 8 sets of 20.
  • Screen-free use needs no internet or account.

Getting started checklist

Where is the AI in this product?

Sphero indi has no AI. The car follows the colors it reads, in the order laid out. Children build sequencing skills.

Privacy and safety

The screen-free mode needs no app or account and collects no student data. The optional Edu Jr app policy says personal data is not collected through the app. It lists toy and mobile diagnostics that go to Sphero servers. A teacher should decide whether to use the app and should read the privacy policy first.

How this can be used for Computer Science
  1. Lay out a color tile path and predict where indi will go.
  2. Change one tile and watch how the path changes.
  3. Build a path that makes indi turn twice.
  4. Swap paths with a partner and test each other's paths.
  5. Move on to block coding in Edu Jr in the final lessons.
How this can be used for Math
  1. Count tiles along an indi path and write the number.
  2. Practice counting on from a starting tile.
  3. Measure how far indi travels along a row of tiles.
  4. Build a pattern of colors and predict the next tile.
  5. Compare a short path and a long path and tell which is longer.
