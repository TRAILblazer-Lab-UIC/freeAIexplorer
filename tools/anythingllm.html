AnythingLLM

A free app for chatting with your own documents using local or cloud AI models.

FREEAIComputingLocal with optional cloud or accounts

Overview

AnythingLLM is an all-in-one AI app from Mintplex Labs. Users upload documents and ask questions about them, or build AI agents without writing code. It comes as a desktop app for Mac, Windows, and Linux, as a Docker version for servers, and as an Android app. It suits high school students and the teachers or librarians who guide them.

Benefits

For students

  • Students can ask questions about a reading and see answers drawn from their own documents.
  • Students can summarize long texts and check the summary against the source.
  • Students practice writing clear questions to get useful answers.

For teachers

  • The desktop app is a simple screen for chat and uploads.
  • Teachers can load class readings and let students question them.
  • Custom agent skills let teachers build small helpers for a unit.

For schools

  • The desktop app is free and the code is MIT licensed.
  • A local model can keep documents on the device, and air-gapped use is possible.
  • The desktop app is single user. A multi-user setup needs the Docker version and a server. IT will likely need to help.

Getting started checklist

Where is the AI in this product?

The AI is a language model that answers questions about uploaded documents, runs agents, and handles transcription. It can run on the device using a local model, or it can connect to cloud providers such as OpenAI, Anthropic, and Google Gemini. A default vector database and embedder stay on the device. Students use the answers to check their reading and then write their own summaries.

Privacy and safety

No account is needed for the desktop app. Anonymous usage telemetry is on by default and the school must turn it off. It records events such as chats and added documents, and does not record document or chat content. Choosing a cloud provider such as OpenAI sends prompts and documents to that company. The privacy page returned 404 and the research found no COPPA or FERPA statement. A teacher should have IT turn off telemetry and set the model provider centrally.

Ideas by subject

Select a subject to see five classroom ideas.

How this can be used for Library and Media Literacy
  1. Upload a library guide and ask the app questions that a new student might ask.
  2. Load three articles on one topic and ask the app to compare their claims, then check the answers.
  3. Build a research question list for a project and test which questions give the best answers.
  4. Test the app with a document that has no answer and note how it responds.
  5. Write a short guide for classmates on how to check an AI answer against the source.
How this can be used for English and Language Arts
  1. Upload a short story and ask the app to summarize it, then rewrite the summary in your own words.
  2. Ask the app questions about a poem and judge which answers match the text.
  3. Compare your reading of a chapter with the app's answer and note any differences.
  4. Write five quiz questions about a text and test whether the app can answer them.
  5. Find a quote from a document by asking the app and then locate it on the page.
