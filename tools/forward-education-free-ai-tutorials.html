Forward Education free AI tutorials

Free micro:bit tutorials that teach machine learning, data inputs, and bias.

AIRoboticsGood for AI beginners

The privacy details for this item are unverified. Check which tools and accounts students will use before class.

Overview

Forward Education offers free AI tutorials and weekly educator webinars built on the micro:bit. Search results for the ORISE listing mention two hands-on tutorials and an educator course. One tutorial trains a machine learning model and the other uses a CreateAI model in Microsoft MakeCode. The stated aim is to teach data inputs, bias, and ethics. The tutorial details are unverified.

Benefits

For students

  • The tutorials are described as having students train a model for MakeCode.
  • Students learn about data inputs, bias, and ethics.
  • Students code with blocks.

For teachers

  • The tutorials and weekly webinars are free.
  • The vendor learning platform lists over 200 CS and AI lessons.
  • The vendor describes grade bands from K through 12.

For schools

  • The tutorials are described as free. A micro:bit is needed.
  • The vendor sells kits from $70.
  • The materials do not state account needs. IT should check the sign-up terms.

Getting started checklist

Where is the AI in this product?

The AI is a machine learning model that students train with data. The materials do not say clearly where the training runs. Students collect examples, train the model, and then use it in a MakeCode program on the micro:bit.

Privacy and safety

The materials do not state which tools or accounts students need. They also do not say whether the internet is needed or where student data goes. The research did not review the tutorials or any privacy terms. The vendor site lists a related Data Driven Smart Farming site that requires sign-up. Forward Education also sells kits and a MicroChat AI product, which are separate from these tutorials. A teacher should check which sites students must join and what data those sites keep.

How this can be used for Computer Science
  1. Train a model on two kinds of movement and test whether the micro:bit tells them apart.
  2. Collect more examples and compare the model's accuracy with the first try.
  3. Discuss how a small data set might cause bias in the model.
  4. Use the trained model in a MakeCode program that shows a message.
  5. Explain the steps from data to decision in a short class talk.
