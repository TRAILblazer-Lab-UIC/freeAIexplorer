VEX GO

A snap together robotics kit for grades 3-5 coded with VEXcode GO.

$$$ComputingRoboticsUnverified

The privacy details for this item are unverified. Check which tools and accounts students will use before class.

Overview

VEX GO is a snap together robotics kit coded with VEXcode GO. The VEX Library lists it for grades 3-5. Students build robots from the kit and program them with blocks, Switch, or text. A search snippet says a desktop app runs offline on Windows and Mac. A web version runs in Chrome or Edge.

Benefits

For students

  • Students build a robot with snap together parts.
  • Students code it with blocks and can later try text.
  • Students see the robot move as soon as they run a program.

For teachers

  • A VEX knowledge base says VEXcode GO 4.0 added an offline desktop app.
  • The web version at codego.vex.com needs no install.
  • Teachers can pick the app that suits their devices.

For schools

  • A search snippet of the VEX store lists the GO Education Kit from 224.49 USD.
  • Classroom bundles start at 1,399.99 USD.
  • The web version needs Windows 10 or later and Chrome or Edge 100 or newer with BLE 4.1.

Getting started checklist

Where is the AI in this product?

VEX GO has no AI. The robot runs the blocks or text code that students write. Students build skills in sequencing and logic.

Privacy and safety

The materials do not state whether an account is needed. A note lists optional Google or Microsoft sign in for saving in the web version, but the research did not verify it. The internet is needed at setup. A search snippet of the VEX software privacy policy says some apps are directed to children under 13 and that Google Analytics is used. The policy page could not be read. A teacher should read it and use the offline desktop app when in doubt.

How this can be used for Engineering and Design
  1. Build a robot from the snap together parts and test that it drives.
  2. Change one part of the design and note the effect.
  3. Build a course and see how the robot handles it.
  4. Compare two designs on the same task.
  5. Draw a plan for a robot before building it.
How this can be used for Computer Science
  1. Use VEXcode GO blocks to drive the robot forward and back.
  2. Add a turn block to make the robot drive a square.
  3. Use a loop to repeat a pattern.
  4. Change one value and tell what changes.
  5. Debug a program that sends the robot the wrong way.
