Overview

Explorations in Data Science is a full year high school course by youcubed made with Google. Students work on project based units and build a portfolio. Topics include sampling, correlation and causation, bias, probability, and modeling with data. The course has University of California A-G approval.

Benefits

For students

  • Students work on real data projects.
  • Students build a portfolio of their work.
  • Students learn free tools used in data work.

For teachers

  • Teachers can use their own datasets.
  • The course page names Google Sheets, Python, and Data Commons as free tools.
  • Lessons include Analyzing Voter Data.

For schools

  • The page says the tools are free. Course costs were not stated.
  • Students need only a browser.
  • The course has University of California A-G approval.

Getting started checklist

Where is the AI in this product?

The course lists no AI tool. It teaches data analysis and modeling with data, which are skills that sit behind many AI systems. Students use free tools such as Google Sheets and Python in a browser and build their own models from data.

Privacy and safety

The materials do not state which accounts students need or what data is collected. The tools run on the web. The internet is always needed. The research did not review how Google Sheets, CODAP, or Data Commons handle student data. A teacher should check the account terms for those tools and choose datasets without personal information.

How this can be used for Math
  1. Analyze voter data and describe the sampling used.
  2. Test whether two measures are linked and explain the difference between correlation and causation.
  3. Spot bias in a survey and rewrite the question.
  4. Simulate a probability problem and compare it to the theory.
  5. Build a model from data and test its predictions.
How this can be used for Computer Science
  1. Load a dataset into Python and print the first rows.
  2. Write a short program that finds an average.
  3. Make a chart in Google Sheets and a chart in Python and compare them.
  4. Clean a dataset by finding missing values.
  5. Add a project to a portfolio and describe the code.
