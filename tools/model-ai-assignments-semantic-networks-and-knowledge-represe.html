Model AI Assignments: Semantic Networks and Knowledge Representations unplugged

A cut and paste card activity where students build a semantic network and query it.

FREEAIUnpluggedNo device neededGood for AI beginners

Overview

This is a card activity on semantic networks and knowledge representation. Students cut out printable concept cards and arrow cards and glue them onto paper to build a network. Partners then swap networks and ask each other questions. The answering partner may use only the network, which simulates an AI agent whose only knowledge is that network. The class then discusses the strengths and limits of the representation.

Benefits

For students

  • Students build a map of ideas from cards.
  • Students ask and answer questions using only the network.
  • Students compare semantic networks with neural networks.

For teachers

  • The deck has square concept cards and arrow relationship cards.
  • Blank cards allow custom concepts.
  • Editable INDD and DOCX versions are available.

For schools

  • The download is free.
  • Classroom cost is printing, scissors, and glue.
  • No computers or accounts are needed. The internet is used only to download the card deck.

Getting started checklist

Where is the AI in this product?

The activity has no running AI program. It teaches how a knowledge-based AI agent stores facts as a network. Students build a network and answer questions with only that network. The page states one limit. With no computer, learners cannot test how a machine would use their network.

Privacy and safety

The activity runs on paper, no account is needed, and no internet is needed. The materials describe no student data collection. The page says ages 6 and up have taken part. A teacher should plan adult help for younger children.

How this can be used for Computer Science
  1. Glue concept cards and arrow cards into a semantic network.
  2. Swap networks with a partner and ask questions that the network can answer.
  3. Find a question that your partner's network cannot answer and say why.
  4. Add a blank card with a new concept and a new link.
  5. Compare a semantic network with a neural network in a short discussion.
