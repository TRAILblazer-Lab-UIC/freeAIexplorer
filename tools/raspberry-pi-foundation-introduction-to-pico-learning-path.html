Raspberry Pi Foundation Introduction to Pico learning path

A six-project path for learning MicroPython with the Raspberry Pi Pico.

ComputingRobotics

The privacy details for this item are unverified. Check which tools and accounts students will use before class.

Overview

This is a six-project path for the Raspberry Pi Pico microcontroller. Explore projects are LED firefly, Party popper and Beating heart. Design projects are Mood indicator and Sound machine. The Invent project is Sensory gadget. Each project takes about one hour, and students program the Pico in MicroPython with the Thonny editor.

Benefits

For students

  • Students build six gadgets with lights, buzzers and buttons.
  • Students move from exploring to designing to inventing.
  • Students can share work in a project gallery.

For teachers

  • Each project takes about one hour.
  • The path gives a clear order of lessons.
  • The instructions are free.

For schools

  • Instructions are free. A Pico, a USB cable and parts are needed.
  • The kit price was not checked.
  • IT must install Thonny. A Chromebook route was not confirmed.

Getting started checklist

Where is the AI in this product?

The path has no AI. It builds skills in text coding, sensing and logic. Students write MicroPython that responds to buttons and sensors.

How this can be used for Computer Science
  1. Write MicroPython for the LED firefly and change the timing.
  2. Change the Party popper code to show a new pattern.
  3. Use a button press in the Mood indicator.
  4. Write the Sound machine with a loop and a list of notes.
  5. Invent a Sensory gadget and explain the code.
How this can be used for Engineering and Design
  1. Wire the Beating heart circuit on a breadboard.
  2. Test how a resistor changes an LED.
  3. Design a Mood indicator and choose the sensors.
  4. Improve the Sound machine layout and test it.
  5. Document the Sensory gadget design for a classmate.
