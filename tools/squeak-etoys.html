Squeak Etoys

A free, child-friendly environment for building media projects with drag-and-drop scripts.

FREEComputingStays on the device

The official website did not respond when we checked in November 2026. Confirm that this tool is still available before you plan with it.

Overview

Etoys is a free and open source programming environment based on Squeak Smalltalk. Alan Kay directed its development and drew on the ideas of Seymour Papert and Logo. It suits students in grades 3 to 8. Children build media projects by dragging objects onto the screen and writing scripts for them.

Benefits

For students

  • Students make their own drawings, animations, and games by scripting objects on the screen.
  • Students learn programming ideas through visual tiles before they meet typed code.
  • Students can keep working on projects at home or school after a one-time download.

For teachers

  • The software is free and runs on Windows, Mac, and Linux.
  • A teacher can start with simple scripts and add harder ones as students grow.
  • The Etoys To Go version can run from a USB drive.

For schools

  • The software costs nothing and the code is open source.
  • Etoys runs on the student's own device and the internet is needed only for setup.
  • IT will probably need to install it. The vendor does not list hardware requirements.

Getting started checklist

Where is the AI in this product?

Etoys has no AI. Students write scripts that tell objects what to do. This builds the skill of sequencing steps and spotting what a program will do next.

Privacy and safety

No account is needed, and the internet is used at setup. Etoys is a local desktop application with no account described. The research could not fetch the official site and reviewed no privacy policy. The materials do not confirm what data is collected. A teacher should check where saved projects live on shared computers.

How this can be used for Computer Science
  1. Drag a drawn character onto the screen and write a script that makes it move across the page.
  2. Build a small animation with two objects and explain which script controls each one.
  3. Make a simple game in which a character reacts when it touches another object.
  4. Change one value in a script and predict what the object will do before running it.
  5. Trade projects with a partner and describe the scripts you find inside.
