NetLogo Web

The browser version of NetLogo that runs on Chromebooks and tablets.

FREEComputingLocal with optional cloud or accounts

Overview

NetLogo Web is the browser version of the NetLogo agent based modeling environment. It runs on Chromebooks, tablets, and phones and has a basic feature set. Students open models from the library or upload a model file and run it. Models export as .nlogox files for desktop NetLogo or as a single HTML file.

Benefits

For students

  • Students run models on any device with a browser.
  • Students change settings and watch the results.
  • Students can write and run NetLogo code in a blank model.

For teachers

  • No install or account is needed.
  • Exported HTML pages can be hosted on any website.
  • The site itself recommends desktop NetLogo for most uses.

For schools

  • The tool is free and open source.
  • A school can host exported HTML pages on its own server.
  • It lacks HubNet, BehaviorSpace, 3D, and many extensions.

Getting started checklist

Where is the AI in this product?

This tool has no AI. It runs simulations from rules that students can read and change. Students build skills in modeling and logic. They also practice predicting what a system will do.

Privacy and safety

No account is needed, and the internet is needed at all times. The FAQ says the site logs site visits by IP address as page views and does not record interaction with models. A model opened with Upload a Model never leaves the computer. Exported HTML pages include the same visit logging, which a query parameter named disableAnalytics can turn off. A teacher should check the site's data use with IT and test each model first.

How this can be used for Science
  1. Run a model on a Chromebook and change one slider.
  2. Record how the result changes across five settings.
  3. Compare the model to a real system and list differences.
  4. Predict an outcome before each run.
  5. Export a model and share it with a partner.
How this can be used for Computer Science
  1. Open a blank model and write a setup procedure.
  2. Create turtles and move them with a go procedure.
  3. Add a slider and use it in a rule.
  4. Find a model that fails and describe why.
  5. Save a model as a .nlogox file and open it in another tool.
