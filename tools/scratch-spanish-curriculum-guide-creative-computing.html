Scratch Spanish curriculum guide (Creative Computing)

A Spanish translation of the Creative Computing guide for Scratch sessions.

Overview

This is a Spanish translation of the Creative Computing curriculum guide by Karen Brennan, Michelle Chung, and Jeff Hawson. The guide introduces computational thinking through design-based Scratch activities. A search result describes the PDF as organized in 60 minute sessions with session plans, handouts, projects, and videos. The page is from 2012.

Benefits

For students

  • Students learn computing ideas in Spanish.
  • Students build projects through design activities.
  • Students work in 60 minute sessions.

For teachers

  • Session plans and handouts are in Spanish.
  • The guide is a single PDF download.
  • Teachers should expect older screenshots from Scratch 1.4 or 2.0.

For schools

  • The PDF is free.
  • Students use Scratch in a browser or the desktop app.
  • The page does not name the Scratch version the guide targets.

Getting started checklist

Where is the AI in this product?

This guide has no AI. Students build sequencing and design skills with Scratch blocks. They practice planning a project and fixing problems.

Privacy and safety

The guide is a PDF, and the browser version of Scratch needs the internet at all times. An account is optional. The page does not describe data handling, and the research did not review the Scratch privacy policy. The materials do not state what data is collected. A teacher should check whether students will save projects online and whether school rules allow it.

How this can be used for Computer Science
  1. Follow the first session plan and build a short animation.
  2. Create a project that tells a story in Spanish.
  3. Fix a project with a bug and explain the repair.
  4. Remix a classmate's project and credit the first author.
  5. Share a project and describe the design choices in Spanish.
