Gandi IDE

An unofficial browser mod of Scratch 3.0 with real-time collaboration.

ComputingSends student data to a company

Overview

Gandi IDE is an unofficial browser-based mod of MIT Scratch 3.0. It adds real-time collaboration and extensions for multiplayer games. Projects compile to JavaScript. It is linked to Cocrea World, a Chinese Scratch community. It is not affiliated with the Scratch Team.

Benefits

For students

  • Students build Scratch-style block projects in a browser.
  • Students can work together in real time.
  • Students can try multiplayer game extensions.

For teachers

  • The editor looks like Scratch.
  • Team collaboration may suit group projects.
  • Setup details were not confirmed.

For schools

  • The price is not confirmed.
  • It runs in a browser.
  • Search results raise doubts about hosting. Treat it with caution.

Privacy and safety

The site is always online and runs in the vendor cloud. The research did not read a privacy policy. Real time collaboration suggests cloud accounts and server side projects, but this was not confirmed. The listed official address now redirects to an unrelated company, and Scratch forum posts question the branding and domain. The tool is unofficial. A teacher should confirm the official site, then ask IT to review it before any student uses it.
