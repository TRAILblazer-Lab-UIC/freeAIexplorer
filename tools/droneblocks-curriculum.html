DroneBlocks Curriculum

A four-level drone curriculum from block coding to ROS 2 and computer vision.

FREEAIComputingRoboticsLocal with optional cloud or accounts

Overview

DroneBlocks is a four-level drone curriculum. Ground School for K-5 uses block coding and simulator missions in the browser. Hover Lab for middle and high school uses Python and the DEXI-3 simulator. Flight Deck for high school and up uses ROS 2, C++, and computer vision with DEXI drones. Vertical Innovation targets college and industry.

Benefits

For students

  • Students fly a simulator drone before touching a real one.
  • Students grow from blocks to Python to ROS 2.
  • Students try computer vision at the top level.

For teachers

  • Lessons are aligned to CSTA and NGSS.
  • The browser simulator runs the same PX4 stack as the real drones.
  • Students need no account or personal information.

For schools

  • Ground School is free to start, with a 14-day trial of the full platform.
  • A 2024 review gave 495 USD per year and a 2025 roundup gave a higher figure.
  • Browser levels need no hardware.

Getting started checklist

Where is the AI in this product?

AI is optional and appears as computer vision at the Flight Deck level. It runs on the drone or the cloud tools. Students write code that uses the camera and test how the drone responds. The lower levels teach flight and coding with no AI.

Privacy and safety

Students need no account or personal information. Educators give name, email and school. Flight plan saving uses an optional email through Firebase, and Google Analytics runs on the website. The policy commits to COPPA and says schools control education record data. The internet is needed all the time. A teacher should avoid student emails in flight plan saving. A teacher should also read the privacy policy.

How this can be used for Computer Science
  1. Complete a Ground School mission with block code.
  2. Write a Hover Lab Python program for a square flight.
  3. Compare the block version and the Python version.
  4. Read a Flight Deck example and describe how vision guides the drone.
  5. Debug a flight program that drifts off course.
How this can be used for Engineering and Design
  1. Plan a flight mission with a clear goal.
  2. Test the same mission in the simulator several times and record the results.
  3. Describe how PX4 keeps the drone stable.
  4. Compare the DEXI-3 and DEXI-5 drones for a mission.
  5. Write a flight safety checklist.
