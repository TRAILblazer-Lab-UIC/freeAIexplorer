TPBOT AI Smart Lens

A micro:bit camera add-on that recognizes faces, balls, and cards using MakeCode blocks.

AIRoboticsUnverifiedGood for AI beginners

The privacy details for this item are unverified. Check which tools and accounts students will use before class.

Overview

The ELECFREAKS Smart AI Lens Kit is a camera add-on for the micro:bit. It plugs into the TPBot or Nezha robot kits. It recognizes faces, tracks colored balls, reads pattern cards, and learns custom objects with a button press. Students code it with Microsoft MakeCode blocks.

Benefits

For students

  • Students add vision to a robot with simple blocks.
  • Students teach the lens a new object with one button press.
  • Students try tasks such as finding a ball.

For teachers

  • Block coding in MakeCode needs no text coding.
  • The kit includes red and blue balls and 41 recognition cards.
  • Reviewers showed a find-the-ball task and a robot that plays blackjack.

For schools

  • Retail prices were found in pounds, from 39.00 without VAT to 59.90 with VAT.
  • A micro:bit and a TPBot or Nezha kit are sold separately.
  • The vendor does not say whether the internet is needed during use.

Getting started checklist

Where is the AI in this product?

The AI is a camera module that recognizes faces, colored balls, and cards, and learns custom objects. The vendor does not say where the recognition runs. Students write blocks that react to what the lens sees and extend what the robot can do.

Privacy and safety

Retail listings describe a standalone camera module that connects to the micro:bit, which suggests on board processing. No source says this or says whether data leaves the device. The research reviewed no privacy policy. MakeCode is a web tool with its own policy. The materials do not state which accounts students need. Check how MakeCode saves projects and whether the lens stores images. Decide how face recognition is used with students.

How this can be used for Computer Science
  1. Write blocks that show a message when the lens sees a face.
  2. Code the robot to follow a red ball.
  3. Teach the lens a new object and test it in different light.
  4. Use pattern cards to give the robot commands.
  5. Add a second condition so the robot reacts to the ball and the card.
How this can be used for Engineering and Design
  1. Mount the lens on a TPBot or Nezha robot.
  2. Test the best height and angle for finding a ball.
  3. Build a small course with colored balls and track the robot's path.
  4. Add line tracking and compare it with ball tracking.
  5. Redesign the lens mount after a test and describe what improved.
