SAS CodeSnaps

Free printable coding blocks that an app scans to run a Sphero robot.

FREEComputingRoboticsUnverified

The privacy details for this item are unverified. Check which tools and accounts students will use before class.

Overview

SAS CodeSnaps is a free app with printable coding blocks. Students arrange printed blocks to build a program. They scan the blocks with the app, and the program runs on a connected Sphero robot. It suits early elementary classrooms.

Benefits

For students

  • Students build programs by hand with paper blocks before they use a screen.
  • Students see their printed program drive a real robot.
  • Students can use blocks in 10 languages, and a version exists for visually impaired students.

For teachers

  • Lesson ideas such as an obstacle course, 24 Game, and Word Families link coding to other subjects.
  • Teachers print the blocks from the page, which keeps prep light.
  • A 2nd grade teacher testimonial appears on the SAS page.

For schools

  • The app and printable blocks are free.
  • A Sphero robot is also required, and its price was not checked.
  • The app is listed for iPad, and a teacher can install it.

Getting started checklist

Where is the AI in this product?

SAS CodeSnaps has no AI. The app reads the blocks and sends the same commands to the robot each time. Students build sequencing skills as they put blocks in order.

Privacy and safety

The app runs on the iPad and the SAS page says it needs no internet connection. A search snippet says the app offers cloud storage for saving programs. The materials do not say whether an account is needed or what data the app collects. The research found no privacy policy. A teacher should check the app's privacy details in the App Store and the saving settings before students use it.

How this can be used for Computer Science
  1. Arrange printed blocks into a short program and watch the Sphero follow it.
  2. Build an obstacle course and write a block program to drive through it.
  3. Swap one block in a working program and predict what will change.
  4. Trade programs with a partner and find a bug in each other's blocks.
  5. Retell a story by programming the robot to move through scenes.
How this can be used for Special Education and Accessibility
  1. Use the version made for visually impaired students to build a short program by touch and sound.
  2. Pair students so one builds the block program and one describes how the robot moved.
  3. Practice ordering blocks in a simple three-step program at a comfortable pace.
  4. Use blocks in a student's home language to build a first program.
  5. Make a tactile path on the floor and program the robot to follow it.
