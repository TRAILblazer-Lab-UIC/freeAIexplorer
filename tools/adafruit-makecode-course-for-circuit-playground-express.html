Adafruit MakeCode Course for Circuit Playground Express

A free project course that teaches block coding with the Circuit Playground Express board.

Computing

Overview

This is a project-based course on making with the Circuit Playground Express and Microsoft MakeCode. It has three sections called Introduction, General Reference and Projects. The Projects section has 12 maker projects with assembly and coding steps. The course addresses beginners and teachers who are new to coding.

Benefits

For students

  • Students complete 12 hands-on maker projects.
  • Students code with blocks and see results on a simulator.
  • Students connect code to a real board.

For teachers

  • The General Reference covers coding concepts and how to use MakeCode in class.
  • The course includes notes on student evaluation.
  • The course suits teachers who are new to coding.

For schools

  • The course is free.
  • Boards are sold separately.
  • A search result listed a Code.org pack at 350 USD.

Getting started checklist

Where is the AI in this product?

The course has no AI. Students build skills in sequencing, logic and sensors. They use blocks to tell the board what to do.

Privacy and safety

No account is mentioned on the pages read. MakeCode runs in the browser and code is downloaded to the board. The internet is used at setup. The research did not review the MakeCode privacy terms. A teacher should check the MakeCode terms and confirm that school computers can open MakeCode and use USB.

How this can be used for Engineering and Design
  1. Follow one of the 12 maker projects and assemble it.
  2. Test the sensors on the board and record what each one reads.
  3. Add a new feature to a finished project.
  4. Write an evaluation of your project with one thing to improve.
  5. Design a new maker project and plan its parts.
How this can be used for Computer Science
  1. Build a blocks program that lights the board when it is shaken.
  2. Use the simulator to test code before loading it.
  3. Add a loop to repeat a light pattern.
  4. Combine a button and a sensor in one program.
  5. Explain each block in your program to a partner.
