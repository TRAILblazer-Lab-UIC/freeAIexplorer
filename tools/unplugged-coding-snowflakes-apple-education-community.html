Unplugged Coding Snowflakes (Apple Education Community)

Third graders code and debug paper snowflakes with command cards and a for loop.

ComputingUnplugged

The privacy details for this item are unverified. Check which tools and accounts students will use before class.

Overview

Unplugged Coding: Snowflakes is an Apple Education Community story from December 2022. It was posted for Computer Science Education Week. Third graders match printed command cards to the steps of folding and cutting a paper snowflake. They use a for loop command. Groups then debug their code to make a different snowflake and follow it to cut the paper.

Benefits

For students

  • Students use a loop in a concrete way.
  • Students debug their code and see the snowflake change.
  • Students end with a paper snowflake they made themselves.

For teachers

  • The story is a single teacher account and not a full curriculum.
  • It fits in one class session.
  • An optional Freeform board on iPadOS 16 offers a digital version.

For schools

  • The activity is free and needs paper, scissors and printed cards.
  • The digital version needs iPads with iPadOS 16.
  • Teachers can skip the digital part.

Getting started checklist

Where is the AI in this product?

This activity has no AI. It builds an AI-related skill, which is writing and debugging instructions. Students see that a short loop can repeat steps.

Privacy and safety

The paper version collects no data. The optional Freeform board stores work in Apple's service, and the research did not review it. The materials do not state whether an Apple account is needed for the story page or the board. Check school device rules before using the digital version. Scissors need adult supervision with younger students.

How this can be used for Computer Science
  1. Match command cards to the folding and cutting steps of a snowflake.
  2. Use a for loop card to repeat a fold.
  3. Debug the code to change the shape of the snowflake.
  4. Swap code with another group and cut their snowflake.
  5. Write a new command card for a step the set does not have.
How this can be used for Visual Arts
  1. Fold and cut a snowflake by following your code.
  2. Compare two snowflakes from different code and describe the differences.
  3. Predict the pattern before you unfold the paper.
  4. Design a snowflake with repeating shapes.
  5. Display the class snowflakes and sort them by pattern.
