VEX 123

A palm sized robot for early elementary students that codes with cards or blocks.

$$ComputingRoboticsUnverified

The privacy details for this item are unverified. Check which tools and accounts students will use before class.

Overview

VEX 123 is a palm sized programmable robot for early elementary students. It can be coded without a screen using Coder Cards in the VEX Coder. It can also be coded with VEXcode 123 on a tablet, in a browser, or on a desktop. The VEX Library lists it as Pre-K and up.

Benefits

For students

  • Young children can code with cards and no screen.
  • Children can move on to blocks in VEXcode 123.
  • Children get quick feedback from a robot that moves.

For teachers

  • VEXcode 123 is free and has a Windows and Mac desktop app.
  • A Chrome based browser version runs at code123.vex.com.
  • The free VEX Classroom App manages robots and firmware updates.

For schools

  • A single education kit lists at 132.39 USD.
  • Classroom bundles for 12, 24, or 36 students list at 999.99, 1,999.99, and 2,999.99 USD.
  • Cards need no devices. Tablets are optional.

Getting started checklist

Where is the AI in this product?

VEX 123 has no AI. The robot runs the cards or blocks that children place, in the same order each time. Children build sequencing skills as they test their programs.

Privacy and safety

The materials do not state whether an account is needed or whether the web version asks students to sign in. The internet is needed at setup. A search snippet of the VEX software privacy policy says some apps are directed to children under 13 and that Google Analytics is used. The policy page itself could not be read. What data is collected, COPPA handling, and retention are unconfirmed. A teacher should read that policy before students use VEXcode and should start with Coder Cards.

How this can be used for Computer Science
  1. Place Coder Cards in a row and press go to watch the robot run them.
  2. Change one card and predict what the robot will do.
  3. Build a path to a goal on the floor and code it.
  4. Move from cards to blocks in VEXcode 123.
  5. Find the card that causes a bug and fix it.
How this can be used for Engineering and Design
  1. Build a small obstacle course and test the robot in it.
  2. Measure how far the robot moves in one step.
  3. Plan a route before coding and compare it to the actual route.
  4. Test the robot on different surfaces and note the differences.
  5. Design a simple challenge and ask a partner to solve it.
