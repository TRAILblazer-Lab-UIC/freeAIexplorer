Cytron Maker Uno RP2040

An Arduino Uno style board built on the RP2040 chip with Grove ports and USB-C.

$ComputingStays on the device

Overview

Maker Uno RP2040 is a Cytron microcontroller board in the Arduino Uno form factor. It uses the RP2040 chip and has six Grove ports, a Maker port, a 12-pin servo header, 16 status LEDs, a piezo buzzer, two RGB LEDs, and USB-C or LiPo power. It works with the Arduino IDE, MicroPython, and CircuitPython. A CNX Software reviewer says it suits STEM education.

Benefits

For students

  • Students get many parts on one board.
  • Students can use Arduino code or Python.
  • Students can plug in servos and Grove modules.

For teachers

  • The Uno form factor works with familiar shields.
  • Three programming options give teachers choices.
  • Teachers can start with the built-in LEDs and buzzer.

For schools

  • CNX Software lists the board at 14.90 USD.
  • No account is needed.
  • The internet is needed only to download the board package and libraries.

Where is the AI in this product?

This board has no AI. It builds skills in sensors, logic, and sequencing. Students write code that controls lights, sound, and servos.

Privacy and safety

No account is needed. The board is programmed from a computer, and code stays on the board and the local computer. No privacy policy was reviewed. The internet is needed to download the board package and libraries. The evidence for this board is minimal. A teacher should test the setup steps on one computer before a class uses them.
