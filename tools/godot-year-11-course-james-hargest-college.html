Godot Year 11 course (James Hargest College)

A New Zealand Year 11 video game course built on Godot 4 and GDScript.

Computing

Overview

This is a New Zealand teacher site for a Year 11 NCEA video game course. It starts with a Term 1 Python course. GDScript is based on Python. Unit 1 runs about 6 weeks and builds a 2D platformer or top-down shooter. Unit 2 runs about 4 weeks on game design, art, and level mockups. Unit 3 is an optional game jam of about 5 weeks.

Benefits

For students

  • Students build two games and an art portfolio.
  • Students learn Python first and then move to GDScript.
  • Students can enter a game jam in three sprints.

For teachers

  • The course is mapped out across about 15 weeks and three units.
  • The Python course is assessed against AS92004 for 5 credits.
  • The site points students with Godot 3.5 to other resources.

For schools

  • The course and Godot are free.
  • It needs a laptop that can run Godot.
  • IT can install Godot 4 on Windows, Mac, or Linux.

Getting started checklist

Where is the AI in this product?

This course has no AI. It builds programming and design skills. Students plan, code, and test their own games. The tools run on the local computer.

Privacy and safety

No account is needed and the internet is used for setup. Godot runs locally and student projects stay on the device. The page mentions itch.io for playtesting and OpenGameArt for assets, which are optional external sites. It also mentions a Google Classroom code. The research did not read a privacy policy. A teacher should decide where students save projects and whether students use the optional external sites. The course follows New Zealand standards. Check the local fit.

How this can be used for Computer Science
  1. Write a Python program that uses input, branching, and loops.
  2. Build a 2D platformer in Godot 4 with GDScript.
  3. Build a top-down shooter and add a score.
  4. Debug a classmate's game and report each bug.
  5. Join a game jam sprint and add one new feature.
How this can be used for Visual Arts
  1. Draw a character sketch and turn it into a sprite.
  2. Make a level mockup on paper before building it.
  3. Build an art portfolio of game assets with notes on each one.
  4. Choose a color palette and use it across a game.
  5. Present a game design plan to the class.
