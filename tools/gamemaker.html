GameMaker

A 2D game engine with drag and drop tools and a free education license.

Computing

Overview

GameMaker is a proprietary 2D game engine that uses a drag and drop system and the GML scripting language. It exports to Windows, Mac, Linux, Android, iOS, HTML5, and consoles. Schools can get a free education license for non-commercial teaching with all export options. Educators receive course materials, lesson plans, project files, and homework sheets.

Benefits

For students

  • Students begin with drag and drop and move to GML code.
  • Students make real games they can play.
  • Students learn skills used in game development.

For teachers

  • Course materials and lesson plans are provided.
  • Project files and homework sheets are included.
  • Setup guides are available.

For schools

  • The education license is free for non-commercial teaching. Commercial editions are paid.
  • It runs on Windows, Mac, and Linux.
  • IT should help install it on each computer.

Getting started checklist

Where is the AI in this product?

GameMaker has no AI. It runs as a desktop program on the local computer. It builds logic and sequencing skills. Students plan how objects behave and write the rules.

Privacy and safety

The teacher registers a GameMaker account and creates seat logins, and the internet is used at setup. The education page says the Educator License does not collect or store students' personal information. That is a vendor statement and the research did not read the privacy policy. The research also did not confirm that the editor works offline after install. The free tier outside education uploads to GX.games. A teacher should use the education license and read the privacy policy.

How this can be used for Computer Science
  1. Make a character move with drag and drop actions.
  2. Add an enemy and test collisions.
  3. Write a short GML script for a score counter.
  4. Fix a bug in a game and explain the change.

How this can be used for Career and Technical Education
  1. Plan a small game with a goal and a list of tasks.
  2. Test a classmate's game and write a bug report.
  3. Create a title screen and credits.
  4. Estimate how long each part of the project will take.
  5. Present the finished game to the class.
