DroneBlocks Crazyflie classroom program

A Crazyflie drone kit with a web app, simulator and block-to-Python curriculum.

ComputingRobotics

Overview

DroneBlocks sells a Crazyflie nano drone developer kit and a classroom bundle called Autonomous Drone Kit Level II. The bundle has hardware, web-based software, curriculum and support. The web app includes a coding simulator so students can test code before flying. Programming moves from block coding toward Python in middle and high school.

Benefits

For students

  • Students test code in a simulator before flying.
  • Students move from blocks toward Python.
  • Students fly a small indoor drone.

For teachers

  • A free 14-day trial is offered per the vendor.
  • The classroom bundle includes curriculum and support.
  • A Santa Barbara teacher ran a STEAM elective with the platform.

For schools

  • The developer kit costs 449 USD and the classroom bundle costs 4999 USD on the DroneBlocks page.
  • The platform is device agnostic and runs in a browser.
  • One teacher reported school device and infrastructure problems.

Getting started checklist

Where is the AI in this product?

The vendor does not describe any AI in this program. Students write code that the drone follows and test it in a simulator first. A Python simulation is listed as coming soon.

Privacy and safety

Educators log in to the web app, and students need no account. The policy says students need not provide personal information, and an optional email saves flight plans. Product use and browsing information may be collected. Data goes to the vendor, and the third parties named are Firebase from Google, Google Analytics and Google Ads for adult audiences. The research did not confirm whether the web app works without the internet after load. A teacher should read the policy and plan a clear flight area.

How this can be used for Computer Science
  1. Build a block program in the simulator and run it before flying.
  2. Add a turn to the program and predict the new path.
  3. Move a block program toward Python and compare the two.
  4. Use a loop to repeat a flight pattern.
  5. Debug a program that the simulator shows going off course.
How this can be used for Engineering and Design
  1. Fly the drone in an elective and record each test.
  2. Plan a safe flight area and list the rules.
  3. Compare two flight plans and choose the better.
  4. Test the drone indoors with prop guards.
  5. Present a finished autonomous flight to the class.
