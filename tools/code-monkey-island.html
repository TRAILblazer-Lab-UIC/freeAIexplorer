Code Monkey Island

A 2 to 4 player board game that introduces programming ideas through play.

ComputingUnpluggedNo device needed

Overview

Code Monkey Island is a board game for 2 to 4 players that takes about 45 minutes to play. A university library alignment sheet says it introduces control structures, data structures, Boolean logic, and math operations. Its skill tags include card drafting, route building, and pattern recognition. Students play in small groups and make choices that work like program steps.

Benefits

For students

  • Students meet programming ideas such as Boolean logic and control structures through a game.
  • Students practice route building and pattern recognition.
  • Students work with two to four players and take turns.

For teachers

  • A university library lends the game with a Texas TEKS alignment sheet.
  • The alignment sheet cites TEKS 126.33(c)(6).
  • A game takes about 45 minutes, which fits one class period.

For schools

  • The vendor materials do not list a price.
  • The game needs no devices, internet, or accounts.
  • IT staff have no work to do.

How this can be used for Computer Science
  1. Draft cards and explain which choice works like a step in a program.
  2. Use the game rules to describe a Boolean condition in plain words.
  3. Plan a route and predict the result before you move.
  4. Spot a pattern in the cards and use it to plan a turn.
  5. Teach the rules to a new player using clear step by step instructions.
How this can be used for Math
  1. Use math operations from the game cards to score a turn.
  2. Build a route and count the steps to the goal.
  3. Compare two routes and choose the shorter one.
  4. Track scores across rounds and find the total.
  5. Predict the best card to draft and check the result.
