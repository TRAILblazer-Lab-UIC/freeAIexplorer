SparkFun Education curriculum

Free electronics curriculum built around the SparkFun Inventor's Kit.

FREEComputingUnverified

The privacy details for this item are unverified. Check which tools and accounts students will use before class.

Overview

This is SparkFun's free curriculum on learn.sparkfun.com, centered on the SparkFun Inventor's Kit. A search snippet says the kit has five units covering 16 circuits. Instructor resources include a syllabus, worksheets, sample code, quizzes, and a glossary. The curriculum page returned an access error. These details come from search results.

Benefits

For students

  • Students build real circuits with a kit.
  • Students write Arduino code to control them.
  • Students work through five units.

For teachers

  • The SIK binder is described as a full embedded electronics course written for teachers.
  • Resources include worksheets, quizzes, and sample code.
  • The teacher learning curve is advanced.

For schools

  • The curriculum is free, but kits must be bought and cost over 200 USD.
  • Students need the Arduino IDE on the computer.
  • IT help is likely needed.

Getting started checklist

Where is the AI in this product?

The curriculum has no AI. Students wire circuits and write code for a microcontroller. They build logic and sensor skills.

How this can be used for Engineering and Design
  1. Build the first circuit from the kit and test it.
  2. Change a resistor and describe the effect on an LED.
  3. Wire a sensor and record the readings.
  4. Troubleshoot a circuit that does not work.
  5. Present a finished circuit and explain each part.
How this can be used for Computer Science
  1. Upload sample code to blink an LED.
  2. Change the timing in the code and observe the result.
  3. Write code that reads a sensor.
  4. Use a conditional to turn a light on or off.
  5. Explain how the code controls the circuit.
