Sphero BOLT

A spherical robot with an LED matrix that students program in the Sphero Edu app.

$$ComputingRoboticsLocal with optional cloud or accounts

Overview

Sphero BOLT is a spherical robot with an LED matrix and sensors that include a magnetometer and infrared communication. Students program it in the Sphero Edu app using Draw, Blocks, or JavaScript. The product page mentions kindergarten and elementary use. Students drive it, light it up, and test their code.

Benefits

For students

  • Students can start by drawing a path and move up to blocks and JavaScript.
  • Students see their code change the lights and movement at once.
  • Students can link robots with infrared communication.

For teachers

  • Sphero Edu runs on Chrome, Mac, PC, iOS, Android, and Kindle.
  • Teachers can use the app without any accounts.
  • The same robot works for younger and older students.

For schools

  • The product page lists 179 USD. Classroom packs were not checked.
  • Setup takes about an hour and a teacher can do it.
  • Accounts are optional and use a class code.

Getting started checklist

Where is the AI in this product?

Sphero BOLT has no AI. The robot runs the Draw, block, or JavaScript code that students write. Students build skills in sequencing and sensor data.

Privacy and safety

An account is optional, and the robot can be driven, programmed and used for lessons without logging in. With a class code, students give only a first name and last initial. Sphero says no personal information is shared with third party vendors, but abstracted data may go to Amplitude, Google, Apple and Amazon for analytics. The support page does not mention FERPA, and sources differ on third party sharing. A teacher should check which student details to enter and should use initials only.

How this can be used for Computer Science
  1. Draw a path in Sphero Edu and watch BOLT follow it.
  2. Build a block program that lights the LED matrix in a pattern.
  3. Use a loop to make BOLT roll a square.
  4. Write a short JavaScript program that changes colors.
  5. Debug a program that sends BOLT in the wrong direction.
How this can be used for Science
  1. Use the magnetometer readings to find which way BOLT is facing.
  2. Test how light changes the sensor readings and record the data.
  3. Predict how far BOLT rolls at a set speed and measure the real result.
  4. Use infrared messages between two robots and describe what happens.
  5. Graph speed readings from BOLT during a run.
