micro:bit Musical micro:bit unit

A five lesson unit where students program the micro:bit to play music.

FREEComputingStays on the device

Overview

This unit of work uses MakeCode and the micro:bit to teach music and coding together. The page describes it as written for students aged 9 to 10. The first lesson is unplugged and covers musical algorithms. Later lessons cover programming and debugging music, conductor style gestures, accelerometer inputs, and judging the micro:bit as a music tool.

Benefits

For students

  • Students write an algorithm for a musical phrase before they touch a computer.
  • Students use motion to control sound, such as a conductor does.
  • Students test and fix their own music programs and then judge how well the micro:bit works as an instrument.

For teachers

  • The five lessons come in one downloadable zip.
  • Each lesson lasts about 60 minutes, which fits a standard class period.
  • The unit lists links to England KS2 computing and music, Code.org CS Fundamentals Courses E and F, and CSTA grades 3-5.

For schools

  • The lessons are free.
  • Each micro:bit board is a paid purchase, and the unit also uses pitched instruments such as glockenspiels.
  • Student work stays on the device and in the browser, and IT help is limited to the teacher setup.

Getting started checklist

Where is the AI in this product?

This unit has no AI. It builds the skill of writing an algorithm, which is a clear set of steps a computer can follow. Students also practice spotting and fixing errors in their programs. Both skills help students understand how AI tools are built from rules and data.

Privacy and safety

No account is needed. The pages read do not discuss data handling, and they did not require a sign in. The programs run in the browser and on the board, and the internet is used at setup. The research read no privacy policy for this item. A teacher should check the MakeCode privacy terms, that MakeCode opens on school computers, and that sound output works before the first lesson.

Ideas by subject

Select a subject to see five classroom ideas.

How this can be used for Music
  1. Compose a short musical phrase and write it down as an algorithm that a classmate can play on a glockenspiel.
  2. Program the micro:bit to play the phrase and listen for notes that need fixing.
  3. Build a gesture controlled instrument that changes pitch when the board tilts.
  4. Perform a class piece where one student conducts with a micro:bit and others follow the sound.
  5. Write a short review that judges the micro:bit as a music tool.
How this can be used for Computer Science
  1. Write an unplugged algorithm for a musical phrase and test it on a partner.
  2. Find and fix a bug in a music program that plays notes in the wrong order.
  3. Use the accelerometer input to start a sound when the board shakes.
  4. Compare two versions of a program and explain which one is easier to read.
  5. Present a finished program to the class and describe each step.
