TensorFlow.js

A JavaScript library for training and running machine learning models in the browser.

AIComputing

Overview

TensorFlow.js is a JavaScript library for building, training, and running machine learning models. It works in the browser or in Node.js. It is a developer library. Students use it by writing JavaScript. Friendlier tools such as ml5.js are built on top of it.

Benefits

For students

  • Students train and run models in the browser they already use.
  • Students can retrain an existing model with their own data.
  • Students practice real JavaScript for machine learning.

For teachers

  • Official demos show a webcam trained controller and a piano performance.
  • Tutorials explain each step.
  • Wrapper tools such as ml5.js lower the entry level.

For schools

  • The library is free and open source.
  • Models can run in the browser on the student device.
  • Setup is advanced. IT help is likely.

Getting started checklist

Where is the AI in this product?

The AI is a machine learning library. It can run pre-trained models, retrain them through transfer learning, or build new models. The work runs in the browser on the student device. Students write JavaScript to train a model and then use it in their own pages.

Privacy and safety

No account is needed. The official pages describe running machine learning in the browser and do not state a data policy. The getting started example loads the library from the jsDelivr CDN. A page built that way needs the internet on each load unless the library is bundled or self-hosted. Data handling in a student project depends on the code that is written. Check how your pages load the library and tell students when a webcam project turns the camera on.

How this can be used for Computer Science
  1. Write a short script that loads a pre-trained model and labels an image.
  2. Retrain a model on two kinds of objects with transfer learning.
  3. Try the webcam controller demo and describe how it learned.
  4. Change a model setting and compare the results.
  5. Build a small web page that shows a prediction from a model.
