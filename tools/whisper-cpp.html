Whisper.cpp

A fast offline speech to text engine that runs on many devices.

FREEAIComputingStays on the device

Overview

Whisper.cpp is a C and C++ port of OpenAI's Whisper speech recognition model. It runs on a processor or a graphics card. It supports macOS, iOS, Android, Linux, Windows, Raspberry Pi, and Docker. It is a developer tool used from the command line or built into other apps.

Benefits

For students

  • Students build and run a real speech model.
  • Students can transcribe audio without sending it anywhere.
  • Students learn to work from the command line.

For teachers

  • Model sizes range from tiny to large. Teachers can match the computer.
  • Most teachers will use an app built on it.
  • It supports many platforms.

For schools

  • The software is free.
  • It works offline after the setup downloads.
  • The README shows audio staying on the device. IT will need to help with the build.

Getting started checklist

Where is the AI in this product?

The AI is a speech recognition model that turns audio into text. It runs on the local computer. Students feed it an audio file and read the transcript. They can then compare model sizes for speed and accuracy.

Privacy and safety

No account is needed, and the internet is used only for setup downloads. The README shows an iPhone demo running fully offline on the device. No privacy policy was found for this library and command line tool. A teacher should check the consent of anyone whose voice is recorded. A teacher should also check the transcript before sharing it.

How this can be used for Computer Science
  1. Build the program from source and run it on a sample audio file.
  2. Compare the tiny and larger models on the same recording.
  3. Record a short talk and check the transcript for errors.
  4. Time a transcription and explain what affects the speed.
  5. Write a shell script that transcribes every file in a folder.
