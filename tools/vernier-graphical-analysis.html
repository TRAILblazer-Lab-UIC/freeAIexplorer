Vernier Graphical Analysis

A data collection and graphing app that works with Vernier sensors.

Computing

Overview

Graphical Analysis is Vernier's app for collecting, graphing, and analyzing data. It connects to nearly any Vernier sensor over USB or Bluetooth. Students can also enter data by hand. It replaces the older Logger Pro and Logger Lite.

Benefits

For students

  • Students see live graphs from real sensors.
  • Students can fit curves and read the results.
  • Students can enter their own data by hand.

For teachers

  • The Basic version is free.
  • Pro adds live device to device data sharing and over 45 investigations.
  • A Physics with Vernier lab book lists 35 experiments.

For schools

  • Basic is free. A Pro site license costs $149 for 1 year, $299 for 3 years, or $499 for 5 years.
  • Sensors cost extra.
  • Chromebooks use the browser version with ChromeOS 132 or newer.

Getting started checklist

Where is the AI in this product?

This tool has no AI. The app draws graphs and fits curves with fixed math. Students build data and sensor skills as they collect and read real measurements.

Privacy and safety

An account is optional, and the internet is needed at setup. The Vernier privacy notice covers only the website, which uses Google Analytics and is not meant for children. No privacy notice for the apps was found. What the app sends is unconfirmed, and Pro live data sharing sends data between devices. A teacher should ask Vernier for the app privacy terms before students make accounts and should use manual entry or local files when possible.

How this can be used for Science
  1. Collect temperature data as water cools and graph it.
  2. Use a motion sensor to graph a walk and describe the line.
  3. Compare data from two runs of an experiment.
  4. Follow an experiment from the Physics with Vernier lab book.
  5. Write a conclusion that cites the graph.
How this can be used for Math
  1. Enter a table by hand and draw the graph.
  2. Fit a line to data and read the slope.
  3. Try a curve fit and decide which fits best.
  4. Predict a value from a fitted curve and test it.
  5. Compare linear and nonlinear data from sensors.
