Tynker Creative Coding

A catalog of self-paced Tynker high school courses including an AI course.

$ LicenseAIComputingSends student data to a company

Overview

Tynker offers a high school catalog of 11 self paced courses. They range from the free Programming 400 starter to Python, JavaScript, Java, Data Science, MicroPython, and Artificial Intelligence 401. Lessons last about one class period and include lectures, puzzles, projects, and quizzes. The page does not confirm Creative Coding as a separate product.

Benefits

For students

  • Students work at their own pace.
  • Students can choose from several languages.
  • The AI 401 course uses JavaScript, p5.js, and MediaPipe.

For teachers

  • The school plan has lesson plans and automatic grading.
  • Lessons are about one class period each.
  • A free starter course lets teachers test the style.

For schools

  • Pricing is by quote. A search snippet shows 50 USD per student or 3,600 USD per school.
  • The courses run on the web and on Chromebooks.
  • Student data goes to the vendor. A review is needed.

Getting started checklist

Where is the AI in this product?

AI appears in one course, Artificial Intelligence 401. It uses Google MediaPipe for AI features in a JavaScript and p5.js project. The vendor does not say where the AI runs. Students write code that uses a model and then test the results.

How this can be used for Computer Science
  1. Start with Programming 400 and write down what each lesson teaches.
  2. Complete a Python lesson and add a feature of your own.
  3. Build a p5.js sketch in the AI 401 course that reacts to the camera.
  4. Take a lesson quiz and review the missed questions.
  5. Compare JavaScript and Python by solving one puzzle in each.
