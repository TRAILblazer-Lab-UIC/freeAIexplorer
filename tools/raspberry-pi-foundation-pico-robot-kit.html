Raspberry Pi Foundation Pico Robot Kit

A kit for building a MicroPython rover over six guided lessons.

FREEComputingRoboticsUnverified

The privacy details for this item are unverified. Check which tools and accounts students will use before class.

Overview

The Pico Robot Kit builds a robotic rover over six guided lessons using MicroPython. The kit holds a Raspberry Pi Pico, two DC gear motors, an L298N motor driver, a breadboard, LEDs and jumper wires. The tutorial is aimed at educators of grades 4 to 8 and needs no prior programming experience. Each lesson has plans, slides, activity sheets, starter code and videos.

Where is the AI in this product?

The kit has no AI. It builds skills in text coding, sequencing and motor control. Students write code that makes a rover move.

Privacy and safety

The kit runs on the device and the internet is needed only at setup. An account on the Pathfinders site is optional. The materials do not state what data is collected. A teacher should read the Pathfinders privacy terms before students use it.

How this can be used for Computer Science
  1. Run the starter code and explain what each line does.
  2. Change the motor speed in MicroPython.
  3. Write a loop that drives the rover in a square.
  4. Add an LED signal to show a turn.
  5. Share a program with a partner and debug it.
How this can be used for Engineering and Design
  1. Wire the motor driver on the breadboard.
  2. Test two gear motors and compare their speeds.
  3. Design a rover body that holds the batteries.
  4. Use the design lesson to plan the rover before building.
  5. Record changes after each test drive.
