Swift Playgrounds and Everyone Can Code

Apple's free coding curriculum that teaches Swift through puzzles on iPad and Mac.

FREEComputingUnverified

The privacy details for this item are unverified. Check which tools and accounts students will use before class.

Overview

Everyone Can Code is Apple's free coding curriculum built on the Swift Playgrounds app for iPad and Mac. Apple lists Early Learners, Puzzles, and Adventures guides. Puzzles offers more than 40 hours of activities, according to Apple. Students learn Swift by solving puzzles and walking through code.

Benefits

For students

  • Students learn Swift by solving puzzles that step through the code.
  • Students can move from Early Learners to Puzzles and Adventures.
  • Tactile graphics are available for students who are blind or have low vision.

For teachers

  • Teacher guides include example solutions and assessment ideas.
  • The Puzzles Teacher Guide includes CSTA correlations, per a search snippet.
  • A Curriculum Guide PDF is available.

For schools

  • The app and guides are free, but Apple devices are required and cost extra.
  • The app runs on iPad and Mac. No Chromebook support was found.
  • The internet is needed only at setup.

Getting started checklist

Where is the AI in this product?

Everyone Can Code has no AI. Students write Swift code and run it on the device. They practice sequencing, logic, and debugging as they solve each puzzle.

Privacy and safety

Apple says no account is needed for the coding resources and the internet is used only at setup. Work stays on the device. Data may leave the device if the school turns on iCloud, but this was not verified. The research did not read Apple's privacy terms for Swift Playgrounds. What the app collects is unknown. Check the school's iCloud settings and rules for apps on Apple devices.

How this can be used for Computer Science
  1. Solve the first Puzzles and explain what each command does.
  2. Predict what a piece of code will do before you run it.
  3. Fix a puzzle program that does not reach the goal.
  4. Write a new set of steps to solve a puzzle in fewer lines.
  5. Teach a partner how to use a loop.
How this can be used for Special Education and Accessibility
  1. Use tactile graphics to follow a puzzle layout by touch.
  2. Work through a puzzle with a partner and describe each step aloud.
  3. Break a puzzle into small steps and check each one.
  4. Choose an Early Learners activity and practice it at your own pace.
  5. Share a favorite puzzle solution with the class.
