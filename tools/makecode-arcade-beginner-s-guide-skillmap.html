MakeCode Arcade Beginner's Guide skillmap

An 11-tutorial path that teaches first coding skills through arcade games.

Computing

The privacy details for this item are unverified. Check which tools and accounts students will use before class.

Overview

The Beginner's Guide to Arcade Games is a MakeCode Arcade skillmap for ages 11 to 15 with little or no coding experience. It has 11 tutorials of about 145 minutes in total over 5 sessions. Students make a greeting card and joke, a clicker game, and a collector game with a dinosaur. Each learning path ends with a certificate of completion.

Benefits

For students

  • Students learn events, loops, variables, sprites, and scores.
  • Students finish three small projects.
  • Students earn a certificate for each path.

For teachers

  • The path is ready to use over a five-day plan.
  • Students can save projects to My Projects and change them.
  • The setup takes minutes.

For schools

  • The path is free.
  • It runs in a browser. Chromebook use is assumed and was not stated.
  • No install is described.

Getting started checklist

Where is the AI in this product?

This path has no AI. The vendor describes no AI features. Students build a game by writing rules. They practice sequencing, events, and logic.

Privacy and safety

The page does not say whether an account is needed. It mentions Save to My Projects, and the research did not confirm where progress data is saved. The research did not read the Microsoft privacy statement. The skillmap needs the internet at setup. A teacher should check whether students need a Microsoft account to save progress and what the privacy terms say.

How this can be used for Computer Science
  1. Make a greeting card with a joke that appears on a key press.
  2. Build a clicker game that adds one point for each click.
  3. Create a collector game with a dinosaur that catches items.
  4. Use random numbers to move an item to a new place.
  5. Save a finished game and change one rule.
