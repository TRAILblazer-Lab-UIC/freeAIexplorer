Matatalab Coding Set and Pro Set

A screen-free coding set where children place blocks in a tower to guide a robot car.

ComputingRobotics

Overview

The Matatalab Coding Set uses physical coding blocks placed in a command tower to control a small robot car. The site says kids learn coding skills by using the blocks to control the robot through algorithms. The Pro set adds Music and Artist block expansions. A Nasco classroom bundle lists four curriculum guides of 12 lessons each for PreK to grade 4. Listings give ages as 4 and up.

Benefits

For students

  • Students code with blocks and no screen.
  • Students see the robot car follow their program.
  • The Pro set adds music and drawing.

For teachers

  • Classroom sets include curriculum guides.
  • The robot needs only charging by USB.
  • The teacher learning curve is easy.

For schools

  • The Pro Set cost 229.99 USD at School Specialty.
  • A Pro classroom set of six was about 1,199.95 USD at ThinkEdu.
  • The set needs no accounts, devices or internet.

Getting started checklist

Where is the AI in this product?

The Matatalab set has no AI. The car follows the blocks that children place. Children build the skill of sequencing, which means putting steps in the right order.

Privacy and safety

No account is needed. The core robot is screen free and works without the internet. The site links a general privacy and cookie policy that the research did not read. A separate app and simulator exist, and their data practices were not checked. No independent classroom study was found. A teacher should check the privacy policy and the age guidance and small parts before giving the set to young children.

How this can be used for Computer Science
  1. Place blocks in the tower to drive the car forward and turn.
  2. Predict the car's path before pressing go.
  3. Fix a block order that sends the car the wrong way.
  4. Trade block programs with a partner.
  5. Build a longer route to a goal.
How this can be used for Music
  1. Use the Music blocks in the Pro set to play a short tune.
  2. Build a sequence that repeats a musical phrase.
  3. Match robot moves to the beat of a song.
  4. Compare two tunes made with different block orders.
  5. Perform the finished tune for the class.
