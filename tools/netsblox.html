NetsBlox

A networked block language built on Snap! for multiplayer games and apps.

Computing

Overview

NetsBlox is a networked visual programming language built as an extension of Snap!. Students build apps that send messages with data to other NetsBlox projects. They also call remote procedures on a server, such as a Maps service that returns a map image. High school students can make multiplayer games and client server programs.

Benefits

For students

  • Students build apps that talk across machines.
  • Students make multiplayer games such as Tic-Tac-Toe.
  • Students use blocks, which keeps the focus on ideas.

For teachers

  • A high school activity sequence starts with message passing and a simple chat app.
  • A curriculum site is available.
  • The hosted version needs no install.

For schools

  • The tool is free and open source.
  • A school can self-host with Docker Compose, which needs IT support.
  • The repository license was listed as none, and the latest release was v1.52.0 in 2023.

Getting started checklist

Where is the AI in this product?

This tool has no AI. It builds skills in networking, messages, and data. Students learn how programs on different machines work together.

Privacy and safety

An account is optional for browsing but is needed to save projects and to play multiplayer games. Sign up uses an account email and a guardian email, and saved projects are stored on the hosted site. The privacy policy page was unreadable. The research could not confirm COPPA or FERPA status. Services such as Maps may call third-party APIs, which the research did not verify. Confidence is low. A teacher should check the school data policy before using hosted accounts or choose to self-host.
