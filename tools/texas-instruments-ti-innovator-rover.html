Texas Instruments TI-Innovator Rover

A wheeled robot that students program from a TI graphing calculator.

$$ComputingRoboticsStays on the device

Overview

The TI-Innovator Rover is a wheeled robot with an aluminum chassis, a rechargeable battery, two driven wheels with encoders, a distance sensor, a gyroscope, and a color sensor. It is controlled by the TI-Innovator Hub, which sits in a bay on the Rover. Students write programs on a compatible TI graphing calculator and send them to the Rover. TI describes it as suited to middle grades and high school.

Benefits

For students

  • Students use a calculator they may already know to drive a real robot.
  • Students program in TI-Basic, or in Python on the TI-Nspire CX II family.
  • Students can draw paths on paper with the marker holder.

For teachers

  • TI offers free activities such as 10 Minutes of Code and Math in Motion.
  • The Rover works without a computer or Chromebook.
  • Activities fit math, science, and coding classes.

For schools

  • TI pages list no price. Search summaries of retailers showed about 167 to 182 USD for the Rover.
  • The TI-Innovator Hub and a compatible calculator are also needed.
  • The calculators may already be in the school.

Getting started checklist

Where is the AI in this product?

The Rover has no AI. It runs the program that students write and reads its sensors. Students build skills in sequencing, logic, and sensor data.

Privacy and safety

The product pages describe no accounts or cloud features. Students program the Rover from a calculator. The activities page has no Rover specific data notes and links only to general TI privacy, software data, and cookie policies. The research did not find TI data practices for the Rover. Visits to the TI website fall under TI cookie policies. Check the TI privacy links before students use the software. Check that the calculator model works with the Hub before ordering.

Ideas by subject

Select a subject to see five classroom ideas.

How this can be used for Math
  1. Drive the Rover in a square and measure each side.
  2. Program a triangle and find the turn angle that closes it.
  3. Use the marker holder to draw a geometry construction on paper.
  4. Compare the distance programmed with the distance the Rover travels.
  5. Change one number and predict how the path will change.
How this can be used for Computer Science
  1. Write a short TI-Basic program that drives the Rover forward and back.
  2. Use the color sensor to stop the Rover on a line.
  3. Program the Rover to escape a maze built from colored tape.
  4. Convert a program to Python on a TI-Nspire CX II calculator.
  5. Debug a program that sends the Rover off course.
How this can be used for Engineering and Design
  1. Build a maze from colored tape and test the Rover on it.
  2. Use the distance sensor to keep the Rover away from a wall.
  3. Plan the steps needed for the Rover to leave a maze, then test the plan.
  4. Record how many tries a program needed to work.
  5. Compare two designs for the same course and pick the better one.
