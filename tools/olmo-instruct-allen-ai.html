OLMo Instruct (Allen AI)

A fully open family of chat models from Ai2 with public data and code.

FREEAIStays on the device

Overview

OLMo, now branded Olmo 3 on the Ai2 site, is a family of fully open language models from the Allen Institute for AI. It has Base, Think, and Instruct variants at 7B and 32B sizes. Instruct models are built for chat, tool use, and multi-turn dialogue. Ai2 publishes the training data and the training and evaluation code.

Benefits

For students

  • Students can study how a language model is built from open data and code.
  • Students can chat with an Instruct model on their own computer.
  • Advanced students can compare model sizes.

For teachers

  • The European Open Source AI Index recommends OLMo Instruct for education.
  • The index cites its openness, documentation, and ease of access.
  • A hosted option exists in the Ai2 Playground.

For schools

  • The model weights are free.
  • Running costs depend on the hardware, and the 32B model needs much more than the 7B.
  • IT must install a runtime such as Ollama, llama.cpp, or LM Studio.

Getting started checklist

Where is the AI in this product?

The AI is an open language model that chats and writes text. It can run on the local computer or in the Ai2 Playground at the vendor's cloud. Students chat with the model and read the public data and code to see how it was made.

Privacy and safety

No account is needed, and the internet is used for the download. Local chats stay on the device when a runtime such as Ollama or llama.cpp runs the weights. The hosted Ai2 Playground sends prompts to Ai2, and the research did not read its privacy terms. Student data should not go there. A teacher should choose the local route for student work and check the license, which the Ai2 page read did not state.

How this can be used for Computer Science
  1. Read the model's published training data notes and list what kinds of text it includes.
  2. Chat with the 7B Instruct model and note where it makes mistakes.
  3. Compare an Instruct model with a Think model on the same question.
  4. Explain why open data and code help people check a model.
  5. Write a short report comparing a local model with the Ai2 Playground.
