Overview

This Skill Struck unit introduces programming and HTML through fourth grade math. It has five lessons on sequencing, variables, and conditionals. Students also use HTML for word problems and geometry with images. The unit sits inside a Grade 4 Cross Curricular course of 17 lessons across math, science, and ELA.

How this can be used for Math
  1. Write a short program that adds the steps of a word problem in order.
  2. Use a variable to store a number and update it in a math problem.
  3. Build a program that checks whether an answer is greater than a target using a conditional.
  4. Create an HTML page that shows a word problem and its answer.
  5. Place images on a page to show a geometry shape and label its sides.
How this can be used for Computer Science
  1. Put the steps of a simple task in order as a sequence.
  2. Store a value in a variable and print it.
  3. Write a conditional that gives one message for a right answer and another for a wrong one.
  4. Build a web page with headings and an image using HTML.
  5. Use a checkpoint to find and fix an error in a program.
