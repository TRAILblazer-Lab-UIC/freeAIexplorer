BBC micro:bit V2

A pocket-sized programmable board with sensors, a speaker, and optional AI training.

$AIComputingLocal with optional cloud or accounts

Overview

The micro:bit V2 is a pocket-sized programmable board. It has an LED display, buttons, motion and temperature sensors, a compass, a microphone, a speaker, and a touch-sensitive logo. Students program it with Microsoft MakeCode blocks or Python and download code over USB. The privacy policy cites ages 8 to 14.

Benefits

For students

  • Students see their code run on a real device within minutes.
  • The built-in sensors let students collect data with no extra parts.
  • Students can train a movement model with micro:bit CreateAI.

For teachers

  • Teachers can use free MakeCode lessons such as name badges, step counters, and nightlights.
  • The board works with a browser, including on a Chromebook.
  • Classroom accounts are optional.

For schools

  • Boards cost about 20 to 25 USD each. The Buy page did not show a price.
  • The board collects no data and needs no student account. Classroom accounts are optional.
  • A teacher can usually do setup without IT help, but some schools may need USB access approved.

Getting started checklist

Where is the AI in this product?

The board has no AI of its own. The foundation offers a separate tool called micro:bit CreateAI. It lets students record movement data, train a model in the browser, and use the model with the board. Students test the model with their own moves and then improve it.

Privacy and safety

The board collects no data and needs no student account. The optional Classroom service sends student names and code through foundation services on Amazon Web Services and Pusher. The policy says Pusher cannot read them. MakeCode is provided by Microsoft under its own privacy statement and the website uses Google Analytics. CreateAI keeps movement data in browser local storage. The policy says the board is designed for ages 8 to 14 and asks for parental consent under 13 citing GDPR. It does not mention COPPA. A teacher should decide whether to use Classroom accounts.

How this can be used for Computer Science
  1. Make a name badge in MakeCode and download it to the board.
  2. Build a step counter with the motion sensor and test it on a walk.
  3. Create a nightlight that responds to the light sensor.
  4. Make an emotion badge that shows a face when a button is pressed.
  5. Switch a project from blocks to Python and compare the two.
How this can be used for Engineering and Design
  1. Build a simple game controller using the buttons and motion sensor.
  2. Test how the speaker and microphone work together in a sound level meter.
  3. Design a case for the board and test it on a wrist or a backpack.
  4. Use the radio feature to send a message between two boards.
  5. Add a battery pack and record how long a project runs.
How this can be used for Science
  1. Log temperature data with the built-in sensor and chart it.
  2. Wrap boards in different materials and time how long each takes to warm up.
  3. Run a playground survey of activity and temperature using the boards.
  4. Compare indoor and outdoor readings and explain the difference.
  5. Use the accelerometer to measure how hard a toy cart stops.
