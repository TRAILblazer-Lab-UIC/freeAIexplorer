OpenBot

An open-source project that turns an Android phone into the brain of a low-cost robot.

Overview

OpenBot is an open-source project that turns an Android smartphone into the brain of a low-cost wheeled robot. The robot body costs about 50 USD and the phone is extra. The Android app supports person following and real-time autonomous navigation. Assembly needs basic mechanical and electronics skills, and the software setup relies on a command line.

Benefits

For students

  • Students build a real robot and give it a phone for a brain.
  • Students flash an Arduino and run an Android app.
  • Students see person following work on a robot they built.

For teachers

  • The code is MIT licensed.
  • The repository is active. It was pushed on 2026-11-18 and the latest release is v0.10.0.
  • IEEE Spectrum compares the hardware skill to an Arduino project.

For schools

  • The robot body costs about 50 USD. A compatible Android phone is extra.
  • The robot works only with an Android phone and not a Chromebook alone.
  • Setup is at maker level and IT should plan on days.

Getting started checklist

Where is the AI in this product?

The AI is person following and autonomous navigation. It runs in the Android app on the phone. Students build the robot, run the app, and test how well the robot follows.

Privacy and safety

No account is needed, and the internet is needed at setup. The phone does the processing. The privacy page on the project site loaded with no policy text. The research did not confirm whether the app uploads data, and one discovery note mentioned optional data upload. A teacher should check the app's camera permissions and its data settings. A teacher should also keep the phone's camera pointed away from faces when possible.

How this can be used for Computer Science
  1. Flash the Arduino and describe what the program does.
  2. Run person following and record when the robot loses the person.
  3. Compare robot behavior with the phone in two mounting positions.
  4. Read the app's settings and explain two of them.
  5. Write a plan to test the robot's navigation in a hallway.
How this can be used for Engineering and Design
  1. Build the robot body from parts or print it.
  2. Wire the Arduino Nano to the motors and test them.
  3. Mount the phone securely and balance the body.
  4. Measure the robot's speed over a set distance.
  5. Document the build in a guide with photos.
