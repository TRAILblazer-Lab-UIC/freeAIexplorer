Chatbox

A chat app that connects to many AI providers and to local models.

AI

Overview

Chatbox is a desktop and mobile chat client for many large language model providers. Users bring their own API keys or use Chatbox's hosted models. The open source Community Edition lists Ollama among its providers. It can talk to local models. It also offers document and image understanding, web search, and an agent mode. It is aimed at teachers and technical users more than students.

Benefits

For students

  • Older students can compare cloud and local models.
  • Students can see how a chat tool connects to a model.
  • Students can ask questions about a document or image.

For teachers

  • One interface works with OpenAI, Gemini, Anthropic, and others.
  • Chat history is stored on the device.
  • The Community Edition is open source.

For schools

  • The Community Edition is free.
  • Paid Chatbox AI subscription prices were not verified.
  • Cloud provider fees apply when using their API keys.

Getting started checklist

Where is the AI in this product?

The AI is the model that you connect. It may run at a cloud provider or on a local Ollama server. Chatbox is only the chat window. Students and teachers write prompts, read the answers, and use them in their own work.

Privacy and safety

Chat history is stored on the device, and the policy says Chatbox does not store chat logs on its servers. Log data such as device type, operating system, and IP address may be collected, and the policy names Google Analytics and Sentry. With a cloud provider, student prompts leave the school and go to that provider. The optional Chatbox AI service receives the current conversation but says it does not store it. Fully local use needs Ollama. The policy says the service is not intended for children under 13. A teacher should check the provider terms before students use the app.

How this can be used for Computer Science
  1. Send the same prompt to a cloud model and a local model and compare the answers.
  2. Time the two models and record the results.
  3. Upload a short document and ask the model a question about it.
  4. Write a prompt that gets a better answer after three tries.
  5. Explain in a paragraph how the app connects to a model.
