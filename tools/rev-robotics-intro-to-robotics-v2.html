REV Robotics Intro to Robotics V2

A semester-long high school robotics course written for REV hardware.

Overview

This is a semester-long high school robotics course with six units and more than 50 hours of content, for grades 9 to 12. It needs no prior robotics or programming experience. It builds from gear trains to autonomous robots. The course was written for REV hardware, and the kit is sold separately.

Benefits

For students

  • Students start with no experience and end with an autonomous robot.
  • Students learn mechanics before they learn programming.
  • Students build a robot in each unit.

For teachers

  • The course comes in an editable Google or Microsoft version.
  • A SCORM version is offered for a learning management system.
  • A search snippet says the course aligns with ISTE and ITEEA standards.

For schools

  • The list price is 299 USD. Teachers can get it free with a coupon code from the Curriculum Response Form.
  • The REV EDU Kit V2 was listed at 1,135 USD and was out of stock.
  • Intro to Robotics V1 is discontinued, according to a search snippet.

Getting started checklist

Where is the AI in this product?

This course has no AI. Students program robots to follow set rules. They build skills in sequencing and logic as they write autonomous routines.

Privacy and safety

The materials do not state which accounts or tools students need. Course files download from the REV site after checkout. The editable version needs a Google or Microsoft account, and the SCORM version needs a learning management system. The research did not read the privacy policy. The internet is used at setup, and a teacher can download the files in advance. A teacher should check the course files and the programming software before class.

How this can be used for Engineering and Design
  1. Build a gear train and measure how it changes speed.
  2. Compare two gear ratios and record which one climbs better.
  3. Design a drivetrain and sketch it before building.
  4. Test the robot on a small course and list fixes.
  5. Present the final build to the class and explain each choice.
How this can be used for Computer Science
  1. Write a program that drives the robot a set distance.
  2. Add turns to make the robot trace a square.
  3. Use a sensor reading to make the robot stop.
  4. Debug a routine that runs the wrong path.
  5. Combine the steps into an autonomous run.
