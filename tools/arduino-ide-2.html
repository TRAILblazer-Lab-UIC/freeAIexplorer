Arduino IDE 2

The free open source desktop editor for writing and uploading Arduino sketches.

FREEComputingStays on the device

Overview

Arduino IDE 2 is the open source desktop editor for writing and uploading Arduino sketches. The software page lists version 2.3.11 as current. It has autocomplete, board and library managers and a live debugger. Students write text code and send it to a board over USB.

Benefits

For students

  • Students get autocomplete that helps them write code.
  • Students can debug a sketch while it runs on the board.
  • Students use the same editor that many makers use.

For teachers

  • The board and library managers make setup simple.
  • The editor is open source under AGPL-3.0.
  • Arduino also offers a free Cloud Editor and a Cloud app for Chromebooks.

For schools

  • The editor is free.
  • No account is needed and projects stay on the device.
  • IT needs to install it and preload board packages for offline labs.

Getting started checklist

Where is the AI in this product?

The IDE has no AI. Students build skills in sequencing, logic and debugging. They write code, upload it and watch how the board responds.

Privacy and safety

No account is needed and sketches stay on the device in the desktop editor. Downloading board packages and libraries needs the internet. The software page does not mention telemetry and the research did not confirm update check behavior. The Cloud Editor stores sketches in Arduino Cloud. The materials do not say what student data the software collects. A teacher should test the install on a lab machine and check proxy settings on the school network.
