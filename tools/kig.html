Kig

Free interactive geometry software from the KDE Education Project.

FREEComputingStays on the device

Overview

Kig is interactive geometry software from the KDE Education Project. Users build constructions from points, vectors, lines, and polygons and move them with the mouse. It supports Python macros and can import DrGeo and Cabri files. It exports figures to LaTeX and SVG.

Benefits

For students

  • Students drag a point and watch the whole figure change.
  • Students test geometry ideas by moving shapes.
  • Students can save figures as pictures.

For teachers

  • Teachers can import files from DrGeo and Cabri.
  • The tool is easy for students and moderate for teachers.
  • Python macros give older students an extension.

For schools

  • The software is free and the code is open.
  • The KDE site lists Linux packages and macOS nightly builds.
  • Wikipedia also lists Windows, but the KDE page does not.

Getting started checklist

Where is the AI in this product?

Kig has no AI. It draws constructions by fixed rules. Students build pattern spotting skills as they see which properties stay the same when a figure moves.

Privacy and safety

No account is needed, and the internet is used for setup. The app runs locally, and the pages describe no accounts. No privacy policy was read. A teacher should check that the school computers run Linux or macOS.

How this can be used for Math
  1. Build a triangle and drag a corner to see which angles change.
  2. Construct the midpoint of a line and test it.
  3. Draw a perpendicular bisector and check where it meets the line.
  4. Build a quadrilateral and find the shapes that stay square.
  5. Export a figure and use it in a short write up.
