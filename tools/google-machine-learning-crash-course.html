Google Machine Learning Crash Course

A free self-paced Google course on machine learning with Python exercises in the browser.

FREEAILocal with optional cloud or accounts

Overview

This is a free machine learning course from Google. Modules cover regression, classification, data, neural networks, embeddings, large language models, production ML, automated ML, and fairness. Exercises run in the browser in Google Colaboratory with Python, NumPy, pandas, and Keras. Google recommends comfort with Python, algebra, and statistics. It suits advanced older students.

Benefits

For students

  • Students learn real machine learning methods at their own pace.
  • Students run code in Colab with no install.
  • Students explore neural networks in TensorFlow Playground.

For teachers

  • The modules give a ready path from linear regression to large language models.
  • Teachers do not need to write the lessons.
  • The course fits an independent study or an advanced elective.

For schools

  • The course is free.
  • It needs only a browser and works on Chromebooks.
  • Colab normally uses a Google account, and the internet is always needed.

Getting started checklist

Where is the AI in this product?

The AI is the set of methods that the course teaches. These include regression, classification, neural networks, embeddings, and large language models. Exercises run in Google's cloud through Colab, and TensorFlow Playground runs in the browser. Students write code, train small models, and read the results.

Privacy and safety

The internet is always needed. Exercises run in Google Colab. Code and data go to Google servers. The course pages do not state whether accounts are needed, and Colab normally uses a Google account, which the research did not verify. Notebooks may be stored in the cloud. TensorFlow Playground is described as not an official Google product. A teacher should check which accounts students will use and where notebooks are saved.

Ideas by subject

Select a subject to see five classroom ideas.

How this can be used for Computer Science
  1. Complete the first regression module and predict a value from data.
  2. Train a small classifier in Colab and measure how often it is right.
  3. Change the layers in TensorFlow Playground and describe the effect on the result.
  4. Read the fairness module and list two ways a model can treat groups unevenly.
  5. Explain embeddings to a classmate using one example.
How this can be used for Math
  1. Plot a line of best fit and explain its slope.
  2. Compute a loss value by hand for a tiny dataset.
  3. Explain how algebra helps describe a linear model.
  4. Compare the mean and spread of two small datasets.
  5. Describe how a model uses statistics to decide between two classes.
