Anki Cozmo

A small robot with a camera and face detection that kids program with blocks.

AIComputingRoboticsGood for AI beginners

The privacy details for this item are unverified. Check which tools and accounts students will use before class.

Overview

Cozmo is a small tracked robot with a camera, an animated face, and a lift arm. Anki launched it in 2016. Students program it in the Code Lab app, which uses Scratch based blocks. A Python SDK also exists.

Benefits

For students

  • Students program a robot with a lively personality.
  • Students use blocks first and can move to Python later.
  • Students watch the robot find and react to faces.

For teachers

  • The Code Lab app is easy to learn.
  • The robot holds student interest.
  • A Python SDK offers a path for older students.

For schools

  • Anki closed in 2019 and Digital Dream Labs now owns the robot.
  • Cozmo 2.0 is listed at 399.99 USD but was marked coming soon.
  • Buying and support are uncertain. Check before planning.

Getting started checklist

Where is the AI in this product?

Cozmo has face detection and an emotion engine that drives its behavior. The AI runs on the robot. Students program how Cozmo responds when it sees a face. They then watch the robot act on their code.

Privacy and safety

The app connects to the robot over WiFi. The materials do not state whether an account is needed or what data is collected. The research could not read a privacy policy because the privacy page returned 404. The Cozmo 2.0 page did not describe accounts or data handling. The robot uses a camera. A teacher should check the privacy terms from the current owner and confirm which phone apps the school can install.
