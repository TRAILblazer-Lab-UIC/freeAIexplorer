Common Sense Education cybersecurity lessons

Twenty-five free cybersecurity lessons for kindergarten through grade 12.

FREEAIComputingSends student data to a company

Overview

This collection has 25 lessons for kindergarten through grade 12. Titles include Internet Traffic Light, Gone Phishing, Data Breach Basics, and Facing Off with Facial Recognition. Each lesson has an extension activity from CYBER.ORG. Craig Newmark Philanthropies supported the work.

Benefits

For students

  • Students learn to spot phishing, protect privacy, and handle data breaches.
  • Lessons fit each grade, from kindergarten to grade 12.
  • Students learn about deepfakes and facial recognition in some lessons.

For teachers

  • Teachers browse by grade and open the lesson.
  • Each lesson comes with a CYBER.ORG extension activity.
  • The materials are free and need no setup.

For schools

  • The lessons are free.
  • They run in a browser with no install.
  • A separate K-8 collection also exists.

Getting started checklist

Where is the AI in this product?

The collection has no AI tools. Some lessons cover facial recognition and AI-based social engineering. Students learn to spot these risks. They build critical thinking and data skills.

Key terms on this page

Short definitions of words used above and below. Select a term for the full glossary entry.

Data breach
A data breach is an event where private data is stolen or exposed.
Deepfake
A deepfake is a fake video, image, or audio clip made with AI.
Face recognition
Face recognition is AI that finds faces in images or matches a face to a person.

Privacy and safety

The collection page does not say whether sign-in is required. The site needs the internet at all times. The materials do not say what data is collected. A teacher should check whether an account is asked for and review the vendor privacy terms. A teacher should also preview each lesson before sharing it with students.

Ideas by subject

Select a subject to see five classroom ideas.

How this can be used for Library and Media Literacy
  1. Use the Gone Phishing lesson to sort real and fake messages.
  2. Make a poster that shows three signs of a fake message.
  3. Discuss how a deepfake can spread and how to check it.
  4. Read about a data breach and list what people can do next.
  5. Write a class guide to safe sharing online.
How this can be used for Computer Science
  1. Use the Internet Traffic Light lesson to sort safe and risky actions.
  2. Study Data Breach Basics and explain how data gets lost.
  3. Do a CYBER.ORG extension activity and report what you found.
  4. Explain how facial recognition works at a basic level.
  5. Make a password plan with three rules.
