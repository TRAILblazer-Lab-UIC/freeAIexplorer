TidalCycles

A free live coding environment for making music patterns in code.

FREEComputingStays on the device

Overview

TidalCycles is a free and open source live coding environment for algorithmic music patterns. It is written in Haskell and lets users build polyphonic, polyrhythmic, and generative sequences in code. It uses SuperCollider for sound and MIDI. It suits advanced high school students. The project also points to Strudel, a browser version of the same pattern language.

Benefits

For students

  • Students write code that makes layered rhythms and melodies.
  • Students can perform music live from their keyboard.
  • Students can try Strudel in the browser as an easier start.

For teachers

  • A community offers docs, a forum, and chat.
  • A Live coding with Strudel course is available.
  • The sweep note says the install is harder than Strudel.

For schools

  • The software is free and open source.
  • It needs Haskell, SuperCollider, a text editor plugin, and the Tidal library.
  • IT approval and technical help are likely needed.

Getting started checklist

Where is the AI in this product?

TidalCycles has no AI. Students write code patterns that the program turns into music. They practice pattern spotting and logic.

Privacy and safety

No account is needed. The site makes no data statements and the research found no privacy policy. The software runs locally with SuperCollider and the internet is used at setup. The course page uses Strudel, a browser version, and the research did not review it. Plan time for IT to support the install. Ask IT to review the Strudel site before students use it.

How this can be used for Music
  1. Write a pattern that plays a drum rhythm.
  2. Layer two rhythms with different lengths and listen to the result.
  3. Change one number and describe how the beat shifts.
  4. Make a generative pattern that varies each cycle.
  5. Perform a short live set for the class.
How this can be used for Computer Science
  1. Read a pattern as code and say what each part does.
  2. Fix a pattern that has a typing error.
  3. Use a function to speed up a pattern.
  4. Compare Tidal with Strudel and note differences.
  5. Explain how the code reaches SuperCollider.
