Bot Blitz workshop

A story-driven robot workshop where students program Sphero RVR+ robots.

AIRobotics

The privacy details for this item are unverified. Check which tools and accounts students will use before class.

Overview

Bot Blitz is a hands-on workshop framework described in an AAAI-26 EAAI paper. It teaches AI and autonomous systems concepts to grades 5-12 through narrative problem solving. Students program Sphero RVR+ robots in storylines from fairground rescue missions to urban traffic management. Duke runs a 4-hour Junior track for grades 5-8 and an Advanced track for grades 8-12.

Benefits

For students

  • Students solve story-based robot missions.
  • Students program real robots on obstacle courses and scavenger hunts.
  • Students learn about sensors and robot navigation.

How this can be used for Computer Science
  1. Program a Sphero RVR+ to complete a rescue mission from a short story.
  2. Use a sensor reading to change the robot's path.
  3. Debug a failed run and write down the fix.
  4. Rewrite a program to finish the course faster.
  5. Explain how the robot decides where to go.
How this can be used for Engineering and Design
  1. Design an obstacle course for a rescue mission.
  2. Test the robot's path and measure the time taken.
  3. Plan a traffic management scenario with several robots.
  4. Compare two routes and pick the safer one.
  5. Present the solution and explain the design choices.
