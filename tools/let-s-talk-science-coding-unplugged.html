How this can be used for Computer Science
  1. Write steps for making a sandwich and have a partner follow them exactly.
  2. Find the unclear step and rewrite it.
  3. Plan a path for a toy through a maze using code text.
  4. Trade mazes with another pair and test the code.
  5. Add a repeat to your code and see if it gets shorter.
