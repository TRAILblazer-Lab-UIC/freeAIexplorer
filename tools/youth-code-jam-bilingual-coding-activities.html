Overview

Youth Code Jam offers free coding activities in English and Spanish, per a search summary of its CSforAll page. The activities have written step by step instructions with images. Getting started checklist

Where is the AI in this product?

The materials describe no AI. The activities use Scratch coding and unplugged tasks. Students build sequencing and logic skills as they follow steps and write code.

Privacy and safety

The materials do not state which tools or accounts students need. They do not say what data is collected. A teacher should check the tools in each activity and the Scratch account rules at school.
