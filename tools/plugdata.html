plugdata

A free visual audio programming tool based on Pure Data.

FREEComputingStays on the device

Overview

plugdata is a free open source visual programming environment for audio. It is based on Pure Data. Users connect blocks on a canvas to build synthesizers, effects, and sound tools. It runs as a standalone app or as a plugin inside a music program.

Benefits

For students

  • Students build their own instruments and effects.
  • Students hear the result of each connection right away.
  • Students can export code through Heavy for embedded boards.

For teachers

  • Built in documentation and tooltips help teachers learn.
  • Bundled libraries give students ready parts.
  • The patching style is node based and unlike Scratch. Teachers need practice.

For schools

  • The software is free and open source.
  • It runs offline on the local computer.
  • IT will likely need to approve the install.

Getting started checklist

Where is the AI in this product?

The vendor does not describe any AI in plugdata. It is a dataflow tool. Students build logic and sequencing skills as they connect blocks that pass signals along.

Privacy and safety

No account is needed and the program works offline. Student patches stay on the device. A teacher should check the volume on headphones before students test their sounds.

How this can be used for Music
  1. Build a simple synthesizer and change its pitch with a number box.
  2. Connect an effect to a sound and describe the change.
  3. Make a short loop and layer a second sound on top.
  4. Compare two filter settings and write down what you hear.
  5. Record a short piece made with your patch.
How this can be used for Computer Science
  1. Build a patch that turns a number into a sound and trace the flow of data.
  2. Add a control that changes a setting while the patch runs.
  3. Read a classmate's patch and explain it.
  4. Fix a patch that makes no sound.
  5. Compare dataflow programming with writing lines of code.
