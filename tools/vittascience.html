Vittascience

A French browser platform for block and Python coding of micro:bit, Arduino, and mBot.

FREEComputingRoboticsSends student data to a company

Overview

Vittascience is a French educational platform for coding and electronics that runs in a web browser. Learners program boards such as the BBC micro:bit, Arduino, and mBot with visual blocks or Python. Block code can be translated into Python. A class management module lets teachers create activities and view learner results.

Benefits

For students

  • Students can start with blocks and move to Python.
  • Students see their block code turn into Python.
  • Students can program real boards such as micro:bit and Arduino.

For teachers

  • The class management module lets teachers create activities and see results.
  • The interface comes in eight languages.
  • Teachers can add students by sign-up with email or other sign in.

For schools

  • A free tier exists.
  • A Premium plan and a class management offer of 99 euros are listed. Plan prices were not listed.
  • A micro:bit, Arduino, or other board is needed for physical projects.

Getting started checklist

Where is the AI in this product?

The vendor does not describe any AI on the pages read. One testimonial mentions students using free AI language models. AI features may exist. Students write blocks or Python that run on boards. They build skills in sequencing and logic.

Privacy and safety

The platform runs in the vendor's cloud and needs the internet at all times. Accounts are optional. Sign up uses email or Google, Microsoft, Apple, or IAM Luxembourg. Those sign in providers are involved when used. The privacy policy was not read, and the pages do not state what data is collected or where it is hosted. A teacher should read the privacy policy and decide what students may enter.

How this can be used for Computer Science
  1. Build a block program for a micro:bit that shows a message.
  2. Open the Python view of the same program and compare.
  3. Add a button input to the program.
  4. Change one block and predict the result.
  5. Debug a block program that does not run.
How this can be used for Engineering and Design
  1. Wire a simple circuit to an Arduino and program it from the browser.
  2. Program an mBot to move through a short course.
  3. Test a sensor and record its readings.
  4. Plan a small device and list the parts needed.
  5. Improve a program after a failed test.
