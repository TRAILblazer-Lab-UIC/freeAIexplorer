VEXcode VR

A browser based virtual robot platform where students code with blocks.

FREEComputingRoboticsLocal with optional cloud or accounts

Overview

VEXcode VR is a browser based virtual robot platform. Students code a virtual robot with blocks in simulated playgrounds. Paid Enhanced and Premium tiers add Python and project sharing through Google Drive or Dropbox. No hardware is needed.

Benefits

For students

  • Students code a virtual robot and see it move on screen.
  • Students solve challenges in simulated playgrounds.
  • Students can move on to Python in the paid tiers.

For teachers

  • Teachers open vr.vex.com and start in minutes.
  • A VR Educators Start Here guide supports lessons.
  • One review said core use needs no sign-in.

For schools

  • The free tier needs no purchase.
  • Enhanced costs 199 USD per educator per year and Premium costs 499 USD, per a search snippet.
  • Any computer or tablet with a browser works.

Getting started checklist

Where is the AI in this product?

VEXcode VR has no AI. The virtual robot follows the blocks that students build. Students build skills in sequencing and logic.

Privacy and safety

An account is optional and the tool needs the internet at all times. The materials say sharing in the paid tiers goes through Google Drive or Dropbox, which sends project files to those services. A search snippet of the VEX software privacy policy says VEX uses service providers including Google for analytics and storage and Cloudflare for delivery and security. The snippet also says some applications are directed to children under 13. The policy page could not be read, and the materials do not say what data is collected. A teacher should read the VEX privacy policy and check which sign in students would use.

How this can be used for Computer Science
  1. Build a block program that drives the virtual robot across a playground.
  2. Use a loop to repeat a motion.
  3. Change one block and predict the result.
  4. Trade programs with a partner and fix any bugs.
  5. Move a working program into Python if a paid tier is available.
How this can be used for Engineering and Design
  1. Plan a route in a playground and test the robot on it.
  2. Measure how far the robot travels in a set time.
  3. Change the robot's path to avoid an obstacle.
  4. Compare two solutions to one challenge and pick the better one.
  5. Record each attempt and note how the design improved.
