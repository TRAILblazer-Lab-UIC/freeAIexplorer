The Da Vinci Coders

A board game that teaches basic programming and Java syntax without a computer.

ComputingUnplugged

Overview

The Da Vinci Coders is a board game that teaches basic programming and Java syntax. A student group led by Nora Husani made it. They showed it at the Educational Arcade of the Games + Learning + Society conference. Players read Java code to move their tokens. A search summary of the 2017 conference paper says the target age is 12 and up.

Benefits

For students

  • Students read real Java code on game cards.
  • Students move tokens by working out what each line does.
  • A final card asks students to translate English into Java.

For teachers

  • The game needs no computer.
  • A rulebook and a demo of Version 1.0 are said to be linked from the conference paper.
  • The game is a student design project. Confirm that it can be obtained.

For schools

  • The price and availability were not found.
  • The game needs no devices or internet.
  • It collects no student data.

Getting started checklist

Where is the AI in this product?

This game has no AI. It builds an AI-related skill, which is reading and following code. Students trace what each line does to a token.

Privacy and safety

The game is a physical board game with cards, and no data collection is described. No accounts are needed. The project page labels it a digital game, which conflicts with the board game description. The research could not confirm the publisher or how to get the game. Check that before planning a lesson. Read the cards for age fit with your class.

How this can be used for Computer Science
  1. Read a Java card and move your token to the spot the code says.
  2. Predict where a line of code will send a token before you move it.
  3. Translate a plain English instruction into a Java line on the final card.
  4. Explain to a partner what a line of Java does.
  5. Write your own short card in plain English and swap it with a classmate.
