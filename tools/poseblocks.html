PoseBlocks

Scratch-style blocks from MIT that track the body for dance and movement projects.

FREEAIComputingUnverifiedGood for AI beginners

Overview

PoseBlocks is a set of block-based tools from the MIT Media Lab Personal Robots Group. Students build body-interactive AI projects in a web browser. The blocks live in a forked version of Scratch. It pairs with the Dancing with AI workshop for middle schoolers.

Benefits

For students

  • Students build projects that react to their body movement.
  • Students see pose detection at work through a webcam.
  • Students can make dance projects with blocks.

For teachers

  • A week-long Dancing with AI workshop gives a ready path.
  • The tool opens from the Dancing with AI site.
  • The interface looks like Scratch.

For schools

  • No cost was found. It is an academic research tool.
  • It runs in a browser and needs a webcam.
  • No install is needed.

Getting started checklist

Where is the AI in this product?

The AI is pose detection. It runs in the browser on the local device. Students move in front of the webcam and the blocks respond. They then change their code to make new body-controlled projects.

Privacy and safety

The materials do not state what student data is collected or whether accounts are needed. The tool uses a webcam. A paper snippet says projects run in a web browser. The research did not confirm where pose detection runs, and no privacy policy was read. A teacher should check how video is handled and confirm that students have permission to use cameras.

How this can be used for Computer Science
  1. Run the Dancing with AI workshop and build a project that follows your arms.
  2. Make a sprite copy a dance move you perform.
  3. Build a game that you control with your body and no keyboard.
  4. Test the pose detection in dim light and describe what changes.
  5. Teach a partner how the blocks track the body.
