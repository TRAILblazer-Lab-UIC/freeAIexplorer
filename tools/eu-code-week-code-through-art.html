EU Code Week Code through Art

Three lesson plans that mix pixel art, grid play, and a Bee-bot for ages 4-6.

FREERoboticsUnpluggedUnverified

The privacy details for this item are unverified. Check which tools and accounts students will use before class.

Overview

Code Through Art is an EU Code Week learning bit by Maria Tsapara for children aged 4 to 6. It has three lesson plans called Artful Coding, Creative Code Lab, and Touch Canvas. The activities include unplugged pixel art and children acting as robots on a floor grid. The plugged parts use a Bee-bot robot and a Makey Makey kit.

Benefits

For students

  • Children learn early coding ideas through drawing and play.
  • Children act as robots and give each other directions.
  • Children make interactive paintings with a Makey Makey kit.

For teachers

  • The plans are ready to download.
  • The first two plans work with paper and floor space.
  • The Creative Code Lab runs about 90 minutes, according to a search snippet.

For schools

  • The lesson plans are free.
  • The Bee-bot robot and Makey Makey kit are separate purchases.

Getting started checklist

Where is the AI in this product?

This lesson set has no AI. Children give step-by-step directions to a robot or to each other. They build sequencing skills.

Privacy and safety

The materials do not state whether an account is needed. The page says the lesson plans collect no data. The internet is used only to download the plans. Bee-bot and Makey Makey are offline devices, but the research did not read their own privacy policies. A teacher should check the Code Week site terms before use. A teacher should also supervise young children around the electronic parts.

Ideas by subject

Select a subject to see five classroom ideas.

How this can be used for Visual Arts
  1. Make a pixel art picture on a paper grid by coloring squares.
  2. Describe a pixel picture to a partner who draws it from your words.
  3. Design a painting that will become a Touch Canvas.
  4. Add copper tape or a touch point to the painting.
  5. Show the interactive painting to the class and explain how it works.
How this can be used for Computer Science
  1. Act as a robot on a floor grid and follow a partner's directions.
  2. Program the Bee-bot to move to a picture on a mat.
  3. Predict where the robot will stop before pressing go.
  4. Fix a set of directions that sent the robot the wrong way.
  5. Write a short list of steps for a friend to follow.
