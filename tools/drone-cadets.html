Drone Cadets

A New York program offering indoor drone flight and light show courses.

ComputingRobotics

The privacy details for this item are unverified. Check which tools and accounts students will use before class.

Overview

Drone Cadets is a New York based program offering indoor drone flight and light show courses with guarded drones. The listing shows six programs, from Mini Cadets Drone Flight School for K-2 to Cyber Cadets and VR Metaverse for older students. Students set up base stations, calibrate software and set geofences. Longer programs add coding.

Benefits

For students

  • Students fly guarded drones indoors.
  • Students learn base station setup, calibration and geofences.
  • Students in longer courses add soldering, hardware basics and coding.

For teachers

  • The provider runs the program with its own drones.
  • Programs range from K-2 to grade 12 and workforce.
  • Teachers need little drone knowledge to host a course.

For schools

  • A 2025 press article lists Mini Cadets at 7000 USD for 10 hours and 15 students.
  • It lists the Drone Flight School at 25000 USD for 20 hours and 20 students.
  • These prices were not confirmed on a provider page.

How this can be used for Engineering and Design
  1. Set up a base station and describe each step.
  2. Calibrate the flight software and record the settings.
  3. Set a geofence and test that the drone stays inside.
  4. Design a light show pattern and plan the flight.
  5. Solder a simple part in a longer program and test it.
How this can be used for Computer Science
  1. Write a short flight program in a longer course.
  2. Change one value in the code and predict the flight.
  3. Plan a light show with a list of moves.
  4. Test a program and fix a mistake.
  5. Explain how a geofence works in the code.
