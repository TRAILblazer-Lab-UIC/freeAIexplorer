Parallax Boe-Bot with Arduino shield

A servo-driven Arduino robot kit with a free 40-activity tutorial.

$$$ComputingRoboticsStays on the device

Overview

The Boe Shield-Bot is a Parallax robot kit that pairs a Board of Education Shield with an Arduino Uno on an aluminum chassis. It has two continuous rotation servos. A free online tutorial has 40 hands-on activities. Building takes about an hour and the kit assumes no prior programming.

Benefits

For students

  • Students build and program a real robot.
  • Students try servo calibration, touch switches, phototransistors and infrared distance sensing.
  • Students write Arduino code with a clear tutorial to follow.

For teachers

  • The free tutorial has 40 activities.
  • The kit assumes no prior programming.
  • STEMfinity lists it for grades 7-12.

For schools

  • STEMfinity lists it at 299 USD with an Arduino Uno. Parallax showed 259 USD without one.
  • Five AA batteries are needed and are not included.
  • IT must install the Arduino IDE.

Getting started checklist

Where is the AI in this product?

The kit has no AI. It builds skills in sensors, logic and sequencing. Students write code that turns sensor readings into robot moves.

Privacy and safety

The robot runs from the Arduino board, and no account is needed. The internet is used to download the Arduino IDE. The materials document no student data collection, and the research read no privacy policy. A teacher should note that product names vary across Boe-Bot, Boe Shield-Bot, and Robot Shield with Arduino. Check that you order the right one.

How this can be used for Engineering and Design
  1. Assemble the chassis and the shield and test the wiring.
  2. Calibrate the servos so the robot drives straight.
  3. Add touch switches and test how the robot reacts to a bump.
  4. Use infrared sensing to avoid a wall.
  5. Record how each change improves the robot.
How this can be used for Computer Science
  1. Write an Arduino sketch to move the robot forward and stop.
  2. Add a loop for a repeated square path.
  3. Use a condition to react to a touch switch.
  4. Read a phototransistor value and print it.
  5. Debug a program that makes the robot drift.
