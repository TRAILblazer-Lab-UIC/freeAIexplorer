Experience CS

A free integrated computer science curriculum for grades 3 to 8.

FREEComputingSends student data to a company

Overview

Experience CS is a free integrated computer science curriculum for grades 3 to 8. It has 18 project-based units, three per grade, that fold coding into math, science, language arts, social studies, and the arts. Each unit includes lesson plans, slides, student activities, starter Scratch projects, and teacher guidance. No prior computer science experience is needed for teachers.

Benefits

For students

  • Students use coding inside subjects they already study.
  • Students start from Scratch projects that already work.
  • Students make projects such as figurative language, networks, and generative art.

For teachers

  • Every unit has lesson plans, slides, and guidance.
  • Free teacher professional development is offered.
  • No prior computer science experience is needed.

For schools

  • The curriculum and professional development are free.
  • A school-safe Scratch editor is included.
  • A district can request a data privacy agreement.

Getting started checklist

Where is the AI in this product?

Experience CS has no AI. It builds sequencing, loop, and data skills. Students plan steps in Scratch and test them against a goal.

Privacy and safety

Accounts are required and the internet is always needed. Teachers create student accounts in Code Classroom, or students sign in with Google. The data listed is a first name and last initial or a school-provided ID, plus project work. The Raspberry Pi Foundation policy says it does not use student data for advertising or profiling and acts as a processor for schools. It cites COPPA, with parental consent given through the school. The policy does not state where data is stored. A teacher should ask the district about a data privacy agreement before students sign in.

Ideas by subject

Select a subject to see five classroom ideas.

How this can be used for Computer Science
  1. Open a starter Scratch project and change what a sprite does.
  2. Build a project with a loop and an event.
  3. Learn how networks send packets and act out the steps.
  4. Use an algorithm to make generative art.
  5. Share a project and explain how it works.
How this can be used for English and Language Arts
  1. Build a grade 3 project about figurative language and idioms.
  2. Animate a short story with characters who talk.
  3. Write the dialogue first and then code it.
  4. Act out an idiom and show its meaning.
  5. Present a project to the class and read the text aloud.
How this can be used for Math
  1. Use coding to draw shapes with exact side lengths.
  2. Build a project that counts and shows a total.
  3. Test a pattern in a loop and describe the rule.
  4. Make a project that checks an answer.
  5. Compare two programs that give the same result.
How this can be used for Science
  1. Build a model of a science idea in Scratch.
  2. Show a cycle with a loop.
  3. Collect results in a project and describe them.
  4. Test a prediction and record what happened.
  5. Explain a science idea with a short Scratch demo.
How this can be used for Social Studies
  1. Create a project that tells a story from history.
  2. Make a map project with moving characters.
  3. Show how a community changes over time.
  4. Build a short quiz on a social studies topic.
  5. Present a project and tell what was learned.
