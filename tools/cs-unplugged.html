CS Unplugged

A free website of computer science games and puzzles that need no computers.

FREEComputingUnpluggedNo device needed

Overview

CS Unplugged is a free website of teaching material that introduces computer science without computers. It uses games and puzzles with cards, string, crayons, and physical activity. The site holds topics, printables, curriculum integrations, distance lessons, a MOOC, and a glossary. It is run by the Computer Science Education Research Group at the University of Canterbury.

Benefits

For students

  • Students learn computer science through games and movement.
  • Students explore ideas such as binary numbers and image representation.
  • Students can read the site in six languages.

For teachers

  • The site offers topics, printables, and curriculum integrations.
  • Distance lessons and a teacher MOOC are available.
  • A glossary explains key terms.

For schools

  • The site is free, and the content uses a CC BY-SA 4.0 license.
  • The activities need cards, string, and paper.
  • No devices or accounts are needed.

Getting started checklist

Where is the AI in this product?

This site has no AI. It builds computing skills such as working with data, algorithms, and sorting. Students learn the ideas behind computers by acting them out.

Privacy and safety

The activities run on paper and with physical materials. The home page mentions no account or login, and the research found no student data collected. No privacy policy was read. The internet is used to browse and print. The grade range is not stated on the home page. A teacher should check each lesson for its age range.

Ideas by subject

Select a subject to see five classroom ideas.

How this can be used for Computer Science
  1. Hold dot cards to show how a computer stores a number in binary.
  2. Act out an algorithm with a partner using cards.
  3. Explore how an image is built from pixels.
  4. Sort a set of numbers using a physical network.
  5. Explain one activity to a younger class.
How this can be used for Math
  1. Count in binary with dot cards.
  2. Sort numbers with a sorting activity.
  3. Play a guessing game and count the guesses.
  4. Find the pattern in a set of codes.
  5. Make up a number puzzle for a classmate.
How this can be used for Visual Arts
  1. Make a binary pattern with two colors.
  2. Draw a pixel image from a set of codes.
  3. Design a necklace that encodes a name in binary.
  4. Compare two coded images and describe the difference.
  5. Show your art with a key that explains the code.
How this can be used for Music
  1. Perform a binary tune with claps and rests.
  2. Write a rhythm from a binary number.
  3. Swap rhythms with a partner and play each other's tune.
  4. Change one bit in a rhythm and listen to the result.
  5. Teach a coded rhythm to the class.
