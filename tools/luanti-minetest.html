Luanti (Minetest)

A free, open source block-world game engine that students can mod with Lua.

Computing

Overview

Luanti, formerly Minetest, is a free voxel game engine. Worlds are built from nodes. Games and mods are installed from the built-in ContentDB, and mods are written in Lua. The engine has no playable content until a game or mod is added.

Benefits

For students

  • Students build and explore in 3D worlds.
  • Students can write mods in Lua.
  • Students work together on shared projects.

For teachers

  • ContentDB has over 2,000 community mods and an education tag.
  • Teachers can run single player, a local server, or a BLOCKALOT world.
  • Teachers will need time to learn the setup.

For schools

  • The software is free. BLOCKALOT hosting is currently free per the education page.
  • It runs on low-spec hardware.
  • A server on the school network needs a server administrator.

Getting started checklist

Where is the AI in this product?

Luanti has no AI. Students can write Lua code that controls how blocks and mods behave. They build skills in logic and sequencing.

Privacy and safety

No account is needed for single player. Each multiplayer server keeps its own separate accounts. A school run server keeps data on that server. The education page links an app privacy policy that the research did not read. The materials do not state what student data is collected. The public server list and ContentDB need the internet. A teacher should check who runs the server and set clear rules for chat and behavior.

Ideas by subject

Select a subject to see five classroom ideas.

How this can be used for Social Studies
  1. Rebuild a heritage site and add notes about its history. Primary classes did this in the Minestory project.
  2. Design a community space and explain who will use it.
  3. Place the buildings of a historic town on a timeline.
  4. Share a city plan with a classmate and compare ideas.
  5. Write a short guide to a world for a visitor.
How this can be used for Science
  1. Build a model of a local habitat and label each part.
  2. Make a virtual field trip stop for a place the class has studied.
  3. Create a digital twin of the school grounds and measure it.
  4. Compare a model world with photos of the real place.
  5. Present what the model shows about the environment.
How this can be used for Computer Science
  1. Install a simple mod and read its Lua code.
  2. Change a value in the code and describe the effect.
  3. Write a mod that adds a new block.
  4. Debug a classmate's mod by reading the error message.
  5. Document a mod so another student can use it.
