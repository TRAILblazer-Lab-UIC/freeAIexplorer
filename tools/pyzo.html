Pyzo

A free Python editor with an interactive shell for trying code line by line.

FREEComputingStays on the device

Overview

Pyzo is a free open source Python IDE aimed at interactivity and simplicity. It has an editor, an interactive shell, and a set of tools. It works with any Python 3 interpreter on the computer, including Conda environments. Students run commands in the shell or write code in the editor and run it.

Benefits

For students

  • Students test single lines in the shell and see answers at once.
  • Students write longer programs in the editor.
  • Students can run code a cell at a time.

For teachers

  • The simple layout is easy to demonstrate.
  • Teachers can install packages from the shell with the install command.
  • The tool works with the Python that the school already uses.

For schools

  • The software is free and open source.
  • Work stays on the local computer.
  • The install has two parts. IT will likely need to help.

Getting started checklist

Where is the AI in this product?

Pyzo has no AI. It builds an AI-related skill, which is working with data. Students try ideas in the shell and see results at once. That habit supports later data work.

Privacy and safety

No account is needed, and the internet is used only at setup. Code and files stay on the device. Pyzo is not a native Chromebook app. A teacher should plan for IT help with the two-part install.

How this can be used for Computer Science
  1. Type short expressions in the shell and record what each one returns.
  2. Write a program in the editor and run it a cell at a time.
  3. Install a small package with the install command and use it.
  4. Write a function and test it in the shell.
  5. Compare the shell and the editor and explain when each one helps.
