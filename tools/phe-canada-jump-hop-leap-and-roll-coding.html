PHE Canada Jump, Hop, Leap, and Roll Coding

A one-page K-3 activity where children order movement slips into a performance code.

ComputingUnplugged

Overview

This is a one-page activity from PHE Canada's home learning resources. A child writes movement skills such as jump, hop, leap and roll on six paper slips. The child lays the slips in a line to make a performance code. The child performs the code and then tries to repeat it from memory.

Benefits

For students

  • Students learn that a code is an ordered list of steps.
  • Students move their bodies while they practice sequencing.
  • Students challenge their memory and make new codes.

For teachers

  • The page includes inclusion modifications through the STEP framework.
  • It includes reflection questions for after the activity.
  • Older children can add direction arrows to each slip.

For schools

  • The activity is a free download.
  • It needs only paper, a container and a safe open space.
  • It uses no devices and the PDF does not mention computers.

Getting started checklist

Where is the AI in this product?

This activity has no AI. It builds an AI-related skill, which is sequencing. Children see that a list of steps in a set order gives a repeatable result.

Privacy and safety

The activity runs on paper. No accounts are needed and no student data is collected. The internet is used only to download the PDF. A teacher should check the space for hazards before children jump, hop, leap and roll. Use the STEP modifications to include every child.

How this can be used for Health and PE
  1. Perform a six-move code of jumps, hops, leaps and rolls in order.
  2. Repeat a classmate's code from memory.
  3. Change one slip and describe how the movement changes.
  4. Use the STEP framework to adjust a code so every child can join.
  5. Answer the reflection questions about how your body felt.
How this can be used for Computer Science
  1. Lay six slips in a line and say that the line is your code.
  2. Swap two slips and tell what happens to the performance.
  3. Add direction arrows to each slip and perform the new code.
  4. Write a code on paper and give it to a partner to act out.
  5. Find a slip out of order and fix the code.
