Hong Kong EDB Coding in PE example

A Hong Kong Education Bureau outline for a two-week coding project in PE.

Overview

This is an 8-slide Education Bureau deck titled Coding in PE. It describes a two-week project of four 35-minute lessons. Lesson 1 is an introduction and demo, Lesson 2 is the first trial, Lesson 3 is refinement and a second trial, and Lesson 4 is workouts and a presentation. The slides do not state the grade, the coding tool, or whether devices are used.

How this can be used for Health and PE
  1. Write a short sequence of movements and perform it for a partner.
  2. Run a first trial of a movement plan and reflect on what worked.
  3. Refine the plan and run a second trial.
  4. Design a workout from a set of coded steps.
  5. Present the final workout to the class.
How this can be used for Computer Science
  1. Break a movement into small ordered steps.
  2. Use a loop in a plan that repeats an exercise.
  3. Find a mistake in a classmate's steps and suggest a fix.
  4. Compare two plans and decide which is shorter.
  5. Explain how trial and refinement helps improve a program.
