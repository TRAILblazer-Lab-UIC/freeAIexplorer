CodeHS Ozobot course

An elementary CodeHS course that teaches coding with Ozobot color codes on paper.

ComputingRobotics

Overview

Coding with Ozobot is an elementary CodeHop course for grades K to 5. It has 1 unit with 5 lessons and takes about 3 hours. Students program Ozobot robots with color codes drawn on paper in increasingly complex challenges. They also build projects such as animating a science cycle and a timeline of events.

Benefits

For students

  • Students draw color codes that the robot reads.
  • Students build projects across science and ELA.
  • Most lessons need no computer.

For teachers

  • The course has lesson plans, slides and rubrics.
  • Slides are in English and Spanish.
  • It lists alignment to state CS standards and connections to NGSS and Common Core ELA.

For schools

  • No price is listed. The page offers a Get in Touch link.
  • Ozobot robots are bought separately.
  • Paper and color markers cover the rest of the supplies.

Getting started checklist

Where is the AI in this product?

The vendor does not describe any AI in this course. Ozobot reads the color codes that students draw and follows them. Students build skills in sequencing, patterns and debugging.

Privacy and safety

The materials do not say what accounts this course needs. Most lessons use paper and markers, and one lesson uses Ozobot Classroom. A search snippet says Ozobot Classroom is for teachers only and that Ozobot lists FERPA and COPPA certification through iKeepSafe. The CodeHS policy lists name, email, coursework, and saved code. It says data on users under 13 is collected only with parental consent obtained by the school, district, or teacher. It says data is hosted on AWS and deleted about 4 years after last login. A teacher should ask CodeHS what student data applies before using any online part.

Ideas by subject

Select a subject to see five classroom ideas.

How this can be used for Computer Science
  1. Draw a color code path and watch Ozobot follow it.
  2. Predict what Ozobot does at a junction and test the guess.
  3. Fix a path that the robot reads the wrong way.
  4. Make a more complex challenge with several color codes.
  5. Swap paths with a partner and solve each other's puzzle.
How this can be used for Science
  1. Animate a science cycle by sending Ozobot around its stages.
  2. Draw a water cycle path with color codes for each stage.
  3. Label each stop on the path with a science word.
  4. Compare two cycles and describe the differences.
  5. Explain the path to the class using science terms.
How this can be used for English and Language Arts
  1. Build a timeline of events and send Ozobot along it in order.
  2. Retell a story by drawing a path through each scene.
  3. Write a caption for each stop on the timeline.
  4. Order a set of events and test the order with the robot.
  5. Present a timeline to a partner group and answer questions.
