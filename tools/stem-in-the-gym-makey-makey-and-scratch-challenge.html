STEM in the Gym Makey Makey and Scratch Challenge

A two-week challenge to design an active PE game with Makey Makey and Scratch.

FREEComputingSends student data to a company

Overview

This guide asks students to design a physical activity game using a Makey Makey and Scratch. It is adapted from Round Hill PE's STEM in the Gym project by Eric Turrill. The challenge asks how to design a game that gets kids moving. It runs about two weeks of 45 minute classes for grades 3 to 8.

Benefits

For students

  • Students build switches from foil and cardboard and see how a circuit sends a signal.
  • Students add a score and a timer in Scratch with variables.
  • Students share their finished games with other PE classes.

For teachers

  • The guide walks through the unit from exploring switches to building and sharing.
  • Teachers can copy a student Google Doc to guide groups.
  • The unit joins PE with coding and building.

For schools

  • The guide is free. Each group needs one Makey Makey Classic, and its price was not checked.
  • Other supplies are foil, paper, conductive tape, and PE equipment.
  • The unit needs the internet at all times and Scratch accounts for each group.

Getting started checklist

Where is the AI in this product?

This unit has no AI. Students build switches and write score and timer code in Scratch. They practice logic and sequencing by deciding what each touch should do in the game.

Privacy and safety

Scratch accounts are required for each group, and the internet is needed at all times. The guide also asks for a student Google Doc. Scratch and Google handle that account data under their own policies, which the research did not read. A teacher should check the school's rules and consider using group accounts that carry no personal details.

Ideas by subject

Select a subject to see five classroom ideas.

How this can be used for Health and PE
  1. Design a game that gets every player moving and name the muscles or skills it uses.
  2. Write the rules for the game on a poster and teach them to another PE class.
  3. Test the game for ten minutes and record how active each player stays.
  4. Change one rule to make the game safer or more fun and play again.
  5. Hold a share day where classes try each other's games.
How this can be used for Computer Science
  1. Build a Scratch score variable that goes up each time a player hits a switch.
  2. Add a timer that ends the game after a fixed time.
  3. Make Scratch respond to different Makey Makey keys in different ways.
  4. Find and fix a bug in the score code after a test round.
  5. Explain to a partner how a press on a foil switch leads to a point on screen.
How this can be used for Engineering and Design
  1. Build a foil and cardboard switch and test whether it works every time.
  2. Compare two switch designs and choose the one that lasts longer.
  3. Redesign a switch for players to use while running.
  4. Draw a diagram of the circuit from the player's hand to the Makey Makey.
  5. Improve the game board layout after watching a test round.
