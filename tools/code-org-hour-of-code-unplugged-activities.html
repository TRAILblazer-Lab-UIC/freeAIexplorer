Code.org Hour of Code Unplugged Activities

Five free unplugged lessons on robots, compression, encryption, dance, and AI ethics.

FREEAIComputingUnpluggedUnverifiedGood for AI beginners

The privacy details for this item are unverified. Check which tools and accounts students will use before class.

Overview

The Hour of Code unplugged unit from Code.org has five lessons. They are My Robotic Friends Relay, Text Compression, Simple Encryption, Dance Party Unplugged, and Our AI Code of Ethics. Grade bands run from K-2 to 9-12. Activities take about 15 to 45 minutes.

Benefits

For students

  • Students learn computing ideas by moving, talking, and working on paper.
  • Students practice giving exact instructions and spotting patterns.
  • Older students discuss AI ethics in a lesson of their own.

For teachers

  • Teacher guides and student handouts are included.
  • Lessons need little preparation.
  • Teachers can pick a lesson that fits the grade band.

For schools

  • The unit is free.
  • Most lessons need only printed handouts.
  • Some lessons need a projector or a browser for a video or widget.

Getting started checklist

Where is the AI in this product?

Most of the unit has no AI. Lesson 5, Our AI Code of Ethics, is the AI lesson, and it is a discussion activity. The unit has no AI tool that runs on a device. Students build skills in instructions, compression, and ethics that help them think about AI.

Privacy and safety

The materials do not state which accounts students need or how data is handled. The unit is built on paper. Text Compression and Simple Encryption list an online widget for students, and Dance Party lists a Spotify playlist. The internet is needed for those items. A teacher should check any online widget and the playlist before class. A teacher should also set ground rules for discussing AI ethics.

How this can be used for Computer Science
  1. Play My Robotic Friends Relay and write exact instructions for a classmate to follow.
  2. Compress a short message in the Text Compression lesson and count how much shorter it gets.
  3. Crack and create a code in the Simple Encryption lesson.
  4. Choreograph a dance with repeat rules in Dance Party Unplugged.
  5. Write a class code of ethics for AI in Our AI Code of Ethics.
