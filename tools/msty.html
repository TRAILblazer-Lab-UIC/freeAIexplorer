Msty

A desktop AI workspace for chatting with local or cloud models.

FREEAILocal with optional cloud or accounts

Overview

Msty Studio is a desktop AI workspace for chatting with models, organizing knowledge, and reusing prompts. It works with local models or cloud providers. The Msty family also lists Go, Nexus, and Stack, which is marked coming soon. It is aimed at professionals more than K-12, and it suits older students.

Benefits

For students

  • Older students can chat with a model and save useful prompts.
  • Students can ask questions about their own documents with Knowledge Stacks.
  • Students can compare answers from different models.

For teachers

  • Teachers can reuse prompts for lesson planning and drafting.
  • The interface is a plain desktop app with chat.
  • Teachers can pick a local model or connect a cloud provider key.

For schools

  • Studio has a free plan, and the paid Aurum plan costs $149 per user per year.
  • An Aurum Lifetime license costs $349 one time.
  • The policy says Msty has zero product telemetry, and IT approval is likely needed to install it.

Getting started checklist

Where is the AI in this product?

The AI is a language model that chats and finds answers in uploaded documents. It can run on the device with a local model or at a cloud provider that the user connects. Students and teachers use it to draft, ask questions about their own files, and refine their writing.

Privacy and safety

An account is optional, and paid plans use license keys. The free plan account rules are not stated. Msty says it collects no product analytics or telemetry from Studio, and its website uses analytics. Prompts sent to a cloud model go to that outside company. The research did not read the separate privacy policy for Msty Go. A teacher should check which model is selected and keep student work on local models.

How this can be used for English and Language Arts
  1. Ask a model for feedback on a short draft and decide which ideas to keep.
  2. Save a prompt for a thesis statement and reuse it on a new topic.
  3. Compare answers from two models to the same writing question.
  4. Rewrite a paragraph in a new style and explain the changes.
  5. Check an AI answer against a reliable source and note any errors.
How this can be used for Library and Media Literacy
  1. Add a few class documents to a Knowledge Stack and ask questions about them.
  2. Check each answer against the source document.
  3. Build a stack for a research topic and list the sources it holds.
  4. Write a short guide on how to ask clear questions of a document.
  5. Compare the answers from a local model with a cloud model on the same stack.
