Extension of Teachable Machine (GenAI project Finland)

An online machine learning demo listed by AI4K12 as an extension of Teachable Machine.

Overview

This is an online demo listed by AI4K12 in its Machine Learning area. It lives at tm.gen-ai.fi and its page title is GenAI Teachable Machine. The AI4K12 listing shows only a screenshot. The listing does not explain how the tool works, who built it, or what grades it targets.

Benefits

For students

  • Students can open the demo in a browser with no install.
  • Students can try a machine learning example linked to Teachable Machine.
  • The vendor does not say what students can train or test.

For teachers

  • Setup is one step. Teachers open the web address.
  • The listing places it in the AI4K12 Machine Learning area.
  • Teachers should test the tool before planning a lesson.

For schools

  • The cost is not stated on the pages that were checked.
  • The tool needs the internet at all times.
  • The vendor does not say which devices it needs.

Privacy and safety

The research found no privacy information for this tool. The AI4K12 footer privacy statement covers that site only. The materials do not state which tools or accounts students need. They also do not say where student data goes or where the AI runs. The tool page could not be read and the internet is always needed. A teacher should check whether the site asks for a camera, microphone, or sign in. A teacher should also find out who runs it and read any privacy page it has.
