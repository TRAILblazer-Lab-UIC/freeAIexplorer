Mokxi

A free browser simulator for breadboards, microcontroller boards, and firmware.

AIComputing

Overview

Mokxi is an electronics simulator that runs in a web browser. Students wire a breadboard, write firmware, and press Run. The site lists 45 boards, including Arduino, ESP32, Raspberry Pi Pico, and micro:bit V2, along with 525 parts. It suits middle and high school classes.

Benefits

For students

  • Students test circuits and code with nothing to install.
  • Students try many boards and parts without buying hardware.
  • Students can browse a gallery of public projects shared by other users.

For teachers

  • The editor opens in a browser tab and works without an account.
  • A classroom plan adds class tools for teachers.
  • Mokxi AI can answer student questions about circuits and code.

For schools

  • The free plan allows 10 private projects and 5 AI questions a day.
  • The classroom plan costs $9.99 per student per year, with a minimum.
  • No device needs special hardware. The site runs on Chromebooks, tablets, and phones.

Getting started checklist

Where is the AI in this product?

Mokxi AI is an optional question helper that answers questions about circuits and code. It runs in the vendor's cloud. Students can ask it why a circuit fails and then fix the wiring themselves. The simulator itself has no AI and runs in the browser.

Privacy and safety

Without an account, the simulation stays in the browser. Accounts store sign-in details, a profile, projects, learning progress, class records, and an activity log. Circuits leave the device when a user saves, shares, submits to a class, or asks Mokxi AI. Mokxi AI is run by Anthropic and receives project text and recent chat. Analytics and ad tags are on by default in the US unless a user opts out. Accounts for children under 13 need school or parent consent, and the policy says Mokxi AI is off for them and for class logins. A teacher should read the privacy policy at mokxi.com/privacy and check the analytics setting.

How this can be used for Engineering and Design
  1. Build a simple breadboard circuit with an LED and a resistor, then press Run to test it.
  2. Swap one part for another and describe how the circuit behaves differently.
  3. Wire a sensor to a microcontroller board and read its values in the simulator.
  4. Share a project link with a partner and ask them to find a wiring mistake.
  5. Browse the public gallery, pick one project, and explain how its circuit works.
How this can be used for Computer Science
  1. Write firmware that blinks an LED on an Arduino board and watch it run.
  2. Run the same program on two different boards and compare the results.
  3. Change a delay value in the code and predict what the LED will do.
  4. Add a button to a circuit and write code that reacts to each press.
  5. Ask Mokxi AI to explain a line of code, then rewrite that line in your own words.
