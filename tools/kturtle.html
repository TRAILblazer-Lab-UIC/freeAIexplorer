KTurtle

A free Logo style programming tool where students draw with a turtle.

FREEComputingStays on the device

Overview

KTurtle is an educational programming environment that uses TurtleScript, which is loosely based on Logo. It has syntax highlighting, simple error messages, a drawing canvas, and built in help. Slow motion and step execution let students watch code run. Commands and messages are translated into the user's language.

Benefits

For students

  • Students see a drawing appear from their code.
  • Students get simple error messages.
  • Students can slow the program down to see each step.

For teachers

  • The tool targets young students learning basic maths, geometry, and programming.
  • Help is built in.
  • No classroom write ups were found.

For schools

  • The software is free and the code is open.
  • The tool runs offline.
  • It installs from the Linux software center, Flathub, or Snap Store, and a Windows nightly build is listed.

Getting started checklist

Where is the AI in this product?

KTurtle has no AI. It follows each command exactly. Students build sequencing and logic skills as they plan the steps that draw a shape.

How this can be used for Computer Science
  1. Write commands that draw a square and watch them in slow motion.
  2. Use a repeat command to shorten the code.
  3. Write a procedure for a shape and use it twice.
  4. Read an error message and fix the code.
  5. Trade programs with a partner and predict the drawing.
How this can be used for Math
  1. Draw a triangle and find the turn angles.
  2. Draw a regular polygon and count the sides.
  3. Change the side length and describe the effect.
  4. Build a pattern of shapes with a repeat.
  5. Draw a shape that returns to the start and explain why.
