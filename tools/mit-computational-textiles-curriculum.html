MIT Computational Textiles Curriculum

A sequence of e-textile projects that teach computer science with LilyPad Arduino.

Computing

The privacy details for this item are unverified. Check which tools and accounts students will use before class.

Overview

This is a sequence of e-textile projects that teach introductory computer science to middle and high school students. Projects rise in difficulty. Each introduces a concept such as control flow, abstraction, networking, data processing, or algorithms. Examples include a game controller, a networked fabric piano, an activity monitor, and a gesture recognition glove.

Where is the AI in this product?

This curriculum has no AI. It builds skills in control flow, data processing, and algorithms. Students also practice reading sensor data from fabric.

How this can be used for Computer Science
  1. Sew a simple circuit and write code that blinks a light.
  2. Use a switch and an if statement style rule to change the light pattern.
  3. Build a fabric piano and map each key to a note.
  4. Read sensor data from an activity monitor and display it.
  5. Write the steps of an algorithm for a gesture glove.
How this can be used for Engineering and Design
  1. Design a wearable device and sketch where each part goes.
  2. Test a conductive thread connection and fix a weak joint.
  3. Build a game controller from fabric and LilyPad parts.
  4. Compare two designs and choose the more durable one.
  5. Present the finished device and explain the design choices.
