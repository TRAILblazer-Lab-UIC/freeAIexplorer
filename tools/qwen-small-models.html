Qwen small models

Small open language models from Alibaba that can run on a laptop.

FREEAIStays on the device

Overview

Qwen is a family of open-weight language models from Alibaba. The Qwen3 family has dense and mixture-of-experts models. The smaller sizes can run on a laptop through local tools such as Ollama, LM Studio, MLX-LM, and llama.cpp. It suits a teacher or a high school computing class.

Benefits

For students

  • Students chat with a model that runs on their own computer.
  • Students compare model sizes and see how size affects answers.
  • Students can read the model card to learn about sizes and licenses.

For teachers

  • The Qwen3-4B and Qwen3-1.7B cards list Apache 2.0.
  • Teachers can run a model in a class demo with no online service.
  • Several local tools can load the models.

For schools

  • The weights are free. Hardware cost depends on model size.
  • Chats stay on the device after setup.
  • IT will likely help. The licence of each size and each later model must be checked one by one.

Getting started checklist

Where is the AI in this product?

The AI is a language model that generates text and chats. It runs on the local computer through a tool such as Ollama. Students type prompts, read the replies, and use them to extend their own work.

Privacy and safety

No account is needed. The internet is used at setup to download the weights. Run locally in tools such as Ollama, chats stay on the device. The research did not review hosted Qwen chat or API services, which would differ. The vendor does not describe student data rules. A teacher should check the license of the chosen model and review prompts. Small models can be wrong.

How this can be used for Computer Science
  1. Read a model card and list the size and licence of the model.
  2. Run two sizes of Qwen on the same question and compare speed and answer quality.
  3. Test the model on a math problem and note where it fails.
  4. Change the system prompt and describe how the replies change.
  5. Explain why a small model can run on a laptop and a large one cannot.
