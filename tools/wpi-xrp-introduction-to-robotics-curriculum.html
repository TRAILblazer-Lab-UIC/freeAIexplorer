WPI XRP Introduction to Robotics curriculum

A free online robotics course for the XRP robot using Blockly and Python.

FREERoboticsUnverified

The privacy details for this item are unverified. Check which tools and accounts students will use before class.

Overview

This is a free online Introduction to Robotics course built for the XRP robot from WPI. It teaches robotics and programming in Blockly first and Python later. Modules cover an intro to the XRP, driving, the ultrasonic sensor, line following, the manipulator arm, and a final project. The course can run with one robot per student or small teams sharing.

Benefits

For students

  • Students start with Blockly and move on to Python.
  • Students program driving, sensing, and arm tasks.
  • Students finish with a final project.

For teachers

  • The course is free and online.
  • WPI also offers tutorials, lesson plans, in class projects, and a teacher forum.
  • The course works in a browser on Windows, Mac, or Chromebook.

For schools

  • The course is free. The SparkFun DIY kit is 99.95 USD, with the chassis sold separately at 34.95 USD.
  • The research notes say WPI describes the XRP as open source hardware, but this was not verified.
  • A teacher can install the tools, although IT may help.

Getting started checklist

Where is the AI in this product?

This course has no AI. Students write programs that tell the robot how to drive and sense. They build skills in sequencing, sensors, and logic.

Privacy and safety

The course site is public documentation that the research read without signing in. The research did not review the programming editor, any accounts, or any data collection. The materials do not state how much the internet is used. Programs run on the robot and in the browser. A teacher should check where the browser tools save student code.

How this can be used for Engineering and Design
  1. Assemble the XRP and test how it drives.
  2. Test the ultrasonic sensor at different distances.
  3. Build a course for the robot to follow using a line.
  4. Try the manipulator arm and note what it can lift.
  5. Plan a final project and present the design.
How this can be used for Computer Science
  1. Write a Blockly program that drives the XRP forward.
  2. Add a turn and a stop to the program.
  3. Use the ultrasonic sensor to stop before a wall.
  4. Write a short line following program.
  5. Convert one Blockly program into Python.
