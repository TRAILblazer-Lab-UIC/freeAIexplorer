I Love Algorithms card deck (Stanford d.school)

A printable card kit for prototyping machine learning ideas without screens.

FREEAIUnpluggedNo device neededGood for AI beginners

Overview

I Love Algorithms is a paper kit from the Stanford d.school. It has an Algorithms Card Deck, a Dataset Card Deck, and a Game Board. The algorithms deck covers six algorithm types, each shown as a cartoon with a description and sample questions. A K-12 version is offered for students and educators. The page estimates the activity at 45 to 60 minutes.

Benefits

For students

  • Students learn six kinds of machine learning algorithms through cartoons and questions.
  • Students prototype a machine learning idea with cards and a game board.
  • Students work in a design process that rewards trying ideas fast.

For teachers

  • The kit has a version made for K-12 use.
  • The cards explain each algorithm in simple words.
  • The activity fits into one class period.

For schools

  • The page states no price, and printing is the only expected cost.
  • The download is a Google Drive link.
  • The activity needs no devices for students.

Getting started checklist

Where is the AI in this product?

The kit has no running AI program. It teaches six types of machine learning algorithms, which are classification, clustering, reinforcement learning, dimensionality reduction, regression, and association. Students use the cards to sketch how a machine learning idea might work. They build skills in data and in matching a problem to a method.

Privacy and safety

The kit is a set of printed cards and a board with no software, and the materials describe no student data collection. The download link points to a Google Drive folder. The page does not say whether a sign in is needed to download. A teacher should download and print the kit ahead of class. The kit was first designed for design workshops. A teacher should also read the K-12 cards before class.

Ideas by subject

Select a subject to see five classroom ideas.

How this can be used for Computer Science
  1. Read one algorithm card and explain its cartoon to a partner.
  2. Match each dataset card to the algorithm that fits it best.
  3. Use the game board to plan a machine learning idea for a school problem.
  4. Sort the six algorithm types into groups and explain your groups.
  5. Present your prototype and answer the sample questions from the card.
How this can be used for Engineering and Design
  1. Prototype a machine learning helper for the school with the cards and board.
  2. Test your idea by walking a classmate through it step by step.
  3. Revise the prototype after the classmate asks questions.
  4. List what data your idea would need and where it might come from.
  5. Compare two prototypes and tell which one solves the problem better.
