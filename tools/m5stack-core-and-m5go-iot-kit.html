M5Stack Core and M5GO IoT Kit

An ESP32 controller kit with a screen, sensors, and block or text programming.

The privacy details for this item are unverified. Check which tools and accounts students will use before class.

Overview

The M5GO IoT Kit has SKU K006 and is built around the M5GO controller, an ESP32 dual core board with a 2 inch screen, speaker, microphone, 10 RGB LEDs, motion sensors and a battery. The kit adds six units, LEGO compatible bricks and connectors, Grove cables and a USB-C cable. It can be programmed in UiFlow blocks, Arduino IDE, ESP-IDF or PlatformIO. The docs describe it as STEM education for students of all ages.

Privacy and safety

The materials do not state which accounts students need or what data is collected. Programs run on the device, which has 2.4 GHz Wi-Fi. The docs describe a cloud based UIFlow WebIDE for pushing code over the network. The research read no privacy policy. The M5Stack privacy policy URL tried returned a 404. A teacher should check the UiFlow account terms and whether the school network allows the tools.
