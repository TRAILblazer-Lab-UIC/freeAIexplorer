Poppy Humanoid

An open-source 3D-printed humanoid robot for research and education.

Overview

Poppy Humanoid is an open-source 3D-printed humanoid robot that its repository describes as optimized for research and education. It uses 25 Robotis Dynamixel actuators and runs on a Raspberry Pi 3 or 4 with a provided system image. The project began in 2012 at Inria Bordeaux and is now hosted by the Poppy Station non-profit. Advanced high school students could build and program it in Python.

Benefits

For students

  • Students print and assemble a full humanoid robot.
  • Students program the robot with a Python library.
  • Students learn how actuators, a small computer, and code work together.

For teachers

  • The repository gives a system image and a Python library installable with pip.
  • The build suits a long-term advanced project.
  • The smaller Ergo Jr is the classroom variant, according to the research notes.

For schools

  • The repository estimates the build at 8000 to 9000 USD, with about 60 percent going to the actuators.
  • The design is open source for both code and hardware.
  • IT will likely need to help with the Raspberry Pi and software setup.

Getting started checklist

Where is the AI in this product?

This project has no AI. Students write Python to move the actuators. They build skills in sequencing and sensing as they plan each motion.

Privacy and safety

No account is needed, and no vendor cloud is documented. The robot runs on a local Raspberry Pi or a computer with a USB adapter. The internet is used at setup. The official project site did not resolve, and no privacy policy was reviewed. A teacher should check the robot's moving joints and keep fingers clear of the actuators.

How this can be used for Engineering and Design
  1. Study the 3D-printed body and list how the parts fit together.
  2. Print one limb and compare it with the CAD drawing.
  3. Assemble a joint and test how far it turns.
  4. Compare Poppy Humanoid with a human body and note the differences.
  5. Plan a budget for a class build using the repository's cost estimate.
How this can be used for Computer Science
  1. Run a short Python script that moves one actuator.
  2. Write a sequence that makes the robot wave.
  3. Change a number in the script and predict the new movement.
  4. Group several moves into a function and call it.
  5. Debug a script that makes the robot move the wrong way.
