Forgejo

A self-hosted Git forge that a school can run on its own server.

FREEComputingStays on a school server

Overview

Forgejo is a self-hosted, lightweight software forge for hosting Git repositories. It is developed under Codeberg e.V., a non-profit, and was forked from Gitea. Schools that run it host student repositories on their own server. It has no built-in classroom assignment system. A separate Forgejo Classroom project exists but its maturity and license were not confirmed.

Benefits

For students

  • Students push code to a school-hosted server.
  • Students use issues and pull requests.
  • Students learn how teams work with Git.

For teachers

  • Student accounts and repositories stay under school control.
  • Official binary and Docker installs are offered.
  • Teachers need an administrator for setup.

For schools

  • The software is free. Server hardware and admin time are the school's cost.
  • It uses few resources, and a Raspberry Pi is mentioned in a search snippet.
  • Backups, upgrades, and runner security fall on the host.

Getting started checklist

Where is the AI in this product?

Forgejo has no AI. It runs on a school server that the school controls. It builds version control and teamwork skills. Students commit code and track changes over time.

Privacy and safety

The server belongs to the school. Student accounts, repositories, and commits stay on the school server, and the school is responsible for backups and security. Accounts are required and the internet is used at setup. Telemetry is not mentioned on the pages read. A teacher should confirm who runs backups and who can see student repositories. A teacher should also ask the administrator to check for telemetry.
