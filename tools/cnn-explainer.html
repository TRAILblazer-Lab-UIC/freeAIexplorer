CNN Explainer

An interactive web page that shows how a convolutional neural network works.

FREEAIStays on the deviceGood for AI beginners

Overview

CNN Explainer is an interactive visualization that teaches non-experts how convolutional neural networks work. Learners step from a model overview to single layers and the math beneath them. It came from a 2020 paper by researchers at Georgia Tech and Oregon State. It runs in a browser with no install.

Benefits

For students

  • Students see each layer of an image classifier.
  • Students move between the big picture and the math.
  • Students can explore at their own pace.

For teachers

  • The page needs no setup beyond a browser.
  • Teachers can project it for a class talk.
  • It builds on neural network vocabulary students may already know.

For schools

  • The tool is free and the code is open.
  • It works on Chromebooks, Windows, Mac, and Linux.
  • No special hardware is needed.

Getting started checklist

Where is the AI in this product?

The AI is a convolutional neural network that classifies images. It runs in the browser on the local computer. Students watch an image pass through the layers and see how the network builds up its answer. The paper aims at college learners, but advanced high school students can follow it.

Privacy and safety

No account is needed. The page is static and hosted on GitHub Pages, and the internet is used to load it. The README and paper say nothing about analytics or data collection. None is documented. The research could not read the live page text and did not verify it directly. A teacher should test the page on school browsers. A teacher should also check that students know basic neural network words before they start.

How this can be used for Computer Science
  1. Follow one image through the layers and describe what each layer does.
  2. Find a convolution step and explain what a filter does.
  3. Compare the output for two different images.
  4. Explain the ReLU step in your own words.
  5. Draw the network from memory and label its parts.
