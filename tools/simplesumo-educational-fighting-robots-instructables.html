SimpleSumo Educational Fighting Robots (Instructables)

A 14 step Instructables guide to building an Arduino mini-sumo robot.

Overview

This Instructables guide walks through building an Arduino based mini-sumo robot in 14 steps. The robots follow official mini-sumo rules with a 500 gram limit and a 10 cm by 10 cm footprint. Example programs make the robot flee, follow lines, or find and push objects. It suits older students who can build and code.

Benefits

How this can be used for Engineering and Design
  1. Build the chassis from the 14 step guide and check its size and weight against the rules.
  2. Test the robot in a small ring and note where it fails.
  3. Redesign one part of the chassis to push better.
  4. Compare two builds in a class match and explain why one won.
  5. Write a short build log that records each step and any fix.
How this can be used for Computer Science
  1. Upload the example sketch that makes the robot flee and describe what it does.
  2. Change a number in the line-following sketch and observe the result.
  3. Read the sketch that finds and pushes objects and explain each part in plain words.
  4. Write a short plan for a new behavior before changing the code.
  5. Test and debug one change, and record what happened.
