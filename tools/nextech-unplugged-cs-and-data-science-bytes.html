Nextech unplugged CS and data science bytes

A K-12 set of no-computer data science activities with dice and cards.

Overview

This Nextech CS Byte gathers no-computer activities on data science for all grade levels. One activity is the Data Science Dice. Seven dice or numbered cards carry prompts that help students generate, use or evaluate data. The byte also lists an ELA lesson built on children's books and a sorting algorithms card deck.

Benefits

For students

  • Students practice asking questions about data without using a device.
  • Students connect stories and children's books to data ideas.
  • Students try sorting steps with cards and see how an algorithm works.

For teachers

  • The activities span kindergarten through grade 12. One source serves many classes.
  • Dice prompts give quick starters for discussion.
  • Setup takes only a few minutes. The vendor page did not load during research. A teacher should read it before planning.

Getting started checklist

Where is the AI in this product?

This byte has no AI. It builds an AI-related skill, which is working with data. Students generate, use and evaluate data, and these are the first steps in how AI systems learn.

Privacy and safety

Ideas by subject

Select a subject to see five classroom ideas.

How this can be used for Computer Science
  1. Sort a shuffled card deck by hand and write down the steps that worked.
  2. Compare two sorting methods and decide which took fewer moves.
  3. Roll the Data Science Dice and write a rule for the data it describes.
  4. Teach a partner a sorting algorithm using only spoken steps.
  5. Find a mistake in a classmate's sorting steps and fix it.
How this can be used for Math
  1. Roll the dice and collect the results in a tally chart.
  2. Use the dice prompts to decide what to count and how to count it.
  3. Make a bar graph of the class dice results.
  4. Compare two groups of numbers and say which looks larger.
  5. Evaluate whether a small sample can tell the whole class story.
How this can be used for English and Language Arts
  1. Read a children's book and list the facts that could become data.
  2. Write a question about a story that a survey could answer.
  3. Sort story characters by one trait and explain the choice.
  4. Retell a story using a simple chart of events.
  5. Write a short paragraph that uses data to support an opinion about a book.
