Overview

Codemao Kitten is a block-based programming editor from the Chinese company Codemao. The official page that could be read shows only a Chinese title. English documentation for the editor exists. A third-party listing says the platform has school management and curriculum features.

Benefits

For students

  • Students build programs by joining blocks.
  • Students may find English documentation for the editor blocks.
  • The block approach suits learners new to coding.

For teachers

  • A block editor lowers the barrier to a first coding lesson.
  • A third-party listing mentions school management features.
  • The vendor does not say which classroom tools are included.

For schools

  • Cost was not confirmed.
  • The notes list the platform as browser based.
  • Little else could be verified. IT should ask the vendor for details.

Privacy and safety

The materials do not state which tools or accounts students need, whether the internet is required, or where student work goes. The research found and read no privacy policy. Codemao is a Chinese company, and the research did not confirm where student data is stored. The fetched page had almost no content. A teacher should ask the vendor whether students need accounts, whether the internet is required, and what the privacy policy says about children.

How this can be used for Computer Science
  1. Join blocks to make a character move across the screen.
  2. Predict what a short block program will do and then run it.
  3. Fix a block program that has two blocks in the wrong order.
  4. Add a repeat block to shorten a long program.
  5. Explain a finished program to a partner step by step.
