jamovi

A free spreadsheet style statistics program built on R that runs offline or in a browser.

Computing

Overview

jamovi is a free and open statistical spreadsheet built on R. It comes as an offline desktop app and as a Cloud version that runs in any browser, including on Chromebooks. The site reports use at more than 300 universities. Students load data into a spreadsheet and run analyses from menus.

Benefits

For students

  • Students run statistics with menus and no code.
  • Students see results update next to their data.
  • Students can use a free open textbook, Learning Statistics with jamovi.

For teachers

  • The spreadsheet layout feels familiar.
  • The tool grows with students and is built on R.
  • The open textbook gives teachers a ready reference.

For schools

  • The desktop app is free and the Cloud Guest plan is free.
  • Paid Cloud plans were not seen.
  • The desktop app works offline, and Cloud runs on Chromebooks.

Getting started checklist

Where is the AI in this product?

jamovi has no AI. It performs the statistics that students choose from menus. Students build data skills by picking a method, running it, and reading the result.

Privacy and safety

No account is needed. The desktop app keeps data on the computer and works offline. The Cloud version processes data on jamovi servers and needs the internet. The research did not read the privacy policy because its address returned a 404, and Cloud account and retention details are not confirmed. A teacher should use the desktop app or sample data for student work.

How this can be used for Math
  1. Load class survey data and find the mean, median, and spread of one variable.
  2. Make a histogram and describe its shape.
  3. Compare two groups with a box plot and write one sentence about the difference.
  4. Run a simple test and explain the result in plain words.
  5. Read a chapter of Learning Statistics with jamovi and repeat one example.
How this can be used for Science
  1. Load data from a lab and make a graph of the main result.
  2. Compare a control group and a test group with a summary table.
  3. Check if two measurements move together with a scatter plot.
  4. Record the steps of an analysis so another student can repeat them.
  5. Write a short conclusion that cites the numbers from jamovi.
