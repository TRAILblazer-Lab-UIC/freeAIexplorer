TIC-80

A free tiny game console for making, playing, and sharing small retro games.

Computing

The privacy details for this item are unverified. Check which tools and accounts students will use before class.

Overview

TIC-80 is a free and open source fantasy computer for making, playing, and sharing small games. It includes a code editor, sprite and map editors, a sound editor, and a command line. It uses retro limits such as a 240 by 136 display and a 16 color palette. Games can be written in Lua, JavaScript, Python, and several other languages.

Benefits

For students

  • Students make a whole game in one small program.
  • Students draw sprites and maps and write sound in the same tool.
  • Students can share games as cartridge files.

For teachers

  • Everything students need is built in.
  • Nine scripting languages are supported.
  • Tight limits keep projects small.

For schools

  • The software is free. The Pro version is sold on itch.io and the price was not verified.
  • It runs on Windows, Mac, Linux, Android, and in the browser.
  • The editor works offline once installed.

Getting started checklist

Where is the AI in this product?

TIC-80 has no AI. Students write code that tells the game what to do on each frame. They practice logic, loops, and debugging.

Privacy and safety

No account is needed and the internet is used at setup. The README and site do not describe telemetry or data collection, and the research found no privacy policy. The build uses libcurl and the research did not explain its network use. The research did not check whether the browser editor stores carts on the server. Cartridges on the community site are user generated. Ask IT about network use and decide whether students may share cartridges on the website.

How this can be used for Computer Science
  1. Write a program in Lua, JavaScript, or Python that moves a sprite.
  2. Add a score to a game and show it on screen.
  3. Use a loop to draw a pattern of squares.
  4. Fix a game bug by reading the code.
  5. Share a cartridge and explain how it works.
How this can be used for Visual Arts
  1. Draw a character with the sprite editor in a 16 color palette.
  2. Build a map from tiles for a game level.
  3. Compose a short sound in the sound editor.
  4. Compare how limited colors change the look of a game.
  5. Present your game art to the class.
