TensorFlow Playground

A browser tool that shows a small neural network learning in real time.

FREEAIUnverifiedGood for AI beginners

The privacy details for this item are unverified. Check which tools and accounts students will use before class.

Overview

TensorFlow Playground is a browser based picture of a small neural network. Students pick a dataset, choose input features, and add hidden layers and neurons. They set the learning rate, activation function, and regularization. They then watch the network train. The AI4K12 listing gives grades 11 to 12.

Benefits

For students

  • Students see a neural network learn step by step.
  • Students change one setting at a time and see the effect.
  • Students work with both classification and regression problems.

For teachers

  • No install or account is needed.
  • A setup can be shared by copying the page link.
  • Google's Machine Learning Crash Course uses it for exercises.

For schools

  • The tool is free and open source.
  • It runs in a modern browser, including on Chromebooks.
  • IT involvement is none.

Getting started checklist

Where is the AI in this product?

The AI is a small neural network that trains in the browser. Colors show predictions and line thickness shows connection weights. Students adjust features and layers, then watch the loss fall. The network runs on the local device.

Privacy and safety

No account is needed. Students choose built in datasets and settings and enter no content of their own. The page does not mention privacy or data collection. The research did not check whether the hosted page loads analytics. The tool is open source and a school could self-host it. Google says it is not an official Google product. Ask IT to review the hosted page or host it.

How this can be used for Computer Science
  1. Train the network on the circle dataset and note how many neurons it needs.
  2. Add noise to a dataset and describe what happens to the loss.
  3. Remove a hidden layer and compare the result.
  4. Switch the activation function and explain the change.
  5. Share your setup link with a partner and ask them to improve it.
How this can be used for Math
  1. Pick two input features and explain how each one shapes the boundary.
  2. Change the learning rate and graph how fast the loss falls.
  3. Compare a linear model with one that has hidden layers.
  4. Explain how the train and test split links to data sampling.
  5. Predict the result of a setting change before pressing play.
