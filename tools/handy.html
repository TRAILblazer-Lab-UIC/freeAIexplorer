Handy

A free desktop app that turns your voice into text in any program.

AI

Overview

Handy is a free, open source speech-to-text app for desktop computers. The user presses a shortcut, speaks, and the text is pasted into whatever app is in focus. The transcription uses local Whisper and Parakeet models. The README says audio does not go to the cloud.

Benefits

For students

  • Students can speak their ideas and see them as text.
  • Students who find typing hard can write by voice.
  • Students can practice speaking and read the transcript.

For teachers

  • The shortcut works in any app, including a word processor.
  • Teachers can pick a smaller model for older computers.
  • Teachers can use it to dictate their own notes.

For schools

  • The app is free and has no paid tier.
  • The process runs on the device and does not need an account.
  • IT will likely need to approve the install. The app is not for Chromebooks.

Getting started checklist

Where is the AI in this product?

The AI is speech recognition that uses local Whisper and Parakeet models and Silero voice activity detection. It runs on the computer, and a GPU helps with larger models. Students speak, read the text, and edit it into their own work. Reviews note that auto-paste may land in the wrong window.

Privacy and safety

No account is needed and the internet is used for setup and model downloads. The README says the process is entirely local and no audio goes to the cloud. An experimental post processing feature can use local or external AI providers, according to a review. Teachers should keep that feature off. The research found no separate privacy policy. A teacher should check the active window before students dictate. A teacher should also remind students to avoid speaking private details.

How this can be used for Special Education and Accessibility
  1. Dictate a short paragraph about a favorite hobby and edit the text.
  2. Use voice to write a list for a class project.
  3. Compare typing speed with dictation speed on the same sentence.
  4. Practice speaking clearly and fix any words the app misheard.
  5. Dictate answers to a reading question and check spelling.
How this can be used for World Languages
  1. Speak a sentence in the target language and read the transcript.
  2. Compare the transcript with the written sentence and mark the errors.
  3. Try a slower pace and watch how the accuracy changes.
  4. Record the same sentence twice and compare the results.
  5. Keep a list of words that the app often mishears.
