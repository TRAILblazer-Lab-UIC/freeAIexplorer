Overview

This is a collection of lessons created by school library media specialists across Maryland. The lessons weave computational thinking, computer science and robotics into classroom curricula. A search result says they can be searched by grade level, computer science standard or curricular connection. The page is titled Integrating School Library Media and Computer Science.

How this can be used for Library and Media Literacy
  1. Use a lesson from the collection to link a library book to a coding task.
  2. Plan a short coding activity that fits a library visit.
  3. Search the collection for lessons by curricular connection.
  4. Create a reading list that supports a computer science unit.
  5. Present a finished lesson to colleagues and share what worked.
How this can be used for Computer Science
  1. Try a computational thinking lesson and explain each step.
  2. Break a task into small parts and write them in order.
  3. Spot a pattern in a problem and describe it.
  4. Test a simple program and fix one mistake.
  5. Compare two solutions to the same problem.
