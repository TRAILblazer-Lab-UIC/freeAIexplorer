Cherry Studio

An open source desktop AI client for cloud and local language models.

AI

Overview

Cherry Studio is an open source desktop AI client for Windows, macOS, and Linux. It connects to cloud providers such as OpenAI, Anthropic, and Gemini. It also connects to local models served through Ollama and LM Studio. Users can compare answers from several models and build knowledge bases from files and web pages. It is a general tool and was not made for schools.

Benefits

For students

  • Older students can compare several models in one conversation.
  • Students can ask questions about their own documents.
  • Students can try image generation, translation, and speech.

For teachers

  • One app works with many providers.
  • Knowledge bases let teachers build a custom helper from class files.
  • Teachers can try agents with tools.

For schools

  • The Community Edition is free.
  • A commercial license and an Enterprise Edition exist.
  • Cloud providers charge their own fees.

Getting started checklist

Where is the AI in this product?

The AI is the model that you connect. It may run at a cloud provider or on the local computer through Ollama or LM Studio. Cherry Studio is the app around it. Students write prompts, read answers, and compare models to extend their own research.

Privacy and safety

Chat history, API keys, and preferences stay on the device. The software version, aggregated feature use, and anonymous crash logs are collected by default. Usage and crash reports can be turned off in the privacy settings. Prompts sent to a cloud provider go from the device to that provider under its own policy. Prompts sent through the built in model service pass through a Cherry Studio relay that the policy says does not log content. The internet is needed whenever a cloud provider is used. The research found no COPPA, FERPA, or student privacy pledge. A teacher should check the provider terms and the default sharing settings. Chromebooks are not listed as supported.

How this can be used for Computer Science
  1. Ask two models the same question and compare the answers.
  2. Build a small knowledge base from class notes and ask it a question.
  3. Compare the speed of a local model with a cloud model.
  4. Test how a system prompt changes the answer.
  5. Write a short guide on how to connect a model to the app.
