Callysto

Free Jupyter notebooks that teach data literacy and coding across school subjects.

FREEAIComputingSends student data to a company

Overview

Callysto is a free Canadian program for grades 5 to 12. It teaches data literacy, coding, and computational thinking through Jupyter notebooks. Notebooks link to curriculum subjects including math, science, social studies, and languages. Each module has a teacher lesson plan, a teacher notebook, and a student notebook.

Benefits

For students

  • Students work with real data in subjects they already study.
  • Students learn Python and data skills inside a notebook.
  • Students see charts of their own results.

For teachers

  • Each module has a lesson plan and both teacher and student notebooks.
  • A free teacher starter kit and online courses are available.
  • Teachers can join a free training workshop.

For schools

  • Callysto is free.
  • Hosted notebooks run in a browser on any device, including a Chromebook.
  • Setup takes minutes and needs no IT install.

Getting started checklist

Where is the AI in this product?

Callysto has no AI tools of its own. Students build data skills such as analysis and visualization. These skills help students understand the data that AI systems learn from. The notebooks run on a hosted JupyterHub in the cloud at Cybera.

Privacy and safety

The hosted notebooks run in the cloud, and a search result says Cybera hosts them. The internet is needed at all times for the hosted version. Notebooks can also be run locally from GitHub. The materials do not say whether student accounts are needed or what data is kept. The site links a Privacy Notice as an external Google Doc, which the research did not read. A teacher should read that notice with the school. A teacher should also tell students not to type personal details into notebooks.

Ideas by subject

Select a subject to see five classroom ideas.

How this can be used for Math
  1. Open a math notebook and graph a data set, then describe the pattern.
  2. Change a number in the notebook and predict how the chart will change.
  3. Calculate the mean and median of a class survey and compare them.
  4. Make a chart of a real data set and write one question about it.
  5. Explain what one line of Python does in a math notebook.
How this can be used for Science
  1. Analyze a weather data set and graph the changes over time.
  2. Compare two data sets from a science notebook and explain the difference.
  3. Change a variable in a notebook and note the result.
  4. Draw a conclusion from a chart and name one limit of the data.
  5. Write a short lab report that uses a chart from a notebook.
How this can be used for Social Studies
  1. Analyze climate data and government spending, as Grade 6 students have done.
  2. Compare population data for two regions and describe what you see.
  3. Make a chart that shows a historical trend.
  4. Write a short claim and support it with a chart.
  5. Discuss which data a community would need to decide a local question.
How this can be used for English and Language Arts
  1. Count word use in a text with a language notebook and chart the results.
  2. Compare two short texts by their most common words.
  3. Write a short claim about an author's style and support it with a count.
  4. Test how a change in the text changes the results.
  5. Present a chart of word data to the class.
How this can be used for Computer Science
  1. Run a notebook cell by cell and say what each cell does.
  2. Change a line of Python and describe the new output.
  3. Add a new chart to a notebook and label it clearly.
  4. Find and fix an error in a notebook cell.
  5. Write a short notebook that loads data and makes a chart.
