AI for Oceans

A Code.org Hour of Code activity where students train a model to spot fish.

AIGood for AI beginners

Overview

AI for Oceans is a 2019 Hour of Code activity from Code.org. Students train a classifier by labeling images as fish or not fish. They then train it on a word of their choice, such as angry or fun. Short videos explain machine learning and how bias in a training set changes results.

Benefits

For students

  • Students see a model improve as they add labeled examples.
  • Students learn how a biased training set leads to biased results.
  • Students can earn a printable completion certificate.

For teachers

  • The activity takes minutes to set up and runs in a browser.
  • A lesson plan and videos support a warm-up and a class talk on bias.
  • The lesson page lists grade bands 3-5, 6-8, and 9-12.

For schools

  • The activity is free.
  • No IT install is needed, and it runs on a desktop or laptop.
  • The activity comes in several languages, including Spanish, French, and Arabic.

Getting started checklist

Where is the AI in this product?

The AI is an image classifier that students train. The materials do not say whether it runs in the browser or on the vendor's cloud. Students label examples, watch the model learn, and then test how well it does on new images. The activity builds the skill of training and checking a model.

Privacy and safety

Students can sign in, and an account is optional. The activity is online and always needs the internet. The lesson page links to the Code.org Privacy Policy, Cookie Notice, and Terms of Service. The research did not read the policy. The materials do not state what student data goes to the vendor. A teacher should read the Code.org privacy terms before students sign in. The word step lets students pick words. A teacher should set clear rules for choices.

Ideas by subject

Select a subject to see five classroom ideas.

How this can be used for Computer Science
  1. Watch the warm-up video and discuss how a computer can learn from examples.
  2. Label images as fish or not fish and watch the model improve.
  3. Train the model on a subjective word such as angry or fun and compare class results.
  4. Find a case in which the training set was biased and describe how it changed the results.
  5. Write a short list of rules for building a fair training set.
How this can be used for Science
  1. Sort ocean animals by features and compare the sorting rules with the model's rules.
  2. Discuss how scientists could use image classifiers to study sea life.
  3. Try the optional Zooniverse animal project and record what the class sees.
  4. Describe a trait that makes a fish a fish and test whether the model learns it.
  5. Write a question about ocean life that a trained model could help answer.
