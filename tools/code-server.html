code-server

Software that runs VS Code on a school server so students code in a browser.

Computing

Overview

code-server runs VS Code on a remote machine and lets users work in it through a browser. A school can host it on its own Linux server. Students code from Chromebooks or any browser without installing anything. It is MIT licensed.

Benefits

For students

  • Students use a professional code editor in a browser.
  • Students can work from a Chromebook or any browser.
  • Students keep the same setup on every device.

For teachers

  • Teachers set up one editor for the whole class.
  • Students need no local installs.
  • Teachers can give students the URL to start.

For schools

  • The software is free. Hosting costs and IT time apply.
  • The README lists Linux, WebSockets, about 1 GB RAM, and 2 vCPUs.
  • It runs on the school server, and files stay there.

Getting started checklist

Where is the AI in this product?

This tool has no AI. It is a code editor in a browser. Students build skills in sequencing and logic as they write and run code.

Privacy and safety

Files stay on the server the school runs, and accounts are optional. The research did not confirm telemetry or authentication defaults, and the README does not describe them. Extensions installed from marketplaces may contact outside services. The internet is not needed only when students are on the same network as the server. A teacher should ask IT to confirm the authentication, the telemetry setting, and the HTTPS setup.

How this can be used for Computer Science
  1. Open the browser editor and write a first program in a language the class uses.
  2. Create a project folder and organize several files.
  3. Use the built-in terminal to run a program.
  4. Install an editor extension that the teacher approves and describe what it does.
  5. Debug a program with the editor's error messages.
