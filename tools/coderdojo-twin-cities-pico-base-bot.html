CoderDojo Twin Cities Pico base bot

A low-cost Raspberry Pi Pico robot with MicroPython lessons from CoderDojo Twin Cities.

ComputingRobotics

Overview

The Pico base bot is a two-wheel-drive robot built on a Raspberry Pi Pico and programmed in MicroPython. Parts are a 2WD chassis, a Pico, an L293 motor driver, a VL53L0X distance sensor and a 6 V battery pack. The target cost is under 25 USD. Students in grades 5 through 12 build it and program collision avoidance.

Benefits

For students

  • Students build a working robot from basic parts.
  • Students write MicroPython that drives and turns the robot.
  • Students build a collision-avoidance program and try four extension challenges.

For teachers

  • Lessons test the sensor, test the motors and build up to avoidance.
  • CoderDojo Twin Cities uses the robot as a base for about a dozen other club robots.
  • Content is shared under Creative Commons Attribution NonCommercial ShareAlike.

For schools

  • The lessons are free and the parts target under 25 USD per robot.
  • No account is needed.
  • The internet is needed only at setup.

Getting started checklist

Where is the AI in this product?

The Pico base bot has no AI. The robot runs the MicroPython code that students write and load. Students build skills in sensors, logic and sequencing.

Privacy and safety

No account is needed, and the research found no student data collection. The robot runs on a microcontroller with no cloud service. The lesson site is a static GitHub Pages site, and the internet is needed only to reach it and to set up. A teacher should check the battery voltage. The page says a voltage below about 5 V makes the sensor unreliable.

How this can be used for Engineering and Design
  1. Assemble the chassis, Pico and motor driver and test that the wheels turn.
  2. Wire the distance sensor and check its readings.
  3. Compare driving with fresh and weak batteries and record the sensor changes.
  4. Pick one extension challenge and build the change.
  5. Present the robot and explain each part.
How this can be used for Computer Science
  1. Run the I2C test and describe what the readings mean.
  2. Write functions that drive forward and turn.
  3. Build a collision-avoidance program that turns near a wall.
  4. Change the distance limit and observe the change.
  5. Debug a program that never stops and explain the fix.
