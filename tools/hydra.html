Hydra

Browser tools for live coding visuals, inspired by analog video synthesizers.

Computing

The privacy details for this item are unverified. Check which tools and accounts students will use before class.

Overview

Hydra is a set of browser based tools for live coding networked visuals. It is inspired by analog modular video synthesizers. Users write JavaScript to route video sources and outputs in real time. The maintainer calls it experimental and in development. It suits high school students in art and coding.

Benefits

For students

  • Students make moving visuals by typing short lines of code.
  • Students see changes the moment they run a line.
  • Students can use a webcam or screen as input.

For teachers

  • It runs in a browser at hydra.ojack.xyz.
  • Workshop slides by Zach Krall are available.
  • It is common in art and live coding communities.

For schools

  • The tool is free and open source.
  • It needs only Chrome or Chromium with WebGL.
  • IT can run it locally with Node.js and Yarn if needed.

Getting started checklist

Where is the AI in this product?

Hydra has no AI. It builds coding and visual design skills. Students write JavaScript that shapes color, motion, and layers. The code runs in the browser on the device.

Privacy and safety

The internet is needed at all times, and the research did not confirm whether the hosted editor needs an account. No privacy policy was found. Rendering runs in the browser. Optional WebRTC stream sharing uses a hosted signalling server, and a keyboard shortcut can share to Twitter if available. Screenshots save as local files, and camera input is optional. A teacher should turn off camera use unless the class needs it.

How this can be used for Visual Arts
  1. Make a moving color pattern with an oscillator.
  2. Layer two patterns and blend them.
  3. Change one number in a line and describe how the image changed.
  4. Save a screenshot of a favorite frame.
  5. Create a visual for a short piece of music.
How this can be used for Theater and Media Arts
  1. Build a live backdrop for a class performance.
  2. Feed a screen capture into the visual and distort it.
  3. Use a webcam, with permission, to create a live effect.
  4. Plan a short visual show with three scenes.
  5. Perform a live code set for the class.
How this can be used for Computer Science
  1. Write a JavaScript line that draws a shape.
  2. Chain several functions to build a visual.
  3. Use a variable to change speed.
  4. Find an error in a line and fix it.
  5. Explain how the code connects sources to outputs.
