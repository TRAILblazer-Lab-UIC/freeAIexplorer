RoboScape Online (NetsBlox)

A free browser robot simulation where novices program virtual robots with blocks.

FREEComputingRoboticsUnverified

The privacy details for this item are unverified. Check which tools and accounts students will use before class.

Overview

RoboScape Online is a free, open-source, browser-based robotics simulation built on NetsBlox. Novice students program simulated robots with blocks. A Spring 2022 high school classroom study is reported in Frontiers in Computer Science. It was designed as a simpler alternative to tools like Gazebo.

Benefits

For students

  • Students program virtual robots with blocks.
  • Students need no robot hardware.
  • Students work in a browser.

For teachers

  • A high school classroom study backs its use.
  • The tool opens in minutes.
  • The code is open source.

For schools

  • The Frontiers paper describes it as free.
  • No device install is needed.
  • It needs the internet at all times.

Getting started checklist

Where is the AI in this product?

The tool has no AI. It builds skills in block coding, sequencing and logic. Students watch a simulated robot respond to their code.

Privacy and safety

The tool runs in the browser and uses a cloud service. Accounts are optional. The materials do not state what student data is collected or where it goes. A teacher should check the NetsBlox privacy terms before students save work or create accounts.

How this can be used for Computer Science
  1. Follow the high school study and run a first block program.
  2. Drag blocks to drive a virtual robot forward and turn.
  3. Use a loop to repeat a move.
  4. Add a sensor condition to avoid a wall.
  5. Compare two programs for the same task.
How this can be used for Engineering and Design
  1. Test a robot task in the simulation and record the result.
  2. Change one setting and describe the effect.
  3. Plan a route through an obstacle course.
  4. Compare the simulation with what a real robot might do.
  5. Write a short test report.
