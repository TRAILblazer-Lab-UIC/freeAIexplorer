Unplugged lesson ideas for learning how a network works without computers.

Overview

How this can be used for Computer Science
  1. Act out sending a message through a network with classmates as devices.
  2. Write an algorithm for passing a message from one student to another.
  3. Find what happens when one student in the chain is missing.
  4. Name the parts of the network and what each does.
  5. Compare the classroom network with a real school network.
