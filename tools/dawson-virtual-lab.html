Dawson Virtual Lab

A browser site for learning Arduino code with a simulated robot lab.

FREEComputingRoboticsUnverified

The privacy details for this item are unverified. Check which tools and accounts students will use before class.

Overview

Dawson Virtual Lab is a browser-based site for learning Arduino programming and engineering robotics. It simulates hardware so students can write code and test it in a virtual robot environment. The site lists an Arduino introduction, a robot lab and a DC motor robot lesson. It suits upper high school students.

Benefits

For students

  • Students write Arduino code and test it with no hardware.
  • Students use a 2D robot simulation.
  • Students can try the code on real Arduino hardware afterward.

For teachers

  • The site has homework, hackathon and workshop pages.
  • Nothing needs to be installed and no prerequisites are required.
  • Dawson College is in Quebec. The content may suit grades 11 and 12 more than lower grades.

For schools

  • The site appears free to use.
  • It needs only a web browser and an internet connection.
  • No IT install is needed.

How this can be used for Computer Science
  1. Work through the Arduino Intro and write a program that blinks an LED.
  2. Change the timing in a program and predict the result.
  3. Write code that reads a virtual sensor.
  4. Use a loop to repeat an action in the simulator.
  5. Debug a program that a partner wrote and explain the fix.
How this can be used for Engineering and Design
  1. Build a robot in the Robot Lab and test its movement.
  2. Complete the DC Motor Robot lesson and describe how the motor works.
  3. Tune a motor speed and record the effect on the path.
  4. Plan a robot task on paper before coding it.
  5. Test the code on a real Arduino board and compare the results.
