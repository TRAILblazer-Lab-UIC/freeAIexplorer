Photon Robot EDU (Eduscape)

A programmable classroom robot with ten sensors and a free Bluetooth app.

$$$AIComputingRoboticsUnverified

The privacy details for this item are unverified. Check which tools and accounts students will use before class.

Overview

Photon Robot EDU is a programmable classroom robot sold by Midwich US under SKU PH_02. It carries ten built-in sensors for light, touch, sound, obstacles, rotation, and surface contrast. Students program it through the free Photon EDU app over Bluetooth. The app offers tiers from graphical blocks up to Python and JavaScript. The vendor describes uses from early childhood through secondary school.

Benefits

For students

  • Students start with graphical blocks and later use Python.
  • Students use ten sensors to make the robot react.
  • Add-on kits cover special education, early education, ecology, and physics.

For teachers

  • The app has tiers that fit different grade levels.
  • An AI Discovery edition kit is listed.
  • Mats, flashcards, and workbooks are sold separately.

For schools

  • The robot lists at 275 USD. Teaching kits list at 495 to 660 USD.
  • The Midwich US page gives no data practices.
  • No independent hands-on classroom review was found.

Getting started checklist

Where is the AI in this product?

The vendor does not describe any AI in the robot. An AI Discovery edition kit is listed, but the materials give no detail. Without AI, students still build sensor and logic skills. They program the robot to react to light, sound, and touch.

The materials do not state which accounts students need or what data the app collects. The research did not review the Photon EDU app's privacy practices, and no privacy policy was found. The materials do not say whether the robot works offline once the app is installed. A teacher should read the app privacy policy and test Bluetooth on school devices.

Ideas by subject

Select a subject to see five classroom ideas.

How this can be used for Computer Science
  1. Use graphical blocks to make the robot follow a line.
  2. Use the sound sensor to start a program with a clap.
  3. Add a decision based on the obstacle sensor.
  4. Move one program from blocks to Python.
  5. Compare which sensors react best to a task.
How this can be used for Science
  1. Use the light sensor to measure how bright a window is.
  2. Test how surface color changes the contrast sensor reading.
  3. Roll the robot down a ramp and time it.
  4. Record sensor data from a sunny and a shaded spot.
  5. Use the ecology or physics kit to plan a simple experiment.
How this can be used for Special Education and Accessibility
  1. Use touch and sound to give students a simple way to start the robot.
  2. Use a flashcard to link a picture to a robot action.
  3. Practice turn taking by passing the robot between students.
  4. Use the special education kit activities with a small group.
  5. Celebrate each step with a light or sound from the robot.
