ROSMO

An open-source micro-robot for ROS 2 and MicroBlocks that needs no soldering.

$$RoboticsUnverified

The privacy details for this item are unverified. Check which tools and accounts students will use before class.

Overview

Rosmo is an open-source micro-robot for ROS 2 and MicroBlocks. It is built around an ESP32-S3 board on a custom PCB chassis with two or four motors. The project says it can be assembled without soldering or a 3D printer. Older students and advanced middle schoolers could program it in MicroBlocks.

Benefits

For students

  • Students assemble a working robot with no soldering.
  • Students program it with MicroBlocks.
  • Students can explore ROS 2 as a next step.

For teachers

  • The project site is rosmo-robot.github.io.
  • The page lists the MicroBlocks side as working and MicroPython as limited.
  • The ROS 2 side uses Linorobot, and its status is mixed.

For schools

  • The project page estimates about 50 USD for 2WD and about 80 USD for 4WD in parts.
  • A 4WD kit is listed on Elecrow and a Tindie kit is listed too.
  • The code and hardware are open source, and IT may need to help with flashing.

Getting started checklist

Where is the AI in this product?

This kit has no AI. Students program motor movements with blocks. They build skills in sequencing and sensing as they plan how the robot moves.

Privacy and safety

The project describes no accounts and no data collection. The research did not find a privacy policy. Setup involves flashing firmware and loading a file in the MicroBlocks app. The page does not state the internet needs, and the research did not review the app's data handling. Programs run on the robot and the computer. A teacher should check the firmware source and keep the USB power bank charged and stored safely.

How this can be used for Engineering and Design
  1. Assemble the chassis and count the motors and encoders.
  2. Compare 2WD and 4WD builds on a small track.
  3. Measure how far the robot travels in five seconds.
  4. Suggest a part to add and sketch where it would go.
  5. Write an assembly guide for another team.
How this can be used for Computer Science
  1. Load the Rosmo library and run a drive block.
  2. Program the robot to drive in a square.
  3. Use a loop to repeat a movement.
  4. Debug a program that turns too far.
  5. Compare MicroBlocks with a short MicroPython example.
