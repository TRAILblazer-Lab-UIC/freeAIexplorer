Calypso for Cozmo and Calypso curriculum

A rule-based language and curriculum for programming Cozmo robots.

AIComputingRoboticsGood for AI beginners

The privacy details for this item are unverified. Check which tools and accounts students will use before class.

Overview

Calypso is a rule-based language for programming intelligent robots such as Cozmo. David Touretzky of Carnegie Mellon and Visionary Machines LLC created it. Commands refer to objects the robot sees, such as a blue cube. The curriculum says it is accessible to children as young as eight.

Benefits

For students

  • Students program a robot that sees objects.
  • Students learn how rules and state machines drive behavior.
  • Students practice careful reasoning about programs.

For teachers

  • The curriculum teaches computational thinking.
  • A search result says it has beginner, intermediate, and advanced parts.
  • AI4K12 lists it for all ages.

For schools

  • The pages read state no cost.
  • A Cozmo robot is needed, and Anki closed in 2019.
  • Hardware availability should be confirmed first.

Getting started checklist

Where is the AI in this product?

The AI is object recognition with the robot camera. The vendor does not say where the AI runs. Students write rules that use what the robot sees. They then test how well the robot follows those rules.

How this can be used for Computer Science
  1. Write a rule that makes the robot react to a blue cube.
  2. Predict what a set of rules will do and then test it.
  3. Draw a state machine for a simple robot task.
  4. Debug a rule that makes the robot loop forever.
  5. Explain to a partner how the robot knows what it sees.
