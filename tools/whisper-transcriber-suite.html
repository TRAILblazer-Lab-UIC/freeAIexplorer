Whisper Transcriber Suite

A free desktop app that makes transcripts and subtitles from audio and video.

AI

Overview

Whisper Transcriber Suite is a free, open source desktop app for Windows, macOS, and Linux. It runs speech recognition engines such as faster-whisper and whisper.cpp on the user's computer. It makes transcripts and subtitles from audio, video, or video links. It adds speaker labels, SRT and VTT output, and live captions.

Benefits

For students

  • Students can turn recordings into text.
  • Students can make subtitles for their own videos.
  • Students can see live captions.

For teachers

  • Installers carry their own Python runtime.
  • Teachers can caption class media.
  • No account is needed.

For schools

  • The app is free with no subscription.
  • Audio stays on the computer by default.
  • The app sends usage statistics by default, which IT should turn off.

Getting started checklist

Where is the AI in this product?

The AI is a speech recognition model such as faster-whisper or whisper.cpp. It runs on the computer. Students and teachers load a recording and review the transcript. Optional cloud engines exist, but they send audio away.

Privacy and safety

No account is needed. The README says audio and transcripts stay on the computer by default. The app still contacts the network for model downloads, a config fetch at startup, and a daily update check. Usage statistics are on by default and include model, language, durations, OS, memory size, region, and a random install ID. They can be turned off under Help, and Work offline in the File menu blocks all connections. Audio goes to Google only if someone picks a cloud engine, and transcript text goes to a remote AI provider only if one is configured. A teacher should have IT turn statistics off and keep cloud engines off.

  2. Record a book talk and turn it into notes.
  3. Compare the spoken and written versions of a speech.
  4. Fix errors in a transcript and list the common ones.
  5. Use a transcript to find a strong quote.
