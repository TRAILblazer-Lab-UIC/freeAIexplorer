Getting started checklist

Where is the AI in this product?

The projects use decision trees, image classification, random forests, reinforcement learning, and minimax search. Some run in the browser and some use a company's cloud. Students collect data, train a model, and test how well it works.

Key terms on this page

Short definitions of words used above and below. Select a term for the full glossary entry.

Classifier
A classifier is an AI model that sorts inputs into groups.
Cloud service
A cloud service is software that runs on a company's servers and reaches you over the internet.
Dataset
A dataset is an organized collection of data.
Decision tree
A decision tree is a model that makes choices through a series of yes or no questions.
Image classification
Image classification is an AI task that puts a single label on a whole picture.
Machine learning
Machine learning is a way to build AI from examples.
Model accuracy
Accuracy is the share of answers an AI model gets right.
Model training
Training is the process where an AI model learns from examples.
Neural network
A neural network is a type of AI model built from layers of simple connected units.
Reinforcement learning
Reinforcement learning is machine learning by trial and error.

Privacy and safety

The page is an index of many projects, and the research could not read the project pages. The materials do not state which accounts students need. Data collected varies by project. Teachable Machine projects run in the browser, and the DeepRacer project uses Amazon cloud services. A teacher should check each project for accounts, cameras and cloud services before use.

Ideas by subject

Select a subject to see five classroom ideas.

How this can be used for Science
  1. Build a decision tree that sorts animals by their traits.
  2. Collect water quality data and test how well a model predicts it.
  3. Design a fair test for a model and record the results.
  4. Compare predictions from a model with real observations.
  5. Write a science fair report that explains what the model learned.
How this can be used for Computer Science
  1. Train a Teachable Machine model to tell happy and sad faces apart.
  2. Test the model on a new face and record the result.
  3. Explore a minimax game such as Connect 4 and describe how the computer chooses moves.
  4. Build a random forest for a small data set.
  5. Draw the steps a model follows from data to prediction.
How this can be used for Math
  1. Sort data into groups and count how many items fall in each.
  2. Graph the accuracy of a model after each change.
  3. Calculate the percent of right answers a model gives.
  4. Compare two models and decide which has better results.
  5. Use averages to summarize water quality readings.
