eCraft2Learn AI programming guide and PWA

A seven chapter Snap! guide to AI programming with speech, vision, and neural nets.

FREEAILocal with optional cloud or accountsGood for AI beginners

Overview

The eCraft2Learn guide has seven chapters of Snap! AI programming for children and beginning programmers. Chapters cover speaking, listening, image recognition, pre-trained models, words and sentences, neural nets, and nearest neighbors. Each chapter has example projects built on importable Snap! libraries. A progressive web app lets many AI blocks work offline after first use.

Benefits

For students

  • Students build AI projects with blocks and no typed code.
  • Students try speech, image recognition, and neural nets.
  • Students can work offline after the first use.

For teachers

  • Each chapter has example projects.
  • Seven block libraries import into Snap!.
  • Chapters 4, 6, and 7 run slowly without a GPU.

For schools

  • The guide and the code are free and open.
  • The guide runs in Chrome or Edge on common computers.
  • Some blocks call cloud services and need API keys.

Getting started checklist

Where is the AI in this product?

Some AI runs in the browser on the student's device and some calls cloud services. Blocks cover speech synthesis, speech recognition, image recognition, word embeddings, neural nets, and nearest neighbors. Students snap blocks together and test the results. They use the blocks to build their own talking, listening, and seeing projects.

Privacy and safety

No account is needed for local blocks, and cloud blocks need API keys. Cloud blocks such as speech recognition and some image recognition send data to providers such as Google, IBM, Microsoft and OpenAI. Local blocks run in the browser, and the web app works offline after first use. The camera and microphone are used for some chapters. No privacy policy was found. A teacher should check which blocks use the cloud, protect any API keys, and review how each service handles student data.

How this can be used for Computer Science
  1. Build a Snap! program that speaks a sentence from Chapter 1.
  2. Make a program that listens and writes down what you say.
  3. Train an image recognizer on two objects and test it.
  4. Use nearest neighbors to sort new examples into groups.
  5. Compare a cloud block with an offline block and record the speed.
