Zero Robotics (MIT)

A free MIT coding competition where code flies simulated robots and finals run on the ISS.

FREEComputingRoboticsSends student data to a company

Overview

Zero Robotics is a free programming competition run from MIT. Students write code in a web browser that flies simulated robots through a yearly game. Winning alliances have their code run on NASA Astrobee robots aboard the International Space Station. High school teams compete in a fall tournament with text based coding, and middle school teams join a five week summer program with block based coding.

Benefits

For students

  • Students write code that may fly on the space station.
  • Students compete in teams on a real mission style game.
  • Students work with block or text code by grade level.

For teachers

  • The platform is free for all teams.
  • No hardware is needed.
  • Questions can go to zerorobotics@mit.edu.

For schools

  • The program is free.
  • Students need only a computer with a web browser and a Google account.
  • Setup takes about an hour.

Getting started checklist

Where is the AI in this product?

Zero Robotics has no AI. Students write code that flies simulated robots. They build skills in logic and in planning a robot's moves.

Privacy and safety

An account is required through Google sign in, and the internet is always needed. Code and team data live on the MIT hosted site. No privacy policy page was found. Data practices are not confirmed. A teacher should check the privacy terms and school policy on Google accounts before students sign in.

How this can be used for Computer Science
  1. Write block code for a simulated robot in the summer program.
  2. Write text code for the fall tournament game.
  3. Test a program in the simulator and fix the first bug.
  4. Compare two strategies for the same game.
  5. Review a teammate's code and suggest one change.
How this can be used for Engineering and Design
  1. Plan how a robot should move in space to reach a goal.
  2. Test how fuel and motion limits shape a plan.
  3. Record each run and look for patterns in what works.
  4. Divide team roles for planning, coding, and testing.
  5. Explain how a space robot such as Astrobee helps astronauts.
