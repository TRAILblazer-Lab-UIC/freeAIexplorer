Lingva Translate

An open source front end that shows Google Translate results on a cleaner page.

AI

Overview

Lingva Translate is an open source alternative front end for Google Translate. It fetches translations from Google without using Google's own page. The lingva.ml site offers text translation, an API, and export to txt or pdf. Students and teachers paste text and read the result.

Benefits

For students

  • Students can translate text between many language pairs.
  • The page is plain and quick to open.
  • Students can export a translation to txt or pdf.

For teachers

  • Teachers need no install. The site works in any browser.
  • Teachers can use it to compare machine translation with student work.
  • The tool offers a REST and GraphQL API for advanced projects.

For schools

  • The tool is free.
  • It can be self-hosted from the GitHub repository.
  • Translation is done by Google. Text leaves the school.

Getting started checklist

Where is the AI in this product?

The AI is Google's machine translation, which runs in Google's cloud. Lingva fetches the results and shows them on its own page. Students paste text, read the translation, and then check and refine it. The tool relies on scraping Google Translate, which may break without notice.

Privacy and safety

No account is needed, and the internet is always required. The site says it has zero logs, no ads, and no tracking cookies. That claim applies to the public instance only. Text is relayed to Google Translate. Google still receives it, and it leaves the school. A teacher should review the privacy notes with the school's technology lead and keep personal details out of anything students paste.

How this can be used for World Languages
  1. Translate a short paragraph and mark words that look wrong to a language learner.
  2. Compare the tool's output with a classmate's own translation.
  3. Translate a simple recipe and discuss which steps lose meaning.
  4. Test how the tool handles a sentence with slang or an idiom.
  5. Write a list of tips for using machine translation as a check and not as a shortcut.
