Linkat

A free Linux system for school computers from the Catalan education department.

FREEComputingStays on the device

Overview

Linkat is a GNU/Linux system offered by the Departament d'Educació of Catalonia. It gives schools free office, internet, multimedia, and educational applications. The latest version is Linkat 26.04, built on Ubuntu 26.04 LTS with a customized Cinnamon desktop. Earlier variants include Blue, Infant, Primary, and Web desktops.

Benefits

For students

  • Students get a ready set of educational and office programs.
  • Younger students can use variants made for their age.
  • Students see an open source computer system at work.

For teachers

  • The desktop comes with bundled applications.
  • Teachers do not need to hunt for software.
  • The site and interface are in Catalan, which suits Catalan schools.

For schools

  • The system is free.
  • It can run on existing school computers.
  • Installation needs IT skill and may take days.

Privacy and safety

Linkat is a locally installed operating system and needs no account. The internet is used for setup. The project page has no privacy information. The materials do not state what student data any bundled application collects. A teacher should check the applications before students use them.
