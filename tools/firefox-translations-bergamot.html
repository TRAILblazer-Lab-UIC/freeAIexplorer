Firefox Translations (Bergamot)

Firefox can translate web pages on the device with no cloud service.

FREEAIStays on the device

Overview

Firefox can translate web pages in near real time using neural translation models that run in the browser. The engine comes from Project Bergamot, an EU funded effort with several European universities, and Mozilla ported it to WebAssembly. Language models are downloaded to the browser. Mozilla says it does not record which pages users translate. Students use it to read pages in other languages.

Benefits

For students

  • Students can read web pages in other languages.
  • Students can compare the translation with the original text.
  • Students learn how translation models make choices.

For teachers

  • The feature is built into Firefox.
  • A prompt appears when a page is in a supported language.
  • Teachers need no extra software.

For schools

  • The feature is free and the code is open.
  • Translation runs in the browser on the device.
  • IT must approve and install Firefox.

Getting started checklist

Where is the AI in this product?

The AI is a neural machine translation model that runs in the browser on the device. Students open a page and accept the prompt. They read the translated text and compare it with the original. They can then spot mistakes and improve their own understanding of the language.

Privacy and safety

No account is needed and the language models are downloaded once. Mozilla says translations are done locally and that it does not track the pages translated. The research did not fetch the Firefox privacy policy. It also could not confirm that translation works offline after the download. Firefox is not a ChromeOS browser. A teacher should read the Firefox privacy policy and remind students that machine translation can make errors.

How this can be used for World Languages
  1. Translate a short news article and compare it with a version you read in the original language.
  2. List three phrases the translation got wrong and suggest better ones.
  3. Translate a page and find words you already know in the other language.
  4. Write a short summary of the page in the target language.
  5. Compare the translation of a joke or an idiom with its meaning.
