ScratchJr Spanish curriculum (BC DevTech)

Spanish ScratchJr coding curricula for kindergarten through second grade.

FREEComputingStays on the device

Overview

This is the Spanish version of the Coding as Another Language ScratchJr curricula from the DevTech Research Group at Boston College. The Varkey Foundation and Comunidad Atenea translated and adapted it. The hub page links to kindergarten, first grade, and second grade materials. Students learn coding with ScratchJr on tablets.

Benefits

For students

  • Young students learn coding in Spanish.
  • Students build projects in ScratchJr.
  • Students work at a level for kindergarten through second grade.

For teachers

  • The hub links to a curriculum for each grade.
  • The learning curve is easy.
  • Classrooms in Corrientes and Mendoza have used the materials.

For schools

  • The curricula are free.
  • Funding comes from the US Department of Education and the Scratch Foundation.
  • Tablets need ScratchJr, and IT may need to approve it.

Getting started checklist

Where is the AI in this product?

This curriculum has no AI. ScratchJr uses icon blocks on a tablet. Students build sequencing skills as they put blocks in order. They learn to plan what happens first, next, and last.

Privacy and safety

The curriculum page does not discuss data or accounts. A batch note says ScratchJr needs no account and stores projects on the device. The research did not verify this on a ScratchJr page. The internet is used to install and download. The research did not read the individual lesson pages. A teacher should check the privacy label for ScratchJr and where tablets store student projects.

How this can be used for Computer Science
  1. Follow a lesson from the hub and build the first project in Spanish.
  2. Make a character move to a place named in Spanish.
  3. Use blocks to put the steps of a daily routine in order.
  4. Change a project so a character repeats a move.
  5. Show a finished project and name each block in Spanish.
