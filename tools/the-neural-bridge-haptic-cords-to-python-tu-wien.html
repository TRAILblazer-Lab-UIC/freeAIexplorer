The Neural Bridge: haptic cords to Python (TU Wien)

A research paper on acting out neural networks with cords, then coding them in Python.

Overview

This record is a 2026 WiPSCE paper titled Turning Students into Neurons. It evaluates an embodied unplugged activity on neural networks. A related ITiCSE 2026 paper describes a K-12 sequence with physical cords and carabiners that moves to Python. The two papers are not confirmed to be the same item. Treat it as a research paper and plan your own lesson.

Benefits

For students

Getting started checklist

Where is the AI in this product?

The AI idea is the feedforward neural network and its artificial neurons. Students act as neurons using cords. No AI tool runs in the physical part. In the related sequence, students then move to Python code.

Privacy and safety

The physical cord activity is on paper and uses no accounts. The research did not review the Python stage tools. Accounts and data flow there are unconfirmed. The materials do not state whether the internet is needed. Check the Python tools before students use them. Plan a safe way to use cords and carabiners in a classroom.

How this can be used for Computer Science
  1. Stand in a line as neurons and pass a signal along the cords.
  2. Describe what each neuron adds up before it passes a signal on.
  3. Change the weight of one connection and see how the output changes.
  4. Write a short Python program that mirrors the cord model.
  5. Explain how the physical model matches the code.
