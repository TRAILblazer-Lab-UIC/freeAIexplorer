ArduPilot

An open source autopilot with a simulator for drones, planes, boats, and rovers.

ComputingRobotics

Overview

ArduPilot is an open source autopilot developed since 2009 and reported to be in over a million vehicles. It supports multicopters, helicopters, planes, boats, submarines, and rovers. Software in the loop simulation runs the real flight code on a desktop computer. Students can fly and crash virtual vehicles without hardware. It is an advanced tool for upper secondary or college work.

Benefits

For students

  • Students test flight code in a safe simulator.
  • Students learn guidance, navigation, and control ideas.
  • Students can work with MAVLink and ROS 2.

For teachers

  • Full source and logs are available.
  • It is licensed GPLv3 with no fees.
  • Setup is technical and takes days.

For schools

  • The software is free. Vehicles and flight controllers cost extra.
  • The simulator needs only a desktop computer.
  • IT must install the toolchain.

Getting started checklist

Where is the AI in this product?

This tool has no AI. The autopilot runs control code with fixed rules. Students build logic and data skills as they study flight logs and tune settings for autonomous moves.

Privacy and safety

The software runs on the computer or vehicle hardware and needs no account. The research found no student data collection but reviewed no privacy policy. Flight logs stay on the device unless the user shares them. The internet is needed at setup. A teacher should keep real flights supervised and follow local drone rules.

  1. Run the flight code in the simulator and read its output.
  2. Send a command through MAVLink and watch the response.
  3. Write a script that sets waypoints.
  4. Parse a flight log and plot a value.
  5. Discuss how a companion computer talks to the autopilot.
