Bitsy

A small browser engine for making pixel games, worlds, and stories.

FREEComputingStays on the device

Overview

Bitsy is a small engine for making little pixel games, worlds, and stories in the browser. Students draw avatars, tiles, and rooms and add dialogue. Finished games export as a web page. The tool is listed as in development on itch.io, with version 8.15 posted in February 2026.

Benefits

For students

  • Students draw their own characters and worlds in a simple pixel editor.
  • Students write dialogue and shape a short story.
  • Students can share a finished game as a web page.

For teachers

  • The tool is easy to learn, and a lesson can start in minutes.
  • Opensource.com calls it a tool for teaching programming and points to the Bitsy class curriculum by Hal Meeks.
  • Teachers can cover writing, art, and design in one project.

For schools

  • The tool is free, and the code is open source.
  • It runs in the browser, and Chromebooks are listed as supported.
  • The project moved its repositories to Codeberg in July 2026.

Getting started checklist

Where is the AI in this product?

Bitsy has no AI. It builds the skill of design logic, as students decide what happens when a player enters a room or talks to a character. It also builds sequencing as they plan a story path.

Privacy and safety

No account is needed and the internet is used at setup. The research found no privacy policy. It did not confirm how and where projects are saved. Student games can be shared on itch.io and the research found one public student collection there. A teacher should decide whether students may post games publicly.

Ideas by subject

How this can be used for Computer Science
  1. Build a small world with three rooms and connect them with exits.
  2. Plan a game on paper before drawing any tiles.
  3. Add an item the player can pick up and use it in a later room.
  4. Test a partner's game and write down one bug.
  5. Explain how the game decides what to show next.
How this can be used for English and Language Arts
  1. Write a short dialogue for a character in a Bitsy room.
  2. Tell a story in three rooms with a beginning, a middle, and an end.
  3. Give a character a clear voice through word choice.
  4. Write two endings and let the player find one.
  5. Read a partner's game and describe the setting in a paragraph.
How this can be used for Visual Arts
  1. Draw an avatar in the pixel editor with a limited set of colors.
  2. Design a set of tiles for a forest or a school.
  3. Create a room that shows a mood through color.
  4. Animate a sprite with two frames.
  5. Compare two pixel styles and explain which fits a story better.
