Overview

The Robotics TXT 4.0 Base Set is a construction kit built around the TXT 4.0 controller. Search results say it is for secondary schools and uses ROBO Pro Coding graphical software. Listings name a USB camera, an ultrasonic sensor, an IR track sensor and two encoder motors. School material includes 12 models and 25 experiments for groups of 2 to 4 pupils. The product pages returned errors. These details come from search snippets.

How this can be used for Engineering and Design
  1. Build one of the 12 models and describe how its parts work together.
  2. Test an encoder motor and measure how far the model travels.
  3. Work in a group of three and assign a builder, a tester and a recorder.
  4. Compare two models and list what each one does best.
  5. Improve a model and write down the result of the change.
How this can be used for Computer Science
  1. Write a ROBO Pro Coding program that starts a motor.
  2. Use the ultrasonic sensor to stop a model near an object.
  3. Use the IR track sensor to follow a line.
  4. Read the camera view and describe what the controller can see.
  5. Explain a program's flow to a partner using the graphical blocks.
