Pybricks

Python and block coding for smart LEGO hubs, run from a browser editor.

FREEComputingRoboticsUnverified

The privacy details for this item are unverified. Check which tools and accounts students will use before class.

Overview

Pybricks is Python and block coding for smart LEGO hubs. Supported hubs are BOOST, City, Technic, MINDSTORMS and SPIKE. Programs run directly on the hub. The online editor at code.pybricks.com sends programs over Bluetooth.

Benefits

For students

  • Students write real Python for LEGO robots.
  • Students see programs run on the hub.
  • Students can work on Windows, Mac, Linux, Chromebook and Android.

For teachers

  • Python coding is free and open source.
  • Block coding is an extra for supporters.
  • The editor runs in a browser.

For schools

  • Python is free. The supporter plan for blocks was not priced.
  • IT must approve the firmware install and Bluetooth use.
  • No classroom study was found.

Getting started checklist

Where is the AI in this product?

Pybricks has no AI. It builds skills in text coding, sensing and logic. Students write Python that controls motors and reads sensors.

Privacy and safety

Programs run on the hub and the editor runs in the browser. The privacy page returned 404. The materials do not state whether an account is needed or what data is collected. A teacher should check the Pybricks privacy terms with IT. Installing firmware changes the hub. Test it on one hub first.

How this can be used for Computer Science
  1. Write a Python program that spins a motor for two seconds.
  2. Use a sensor reading to decide when the robot stops.
  3. Turn a short program into a function.
  4. Compare a block program with the Python version if blocks are available.
  5. Fix a bug in a partner's program.
How this can be used for Engineering and Design
  1. Build a LEGO robot and tune its drive speed.
  2. Test turning accuracy and record the results.
  3. Add a sensor and change the design to hold it.
  4. Compare two gear choices on the same course.
  5. Write a design log of changes and test results.
