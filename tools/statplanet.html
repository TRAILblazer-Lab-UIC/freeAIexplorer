StatPlanet

Free data software that links interactive maps and charts in one view.

Computing

The privacy details for this item are unverified. Check which tools and accounts students will use before class.

Overview

StatPlanet is data visualization software that combines interactive maps and graphs in one screen. The desktop version for Windows and Mac is free for educational use. It suits students in grades 6 to 12. Students filter data, switch between datasets and time periods, and watch the map and charts change together.

Benefits

For students

  • Students see the same data as a map and as a chart at the same time.
  • Students switch chart types and time periods to ask new questions.
  • Students can bring in their own data from a CSV file.

For teachers

  • The desktop version is free for educational and non-commercial use.
  • Teachers can make custom maps from ESRI shapefiles.
  • The search found no StatPlanet lesson plans. Teachers will plan their own activities.

For schools

  • The desktop version costs nothing for schools.
  • The data stays on the device.
  • IT will likely need to install it. Other versions need a StatSilk plan or self-hosting.

Getting started checklist

Where is the AI in this product?

StatPlanet has no AI. Students choose the filters and charts themselves. This builds the skill of reading data and spotting patterns across places and years.

Privacy and safety

No account is needed, and the desktop version loads local data and shapefiles. The materials do not say whether the internet is needed after setup. The research found no StatSilk privacy page. Data handling for the desktop app and the cloud version is not confirmed. A teacher should check how the program behaves offline and ask the vendor about data handling. The vendor notes offline problems in old Firefox 68. Test the browser first.

How this can be used for Math
  1. Load a dataset and compare a bar chart and a line chart of the same numbers.
  2. Filter the data to one group and describe how the average changes.
  3. Spot an outlier on a chart and explain what might cause it.
  4. Import a class survey from a CSV file and graph the results.
  5. Write three questions that a graph could answer and test them.
How this can be used for Social Studies
  1. Open a world map of a country statistic and name the highest and lowest places.
  2. Move through time on the map and describe how one region changes.
  3. Compare two indicators for the same countries and discuss any link.
  4. Choose a region and present what the map shows to the class.
  5. Pick a map from a custom shapefile and describe what a viewer learns from it.
