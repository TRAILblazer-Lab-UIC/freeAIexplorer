EdUBudgie

A Linux desktop with student software installed, built for high school and university.

Overview

EdUBudgie Linux is an Ubuntu Budgie remix prepackaged for high school and university students. It is installed as an operating system. It bundles software such as GIMP, Inkscape, Krita, and Scribus. A Lite edition runs on a dual-core Celeron with 4 GB RAM and 32 GB storage.

Benefits

For students

  • Students get art and design software on day one.
  • Students learn a Linux desktop.
  • Students can run it on modest computers with the Lite edition.

For teachers

  • Tools for drawing, painting, and page layout are already installed.
  • The desktop is based on Ubuntu Budgie.
  • The project offers no tailored school IT support.

For schools

  • The system is free.
  • The ISO is about 5.7 GB per a review.
  • IT staff must handle deployment, and the project may be dormant. The newest confirmed release is 22.04.1.

Getting started checklist

Where is the AI in this product?

EdUBudgie has no AI. It builds skills in using an operating system and creative tools. Students learn files, windows, and software setup.

Privacy and safety

No account is needed, and the internet is used for setup. The system is a local operating system, and work stays on the computer. It includes Google Chrome and a Zoom client, which have their own data practices. No privacy policy was found, and the materials do not say what data the system collects. A teacher should ask IT to review the bundled apps and the project status. The newest confirmed release is 22.04.1.
