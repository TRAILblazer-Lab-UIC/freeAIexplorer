Arm Raspberry Pi Pico Projects for Schools

A free project book with nine Raspberry Pi Pico projects for ages 16 to 18.

FREEAIComputingLocal with optional cloud or accounts

Overview

This free project book from Arm is built around the Raspberry Pi Pico microcontroller and Python. It has nine projects for ages 16 to 18. Topics include environmental data logging, Jupyter notebook data analysis, IoT networks, physics experiments, facial recognition, and a capstone bird feeder that identifies and deters squirrels.

Benefits

For students

  • Students build real projects from a first sensor to a full capstone.
  • Students learn Python on a small device and analyze data in Jupyter notebooks.
  • The book introduces machine learning and facial recognition in a hands-on way.

For teachers

  • Teachers can download the book or adapt it through GitHub.
  • Project 1 lists the sensors and tools to buy.
  • The book gives a clear path through nine projects.

For schools

  • The book is a free download.
  • Pico boards and sensors are bought separately. The materials call them cheap but give no price.
  • Setup takes days and a teacher will likely need IT help to install tools.

Getting started checklist

Where is the AI in this product?

The book introduces machine learning, facial recognition, animal identification, and data science. The AI runs on the device, and Jupyter notebooks run in the browser for data work. Students build a facial recognition project and a bird feeder that spots squirrels, then adjust them for their own idea.

Privacy and safety

No account is needed and the internet is used at setup. Projects run on the board and a computer. Some IoT projects push data to internet visualization services. Those parts need the internet and a third party service. The research did not check the vision sensor projects for data handling. A teacher should check any visualization service before students send data and set rules for facial recognition on classmates.

Ideas by subject

Select a subject to see five classroom ideas.

How this can be used for Engineering and Design
  1. Complete Project 1 and test each sensor with a short program.
  2. Build a data logger and place it in two spots to compare readings.
  3. Design a housing for the Pico project and test it for a week.
  4. Plan the bird feeder capstone and list the parts it needs.
  5. Test the bird feeder against a toy squirrel and record the results.
How this can be used for Computer Science
  1. Write Python code that reads a sensor and prints the value each second.
  2. Push sensor data to an online chart and describe how the data travels.
  3. Read the facial recognition project and explain each step in your own words.
  4. Change the squirrel detection settings and compare the results.
  5. Use a Jupyter notebook to plot logged data and describe a trend.
How this can be used for Science
  1. Log air temperature at school for a week and chart the changes.
  2. Compare readings indoors and outdoors and explain the difference.
  3. Plan a physics test with the Pico and record the results.
  4. Write a hypothesis about a sensor reading and test it.
  5. Present a short report on what the logged data shows.
