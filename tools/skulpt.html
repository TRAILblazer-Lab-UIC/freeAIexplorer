Skulpt

A Python engine written in JavaScript that runs inside the browser.

Computing

Overview

Skulpt is a Python implementation written in JavaScript that runs entirely in the browser. It needs no plugins, preprocessing, or server-side support. Web developers embed it in pages so students can write and run Python, including turtle graphics. Education sites such as Trinket use it as their Python engine.

Benefits

For students

  • Students write and run real Python in a browser.
  • Students draw with turtle graphics.
  • Students see a normal Python experience.

For teachers

  • Teachers usually meet Skulpt inside Trinket or Runestone.
  • A teacher can copy an iframe embed code into a lesson page.
  • Using Skulpt directly has an advanced learning curve.

For schools

  • The software is free and open source.
  • Code runs in the browser on the student device.
  • Self-hosting needs a teacher or IT to load the files.

Getting started checklist

Where is the AI in this product?

Skulpt has no AI. It runs Python code in the browser. Students build sequencing and logic skills as they write and test programs.

Privacy and safety

No account is needed for Skulpt itself, and the code runs entirely in the browser. The library has no privacy policy of its own. Data handling depends on the site that embeds it. Trinket, for example, sends code to its server for autocomplete and lets users save work to a free account. A teacher should check the privacy terms of the host site before students use it.
