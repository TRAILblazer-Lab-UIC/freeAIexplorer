Robo Wunderkind

A modular block robot kit for young learners with a companion coding app.

ComputingRobotics

Overview

Robo Wunderkind is a modular block robot kit for young learners. Children snap colored blocks together to build robots. They then code the robots in the app with a remote, icon based code or Blockly modes. The app lists 19 in-app tutorials and more than 30 free projects.

Benefits

For students

  • Young children build robots with snap-together blocks.
  • Children can start with a remote and move to icons and then Blockly.
  • Children follow tutorials inside the app.

For teachers

  • The app has 19 tutorials and more than 30 free projects.
  • The kit suits PreK-5.
  • The App Store says it works offline.

For schools

  • The app is free. The kit price was not confirmed.
  • The app needs iOS 15 or later per the App Store. Android and Chromebook support was not confirmed.
  • The App Store lists a rating of 3.7 from 6 ratings.

Getting started checklist

Where is the AI in this product?

The kit has no AI. It builds skills in sequencing and logic. Children move from remote control to icon code to Blockly.

Privacy and safety

App data goes to the vendor. The policy lists an account email, an optional child birth month and year, a device hardware ID, location and IP address, and in-app usage. Usage data is linked to a username only when logged in. The policy says it protects children under 13 in line with COPPA. It does not name third party recipients or server locations. The App Store label lists email for marketing and product interaction for analytics. A teacher should avoid child accounts, review the policy, and ask IT before installing.

How this can be used for Computer Science
  1. Drive a robot with Live mode and describe each move.
  2. Build a short icon program and run it.
  3. Move to Blockly and repeat the same program.
  4. Fix a sequence that sends the robot the wrong way.
  5. Show a program to a partner and explain it.
How this can be used for Engineering and Design
  1. Snap blocks together to build a first robot.
  2. Change the build and test how it moves.
  3. Draw the robot before building it.
  4. Compare two designs and pick one.
  5. Tell a partner how the blocks connect.
