BirdBrain Technologies Hummingbird Bit

A robotics kit that pairs a micro:bit with craft materials and sensors.

ComputingRoboticsLocal with optional cloud or accounts

Overview

The Hummingbird Bit is a robotics kit for designing, building and programming robots with a micro:bit and craft materials. The official page lists 14 parts, including LEDs, servos, and light, distance, sound and dial sensors. It is listed for grades 4 through 12. Students code it in BirdBlox, Snap!, MakeCode, Python or Java.

Benefits

For students

  • Students build robots from cardboard and other craft materials.
  • Students choose block or text coding.
  • Students use sensors to make their creations respond.

For teachers

  • The vendor describes the kit as low floor and high ceiling.
  • A learning hub offers lessons for the kit.
  • The kit shares software with the Finch robot.

For schools

  • It works with Chromebook, Windows, Mac, Linux, iOS and Android.
  • No account is needed and the internet is needed at setup.
  • The official page lists no price. The micro:bit is sold separately.

Getting started checklist

Where is the AI in this product?

The Hummingbird Bit has no AI. The kit runs the programs that students write. Students build skills in sensors, logic and sequencing.

Privacy and safety

No account is needed on the pages read, but account needs for the Hummingbird were not confirmed. The BirdBlox app policy says the app is directed to children under 13 and lists Bluetooth and sensor permissions. It says BirdBrain in Pittsburgh processes the data. It does not mention COPPA by name. A teacher should check which editor the class will use and read its privacy policy.

Ideas by subject

Select a subject to see five classroom ideas.

How this can be used for Engineering and Design
  1. Build a moving creature from cardboard and a servo.
  2. Design a robot that reacts to light and test it in a dark box.
  3. Use the distance sensor to build a door that opens as a hand nears.
  4. Test two ways to attach a servo and pick the stronger one.
  5. Present a finished robot and explain how each part works.
How this can be used for Computer Science
  1. Program a servo to sweep back and forth in BirdBlox.
  2. Use the dial sensor to control the brightness of an LED.
  3. Write a program that reacts to loud sounds.
  4. Move a block program into MakeCode or Python and compare the code.
  5. Debug a program that sends a servo too far.
How this can be used for Visual Arts
  1. Build an art piece with a moving part made from craft materials.
  2. Add LEDs that change color when a viewer comes near.
  3. Create a kinetic puppet with a servo arm.
  4. Design a sculpture that responds to light and describe the effect.
  5. Show the artwork in a class gallery and explain the mechanism.
