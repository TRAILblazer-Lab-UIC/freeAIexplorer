micro:bit proxy lamps (Newcastle University Open Lab)

Tabletop micro:bit lamps that let students practise stage lighting control.

ComputingRoboticsStays on the device

Overview

The proxy lamps are small models of full-sized stage lights. Each lamp is a BBC micro:bit in a laser-cut plastic case with LEDs on its pins. A mains-powered Raspberry Pi broker links the lamps to industry stage lighting control. Students practise lighting control before they move to a full rig.

Benefits

For students

  • Students practise real lighting control on a safe tabletop model.
  • Students work with the same control tools that theaters use.
  • Students see how code and hardware work together in a live show.

For teachers

  • The lamps are battery powered and controlled wirelessly.
  • Teachers can run lighting practice before booking a full theater rig.
  • The micro:bit runs a Python application that advanced students can read.

For schools

  • The page does not sell the lamps. A school would need to build them.
  • The page gives no build guide. Setup can take days.
  • IT needs to help with the Raspberry Pi broker.

Getting started checklist

Where is the AI in this product?

The lamps have no AI. Students build skills in logic and sequencing as they plan lighting cues. They also work with control signals sent from software to hardware.

Privacy and safety

The page describes local wireless control over the school network. It does not mention data collection or accounts. This is a research project, and the research reviewed no privacy policy. A teacher should check the mains powered broker and the wiring with IT before students handle it.

How this can be used for Theater and Media Arts
  1. Plan a lighting cue list for a short scene and run it on the lamps.
  2. Match lamp colors to the mood of each moment in a play.
  3. Practise a timed light change with a partner calling the cues.
  4. Compare the lamp setup with a full rig and note what is the same.
  5. Write a lighting plan that a stage crew could follow.
How this can be used for Engineering and Design
  1. Draw a diagram of how a lamp, the broker and the control software connect.
  2. Test how far the wireless control reaches in a room.
  3. Improve a lamp case design and explain the change.
  4. Measure how long a battery lasts during a rehearsal.
  5. Document the broker setup for the next class.
How this can be used for Computer Science
  1. Read the Python application on the micro:bit and describe what each part does.
  2. Change a lamp's brightness behavior in the code.
  3. Trace a message from the control software to a lamp.
  4. Add a new lighting effect and test it.
  5. Explain in a short talk how the broker passes control data.
