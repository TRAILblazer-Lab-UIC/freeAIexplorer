Berkeley Language Center Language and AI machine translation resources

Open activity templates on using machine translation and AI for language learning.

FREEAISends student data to a companyGood for AI beginners

Overview

The Berkeley Language Center offers open-access activity templates that teachers can adapt to any language. They are sorted by proficiency level and by three goals. The goals are how the tools work, how to use them for learning, and their ethics. The page does not state a K-12 audience, and a discovery note suggests grades 9 to 12.

Benefits

For students

  • Students learn how machine translation works.
  • Students practice using translation tools to learn a language.
  • Students discuss the ethics of using AI in language study.

For teachers

  • Templates adapt to any language.
  • Levels run from foundational to advanced.
  • Modules exist for Arabic, Dutch, Filipino, French, German, Hindi, Italian, and Mandarin.

For schools

  • The templates are free to download.
  • The tools used may have their own terms.
  • The work is funded by a US Department of Education grant for 2023 to 2026.

Getting started checklist

Where is the AI in this product?

The AI is machine translation and generative AI, which run in the cloud on tools that teachers choose. The templates guide students to test the tools, compare outputs, and judge them. Students use the tools to extend their own language study and reflect on the limits.

Privacy and safety

The materials do not say which tools or accounts students need. The page names no specific translation products. The activities use online translation or generative AI tools, which send entered text to those providers. The research did not review those terms. A teacher should check the terms and age limits of each tool and tell students to leave out personal details.

How this can be used for World Languages
  1. Translate a short paragraph with a machine tool and mark each error.
  2. Compare two tools on the same sentence and explain the differences.
  3. Write a message in the target language and use a tool to check it.
  4. Discuss when it is fair to use a translation tool for homework.
  5. Create a class guide for using AI as a study partner.
