How this can be used for Computer Science
  1. Reflect on a favorite board game and list the rules that make it work.
  2. Design a board and a set of rules for a new game.
  3. Test your game with another group and note unclear rules.
  4. Rewrite the rules to remove any step that confused players.
  5. Explain how clear rules are like an algorithm.
How this can be used for English and Language Arts
  1. Write an instruction manual for your game in plain steps.
  2. Add a short story that sets the scene for the game.
  3. Swap manuals with a partner and mark unclear sentences.
  4. Revise your manual after a play test.
  5. Present your game and read the rules aloud.
