Gridworld Reinforcement Learning demo

Interactive demos that show how an agent learns by rewards on a grid map.

FREEAIUnverifiedGood for AI beginners

The privacy details for this item are unverified. Check which tools and accounts students will use before class.

Overview

This AI4K12 page lists three interactive reinforcement learning demos on grid world maps. Imaginary AI shows temporal difference learning with rewards and punishments on an editable map. TDDemo shows the same idea with stochastic actions. REINFORCE.js is a family of demos that the page says suits undergraduates.

Benefits

For students

  • Students watch an agent learn by trial and error.
  • Students edit the map and change rewards and punishments.
  • Students see how small changes lead to new behavior.

For teachers

  • The demos run in a browser and need no install.
  • The page pairs with AI4K12 Big Idea 3 on learning.
  • The editable map makes good class discussion.

For schools

  • The demos are free to open.
  • No accounts are described.
  • Each demo links to an external site on GitHub Pages, Carnegie Mellon, or Stanford.

How this can be used for Computer Science
  1. Open Imaginary AI and describe how the agent learns a path to a goal.
  2. Add a punishment square and watch how the path changes.
  3. Move the goal and note how long it takes the agent to adapt.
  4. Compare the plain demo with the stochastic version in TDDemo.
  5. Write a rule of thumb for how rewards shape behavior.
How this can be used for Math
  1. Change a reward value and record how the values on nearby squares change.
  2. Predict the agent's path before you run it and check the guess.
  3. Count how many steps the agent needs before and after a map edit.
  4. Make a table of reward values and the path each one produces.
  5. Explain how an average of past results can guide a decision.
