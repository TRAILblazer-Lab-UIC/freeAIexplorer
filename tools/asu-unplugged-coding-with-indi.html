ASU Unplugged coding with Indi

A Kindergarten and Grade 1 lesson on coding vocabulary and color card paths for indi.

FREEComputingRoboticsUnpluggedUnverified

The privacy details for this item are unverified. Check which tools and accounts students will use before class.

Overview

This is a Kindergarten and Grade 1 lesson by Tina Martinez. In Part 1 students learn coding vocabulary and how to handle the Sphero indi robot. In Part 2 they use colored cards and arrows to build a path maze for the robot. The page says it is easily adapted for other unplugged screen free coding robots.

Benefits

For students

  • Young students learn coding words and robot care.
  • Students build a path maze with colored cards and arrows.
  • Students learn that a plan can be fixed when it fails.

Privacy and safety

The lesson uses the indi robot, which reads color cards and has no screen. The lesson page does not discuss data. The materials do not state whether an account or internet is needed. The lesson materials are in a Google Slides presentation linked from the page. A teacher should check the privacy details of any robot app before using it and open the slides before class.

Ideas by subject

Select a subject to see five classroom ideas.

How this can be used for Computer Science
  1. Learn the words code, algorithm, and bug and use each in a sentence.
  2. Handle the robot with care and tell what it does.
  3. Build a path maze from colored cards and arrows.
  4. Run the robot on the maze and find a bug.
  5. Fix the bug and run the path again.
How this can be used for Engineering and Design
  1. Plan a path on paper before laying cards.
  2. Test the path and note where the robot goes wrong.
  3. Change one card to improve the path.
  4. Build a longer maze with two turns.
  5. Show the maze to a partner and explain the plan.
