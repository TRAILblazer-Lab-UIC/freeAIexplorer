p5.js

A free JavaScript library for learning to code by making art.

FREEComputingStays on the device

Overview

p5.js is a free open source JavaScript library for learning to code and making art. It targets artists, designers, beginners, and educators. A complete library zip can be used offline in any text editor and browser. Students write code that draws and animates on a canvas.

Benefits

For students

  • Students see their code turn into drawings right away.
  • Students learn real JavaScript through creative projects.
  • Students can build animations and interactive sketches.

For teachers

  • The project has a reference, tutorials, and examples.
  • A p5.js education resources page supports teachers.
  • CodeHS and Tynker offer courses that use p5.js.

For schools

  • The library is free and open source.
  • It works offline once downloaded.
  • It runs on Chromebooks, Windows, Mac, and Linux with a text editor and a browser.

Getting started checklist

Where is the AI in this product?

The vendor does not describe any AI in p5.js. It is a drawing library. Students build sequencing and pattern spotting skills as they use loops to repeat shapes.

Privacy and safety

No account is needed, and the library runs in the browser. The internet is used to download the library. Sketches stay on the device when used offline. The p5js.org website uses Google Analytics. The privacy policy says COPPA does not apply to the nonprofit foundation but includes a section for users under 13. A teacher should check which editor students use, as online editors may ask for accounts.

How this can be used for Computer Science
  1. Follow a CodeHS style lesson and draw shapes with code.
  2. Use a loop to draw a row of circles.
  3. Make a shape follow the mouse and explain how the code works.
  4. Fix a broken sketch and describe the error.
  5. Build a small interactive game from a sketch.
How this can be used for Visual Arts
  1. Draw a pattern with code and change its colors.
  2. Recreate a favorite abstract painting using shapes and coordinates.
  3. Use random values to make a new piece each time the sketch runs.
  4. Animate a drawing and compare it with a hand drawn flipbook.
  5. Write an artist statement that explains how the code shaped the artwork.
