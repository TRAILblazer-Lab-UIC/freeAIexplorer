FIRST XRP Level 2 Programming with ML and AI

A year-long FIRST course outline for programming robots with cameras and AI.

FREEAIUnverified

The privacy details for this item are unverified. Check which tools and accounts students will use before class.

Overview

This is a course outline from FIRST called Programming with Machine Learning and AI. It is a year-long career and technical education course for high school. Students program a robot with a camera, build computer vision pipelines, and deploy pre-trained AI models onto the robot. The outline lists Intro to Robotics Programming as the prerequisite.

Benefits

For students

  • Students write real text code for a robot that can see.
  • Students learn tools used in industry, including OpenCV, GitHub, and telemetry dashboards.
  • Students can work toward the Python Institute PCAP, Certiport, and OpenCV University certifications that the outline lists.

For teachers

  • The outline gives a full year plan with linked FIRST Training content, SparkFun Module 9, FTC docs, and WPILib.
  • The outline lists standards from NGSS, ISTE, ITEEA, NIMS, NBEA, and ACTE.
  • Teachers can pick the robot platform that a program already owns.

For schools

  • The outline is a free PDF.
  • The SparkFun page lists the XRP kit at $119.95, with an educator discount for FIRST teams.
  • Schools with an FTC or FRC robot and a camera can reuse that equipment.

Getting started checklist

Where is the AI in this product?

The AI is computer vision and pre-trained machine learning models that run on the robot. Students build vision pipelines with Limelight or OpenCV and deploy a pre-trained model onto the robot. They then write code that acts on what the camera sees.

Privacy and safety

The materials do not state whether accounts are needed, what data is collected, or whether the internet is required. The outline says students deploy pre-trained models onto the robot. The camera inference runs on the device. The outline is a course description and not a software product. No privacy policy applies. A teacher should check which accounts and online tools the linked training content needs. A teacher should also check that robot cameras point only at the work area.

Ideas by subject

Select a subject to see five classroom ideas.

How this can be used for Career and Technical Education
  1. Plan a year-long robotics project that follows the course outline and ends with a certification practice exam.
  2. Track the work in a GitHub repository and write a short commit history that shows the team's progress.
  3. Build a telemetry dashboard that shows the robot's sensor readings during a run.
  4. Prepare a short demonstration for a local employer that explains how the robot uses a camera.
  5. Write a skills log that connects each outcome in the outline to a job task.
How this can be used for Engineering and Design
  1. Mount a camera on a robot and record how the view changes with height and angle.
  2. Design a test course with colored markers that the robot must detect.
  3. Tune a motion profile and compare how smooth the robot's movement looks before and after.
  4. Test the robot's vision under different lighting and describe the failures.
  5. Improve the robot's design after a test run and explain each change to the team.
How this can be used for Computer Science
  1. Build a computer vision pipeline with OpenCV that finds an object in a camera image.
  2. Write command-based robot code that reacts to a detected object.
  3. Deploy a pre-trained AI model onto the robot and record how often it is right.
  4. Compare the Limelight approach and the OpenCV approach on the same task.
  5. Write a short report that explains one failure of the vision system and a possible fix.
