NetTango Web

A block based tool for building simulations on top of NetLogo Web models.

FREEComputingUnverified

The privacy details for this item are unverified. Check which tools and accounts students will use before class.

Overview

NetTango Web is a block based programming tool built on NetLogo Web. A builder lets an author define blocks and link them to a NetLogo Web model. A player page shows the finished model. Students arrange blocks and see how the agent based simulation changes. It is developed by Northwestern's Center for Connected Learning and the TIDAL Lab.

Benefits

For students

  • Students program a simulation with blocks.
  • Students see the effect of each block on the model.
  • Students compare blocks with the NetLogo code behind them.

For teachers

  • The builder lets teachers define custom blocks.
  • A sample project, Wolves and Sheep, is included.
  • A CT-STEM lesson called Analyzing the Code Behind the Blocks is available.

For schools

  • The tool is free and open source.
  • It runs in a browser.
  • No install or account is needed.

Getting started checklist

Where is the AI in this product?

This tool has no AI. It builds skills in modeling, logic, and sequencing. Students see how blocks turn into code that moves agents.

Privacy and safety

The research found no account mentioned for the builder or the player, and the internet is needed at all times. The pages read do not state a privacy policy or data practices. A teacher should check the data practices with IT and test the player page before class.

How this can be used for Science
  1. Use blocks to change how wolves and sheep behave.
  2. Transform an ecosystem model and describe the result.
  3. Run the model several times and record the population counts.
  4. Predict what happens before each change.
  5. Explain how one change affected the ecosystem.
How this can be used for Computer Science
  1. Compare a NetTango block with the NetLogo code behind it.
  2. Reorder blocks and watch how the behavior changes.
  3. Describe what each block tells an agent to do.
  4. Build a simple rule set for one agent.
  5. Explain how blocks relate to text code.
