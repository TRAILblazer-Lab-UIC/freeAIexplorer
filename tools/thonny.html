Thonny

A free beginner Python editor with a step-by-step debugger built in.

FREEComputingStays on the device

Overview

Thonny is a Python IDE for beginners that comes with Python built in. It has a simplified starting interface, a variables view, and a step-by-step debugger that needs no breakpoints. It highlights common syntax errors and includes a package manager. It was developed at the University of Tartu in Estonia and is used to program Raspberry Pi Pico with MicroPython.

Benefits

For students

  • Students see variables change as they step through code.
  • Students get help spotting common syntax errors.
  • Students can program a Raspberry Pi Pico with MicroPython.

For teachers

  • Python is already built in, which leaves little to set up.
  • The Raspberry Pi Foundation has a learning path that uses Thonny with the Pico.
  • A plug-in system allows more features.

For schools

  • The software is free and the code is open.
  • It runs on Windows, macOS, and Linux and needs a standard computer.
  • IT approval for installs may be needed. The Debian install pulls in about 300 MB.

Getting started checklist

Where is the AI in this product?

Thonny has no AI. Students write Python and watch it run step by step. They build skills in debugging and in reading how a program changes its variables.

Privacy and safety

No account is needed and the internet is used at setup. Programs stay on the device. The official site has no privacy or data statements. Package installs through pip contact the public package index. The site mentions an Assistant feature that the research did not examine. Decide where students save files on shared computers. Ask IT to review pip use and the Assistant feature.

How this can be used for Computer Science
  1. Write a short program that prints your name and run it, following the beginner interface.
  2. Step through a loop with the debugger and watch the variables view.
  3. Fix a program that Thonny marks with a syntax error.
  4. Use the pip package manager to add a library, with teacher approval.
  5. Write MicroPython for a Raspberry Pi Pico that blinks a light.
