Wio Terminal TinyML course

A free course that teaches TinyML on the Wio Terminal board.

AIComputingRobotics

Overview

Seeed Studio's wiki offers a TinyML course for the Wio Terminal board. It comes as a PDF, a GitHub repository, and a no-code Codecraft version. Search results describe seven projects such as people counting and a weather station. Students use the Arduino IDE, Edge Impulse, and TensorFlow Lite for Microcontrollers.

Benefits

For students

  • Students train small models on real sensor data.
  • Students see trained models run on the board.
  • Students work through seven projects.

For teachers

  • The course PDF and repository give a ready path.
  • A no-code Codecraft version lowers the first barrier.
  • No independent review was found. Teachers should try a project first.

For schools

  • Course material is free. A Wio Terminal board is needed and was not priced.
  • The tools run on Windows, Mac, and Linux.
  • IT may need to install the Arduino IDE.

Getting started checklist

Where is the AI in this product?

The AI is TinyML. Students train neural networks on sensor data with Edge Impulse, which is a company's cloud tool. The trained model then runs on the Wio Terminal board. Students collect data, train, and test their own model.

Privacy and safety

The materials do not state which accounts students need. The internet is used at setup. Edge Impulse training is cloud based. Sensor data used for training goes to that company. The trained model then runs on the Wio Terminal board. A teacher should review the Edge Impulse terms and use a school account where possible.

How this can be used for Computer Science
  1. Follow the course to collect sensor data and train a first model.
  2. Compare two models trained on different amounts of data.
  3. Test the model on new data and record how often it is right.
  4. Describe in words how the model decides between two classes.
  5. Use the no-code Codecraft version and compare it with the Arduino version.
How this can be used for Engineering and Design
  1. Wire a sensor to the Wio Terminal and test its readings.
  2. Build a people counter project and test it in a hallway.
  3. Place a weather station sensor and record its data for a day.
  4. Compare readings in two locations.
  5. Write setup notes another team could follow.
