Bootstrap Illustrative Mathematics and CMP pathways

Bootstrap coding lessons mapped onto Illustrative Mathematics and CMP3 units.

Computing

The privacy details for this item are unverified. Check which tools and accounts students will use before class.

Overview

Bootstrap publishes teacher materials that add coding lessons to Illustrative Mathematics (IM) and Connected Mathematics (CMP3) units. The IM Grade 7 PDF links units 2.1, 2.2, and 2.6 to lessons on function composition, transforming images, order of operations, and simple inequalities. In the scale drawing lessons, students scale images up or down and distort them with code. A CMP3 grade 8 pathway uses code to rotate, scale, and reflect images.

Benefits

For students

  • Students use code to scale and transform images.
  • Students practice function composition and order of operations.
  • Students see math ideas change a picture on screen.

For teachers

  • Each pathway PDF points to the matching IM or CMP3 unit.
  • Lessons fit into existing math units.
  • Several editions exist, from spring 2022 to fall 2025.

For schools

  • The materials are free.
  • The IM and CMP textbooks are separate.
  • Students code in a browser editor, and Chromebooks are listed.

Getting started checklist

Where is the AI in this product?

These lessons have no AI. They build the skill of using functions, as students compose steps that change an image. Students also practice sequencing.

Privacy and safety

The internet is needed throughout, and accounts are optional. The research could not read the pathway PDF well and did not confirm the tool or data handling. Bootstrap pages describe Pyret editors at code.pyret.org, which uses Google sign in to save to Drive. The materials do not say what student data is collected. A teacher should find out which editor the lessons use and read its privacy terms before students log in.

How this can be used for Math
  1. Scale an image up and down with a scale factor, as an alternative to hand-drawn scale drawings.
  2. Use scale-xy to distort an image and describe what changed.
  3. Compose two image functions and predict the result.
  4. Rotate, scale, and reflect an image in a CMP3 grade 8 task.
  5. Compare order of operations in code and on paper.
How this can be used for Computer Science
  1. Write a function that returns a scaled image.
  2. Test a function with two inputs and compare outputs.
  3. Compose three functions into one picture.
  4. Find an error in a short program.
  5. Explain the order a program runs in.
