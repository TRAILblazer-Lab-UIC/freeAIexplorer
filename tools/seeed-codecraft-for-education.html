Seeed CodeCraft for Education

A zero-code AI and block programming platform for Seeed boards, sold to schools.

AIComputing

Overview

CodeCraft for Education is a zero-code AI programming and maker platform sold to schools as seat packages. Teachers create a course code in an admin panel. Students join with the code and program Seeed hardware such as the Grove Beginner Kit, Wio Terminal, and XIAO ESP32-S3. Boards are flashed from the browser over USB.

Benefits

For students

  • Students program real boards with blocks.
  • Students join with a code and need no personal account in class.
  • Students use AI compute features in their projects.

For teachers

  • A teacher admin panel sets session length and class size.
  • Classroom Code Login avoids student accounts during class.
  • Boards need no driver install.

For schools

  • Seat packages include AI compute quotas.
  • No prices are listed on the page.
  • Hardware kits are optional.

Getting started checklist

Where is the AI in this product?

The AI is a set of AI compute features that students use in their projects. It runs in the vendor's cloud, and some work runs in the browser. Students build with blocks, call the AI features, and test the results on their boards.

Privacy and safety

Students join with a class code and need no personal account in class. Course code sessions record activity. The page says Seeed monitors teaching data in real time, and students are logged out automatically after class. The general Seeed privacy policy names Google Analytics, Google Ads and Mailchimp. It says the services are not intended for children under 16, which is a data rule and not a stated class limit. The research found no education specific privacy terms. A teacher should ask Seeed for those terms and have IT review them before use.

How this can be used for Computer Science
  1. Build a block program that lights an LED when a sensor reading goes high.
  2. Use an AI feature in a project and describe what it does.
  3. Change one block and predict how the board will respond.
  4. Test the program with a partner and note one bug.
  5. Explain how blocks become code that the board runs.
How this can be used for Engineering and Design
  1. Connect a Grove sensor to a board and read its values.
  2. Flash a program to the board over USB from the browser.
  3. Design a small device that reacts to light or sound.
  4. Test the device and record how well it works.
  5. Present the device and explain each part.
