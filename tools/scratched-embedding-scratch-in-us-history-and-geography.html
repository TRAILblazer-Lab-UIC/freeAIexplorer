ScratchEd Embedding Scratch in US History and Geography

A 2009 unit outline that turns 5th grade map activities into Scratch challenges.

Computing

The privacy details for this item are unverified. Check which tools and accounts students will use before class.

Overview

This is a work-in-progress unit outline from teacher Karen Randall, posted in 2009. It turns four map activities from a 5th grade social studies class in St. Paul, Minnesota into Scratch project challenges. The topics are geographic terms, Native American cultural regions, European explorers, and English colonies. Templates exist only for the first two topics.

Benefits

For students

  • Students show what they know about maps by building Scratch projects.
  • Students work on geographic terms and cultural regions.
  • Students create projects as well as read about maps.

For teachers

  • The outline gives a worked example from a real classroom.
  • A Word document and .sb templates are provided.
  • The outline is unfinished. Teachers will need to fill gaps.

For schools

  • The materials are free.
  • Setup may take an hour.
  • The .sb files need an old Scratch desktop version or conversion to open in current Scratch.

Getting started checklist

Where is the AI in this product?

This unit has no AI. Students build sequencing and event skills with Scratch blocks. They connect map facts to what a sprite does on the screen.

Privacy and safety

The materials do not state whether accounts are needed or what data is collected. The files run in Scratch on the computer. A teacher should check which Scratch version students will use and where projects are saved.

Ideas by subject

Select a subject to see five classroom ideas.

How this can be used for Social Studies
  1. Use the geographic terms template and label each term on a map.
  2. Make a Scratch project that shows the Native American cultural regions of North America.
  3. Add a click that tells one fact about each region.
  4. Create a challenge about the routes of European explorers and share it with the class.
  5. Quiz a partner with a project about the English colonies.
How this can be used for Computer Science
  1. Open a template and describe what each sprite does.
  2. Change a block so a label appears on a click.
  3. Build a short quiz with a score variable.
  4. Find and fix a bug in a classmate's map project.
  5. Explain how the project responds to each click.
