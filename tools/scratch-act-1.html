Scratch Act 1

A five-unit beginning Scratch curriculum for 4th grade with workbook and assessments.

FREEComputingSends student data to a company

Overview

Scratch Act 1 is a beginning Scratch curriculum for 4th grade. It has five units on Scratch basics, sequence, events, loops, and a cumulative cartoon project. Students make a name poem, an About Me project, a Dance Party, and a Culture Cartoon. It prepares students for Scratch Encore.

Benefits

For students

  • Students build four projects that grow in skill.
  • Students use language frames to speak and write about their work.
  • Students follow a Use-Modify-Create path.

For teachers

  • Materials include a student workbook, tutorial links, and assessments.
  • The curriculum lines up with CSTA, ISTE, and ELA standards.
  • A teacher needs little coding background.

For schools

  • The curriculum is free and shared under CC BY-NC-SA 4.0.
  • Students use Scratch in a browser on a Chromebook.
  • The materials do not state whether student accounts are needed.

Getting started checklist

Where is the AI in this product?

This curriculum has no AI. Students build sequencing, event, and loop skills with Scratch blocks. They learn to plan the order of steps in a program.

Privacy and safety

The curriculum asks students to use Scratch in a browser, and the page does not discuss accounts. Scratch accounts store projects on Scratch servers. The research did not confirm whether the internet is needed or what student data is collected. Scratch Desktop may work offline, but the research did not verify this. A teacher should check school rules on Scratch accounts before students save projects online.

Ideas by subject

Select a subject to see five classroom ideas.

How this can be used for Computer Science
  1. Build a name poem in which each letter of a name triggers an action, using a sequence of blocks.
  2. Create an About Me project that responds to clicks and key presses.
  3. Use a loop to build a Dance Party with repeating moves.
  4. Modify a classmate's project and describe what changed.
  5. Plan and code a cartoon about a country's culture.
How this can be used for English and Language Arts
  1. Use a language frame to explain how a name poem project works.
  2. Write a short script for an About Me project and read it aloud.
  3. Describe the steps of the Dance Party in order using sequence words.
  4. Give a partner spoken feedback on a project using the frames.
  5. Write a story for the Culture Cartoon before coding it.
