Firia Labs CodeAIR Fly with Python

A programmable quadcopter that students fly with Python code.

$$$AIComputingRoboticsSends student data to a companyGood for AI beginners

Overview

CodeAIR is an assembled quadcopter that students program in Python. The code runs on the drone itself. A press release says it has an onboard camera and a neural network for machine learning models. Students sign in to the CodeSpace web IDE on a PC or Chromebook and connect the drone by USB-C. The kit includes the Fly with Python curriculum for grade 6 and up.

Benefits

For students

  • Students write real Python and watch a drone obey it.
  • Students use an interactive textbook inside the CodeSpace editor.
  • Students work in pairs on a hands-on flight project.

For teachers

  • The kit comes with the Fly with Python curriculum.
  • A reseller lists 12 missions.
  • A reseller recommends one to two students per kit.

For schools

  • STEMfinity lists the kit at 299 USD with a one-year curriculum license.
  • Renewals and parts are sold separately.
  • Sign-in uses a Google account. IT may need to approve it.

Privacy and safety

An account is required and the internet is needed at all times. Students and teachers sign in to CodeSpace with a Google account. CodeSpace collects the account email and username, lesson progress, and saved programs. The Firia Labs policy says student projects are stored in each pupil's own Google Drive. It names Google as the main processor and lists Sentry for error logs and Smartsupp for support. It says student data is not used for third party behavioral tracking and is deleted when a school asks. A teacher should review the privacy policy and get IT approval for Google sign-in before students log in.

How this can be used for Computer Science
  1. Write a short Python program that makes the drone take off and land.
  2. Change one number in the code and predict how the flight changes.
  3. Use the interactive textbook to learn a new Python command.
  4. Debug a program that sends the drone the wrong way.
  5. Explore how the onboard camera and neural network can spot a pattern.
How this can be used for Engineering and Design
  1. Test the drone on a flat course and measure how long each flight lasts.
  2. Plan a flight path around cones and fly it.
  3. Compare two flight settings and record which is steadier.
  4. Inspect how the drone's parts work together in flight.
  5. Write safety rules for the flight space and share them with the class.
