Overview

Student groups follow the engineering design process to build and program a robot for a sumobot competition. A search summary says the activity uses LEGO MINDSTORMS NXT or EV3 kits and takes about 75 minutes. Groups weigh robot structure, weight, and gear ratios so their robot pushes opponents out of the ring. The search summary also says TeachEngineering has retired the curriculum.

How this can be used for Engineering and Design
  1. Sketch a sumobot design and explain how it will stay in the ring.
  2. Compare two gear ratios and predict which pushes harder.
  3. Add weight to the robot and test how it changes the push.
  4. Build, test, and improve the robot after a practice round.
  5. Run a class ring contest and discuss which designs won.
How this can be used for Computer Science
  1. Program the robot to drive forward and push.
  2. Add a block that turns the robot when it reaches the ring edge.
  3. Test the program and fix any step that fails.
  4. Compare two programs and pick the better one.
  5. Explain your program to another group.
