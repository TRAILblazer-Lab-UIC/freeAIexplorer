Sphero.Math (University of Maryland)

A fourth grade math curriculum where students program Sphero robots with blocks.

Robotics

The privacy details for this item are unverified. Check which tools and accounts students will use before class.

Overview

Sphero.Math is a computational thinking enhanced fourth grade math curriculum. University of Maryland researchers built it with District of Columbia Public Schools teachers. Students work in groups to program Sphero robots with block-based scripts from a tablet or phone. One example is a prime number maze where the robot may roll only on primes.

Benefits

For students

  • Students use math to guide a real robot.
  • Students debug by comparing their code to the robot's movement.
  • Students finish with a masking tape maze task, according to a search snippet.

For teachers

Getting started checklist

Where is the AI in this product?

This curriculum has no AI. Students write block scripts that the robot follows. They build skills in sequencing and debugging.

Privacy and safety

The materials do not state whether accounts are needed. They do not say what data the app collects. A teacher should check the app's privacy details with the school before use. A teacher should also decide how devices are shared among groups.

How this can be used for Math
  1. Program a Sphero to roll only on prime numbers in a maze.
  2. Measure the robot's path and add up the distances.
  3. Change a speed or time value and see how the distance changes.
  4. Design a masking tape maze with a math rule.
  5. Explain to the class why each step in your path fits the rule.
How this can be used for Computer Science
  1. Build a block script that moves the Sphero forward.
  2. Run the script and compare the code to the robot's movement.
  3. Find the block that sent the robot the wrong way and fix it.
  4. Add a loop to repeat a part of the route.
  5. Swap scripts with another group and predict the result.
