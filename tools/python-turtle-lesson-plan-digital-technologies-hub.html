Python Turtle lesson plan (Digital Technologies Hub)

A free 20-hour Year 7-8 course plan for drawing shapes with Python turtle.

FREEComputingUnverified

The privacy details for this item are unverified. Check which tools and accounts students will use before class.

Overview

This is an Australian DT Challenge course plan for Years 7 and 8 on Python turtle graphics. Students learn first commands such as move and turn and combine them to draw shapes. The plan covers simple algorithms, loops, and command line input and output. It takes about 20 hours of class time and is licensed CC BY 4.0.

Benefits

For students

  • Students see their commands draw shapes at once.
  • Students learn loops by repeating a move and turn.
  • Students practice data as integers and strings.

For teachers

  • The plan gives a clear 20 hour path.
  • The plan links to the Australian codes ACTDIK015, ACTDIP019, and ACTDIP020.
  • Teachers can reuse and adapt the plan under CC BY 4.0.

For schools

  • The lesson plan is free.
  • The course can use Python with turtle.

Getting started checklist

Where is the AI in this product?

The vendor does not describe any AI, and the plan teaches turtle drawing. It builds an AI-related skill, which is sequencing. Students write steps in order and use loops to repeat them. That practice is the base of every algorithm.

How this can be used for Computer Science
  1. Use the move and turn commands to draw a square, as the course plan does.
  2. Draw a triangle and a hexagon and compare the turn angles.
  3. Replace repeated lines with a loop and describe what changed.
  4. Ask the user for a size with input and draw a shape of that size.
  5. Store a number and a string in variables and print both.
