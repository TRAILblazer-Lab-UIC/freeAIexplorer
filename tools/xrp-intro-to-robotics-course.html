XRP Intro to Robotics Course

A free modular course for the XRP robot that covers driving, sensors, and an arm.

FREEComputingRoboticsUnverified

The privacy details for this item are unverified. Check which tools and accounts students will use before class.

Overview

This is a free modular course for the XRP robot from WPI Open-STEM and SparkFun. Modules start with an introduction to robotics and then cover driving, sensors, and a robot arm. A final project combines the earlier material. Lessons use Blockly and Python, and each module has interactive robot challenges.

Benefits

For students

  • Students build skills step by step across the modules.
  • Students start with Blockly and move to Python.
  • Students finish with a final project.

For teachers

  • The course runs with one robot per student or small teams sharing a robot.
  • Modules give a clear order for a unit.
  • Interactive challenges check student progress.

For schools

  • The course is free.
  • A search summary lists the XRP kit at 119.95 USD with discounts for educators and FIRST teams.
  • Setup takes days and a teacher can do it.

Getting started checklist

Where is the AI in this product?

The course has no AI. Students write code that drives the robot and reads its sensors. They build skills in sequencing, logic, and sensor data.

How this can be used for Engineering and Design
  1. Drive the robot in a straight line and measure the distance.
  2. Test the sensors and record what each one detects.
  3. Use the arm to move a small object.
  4. Compare two designs for a driving task.
  5. Plan the final project and list the parts.
How this can be used for Computer Science
  1. Write a Blockly program that drives a square.
  2. Move a block program into Python and compare.
  3. Use a sensor in a program.
  4. Add a loop to repeat a motion.
  5. Combine earlier modules in the final project.
