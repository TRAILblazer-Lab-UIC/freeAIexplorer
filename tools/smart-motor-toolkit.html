Smart Motor toolkit

A research toolkit that lets young students train a motor to react to sensors.

AIRoboticsUnverified

The privacy details for this item are unverified. Check which tools and accounts students will use before class.

Overview

Smart Motor is a research toolkit of low-cost hardware and software for teaching supervised machine learning in elementary school. Students train a motor's response to sensor input from distance, light, rotary, and slide sensors. It uses a nearest neighbor model with visualizations. A one-week study used it with children ages 9 to 12 in building projects.

Benefits

For students

  • Students teach a motor by example and see the model respond.
  • Students build the motor into their own projects.
  • Students see a visual picture of how the model decides.

For teachers

  • The study reports that students trained motors without writing code, according to search snippets.
  • It fits building and robotics projects that teachers may already run.

For schools

  • The paper title says low cost, but no price was found.
  • The model runs on the device and needs no internet.
  • This is a research prototype, and no purchase or build instructions were found.

Getting started checklist

Where is the AI in this product?

The AI is a supervised learning model that uses the nearest neighbor method. Students give the motor examples of sensor readings and the response they want. The model runs on the device. Students then test new readings and see which stored example the motor matches.

Ideas by subject

Select a subject to see five classroom ideas.

How this can be used for Computer Science
  1. Train a motor to spin faster as a hand moves closer to a distance sensor.
  2. Add a wrong example on purpose and watch how the motor behaves.
  3. Compare results from five training examples with results from fifteen.
  4. Explain in a drawing how the nearest example decides the motor's response.
  5. Swap the distance sensor for a light sensor and retrain the motor.
How this can be used for Engineering and Design
  1. Build a small fan that speeds up as a student's hand comes near.
  2. Attach a motor to a cardboard creature and train it to react to light.
  3. Place a slide sensor on a model and use it to set motor speed.
  4. Test a build in a bright room and a dim room and record the changes.
  5. Redesign the sensor placement after a test and describe what improved.
