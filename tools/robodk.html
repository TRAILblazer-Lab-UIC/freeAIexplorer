RoboDK

A desktop program for simulating industrial robots and writing their programs offline.

$ LicenseRoboticsLocal with optional cloud or accounts

Overview

RoboDK is a desktop program for industrial robot simulation and offline programming. Users simulate robots and generate robot programs without a physical robot. A free 30 day trial and a paid yearly educational license are offered. RoboDK Academy provides free self-paced courses.

Benefits

For students

  • Students try industrial robot programming without a physical robot.
  • Students can use a large library of robot models.
  • Students can follow the free RoboDK Academy courses.

For teachers

  • Teachers can demonstrate robot motion on one computer.
  • A Python API is listed in the Academy course list.
  • A search snippet shows a college mechatronics training page that uses it.

For schools

  • The educational license costs 145 USD per year. It requires a university email.
  • High school use may not qualify for the educational license.
  • Professional use costs 3995 USD for a permanent license. IT will likely need to install it.

Getting started checklist

Where is the AI in this product?

This program has no AI. It simulates robots and writes programs from the paths users set. Students build skills in sequencing and logic as they plan each robot motion.

Privacy and safety

An account is optional. The internet is used at setup. Programs run on the desktop computer. The materials do not state what data the software collects. A teacher should check the license terms and the privacy policy before students install it.

How this can be used for Engineering and Design
  1. Load a robot model and move it through a set of positions.
  2. Build a simple work cell with a robot and a table.
  3. Simulate a pick-and-place task and time it.
  4. Compare two robot models for the same task.
  5. Write a short report on what a simulation can show before a real build.
How this can be used for Career and Technical Education
  1. Follow a RoboDK Academy lesson on setting up a robotic cell.
  2. Simulate a task a factory robot might do.
  3. Generate a robot program from a simulated path.
  4. Add a Python script to repeat a motion.
  5. Describe how offline programming saves a company time.
