PrusaSlicer

A free slicer that turns 3D models into printer instructions.

Computing

Overview

PrusaSlicer is a free open source slicer that turns 3D models into printer instructions. It has Simple, Advanced, and Expert modes. It includes over 200 tested Prusa profiles and a built in Printables browser. Santa Clara University's maker lab uses it in K-12 outreach.

Benefits

For students

  • Students learn the steps from a model to a printed object.
  • Students can start in Simple mode and move to more options.
  • Students can try supports and multi material painting.

For teachers

  • Teachers can slice for younger grades and let older students take over.
  • The program works with many printer brands.
  • A command line batch slicing option is available.

For schools

  • The software is free and open source.
  • It runs locally and needs no account.
  • IT will likely need to approve the install. A 3D printer is a separate cost.

Getting started checklist

Where is the AI in this product?

The vendor does not describe any AI in PrusaSlicer. It follows fixed rules to make printer instructions. Students build sequencing and logic skills as they see layers stack.

Privacy and safety

No account is needed. The internet is used for setup. Student files stay on the computer. The built in Printables browser connects to Printables, which is a separate vendor service. No privacy policy was read. A teacher should check which models students slice and print, and whether students use the Printables browser.

How this can be used for Engineering and Design
  1. Slice a model at two layer heights and compare print time, as a maker lab does with its prints.
  2. Add supports to an overhang and note the difference.
  3. Cut a model with the cut tool and print the pieces.
  4. Estimate the material used and compare it with the real print.
  5. Write a guide that helps a classmate slice their first model.
How this can be used for Career and Technical Education
  1. Follow the full path from a downloaded model to a printed part.
  2. Use Simple mode and then Expert mode and describe the difference.
  3. Prepare a batch of parts for a class project.
  4. Test a profile and log the results.
  5. Present a short report on a fabrication workflow.
