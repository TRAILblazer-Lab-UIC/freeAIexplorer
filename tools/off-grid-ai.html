Off Grid AI

A local desktop app that runs chat, image, and speech models on your own computer.

AI

Overview

Off Grid AI is a local-first desktop app for macOS, Windows, and Linux that runs open models on the user's own machine. The free core offers text and vision chat, on-device image generation, speech to text, text to speech, and document-grounded projects. An optional paid Pro add-on adds screen capture, memory, and approval-gated actions.

Benefits

For students

  • Students can chat with a model that runs on their own computer.
  • Students can make images, dictate text, and hear text read aloud.
  • Students can ask questions about their own documents.

For teachers

  • Teachers can choose any GGUF model from Hugging Face.
  • A model catalog helps teachers find models to try.
  • The app can run offline after models are downloaded.

For schools

  • The core app is free, and Pro is a one-time payment of unlisted price.
  • A Pro license covers up to 5 devices.
  • The computer needs enough RAM or GPU, and IT must install the app.

Getting started checklist

Where is the AI in this product?

The AI is a set of open models for chat, vision, images, and speech. They run on the local computer through llama.cpp, whisper.cpp, and stable-diffusion.cpp. Students chat, create images, and dictate text, then edit the results to make their own work.

Privacy and safety

No account is needed, and the internet is used for setup and downloads. The README says conversations, files, and models stay on the device. The app updates itself through signed releases and contacts the network for that. MCP connectors and Pro license activation use separate network paths. The README says analytics are off unless a user opts in, but the releases page mentions an analytics opt-out. The research found no formal privacy policy and no independent coverage. A teacher should check the analytics setting and test the app before class.

Ideas by subject

Select a subject to see five classroom ideas.

How this can be used for English and Language Arts
  1. Ask the model for feedback on a short draft and decide which tips to use.
  2. Add a class reading to a project and ask questions about it.
  3. Dictate a story with speech to text and revise the text.
  4. Listen to a poem read by text to speech and discuss tone.
  5. Check an answer from the model against the source document.
How this can be used for Visual Arts
  1. Write a prompt for an image and describe how the result matches your idea.
  2. Change one word in a prompt and compare the two images.
  3. Use a generated image as a sketch and draw over it by hand.
  4. Make a set of images in one style and write about the choices.
  5. Discuss how to credit AI help in an art project.
How this can be used for Special Education and Accessibility
  1. Dictate a short paragraph with speech to text and skip the typing.
  2. Listen to text read aloud by text to speech while following along.
  3. Try two voices and choose the one that is easiest to follow.
  4. Ask the model to restate a reading in simpler words.
  5. Use the tools to complete a short assignment with a teacher.
