ELECFREAKS Pico:ed V2

A Raspberry Pi RP2040 board in a micro:bit style shape with an LED dot matrix.

ComputingRobotics

Overview

Pico:ed V2 is an education board built on the Raspberry Pi RP2040 chip. It has a micro:bit style edge connector and a 7x17 LED dot matrix display. Search results say it supports MicroPython and C++. It is meant for older students who are ready for text code.

Benefits

For students

  • Students program a real RP2040 chip, the same family used in many hobby projects.
  • Students see their code light up the dot matrix display.
  • Students learn text code in MicroPython or C++.

For teachers

  • The board connects by USB and needs no internet.
  • The edge connector matches the micro:bit shape.
  • The materials rate the teacher learning curve as advanced.

For schools

  • Reported prices ranged from 12.90 to 18.80 USD.
  • The board has no radio and no accounts.
  • Stock status is uncertain. Check availability before ordering a class set.

Getting started checklist

Where is the AI in this product?

Pico:ed V2 has no AI. It runs the code that students write. Students build skills in logic and text programming.

Privacy and safety

The board works offline, has no accounts, and has no radio or Bluetooth. The research did not read the coding editors. Their data practices are unknown. The maker claims compatibility with micro:bit accessories, but a review headline says most accessories do not work. A teacher should test every accessory before class and check which editor students use.

How this can be used for Computer Science
  1. Write a MicroPython program that shows a message on the dot matrix.
  2. Draw a simple picture by turning on chosen LEDs.
  3. Change one value in a loop and describe what happens on the display.
  4. Compare a MicroPython program with a C++ program that does the same task.
  5. Write comments that explain each line for a classmate.
