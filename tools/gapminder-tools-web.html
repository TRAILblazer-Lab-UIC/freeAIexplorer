Gapminder Tools (web)

Animated bubble charts of world development data that run in a browser.

Computing

The privacy details for this item are unverified. Check which tools and accounts students will use before class.

Overview

Gapminder Tools is an interactive web application for world development data. Users pick indicators and animate bubble charts over time. Individual indicators can be downloaded as CSV or XLSX files. It suits middle and high school students who study global trends.

Benefits

For students

  • Students watch data change over time in animated charts.
  • Students choose their own indicators and test their ideas.
  • Students can download data and graph it in a spreadsheet.

For teachers

  • The tool needs no account and opens in a browser.
  • Teaching materials and a Gapminder Tools Guide in PDF are available.
  • Data can be reused with attribution.

For schools

  • The tool is free.
  • It works on Chromebooks and on Windows, Mac, and Linux computers.
  • Gapminder Tools Offline can be installed for use without internet.

Getting started checklist

Where is the AI in this product?

This tool has no AI. Students build data skills by reading trends and relationships in indicators. The charts run in the browser.

Ideas by subject

Select a subject to see five classroom ideas.

How this can be used for Social Studies
  1. Animate income and life expectancy for five countries and describe the change.
  2. Pick one country and tell its story through three indicators.
  3. Compare two regions over fifty years and write a short summary.
  4. Choose an indicator and predict which countries rank highest before checking.
  5. Cite the data source and attribution on a class poster.
How this can be used for Math
  1. Read the axes of a bubble chart and explain what each bubble shows.
  2. Download an indicator as CSV and make a line graph in a spreadsheet.
  3. Describe a relationship between two indicators as rising, falling, or flat.
  4. Compare the rate of change for two countries.
  5. Write a question that the chart cannot answer and say what data is missing.
