Code.org AI and Machine Learning lesson 5: Classification Models

A 45-minute unplugged lesson where students draw a boundary between fruits and veggies.

FREEAIUnpluggedUnverifiedGood for AI beginners

The privacy details for this item are unverified. Check which tools and accounts students will use before class.

Overview

This 45 minute unplugged lesson simulates how a machine learning algorithm separates data into groups. Students help a computer classify food as fruits or vegetables. They graph 20 foods on two axes that compare sweetness to how easy the food is to eat. They then draw a boundary between a fruit area and a veggie area and test the model.

Benefits

For students

  • Students see how a model draws a line between two groups.
  • Students graph data on two axes.
  • Students test their line on new examples.

For teachers

  • The lesson has a journal warm up and wrap up.
  • The 2026 teacher PDF frames it as a support vector machine simulation.
  • Standards tags include AI4K12 BI-3 and CSTA Data and Analysis.

For schools

  • The lesson is free.
  • It needs cards, rulers, and slides.
  • The internet is needed only for setup.

Getting started checklist

Where is the AI in this product?

The lesson has no software and no AI runs on any device. It simulates a classifier that separates data into groups with a boundary. Students build skills in training data, decision boundaries, and testing a model. The data is simple enough to plot by hand.

Privacy and safety

The activity uses printed cards, rulers, and a journal, and the lesson asks for no student data. The lesson page shows Sign in and Create account links, and the research did not confirm whether an account is needed. Teacher materials are Google Slides and Docs to copy. The internet is used to reach the page and the slides. A teacher should check the Code.org privacy terms before signing in. A teacher should also check the cards for foods that students might see as sensitive.

How this can be used for Computer Science
  1. Graph 20 foods on two axes for sweetness and ease of eating.
  2. Draw a boundary line that separates fruits from veggies.
  3. Test the line on a new food and see which side it lands on.
  4. Find a food that the line gets wrong and explain why.
  5. Write in a journal how the line is like a trained model.
How this can be used for Math
  1. Plot 20 points on a two axis graph and label each axis.
  2. Use a ruler to draw a straight line that separates two groups.
  3. Count how many points fall on the wrong side of the line.
  4. Move the line and compare the number of mistakes.
  5. Describe the line in words using the axes.
