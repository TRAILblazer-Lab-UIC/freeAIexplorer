Adafruit CLUE

A small sensor board with a color display for CircuitPython and Arduino projects.

$ComputingStays on the device

Overview

The Adafruit CLUE is a board the size of a BBC micro:bit. It has an nRF52840 Bluetooth LE processor, a 1.3 inch 240x240 color display and many sensors. These include a 9-axis motion sensor, a proximity, light, color and gesture sensor, a microphone, and humidity, temperature and pressure sensors. Students program it with Arduino or CircuitPython. The listing says there is no MakeCode or Scratch support.

Benefits

For students

  • Students can read nine kinds of sensor data on one board.
  • Students can show results on the built-in color screen.
  • Students practice text coding on a real device.

For teachers

  • Adafruit recommends the Mu editor for CircuitPython.
  • Libraries detect the accelerometer chip automatically.
  • The board suits teachers who already know some text code.

For schools

  • A single board costs 44.95 USD and an order of 100 costs 35.96 USD each.
  • The board needs a computer with USB.
  • The listing was out of stock when read. Check supply first.

Getting started checklist

Where is the AI in this product?

The board has no AI. Students build skills in sensors and data as they read values and show them on the screen. They write code that turns raw readings into messages.

Privacy and safety

The board runs code on the device and needs no account. Bluetooth LE can send data to a nearby computer or phone if students program that. Setup downloads packages and libraries from the web. The research found no privacy policy for the board. A teacher should keep wireless features off unless a lesson needs them. A teacher should also test the install before class.
