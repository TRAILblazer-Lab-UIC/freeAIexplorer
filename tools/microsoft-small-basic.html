Microsoft Small Basic

A beginner text programming language based on BASIC with a few keywords.

Computing

The privacy details for this item are unverified. Check which tools and accounts students will use before class.

Overview

Microsoft Small Basic is a beginner text based programming language and editor based on BASIC. The desktop version 1.2 runs on Windows. A browser edition called Small Basic Online was announced in 2019 as a public preview. The last desktop release was 1 October 2015.

Benefits

For students

  • Students learn text code in a language with few keywords.
  • Students can move from blocks to real code.
  • A 2013 Microsoft blog reports testimonies from 47 students aged 8 to 13 who learned Small Basic.

For teachers

  • The language is small, which makes it easy to teach.
  • A Small Basic Teaching Curriculum is linked from the Microsoft blog.
  • The desktop tool needs no account.

For schools

  • Small Basic is a free download.
  • The desktop version needs Windows 7, 8, 8.1, or 10.
  • IT may need to approve the install.

Getting started checklist

Where is the AI in this product?

This tool has no AI. It builds the skill of writing text code and following program flow. Students also practice naming steps in clear order.

Privacy and safety

No account is needed, and the internet is used at setup. The desktop app is installed from an MSI file and runs locally. The installation guide says the user accepts an End User License Agreement. The research read no privacy statement for the app. The research did not check the browser edition's data handling or confirm that it is still running. A teacher should check that the school can run the older Windows installer and review the browser edition before using it.
