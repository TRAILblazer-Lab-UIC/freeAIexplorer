Processing Foundation Art + Code

A free p5.js curriculum that helps art teachers make interactive artworks.

Computing

The privacy details for this item are unverified. Check which tools and accounts students will use before class.

Overview

Art + Code is a professional development program for U.S. educators who bring software concepts into K-12 art classrooms. Teachers use p5.js to build interactive artworks and apply computational thinking through artmaking. The curriculum is licensed CC BY-NC-SA 4.0 and links to OpenProcessing. Search results say the Teacher Camp is funded by the National Endowment for the Arts.

Benefits

For students

  • Students make artworks that respond to a viewer.
  • Students learn coding as a way to make art.
  • Topics include drawing in contemporary art and generative art, according to a search snippet.

For teachers

  • The FAQ says no coding experience is assumed, according to a search snippet.
  • The curriculum has unplugged warm-ups and project templates.
  • The 2025 version remixes a 2024 version by Jean Y. Kim and Chelly Jin, according to a search snippet.

For schools

  • The curriculum is free.
  • It runs in a browser and IT work is light.
  • Districts can submit an inquiry form to bring the program to a region.

Getting started checklist

Where is the AI in this product?

The vendor does not describe any AI in this curriculum. Students write p5.js code that draws and responds. They build sequencing and logic skills through artmaking.

Privacy and safety

The materials do not state which accounts students need. The p5.js tools run in the browser and need the internet. OpenProcessing may ask students to sign in to save work, and the research did not check this. The page says nothing about data collection. A teacher should check whether the p5.js web editor or OpenProcessing asks for accounts and where student sketches are stored.

How this can be used for Visual Arts
  1. Build an interactive artwork with p5.js, as the program asks art teachers to do.
  2. Explore generative art by changing a random value.
  3. Draw a contemporary style piece with code.
  4. Remix a classmate's sketch and describe your change.
  5. Write an artist statement about your use of code.
How this can be used for Computer Science
  1. Use computational thinking to break an artwork into steps.
  2. Write a loop that draws a repeating shape.
  3. Do an unplugged warm-up and then code the same idea.
  4. Debug a sketch and explain the fix.
  5. Compare an unplugged plan with the finished code.
