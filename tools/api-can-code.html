API Can Code

A high school data science curriculum where students pull API data and visualize it with blocks.

FREEComputingUnverified

The privacy details for this item are unverified. Check which tools and accounts students will use before class.

Overview

API Can Code is a high school data science foundations curriculum. It comes from a partnership between the University of Maryland and Washington Leadership Academy, supported by NSF Award 2141655. It has three units and a final project, with lesson plans, slides and worksheets. Students retrieve public data from APIs, process it in block-based environments and visualize it.

Benefits

For students

  • Students work with real public data.
  • Students code with blocks and then visualize results.
  • Students present insights in a final project.

For teachers

  • The materials include complete lesson plans, slides and worksheets.
  • The 19 lessons are split into three units.
  • The coding activities follow a Use-Modify-Create approach.

For schools

  • The cost is not stated and the materials appear downloadable without charge.
  • Students need a browser and a steady internet connection.
  • CSTA published an alignment document.

Getting started checklist

Where is the AI in this product?

The curriculum has no AI. It is data science and programming. Students build skills in data, sequencing and visualization as they pull, clean and chart data.

Privacy and safety

The materials do not state which accounts students need. The tools run in a browser and need the internet at all times. Search results name EduBlocks and CODAP for the final project. The research did not review their account rules or privacy terms. Download conditions for the materials are not stated. A teacher should check each tool for account rules and data storage.

Ideas by subject

Select a subject to see five classroom ideas.

How this can be used for Math
  1. Make a chart from a public data set and describe the pattern.
  2. Calculate an average from data pulled from an API.
  3. Compare two data sets with a visual and explain the difference.
  4. Use data to make a claim and check how strong the evidence is.
  5. Present the insights from your final project to the class.
How this can be used for Computer Science
  1. Use a block program to request data from a public API.
  2. Modify a given program to show a different data field.
  3. Create a new block program that filters data.
  4. Debug a classmate's data program.
  5. Explain what an API does in plain words.
