Thymio Suite and VPL

The free desktop software for programming Thymio robots with icons, blocks, or text.

FREEComputingRoboticsStays on the device

Overview

Thymio Suite is the desktop programming environment for the Thymio robot, version 2.4.0 on the pages read. It offers VPL and VPL 3 icon languages, Scratch, Blockly, and Aseba text code. Python is listed as coming soon. A Thymio Suite Mobile app for iOS and Android works with the computer version over the same Wi-Fi network.

Benefits

For students

  • Students can start with icons and move up to blocks and text.
  • Students see the robot respond to the program they build.
  • Students can use the mobile app on a tablet.

For teachers

  • One program supports many skill levels.
  • Aseba text code includes live monitoring.
  • The software comes in English, French, German, and Italian.

For schools

  • The privacy policy calls downloads free.
  • A Thymio robot is required.
  • The software runs locally and needs the internet only at setup.

Getting started checklist

Where is the AI in this product?

Thymio Suite has no AI. It sends the program that students build to the robot. Students build skills in sequencing and logic.

Privacy and safety

No account is needed. The Mobsya privacy policy says Thymio Suite downloads collect no identifying data beyond what you send voluntarily. It says the applications run only on your computer or tablet and Mobsya systems process no usage or connection data. The mobile app works with the computer version over the same Wi-Fi network. The internet is used at setup. Check which desktop operating systems are supported because the page read does not list them.

How this can be used for Computer Science
  1. Build a VPL program that changes the robot's color when a button is touched.
  2. Rebuild the same program in Scratch and compare the two.
  3. Try a Blockly program that drives the robot forward and back.
  4. Read an Aseba text program and explain each line.
  5. Debug a program that makes the robot react to the wrong sensor.
How this can be used for Engineering and Design
  1. Use the sensors to build a robot that avoids a wall.
  2. Test how the robot reacts to light and touch.
  3. Record sensor readings during a run.
  4. Plan a robot task and test it.
  5. Improve a program after a failed test.
