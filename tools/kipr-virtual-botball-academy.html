KIPR Virtual Botball Academy

A browser based 3D robot simulator with hundreds of coding activities.

FREEComputingRoboticsUnverified

The privacy details for this item are unverified. Check which tools and accounts students will use before class.

Overview

Virtual Botball Academy is a web-based STEM and coding program from the nonprofit KIPR. Students use a 3D robot simulator and a virtual IDE in the browser, with no software to download. KIPR says the program offers hundreds of open-ended activities with built-in performance-based assessments. The page says no previous robot or coding experience is needed.

Benefits

For students

  • Students code a simulated robot with no hardware.
  • Students work through open-ended activities.
  • Students use the same tools on computers, tablets, Chromebooks, iPads and phones.

For teachers

  • Built-in assessments check student performance.
  • KIPR offers free training workshops for teachers and students.
  • The activities align to CSTA, ISTE, NGSS and CCSS.

For schools

  • The page lists the workshops as free, but the cost of the simulator and curriculum is not stated.
  • Students need only a browser.
  • State standards can be added by emailing simulator@kipr.org.

Getting started checklist

Where is the AI in this product?

The materials describe no AI. The simulated robot follows the code that students write. Students build skills in sensors, logic and testing.

Privacy and safety

The simulator needs the internet every time. The official page shows only a cookie consent notice and no privacy policy text. The public source repo shows Firebase authentication, a KIPR database service, Mailgun email, and files named parentalConsent and classrooms. That suggests accounts and classroom features exist. The README does not explain what student data is stored or where. A teacher should ask KIPR how student accounts and data are handled before class. A teacher should also test the simulator on school devices.

How this can be used for Computer Science
  1. Open the simulator and write a program that drives the robot forward.
  2. Use a sensor to make the robot stop at a wall.
  3. Add a loop that repeats a task.
  4. Fix a program that fails an activity check.
  5. Explain a finished program to a partner.
How this can be used for Engineering and Design
  1. Choose a challenge and plan how the robot should solve it.
  2. Test two approaches and compare the results.
  3. Tune a speed value and record the outcome.
  4. Redesign a program after a failed run.
  5. Present the best solution to the class.
