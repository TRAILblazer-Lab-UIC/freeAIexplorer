Barnabas-Bot

An open source classroom robot with a 3D-printed body and Arduino controller.

ComputingRobotics

Overview

Barnabas-Bot is an open source educational robotics project for elementary and middle school students. Students build a robot with a 3D-printable body and an Arduino-compatible controller called the Barnabas Noggin. It comes with a free teacher curriculum and sample engineering notebooks. Students assemble the robot and program its servos.

Benefits

For students

  • Students build a whole robot from printed parts and a controller.
  • Students program three servo motors, a buzzer and an LED.
  • Students keep engineering notebooks as they work.

For teachers

  • The curriculum and sample notebooks are free.
  • A quick-build version and a full class version both exist.
  • Teachers can use the Arduino IDE or a block tool such as ArduBlock.

For schools

  • The project is open source for both code and hardware.
  • No account is needed and the internet is needed only at setup.
  • The project page lists no price. The robot needs a 3D printer or purchased parts.

Getting started checklist

Where is the AI in this product?

Barnabas-Bot has no AI. The robot runs the program that students load on it. Students build skills in sequencing and logic as they plan servo movements.

Privacy and safety

No account is needed and the robot is a stand alone Arduino based device. The research found no documented data collection and reviewed no privacy policy. The internet is needed to download software. A teacher should note that the project page was last updated in 2017. A teacher should also test every part before class.

Ideas by subject

How this can be used for Engineering and Design
  1. Assemble the robot body and note each step in an engineering notebook.
  2. Test the quick-build version against the full version and compare the two.
  3. Redesign one printed part and explain the change.
  4. Fix a servo that moves in the wrong direction and record the repair.
  5. Present the finished robot and describe what each part does.
How this can be used for Computer Science
  1. Program the servos to move in a set order using the Arduino IDE.
  2. Make the buzzer play a short signal at the end of a routine.
  3. Use ArduBlock to build a program with blocks and compare it to written code.
  4. Add an LED signal to show each stage of a routine.
  5. Debug a program that a partner wrote and list the fixes.
