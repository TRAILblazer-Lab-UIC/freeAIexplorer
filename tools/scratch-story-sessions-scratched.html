Scratch Story Sessions (ScratchEd)

An introductory Scratch curriculum for building non-linear stories.

FREEComputingUnverified

The privacy details for this item are unverified. Check which tools and accounts students will use before class.

Overview

Scratch Story Sessions is an introductory Scratch storytelling curriculum. Ji-Sun Ham remixed it from the Creative Computing guide for a Harvard course taught by Karen Brennan. Students explore non-linear stories through non-linear programming. The sessions include MetaMoments reflection prompts and end with handouts and examples.

Benefits

For students

  • Students build stories that branch in more than one direction.
  • Students pause to reflect on their work with MetaMoments prompts.
  • Students may find it helpful as English language learners, as the author suggests.

For teachers

  • The curriculum is one PDF with sessions, handouts, and examples.
  • It is listed for elementary, middle, and high school.
  • Setup takes only minutes.

For schools

  • The curriculum is free.
  • Students use Scratch in a browser.
  • No IT involvement is listed.

Getting started checklist

Where is the AI in this product?

This curriculum has no AI. Students build sequencing and logic skills with Scratch blocks. They plan how a story branches and what happens at each choice.

Privacy and safety

The page does not state accounts or data handling. The research lists an account as optional and the internet as needed at all times for the browser version. The Scratch offline editor can save projects locally, but the research did not check this on the page. A teacher should read the Scratch privacy policy and check whether students will save projects online.

Ideas by subject

Select a subject to see five classroom ideas.

How this can be used for English and Language Arts
  1. Plan a story with two different endings and draw a map of the choices.
  2. Write the text for each scene and read it aloud to a partner.
  3. Build the story in Scratch with a click that chooses the next scene.
  4. Trade stories with a classmate and describe which path was the most surprising.
  5. Write a short reflection using a MetaMoments prompt.
How this can be used for Computer Science
  1. Build a project with two scenes and a block that moves between them.
  2. Use a broadcast block to send the story to a new scene.
  3. Fix a story path that leads nowhere.
  4. Remix a classmate's story and add one new branch.
  5. Explain to the class how the program picks the next scene.
