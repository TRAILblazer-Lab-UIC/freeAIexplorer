TKI Computational thinking unplugged (New Zealand)

Unplugged unit plans from CS Unplugged, adapted for the New Zealand curriculum.

FREEComputingUnpluggedNo device needed

Overview

TKI hosts unit plans based on CS Unplugged from the University of Canterbury. The units are adapted for the New Zealand digital technologies curriculum. Search coverage says the set has nine units on topics such as binary numbers, error correction and search algorithms. It also lists sorting networks and kidbots. The TKI page returned an error when checked. These details come from search snippets.

Benefits

For students

  • Students learn computing ideas through games and movement.
  • Students explore binary numbers, searching and sorting.

For teachers

Getting started checklist

Where is the AI in this product?

These units have no AI. They build an AI-related skill, which is understanding how data is stored and searched. Binary numbers and search algorithms are core ideas behind how computers handle data.

How this can be used for Computer Science
  1. Play a search algorithm game with cards and describe the steps that found the answer.
  2. Use a sorting network on the floor and walk through it with a partner.
  3. Send a message in binary using on and off cards.
  4. Check a message for a mistake using an error correction trick.
  5. Act as a kidbot and follow a classmate's commands.
How this can be used for Math
  1. Count in binary with a set of cards.
  2. Compare a sorting network with a number line and put numbers in order.
  3. Find the missing card in a binary pattern.
  4. Count the steps each search method needs and compare the totals.
  5. Make a chart of numbers and their binary forms.
