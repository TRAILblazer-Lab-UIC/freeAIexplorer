Kitronik LAB:bit

A classroom board for the micro:bit with seven MakeCode tutorials.

ComputingRoboticsStays on the device

Overview

LAB:bit is a classroom platform board that a BBC micro:bit plugs into. Kitronik says it is designed for delivering computing to students aged 8 and up. It comes with a printed getting started guide and custom MakeCode blocks for inputs, traffic light, dice, colour lights and motor. Seven online MakeCode tutorials cover a switch, a dice, ZIP LED colour, traffic lights, motor speed control, microphone sound input and an ultrasonic parking sensor.

Benefits

For students

  • Students build small circuits such as a traffic light and a parking sensor.
  • Students follow seven step by step tutorials.
  • Students use custom blocks made for the board.

For teachers

  • A printed guide and online tutorials give a clear path.
  • The board is sold singly or as a lesson in a box classroom set.

Getting started checklist

Where is the AI in this product?

LAB:bit has no AI. The board follows the code students write. Students build skills in inputs, sensors and logic. The microphone and ultrasonic tutorials show how a device reads the world and reacts.

Privacy and safety

No account is needed. The board runs programs on the micro:bit with no network, and programming uses the MakeCode web editor. The privacy terms of MakeCode belong to Microsoft and were not reviewed. The research fetched no Kitronik privacy policy. The address tried returned a 404. A teacher should check the MakeCode terms. A teacher should also check the batteries before each class.

How this can be used for Computer Science
  1. Follow the switch tutorial and make an LED turn on with a button.
  2. Build the dice tutorial and run it ten times.
  3. Control ZIP LED colours with code.
  4. Use the microphone tutorial to react to a loud sound.
  5. Adjust a motor speed and describe the change.
How this can be used for Engineering and Design
  1. Build the traffic light circuit and test the light order.
  2. Build the ultrasonic parking sensor and test it at several distances.
  3. Compare how the motor speeds differ.
  4. Design a use for the board at school.
  5. Write a short report on how the circuit parts work together.
