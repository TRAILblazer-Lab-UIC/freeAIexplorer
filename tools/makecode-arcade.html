MakeCode Arcade

A free browser editor for making retro arcade games with blocks or JavaScript.

FREEComputingUnverified

The privacy details for this item are unverified. Check which tools and accounts students will use before class.

Overview

MakeCode Arcade is a Microsoft editor for making retro arcade games. Students use blocks or JavaScript and test the game in an in-browser simulator. The lessons page lists three game lessons and links to CS Intro 1, 2, and 3 courses. The project is open source under the MIT license.

Benefits

For students

  • Students make a game they can play right away.
  • Students can start with blocks and move to JavaScript.
  • Students draw their own sprites and backgrounds.

For teachers

  • The lessons Cherry Pickr, Dance Party, and BlockOut give a start.
  • CS Intro courses offer a longer path.
  • The editor opens in minutes with no install.

For schools

  • The tool is free.
  • It runs in a browser on Chromebooks, Windows, macOS, and Linux.
  • An optional handheld arcade device is sold separately.

Getting started checklist

Where is the AI in this product?

MakeCode Arcade has no AI. The vendor describes no AI features. Students write code that follows rules. They build skills in sequencing, logic, and events.

Privacy and safety

The research could not confirm the account and privacy claims. Discovery notes say projects save in local browser storage, sign in is optional for cloud saves, and offline use is possible. The official page text did not confirm this. The offline app page is inconsistent about whether a download exists. The privacy link redirects to the Microsoft privacy statement, which the research did not read. A teacher should check the Microsoft privacy terms and where projects are saved.

How this can be used for Computer Science
  1. Build the Cherry Pickr game and describe each block.
  2. Add a score that goes up when a player collects an item.
  3. Create a second level with a new rule.
  4. Find a bug in a classmate's game and report it.
  5. Switch a block program to JavaScript and compare the two views.
How this can be used for Visual Arts
  1. Draw a sprite for a hero with a small pixel grid.
  2. Design a background tile that repeats across the screen.
  3. Choose a color palette that suits the mood of a game.
  4. Animate a character with two or more frames.
  5. Share a game and explain the art choices.
