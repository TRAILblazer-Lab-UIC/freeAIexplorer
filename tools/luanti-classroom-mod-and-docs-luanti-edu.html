Luanti Classroom mod and docs (luanti edu)

A teacher guide and classroom mod for using the Luanti block-world game with students.

FREEComputingStays on a school server

Overview

Luanti edu is a work-in-progress guide for teachers, youth workers, and social workers who use the open source Luanti game engine with children. It covers what Luanti offers, how to add mods, how to set up a server, and how to supervise young players. A separate community Classroom mod lets a teacher move players and grant or remove privileges. Students build and explore in shared block worlds.

Benefits

For students

  • Students build together in a shared 3D world.
  • Students can write their own mods with the scripting system.
  • Students explore real projects such as heritage and urban planning.

For teachers

  • The guide explains how to run Luanti with children.
  • The Classroom mod helps a teacher move players and manage privileges.
  • Teachers report setting rules each session, such as turning off fire and lava.

For schools

  • The engine and mods are free. BLOCKALOT hosted worlds are currently free per the education page.
  • Luanti runs on low-spec hardware.
  • A school server is optional for a LAN. IT approval for installs is likely needed.

Getting started checklist

Where is the AI in this product?

Luanti has no AI. Students use a scripting system to write mods. They build skills in logic and sequencing as they code how blocks and players behave.

Privacy and safety

The server may run on the school network, and the materials describe no account need. A school hosted server keeps world data on the school's own machine. The education page links a privacy policy, but the linked page returned a 404 and was not read. The docs say nothing about accounts or student data. A separate hosted BLOCKALOT dashboard is a vendor option that the research did not review. The Classroom mod itself was not found on a fetched page. A teacher should supervise players, set rules each session, and check which server hosts the world.

Ideas by subject

Select a subject to see five classroom ideas.

How this can be used for Social Studies
  1. Rebuild a local historic site in a shared world and add a short sign about its history.
  2. Plan a new park for the town and compare designs with classmates.
  3. Build a timeline of a historical period with one building for each era.
  4. Map a neighborhood and mark places that matter to the community.
  5. Present a world tour to the class and explain the design choices.
How this can be used for Computer Science
  1. Read a simple mod and describe what each part does.
  2. Change one value in a mod and observe the result.
  3. Write a small mod that adds a new block.
  4. Test a classmate's mod and report any bugs.
  5. Use the Classroom mod ideas to plan rules for a safe shared world.
