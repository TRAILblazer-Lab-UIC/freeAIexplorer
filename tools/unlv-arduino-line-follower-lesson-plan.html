UNLV Arduino line follower lesson plan

A six-part plan for building an Arduino robot that follows a black line.

FREERoboticsUnverified

The privacy details for this item are unverified. Check which tools and accounts students will use before class.

Overview

Students build and program an Arduino robot that follows a black line using two infrared sensors. A later part adds an ultrasonic sensor for obstacle avoidance. The kit is a laser cut robot car from Wrebotics with an Arduino board, a motor shield, two motors, LEDs, and a portable battery. The plan has six parts from introduction through assembly, pseudocode, testing, and a team presentation.

Benefits

For students

  • Students assemble a robot car and program it with sensors.
  • Students write pseudocode before code.
  • Students present a video demo of their robot.

  • It lists the CTE pathway Energy, Environment, and Development.

Ideas by subject

Select a subject to see five classroom ideas.

How this can be used for Engineering and Design
  1. Assemble the laser cut car and mount the sensors.
  2. Test the car on a black line track and record the results.
  3. Adjust sensor positions and compare the runs.
  4. Add the ultrasonic sensor and test obstacle avoidance.
  5. Present a video demo and explain the design.
How this can be used for Science
  1. Explain how an infrared sensor tells black from white.
  2. Test the sensor on different colors of paper.
  3. Record the readings in a table.
  4. Graph the results and look for a pattern.
  5. Predict how room light might change the readings.
How this can be used for Computer Science
  1. Write pseudocode for following a line.
  2. Turn the pseudocode into Arduino code.
  3. Test the code and fix steps that fail.
  4. Add a rule that stops the car at an obstacle.
  5. Explain your program to another team.
