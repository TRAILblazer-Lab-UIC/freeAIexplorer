Twin Science Autonomous Vehicle Kit

A kit for building a self-driving car and coding it from a phone or tablet.

AIComputingRoboticsUnverified

The privacy details for this item are unverified. Check which tools and accounts students will use before class.

Overview

This DIY kit lets children build and program a self-driving car. Retailer listings describe an Arduino-based Twin coding module, DC motors, a proximity sensor, and an ultrasonic sensor. Students program it in the Twin Code Lab app over Bluetooth. Several listings give ages 8 to 13.

For students

  • Students build a car and code it to drive on its own.

How this can be used for Computer Science
  1. Write a program in the Twin Code Lab app that drives the car forward and turns.
  2. Use the proximity sensor to make the car stop before a wall.
  3. Try the Coding and AIoT mode and describe what it adds.
  4. Debug a program that makes the car drive in a circle.
  5. Plan the steps a self-driving car follows to stay on a line.
How this can be used for Engineering and Design
  1. Build the car from the kit and test each motor.
  2. Test the ultrasonic sensor at three distances and record the readings.
  3. Design a track with turns for the car to follow.
  4. Adjust the car's speed and observe how it affects line tracking.
  5. Sketch a better design for the car body.
