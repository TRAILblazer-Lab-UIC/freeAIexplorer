Model AI Assignments: A Fresh Squeeze on Data

A grade 3 to 5 lesson on data bias using a lemonade stand story.

FREEAIUnverifiedGood for AI beginners

The privacy details for this item are unverified. Check which tools and accounts students will use before class.

Overview

A Fresh Squeeze on Data is a lesson for grades 3 to 5 about data bias. Students read an interactive story about a girl who runs a lemonade stand with her data scientist mother. They then do a Candy Stand activity and a Selecting a Pet for the Family activity. The lesson takes 90 minutes, or two 45-minute sessions.

Benefits

For students

  • Students learn about data bias through a friendly story.
  • Students see how training data shapes what a model learns.
  • Students make charts to look at data in the Candy Stand activity.

For teachers

  • The lesson plan and story come as PDFs.
  • The teacher trains the Teachable Machine model beforehand. Class time stays simple.
  • Each activity takes about 35 minutes.

For schools

  • The lesson is free to download.
  • It runs in a web browser and needs an internet connection.
  • IT involvement is low, but the teacher needs a Teachable Machine setup ahead of time.

Getting started checklist

Where is the AI in this product?

The AI is a Teachable Machine model that the teacher trains before class. It runs in the web browser. Students see how the examples used for training change what the model says. They use that idea to talk about fairness in data.

Privacy and safety

The materials do not state whether accounts are needed or where data goes. The internet is needed during the lesson. Teachable Machine is a Google web tool and Google Docs needs a Google account. The research did not review how either one handles data. A teacher should check the privacy terms for both before class.

Ideas by subject

Select a subject to see five classroom ideas.

How this can be used for Computer Science
  1. Listen to the story and name the data the girl and her mother collect.
  2. Test the teacher's model and describe a case where it gives a poor answer.
  3. Explain how a different set of training examples might change the result.
  4. Sort candy by a rule and discuss when a rule is unfair.
  5. Choose a pet for the family with a data table and explain what data was missing.
How this can be used for Math
  1. Count the candy sold at the Candy Stand and record the numbers in a table.
  2. Make a chart in Google Docs to show which candy sold best.
  3. Compare two charts and say which one shows the data more clearly.
  4. Find a missing group in the data and explain how it changes the totals.
  5. Write a sentence that explains what a chart does and does not show.
