MakeCode Science Experiments course

Ten micro:bit experiment series for collecting and graphing sensor data.

FREEComputingStays on the device

Overview

This MakeCode course by Carl Lyman and the Utah Coding Project is for middle school and early high school. It has ten lesson series that combine science and computing. Series include Data Collection Methods, Temperature Data, Soil Moisture Tester, Rocket Acceleration, Egg Drop Experiment, and Spoon Race. Students record measurements with a micro:bit, graph them, and download the data to a spreadsheet.

Benefits

For students

  • Students run real experiments and collect data.
  • Students graph results in MakeCode.
  • Students move their data into a spreadsheet.

For teachers

  • Each lesson has Overview, Setup and procedure, and Resources pages.
  • The course covers observation, measurement, and data analysis.
  • Some older lessons targeted the Windows 10 app. Check each one.

For schools

  • The course is free. Micro:bit boards and experiment materials cost extra.
  • Data stays on the device.
  • A teacher can usually do the setup.

Getting started checklist

Where is the AI in this product?

This course has no AI. Students program a sensor to record data. They build skills in data collection, graphing, and pattern spotting.

Privacy and safety

No account is needed. The micro:bit records readings on the device. The page says students may download data to a spreadsheet program. The internet is used for setup. The research found no privacy policy. A teacher should check where students save data files and review safety for experiments such as the Egg Drop.

How this can be used for Science
  1. Record the temperature of a room over a day and graph it.
  2. Build the Soil Moisture Tester and compare two soil samples.
  3. Measure the acceleration of a model rocket launch.
  4. Test the Egg Drop and record what the sensor shows.
  5. Write a conclusion that uses the graph as evidence.
How this can be used for Computer Science
  1. Write a program that logs a reading each second.
  2. Use a variable to store the highest value.
  3. Change the sample rate and compare the results.
  4. Fix a program that records wrong data.
  5. Explain how the micro:bit senses the world.
How this can be used for Math
  1. Graph a data set and describe the shape.
  2. Find the mean of a set of readings.
  3. Compare two data sets in a spreadsheet.
  4. Make a chart in a spreadsheet and label each axis.
  5. Predict the next reading from a pattern.
