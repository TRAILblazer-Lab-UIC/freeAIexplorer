FaceDemo

A Carnegie Mellon browser demo that shows how a network detects faces.

FREEAIStays on the deviceGood for AI beginners

Overview

FaceDemo is a browser demo from Carnegie Mellon that runs the TinyYoloV2 face detection network on webcam or image input. It has an Image Investigation Mode and a Kernel Investigation Mode. They let students examine the first and last stages of a convolutional neural network. The page links to a tutorial and experiments. It builds on the face-api.js demo by Vincent Muehler.

Benefits

For students

  • Students see inside the stages of a face detector.
  • Students try live webcam input or still images.
  • Students follow a tutorial with experiments.

For teachers

  • The AI4K12 group developed activity guides for the demo.
  • The demo opens in a browser with no install.
  • It is listed for grades 3 to 12.

For schools

  • The demo is free.
  • Detection runs in the browser on the device.
  • A webcam is optional.

Getting started checklist

Where is the AI in this product?

The AI is a convolutional neural network called TinyYoloV2 that detects faces. It runs in the browser on the local device. Students give it an image or webcam view and see where it finds a face. They then look at the early and late stages of the network to see what it notices.

Privacy and safety

No account is needed and the page needs an internet connection to load. The page's privacy notice says all input is processed in the browser and no images leave the computer. The research did not test that claim. The demo can use a webcam or an image. A teacher should consider using sample images in place of live webcam views of students.

How this can be used for Computer Science
  1. Open the Part 1 activity and describe what the first stage of the network detects.
  2. Try several images and record when the detector finds the face and when it misses.
  3. Use Kernel Investigation Mode to describe what a kernel highlights.
  4. Compare the first and last stages and explain what changed.
  5. Test a picture with part of the face covered and explain the result.
