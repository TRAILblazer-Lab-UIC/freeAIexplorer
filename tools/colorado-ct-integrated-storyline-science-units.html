Colorado CT-integrated storyline science units

Four middle school science units where students code micro:bit sensors.

FREEComputingUnverified

The privacy details for this item are unverified. Check which tools and accounts students will use before class.

Overview

These four units come from CU Boulder SchoolWide Labs. They bring computational thinking into NGSS-aligned storylines. The units are Sensor Immersion, Mold, Maglev Trains, and Ecosystems with urban farming and composting. Students program micro:bit boards with gator:bit sensors in MakeCode to collect data about what they study.

Benefits

For students

  • Students collect real data with sensors.
  • Students use code to study a science question.
  • Students can code with blocks or text.

For teachers

  • The units were co-designed with middle school teachers, mainly in Denver Public Schools.
  • The units can be used in any order.
  • Unit lengths run from 1 to 3 weeks.

For schools

  • Unit materials are free to view.
  • Sensor kits must be bought, and no price is given on the page.
  • Plan about one kit for every four students or fewer.

Getting started checklist

Where is the AI in this product?

This curriculum has no AI. It builds skills in data and sensors. Students write code to read measurements and use the data to support a claim.

Privacy and safety

The materials do not state which accounts students need, whether the internet is required, or where student work goes. Students code in MakeCode, which is an online editor. Sensor data stays on the micro:bit unless the teacher exports it, but the unit pages do not discuss accounts or student data and the research did not confirm this. A teacher should check the MakeCode terms and decide whether students will save projects.

How this can be used for Science
  1. Investigate the conditions that help mold grow with sensor data.
  2. Study how maglev trains float and move in the Forces at a Distance unit.
  3. Collect sensor data in the Sensor Immersion unit and describe a pattern.
  4. Measure conditions in a composting system for the Ecosystems unit.
  5. Use data to support a claim and share it with the class.
How this can be used for Computer Science
  1. Program a micro:bit to read a sensor value.
  2. Show a sensor reading on the display.
  3. Use a variable to store a measurement.
  4. Debug a program that reports the wrong reading.
  5. Switch a block program to text and compare the two.
