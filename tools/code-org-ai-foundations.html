Code.org AI Foundations

A free high school course on AI literacy, data, cybersecurity, and programming.

AIComputingGood for AI beginners

Overview

AI Foundations is a free high school course for grades 9 to 12. It runs as a 180 period year, a semester, or single units. Semester 1 covers AI literacy, how the internet works, cybersecurity, and data. Semester 2 teaches JavaScript and interactive web apps. Students use Web Lab, Python Lab, and AI Chat Lab.

Benefits

For students

  • Students build AI literacy and programming skills in one course.
  • Students write code in Python and JavaScript.
  • Students use AI Chat Lab to explore and customize a chatbot.

For teachers

  • Teachers get lesson plans, videos, slides, and assessments.
  • Teachers can take self-paced professional development.
  • State-aligned versions exist for Idaho and Indiana.

For schools

  • The course is described as 100 percent free.
  • It runs in a browser.
  • IT will likely need to approve Code.org and the student accounts.

Getting started checklist

Where is the AI in this product?

Students learn AI literacy, programming with AI support, and chatbot customization. AI Chat Lab is available only through the curriculum. The AI runs in the vendor's cloud. Students write prompts and code, test what the chatbot does, and adjust their work.

Privacy and safety

The course page says a CodeAI account is needed for lesson materials and progress tracking, and the internet is needed at all times. The vendor collects account, progress, and project data. The policy says it does not sell personal data or show ads. It says it uses third party language model providers and does not describe their retention. AI Chat Lab sends what students type to the vendor cloud. A teacher should review the CodeAI privacy terms with the school. A teacher should also set rules for what students type into AI Chat Lab.

How this can be used for Computer Science
  1. Work through Problem Solving with AI and write down one step where the AI helped and one where it failed.
  2. Write a Python program in Python Lab that uses a list.
  3. Customize a chatbot in AI Chat Lab and test it with five questions.
  4. Build an interactive web app in JavaScript.
  5. Trace how a message travels across the internet and draw the steps.
