Parallax cyber:bot Sumo Contests course

A two-level micro:bit course for building sumo-style robot contests.

FREEComputingRoboticsUnverified

The privacy details for this item are unverified. Check which tools and accounts students will use before class.

Overview

This course has students build sumo-style contests with the cyber:bot robot and a micro:bit. Search results describe two levels with 11 lessons. Level 1 uses micro:bit tilt controllers and Level 2 uses sensors to detect an opponent and the ring border. Students should first finish the micro:bit Python and cyber:bot build tutorials. The course page itself returned no content when fetched.

Benefits

For students

  • Students compete in a friendly robot contest.
  • Students move from remote control to autonomous robots.
  • Students write Python for the micro:bit.

For teachers

  • The lessons are described as free.
  • A MakeCode version of the course also exists.
  • The two levels give a clear path.

For schools

  • Each team needs a cyber:bot kit with a micro:bit.
  • Level 2 needs a QTI line follower kit per a search snippet.
  • Setup can take days.

How this can be used for Computer Science
  1. Write micro:bit Python that sends tilt data by radio.
  2. Code the robot to turn when the controller tilts.
  3. Use a sensor reading to detect an opponent.
  4. Add a rule that keeps the robot inside the ring border.
  5. Compare the Python code with the MakeCode version.
How this can be used for Engineering and Design
  1. Build the cyber:bot and test how it drives.
  2. Tune the speed and turning so the robot pushes well.
  3. Test the border sensors and record when they fail.
  4. Change the design after a match and describe why.
  5. Hold a class contest and write a short review.
