BlocksCAD

A web block coding tool for building 3D models, with a teacher dashboard.

ComputingSends student data to a company

Overview

BlocksCAD is a web-based block coding tool for creating 3D models. It teaches K-12 students blocks-based coding, math reasoning, and 3D design. A registered 501(c)(3) nonprofit based in Brookline, Massachusetts now runs it. Educators get a teacher dashboard with standards-aligned lesson plans and class management.

Benefits

For students

  • Students build 3D shapes by snapping blocks together.
  • Students practice math reasoning with real models.
  • Students can create basic accounts and save their projects.

For teachers

  • The teacher dashboard includes lesson plans and class management.
  • Schools or districts can use access codes at registration.
  • An applied engineering teacher reviewed the classroom features on MatterHackers.

For schools

  • A basic account is free, and the educator account has a 30-day free trial.
  • Paid school licenses exist, but prices are not listed.
  • It runs in a browser, and Chromebooks are listed as supported.

Getting started checklist

Where is the AI in this product?

BlocksCAD has no AI. It builds the skills of sequencing and logic through blocks that make 3D shapes. Students also practice spatial reasoning.

Privacy and safety

BlocksCAD stores student work on the vendor cloud, and the internet is needed all the time. Accounts are optional but are needed to save work and join classes. The site collects a username or display name, country, birth month and year, gender, email, projects, comments, forum posts, IP address, and device and browser data. The policy says it does not sell personal information. It also says it uses Google Analytics, shares data with service providers, and uses de-identified data for research. Full deletion requires an email to the vendor. A teacher should read the policy and check the parent email rule for students under 14.

Ideas by subject

Select a subject to see five classroom ideas.

How this can be used for Engineering and Design
  1. Design a simple part, such as a bracket, and check its size with blocks.
  2. Build a small house model from shapes and measure each part.
  3. Change one number in a design and describe the result.
  4. Redesign a model after peer feedback.
  5. Prepare a model for a class showcase and explain the design steps.
How this can be used for Math
  1. Build a cube and a prism and compare their volumes.
  2. Use a variable to scale a model and record the change.
  3. Use coordinates to place shapes in three dimensions.
  4. Make a pattern with a repeat block and count the pieces.
  5. Write a rule for how a model grows as a number changes.
How this can be used for Computer Science
  1. Build a shape with blocks and explain the order of the blocks.
  2. Use a loop to repeat a shape around a circle.
  3. Write a variable that controls the size of a model.
  4. Debug a model that looks wrong.
  5. Trade models with a partner and describe the code in words.
