Unplugged Facial Recognition Game (AAAI 2024)

A middle school board game where players trace face features and guess the hidden face.

AIUnpluggedGood for AI beginners

Overview

Guess Whose Face is an unplugged board game on facial recognition. It is described in an AAAI 2024 paper by Lim, Min, Vandenberg, Cateté, and Mott. One student traces facial features from a familiar face card. Other students try to identify the hidden face.

Benefits

For students

  • Students learn that a face can be described as a set of features.
  • Students practice choosing features that help tell faces apart.
  • Students talk about how faces are represented.

For teachers

  • The game targets the AI4K12 Representation and Reasoning big idea.
  • It was piloted at a summer camp for rural middle school students.
  • The related Card Craft Studio toolkit lets educators customize cards.

For schools

  • The cost is not stated in the sources read.
  • The game is on paper and few devices are needed.
  • No accounts or student data are involved.

Getting started checklist

Where is the AI in this product?

The game teaches facial recognition and feature representation. It runs on paper with no computer. Students trace features from a card and others use those features to find the face. They then see how a system can reduce a face to a few data points.

Privacy and safety

The game is on paper and no student data is collected. No accounts are needed. A teacher should check what faces appear on the cards. A teacher should also avoid using photos of real students without permission.

How this can be used for Computer Science
  1. Trace dot-based features from a face card and share them with a partner.
  2. Identify the hidden face from the features alone.
  3. Choose which features give the most clues and explain why.
  4. Compare how many features players need to identify a face.
  5. Discuss how a computer might represent a face as numbers.
