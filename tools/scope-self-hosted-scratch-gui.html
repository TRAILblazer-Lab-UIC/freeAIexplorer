Scope (self-hosted scratch-gui)

A tool described as hosting a local copy of the Scratch editor.

Overview

Scope is described as a tool that runs a hosted copy of scratch-gui, scratch-www, or hackercat-www on your own system. HackerCat is a mod of Scratch with custom extensions and features. It would suit a school with a server administrator. Students would use the Scratch block editor from that server.

Benefits

For students

  • Students would use the familiar Scratch block editor.
  • Students could build stories, games, and animations with blocks.
  • Students could try the HackerCat mod if the school hosts it.

For teachers

  • The editor would match the standard Scratch tools.
  • The vendor does not say how teachers manage classes.
  • The setup steps could not be read. Plan extra time.

For schools

  • The tool is listed as free, but this is not confirmed.
  • A school would run it on its own server.
  • A server administrator would need to install and maintain it.

Getting started checklist

Where is the AI in this product?

The vendor does not describe any AI. The tool hosts a block editor. Students would build sequencing and logic skills with Scratch blocks.

Privacy and safety

The tool would run on a school server. The materials do not state whether accounts are needed or what data is collected. Self hosting would keep data on the host machine, but the research could not confirm this. The project repository returned an error and may be gone. A teacher should ask IT to check that the project still exists and review the install, accounts and data flow before students use it.
