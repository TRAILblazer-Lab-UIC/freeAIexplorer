IoT4schools Pedometer projects teacher guidelines

Teacher guidelines for building a step counting pedometer with a micro:bit or Pico W.

Computing

The privacy details for this item are unverified. Check which tools and accounts students will use before class.

Overview

This is a set of teacher guidelines for a pedometer project from the Erasmus+ IoT4schools project. It is one of six interdisciplinary IoT projects. Search summaries say students use the micro:bit accelerometer to count steps and distance. A Raspberry Pi Pico W version targets ages 15-18.

Benefits

For students

  • Students build a working device that counts their steps.
  • Students work in teams and move from building to testing to improving.
  • Students see how a sensor reading becomes a number they can use.

For teachers

  • The guidelines suggest clear stages, from building a pedometer to testing and optimization.
  • Teacher workshops built a pedometer with micro:bit in early 2025.
  • The project links physics and computing in one activity.

For schools

  • The guide and the teacher workshops are free according to search summaries.
  • Board prices were not checked. Confirm the cost of micro:bit or Pico W boards.
  • A teacher will need to install and prepare the programming environment.

Getting started checklist

Where is the AI in this product?

The vendor does not describe any AI in this project. The pedometer builds sensor and data skills. Students turn accelerometer readings into a step count and test how accurate it is.

Privacy and safety

The research did not read the guideline text, and the page that hosts it failed certificate checks. The materials do not state which tools or accounts students need. Step counts on a micro:bit usually stay on the board unless a network feature is added. That was not confirmed in the guidelines. A teacher should check the programming environment for account rules. A teacher should also decide how students will share step data with each other.

Ideas by subject

How this can be used for Computer Science
  1. Program a micro:bit to count a step each time the accelerometer detects a shake.
  2. Add a display that shows the step count.
  3. Convert steps to distance using a stride length that you measure.
  4. Add a button that resets the count.
  5. Review a partner's code and suggest one improvement.
How this can be used for Science
  1. Explain how an accelerometer senses movement.
  2. Record readings while walking and while standing still, then compare them.
  3. Walk a known distance and compare the pedometer count to a hand count.
  4. Test where on the body the board works best.
  5. Graph the results and write a short conclusion.
How this can be used for Engineering and Design
  1. Build a pedometer in teams with a clear plan.
  2. Test the pedometer on a measured walk and record the errors.
  3. Change the code or the way the board is worn to cut the errors.
  4. Compare team designs and pick the most accurate one.
  5. Present the final design and explain each change.
