Garden TOOLS Project (University of Nebraska-Lincoln)

Grades 3 to 5 lessons that use micro:bits and sensors in school gardens.

Computing

The privacy details for this item are unverified. Check which tools and accounts students will use before class.

Overview

Garden TOOLS stands for Technology Opportunities in Outdoor Learning Spaces. It is a lesson set for grades 3 to 5 on agricultural technology and engineering. Students code BBC micro:bits with environmental sensors in school gardens and analyze the data.

Benefits

For students

  • Students program real devices with blocks in MakeCode.
  • Students collect real data such as soil moisture in a garden.
  • Students use the data to plan an irrigation schedule.

For teachers

  • The site offers a lesson set as a Word or Google Drive document.
  • Coding guides, finished code, video tutorials, and project cards are included.
  • Professional development modules help teachers prepare.

For schools

  • The lessons are free to download.
  • The micro:bit and sensor costs are not stated. A school should price them first.
  • The standards listed include NGSS 3-LS4-4, 3-5-ETS1-2, and 4-PS3-2.

Getting started checklist

Where is the AI in this product?

This curriculum has no AI. It builds sensor and data skills. Students collect readings and use them to make decisions. The code runs on the micro:bit and the editor runs in a browser.

Privacy and safety

Sensor readings stay on the micro:bit. The pages do not say whether MakeCode or Google Drive accounts are needed. They also do not say what data is collected or where saved projects go. A teacher should check which tools and accounts students need for MakeCode and for saving projects. A teacher should also plan for safe handling of the sensors outdoors.

Ideas by subject

How this can be used for Science
  1. Program a micro:bit to monitor soil moisture and set an irrigation schedule.
  2. Record sensor readings for a week and graph the results.
  3. Compare readings from sunny and shady parts of the garden.
  4. Write a claim about what plants need and support it with data.
  5. Predict how rain will change the readings, then check.
How this can be used for Engineering and Design
  1. Design a simple watering plan and list the sensor needs.
  2. Test a micro:bit setup and fix any problem found.
  3. Draw a diagram of how the sensor, battery, and micro:bit connect.
  4. Improve a first design after a trial and describe the change.
  5. Present the final design to the class.
How this can be used for Computer Science
  1. Build a block program that reads a sensor value.
  2. Add a condition that shows a message when the soil is dry.
  3. Use the finished code as a guide and explain each block.
  4. Debug a program that gives a wrong reading.
  5. Record data in a variable and display it on the micro:bit.
