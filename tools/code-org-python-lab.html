Code.org Python Lab

A browser Python environment for grades 9 to 12 with data libraries.

FREEAIComputingSends student data to a company

Overview

Python Lab is a browser-based place where students write and run Python 3. It supports functions, loops, conditionals, lists, a Painter mode for drawings and simple animations, and the Pandas, Matplotlib, and NumPy libraries. It is designed for students 13 and older. It is used in two courses for grades 9-12, Foundations of AI Programming and Artificial Intelligence Foundations.

Benefits

For students

  • Students write real Python with nothing to install.
  • Students can draw with Painter mode and chart data with Matplotlib.
  • Students study ethics topics such as bias in the Foundations of AI Programming course.

For teachers

  • Teachers use the Foundations of AI Programming or AI Foundations course in Code Studio.
  • A Try Python Lab link is on the tool page.
  • Self-paced teacher learning is offered.

For schools

  • Python Lab is free.
  • It runs on laptops, Chromebooks, and tablets.
  • The interface is English only.

Getting started checklist

Where is the AI in this product?

Python Lab itself is a coding tool. The courses that use it contain AI content, and some programming units have an AI tutor. The tutor runs in the vendor's cloud. Students write Python and may ask the tutor for hints. They also use data libraries to study results.

Privacy and safety

Accounts are optional, and the internet is needed at all times. The vendor collects account details and project code for signed in students. Progress is saved only with accounts. The policy says language model providers are used for AI supported curricula and AI tutor queries may be stored. The research did not confirm where Python code runs, and it did not find a Student Privacy Pledge in the policy. The page says the tool is designed for students 13 and older. A teacher should review the CodeAI privacy policy. A teacher should also check whether the tutor is on for a course.

How this can be used for Computer Science
  1. Write a program with a loop and a list and run it in Python Lab.
  2. Draw a pattern in Painter mode and change it with a loop.
  3. Write a function that returns a greeting and call it three times.
  4. Follow the bias project and list how a data set can lead to unfair results.
  5. Read a partner's code and explain what it does.
How this can be used for Math
  1. Use NumPy to compute the mean of a list of numbers.
  2. Plot a data set with Matplotlib and describe the shape.
  3. Load a table with Pandas and find the highest value.
  4. Write a loop that tests a formula for ten values.
  5. Compare two data sets with a chart.
