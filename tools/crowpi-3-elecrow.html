CrowPi 3 (Elecrow)

A briefcase style Raspberry Pi 5 lab with sensors, a touchscreen, and AI lessons.

AIComputingRoboticsGood for AI beginners

The privacy details for this item are unverified. Check which tools and accounts students will use before class.

Overview

CrowPi 3 is a briefcase style electronics and coding lab built around a Raspberry Pi 5. It has a 4.3 inch touchscreen, more than 20 pre-wired sensors, two breadboards, and GPIO access. It runs Python projects with a code editor, plus drag and drop blocks. Raspberry Pi Official Magazine says the lessons cover LLMs, voice commands, and computer vision.

Benefits

For students

  • Students work with many sensors in one case.
  • Students can start with blocks and move to Python.
  • Students try beginner AI projects with the camera and microphone.

For teachers

  • It includes 39 Python projects and block coding.
  • Lessons pair instructions with a code editor.
  • Local user accounts save progress on the device.

For schools

Getting started checklist

Where is the AI in this product?

The kit has beginner AI projects that use the camera and microphone. They cover computer vision, voice commands, and language model lessons. The vendor does not say exactly where each AI runs. Students follow a project, run it, and then change it to see new results.

Privacy and safety

Accounts are local profiles stored on the device. The pages read do not state any student data collection, and no privacy policy was reviewed. Some lessons use a camera and microphone. The reviews do not say whether the language model lessons call a cloud service. Where that AI runs is unconfirmed. The internet is used for setup. A teacher should test any language model lesson to see whether it sends student voice or text to a cloud service.
