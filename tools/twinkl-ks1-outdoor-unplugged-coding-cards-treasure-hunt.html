Overview

This Twinkl resource is a set of printable illustrated cards for an outdoor coding treasure hunt. Teachers place start, finish and obstacle cards. Children lay arrow cards to build a route for a peer to follow. The product page returned no readable content. These details come from search snippets.

How this can be used for Computer Science
  1. Lay arrow cards from the start card to the finish card and let a partner follow them.
  2. Add an obstacle card and change the route to go around it.
  3. Read a classmate's route and find any wrong turn.
  4. Predict where a route will end before a partner walks it.
  5. Write the same route a second time using fewer cards.
