Sensor Logger

A free iOS app that records phone sensors and exports data for analysis.

FREEComputingLocal with optional cloud or accounts

Overview

Sensor Logger is a free iOS app that records phone sensors. These include the accelerometer, gyroscope, magnetometer, barometer, GPS, microphone, and camera. It also reads Apple Watch, AirPods, and Bluetooth devices. Recordings appear in interactive plots and export as CSV, JSON, Excel, KML, and SQLite files.

Benefits

For students

  • Students turn a phone into a science instrument.
  • Students see their recordings as interactive plots.
  • Students export data and graph it in a spreadsheet.

For teachers

  • The app needs no account.
  • The listing says it targets researchers, educators, and STEM hobbyists.
  • Search found only App Store listings. Test it before class.

For schools

  • The app is free to download.
  • It works with no internet.
  • Student devices must run iOS.

Getting started checklist

Where is the AI in this product?

Sensor Logger has no AI. It records sensor readings. Students build data skills as they collect, export, and graph measurements.

Privacy and safety

No account is needed, and the app works with no internet. Sensor recordings are stored on the device. The App Store label lists device ID for analytics, precise location and crash data. The developer provides that label. The Streaming and Studies features can send data off the device when a user turns them on. A teacher should tell students which sensors to turn on, keep those features off and delete recordings after the lesson.

How this can be used for Science
  1. Record the accelerometer during a short walk and describe the pattern.
  2. Measure how the barometer changes between floors of the school.
  3. Spin a phone and study the gyroscope data.
  4. Compare readings from two phones at the same time.
  5. Write a short lab report that uses the exported data.
How this can be used for Math
  1. Export a CSV file and make a line graph of the readings.
  2. Find the highest and lowest values in a recording.
  3. Calculate an average from a set of readings.
  4. Compare two trials in a table.
  5. Describe a trend in the data using math words.
