Kojo

A free Scala learning environment for drawing, animation, music, games, and Arduino.

Computing

The privacy details for this item are unverified. Check which tools and accounts students will use before class.

Overview

Kojo is an open source learning environment built around the Scala programming language. Students and teachers use it to make drawings, animations, music, games, simulations, and Arduino circuits. It has a desktop app for Linux, Windows, and Mac and a web app at ikojo.in. The project site says it is part of some government curricula for grades 7 to 10.

Benefits

For students

  • Students see turtle drawings appear as they code.
  • Students use a real programming language.
  • Students use an editor with code completion and tracing.

For teachers

  • The project site says it is part of some grade 7 to 10 curricula.
  • Creator interviews report over 7,000 children and 60 teachers trained, which is self reported.
  • Teachers can choose the desktop app or the web app.

For schools

  • The software is free and the code is open.
  • Reported users include schools in India and Lund University.
  • No independent comparative review was found.

Getting started checklist

Where is the AI in this product?

Kojo has no AI. It runs the Scala code that students write. They build logic and pattern spotting skills as they write programs that draw and animate.

Privacy and safety

No account is mentioned for the desktop app. The official page does not cover privacy or data collection. The research did not confirm whether the web app or the Code Exchange stores data, and offline use was not confirmed. A teacher should check the privacy terms for ikojo.in. A teacher should also have students use the desktop app for personal work.

  1. Write a program that draws a square, as in the grade 7 to 10 curricula.
  2. Use a loop to draw a pattern of squares.
  3. Write a function for a shape and call it with different sizes.

  2. Draw a regular polygon with a loop.
  3. Change a side length and describe how the shape grows.
  4. Build a pattern from shapes that repeat.
  5. Draw a picture that uses coordinates.
