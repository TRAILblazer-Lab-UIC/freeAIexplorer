Vensim PLE

Free system dynamics software for building and running simulations.

FREEComputingStays on the device

Overview

Vensim PLE is the free Personal Learning Edition of Vensim from Ventana Systems. Users build stock and flow models and causal loop models. They run simulations to see how quantities change over time. It installs as a desktop application and suits high school students.

Benefits

For students

  • Students build models of how things change over time.
  • Students test what happens when they change a value.
  • Students see feedback loops in action.

For teachers

  • A sample model library comes with the help system.
  • A free Model Reader runs shared models.
  • Teachers can use it in science and math.

For schools

  • It is free for educational use and software evaluation.
  • Commercial and government users must buy a license.
  • It does not run on Chromebooks. IT may need to approve the install.

Getting started checklist

Where is the AI in this product?

This tool has no AI. The simulation follows the equations students enter. Students build data and modeling skills as they test how changes affect results.

Privacy and safety

The tool runs on the computer and needs no account. The download form asks for a valid email address and says the user agrees to be contacted afterward. Ventana says newsletters go out about four times a year and addresses are not shared. The research did not read a privacy policy and found no statement about telemetry. A teacher should use a school email for the download.

How this can be used for Science
  1. Model a bathtub as a stock with an inflow and an outflow.
  2. Build a population model and change the birth rate.
  3. Use a causal loop diagram to explain a feedback loop in an ecosystem.
  4. Run a sample model and predict the graph before you see it.
  5. Compare two runs and explain the difference.
How this can be used for Math
  1. Create a model and graph how a quantity changes over time.
  2. Change one rate and describe the effect on the graph.
  3. Write the equation behind a flow.
  4. Find the point where a stock stops changing.
  5. Present a model and defend your assumptions.
