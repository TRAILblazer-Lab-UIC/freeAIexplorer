Sphero Indi Educator Guide and lesson plans

A 2021 PDF guide of lessons for the screen-free Sphero indi robot car.

FREEComputingRoboticsUnverified

The privacy details for this item are unverified. Check which tools and accounts students will use before class.

Overview

The Sphero indi Educator Guide Book is a 2021 PDF of lessons for the screenless indi robot car. Its units are Meet Sphero indi, Directions, Patterns and Sequences, Measuring, Mixed bag, and Sphero Edu Jr. Students lay out color code cards to make paths for the car. A separate INL plan targets grades K to 5.

Benefits

For students

  • Students build paths with color code cards and see the car follow them.
  • Students practice patterns, sequences, and measuring.
  • Students learn cause and effect and basic programming.

For teachers

  • The guide has six units with about 3 to 4 lessons each.
  • Teachers can find related plans in math and music.
  • The guide is free to read.

For schools

  • The PDF is free, but indi robot cars cost extra and no price was read.
  • Lessons run on paper and the robot.
  • The guide is copyrighted by Sphero with all rights reserved.

Getting started checklist

Where is the AI in this product?

The guide has no AI. Students build sequencing and pattern skills with cards that control the car. The car follows the same cards the same way each time.

Privacy and safety

The lessons use cards and the robot. The materials do not state whether an account or the internet is needed. A teacher should check the privacy details if the final unit uses the Sphero Edu Jr app.

How this can be used for Computer Science
  1. Set color code cards in a sequence and watch indi follow the path.
  2. Change one card and tell what moves differently.
  3. Build a path that includes a repeated pattern.
  4. Trade card paths with a partner and try them.
  5. Find the bug in a path that does not reach the goal.
How this can be used for Math
  1. Use indi paths to practice counting on.
  2. Measure a path with tiles and record the length.
  3. Build a pattern with cards and extend it.
  4. Compare two paths and tell which is longer.
  5. Put cards in order from first to last.
How this can be used for Music
  1. Code indi to play the first line of a children's song.
  2. Match each card color to a note and play a pattern.
  3. Make a rhythm with cards and clap it.
  4. Trade songs with a partner and play them back.
  5. Change one card to change the tune.
