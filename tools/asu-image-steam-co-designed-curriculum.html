ASU IMAGE STEAM co-designed curriculum

Eleven teacher co-designed lessons that use image-based AI across school subjects.

FREEAIUnverifiedGood for AI beginners

The privacy details for this item are unverified. Check which tools and accounts students will use before class.

Overview

This set has 11 lessons built with middle school teachers in an NSF funded project run by Arizona State University with the University of Georgia. The lessons use image-based AI and machine learning in many subjects. Tools named include Teachable Machine, Pixlr X, Tinkercad, and pixil.art. Students classify images, compare human and computer vision, and make images with generative tools.

Benefits

For students

  • Students train and test an image classifier with Teachable Machine.
  • Students study bias and sample size in image tools.
  • Students link AI to science, math, literature, and art.

For teachers

  • The lessons were co-designed by teachers.
  • Slides and documents are shared in Google Drive.
  • Teachers can pick the lessons that fit their subject.

For schools

  • The lesson materials are free.
  • The lessons use browser tools. Little needs to be installed.
  • The license is stated two ways, as CC-BY-NC-SA and as attribution non-commercial. Check it before sharing.

Getting started checklist

Where is the AI in this product?

The AI is image classification and generative image making. Teachable Machine trains a model from student images. Some lessons use unnamed generative image tools. The tools run in the browser, and the vendor materials do not say where each one processes data. Students use the results to test ideas in science, math, and the arts.

Privacy and safety

The materials do not state whether accounts are needed or where student data goes. The research marks this as not verified. Data flow depends on the tool used in each lesson. Eight of the 11 lessons name no AI tool and some use unnamed generative image tools. The lessons need the internet. A teacher should check the privacy terms of every tool before class and avoid uploading photos of students.

Ideas by subject

Select a subject to see five classroom ideas.

How this can be used for Science
  1. Classify images of cells with Teachable Machine and compare the model with a doctor's task.
  2. Test how the number of training images changes accuracy.
  3. Compare human vision and computer vision on the same set of pictures.
  4. Record where the model fails and propose a better data set.
  5. Discuss why a cancer diagnosis tool needs careful human review.
How this can be used for Math
  1. Collect cat images and count how many the model gets right.
  2. Graph accuracy against sample size and describe the trend.
  3. Use ratios to compare correct and wrong predictions.
  4. Explore how a few odd images change the results.
  5. Write a short report that uses percent to describe the model.
How this can be used for English and Language Arts
  1. Write a scene description from a book and make an image with a text-to-image tool.
  2. Compare the image with the text and mark what the tool missed.
  3. Rewrite the prompt with richer words and make a new image.
  4. Discuss how the image shapes a reader's view of a character.
  5. Write a short reflection on what the tool gets right about setting.
How this can be used for Engineering and Design
  1. Follow the engineering design process to improve an image classifier.
  2. Define a problem that a classifier could help solve.
  3. Test two sets of training data and record the results.
  4. Model a simple object in Tinkercad and describe how a classifier might see it.
  5. Present design changes and explain why each helps.
How this can be used for Visual Arts
  1. Make a pixel art picture in pixil.art and test whether a classifier can name it.
  2. Edit a picture in Pixlr X and see how edits change the prediction.
  3. Compare an artwork made by hand with a generated image.
  4. Discuss who owns an image made with a generative tool.
  5. Create a series of images that try to fool the classifier.
