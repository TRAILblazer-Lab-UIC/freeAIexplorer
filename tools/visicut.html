VisiCut

Free software that prepares designs and sends jobs to laser cutters.

Computing

Overview

VisiCut is a free, open source program for preparing and sending jobs to laser cutters. Users import SVG, EPS, or DXF designs and preview them on the material. They can position designs with a camera image. It suits high school fabrication labs.

Benefits

For students

  • Students learn the steps from design file to cut part.
  • Students can choose material presets for different materials.
  • Students see how a design sits on the material before cutting.

For teachers

  • Material presets save setup time.
  • Camera assisted positioning helps with placing designs.
  • It fits career and engineering classes.

For schools

  • The software is free and open source.
  • A compatible laser cutter is needed, which costs extra.
  • IT must install it and set up the cutter connection.

Getting started checklist

Where is the AI in this product?

This tool has no AI. VisiCut follows the settings that users choose. Students build logic and sequencing skills as they plan the order of cuts.

Privacy and safety

VisiCut runs on the computer and needs no account. The project README does not mention telemetry, and no privacy policy was found. The internet is needed only at setup. Jobs are sent to the laser cutter, which may be over the local network. A teacher should ask IT how the cutter connection is set up and should supervise every laser job. Laser cutters can start fires and need ventilation.

How this can be used for Career and Technical Education
  1. Prepare an SVG design and send it to the laser cutter with a teacher.
  2. Choose a material preset and explain the choice.
  3. Position a design with the camera image and compare it to a manual plan.
  4. Cut a set of identical parts for a class project.
  5. Write a safety checklist for the laser lab.
How this can be used for Engineering and Design
  1. Design a simple part and follow it from file to finished cut.
  2. Test two material thicknesses and record the results.
  3. Adjust a design to fit the material.
  4. Compare a DXF file and an SVG file in the preview.
  5. Build a small product from cut parts and test it.
