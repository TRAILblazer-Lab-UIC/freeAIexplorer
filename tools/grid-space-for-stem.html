Grid.Space for STEM

Free browser tools for slicing 3D prints and planning CNC and laser cuts.

FREEComputingStays on the device

Overview

Grid.Space offers free browser based tools for digital fabrication education. Kiri:Moto slices for 3D printing and makes toolpaths for CNC and laser cutting. Mesh:Tool handles 3D modeling and mesh editing. The site lists K-12 as its range. Students prepare designs for a printer, router, or cutter.

Benefits

For students

  • Students turn a 3D model into instructions that a machine can follow.
  • Students see how a part is sliced into layers.
  • Students edit and repair meshes before making a part.

For teachers

  • The tools run in a browser.
  • Documentation and tutorials are available.
  • Teachers can use the tools with any printer, CNC machine, or laser cutter that students have.

For schools

  • The tools are free, with no subscriptions or per seat fees.
  • The site says student work stays on the user's device, with no sign ups.
  • The tools work offline after the first load and run on Chromebooks.

Getting started checklist

Where is the AI in this product?

Grid.Space has no AI. It builds engineering skills. Students think through layers, toolpaths, and the order of machine steps. It runs in the browser on the device.

Privacy and safety

No account is needed and the internet is needed for the first load. The site says it has no data collection and no cloud uploads, and it calls the tools COPPA and FERPA friendly. These are vendor statements. The research did not read a formal privacy policy. A teacher should read the site's privacy statement. A teacher should also set safety rules for printers, CNC machines, and laser cutters. The tools need physical machines to make real output.

How this can be used for Engineering and Design
  1. Slice a small model and compare two layer heights.
  2. Move a model on the build plate and note how it changes the print.
  3. Generate a laser cutting path for a flat design.
  4. Repair a broken mesh in Mesh:Tool.
  5. Test a printed part and improve the design.
How this can be used for Career and Technical Education
  1. Prepare a keychain design for 3D printing.
  2. Plan a CNC toolpath for a wooden sign.
  3. Make a cut file for a laser cut gift tag.
  4. Follow a tutorial and write the steps in order.
  5. Run a class print queue and track each job.
