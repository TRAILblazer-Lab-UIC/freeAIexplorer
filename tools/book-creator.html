Book Creator

A classroom tool where students create, read, and publish multimedia books.

FREEComputingSends student data to a company

Overview

Book Creator is a classroom tool where students create, read, and publish multimedia books. It is an authoring tool for English, art, and other subjects, and it is not a coding tool. Teachers sign up for a free account, and students use a separate sign-in. Kami acquired Book Creator in September 2025.

Benefits

For students

  • Students combine text, images, drawing, and other media in one book.
  • Students can read the books of classmates.
  • Students can download their own books.

For teachers

  • Teachers create a library and invite students.
  • Books are private by default.
  • The site lists the ISTE Seal and ESSA Level III evidence.

For schools

  • The free plan has one library with up to 40 books.
  • Paid plans exist, and schools can request a quote.
  • It runs in a browser, on Chromebooks, and on iPad.

Getting started checklist

Where is the AI in this product?

The vendor does not describe any AI in the materials read. Book Creator is an authoring tool. It builds the skills of sequencing and organizing ideas, as students plan the pages of a book.

Privacy and safety

Book Creator stores student accounts and books on the vendor cloud, which runs on Google Cloud. Accounts are needed, and the internet is needed all the time. The vendor says student books are private by default and that it does not sell user data. It states COPPA, FERPA, and GDPR compliance. The materials do not list the data fields collected. The research did not confirm whether the tool has AI features. A teacher should read the privacy policy and decide which books to publish.

How this can be used for English and Language Arts
  1. Write and publish a short story with pictures on each page.
  2. Create a class book of poems with one page per student.
  3. Make a book that explains a topic from a unit.
  4. Record a reading of a page as audio.
  5. Read a classmate's book and write a response.
How this can be used for Visual Arts
  1. Draw an illustration for each page of a book.
  2. Combine photos and drawings on one page.
  3. Design a cover that fits the theme.
  4. Make a book about an art style.
  5. Compare layouts and choose the clearest one.
How this can be used for Library and Media Literacy
  1. Publish a class book and add it to a classroom library.
  2. Make a book review with a cover and a short summary.
  3. Create a guide to a school library section.
  4. Read a peer book and write a review.
  5. Plan how to share books safely with families.
