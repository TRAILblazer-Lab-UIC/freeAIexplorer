MakeCode for Minecraft Education

A block coding tool inside Minecraft Education that also leads to Python.

Computing

Overview

MakeCode for Minecraft Education lets students write block or code programs that act inside the game. Microsoft describes the in-game Code Builder as working with MakeCode through a drag-and-drop canvas. Microsoft's CS path runs from block coding in K-5 to Python in grades 9-12. It needs a Minecraft Education license and school Microsoft accounts.

Benefits

For students

  • Students code actions in a world they already know.
  • Students move from blocks to Python over the grades.
  • Students can try Hour of Code content.

For teachers

  • A 10-unit Computing with Minecraft course is available.
  • Lessons such as Escape Estate, Compute a Zoo, and Sea Turtle Assistance are listed.
  • Teachers open Code Builder in game and choose MakeCode.

For schools

  • The MakeCode editor is free. Class use needs a Minecraft Education license, and license prices were not verified.
  • School IT must enable Minecraft Education for school accounts.
  • The tool needs the internet at all times.

Getting started checklist

Where is the AI in this product?

MakeCode for Minecraft Education has no AI. Students write code that controls the game. They build skills in sequencing, loops, and logic.

Privacy and safety

Student accounts are required and data goes to the vendor. Students and teachers sign in with school Microsoft accounts, and the internet is always needed. Microsoft states that for K-12 school products it collects only data needed for school purposes. It says it does not sell the data or use it for advertising or student profiling. The school administrator controls school accounts. The Minecraft Education privacy page timed out and was not read. A teacher should work with IT to review the Microsoft education privacy terms before students sign in.

How this can be used for Computer Science
  1. Complete the Escape Estate lesson and explain the blocks you used.
  2. Write a program that builds a wall in the world.
  3. Use a loop to build a row of blocks.
  4. Compare a block program with the same program in Python.
  5. Work through a Compute a Zoo lesson and share your design.
