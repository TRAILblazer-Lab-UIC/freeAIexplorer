Pinnguaq MagicaVoxel module

A module where students sketch a landscape and build it in 3D pixel art.

FREEComputingUnverified

The privacy details for this item are unverified. Check which tools and accounts students will use before class.

Overview

This is a classroom module on three-dimensional pixel art with MagicaVoxel. Students first sketch a landscape by hand and then build it in the voxel editor. Search snippets say it ties to art and to geometry in math. It also prepares students for a Blender module.

Benefits

For students

  • Students plan on paper before they build.
  • Students learn basic 3D modeling terms.
  • Students can draw ideas from Minecraft worlds.

For teachers

  • The module has a clear order of sketch and then build.
  • It links art and geometry.
  • The module is free, according to search results.

For schools

  • The module and MagicaVoxel are described as free in search results.
  • MagicaVoxel installs on each computer.
  • IT will likely need to approve the install.

How this can be used for Visual Arts
  1. Sketch a landscape by hand and then build it in MagicaVoxel, as the module describes.
  2. Choose a limited color palette and apply it to your build.
  3. Build a small scene inspired by a Minecraft world.
  4. Add light and shadow with color choices.
  5. Present your build and compare it with your sketch.
How this can be used for Math
  1. Count the cubes in a build and find its volume.
  2. Build a shape with a given width, depth, and height.
  3. Compare the front and top views of your model.
  4. Build a symmetric shape and describe its line of symmetry.
  5. Use cube counts to plan a scale model.
