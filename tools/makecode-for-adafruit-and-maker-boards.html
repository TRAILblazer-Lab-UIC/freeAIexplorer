MakeCode for Adafruit and Maker boards

A browser editor for programming the Adafruit Circuit Playground Express with blocks.

Computing

The privacy details for this item are unverified. Check which tools and accounts students will use before class.

Overview

This is a browser-based Microsoft MakeCode editor for the Adafruit Circuit Playground Express board. Students program the board with blocks or JavaScript and test it on a simulator. The editor page names only the Circuit Playground Express. Adafruit and the MakeCode team publish a Maker course and classroom courses for it.

Benefits

For students

  • Students program lights and sensors on a real board.
  • Students can test on screen before using hardware.
  • Students move from blocks to JavaScript.

For teachers

  • A Maker course and classroom courses are available.
  • Per a search snippet, the Maker course maps to CSTA standards.
  • The editor opens in a browser.

For schools

  • The editor is free. The board is bought separately and the price was not verified.
  • The board needs a USB cable.
  • Offline behavior was not verified.

Getting started checklist

Where is the AI in this product?

This editor has no AI. The vendor describes no AI features. Students program a board with rules. They build skills in sensors, logic, and sequencing.

Privacy and safety

The editor page gives no account or privacy information. No account is stated as required. The Microsoft Privacy Statement says children under 13 need parental consent for a Microsoft account. It also says Microsoft does not serve personalized ads to under 18 accounts. The research read no MakeCode specific data terms. The internet is used at setup. A teacher should check the privacy terms and where student projects are saved.

How this can be used for Computer Science
  1. Program the board lights to show a color pattern.
  2. Use a button press to change the pattern.
  3. Switch a block program to JavaScript and compare the two.
  4. Debug a program that does not light the board.
  5. Follow a lesson from the Maker course and report what you learned.
How this can be used for Engineering and Design
  1. Use the light sensor to build a night light.
  2. Use the temperature sensor to display a reading.
  3. Design a wearable that lights up when it moves.
  4. Test the design and note what to improve.
  5. Draw a plan for a board project before coding.
