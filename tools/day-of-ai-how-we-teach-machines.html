Overview

Day of AI: How We Teach Machines is a device-free unit about data, patterns, and predictions. Its lessons include What Is a Machine, Machines Make Predictions, and Dataset Sort. Search coverage lists a total time of about 1 to 2 hours. Students work on paper and talk about how machines learn from examples.

Benefits

For students

  • Students learn what a machine is in plain words.
  • Students see that a machine makes predictions from data.
  • Students sort a dataset by hand and notice patterns for themselves.

For teachers

  • The unit needs no screens, which keeps preparation light.
  • The lessons are short and fit into one or two sessions.
  • Teachers can introduce AI ideas without any AI background.

For schools

  • The unit is free.
  • Students need no devices. The load on IT is small.
  • The unit is described as paper based. The research did not confirm its data practices.

Getting started checklist

Where is the AI in this product?

This unit has no running AI program. It teaches the ideas behind AI on paper, with no device. Students learn about data, patterns, and predictions. They practice these ideas by sorting a dataset and making their own predictions.

How this can be used for Computer Science
  1. Sort a set of data cards into groups and explain the rule used for each group.
  2. Predict the next card in a pattern and talk about how sure the prediction is.
  3. Compare a machine with a living thing and list what each one can do.
  4. Swap datasets with a partner and test whether the same sorting rule still works.
  5. Draw a poster that shows how a machine goes from data to a prediction.
