CircuitPython

A Python language for low cost microcontroller boards, built with education in mind.

Computing

Overview

CircuitPython is a Python language for low cost microcontroller boards, designed with education in mind. More than 600 boards are supported. Students save code files to the board's drive, and the program runs at once with no compiling. A serial console and REPL give live feedback.

Benefits

For students

  • Students see a program run the moment they save it.
  • Students can use over 500 libraries for sensors and displays.
  • Students get live feedback in the console.

For teachers

  • Adafruit educators guides support the classroom.
  • A browser editor works over USB, WiFi, or Bluetooth.
  • The board appears as a drive, which is easy to explain.

For schools

  • The software is free.
  • Boards are bought separately, and educator discounts and class sets exist, per Adafruit.
  • IT will likely need to help with setup.

Getting started checklist

Where is the AI in this product?

CircuitPython has no AI. It builds the skills of sensors and logic, as students program a board to read the world and react. They also practice debugging.

Privacy and safety

No account is needed, and the code runs and is stored on the board. The internet is needed for setup. The materials list no student data collection, and the research read no privacy policy. The research did not examine the optional web editor at code.circuitpython.org for data handling. A teacher should check the source of any libraries that students download. A teacher should also ask IT before students use the web editor.

How this can be used for Computer Science
  1. Write a program that blinks an LED, as in an Intro to CircuitPython class.
  2. Print a sensor value to the serial console.
  3. Use a loop to change a color.
  4. Use an if check to react to a button press.
  5. Add a library and use one of its functions.
How this can be used for Engineering and Design
  1. Build a night light that turns on in the dark.
  2. Read a temperature sensor and log values.
  3. Make a small alarm with a button and a buzzer.
  4. Design a case for a board.
  5. Test a project and write down one improvement.
