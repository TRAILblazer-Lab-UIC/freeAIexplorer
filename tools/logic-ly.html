Logic.ly

A logic gate simulator for building and testing digital circuits.

ComputingUnverified

The privacy details for this item are unverified. Check which tools and accounts students will use before class.

Overview

Logicly is a logic circuit simulator for Windows and macOS. It teaches logic gates and digital circuits with drag-and-drop design. The site offers a free desktop trial, an online browser version, and paid licenses. Students build circuits and watch signals move step by step.

Benefits

For students

  • Students see logic gates work in real time.
  • Students debug a circuit by stepping through the signals.
  • Students can build custom integrated circuits.

For teachers

  • Teachers can build libraries of custom circuits for students to import.
  • The online version starts in minutes.
  • A UK Oak National Academy lesson uses the Logicly demo for its examples.

For schools

  • The online version and desktop trial are free.
  • Paid one-time licenses are Student at $59, Classroom at $599 for up to 20 users, and a Campus tier.
  • No independent teacher reviews were found. Test it before buying.

Getting started checklist

Where is the AI in this product?

Logicly has no AI. It builds logic skills. Students learn how AND, OR, and NOT gates combine to make decisions in a circuit.

How this can be used for Computer Science
  1. Build the basic gates and fill in a truth table for each one.
  2. Wire a circuit that turns a light on only when two switches are both on.
  3. Use step-by-step debugging to find a mistake in a broken circuit.
  4. Build a half adder and test it with every input.
  5. Explain how logic gates connect to the decisions in a computer program.
How this can be used for Engineering and Design
  1. Design a circuit for a simple alarm with two sensors.
  2. Create a custom integrated circuit and reuse it in a larger design.
  3. Test a design with every input combination and record the results.
  4. Import a teacher's circuit and improve it.
  5. Compare a simulated circuit to a real component diagram.
