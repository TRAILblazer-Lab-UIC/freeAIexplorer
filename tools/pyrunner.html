PyRunner

A free Python editor in one web page that runs in the browser.

Computing

Overview

PyRunner is a Python IDE contained in a single HTML file. It runs real Python in the browser through Pyodide. It offers a multi-tab editor, inline input, share-via-URL, examples, and run history. The README says it needs no install and no signup.

Benefits

For students

  • Students write and run Python on any device with a browser.
  • Students keep several files open in tabs.
  • Students share a program with a link.

For teachers

  • Teachers can download one small HTML file and open it.
  • Examples give teachers a quick starting point.
  • Auto-save keeps student work in the browser.

For schools

  • The tool is free and needs no account.
  • It works on Chromebooks, Windows, Mac, and Linux.
  • Code runs in the browser on the student's own device.

Getting started checklist

Where is the AI in this product?

PyRunner has no AI features. The author states that an AI coding tool wrote the code. It builds an AI-related skill, which is sequencing. Students write steps in order and watch the result.

Privacy and safety

No account is needed. The README states there is no signup and no tracking, and it says the tool works offline once loaded. Code is saved in browser local storage. The research did not verify whether Pyodide and packages load from a CDN on first load. No privacy policy exists. The author states that an AI tool wrote the code. A teacher should have IT review the file before school use.

How this can be used for Computer Science
  1. Run a built-in example and change one line to see what happens.
  2. Write a program that asks for a name and prints a greeting.
  3. Open two tabs and keep a function in one and a test in the other.
  4. Use the run history to compare two versions of a program.
  5. Share a program by URL and have a partner improve it.
