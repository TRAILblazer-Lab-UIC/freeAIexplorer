Flower Infinity Bots

Open-source half 3D-printed robots at novice, intermediate and expert levels.

Robotics

Overview

Flower Infinity Bots is a family of open-source differential drive robots that are about half 3D printed. There are three levels named Lily, Daisy and Rosie for novice, intermediate and expert users. The OSHWA record says materials include CAD files, code, Tinkercad and Fritzing files, and videos. A search snippet says groups such as Girl Scouts and Boys and Girls Club have used it.

Benefits

For students

  • Students build a robot that grows with their skill.
  • Students print and assemble real parts.
  • Students can start at the novice level.

For teachers

  • Three levels let a teacher match the robot to the class.
  • Files include CAD, code, Tinkercad and Fritzing.
  • The project is advanced. Plan time to read the files.

For schools

  • The files are open source and free to download.
  • The cost of parts was not confirmed.
  • IT help is likely needed for printing and programming.

Getting started checklist

Where is the AI in this product?

These robots have no AI. They build an AI-related skill, which is programming a machine to drive. Students write code that tells the robot how to move.

Privacy and safety

The robots run on local hardware and no cloud service is described. No privacy policy was found. The materials do not say which controller board or programming tool students use. The research did not confirm those details. The internet is used to download the files. A teacher should check the files, the build steps, and any programming tool before class. Review electrical safety with students.

How this can be used for Engineering and Design
  1. Print the parts for a Lily robot and assemble them.
  2. Test how the robot drives straight.
  3. Adjust a part to fix a wobble.
  4. Compare the Lily, Daisy and Rosie designs.
  5. Document your build with photos and notes.
How this can be used for Computer Science
  1. Load the example code on the robot.
  2. Change a value in the code and observe the result.
  3. Write code to drive the robot in a square.
  4. Debug a program that turns the wrong way.
  5. Plan how you would move up to the next level.
