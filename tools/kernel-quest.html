Kernel Quest

A hands-on activity that uses polarizer filters to model how image networks find patterns.

FREEAIUnpluggedUnverified

The privacy details for this item are unverified. Check which tools and accounts students will use before class.

Overview

Kernel Quest is an activity in the Northwestern AI Unplugged collection. Students use physical polarizer filters and movement to identify fictional creatures called Quirkies. The activity models how convolutional neural networks detect patterns in images. Downloads include instruction cards, an Encyclopedia of Quirkies, a Story Guide, a Field Guide, and box construction instructions.

Benefits

For students

  • Students use a physical filter to find hidden patterns.
  • Students follow a story while they hunt for Quirkies.
  • Students see an idea behind image recognition with their own eyes.

For teachers

  • The downloads include cards and guides for the facilitator.
  • The story gives the lesson a clear frame.
  • The plans are free.

For schools

  • Materials include cardstock or cardboard, polarizer film, and a tablet.
  • The film price was not confirmed.
  • IT involvement is low, although the build takes about an hour.

Getting started checklist

Where is the AI in this product?

The activity has no running AI program. The filters model convolution kernels, which are the small pattern finders in convolutional neural networks. Students slide the filters over objects and watch which patterns appear. They build skills in pattern spotting and in thinking about how machines see images.

How this can be used for Computer Science
  1. Use the filters to find a Quirky and describe the pattern that gave it away.
  2. Explain to a partner how a filter works like a kernel in an image network.
  3. Sort the Quirkies by their patterns and write a rule for each group.
  4. Predict which Quirky a filter will reveal before you try it.
  5. Compare how you spot a Quirky with how a machine might spot one.
How this can be used for Science
  1. Rotate a polarizer filter and record what changes in the light.
  2. Test how two filters together change what you can see.
  3. Draw what an object looks like through each filter angle.
  4. Explain why a filter can reveal a pattern that the eye misses.
  5. Build the box and test how the setup affects the view.
