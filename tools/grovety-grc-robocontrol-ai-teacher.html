Grovety GRC RoboControl AI Teacher

A small offline voice control module with English and Chinese commands for robots.

$AIRoboticsStays on the deviceGood for AI beginners

Overview

The GRC RoboControl is a small ESP32-S3 module with offline voice recognition used to control robots. Elecrow sells it with English and Chinese command sets of 50 or more commands. A PC utility lets users expand the commands. The kit includes bonus firmware called AI Teacher and VoicePIN.

Benefits

For students

  • Students control a robot with their voice.
  • Students can tilt the module to drive a robot.
  • Students may practice English words and simple arithmetic with AI Teacher. This comes from a search snippet.

For teachers

  • The vendor says the kit works entirely offline.
  • It has a race mode and can control up to three robots.
  • A quick start guide is linked to GitHub and Hackster.

For schools

  • Elecrow listed it at $29.00, marked down from $39.90. A robot such as CrowBot is a separate purchase.
  • The module needs no internet and no account.
  • IT or a teacher needs to install the PC command utility. The utility's operating system was not confirmed.

Getting started checklist

Where is the AI in this product?

The AI is offline speech recognition that matches spoken words to commands. It runs on the ESP32-S3 module. Students choose and edit the commands and see how the recognition responds to different voices.

Privacy and safety

No account is needed. Elecrow says the kit works entirely offline and that voice commands need no cloud connection. That claim is vendor stated and the research did not verify it. The module has a Bluetooth radio for robot control. The research found no privacy policy. A teacher should ask the vendor to confirm the offline claim. A teacher should also check that the AI Teacher language game fits the curriculum.

How this can be used for Computer Science
  1. Add five new voice commands with the PC utility and test them.
  2. Compare the English command set with the Chinese command set and note the differences.
  3. Test the module with several voices and chart the success rate.
  4. Write rules for which words make good commands.
  5. Explain in a short note how the module can listen without the internet.
How this can be used for Engineering and Design
  1. Pair the module with a CrowBot and make it drive.
  2. Build a race between two robots using race mode.
  3. Compare voice control with tilt control on a course.
  4. Mount the module on a robot so the microphone is not blocked.
  5. Write a quick start guide in the students' own words.
How this can be used for World Languages
  1. Use the AI Teacher firmware to practice English vocabulary.
  2. Practice numbers with the module and check each answer.
  3. Say a command in English and then in Chinese and note which the module accepts.
  4. Write a list of ten classroom words to use as robot commands.
  5. Teach a classmate a short set of words using the module.
