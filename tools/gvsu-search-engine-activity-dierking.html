GVSU Search Engine Activity (Dierking)

Overview

Search Engine Activity is a 2023 library instruction lesson plan by Amber Dierking, hosted in GVSU ScholarWorks. Its objectives are to deepen understanding of how search engines work, how those mechanics shape results, and how search engines differ from library systems. It suits high school students and librarians. The repository tags it with access, digital literacy, and search engines.

Ideas by subject

Select a subject to see five classroom ideas.

How this can be used for Library and Media Literacy
  1. Compare the results of one search in a search engine and in a library system.
  2. List three differences between the two tools.
  3. Rewrite a search to get better results and explain the changes.
  4. Explain why two classmates may see different results.
  5. Write a short guide that tells younger students how to choose a tool.
How this can be used for Computer Science
  1. Draw a diagram of how a search engine might find and rank pages.
  2. Predict which result will come first and then check.
  3. Test how one changed word changes the results.
  4. Explain what a keyword is and how a computer matches it.
  5. Discuss how the order of results can shape what people read.
