Raspberry Pi OS

The free official operating system for Raspberry Pi computers.

Computing

Overview

Raspberry Pi OS is the official operating system for Raspberry Pi computers. It is based on Debian Linux and is free to use. The recommended desktop edition includes Chromium, Firefox, VLC, and the Thonny Python environment. The Full edition adds LibreOffice, KiCad, and a Scratch environment.

Benefits

For students

  • Students use Thonny to write Python from the first day.
  • Students can use Scratch in the Full edition.
  • Students use the GPIO Zero library for physical computing.

For teachers

  • The OS has about 69,000 packages.
  • The Lite edition is available for projects with no desktop.
  • Teachers need strong comfort with Linux for large setups.

For schools

  • The OS is free.
  • It works offline after install.
  • Updates and extra packages need internet.

Getting started checklist

Where is the AI in this product?

Raspberry Pi OS has no AI. It builds an AI-related skill, which is working with sensors and logic. Students use GPIO Zero to read inputs and control outputs. That practice shows how computers sense and respond.

Privacy and safety

No account is needed. The system runs locally, and the internet is needed for updates and packages from remote repositories. The Raspberry Pi privacy policy does not mention Imager by name and does not address children. A search snippet says Raspberry Pi Connect is installed by default on desktop images and needs a Raspberry Pi ID only if the user signs in. A teacher should plan update times, set strong passwords, and check whether Connect is turned on.
