EdBlocks EdScratch and EdPy

Three free browser languages for programming the Edison robot.

FREEComputingRoboticsSends student data to a company

Overview

EdBlocks, EdScratch and EdPy are three free browser-based languages for the Edison robot. EdBlocks is drag and drop for ages 7 and up. EdScratch is a block language based on Scratch for ages 10 and up. EdPy is a text language similar to Python for ages 13 and up. Students write a program and send it to the robot over USB.

Benefits

For students

  • Students can start in blocks and move up to Python-like text.
  • Students download programs to a real robot.
  • Students stay on one robot as their skills grow.

For teachers

  • The apps run in a web browser with no extra software.
  • They are free for unlimited users.
  • Edison lesson plans support all three languages.

For schools

  • The software is free. The robot is sold separately.
  • V3 programming needs Chrome, Edge or Opera on a computer.
  • The apps need an internet connection.

Getting started checklist

Where is the AI in this product?

The vendor does not describe any AI in these languages. Students write programs and the robot follows them. Students build skills in sequencing, loops and text coding.

Privacy and safety

No account is needed, and the apps need the internet at all times. Optional registration collects name and email to save programs. The policy says minors can use the apps without personal information and that Google Analytics runs on the website. Some data may be processed overseas. The privacy page link in the research returned an error. The site recommends ages 7, 10 and 13 and up for the three languages. A teacher should find the current policy and check the recommended age for EdPy.

How this can be used for Computer Science
  1. Build an EdBlocks program that drives Edison in a square.
  2. Use EdScratch to add sounds and lights to a program.
  3. Write a short EdPy program and compare it to blocks.
  4. Send the same program to Edison from EdBlocks and from EdScratch and compare the two.
  5. Debug a program that a partner wrote and explain the fix.
