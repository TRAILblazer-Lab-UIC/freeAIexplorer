EduBlocks Curriculum

A free six-lesson unit for moving from Scratch to Python with EduBlocks.

FREEComputingUnverified

The privacy details for this item are unverified. Check which tools and accounts students will use before class.

Overview

This is a free six-lesson curriculum for moving from Scratch to Python with EduBlocks. Lessons cover an introduction, Turtle and iteration, user input and data types, variables, functions, and a final Turtle project. The unit includes an end-of-unit assessment with a mark scheme and 123 downloadable Coding Cards. The page names no grade range.

Benefits

For students

  • Students move from blocks to text code in small steps.
  • Students draw with Turtle graphics.
  • Students finish with a project of their own.

For teachers

  • The lessons are ready to use.
  • An assessment with a mark scheme is included.
  • Coding Cards give students quick reference.

For schools

  • The page says the curriculum is completely free.
  • It runs in a browser and needs no install.
  • Anaconda sells a separate certification course, which is optional.

Getting started checklist

Where is the AI in this product?

This curriculum has no AI. It builds sequencing and loop skills. Students build programs that repeat steps in a set order.

Privacy and safety

The curriculum page mentions no accounts, and the research did not read the EduBlocks privacy terms. The materials do not state which accounts students need or where student work is stored. The lessons use EduBlocks in a browser, and the internet is always needed. A teacher should check the EduBlocks policy and see whether accounts are required.

How this can be used for Computer Science
  1. Follow the introduction lesson and run a first program in EduBlocks.
  2. Use Turtle and a loop to draw a square and then a star.
  3. Ask for user input and print it back in a message.
  4. Store a value in a variable and use it in a drawing.
  5. Plan and build a final Turtle project with a function.
