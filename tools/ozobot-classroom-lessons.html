Ozobot Classroom lessons

A free web portal with about 700 lessons for Ozobot robots.

ComputingRobotics

Overview

Ozobot Classroom is a web portal with about 700 lessons across coding, math, ELA, art and music, social studies and science. Teachers sign in with a free account. Lessons use Ozobot Evo or Bit robots with screen-free Color Codes or the OzoBlockly editor. Students do not log in.

Benefits

For students

  • Students learn with robots that follow colored lines and codes.
  • Students can start without a screen and move to block coding later.
  • Students practise coding inside math, ELA, art and science lessons.

For teachers

  • Pacing guides give up to 30 lessons per grade level.
  • Webinars and a Create a Lesson tool are included.
  • The Ozobot Simulator lets teachers test lessons without a robot.

For schools

  • The teacher account and lessons are free.
  • Ozobot robots are sold separately.
  • The portal runs on Chromebooks, Windows and Mac in a browser.

Getting started checklist

Where is the AI in this product?

The vendor does not describe any AI. Students build sequencing and logic skills with Color Codes and OzoBlockly. They also practise planning a path and testing it.

Privacy and safety

The portal runs in the vendor's cloud and needs the internet at all times. Teachers sign in with an account and students do not. The official page shows COPPA, FERPA, and iKeepSafe badges and links a privacy policy and an AI privacy policy. The research did not read either policy or the iKeepSafe page. A teacher should read the Ozobot privacy terms before using the teacher account for the class.

Ideas by subject

Select a subject to see five classroom ideas.

How this can be used for Computer Science
  1. Draw a line with Color Codes and predict how the robot will move.
  2. Build a short OzoBlockly program and run it on the simulator.
  3. Use a loop to repeat a movement.
  4. Fix a program that sends the robot off the path.
  5. Write steps for a robot task and then code them.
How this can be used for Math
  1. Use a ruler to measure the path a robot travels and compare it with a prediction.
  2. Code turns at set angles and name each angle.
  3. Pick a math lesson from the library and solve it with the robot.
  4. Chart how long the robot takes on three paths.
  5. Make a number line on the floor and move the robot along it.
How this can be used for English and Language Arts
  1. Pick an ELA lesson from the library and act out a story with the robot.
  2. Draw a story map and have the robot visit each scene.
  3. Code a robot to move to the setting named in a sentence.
  4. Write directions for the robot in clear steps.
  5. Retell a story using the robot as a character.
How this can be used for Visual Arts
  1. Draw a colorful track and watch how the robot reads it.
  2. Make a pattern art piece with repeating Color Codes.
  3. Pick an art or music lesson from the library and try it.
  4. Design a robot dance and add a beat with the code.
  5. Share the art with the class and explain the pattern.
How this can be used for Science
  1. Pick a science lesson from the library and run it with the robot.
  2. Make a map of a habitat and have the robot travel through it.
  3. Test how the robot moves on different surfaces and record the results.
  4. Predict the path and compare it with what the robot did.
  5. Show a life cycle in order by moving the robot between stages.
