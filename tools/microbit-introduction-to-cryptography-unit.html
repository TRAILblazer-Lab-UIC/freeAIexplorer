micro:bit Introduction to cryptography unit

A three lesson unit on ciphers that moves from paper to text-based coding.

FREEComputingUnpluggedUnverified

The privacy details for this item are unverified. Check which tools and accounts students will use before class.

Overview

This is a three-lesson unit for ages 11 to 14, made with Nominet. It can be used on its own or as part two of the cyber security unit. Lesson 1 covers ciphers over time, World War Two, and Alan Turing. Lesson 2 builds a paper Caesar cipher and then writes algorithms. Lesson 3 reads JavaScript and programs a Caesar cipher in Python, with micro:bits optional.

Benefits

For students

  • Students create and solve ciphers.
  • Students move from paper to text-based programming.
  • Students learn how ciphers shaped history.

For teachers

  • The full unit can be downloaded as a zip file.
  • Each lesson has a plan and slides.
  • A Tes listing says each lesson runs about 60 minutes.

For schools

  • The unit is free.
  • Micro:bit hardware is optional.
  • Lesson 3 needs a Python or MakeCode editor.

Getting started checklist

Where is the AI in this product?

This unit has no AI. It builds algorithm design and text-based programming. Students write steps that hide a message and steps that reveal it.

Privacy and safety

Lessons 1 and 2 run on paper. Lesson 3 uses MakeCode and Python, and the page says micro:bits are optional. The materials do not state which accounts are needed or how student code is stored. The research did not review the data practices of the coding tools. A teacher should check the editor terms and set a place for students to save their code.

Ideas by subject

How this can be used for Computer Science
  1. Create a cipher and challenge a partner to solve it.
  2. Write a Caesar cipher algorithm in plain words.
  3. Read a short JavaScript program and explain each line.
  4. Program a Caesar cipher in Python and test it.
  5. Debug a cipher program that gives the wrong output.
How this can be used for Math
  1. Shift letters by a number and record the new alphabet.
  2. Look for patterns in encrypted messages.
  3. Count how many possible shifts a Caesar cipher has.
  4. Explain why shifting past the end of the alphabet wraps around.
  5. Compare a short key and a long key and discuss which is harder to crack.
How this can be used for Social Studies
  1. Read about ciphers used in World War Two.
  2. Describe the role of Alan Turing in breaking codes.
  3. Compare old ciphers with those used today.
  4. Write a timeline of ciphers across history.
  5. Discuss why secret messages mattered in wartime.
