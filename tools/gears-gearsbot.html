Gears (GearsBot)

A free browser 3D robot simulator programmed with Blockly or Python.

FREEComputingRoboticsStays on the device

Overview

Gears is a free, open source 3D robot simulator that runs in a web browser. Students program simulated robots with Blockly blocks or Python and watch them drive in a physics-based world. It uses the ev3dev API. Code can also run on a Lego Mindstorms EV3. A school can self-host it by copying files to a web server.

Benefits

For students

  • Students test code in a simulated robot with no hardware.
  • Students move from Blockly blocks to Python.
  • Students can try the same code on an EV3 robot.

For teachers

  • Gears opens in a browser in minutes.
  • The interface is translated into several languages, including Spanish, French and German.
  • GearsBot tutorials guide students through tasks.

For schools

  • Gears is free and open source.
  • A school can host the files on its own web server.
  • The simulator needs a modern browser with WebGL.

Getting started checklist

Where is the AI in this product?

Gears has no AI. The simulator follows the code students write. Students build skills in sequencing and logic by watching a virtual robot respond to their programs.

Privacy and safety

No account is needed. The hosted site loads from the public internet each time, unless the school hosts the files itself. The README does not describe user accounts or data handling, and the research found no privacy policy. The research did not confirm whether hosted copies store programs on a server. A teacher should consider hosting the files on a school server. A teacher should also check that real robot ports can differ from the simulated ones.

How this can be used for Computer Science
  1. Write a Blockly program that drives the robot in a square.
  2. Convert the Blockly program to Python and compare the two.
  3. Use a sensor to make the robot stop before a wall.
  4. Debug a program that sends the robot the wrong way.
  5. Share a finished program with a partner and explain each step.
How this can be used for Engineering and Design
  1. Observe how the physics engine moves the robot and describe one effect.
  2. Test how speed changes the turning accuracy of the robot.
  3. Compare simulated results with an EV3 robot if one is available.
  4. Design a task for the simulated robot and test it.
  5. Record the sensor values during a run and explain the pattern.
