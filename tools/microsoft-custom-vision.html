Microsoft Custom Vision

An Azure service where users tag images and train a classifier or object detector.

AI

Overview

Custom Vision is an Azure service for building image classification and object detection models. Users upload and tag images in a web portal, train a model, test it, and can export it for offline use. Microsoft has announced the planned retirement of the service, with full support until 9/25/2028. It suits high school computing with teacher-managed accounts.

Benefits

For students

  • Students label their own images and train a model.
  • Students test the model on new pictures.
  • Students can export a model for offline use.

For teachers

  • A web portal guides tagging and training.
  • A tutorial called Classify images with the Custom Vision service exists.
  • Teachers can run the activity on one managed account.

For schools

  • A free F0 tier allows 2 projects, 5,000 training images per project, and 10,000 predictions per month.
  • The paid S0 tier is also available.
  • An Azure subscription is needed, and the retirement notice affects long-term planning.

Getting started checklist

Where is the AI in this product?

The AI is an image classification and object detection model that trains and runs on Microsoft's cloud. Models can be exported for offline use. Students upload and tag images, train a model, and test it, then use the results to improve their own data.

Privacy and safety

Accounts are required through Azure, and the internet is always needed. Training images are uploaded to the user's Azure resource. Prediction images are stored for 30 days on both tiers. Microsoft says data is not replicated outside the specified region except in NorthCentralUS, and refers to its Trust Center for customer data policies. Exported models can run offline. The research did not check under 18 account rules. The service is planned for retirement in 2028. A teacher should check which images students upload and should avoid photos of people.

How this can be used for Computer Science
  1. Tag two sets of classroom objects and train a classifier.
  2. Test the model with a new photo and record its confidence.
  3. Add more images and see how accuracy changes.
  4. Compare image classification with object detection on one picture.
  5. Export a trained model and describe how it could be used offline.
How this can be used for Science
  1. Photograph leaves and train a model to sort them into types.
  2. Record the accuracy for each type and look for patterns.
  3. Test a leaf from a different tree and discuss the result.
  4. Plan a data project that uses image classification.
  5. Present the data set and results in a short report.
