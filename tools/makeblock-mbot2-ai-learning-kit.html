Makeblock mBot2 AI Learning Kit

An aluminum coding robot bundled with an AI Camera for machine vision.

AIComputingRoboticsGood for AI beginners

Overview

mBot2 is an aluminum-chassis robot controlled by a CyberPi board with Wi-Fi, Bluetooth, a microphone, a speaker, and motion sensors. The kit has an ultrasonic sensor, a color sensor, and encoder motors. Students program it in mBlock with a one-button change from blocks to Python. This bundle adds the AI Camera 2.0, a separate vision module. Core Electronics lists the Starter kit for ages 8 and up and the Rover kit for ages 12 and up.

Benefits

For students

  • Students program a real robot with blocks and then Python.
  • Students try machine vision with the AI Camera.
  • Students try speech recognition.

For teachers

  • mBlock runs as an app, a desktop install, or a browser editor.
  • USB upload is recommended for classrooms.
  • The AI Camera needs its own setup.

For schools

  • The Makeblock site listed mBot2 at 120 USD without the camera. The 279.99 USD kit price was not confirmed.
  • Cloud AI features need 2.4 GHz Wi-Fi.
  • Internet is needed for setup and model download. Speech recognition needs Wi-Fi during use.

Getting started checklist

Where is the AI in this product?

The kit offers machine vision through the AI Camera and speech recognition. Some AI runs on the device and some uses a vendor cloud. Students write programs that act on what the camera sees. They can test how well the robot hears spoken words.

Privacy and safety

The internet is needed at setup. It is not confirmed whether mBlock needs an account. A guide says the AI Camera uses 2.4 GHz Wi-Fi to download user trained models and for online English recognition. Cloud AI features therefore send data to a vendor service. The materials do not say how that data is handled. The Makeblock policy says it does not knowingly collect data from children under 13. That is a data rule and not an age limit. The policy does not address AI or voice cloud services. A teacher should check the mBlock account rules first.

How this can be used for Computer Science
  1. Write a block program that drives the robot in a pattern.
  2. Switch a program to Python with one click and read the code.
  3. Train the AI Camera to spot a color card and react.
  4. Use speech recognition to give the robot a command.
  5. Compare how the robot works with and without Wi-Fi.
How this can be used for Engineering and Design
  1. Build the robot and tighten each bolt.
  2. Test the color sensor on different surfaces.
  3. Mount the AI Camera and find its best angle.
  4. Run a line course and tune the speed.
  5. Design a challenge course for another group.
