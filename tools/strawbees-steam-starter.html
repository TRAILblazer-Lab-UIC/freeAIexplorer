Strawbees STEAM Starter

A straw-and-connector building kit with a micro:bit and a servo board.

ComputingRobotics

The privacy details for this item are unverified. Check which tools and accounts students will use before class.

Overview

The Strawbees STEAM Starter Robotics kit combines a straw-and-connector building set with a BBC micro:bit and a Robotic Inventions board. The set has 230 pieces, with straws in five lengths. Students build models and program them in Microsoft MakeCode blocks. The kit includes an activity booklet and a poster.

Benefits

For students

  • Students build moving models from straws and connectors.
  • Students program a servo motor with MakeCode blocks.
  • Students test and rebuild their models as they learn.

For teachers

  • The activity booklet has 21 lessons and activities.
  • The micro:bit V2 GO kit is included.
  • Programs run on batteries after upload.

For schools

  • STEMfinity lists the kit at 129 USD.
  • Retailers list grades 3-8 or 3-9.
  • The software runs in a browser, and the internet is needed only at setup.

Getting started checklist

Where is the AI in this product?

The kit has no AI. The micro:bit runs the blocks that students write and the servo moves as they say. Students build sequencing and logic skills by testing each change.

Privacy and safety

No account is needed. The programs run on the micro:bit, and the MakeCode browser editor needs the internet at setup. The research reviewed no privacy policy and did not read the Strawbees site. A teacher should check the MakeCode privacy terms and that the school allows saving files from the editor.

How this can be used for Engineering and Design
  1. Build a straw model from the booklet and attach the servo.
  2. Test which straw lengths make the model move best.
  3. Redesign a joint that keeps slipping.
  4. Build a moving creature and test how it moves.
  5. Present a model and explain each design choice.
How this can be used for Computer Science
  1. Use MakeCode blocks to move the servo back and forth.
  2. Add a button input that starts the movement.
  3. Change a number in the program and note what changes.
  4. Use a loop to repeat a motion.
  5. Debug a program that does not move the servo.
