8gwifi Arduino and ESP32 Simulator

A free online simulator for Arduino, Raspberry Pi Pico and ESP32 boards.

Computing

Overview

This is a free online simulator for Arduino Uno and Nano, Raspberry Pi Pico and Pico W, ESP32, ESP32-C3, ESP32-S3 and Raspberry Pi 3B. The page says no signup is needed, with an optional Google login. Students write or paste an Arduino sketch and run it in the browser. Sketches are written in Arduino C++.

Benefits

For students

  • Students can test code without owning a board.
  • Students can pick from several popular boards.
  • Students can use libraries such as Servo, Wire and FastLED.

For teachers

  • The page needs no signup.
  • Multi-file projects are supported.
  • Teachers can demonstrate a sketch to a whole class.

For schools

  • The simulator is free.
  • It runs in a browser on Chromebooks.
  • Student sketches go to a vendor server, and the site has ads and analytics.

Getting started checklist

Where is the AI in this product?

The simulator has no AI. Students build skills in sequencing and logic as they write code for a board. They learn how code reads pins and controls outputs.

Privacy and safety

No signup is needed, but the site always needs the internet. Server logs keep IP address, user agent, URL, timestamp, and referrer for up to 90 days. Google sign in shares account ID, email, and name. The site shows ads and uses Google AdSense and Analytics cookies. Sketches go to a compile server and the policy does not say how they are stored. A teacher should read the privacy policy, which says the site is not aimed at children under 13.

How this can be used for Computer Science
  1. Write a sketch that blinks an LED and run it in the simulator.
  2. Read a serial message and change what the sketch does.
  3. Change a delay value and describe the effect.
  4. Compare the same sketch on an Arduino Uno and an ESP32.
  5. Fix a broken sketch that a classmate wrote.
How this can be used for Engineering and Design
  1. Simulate a servo and set its angle through code.
  2. Test a sketch on two boards and list the differences.
  3. Plan a circuit on paper and then run its code in the simulator.
  4. Use FastLED to make a light pattern.
  5. Describe what each pin does in a sketch you wrote.
