Botley 2.0 the Coding Robot

A screen-free coding robot programmed with a handheld remote.

ComputingRobotics

The privacy details for this item are unverified. Check which tools and accounts students will use before class.

Overview

Botley 2.0 is a screen-free coding robot that children program with a handheld remote. A review describes object sensing, 45 and 90 degree turns, and sequences of up to 150 steps. The set includes 78 stackable obstacles and 40 coding cards. The review suggests it for grades K-2 and the listed age is 5 and up.

Benefits

For students

  • Students program with a remote and need no app.
  • Students build obstacle courses and test their code.
  • Students try if-then ideas with object detection.

For teachers

  • Setup takes minutes with batteries and a clear floor.
  • Coding cards give ready-made challenges.
  • No account or device is needed.

For schools

  • Retailer prices run from about 74 USD to 110 USD.
  • A review says the robot needs no internet, app, or login.
  • The robot uses 5 AAA batteries.

Getting started checklist

Where is the AI in this product?

Botley 2.0 has no AI. The robot follows the sequence that students enter on the remote. Students build skills in sequencing and conditional logic.

Privacy and safety

One independent review says the robot needs no app, login, or data collection. The research could not read the vendor site and saw no vendor privacy statement. The robot is screen free and is described as working without the internet. A teacher should confirm this with the vendor before relying on it. A teacher should also check the floor space and keep small obstacle pieces away from very young children.

How this can be used for Computer Science
  1. Program the robot to travel around a stack of obstacles with the remote.
  2. Use a coding card to plan a path and then run it.
  3. Add an object detection step and describe what the robot does.
  4. Write a sequence of 10 steps and predict where the robot ends.
  5. Debug a sequence that hits an obstacle and explain the fix.
