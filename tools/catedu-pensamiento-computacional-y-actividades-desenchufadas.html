CATEDU Pensamiento computacional y actividades desenchufadas

A free Spanish online book on computational thinking and unplugged activities.

ComputingUnplugged

The privacy details for this item are unverified. Check which tools and accounts students will use before class.

Overview

This Spanish language online book from CATEDU supports the Escuela 4.0 program in Aragon. One chapter explains computational thinking and its four pillars, which are decomposition, pattern recognition, abstraction, and algorithms. A second chapter covers unplugged activities. These include adapted Bebras cards, activities based on CS Unplugged, and board games for logic.

Benefits

For students

  • Students practice logic with board games and card puzzles.
  • Students learn the four pillars of computational thinking through hands-on tasks.
  • Spanish-speaking students can work in their own language.

For teachers

  • The book includes learning situations aligned with the Aragonese curriculum.
  • The book can be exported as HTML, PDF, TXT, Markdown, or ZIP.
  • The chapter on the four pillars gives teachers background reading.

For schools

  • The book is free to read online.
  • Cards and boards print on a standard printer.
  • Aragon schools receive unplugged kits per cycle under Escuela 4.0.

Getting started checklist

Where is the AI in this product?

This book has no AI. It builds computational thinking skills such as decomposition, pattern spotting, and logic. Students solve puzzles and board games by breaking them into parts.

Privacy and safety

The activities run on paper. The book is read in a browser or exported, and the internet is used for that. The page states no privacy policy and no login requirement, and the research did not confirm whether an account is needed. The vendor does not describe student data collection. A teacher should check the book's license and the Spanish wording before sharing printed pages.

How this can be used for Computer Science
  1. Describe decomposition by breaking a classroom task into smaller parts.
  2. Solve an adapted Bebras card and name the pillar it uses.
  3. Look for a pattern in a set of shapes and write the rule.
  4. Write an algorithm for a board game move and test it.
  5. Explain abstraction by drawing a simple map that leaves out detail.
How this can be used for Math
  1. Play a logic board game and explain the winning strategy.
  2. Solve a card that uses ordering and find the rule.
  3. Find the pattern in a number series and extend it.
  4. Count the moves of two strategies and compare them.
  5. Make your own logic puzzle for a classmate.
