Noughts and crosses AI demo with Machine Learning for Kids

A noughts and crosses demo where the computer opponent learns from every game played.

AIGood for AI beginners

Overview

This is a hands-on demo for short stand visits at STEM or science fair events. Children play noughts and crosses against a computer opponent. The opponent's moves come from a machine learning model that is retrained during the event on every game played so far. Early players face near-random moves and later players meet a better-trained opponent.

Benefits

For students

  • Children see an AI get better as more games are played.
  • Children need no coding because the Scratch game is pre-built.
  • Children can talk about how examples teach a model.

For teachers

  • The demo comes with a worksheet for event volunteers.
  • The author says the model is a decision tree built with scikit-learn.
  • The idea draws on Donald Michie's 1960s MENACE project, and a matchbox version is mentioned in the post.

For schools

  • The demo is free to download per the batch notes.
  • It runs in a browser on Machine Learning for Kids and needs the internet.
  • A teacher or organizer must set it up, which takes about an hour.

Getting started checklist

Where is the AI in this product?

The AI is a decision tree that is retrained on every game played. The game runs as a Scratch project on Machine Learning for Kids, and the model lives on the vendor's cloud. Children play, and each game becomes training data that makes the next opponent stronger.

Privacy and safety

The game collects game moves, and they go to the vendor cloud. Game moves train a shared model during the event. The blog post does not state whether accounts are needed or give privacy terms. The internet is needed throughout. A teacher should check the Machine Learning for Kids terms and account rules before the event.

How this can be used for Computer Science
  1. Play against the early opponent and note how random its moves seem.
  2. Play again after many games and compare the opponent's skill.
  3. Explain in your own words how each game teaches the model.
  4. Draw a decision tree for the first move of a game.
  5. Describe how the matchbox version of MENACE learns from wins and losses.
