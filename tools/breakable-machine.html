Breakable Machine

A classroom game where students fool an image classifier to learn how AI fails.

AIGood for AI beginners

The privacy details for this item are unverified. Check which tools and accounts students will use before class.

Overview

Breakable Machine is a classroom game that teaches critical AI literacy through spoofing. Students try to fool an image classifier by changing their appearance or surroundings. An explainable AI view shows which image features the model uses. A shared leaderboard lets the class compare strategies. It is designed for learners aged 10 to 15.

Benefits

For students

  • Students learn that AI can be wrong with great confidence.
  • Students see which parts of an image a model attends to.
  • Students compare strategies with classmates on a leaderboard.

For teachers

  • The game has a teacher projected view.
  • The activity is easy to explain.
  • It sparks talk about how models fail.

For schools

  • The paper states that the game and source code are freely available.
  • No download link was found.
  • The vendor does not say what devices are needed, and a camera is implied.

How this can be used for Computer Science
  1. Change a hat or a background and see whether the classifier changes its answer.
  2. Predict which strategy will work best and then test it.
  3. Use the explainable view to describe what the model looks at.
  4. Rank the class strategies from the leaderboard and discuss them.
  5. Write a short note on why a classifier can be fooled.
