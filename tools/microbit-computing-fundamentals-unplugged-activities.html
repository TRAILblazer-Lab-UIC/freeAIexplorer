micro:bit Computing fundamentals unplugged activities

A free PDF of unplugged activities for core computing concepts.

FREEComputingUnpluggedNo device needed

Overview

This resource holds unplugged activities for learning computing concepts away from a computer. Topics are algorithms, decomposition, abstraction, pattern recognition, loops, selection, variables, and debugging. The activities are in a downloadable PDF. They were first published alongside the Let's talk about computing fundamentals professional development course.

Benefits

For students

  • Students learn core computing ideas through hands-on activities.
  • Students practice debugging, loops, and selection on paper.
  • Students build a base before they use a device.

For teachers

  • The activities link to a free professional development course.
  • A related unit of work has six lessons for ages 11 to 14 per search results.
  • The PDF covers many concepts in one place.

For schools

  • The PDF is free.
  • The activities need no devices.
  • IT staff have no work to do.

Privacy and safety

The activities run on paper. The internet is needed only to read or download the PDF. No account is needed. The research read no privacy policy for this item. The professional development course is on Thinkific and was not reviewed. The PDF itself was not read. A teacher should choose activities that fit the class and check the course site terms before enrolling.

How this can be used for Computer Science
  1. Write an algorithm for a daily task and test it on a partner.
  2. Break a big task into smaller parts to practice decomposition.
  3. Find a pattern in a set of pictures and write the rule.
  4. Use a loop to shorten a long set of instructions.
  5. Debug a set of instructions that a classmate wrote.
