Science on Stage Climapse micro:bit data acquisition

A short micro:bit unit on logging and graphing temperature data in science.

Computing

The privacy details for this item are unverified. Check which tools and accounts students will use before class.

Overview

This short unit is for ages 12 to 14 and takes one or two lessons. Students log temperature with a micro:bit. They can send data between two micro:bits and add an external DHT11 or DHT22 sensor. The unit has three MakeCode tutorials.

Benefits

For students

  • Students collect real temperature data with a built-in sensor.
  • Students can test code in a virtual simulator without hardware.
  • Students export logged data as CSV and graph it in a spreadsheet.

For teachers

  • Three MakeCode tutorials guide the lessons in order.
  • The unit fits one or two lessons depending on prior knowledge.
  • The tutorials are stored as markdown files on GitHub.

For schools

  • The lessons are free. The micro:bits, sensors, and clips are bought separately.
  • The unit runs in a browser on Chromebook, Windows, or Mac.
  • IT may need to install the tools and approve the MakeCode site.

Getting started checklist

Where is the AI in this product?

This unit has no AI. Students write block code that reads a sensor. They build data skills as they log, export, and graph temperature readings.

Privacy and safety

No account is needed. The tutorials run in the MakeCode browser editor, which needs the internet at all times. Logged data goes to the board and the computer. The research did not read the MakeCode privacy policy. The materials do not state whether the tutorials work offline. A teacher should check that the MakeCode site is open on school networks.

Ideas by subject

Select a subject to see five classroom ideas.

How this can be used for Science
  1. Log temperature in a classroom with a micro:bit and graph the readings.
  2. Compare readings from the built-in sensor with a DHT11 or DHT22 sensor.
  3. Place sensors in sun and shade and explain the difference.
  4. Measure the board temperature, discuss why it needs calibration, and suggest a fix.
  5. Send temperature data between two micro:bits and draw a diagram of the readings.
How this can be used for Computer Science
  1. Build a block program that reads the temperature and shows it on the micro:bit.
  2. Test the program in the virtual simulator before using hardware.
  3. Write code that sends a sensor reading to a second micro:bit.
  4. Write code on the second micro:bit that receives the data and displays it.
  5. Export the logged data as CSV and describe the steps the data takes from sensor to spreadsheet.
