MathWorks Discover Robotics courseware

A mobile robotics workshop using MATLAB, Simulink and the MiniQ robot.

FREERoboticsUnverified

The privacy details for this item are unverified. Check which tools and accounts students will use before class.

Overview

This is a mobile robotics workshop from MathWorks, written by Lancaster Country Day School for middle and high school students. Search results describe 5 units, 17 videos and 40 MATLAB and Simulink files. It runs about one week or 15 hours. It uses the MiniQ 2WD Arduino-based robot. It needs MATLAB, Simulink, Stateflow and MATLAB Coder.

Benefits

For students

  • Students program a real robot with professional tools.
  • Students watch videos and work through five units.
  • Students link math models to robot behavior.

For teachers

  • The courseware includes videos and files.
  • A syllabus lays out the unit order.

Getting started checklist

Where is the AI in this product?

This courseware has no AI. It builds an AI-related skill, which is modeling a system with data and logic. Students simulate and test robot behavior.

How this can be used for Engineering and Design
  1. Assemble the MiniQ robot and test the motors.
  2. Study how the robot senses its surroundings.
  3. Test the robot on a simple course.

How this can be used for Computer Science
  1. Work through the first unit's videos and files.
  2. Program the robot in Simulink and download the code to it.
  3. Use Stateflow to plan robot states.
  4. Debug a program that does not match the plan.
  5. Explain your model to a classmate.
How this can be used for Math
  1. Use a model to predict how far the robot will travel.
  2. Graph the robot's speed over time.
  3. Compare predicted and measured distances.
  4. Adjust a number in the model and observe the result.
