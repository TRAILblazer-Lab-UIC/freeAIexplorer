CMU legacy free robotics curricula (EV3, NXT, VEX IQ ROBOTC)

Older free Carnegie Mellon robotics courses for NXT, EV3, VEX IQ and ROBOTC.

FREEComputingRoboticsUnverified

The privacy details for this item are unverified. Check which tools and accounts students will use before class.

Overview

This is a group of older Carnegie Mellon Robotics Academy courses listed as legacy. The catalog says they are no longer actively supported and are freely available as is. The list covers LEGO NXT, LEGO MINDSTORMS EV3, VEX IQ, VEX Cortex and ROBOTC courses. The EV3 intro course has 10 projects plus a capstone and takes about 6 weeks.

Benefits

For students

  • Students build and program real robots with step by step projects.
  • Students finish an EV3 capstone challenge.
  • Students can use block or ROBOTC programming, depending on the course.

For teachers

  • Most legacy entries list a matching course on the CS-STEM Network.
  • Student tracking is available through CS2N.
  • The courses cost nothing to download.

For schools

  • The courses are free as is. Retired robot kits and software are separate.
  • LEGO has retired the EV3 platform and ROBOTC for EV3 is no longer supported.
  • Several ROBOTC VEX IQ courses are still hosted.

Getting started checklist

Where is the AI in this product?

The vendor does not describe any AI in these courses. Students build and program robots with block or ROBOTC code. Students build skills in sequencing, sensors and logic.

Privacy and safety

Course pages say student tracking uses CS2N, and the research did not confirm whether the legacy courses require a CS2N account. The CS2N policy lists name, email, username, and course activity. Robot programming software runs on the student computer. The materials do not state what internet access the courses need. A teacher should check which course needs an account and read the CS2N privacy policy.

How this can be used for Engineering and Design
  1. Build the EV3 robot from the first project and test its drive.
  2. Compare two robot designs on speed and accuracy.
  3. Add a sensor to a robot and describe what it adds.
  4. Finish the capstone challenge and document each design change.
  5. Present a robot to the class and explain each part.
How this can be used for Computer Science
  1. Program the robot to drive a set distance and then stop.
  2. Use a sensor to make the robot react to a wall.
  3. Write a loop that repeats a movement four times.
  4. Compare a block program with a ROBOTC program for the same task.
  5. Debug a program that turns the wrong way.
