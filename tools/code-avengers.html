Code Avengers

An online coding platform with story-based junior courses and text coding for older students.

AIComputingSends student data to a company

Overview

Code Avengers is an online platform for learning coding, web development, design, and computer science. Code Avengers JR is story-based for ages 5 to 14. PRO is for ages 12 and up and uses real languages such as JavaScript, Python, HTML5, and CSS3. Courses have 10 to 30 lessons of five tasks each with quizzes.

Benefits

For students

  • Students move from story-based coding to real languages on one platform.
  • Students get quizzes and automatic marking as they work.
  • Students use a built-in coding environment in the browser.

For teachers

  • The EDU offering adds a teacher dashboard with progress and time on task.
  • Automatic marking and a spreadsheet export save grading time.
  • A US curriculum alignment guide is available.

For schools

  • School plans are paid. The pages read list a free trial and a school license but no prices.
  • Students can join through Google Classroom, SSO, or school logins.
  • The platform runs in a browser, including on a Chromebook.

Getting started checklist

Where is the AI in this product?

Code Avengers has no AI. Students build coding skills such as sequencing, logic, and debugging. These skills carry over to later AI learning. All the work happens in the vendor's cloud.

Privacy and safety

Every student needs an account, and the platform needs the internet at all times. The vendor collects registration details, progress, IP addresses, and server logs. The controller is Digital Education Ltd in New Zealand. For school accounts the policy relies on the school for parental consent. The policy names AWS, Cloudflare, Google Analytics, HubSpot, and payment vendors. It says it does not sell personal data or use it for targeted advertising. It does not name COPPA or FERPA, and it is inconsistent about Google Analytics. A separate Students Privacy Policy is linked, and the research did not read it. A teacher should read that policy with the school before students sign in.

How this can be used for Computer Science
  1. Complete a first JR story course and explain the code in your own words.
  2. Write a short JavaScript program that changes a web page.
  3. Build a simple page with HTML5 and CSS3 and style it.
  4. Write a Python program that asks for a name and prints a greeting.
  5. Compare the quiz results from two lessons and find one topic to practice.
