Code.org CS Discoveries Unit 6 Physical Computing interactive artwork

A Code.org lesson where students build interactive artwork with Circuit Playground sensors.

FREEComputingRoboticsSends student data to a company

Overview

This is Lesson 15 of the 2022-23 CS Discoveries Unit 6, titled Mini-Project: Interactive Art. Students build artwork from physical materials and use Circuit Playground sensors to detect input and respond. The App Lab screen is used only for debugging. The lesson runs about 90 minutes per a search snippet.

Benefits

For students

  • Students build artwork that reacts to touch, light or sound.
  • Students see their code change a physical object.
  • Students combine craft and computing in one project.

For teachers

  • The lesson is free on Code.org.
  • It fits an art or computer science class.
  • The lesson is available in English and Spanish.

For schools

  • The curriculum is free. Circuit Playground boards are bought separately.
  • IT needs to install the Maker Toolkit.
  • Chromebook support is not confirmed.

Getting started checklist

Where is the AI in this product?

This lesson has no AI. Students write code in App Lab that reads sensors and controls the board. Students build skills in sensors, inputs and outputs, and event-based logic.

Privacy and safety

Accounts are optional. Optional accounts store progress and code on Code.org, and without accounts only the IP address is collected. Code is written in App Lab in the browser and sent to the board through the Maker Toolkit. The internet is needed. The policy says it does not sell personal data or show ads. It says the nonprofit is not subject to COPPA and treats school accounts as FERPA student records. The research could not read the lesson page text. A teacher should read the Code.org privacy policy and decide whether students need accounts.

Ideas by subject

Select a subject to see five classroom ideas.

How this can be used for Visual Arts
  1. Build a piece of art from physical materials that lights up when touched.
  2. Sketch an interactive artwork and list what it should sense.
  3. Choose colors and sounds for each response of the artwork.
  4. Show the finished artwork and explain how a viewer interacts with it.
  5. Redesign the artwork after a classmate tests it.
How this can be used for Computer Science
  1. Read a sensor value in App Lab and show it on the screen.
  2. Write code that lights an LED when a sensor passes a limit.
  3. Use the screen to debug a program that does not respond.
  4. Change a threshold and describe how the response changes.
  5. Compare two programs for the same artwork.
How this can be used for Engineering and Design
  1. Design a sensing artifact and write down its goal.
  2. Test the artwork with a partner and record what fails.
  3. Improve the build to hold the board safely.
  4. Compare two sensors for one task and choose the better.
  5. Present the final design and explain each choice.
