iRobot Education Coding app and Root simulator

A free coding app with a simulated Root robot and three coding levels.

ComputingRobotics

The official website did not respond when we checked in November 2026. Confirm that this tool is still available before you plan with it.

Overview

This free coding and simulation platform launched in April 2020 with a simplified 2D simulator of the Root robot. The simulated robot has bumpers, sensors, lights and a pen on a whiteboard. It has three coding levels, from drag and drop blocks to variables and logic to text code. It works on Android, Chrome OS, Windows, iOS and macOS. Code written in the simulator is meant to transfer to a physical Root robot.

Benefits

For students

  • Students code a robot without owning one.
  • Students move from blocks to text code in three levels.
  • Students draw with the simulated pen.

For teachers

  • The app opens in minutes on common devices.
  • Lessons and code samples were offered as downloadable PDFs, and some align to Common Core.
  • The materials rate the teacher learning curve as easy.

For schools

  • The app was free at launch.
  • Premium teacher lessons cost 5 USD per month after a free period then.
  • The Root line passed to SAM Labs in 2024. Current availability needs a check.

Getting started checklist

Where is the AI in this product?

This app has no AI. The simulated robot follows the program students write. Students build skills in sequencing and logic.

Privacy and safety

The app needs the internet and sends data to the vendor. The materials do not confirm what is collected or whether accounts are needed. Search snippets say the policy moved to a SAM Labs domain and was updated May 9, 2025. An older iRobot Education policy snippet names Google Analytics, Google Cloud, and Amazon Web Services, and says the products do not intentionally collect data from children under 13. That is a data rule, and the policy page itself was not readable. A teacher should read the current privacy policy and the account terms before students use it.

How this can be used for Computer Science
  1. Run the first block program and make the simulated robot move.
  2. Draw a square on the whiteboard with the pen.
  3. Use a bumper sensor to turn the robot away from a wall.
  4. Add a variable to count how many turns the robot makes.
  5. Rewrite a block program as text code.
