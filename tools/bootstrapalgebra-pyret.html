Bootstrap:Algebra (Pyret)

A free module that teaches algebra through programming a video game.

Computing

Overview

Bootstrap:Algebra is a free module that teaches algebra ideas through programming in game and design contexts. It covers functions, ratios, coordinates, and inequalities. It comes in a Pyret version and a WeScheme version. The official page gives grades 7-12 and says it suits teachers with no programming experience. A teacher guide and a student workbook PDF are provided.

Benefits

For students

  • Students program a video game with algebra functions.
  • Students practice coordinates and function rules in a game.
  • Students can do the workbook on paper.

For teachers

  • The module is designed for teachers with no programming experience.
  • A teacher guide and workbook are provided.
  • It can run inside an algebra class or as a standalone CS class.

For schools

  • The materials are free.
  • Standards alignments are linked, including Common Core, CSTA, and NGSS.
  • Studies of the program were small and not randomized.

Getting started checklist

Where is the AI in this product?

Bootstrap:Algebra has no AI. It builds the skills of using functions and sequencing, as students write rules that move game objects. Students also practice reading coordinates.

Privacy and safety

The Pyret and WeScheme sites need the internet. Students can write programs without logging in, but they cannot save or share them. The policy says no personal information is collected from users who do not log in, although IP addresses may be recorded for anyone. Logged-in users are identified by a Google ID, with limited Google account and Drive data. Data is stored on Google cloud storage. The policy says Bootstrap does not knowingly collect personal information from children under 13 and does not sell data or show targeted ads. It does not describe Pyret, Drive saving, and WeScheme separately. The research did not confirm district level terms. A teacher should decide whether students log in and read the Bootstrap privacy policy first.

How this can be used for Math
  1. Use algebra functions to move a character on a coordinate plane.
  2. Write a function from a word problem and test it.
  3. Use a ratio to resize a game image.
  4. Write an inequality that decides whether a player is in range.
  5. Compare a function on paper to the same function in code.
How this can be used for Computer Science
  1. Write a first function in Pyret and test it with two inputs.
  2. Build a game screen with a background and a target.
  3. Add a rule that moves the player with the keys.
  4. Fix an error in a short program.
  5. Present the game and explain how the rules work.
