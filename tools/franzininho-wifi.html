Franzininho WiFi

An open hardware ESP32-S2 board for learning electronics and programming.

ComputingStays on the device

Overview

Franzininho WiFi is an open hardware development board from the Brazilian Franzininho project of engineer Fabio Souza. It uses the ESP32-S2 module with a 240 MHz single-core processor and 4 MB flash. It has breadboard-compatible headers, an RGB LED, and a JTAG connector. It was built to teach electronics and programming to students and makers in Brazil.

Benefits

For students

  • Students build circuits on a breadboard-compatible board.
  • Students program in Arduino, MicroPython, or CircuitPython.
  • Students can use the built-in Wi-Fi.

For teachers

  • It supports ESP-IDF, Arduino, CircuitPython, and MicroPython.
  • The project lists English and Portuguese.
  • The board is open hardware.

For schools

  • The price is not stated in the sources read.
  • It needs only a computer with USB and a micro USB cable.
  • Sources are the vendor news post and the project repo only.

Getting started checklist

Where is the AI in this product?

The board has no AI. It builds sensing, logic, and programming skills. Students wire parts and write code that reads and controls them.

Privacy and safety

No account is needed and tool installation needs the internet. The board runs the uploaded program locally. Data leaves the device only if a project uses Wi-Fi. The materials describe no student data collection and the research found no privacy policy. A teacher should check the Wi-Fi settings before students connect the board to a network.

How this can be used for Engineering and Design
  1. Wire an LED and a button to the breadboard headers.
  2. Test the RGB LED with different colors.
  3. Build a simple circuit and draw its diagram.
  4. Measure a signal with a meter.
  5. Document a build with a parts list.
How this can be used for Computer Science
  1. Upload a blink program in Arduino.
  2. Change the blink speed and predict the result.
  3. Read a button and turn on an LED.
  4. Write the same program in MicroPython.
  5. Compare the two versions and describe the differences.
