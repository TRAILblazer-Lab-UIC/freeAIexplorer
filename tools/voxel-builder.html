Voxel Builder

A free voxel 3D modeling app that runs in a browser or on a desktop.

The official website did not respond when we checked in November 2026. Confirm that this tool is still available before you plan with it.

Overview

Voxel Builder by nimadez on GitHub is a free voxel based 3D modeling app. It runs in a browser or as an Electron desktop app. Users model, paint, and render voxels and export to GLB, GLTF, OBJ, and STL. The research could not confirm that it is the same product as the one in the discovery list.

Benefits

For students

  • Students build 3D shapes block by block.
  • Students can paint and render their models.
  • Students can export models for 3D printing.

For teachers

  • The tool is simple to learn.
  • It saves and loads JSON and imports MagicaVoxel VOX files.
  • It suits art and engineering classes.

For schools

  • The app is free and the code is open source.
  • It runs in Chrome or Firefox, and also as a desktop app.
  • Chromebook use was not confirmed.

Getting started checklist

Where is the AI in this product?

This tool has no AI. Students place every voxel by hand. They build spatial reasoning and design skills as they plan a model in three dimensions.

Privacy and safety

The README describes no account step. It says the project is ad free with no trackers and no logging, but this applies to the nimadez project only, which may not be the listed product. The internet is used at setup, and the hosted web version loads from the web. A teacher should confirm that this project matches the product they mean to use and should prefer the offline desktop app.

How this can be used for Visual Arts
  1. Build a small character out of voxels and paint it.
  2. Make a landscape scene with several colors.
  3. Recreate a pixel art picture in three dimensions.
  4. Render a model and compare different colors.
  5. Show a gallery of models and discuss choices.
How this can be used for Engineering and Design
  1. Design a simple object and export it to STL.
  2. Build a model that fits a given size.
  3. Redesign a model to use fewer voxels.
  4. Test how a model looks from each side.
  5. Print a model and note how the print differs from the screen.
