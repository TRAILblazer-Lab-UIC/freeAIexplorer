Sonic Pi Cambridge and Raspberry Pi scheme of work

A KS3 computer science scheme of work that teaches coding with Sonic Pi.

FREEComputingStays on the device

Overview

This is a scheme of work for introductory KS3 Computer Science using Sonic Pi. It is a zipped bundle of PDF lesson plans developed by ICT teachers and researchers at the University of Cambridge. KS3 is England, ages 11 to 14. Students write code that makes music.

Benefits

For students

  • Students learn text-based programming through music.
  • Students hear the result of each program.
  • Students build skills across a full year of lessons.

For teachers

  • The bundle gives ready-made PDF lesson plans.
  • Carrie Anne Philbin and Sam Aaron worked on the scheme, per a search snippet.
  • The lesson plans are licensed CC BY-SA 3.0.

For schools

  • The materials are free.
  • The scheme is mirrored on GitHub under raspberrypilearning.
  • IT must install Sonic Pi on each computer.

Getting started checklist

Where is the AI in this product?

This scheme has no AI. Students write code that plays music on the computer. They build sequencing, loop, and pattern skills. The lessons use text-based programming.

Privacy and safety

No account is needed, and the internet is used at setup. Sonic Pi is a local desktop app and the lessons are PDFs. The page does not discuss data, and the research found no privacy policy. A teacher should check that headphones are available for each student.

How this can be used for Computer Science
  1. Write a program that plays a short sequence of notes, as in the first lessons.
  2. Use a loop to repeat a pattern.
  3. Add a variable to change the speed of a tune.
  4. Write a program with a random choice of notes.
  5. Debug a classmate's code and explain the fix.
How this can be used for Music
  1. Compose a short tune from code.
  2. Build a rhythm with a drum sample.
  3. Change the key of a melody and compare the sound.
  4. Layer two parts to make a simple song.
  5. Perform a piece and describe the code behind it.
