Steam Clown LeRobot arm lessons

Free work-in-progress lessons for building and running SO-101 robot arms in a club.

FREEAIRoboticsUnverified

The privacy details for this item are unverified. Check which tools and accounts students will use before class.

Overview

This is a work-in-progress lesson set for building and running Hugging Face LeRobot SO-101 robot arms. It was written by a mechatronics instructor at a career technical education high school. The page has Linux and Windows install labs, a build lesson, and a calibration and teleoperation check. It suits a robot club in grades 9 to 12.

Benefits

For students

  • Students build a leader arm and a follower arm.
  • Students calibrate and teleoperate the arms with LeRobot commands.
  • Students learn from lessons tested in a real school robotics team.

For teachers

  • The page says no electronics, logic, or coding knowledge is required.
  • Install labs cover both Linux and Windows.
  • The page includes a list of lab and tutorial ideas.

For schools

  • The lessons are free.
  • The arms need printed parts, Feetech servos, and a control board, and no total cost is given.
  • IT will likely need to help install Ubuntu or Miniconda.

Getting started checklist

Where is the AI in this product?

The AI is the LeRobot framework, which is a robotics toolkit from Hugging Face. These lessons focus on setup, building, calibration, and teleoperation. The vendor does not say where any AI runs. Students control the follower arm with the leader and prepare for later training work.

Privacy and safety

The page links to Hugging Face and GitHub repositories but does not say an account is required. Commands run on the student computer over serial ports. The research found no data collection described, and the materials do not say where data goes. A teacher should check which tools and accounts students need, including GitHub and Hugging Face. A teacher should also supervise 3D printing and soldering or wiring tasks. Several slide decks are marked coming soon.

Ideas by subject

Select a subject to see five classroom ideas.

How this can be used for Career and Technical Education
  1. Follow the build lesson and keep a log like a shop technician.
  2. Plan a robot club schedule that covers install, build, and calibration labs.
  3. Write a checklist for the final calibration and teleoperation check.
  4. Present the finished arm to a visitor and explain each part.
  5. Compare the lesson steps with the work of a mechatronics technician.
How this can be used for Engineering and Design
  1. Assemble the follower arm and test each joint.
  2. Build the leader arm and compare it with the follower.
  3. Calibrate both arms and note any joint that needs adjusting.
  4. Troubleshoot a loose servo and describe the fix.
  5. Suggest one change that would make the arm sturdier.
How this can be used for Computer Science
  1. Install Miniconda and create an environment for LeRobot.
  2. Run a lerobot command and explain what it printed.
  3. Compare the Linux install steps with the Windows steps.
  4. Write a short guide for a new student on installing LeRobot.
  5. Teleoperate the arm and describe how the leader's moves reach the follower.
