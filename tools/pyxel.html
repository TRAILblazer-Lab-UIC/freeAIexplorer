Pyxel

A free retro game engine for Python with built-in art and music editors.

FREEComputingStays on the device

Overview

Pyxel is a retro game engine for Python. It has small limits in the style of retro consoles. It includes an image and tilemap editor and a sound and music editor. The project site hosts showcase examples such as a jump game and a platformer.

Benefits

For students

  • Students make a complete game with art, sound, and code.
  • Students work inside small limits that keep a project manageable.
  • Students can share a game through the web build.

For teachers

  • The built-in editors keep all the game parts in one tool.
  • Showcase examples give teachers ideas and code to study.
  • Teachers will need some Python knowledge first.

For schools

  • The software is free and open source.
  • Games and files stay on the computer.
  • IT may need to approve Python installs, and Chromebook use is not confirmed.

Getting started checklist

Where is the AI in this product?

Pyxel has no AI. It builds an AI-related skill, which is logic. Students write rules for how a player moves and what happens on a hit. That practice shows how programs decide.

Privacy and safety

No account is needed, and the internet is used only at setup. Games and assets stay on the device. A teacher should note that the vendor materials found only package listings and community tutorials. A teacher should test the install and review any shared game before class.

How this can be used for Computer Science
  1. Study a showcase platformer and list what the code does on each key press.
  2. Draw a sprite in the image editor and show it in a program.
  3. Write code that moves a character across the screen.
  4. Add a sound from the music editor to a game event.
  5. Change one rule in a jump game and describe how play changes.
