Matchbox computer (Explorable Data Science)

Overview

This is a page in the University of Gottingen Explorable Data Science project. It explains MENACE, the matchbox tic-tac-toe machine that Donald Michie conceived in the 1960s. The machine learns by reinforcement. It adds beads to winning moves and removes beads from losing moves. The page does not describe a ready-made lesson, downloads, or an age group.

Benefits

For students

  • Students read a clear account of how a matchbox machine learns.
  • Students see an early example of reinforcement learning.
  • Students can connect the idea to modern AI.

For teachers

  • The page is available in English and German.

For schools

  • The page does not state costs.
  • A physical MENACE needs about 304 matchboxes and beads.
  • The page gives no teacher preparation steps.

How this can be used for Computer Science
  1. Read the MENACE page and explain in your own words how the machine picks a move.
  2. Draw one matchbox with the beads for a single board position.
  3. Predict what happens to the beads after a win and after a loss.
  4. Compare MENACE with a modern program that learns from results.
  5. Plan how a class could build a small version with paper cups and beads.
