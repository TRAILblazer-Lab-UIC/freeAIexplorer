HP Otto Robot Kit

A bipedal walking robot kit based on the open Otto DIY design.

ComputingRobotics

The privacy details for this item are unverified. Check which tools and accounts students will use before class.

Overview

The HP Otto Robot Kit is a bipedal walking robot kit sold under the HP Robots name and based on the open Otto DIY design. The Creator edition ships electronics and tools and expects schools to 3D print the body. The Builder edition ships printed parts. Students program it in a browser with blocks or Python, or in C++ through the Arduino IDE.

Benefits

For students

  • Students build a walking robot.
  • Students can start with blocks and move to Python or C++.
  • Students use line tracking and ultrasonic sensors.

For teachers

  • Browser programming needs no install.
  • The kit works with Otto DIY code.
  • The Builder edition removes the need for a 3D printer.

For schools

  • Core Electronics Australia lists the Creator kit at 299 AUD including GST. A US price was not confirmed.
  • The Creator kit needs a 3D printer.
  • Listings give different ages, from 8 plus with supervision to 14 plus.

Getting started checklist

Where is the AI in this product?

The Otto robot has no AI. It follows the code that students write. Students build skills in sequencing and sensors.

Privacy and safety

The retailer page describes a browser based coding environment and an onboard Bluetooth and Wi-Fi board. The materials do not say whether the editor needs an account or the internet. The research did not confirm whether the editor sends student code to HP. The HP article could not be read, and no data practices were found. A teacher should check the editor terms before students use it and supervise young builders, as the listings advise.

How this can be used for Engineering and Design
  1. Print or assemble the body and list each part.
  2. Test the walking speed and record the result.
  3. Adjust a leg part and compare the walk.
  4. Use the line tracking sensors on a taped path.
  5. Write a build log for the robot.
How this can be used for Computer Science
  1. Program the robot to walk forward in blocks.
  2. Use the buzzer and RGB LEDs to signal a turn.
  3. Use the ultrasonic sensor to stop at an obstacle.
  4. Compare a block program with the Python version.
  5. Run a short C++ sketch in the Arduino IDE.
