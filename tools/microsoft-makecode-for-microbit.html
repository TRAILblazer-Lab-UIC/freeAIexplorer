Microsoft MakeCode for micro:bit

A block and JavaScript editor with a simulator for the BBC micro:bit.

FREEComputingLocal with optional cloud or accounts

Overview

MakeCode for micro:bit is an editor for the BBC micro:bit with an on-screen simulator. Students build programs from blocks, switch to JavaScript text, test in the simulator, and download a file to the board. It runs in a browser, and an offline app exists for Windows and Mac.

Benefits

For students

  • Students move from blocks to JavaScript in the same project.
  • Students test code in the simulator without a board.
  • Students add new blocks through extensions.

For teachers

  • The editor opens in a browser in minutes.
  • Sign in is optional.
  • The site offers First lessons with MakeCode and the micro:bit.

For schools

  • The editor is free, and the board costs extra.
  • The offline app lets work continue without the internet.
  • The code is open source.

Getting started checklist

Where is the AI in this product?

This tool has no AI. It builds the skills of sequencing, loops, and logic. Students also practice reading blocks and matching them to text code.

Privacy and safety

No account is needed, but sign in with a Microsoft or Google account is optional and enables cloud saving. Sign in data is stored in Microsoft data centers in the United States. The editor collects anonymized product telemetry, such as browser type or button clicks, with no personally identifiable information. The privacy FAQ says student personal data is not sold or used for advertising, and school accounts are controlled by the school. Without sign in, projects stay in the browser cache. A teacher should remind students that clearing browser data erases local projects. Students should export a file.

How this can be used for Computer Science
  1. Build a name badge program with blocks and test it in the simulator.
  2. Switch the program to JavaScript and find the matching lines.
  3. Use a loop to blink an image on the display.
  4. Add an extension and use one new block.
  5. Download the file, copy it to a board, and show the class.
