Experiments with Google for Learning

A Google collection of about 30 browser experiments, including AI drawing and training tools.

AIGood for AI beginners

The privacy details for this item are unverified. Check which tools and accounts students will use before class.

Overview

Experiments with Google for Learning is a curated collection of about 30 browser experiments. They are grouped by theme, including music, drawing, math and science, space, history, and a Coding + AI group. The Coding + AI group lists Teachable Machine and Tiny Sorter. Drawing lists Quick, Draw! and AutoDraw. Most entries open an external site.

Benefits

For students

  • Students try AI tools that run in the browser.
  • Students can draw, make music, and train a model.
  • Students explore topics from space to history.

For teachers

  • One page links to many short experiments.
  • A reviewer suggests picking two or three age-appropriate experiments and having students share what they learned.
  • The page does not confirm which experiments are live. A teacher should test each one.

For schools

  • The experiments are free.
  • Students need only a web browser.
  • No install is needed.

Getting started checklist

Where is the AI in this product?

Some experiments use AI to recognize drawings or classify images. They run in the browser, and some call a company's cloud. Students draw, train, and test the tools. They use the results to explain how a model makes guesses.

Privacy and safety

The collection page needs no account, and the internet is always needed. Each experiment opens an external site, and some call a company's cloud. The collection page links only to a general Google Privacy and Terms page and has no details for each experiment. The research did not check data handling for individual experiments, and it does not know which ones are still live. A teacher should check each experiment before class and turn off the camera if it is not needed.

Ideas by subject

Select a subject to see five classroom ideas.

How this can be used for Computer Science
  1. Train a model in Teachable Machine to tell two objects apart.
  2. Use Tiny Sorter and describe the rule it learns.
  3. Test Quick, Draw! with a hard drawing and see if it guesses.
  4. Compare two experiments and decide which one teaches more about AI.
  5. Explain in a paragraph how a model could learn from your drawings.
How this can be used for Visual Arts
  1. Draw with AutoDraw and compare its suggestions with your own sketch.
  2. Play Quick, Draw! and review how your drawing style changes the guess.
  3. Create a picture with one experiment and add a hand drawn detail.
  4. Discuss how a tool that suggests shapes changes your art.
  5. Display a set of drawings with a note on how each was made.
How this can be used for Music
  1. Try an experiment in the Create Music group and make a short tune.
  2. Change one setting and describe how the sound changes.
  3. Compare two music experiments and list the differences.
  4. Write a short note on how a tool turns your input into music.
  5. Share your tune with a partner and ask for feedback.
How this can be used for Science
  1. Plan a science fair idea that uses Teachable Machine, such as sorting leaves.
  2. Collect images for two groups and train a model.
  3. Test the model on new images and record the accuracy in a table.
  4. Explain where the model made mistakes and why.
  5. Present the results with a short poster.
