Concord Dynamic Data Science

Concord activities where students analyze large data sets in CODAP.

Computing

The privacy details for this item are unverified. Check which tools and accounts students will use before class.

Overview

Dynamic Data Science is a set of activities for working with large, complex data sets again and again. Students act within a context. They then store, organize, analyze, and visualize data in CODAP, the Common Online Data Analysis Platform. The page says it is designed for grades 9 to 14. It is aligned to NGSS and Common Core.

Benefits

For students

  • Students work with large real data sets.
  • Students see linked graphs, maps, and tables.
  • Students practice organizing and analyzing data.

For teachers

  • The activity list did not load during research. Check that activities appear before planning.
  • The materials were built with NSF funding.
  • A virtual workshop for high school science and computer science teachers is documented.

For schools

  • The discovery note says it is free, but the page does not state a cost.
  • It runs in a browser on Chromebooks.
  • The internet is needed at all times.

Getting started checklist

Where is the AI in this product?

This curriculum has no AI. It builds skills in data and pattern spotting. Students look for trends in large data sets and explain them.

Privacy and safety

The materials do not state which accounts students need. They do not say what data is collected. CODAP runs in the browser. A teacher should check whether students must sign in and where saved work is stored.

Ideas by subject

Select a subject to see five classroom ideas.

How this can be used for Science
  1. Study a large data set from a science context and write a claim.
  2. Graph two variables and describe how they relate.
  3. Map data to find where a pattern is strongest.
  4. Filter the data to test a new question.
  5. Share a finding with a graph as evidence.
How this can be used for Math
  1. Store and organize a data set in CODAP.
  2. Compute a mean and a median and compare them.
  3. Build a scatter plot and describe the trend.
  4. Group data and compare the groups.
  5. Explain what a graph shows and what it leaves out.
How this can be used for Computer Science
  1. Visualize a large data set with linked views.
  2. Sort and filter data to find a pattern.
  3. Compare two visualizations of the same data.
  4. Describe how data is stored in a table.
  5. Discuss how computers help people explore data.
