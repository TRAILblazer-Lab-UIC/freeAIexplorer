Strype

A browser editor that helps students move from blocks to typed Python.

FREEComputingUnverified

The privacy details for this item are unverified. Check which tools and accounts students will use before class.

Overview

Strype is a frame-based editor for Python that runs in the browser. It is built by Michael Kolling and the K-PET group at King's College London, who also make BlueJ and Greenfoot. It is aimed at secondary school students moving from blocks to text-based Python. Students build Python programs in frames and can upload code to a micro:bit.

Benefits

For students

  • Students write real Python with frames that guide the layout.
  • Students get autocompletion, including help for the micro:bit.
  • Students can send code to a micro:bit over USB.

For teachers

  • The tool gives a bridge between blocks and typed code.
  • The GitHub page calls it an entirely client-side tool with no server component.
  • Teachers can try the micro:bit version at strype.org/microbit.

For schools

  • The tool is free and the source code is open.
  • Nothing is installed and it runs in the browser, including on Chromebooks.
  • A micro:bit upload needs a WebUSB capable browser.

Getting started checklist

Where is the AI in this product?

Strype has no AI. It helps students write correct Python by shaping the code into frames. Students build the skill of reading and writing text code with logic and loops.

Privacy and safety

No account is needed. The GitHub page calls Strype entirely client side. The research found no privacy policy, and the page for it returned an error. A roadmap mentions saving projects to OneDrive, and the repo lists an analytics summary that the research did not read. The materials do not state how much internet access Strype needs. A teacher should confirm where student programs are saved and ask the vendor what the site collects.

How this can be used for Computer Science
  1. Build a short Python program in frames that prints a message to the screen.
  2. Recreate a simple block project as a Python program and compare the two.
  3. Write a loop that counts and explain each line to a partner.
  4. Use autocompletion to find a function and note what it does.
  5. Upload a program to a micro:bit and test how the board responds.
