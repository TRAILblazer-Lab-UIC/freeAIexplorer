Cytron Edu Pico

A Raspberry Pi Pico kit with pre-connected sensors for MicroPython and CircuitPython.

Computing

Overview

Edu Pico is an all-in-one project kit from Cytron built around a Raspberry Pi Pico. Search coverage describes a board with pre-connected sensors and Grove connectors. Learners practice electronics and CircuitPython programming. Students program the board over USB from a local computer.

Benefits

For students

  • Students use sensors that are already connected.
  • Students write real MicroPython or CircuitPython.
  • Students see code change what the board does.

For teachers

  • Pre-connected sensors cut down on wiring time.
  • Teachers can use a Pico or a Pico W.
  • DigiKey suggests MicroPython as the environment.

For schools

  • A search snippet reports a launch price of 48 USD for the base kit and 54 USD with a Pico W.
  • DigiKey lists 50.99 USD for one unit, and prices vary by distributor.
  • One UK listing said the kit was no longer stocked. Check stock before ordering.

Getting started checklist

Where is the AI in this product?

This kit has no AI. It builds skills in sensors, data, and logic. Students read sensor values and write code that responds.

Privacy and safety

No account is needed, and the board works with no internet. Programs load over USB from a local computer. No privacy policy was reviewed. The Pico W variant has WiFi hardware, and the research did not confirm whether any kit example uses it. A teacher should check that school computers allow USB programming and which variant the school buys.
