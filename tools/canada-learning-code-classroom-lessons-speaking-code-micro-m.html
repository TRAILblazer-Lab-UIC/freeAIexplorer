Canada Learning Code classroom lessons (Speaking Code, Micro Music, Dance Off)

Free classroom lessons that use Scratch, ScratchJr, and micro:bit.

FREEComputingUnverified

The privacy details for this item are unverified. Check which tools and accounts students will use before class.

Overview

Canada Learning Code publishes free classroom lessons. Speaking Code is a seven-lesson unit for grades 4-6 that links to English Language Arts and Science and Technology, with Scratch for a final video game. Micro Music is three projects for grades 4-6 where students code music on a micro:bit in MakeCode. Dance Off is a 45-minute ScratchJr lesson for grades 1-3 on algorithms and sequence.

Benefits

For students

  • Students code stories, music, and dances.
  • Students use block-based and unplugged activities.
  • Students create a video game at the end of Speaking Code.

For teachers

  • Lesson PDFs can be downloaded.
  • Speaking Code takes about 9.5 hours in total.
  • Self-directed modules are available as an alternative.

For schools

  • The lessons are free.
  • micro:bits are a separate purchase for Micro Music.
  • The vendor does not say what IT setup is needed.

Getting started checklist

Where is the AI in this product?

These lessons have no AI. They build the skills of sequencing and algorithms, as students order steps in a dance or a song. Block-based coding adds logic.

Privacy and safety

The materials do not state which accounts students need, whether the internet is required, or where student work goes. Speaking Code uses Scratch and code.org activities. Some Flocabulary videos need a free trial sign up. ScratchJr runs on tablets, and Scratch and MakeCode are online tools. The research did not check the data handling of any of these tools. A teacher should check the privacy terms of each tool before students use them.

Ideas by subject

Select a subject to see five classroom ideas.

How this can be used for English and Language Arts
  1. Code a short story scene in Scratch, as in Speaking Code.
  2. Use speech bubbles to write a dialogue.
  3. Plan a story with a beginning, a middle, and an end before coding.
  4. Trade projects and write feedback.
  5. Present the final video game and explain its story.
How this can be used for Music
  1. Code a short tune on a micro:bit in MakeCode, as in Micro Music.
  2. Change the notes and tempo and describe the change.
  3. Add a button that plays a second tune.
  4. Write a pattern of beats and code it.
  5. Perform the tunes as a class.
How this can be used for Math
  1. Plan a dance routine as a list of steps, as in Dance Off.
  2. Use ScratchJr to repeat a dance move.
  3. Compare two routines and count the steps.
  4. Find a pattern in a sequence of moves.
  5. Write the steps of a simple routine for a partner.
How this can be used for Computer Science
  1. Build a ScratchJr dance with a clear sequence.
  2. Use a loop in Scratch to repeat an action.
  3. Debug a partner's project.
  4. Use an unplugged activity to act out an algorithm.
  5. Explain what an algorithm is in your own words.
