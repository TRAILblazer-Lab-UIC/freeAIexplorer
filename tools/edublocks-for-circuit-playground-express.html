EduBlocks for Circuit Playground Express

A guide for programming the Circuit Playground Express with EduBlocks.

Computing

Overview

This Adafruit Learn guide shows how to program the Circuit Playground Express board with the block editor EduBlocks, which outputs CircuitPython. Students drag blocks, download a main.py file, and copy it to the CIRCUITPY drive. Three lessons cover a blinking LED, NeoPixel colours set by two buttons, and a touch pad drum machine that plays wav files.

Benefits

For students

  • Students see their blocks change real lights on a board.
  • Students build a touch pad drum machine.
  • Students see the Python code that blocks produce.

For teachers

  • Three lessons run from simple to more complex.
  • The workflow is the same each time. Build, download, and copy.
  • Optional extras include alligator clips and a speaker.

For schools

  • The guide and the editor are free.
  • The board is a separate purchase. Its price was not checked.
  • The guide shows no date and image names suggest 2019. EduBlocks was in beta at that time.

Getting started checklist

Where is the AI in this product?

This guide has no AI. It builds sensing and logic skills. Students link button and touch inputs to lights and sounds.

Privacy and safety

The guide mentions no account, and the programs are saved to the board. The editor is web based with no offline version described. The internet is needed. The research did not read the EduBlocks privacy policy. The materials describe no student data collection. A teacher should check that the editor still works with the current board software.

How this can be used for Computer Science
  1. Build a blinking LED program from blocks and download main.py.
  2. Read the Python code that the blocks produced and label each line.
  3. Change the blink speed and predict what will happen.
  4. Use two buttons to pick NeoPixel colours.
  5. Make a touch pad drum machine that plays wav files.
How this can be used for Engineering and Design
  1. Wire up the board and test each LED.
  2. Design a light pattern for a small badge or sign.
  3. Add alligator clips and test a new touch input.
  4. Tune the drum machine so each pad has a clear sound.
  5. Record test results for each build in a short log.
