Tommy the Turtle

A free early coding game where kids tap buttons to move a turtle.

Overview

Tommy the Turtle is a free early coding game for young children from Zyrobotics. Kids tap command buttons to move a turtle. The commands include forward, backward, grow, shrink, turn, spin, and jump. It introduces sequences and loops. A challenge mode offers puzzles. The developer says ages 3 and up and Common Sense Media says ages 5 and up.

Benefits

For students

  • Young children program by tapping, with no typing.
  • Children learn sequences and loops through play.
  • Challenge mode offers puzzles.

How this can be used for Computer Science
  1. Tap a short set of commands to move the turtle forward and turn, following the Hour of Code idea.
  2. Predict where the turtle will end up before you tap play.
  3. Use a loop to repeat a move.
  4. Solve a challenge mode puzzle with a partner.
  5. Act out a command sequence with your own body.
