Open Roberta Lab

A free browser tool for block coding many robots and boards.

ComputingRobotics

Overview

Open Roberta Lab is an open source platform where users build programs by drag and drop with the NEPO graphical language. It runs in a browser and supports many robots and boards, including Arduino, EV3, Edison, NAO, Spike, Thymio and WeDo. It also supports the micro:bit by generating MicroPython code. The same software can be self-hosted on a school server.

Benefits

For students

  • Students code many different robots with one block language.
  • Students can test programs in a simulation without hardware.
  • Students can save programs if they register an account.

For teachers

  • The lab opens in a browser in minutes.
  • Accounts are optional and teachers can set up user groups.
  • One tool covers many classroom robots.

For schools

  • The lab is free and the code is open source.
  • IT can self-host with the Docker image from the openroberta-docker repository.
  • Compiling for physical robots on a self-hosted server needs extra toolchains.

Getting started checklist

Where is the AI in this product?

The lab has no AI. It builds skills in sequencing, logic and program design. Students also learn how blocks turn into code for different robots.

Privacy and safety

The lab needs the internet at all times and runs in the vendor's cloud unless a school self-hosts it. An optional account collects a username, name, email, and age, and saved programs sit on the server. The research did not read the linked privacy policy and could not confirm where the hosted data is kept. A school can self-host with Docker to keep data on its own server. A teacher should avoid registered accounts or ask IT to self-host.

Ideas by subject

How this can be used for Computer Science
  1. Drag NEPO blocks to make a robot drive in a square in the simulator.
  2. Use a loop to repeat a movement.
  3. Add a sensor condition so the robot stops at a wall.
  4. Compare the blocks with the generated code.
  5. Trade programs with a partner and find any bug.
How this can be used for Engineering and Design
  1. Pick a robot or board and list what its sensors can do.
  2. Test the same program in the simulator and on a robot.
  3. Plan a robot task such as line following and write the steps.
  4. Compare two different boards and note what changes in the program.
  5. Document a working program for the next class.
