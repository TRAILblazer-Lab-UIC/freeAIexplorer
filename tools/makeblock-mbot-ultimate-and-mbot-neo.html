Makeblock mBot Ultimate and mBot Neo

Two Makeblock classroom robot kits programmed with blocks, Python, or Arduino C.

AIComputingRobotics

The privacy details for this item are unverified. Check which tools and accounts students will use before class.

Overview

mBot Neo is a classroom robot kit built on the CyberPi ESP32 controller. It has two encoder motors, an ultrasonic sensor, and a four-channel color sensor. mBot Ultimate 2.0 is a 10-in-1 build kit run by a MegaPi board and programmed with blocks or Arduino C. A review places the kits from elementary through high school. A Makeblock app adds a Voice Control mode.

Benefits

For students

  • Students build a robot and then program it.
  • Students on Neo can use blocks or Python.
  • Students on Ultimate can move toward Arduino C.

For teachers

  • The Makeblock app gives quick drive and draw modes.
  • Two kits cover a range of skill levels.
  • The Ultimate kit asks more of the teacher.

For schools

  • The Neo review kit with the Smart World add-on cost 218.99 USD. Ultimate 2.0 listed from 299.99 to 369.99 USD.
  • Neo uses mBlock 5, which IT will likely need to install.
  • Ultimate uses a USB-B upload.

Getting started checklist

Where is the AI in this product?

AI is optional. The only listed feature is voice control in the Makeblock app. The vendor does not say where it runs. Without it the robots have no AI, but students still build sequencing, logic, and sensor skills.

Privacy and safety

The materials do not state which tools or accounts students need. The Makeblock policy says it does not knowingly collect data from children under 13. That is a data rule and not an age limit. The policy does not mention mBlock, AI, or voice cloud services. Reviews did not mention a sign in requirement. A teacher should check whether mBlock and the mobile app need accounts. A teacher should also check what the voice mode sends to a cloud service.

How this can be used for Computer Science
  1. Program the robot to drive a square and explain each block.
  2. Use the ultrasonic sensor to make the robot stop before a wall.
  3. Use the color sensor to follow a line.
  4. Change a block program to Python and compare them.
  5. Plan a program that reacts to a voice command and test it.
How this can be used for Engineering and Design
  1. Assemble the robot and test each motor.
  2. Compare Neo and Ultimate and list the design differences.
  3. Tune the sensor positions for a line course.
  4. Measure how far the robot travels in five seconds.
  5. Design a task such as pushing a box and test it.
