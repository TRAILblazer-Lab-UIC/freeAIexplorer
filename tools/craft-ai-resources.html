CRAFT AI resources

Stanford's free collection of 45 classroom lessons about AI across subjects.

FREEAIUnverifiedGood for AI beginners

The privacy details for this item are unverified. Check which tools and accounts students will use before class.

Overview

CRAFT AI resources is a Stanford collection of 45 lessons about AI. The lessons are grouped into About AI, AI and Society, AI and Science, AI and Arts, AI and Language Arts, AI and Math, and AI and History-Social Science. Lessons run 20 to 120 minutes. Some use named tools such as ChatGPT, Gemini, Perplexity, Firefly, and Teachable Machine.

Benefits

For students

  • Students explore AI through the subjects they already study.
  • Students look at bias, misinformation, ethics, and creative uses.
  • Students try real tools in some lessons, such as Teachable Machine.

For teachers

  • Teachers can pick a lesson that matches their subject.
  • Lesson lengths range from 20 to 120 minutes.
  • Each lesson names the AI tool it needs. Teachers can plan ahead.

For schools

  • The collection is free to access.
  • The lessons run in a browser.
  • Some lessons use outside tools. The materials do not say which accounts students need.

Getting started checklist

Where is the AI in this product?

The collection teaches about AI and some lessons use AI tools. Tools named include generative AI chatbots, an image maker, and Teachable Machine for image classification. The tools run in the browser, and some run in a company's cloud. Students use them to test ideas and then discuss what the tools got right and wrong.

Key terms on this page

Short definitions of words used above and below. Select a term for the full glossary entry.

AI bias
AI bias is a pattern of unfair or one-sided results from an AI system.
Algorithm
An algorithm is a set of step-by-step instructions for doing a task.
Chatbot
A chatbot is a program that holds a written or spoken conversation.
Classifier
A classifier is an AI model that sorts inputs into groups.
Cloud AI
Cloud AI is AI that runs on a company's servers over the internet.
Generative AI
Generative AI is AI that makes new content.
Image classification
Image classification is an AI task that puts a single label on a whole picture.
Image generation
Image generation is AI that creates new pictures from a text description or a sketch.
Model accuracy
Accuracy is the share of answers an AI model gets right.
Model training
Training is the process where an AI model learns from examples.
Prompt
A prompt is the request or question you give an AI tool.

Privacy and safety

The materials do not state what student data is collected or which accounts students need. Some lessons use cloud AI tools such as ChatGPT and Gemini. Each lesson uses its own outside tool, and the data rules differ by lesson. The research did not verify the data flow lesson by lesson. A teacher should read the privacy terms of every tool before class and decide whether students sign in or the teacher demonstrates.

Ideas by subject

Select a subject to see five classroom ideas.

How this can be used for English and Language Arts
  1. Try the lesson Can AI help with storytelling and compare an AI draft to a student draft.
  2. Edit an AI written paragraph and mark what a human writer would change.
  3. List story ideas with a chatbot and pick one to write by hand.
  4. Check an AI summary of a short text against the original and note any mistakes.
  5. Write a short opinion piece on whether AI should help with school writing.
How this can be used for Science
  1. Train a model in Teachable Machine to sort two kinds of objects and test it.
  2. Find an image the model gets wrong and explain why it failed.
  3. Compare how two different training sets change the results.
  4. Record the accuracy of a model over ten tests in a simple table.
  5. Discuss how scientists might use image classification in research.
How this can be used for Music
  1. Try the lesson on creating music with generative AI and describe the result.
  2. Write two different text prompts for a song and compare the results.
  3. Listen to a human made tune and an AI made tune and list the differences.
  4. Discuss who should get credit for a song made with AI.
  5. Write lyrics by hand and ask the tool to suggest a melody style.
How this can be used for Visual Arts
  1. Use an image tool such as Firefly to make a poster from a text prompt.
  2. Change one word in the prompt and describe how the picture changes.
  3. Compare an AI image with a hand drawing of the same idea.
  4. Discuss how artists should be credited when AI is used.
  5. Create a class gallery with a label that says how each piece was made.
How this can be used for Social Studies
  1. Use the AI and History-Social Science lessons to explore how AI treats a historical topic.
  2. Check an AI answer about a past event against a trusted source.
  3. Look at an example of algorithmic bias and explain who it affects.
  4. Debate whether schools should set rules for AI use in research.
  5. Write a short timeline of how technology changed work in one era.
