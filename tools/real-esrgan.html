Real-ESRGAN

An open source tool that upscales and restores images and video frames.

AIComputing

Overview

Real-ESRGAN is an open source project for image and video restoration and upscaling. It offers a Python script that needs PyTorch. It also offers portable ncnn-vulkan programs for Windows, Linux, and macOS. The portable programs include all binaries and models. It is a command line tool for advanced high school students.

Benefits

For students

  • Students sharpen low resolution images with a real AI model.
  • Students compare the original and the upscaled result.
  • Students can try face enhancement in the Python script.

For teachers

  • The portable program needs no CUDA or PyTorch.
  • Teachers can show before and after images.
  • The ncnn build has fewer features than the Python script.

For schools

  • The software is free.
  • It needs a Vulkan-capable GPU for the portable program.
  • IT help is needed to install it.

Getting started checklist

Where is the AI in this product?

The AI is an image super-resolution model trained on synthetic data. It runs on the local GPU. Students give it a small or damaged image and view the sharper result. They can then judge what the model added.

Privacy and safety

No account is needed, and the internet is used at setup. The local programs and scripts process images on the device. The README also links online demos on Colab, Replicate, and Hugging Face Spaces, which would send images to those services. A teacher should tell students to use the local programs. A teacher should also remind students that the model invents detail. Some of the result may not match what was really there.

How this can be used for Visual Arts
  1. Upscale a small photo and compare it with the original.
  2. Restore a blurry scan of an old drawing and describe the changes.
  3. Upscale a video frame and discuss what the model guessed.
  4. Test a pixel art image and judge whether the result looks better.
  5. Write a short note that tells viewers an image was enhanced by AI.
