AI Racing League OpenCV lessons

Nine computer vision labs for Raspberry Pi, shown to high school students.

AIComputingRobotics

Overview

These are nine sample computer vision labs that were shown to high school students. The labs cover face detection, object detection, OCR, color detection, motion tracking, augmented reality, hand gestures, license plate recognition, and QR codes. They run on a Raspberry Pi or NVIDIA Nano with a camera. The page recommends a Raspberry Pi 3 with 4 GB of memory.

Benefits

For students

  • Students see computer vision work on a real camera.
  • Students try nine different vision tasks.
  • Students learn from labs shown to a high school club.

For teachers

  • The content is free.
  • The labs run in order and each has one clear task.
  • Teachers can pick the labs that fit their class.

For schools

  • A Raspberry Pi 4 with 8 GB costs about 75 USD per a search snippet.
  • The labs run on the device. The page does not say that images stay there.
  • Many pages look dated. Staff should check the current schedule.

Getting started checklist

Where is the AI in this product?

The labs use computer vision methods such as Haar cascades, pre-trained OpenCV models, and Tesseract OCR. Everything runs on the Raspberry Pi or Nano. Students run each lab, read the code, and change it. They then see how the results shift.

Privacy and safety

The page describes no accounts and does not discuss the internet. Setup downloads libraries. Processing runs on the Raspberry Pi. The dossier says camera images stay on the device, but the page does not say so directly. The page does not describe student data handling. A teacher should check the face detection labs. Students should only use their own images or those of people who agree.

How this can be used for Computer Science
  1. Run the face detection lab and count the faces the program finds.
  2. Change a color range in the color detection lab and watch the output.
  3. Use the OCR lab to read text from a printed page.
  4. Test the motion tracking lab and describe what it follows.
  5. Scan a QR code with the Pi and explain how the code works.
