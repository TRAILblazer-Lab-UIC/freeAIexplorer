Hiwonder Nexbit micro:bit AI Vision Robot

A micro:bit wheeled robot with a smart camera that recognizes colors and faces.

AIComputingRobotics

Overview

This is a micro:bit powered wheeled robot kit from Hiwonder with the WonderCam smart vision module. The camera recognizes colors, numbers, faces, and waste sorting cards. It also tracks colors, faces, and tags. The standard kit is sold without a micro:bit. Students program it with MakeCode blocks or a phone app.

Benefits

For students

  • Students program a robot that recognizes what it sees.
  • Students use drag and drop blocks in MakeCode.
  • Students try waste sorting cards for a real world task.

For teachers

  • The Hiwonder wiki lists ten AI Vision Game lessons.
  • The robot has a line follower, an ultrasonic sensor, and RGB lights.
  • Android and iOS apps and a Handlebit remote add control options.

For schools

  • RobotShop lists the standard kit at 143.99 USD.
  • A micro:bit is an added cost.
  • Recognition runs on the camera module. MakeCode needs internet to load unless used offline.

Getting started checklist

Where is the AI in this product?

The WonderCam module recognizes colors, numbers, faces, and waste sorting cards, and it tracks colors, faces, and tags. The recognition runs on the module. Students write block programs that decide how the robot reacts. They can build vision line following.

Privacy and safety

The wiki states no account, app, or internet requirement for the AI vision lessons. The research did not confirm whether the internet is needed for MakeCode, and it did not review the phone app. The wiki says the camera module recognizes on the module itself and the lessons load programs over USB. The retailer page does not describe data handling and no privacy policy was reviewed. A teacher should check the apps for permissions. A teacher should also set rules before students use face recognition.

How this can be used for Computer Science
  1. Follow the first wiki lesson and make the robot react to a color.
  2. Program the robot to track a face and describe how it works.
  3. Write block code that sorts a waste card into a bin.
  4. Use number recognition to give the robot a command.
  5. Compare the line follower and the vision line following mode.
How this can be used for Engineering and Design
  1. Assemble the robot and test each sensor.
  2. Mount the camera at a new angle and compare recognition.
  3. Build a track and tune the robot to finish it.
  4. Test the ultrasonic sensor at several distances.
  5. Design a sorting station for waste cards.
