iRobot Create 3

A Roomba-based robot platform that runs ROS 2 and a beginner Python playground.

The privacy details for this item are unverified. Check which tools and accounts students will use before class.

Overview

iRobot Create 3 is a mobile robot platform based on the Roomba i3 body. Its software is entirely ROS 2, with sensor data on ROS 2 topics and built-in behaviors such as docking and wall following. A Python Web Playground lets beginners program it over Bluetooth LE. It suits advanced high school students and college courses.

Benefits

For students

  • Students program a real robot with docking and obstacle behaviors.
  • Students start with Python in a web page.
  • Students can move on to ROS 2, a tool used in real robotics.

For teachers

  • Open documentation is available.
  • A free ROS 2 mini course with Tufts is available.
  • Tufts used Create 3 in a course that taught ROS 2 to undergraduates after Python.

For schools

  • The launch price in 2022 was 299 USD, according to coverage in search snippets.
  • Current sales status is unconfirmed.
  • The ROS 2 work needs IT help and a Wi-Fi network.

Getting started checklist

Where is the AI in this product?

The Create 3 has no AI. It runs built-in behaviors and the code students write. Students build skills in sensors and logic by reading sensor data and choosing an action.

Privacy and safety

No account is needed, and the internet is used for setup. The docs describe a local robot web server and local ROS 2 networking. They do not mention cloud features. The robot's own privacy terms were not reviewed, and the materials do not say what data the robot sends. A teacher should check the robot's Wi-Fi settings with IT.

How this can be used for Computer Science
  1. Run a first Python program in the Web Playground over Bluetooth.
  2. Read a bump sensor and make the robot back up.
  3. Write a program that drives the robot in a square.
  4. Subscribe to a ROS 2 topic and print the sensor data.
  5. Follow the Tufts mini course for one lesson and summarize it.
How this can be used for Engineering and Design
  1. Test the built-in docking behavior and record the success rate.
  2. Mount a small payload on the faceplate and test the robot's movement.
  3. Run wall following along a hallway wall and measure the distance.
  4. Compare the robot's behaviors in a clear room and a cluttered room.
  5. Draw a diagram of how the robot's sensors and actions connect.
