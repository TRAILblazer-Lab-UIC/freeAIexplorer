PyScript

An open source platform for running Python inside web pages.

FREEComputingStays on the device

Overview

PyScript is an open source platform for running Python in the browser. Python code goes in a script tag inside an HTML page. Apps can be shared as web URLs with no complicated installation. It began at Anaconda in 2022 and suits older students and teachers who know some web basics.

Benefits

For students

  • Students build web pages that run Python.
  • Students share an app as a link.
  • Students connect Python to a page in a way that feels like real web work.

For teachers

  • Teachers can build simple tools for class on a web page.
  • Tools such as EduBlocks have been built on it.
  • A CoderDojo Trento turtle graphics project built on PyScript was tested in a high school class.

For schools

  • The platform is free and open source.
  • Search coverage says it can help on locked-down school computers.
  • Pages can be hosted on school servers.

Getting started checklist

Where is the AI in this product?

PyScript has no AI. It builds an AI-related skill, which is logic. Students write Python that reacts to a button click or a change on the page. That practice shows how programs respond to events.

Privacy and safety

No account is needed. The getting started example loads files from pyscript.net. The first load needs the internet. The research did not read the docs on offline use and found no privacy policy. Python runs in the browser on the device. A page that a teacher hosts may add its own tracking. A teacher should check any page and any tool built on PyScript before students use it.

How this can be used for Computer Science
  1. Try a CoderDojo style turtle project and describe how it runs in a web page.
  2. Write a page that prints a message when a button is clicked.
  3. Display a list of numbers on a page with a loop.
  4. Change a config file and note what changes.
  5. Share the page URL with a partner and have them edit the code.
