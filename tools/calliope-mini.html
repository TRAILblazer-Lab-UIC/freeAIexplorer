Calliope mini

A small programmable board for primary schools, inspired by the micro:bit.

Computing

Overview

The Calliope mini is a single-board computer developed for German primary schools and inspired by the BBC micro:bit. It has a 5x5 LED matrix, compass, accelerometer, light sensor, two buttons, radio, and Bluetooth. It also has an RGB LED, speaker, microphone, and a DC motor controller. Students program it with MakeCode, a Scratch-based blocks editor, or MicroPython.

Benefits

For students

  • Students program a real board that lights up, plays sound, and senses.
  • Students can start with blocks and move to MicroPython.
  • Students can connect extra sensors through Grove adapters.

For teachers

  • Class sets exist for primary, secondary level I, and makerspace use.
  • Calliope Campus is a free browser classroom platform.
  • Teachers register to create rooms.

For schools

  • Class sets are ordered through the webshop or by quote request.
  • No price was shown on the pages read.
  • Boards need a USB cable and a computer or tablet with a browser.

Getting started checklist

Where is the AI in this product?

The Calliope mini has no AI. It builds the skills of sensors and logic, as students program a board to respond to light, motion, and sound. They also practice sequencing.

Privacy and safety

Programs run on the board, and the internet is needed for setup. Calliope Campus is a free online editor platform. Teachers register with an email to create Campus rooms, and students join by room code with optional registration. The research did not find the Campus privacy policy, which returned a 404 error. The materials do not say what student data Campus collects. A teacher should find the Campus privacy terms before registering a class.

How this can be used for Computer Science
  1. Program the LED matrix to show a name or a symbol.
  2. Use a button press to change what the board shows.
  3. Use the light sensor to switch a light on in the dark.
  4. Send a radio message to another board.
  5. Move from blocks to MicroPython for one small program.
How this can be used for Engineering and Design
  1. Read the accelerometer and build a step counter.
  2. Use the motor controller to drive a small motor.
  3. Add an external sensor through a Grove adapter.
  4. Design a case for the board and test it.
  5. Record sensor readings and explain a result.
