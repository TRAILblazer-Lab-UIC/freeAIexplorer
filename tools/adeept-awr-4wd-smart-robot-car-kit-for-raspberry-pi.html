Overview

This is a four-wheel-drive robot car chassis kit for a Raspberry Pi. It has independent wheels, line tracking, obstacle avoidance, and USB-C charging. A camera module streams video over WiFi and supports OpenCV projects. Students program it in Python and control it from a Windows, macOS, or Linux computer.

Getting started checklist

Where is the AI in this product?

The AI is optional. Students can use OpenCV for computer vision on the camera feed. The processing runs on the Raspberry Pi. Students write Python code that finds a line or object and then steers the car.
