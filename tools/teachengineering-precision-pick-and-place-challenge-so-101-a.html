TeachEngineering Precision Pick-and-Place Challenge (SO-101 arm)

A 75 minute lesson where teams program a robot arm to sort cubes into bins.

AIComputingRobotics

The privacy details for this item are unverified. Check which tools and accounts students will use before class.

Overview

This activity runs about 75 minutes for grade 11, with a range of 10 to 12. Student teams program an SO-101 robotic arm to sort cubes into bins by color or size. Students learn how warehouse robots sort items and follow the engineering design process. The content covers robot motion, coordinate systems, and basic programming logic.

Ideas by subject

Select a subject to see five classroom ideas.

How this can be used for Engineering and Design
  1. Work as a team to define the sorting problem and list the limits of the arm.
  2. Test the arm's reach and record how far it can move.
  3. Design a bin layout that reduces mistakes and test it.
  4. Run three trials and record how often the arm sorts correctly.
  5. Compare the SO-101 arm with the low cost cardboard arm and list differences.
How this can be used for Computer Science
  1. Write a program that makes the arm pick up one cube and place it in a bin.
  2. Add logic that sorts cubes by color into the right bin.
  3. Debug a failed pick and explain what changed.
  4. Reuse a function to move the arm to each of three bins.
  5. Describe in order the steps a warehouse robot follows to sort items.
How this can be used for Math
  1. Label the arm positions with x and y coordinates on a grid.
  2. Calculate the distance the arm moves between two bins.
  3. Predict where the arm will end up after a set of moves.
  4. Graph the success rate over several trials.
  5. Compare two bin layouts and use numbers to say which is better.
