Crazyflie

An open source nano quadcopter that students program with Python.

ComputingRobotics

Overview

Crazyflie is an open source nano quadcopter from Bitcraze that weighs about 32 g. The brushless version has about 10 minutes of flight time. Its client API is Python, with community APIs for several other languages. Bitcraze presents it for courses from introductory to graduate level, and DroneBlocks uses it in middle and high school.

Benefits

For students

  • Students fly and program a real drone indoors.
  • Students use Python to control the flight.
  • Students see control ideas in a small safe device.

For teachers

  • DroneBlocks sells a Crazyflie kit with a block-to-Python course.
  • Bitcraze lists university courses such as one at CMU.
  • Firmware updates go over radio or Bluetooth LE.

For schools

  • A drone costs about 200 USD and kits cost more. A DroneBlocks developer kit is 449 USD.
  • No account is needed and the internet is needed only at setup.
  • Flights last about 10 minutes and charging takes about 60 minutes.

Getting started checklist

Where is the AI in this product?

Crazyflie has no AI. The drone follows the Python code that students write on a computer. Students build skills in control, sensors and programming.

Privacy and safety

No account or cloud service is needed by the hardware or client library. The drone is controlled over a local radio link from a computer or gamepad, and the research found no student data collected. The internet is needed at setup. The research did not review a privacy policy. A teacher should plan a clear flight area, use prop guards and set rules for flight.

How this can be used for Computer Science
  1. Use the Python client to read a battery value and print it.
  2. Write a short script that makes the drone take off and land.
  3. Program a square path with a list of waypoints.
  4. Compare a block program from DroneBlocks with the same task in Python.
  5. Debug a script that sends the drone off course.
How this can be used for Engineering and Design
  1. Test how prop guards change the flight of the drone.
  2. Record flight time across three batteries and compare them.
  3. Plan a safe flight area and list the rules.
  4. Describe how the radio sends commands to the drone.
  5. Redesign a flight plan after a failed test.
