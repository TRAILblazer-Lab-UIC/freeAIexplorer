Machine Learning Unplugged course (Apps For Good)

An Apps For Good course on machine learning that runs without computers.

AIUnpluggedGood for AI beginners

Overview

This Apps For Good course teaches machine learning without computers. Session 1, What is machine learning, covers how machines learn and how they learn to identify images. Students build a model that sorts images. Materials include a lesson plan, a primer, a presentation, and a resource folder on Google Docs and Drive. Search results describe seven sessions that include facial recognition, natural language processing, recommendation systems, and ethics.

Getting started checklist

Where is the AI in this product?

The course has no running AI program. It teaches how machine learning works through paper activities. Students build a model that sorts images and later study topics such as neural networks and recommendation systems. They build skills in classification and in judging the ethics of AI tools.

Privacy and safety

The activities run on paper, and the materials describe no student data collection. The Session 1 page does not say an account is required to download materials. It links to teacher sign up and log in. The account rules are unconfirmed. The files sit on Google Docs and Drive links. The research read no privacy policy. A teacher should check that those sites open on the school network and check the account rules.

How this can be used for Computer Science
  1. Sort a set of images into groups and write the rules you used.
  2. Build a paper model that sorts new images and test it.
  3. Explain to a partner how a machine learns to identify an image.
  4. Compare how a recommendation system and an image sorter use data.
  5. Discuss a fairness problem that facial recognition could cause.
