Twine Lab (Learn Quebec)

Resources from LEARN Quebec for building interactive stories with Twine.

ComputingUnverified

The privacy details for this item are unverified. Check which tools and accounts students will use before class.

Overview

Twine Lab is a set of resources from LEARN Quebec for teachers and students. It supports creating nonlinear interactive stories with Twine. The listing covers elementary cycles 1 to 3, secondary cycles 1 and 2, and adult education. The linked Twine Lab site could not be read. The actual lessons are unknown.

Benefits

For students

  • Students build interactive stories with Twine.
  • Students practice inquiry and information literacy.
  • Students can write in English or French on the listing site.

For teachers

  • The listing covers many levels from elementary to adult education.
  • One listed resource has students find causes and consequences in Quebec history using documents and Twine.
  • The resource is tagged under inquiry process and information literacy.

For schools

  • Cost is not stated on the listing.

Ideas by subject

Select a subject to see five classroom ideas.

How this can be used for Social Studies
  1. Identify causes and consequences in Quebec history and build them into a Twine story.
  2. Use primary documents as passages in a branching story.
  3. Write a story that shows how one event leads to another.
  4. Let readers choose a historical figure and follow their view.
  5. Trade stories and list the evidence in each one.
How this can be used for English and Language Arts
  1. Write a nonlinear story with three paths.
  2. Add dialogue to a branching scene.
  3. Compare how two endings change the theme.
  4. Edit a partner's story for clear links.
  5. Present a story to the class and explain the choices.
How this can be used for Library and Media Literacy
  1. Build a story that teaches how to check a source.
  2. Plan a research question as a branching map.
  3. Add links to reliable sources in each passage.
  4. Create a story that shows how to cite sources.
  5. Review a classmate's story for source quality.
