Pencil Code

A free browser site for coding with blocks or text and switching between them.

Computing

Overview

Pencil Code is a browser based programming site. It supports Scratch style blocks or CoffeeScript, and students can switch between them. Code runs in the browser and can be shared. Students make drawings, games, and music.

Benefits

For students

  • Students can switch between blocks and text in the same program.
  • Students draw with turtle graphics.
  • Students share and remix pages.

For teachers

  • Teachers can start coding with no setup.
  • The block view helps beginners, and the text view helps advanced students.
  • Pencil Code was used at Worcester Technical High School, according to a 2014 blog post.

For schools

  • The site is free and the front end is open source.
  • It runs on Chromebooks, Windows, Mac, and Linux.
  • Everything posted is public. Privacy needs care.

Getting started checklist

Where is the AI in this product?

The vendor does not describe any AI in Pencil Code. It runs students' programs in the browser. Students build sequencing and logic skills as they turn steps into drawings.

Privacy and safety

Accounts are optional, and saved programs go to the vendor cloud. Everything posted is public. The About page tells users not to rely on the site to protect their data, and it says passwords do not guard against malicious interference. The research found no formal privacy policy. A teacher should tell students to avoid names, photos, and other identifying information in their pages.
