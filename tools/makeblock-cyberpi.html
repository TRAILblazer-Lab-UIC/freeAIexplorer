Makeblock CyberPi

A palm-size ESP32 controller with a color screen that powers mBot2.

AIComputingRoboticsLocal with optional cloud or accountsGood for AI beginners

The official website did not respond when we checked in November 2026. Confirm that this tool is still available before you plan with it.

Overview

CyberPi is Makeblock's palm-size controller board built around an ESP32 with Wi-Fi and Bluetooth. A review lists a 1.44 inch color display, a gyroscope, an accelerometer, a light sensor, an RGB LED, a buzzer, a microphone, a joystick, and buttons. It powers the mBot2 and mBot Neo robots. Students program it in mBlock 5 with blocks or Python. The Makeblock site lists age 12 and up.

Benefits

For students

  • Students program a board that has many sensors built in.
  • Students can use blocks first and Python later.
  • Students can try speech recognition and voice synthesis.

For teachers

  • One board shows many ideas such as sensing, sound, and motion.
  • The board connects by USB or Bluetooth.
  • The official product page returned 404. Teachers should confirm details with a seller.

For schools

  • No official price was found. Search results show the CyberPi Go Kit at 61.21 GBP including VAT on RS UK.
  • The speech features use Wi-Fi.
  • IT will likely need to install mBlock.

Getting started checklist

Where is the AI in this product?

A retailer listing says Wi-Fi enables speech recognition and voice synthesis. The AI runs in part on the device and in part in a vendor cloud. Students use the speech blocks to make the board hear and answer. The vendor does not say how voice data is handled.

Privacy and safety

Accounts are optional. The research did not confirm whether the internet is needed after setup. Speech features likely send audio to a cloud service, and the research did not confirm where the audio goes. This rests on retailer snippets and not on a vendor page. The Makeblock policy says it does not knowingly collect data from children under 13. That is a data rule and not an age limit. The policy does not address AI, voice cloud services, or mBlock. Advertising partners may receive cookie data on the website. A teacher should check the privacy terms and the account rules before students create accounts.

How this can be used for Computer Science
  1. Write a block program that shows a message on the screen.
  2. Use the light sensor to change the LED color.
  3. Read the gyroscope and display a tilt value.
  4. Try the speech blocks and list which phrases the board understands.
  5. Convert a block program to Python and compare them.
How this can be used for Engineering and Design
  1. Test how each sensor responds and record the values.
  2. Build a tilt game using the accelerometer.
  3. Mount the CyberPi on a robot and test it.
  4. Compare USB and Bluetooth connections.
  5. Design a case that protects the board.
