3D Slash

A block-style 3D modeling tool where students build models from cubes.

FREEComputingSends student data to a company

Overview

3D Slash is a 3D modeling tool with a building-game interface for beginners, kids and non-designers. It runs in a browser and also as a downloadable app that works offline and syncs later. Students build models from cubes and can export STL files for 3D printing.

Benefits

For students

  • Students build 3D shapes with a simple cube-based tool.
  • Students can export their models as STL files for 3D printing.
  • Students can work online or offline with the app.

For teachers

  • The Schools plan adds team management.
  • Teachers can create student users with or without email.
  • Teachers can organize student accounts and folders.

For schools

  • A Free plan exists. Premium costs 2 USD per month billed annually.
  • The Schools plan starts from 12 USD per month.
  • Student models are stored online. The school should review privacy first.

Getting started checklist

Where is the AI in this product?

3D Slash has no AI. It is a modeling tool. Students build skills in spatial reasoning and design as they shape cubes into a model. They learn to plan a build from simple blocks.

Privacy and safety

Accounts are optional and models are stored online with the vendor. The research found no privacy policy. The privacy page returned 404 and the Terms of use text did not load. The materials do not state how student data is handled. Content made online is licensed CC BY-NC-SA unless the user buys a premium plan, according to Wikipedia. A teacher should ask the vendor for privacy terms before creating student accounts.

How this can be used for Engineering and Design
  1. Build a small bridge from cubes and test whether it looks stable.
  2. Design a simple object and export it as an STL file for 3D printing.
  3. Redesign a model to use fewer cubes.
  4. Build a model to a set of measurements from the teacher.
  5. Compare two designs and explain which one is easier to print.
How this can be used for Visual Arts
  1. Build a 3D sculpture from cubes using a favorite color palette.
  2. Recreate a famous shape or building as a block model.
  3. Design a character as a cube model.
  4. Plan a model on paper and then build it in 3D Slash.
  5. Share a model with a partner and ask for feedback.
