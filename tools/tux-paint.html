Tux Paint

Free drawing software for children with sound effects and a penguin guide.

FREEComputingStays on the device

Overview

Tux Paint is free, open source drawing software for children ages 3 to 12. It has sound effects and a cartoon penguin guide. It runs on the computer and needs no internet access. Students draw, stamp, and illustrate their own stories.

Benefits

For students

  • Students draw with simple tools and fun sounds.
  • Students illustrate stories, label images, and picture word problems.
  • Students can use it in many languages.

For teachers

  • The interface is easy for young children to learn.
  • The project site lists a page for schools and classroom ideas.
  • Teachers can use one tool across reading, science, and math.

For schools

  • It is free of cost and of advertisements.
  • It runs offline on Windows, macOS, Linux, Android, and Chromebooks that support Android apps.
  • IT may need to install it on lab computers. A separate Tux Paint Config tool changes settings.

Getting started checklist

Where is the AI in this product?

This tool has no AI. Every stroke and stamp comes from the student. Students still build skills for design and sequencing as they plan a picture step by step.

Privacy and safety

No account is needed. The policy says official releases for Windows, macOS, Linux, Haiku, and Android have no networking features and send no information online. Unofficial versions such as iOS are not covered. The tuxpaint.org website uses Google AdSense and Google Analytics cookies and keeps web logs for two weeks. The internet is needed to download the software. Download only official releases. Decide where students save pictures on shared lab computers.

Ideas by subject

Select a subject to see five classroom ideas.

How this can be used for Visual Arts
  1. Draw a self portrait using the paint and stamp tools.
  2. Make a pattern with repeating stamps and colors.
  3. Use the magic tools to change a picture and describe the effect.
  4. Create a class mural from many small drawings.
  5. Try glitch art effects and talk about what changed.
How this can be used for English and Language Arts
  1. Illustrate a scene from a favorite story.
  2. Respond to a class glyph with a drawing.
  3. Draw a character and write a sentence about it.
  4. Make a story map with a picture for each part.
  5. Create a cover for a class book.
How this can be used for Science
  1. Draw a plant and label its parts.
  2. Label a picture of the water cycle.
  3. Illustrate a food chain with arrows.
  4. Draw the phases of the moon in order.
  5. Sketch an animal habitat and add labels.
How this can be used for Math
  1. Write a word problem and draw the picture that goes with it.
  2. Draw groups of objects to show addition.
  3. Use stamps to make a pattern and describe the rule.
  4. Make shapes and label them by name.
  5. Swap word problems with a partner and solve them.
