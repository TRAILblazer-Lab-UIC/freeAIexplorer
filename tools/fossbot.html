FOSSBot

An open design robot built from 3D-printed parts and a Raspberry Pi.

ComputingRoboticsStays on the device

Overview

FOSSBot is an open-design robot built from 3D-printed parts and a Raspberry Pi. It has ultrasonic, line, light and motion sensors, two DC motors and three 18650 batteries. Students program it with Google Blockly or Python in Jupyter. A Flask web interface can control it without code, and a web simulator offers a virtual robot.

Benefits

For students

  • Students print, wire and program their own robot.
  • Students move from Blockly blocks to Python.
  • Students can try the web simulator before the real robot.

For teachers

  • The software has a web interface and a simulator.
  • The design is open. Teachers can study every part.
  • Teacher seminars were planned in Greek and English.

For schools

  • The article gives no price or build cost.
  • Printing the parts takes about 36 hours.
  • The robot needs a 3D printer and IT help.

Getting started checklist

Where is the AI in this product?

FOSSBot has no AI. It follows the code that students write. Students build skills in sensors and logic with the ultrasonic, line, light and motion sensors.

Privacy and safety

No account is needed and the internet is used at setup. The software runs on the robot's Raspberry Pi and serves a web interface from it. No cloud service was described and no privacy policy was found. A teacher should secure the robot's web interface on the school network. A teacher should also handle the lithium batteries with care.

How this can be used for Engineering and Design
  1. Print one part of the robot and check its fit.
  2. Wire a sensor to the Raspberry Pi and test it.
  3. Measure battery life across a few runs.
  4. Use the LEGO-compatible surface to mount an add-on.
  5. Write a build log with photos and notes.
How this can be used for Computer Science
  1. Write a Blockly program that drives the robot forward.
  2. Use the web simulator to test code before the real robot.
  3. Read the ultrasonic sensor in a Python Jupyter notebook.
  4. Use the line sensor to follow a taped path.
  5. Convert a block program into Python and compare them.
