Brush Ninja Code Ninja

A beta browser tool that draws 2D art with Logo-style commands and JavaScript.

Computing

Overview

Code Ninja is a browser coding tool for making 2D art, and it is in beta. It uses the Logo idea of steering a pointer on a canvas with simple commands, combined with JavaScript. Students create, edit, and export work in the browser. Files save to their own devices. It is part of Brush Ninja, whose basic use needs no account.

Benefits

For students

  • Students draw with code and see the result at once.
  • Students can use variables to change a drawing.
  • Students can save and load their code.

For teachers

  • No login is needed, and a no-login classroom setup guide exists.
  • A getting started tutorial is on the site.
  • Teachers can pair art and coding in one lesson.

For schools

  • Basic use needs no account.
  • Optional paid plans add features and are not needed for classroom use.
  • It runs in a browser, and Chromebooks are listed.

Getting started checklist

Where is the AI in this product?

Code Ninja has no AI. It builds the skill of sequencing, as students order commands to draw a shape. It also builds pattern spotting through repeated shapes.

Privacy and safety

Basic use needs no account, and the tool needs the internet throughout. The vendor says no student work is stored on its servers and that files save to the student's device. Optional accounts need a username and password, with an optional email. The vendor says Google Analytics tracks site usage but not student work, and that ads appear on some pages. It says the site is designed to support FERPA, GDPR, and COPPA but offers no signed data processing agreements. All evidence comes from the vendor. A teacher should read the site privacy terms and ask IT about the ads and analytics.

How this can be used for Computer Science
  1. Write commands that draw a square, as in the getting started tutorial.
  2. Use a variable to change the size of a shape.
  3. Repeat a command to draw a star.

  4. Export a drawing and add it to a class gallery.
  5. Compare a code drawing to a hand drawing.
