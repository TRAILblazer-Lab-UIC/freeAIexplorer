Umi-OCR

A free offline program that pulls text out of images, screenshots, and PDFs.

AI

Overview

Umi-OCR is a free, open source program for batch offline OCR. It extracts text from imported images, screenshots, and PDFs. It also reads and makes QR codes and barcodes. Users unzip the release and run Umi-OCR.exe with no installer. It suits teachers and students in grades 6 to 12 who use Windows or Linux.

Benefits

For students

  • Students can turn a printed page into editable text.
  • Students can capture text from a screenshot.
  • Students can read and make QR codes.

For teachers

  • Batch mode handles many images at once.
  • Results save as txt, jsonl, md, or csv.
  • Teachers can digitize printed handouts for accessibility.

For schools

  • The program is free and open source.
  • It works with no internet.
  • It does not run on Chromebooks or in a browser, and IT may need to approve it.

Getting started checklist

Where is the AI in this product?

The AI is optical character recognition that reads letters in pictures. It runs on the computer, and speed depends on the CPU. Students and teachers use it to turn images and PDFs into text they can edit. They should then proofread the result.

Privacy and safety

No account is needed. The README says the software runs offline and needs no network, and the research found no privacy policy. Sweep notes mention a one time model download that the README does not confirm. The research did not verify that images and text never leave the computer. Check the interface language because some menus are in Chinese. Proofread any converted text before sharing it.

How this can be used for Library and Media Literacy
  1. Scan a page from a printed book and compare the text with the original.
  2. Convert a handout to text and save it as a markdown file.
  3. Process a folder of images in one batch and count the errors.
  4. Capture text from a screenshot of a website and cite the source.
  5. Make a QR code that links to a class reading list.
