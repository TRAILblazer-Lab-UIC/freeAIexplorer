Pololu Zumo 32U4 robot

A small tracked Arduino-compatible robot with encoders and proximity sensors.

ComputingRobotics

Overview

The Zumo 32U4 is a tracked robot under 10 cm per side with an Arduino-compatible ATmega32U4 microcontroller. It has encoders for closed-loop control and proximity sensors for obstacles. An OLED version replaced the original 8x2 character LCD. The successor is the Zumo 2040 on the Raspberry Pi RP2040.

Getting started checklist

Where is the AI in this product?

The robot has no AI. It builds skills in text coding, sensing and control. Students use encoder and sensor data to correct a robot's movement.

Privacy and safety

The robot works on the device. No account or internet is needed. The materials document no student data collection. A teacher should check that the model is still sold. The Zumo 2040 is the successor.

How this can be used for Computer Science
  1. Use the C/C++ course example of obstacle navigation and write your own version.
  2. Upload an example sketch and explain each line.
  3. Write a loop that reads a proximity sensor.
  4. Use a condition to turn away from an object.
  5. Compare two programs for the same maze.
How this can be used for Engineering and Design
  1. Build a line following run like the robotics class in the teacher report.
  2. Use the encoders to measure a straight drive.
  3. Test how well the proximity sensors see different objects.
  4. Tune a turn until the robot makes a square.
  5. Record a test log with changes and results.
