Adafruit Learning System

A free library of more than 3,400 electronics and coding tutorials.

FREEAIComputingLocal with optional cloud or accounts

Overview

The Adafruit Learning System is a library of more than 3,400 tutorials on electronics and coding. Topics include Circuit Playground, CircuitPython, MakeCode, micro:bit, machine learning, robotics, sensors, and wearables. Each guide lists an author and a difficulty level. Teachers choose a guide and students follow the steps to build a project.

Benefits

For students

  • Students can pick projects that match their interests, from wearables to robots.
  • Each guide shows a difficulty level. Students can choose a fitting challenge.
  • Students learn to follow technical instructions and fix their own mistakes.

For teachers

  • The Educators category gathers guides for classroom use.
  • Guide code sits in a public GitHub repo that teachers can copy.
  • Teachers can reuse one guide for many boards and skill levels.

For schools

  • The tutorials are free. Boards and parts cost money.
  • Reading a guide needs no student account.
  • Most guides use free browser editors or desktop tools. The IT load is light.

Getting started checklist

Where is the AI in this product?

The library has a Machine Learning category with guides on the topic. Where the AI runs depends on the guide. Some guides run models on a small board and some use tools in the browser. Students can follow a machine learning guide to train a model and then change it for their own project.

Privacy and safety

Reading guides needs no student account. The research expects no student data collection from reading. Optional accounts exist. Some guides use Adafruit IO, a cloud service that sends data to Adafruit. The research did not read the Adafruit privacy page. The library is very large and guides differ in hardware and cloud use. A teacher should review each guide before use and check any cloud service it asks students to join.

How this can be used for Engineering and Design
  1. Build a wearable light project from a guide and test how long it runs on a battery.
  2. Follow a sensor guide and chart the readings over a day.
  3. Choose a robotics guide and list the parts, steps, and a likely trouble spot.
  4. Complete the MakeCode course for Circuit Playground Express and share one favorite project.
  5. Redesign a guide project with one new feature and write the build steps.
How this can be used for Computer Science
  1. Work through a CircuitPython guide and change one line to see the result.
  2. Complete a MakeCode lesson and explain each block to a partner.
  3. Follow a machine learning guide and describe what the model learned.
  4. Read the code in a guide's GitHub repo and write a comment for each section.
  5. Rate three guides for difficulty and explain the rating with evidence.
