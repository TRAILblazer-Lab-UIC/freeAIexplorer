p5.js Web Editor

A free website for writing, running, and sharing p5.js sketches.

FREEComputingSends student data to a company

Overview

The p5.js Web Editor is a website for creating, sharing, and remixing p5.js sketches. It needs no download or setup. It is designed for beginners. Students write code on one side and see the drawing on the other.

Benefits

For students

  • Students start coding in minutes with nothing to install.
  • Students can share and remix sketches.
  • Screen reader outputs and sound cues for errors support students with different needs.

For teachers

  • Teachers can open the editor and start a lesson right away.
  • The editor limits features and frills, which keeps it simple.
  • It runs on Chromebooks, Windows, Mac, and Linux.

For schools

  • The editor is free and the code is open source.
  • No IT install is needed for the hosted site.
  • The school can self-host from the repository with the Docker files.

Getting started checklist

Where is the AI in this product?

The vendor does not describe any AI in the editor. It runs sketches in the student's browser. Students build sequencing and pattern spotting skills as they write code that draws shapes.

Privacy and safety

An account is optional and is needed to save sketches. A signed in student shares a name, an email, and saved sketches with the vendor. Website analytics apply to all visitors. Profile information and showcase submissions may be public. The policy lists providers such as Google Analytics, Google Cloud, MongoDB Atlas, and Cloudflare. It says COPPA does not apply to the nonprofit but includes a section for users under 13. Parents and school officials can ask to review or delete a child's information. A teacher should read the policy and decide whether to use accounts at all.
