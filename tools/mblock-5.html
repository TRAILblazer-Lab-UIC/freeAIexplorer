mBlock 5

A free Scratch-based coding tool for Makeblock robots, Arduino, and micro:bit with AI blocks.

FREEAIComputingRoboticsLocal with optional cloud or accountsGood for AI beginners

Overview

mBlock 5 is a Scratch 3 based coding environment from Makeblock. It has block and Python editors for Makeblock robots, Arduino, and micro:bit. A third-party school page says its AI blocks use Microsoft Cognitive Services and Google Teachable Machine. Makeblock's education page lists AI blocks for speech, text recognition, and face age and emotion. The vendor does not state a grade range.

Benefits

For students

  • Students code robots with familiar Scratch style blocks.
  • Students can move to the Python editor.
  • Students try AI blocks for speech, images, and poses.

For teachers

  • The tool is free.
  • It runs as a desktop app, a mobile app, or in a browser.
  • The browser editors need no install.

For schools

  • The software is free. Robots are bought separately.
  • The internet is needed at setup to download extensions.
  • The official page returned 404 when fetched. IT should confirm the download source.

Getting started checklist

Where is the AI in this product?

The AI blocks cover speech recognition, text recognition, face analysis, audio recognition, pose recognition, image recognition, and generative AI. Some run through cloud services such as Microsoft Cognitive Services. Others use Google Teachable Machine models. Students snap these blocks into projects and test how well they work.

Privacy and safety

Accounts are optional, and free registration may be needed for AI features. The internet is needed at setup. The official page says mBlock integrates Microsoft Cognitive Services and Google Teachable Machine. It does not say where audio or images are processed. Discovery notes say AI service blocks send data to cloud services, and the research did not confirm this on a page read. The Makeblock policy says it does not directly or knowingly collect personal data from children under 13. That is a data rule and not an age limit. It lists Microsoft Azure hosting and analytics vendors such as Google Analytics. The mBlock specific privacy URLs tried returned 404. A teacher should check which blocks use cloud services before students use cameras or microphones.

How this can be used for Computer Science
  1. Make a Scratch style program that moves a sprite and then a robot.
  2. Switch a project to Python and read the code.
  3. Use a speech block to make a program answer a spoken word.
  4. Train an image or pose model and use it in a project.
  5. Compare how two AI blocks handle the same test.
How this can be used for Engineering and Design
  1. Connect a Makeblock robot and upload a short program.
  2. Test the Bluetooth link at several distances.
  3. Use a sensor reading to control a motor.
  4. Record test results for a robot task.
  5. Improve the program after reading the test results.
