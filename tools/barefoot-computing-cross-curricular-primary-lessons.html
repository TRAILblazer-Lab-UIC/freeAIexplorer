Overview

Barefoot Computing offers more than 80 free cross-curricular lesson plans for primary teachers. Lessons range from unplugged activities to Scratch and micro:bit programming. They link computing ideas such as algorithms to subjects like maths, geography, and PE. Barefoot is run by BT with Computing at School and is aligned to the four UK nations.

Benefits

For students

  • Students learn computing ideas through subjects they already study.
  • Students try both unplugged and on-screen activities.
  • Students practice algorithms in maths, geography, and PE.

For teachers

  • The library has more than 80 ready lesson plans.
  • Subject knowledge guides and workshops help teachers who are new to computing.
  • Lessons link to the curricula of England, Wales, Scotland, and Northern Ireland.

For schools

  • The resources are free to UK teachers.
  • The page does not state terms for other countries.
  • Unplugged lessons need no devices, and Scratch or micro:bit lessons need only a browser or boards.

Getting started checklist

Where is the AI in this product?

This resource has no AI. It builds computational thinking, including algorithms. Students practice breaking a task into steps and testing them.

Privacy and safety

Unplugged lessons run on paper and use no student data. Scratch lessons follow Scratch's own data practices. The site mentions a Barefoot account, which is for teachers. The page does not say whether the account is needed to download lessons. The materials do not say how the internet is used. A teacher should check the site terms and review any online tool before students use it.

Ideas by subject

Select a subject to see five classroom ideas.

How this can be used for Computer Science
  1. Write an algorithm for a daily routine and test it with a partner.
  2. Act out an unplugged lesson that teaches a new computing idea.
  3. Build a short Scratch project that follows an algorithm you drew first.
  4. Find and fix a bug in a classmate's instructions.
  5. Explain in your own words what an algorithm is.
How this can be used for Math
  1. Write an algorithm that sorts numbers from smallest to largest.
  2. Use a set of steps to draw a shape on squared paper.
  3. Find a pattern in a number sequence and write the rule as steps.
  4. Compare two algorithms that give the same answer.
  5. Create a number game with clear rules and test it.
How this can be used for Social Studies
  1. Write an algorithm that guides a visitor between two places on a local map.
  2. Use directions and steps to move a robot across a map grid.
  3. Plan a route with a set of ordered instructions and compare routes.
  4. Describe a journey as a set of steps and then shorten it.
  5. Test a classmate's route and report any step that fails.
How this can be used for Health and PE
  1. Write a sequence of movements and have a partner perform it.
  2. Add a repeat to a movement routine to make it shorter.
  3. Debug a routine that does not work the first time.
  4. Design a simple warm-up as an algorithm.
  5. Perform another group's routine and give feedback on the steps.
