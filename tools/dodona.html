Dodona

An online practice platform that gives automated feedback on programming exercises.

Computing

Overview

Dodona is an online practice platform for programming assignments. It gives automated feedback through tests, performance checks, and linting. Teachers get learning analytics. It began at Ghent University in 2016. The interface is in English and Dutch, and single sign-on works with Microsoft, Google Workspace, Smartschool, and SURFconext.

Benefits

For students

  • Students get feedback on their code at once.
  • Students practice with a large set of exercises.
  • Students can sign in with a school account.

For teachers

  • Learning analytics show how students are doing.
  • Teachers set up courses and assign exercises.
  • Teachers use Dodona free.

For schools

  • Student licenses start at 2 EUR per student per month billed annually.
  • The data is hosted in the EEA on Azure.
  • The site lists 3,005 schools and 116,168 students.

Getting started checklist

Where is the AI in this product?

This platform has no AI. It runs tests and checks on student code. Students build skills in logic and debugging as they read the feedback.

Privacy and safety

Accounts are needed, and data goes to the vendor. Dodona holds name, email and username from the login provider, plus enrollments, submitted code, feedback, grades, IP address and session cookies. Data is hosted in the EEA on Microsoft Azure, and Cloudflare, Stripe and the login provider are third parties. For institutional users the institution is the data controller. Private users under 13 need verifiable parental consent. A teacher should read the privacy notice and the sub-processor list before students sign in.

How this can be used for Computer Science
  1. Solve an exercise and read the automated feedback.
  2. Fix a failing test by changing one line.
  3. Improve a program after a linting message.
  4. Compare two solutions to the same exercise.
  5. Join a course and finish a weekly set of exercises.
