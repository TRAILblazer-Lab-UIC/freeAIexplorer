CMU Machine Vision course

A CS2N course where students train a simulated vision system.

AIComputingRobotics

Overview

This is a Machine Vision course in the Carnegie Mellon Robotics Academy catalog on CS2N. A related 2021 primer has students set up a camera sensor on a Wi-Fi Arduino Uno that sends network alerts when it sees an unusual object. Students then train a simulated vision system to inspect parts on an assembly line. The catalog page does not state the platform or grade band.

Benefits

For students

  • Students see how machine vision checks parts.
  • Students train a system and correct its mistakes.
  • Students connect a real camera to a network.

For teachers

  • CS2N tracks student progress.
  • The assembly line scenario is easy to explain.
  • The course is online.

For schools

  • Cost is not stated. A batch note says free with a CS2N account, which the pages do not confirm.
  • The hands-on part needs a Wi-Fi Arduino Uno with a camera.
  • CS2N stores student progress on its servers.

Getting started checklist

Where is the AI in this product?

The AI is machine vision that finds objects in camera images. Students train a simulated vision system in the course. The training runs in the CS2N cloud and the camera work runs on the device. Students review mistakes and retrain the system.

Privacy and safety

Course pages say the course is accessed and tracked through CS2N, and the data goes to the vendor. The CS2N policy lists name, email, username, group membership, and course activity. It says it does not sell or rent personal information. It allows use by children under 13 with consent from a parent, school, district, or teacher. It does not name COPPA or say where data is stored. The materials do not state whether an account is required or whether the internet is always needed. A teacher should read the CS2N policy and check what the course collects.

Ideas by subject

Select a subject to see five classroom ideas.

How this can be used for Computer Science
  1. Train the simulated vision system and record how often it errs.
  2. Correct a mistake in the system and retrain it.
  3. Explain how a camera image becomes data for a model.
  4. Compare the system before and after more training examples.
  5. Describe a school task that a vision system could check.
How this can be used for Engineering and Design
  1. Describe how an assembly line inspector checks parts.
  2. Set up the camera sensor so it can see the whole part.
  3. Test what lighting changes do to the alerts.
  4. Design a rule for what counts as an unusual object.
  5. Map how an alert travels over the network.
