Yahboom ROSMASTER series

A family of ROS2 robots for advanced courses in navigation, mapping, and vision.

Overview

ROSMASTER is a family of ROS and ROS2 robots from Yahboom that run on Jetson or Raspberry Pi 5 boards. Models include the A1 with Ackermann steering, the X3 with Mecanum wheels, lidar, and a depth camera, and the M3 Pro with a 6-DOF arm. The X3 course index lists 103 video courses with Python code. Yahboom targets intermediate to advanced students, university courses, and research.

Benefits

For students

  • Students code mapping, navigation, following, and pose detection.
  • Students work with lidar and a depth camera.
  • Students on the M3 Pro try language model interaction with voice and images.

For teachers

  • The X3 has 103 video courses with Python code.
  • The robots suit advanced classes and clubs.
  • Reseller notes say Yahboom supports only existing courses.

For schools

Getting started checklist

Where is the AI in this product?

The robots offer visual recognition, object tracking, SLAM mapping, speech recognition, and natural-language understanding. The vendor does not say where each part runs. Students write Python code that uses these features and compare how the robot behaves.

Privacy and safety

No account is needed and the internet is used at setup. Core ROS processing runs on the onboard board. The M3 Pro article does not name a language model provider or say whether cloud services are used. The Yahboom store policy covers customers only and does not address children. The materials do not state what student data is collected or where it goes. A teacher should ask Yahboom how voice and image features work and review the M3 Pro language model features before students use them.
