Replit

A browser coding environment with an AI app builder and no school plan.

FREEAIComputingSends student data to a company

Overview

Replit is a browser-based coding environment with AI features, including Replit Agent, which is powered by large language models. Projects and code are stored on Replit servers. Replit ended its Teams for Education product, with removal and data deletion on 1 August 2024. The current pricing page lists Core, Pro, and Enterprise plans and no education plan.

Benefits

For students

  • Students code in a browser with nothing to install.
  • Students can describe an app and watch the agent build it.
  • Students can use voice dictation to enter text.

For teachers

  • It works on Chromebooks because it runs in a browser.
  • Teachers can see how AI builds an app from a plain description.
  • There is no school edition, and accounts are individual.

For schools

  • A free plan exists, but the page read did not describe it.
  • Core costs $20 a month, or $18 billed annually, and Pro costs $100 a month.
  • The loss of the education plan is a notable change for schools.

Getting started checklist

Where is the AI in this product?

Replit offers code generation, an AI agent that builds apps, and voice dictation. The AI runs in the vendor's cloud. Students describe what they want, read the code the agent writes, and then edit it themselves.

Privacy and safety

Each student needs an account, and the internet is needed at all times. Projects, code, and AI prompts are stored on Replit servers. The policy lists registration data, usage data, device data, IP address, voice audio for dictation, and inferred general location. Third party providers, which may include machine learning companies, power features such as Agent. The policy cites a legitimate interest in using personal data to improve machine learning. It says the services are not directed to children under 13 and has no school section. The student data agreement page returned 404. A teacher should check school policy and the vendor terms before students sign up.
