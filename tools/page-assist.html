Page Assist

A browser sidebar that chats with local AI models and with the page you are reading.

FREEAIStays on the device

Overview

Page Assist is an open source browser extension. It adds a sidebar and a ChatGPT-style page for local AI models. Its Chat With Webpage feature answers questions about the page a student has open. It works with Ollama, Chrome AI, and OpenAI-compatible endpoints such as LM Studio.

Benefits

For students

  • Students ask questions about the web page they are reading.
  • Students get reading support in a sidebar.
  • Students can keep chat history in their own browser.

For teachers

  • Teachers can show how a local AI model works with web content.
  • The extension works in Chrome, Brave, Firefox, Vivaldi, Edge, LibreWolf, and Zen Browser.
  • It is free to use.

For schools

  • The software is free.
  • A computer must run a local model server such as Ollama with enough memory for the model.
  • IT will likely need to install the extension and the model server. Chromebook use was not confirmed.

Getting started checklist

Where is the AI in this product?

The AI is a language model that chats and answers questions about a web page. It runs on the local computer or on a machine the school controls, through Ollama or a similar server. Students ask questions, read the answers, and check them against the page itself.

Privacy and safety

No account is needed. The internet is used at setup. Chat history and settings are stored locally in the browser. The privacy file says the extension collects no user data. An optional Page Share feature sends chats to a server and can be turned off. An OpenAI-compatible endpoint that points to a cloud service would send content out. A teacher should turn Page Share off, check that no outside endpoint is set, and make sure students clear shared computers.

How this can be used for English and Language Arts
  1. Open a news article and ask the sidebar for the main claim, then find it in the text.
  2. Ask the sidebar to explain a hard paragraph and rewrite it in your own words.
  3. Ask three questions about a web page and mark any answer that does not match the text.
  4. Use the sidebar to find the evidence for an argument and quote it.
  5. Compare your summary of a page with the summary of the sidebar.
