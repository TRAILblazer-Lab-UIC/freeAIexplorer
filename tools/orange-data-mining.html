Orange Data Mining

A free visual tool for machine learning and data visualization without code.

FREEAIComputingStays on the deviceGood for AI beginners

Overview

Orange is an open source visual programming tool for machine learning and data visualization. Students place widgets on a canvas and connect them. They explore datasets without writing code. The site says it is used in schools, universities, and professional training.

Benefits

For students

  • Students build a machine learning workflow by dragging and connecting widgets.
  • Students see data in scatter plots, box plots, heatmaps, and decision trees.
  • Students can add text mining, networks, and time series with add-ons.

For teachers

  • Some widgets were designed for teaching.
  • No coding is needed to start.
  • A classroom example shows high school students training a neural network on test strip images to predict pH.

For schools

  • The software is free. The site asks users to donate.
  • The program runs on the local computer.
  • IT approval may be needed to install it. Chromebooks are not listed.

Getting started checklist

Where is the AI in this product?

Orange offers classification, regression, clustering, neural networks, and decision trees. The AI runs on the local computer. Students connect widgets to train a model on a dataset and then check how well it predicts. They can change the settings and see the effect.

Privacy and safety

No account is needed, and the program runs on the local computer. The internet is used at setup. The research read no privacy policy. Add-ons may fetch data online. A teacher should check that any dataset students load has no personal details and ask IT to review add-ons before use.

Ideas by subject

Select a subject to see five classroom ideas.

How this can be used for Computer Science
  1. Build a workflow that loads a dataset and trains a decision tree.
  2. Compare a decision tree with a neural network on the same data.
  3. Cluster a set of items and explain why the groups form.
  4. Change one widget setting and predict how the result will change.
  5. Draw the workflow on paper and explain each widget in order.
How this can be used for Science
  1. Follow the pH example and train a neural network on test strip images.
  2. Load a class experiment as a table and plot it in a scatter plot.
  3. Use a box plot to compare results from two groups of plants.
  4. Find which measurements best predict an outcome in a science dataset.
  5. Write a short lab report that uses a heatmap as evidence.
How this can be used for Math
  1. Plot two variables in a scatter plot and describe the pattern.
  2. Use box plots to compare the spread of two sets of numbers.
  3. Build a heatmap of a table and tell what the colors show.
  4. Check how a model's predictions change as the training data grows.
  5. Use a decision tree to sort a dataset and explain each split.
