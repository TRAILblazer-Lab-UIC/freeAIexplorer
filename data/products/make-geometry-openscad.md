## Overview
Make: Geometry is a 2021 book by Joan Horvath and Rich Cameron. It teaches geometry through OpenSCAD models. A Washington State resource page lists it as a hands-on supplement to a main textbook. Students in middle and high school write code to make shapes and print them.

## Benefits for students
- Students see geometry ideas as code and as 3D shapes.
- Students can print a model they designed.
- Students practice code and math together.

## Benefits for teachers
- The authors offer free geometry lesson plans and a Teacher's Guide with a 3D printing section.
- The models are on GitHub as .scad and .stl files under CC BY 4.0.
- The lesson plans predate the book and do not follow it closely.

## Benefits for schools
- The lesson plans and models are free. The book costs about 25 to 30 USD.
- OpenSCAD runs on Windows, macOS, and Linux.
- OpenSCAD does not run on Chromebooks. A 3D printer is optional.

## Getting started
- [ ] Find the authors' free lesson plans and the book listing.
- [ ] Ask IT to install OpenSCAD on a computer.
- [ ] Download the model zip from GitHub.
- [ ] Open a model and change one number in the code.
- [ ] Render the model and view it.
- [ ] Export an STL file if you have a printer.
- [ ] Read the images' alt text if a student uses a screen reader.

## Where is the AI?
This resource has no AI. Students write code that describes shapes. They build skills in logic and in precise instructions.

## Privacy and safety
OpenSCAD is desktop software that runs locally and needs no account. The internet is used to download the program and the model files. The research found no privacy policy. The research did not open the lesson plan page. Student work stays on the computer unless a student shares it. A teacher should check where students save files.

## Ideas by subject
### math
1. Write code for a cube and change its side length to see how volume changes.
2. Build a shape from two overlapping solids and describe the result.
3. Use a rotation to turn a shape through a set angle.
4. Compare the volume of a cylinder and a cone with the same base.
5. Design a shape that uses a given set of measurements.

### engineering
1. Design a small tool holder and export it as an STL file.
2. Test the size of a model against a real object.
3. Change a design to use less material.
4. Print a model and compare it to the plan.
5. Write the steps of the design process in a short log.

### computer_science
1. Write OpenSCAD code for a simple shape.
2. Use a variable to change the size of a whole model.
3. Create a loop that repeats a shape.
4. Find and fix a mistake in broken code.
5. Document the code with comments for a partner.
