## Overview
ArduinoSimulator is an open source Arduino simulator written in JavaScript. It runs in a browser and emulates sketches. The demos show digital and analog pins and a serial monitor. EEPROM support is marked work in progress.

## Benefits for students
- Students can write Arduino code without a board.
- Students can see pins and serial output.
- Students can practice at home in a browser.

## Benefits for teachers
- Teachers can open it with one link.
- It needs no install.
- The app is a single developer project. Library and board coverage was not checked.

## Benefits for schools
- The tool is free.
- It runs in a browser on Chromebooks, Windows, Mac and Linux.
- The main page of the live app has a service worker and no analytics code.

## Getting started
- [ ] Open the live app URL from the project page on GitHub.
- [ ] Write a short sketch.
- [ ] Run it and read the serial monitor.
- [ ] Test the libraries you plan to use.
- [ ] Check what happens when the internet is off.
- [ ] Plan where students save their sketch.
- [ ] Note that no GitHub releases exist.

## Where is the AI?
The simulator has no AI. Students build skills in sequencing and logic. They write code and see how pins react.

## Privacy and safety
No account is needed and the app is a static page hosted on GitHub Pages. The research found no privacy policy. The research inspected only the main page, which has no analytics code. The app appears to work offline after the first load, but this was not tested. The materials do not say how sketches are saved. A teacher should test offline use before class and copy student code to a safe place after each session.

## Ideas by subject
### computer_science
1. Write a sketch that blinks a simulated LED.
2. Print a message to the serial monitor.
3. Read a simulated pin and respond with a condition.
4. Change a loop and describe how the output changes.
5. Debug a sketch with a syntax error.

### engineering
1. Plan a circuit on paper and test its code in the simulator.
2. Watch digital pin states change as the code runs.
3. Compare digital and analog pin readings.
4. Explain how the simulated board differs from a real board.
5. Write the test steps for a new project before building it.
