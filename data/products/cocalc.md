## Overview
CoCalc is a hosted platform for computational work with Jupyter notebooks, Python, Sage, R, LaTeX, and terminals. An instructor creates a course, enrolls students by email, and gives each student a separate project. The instructor and TAs can open, review, and comment on those projects. The guide says it has been used for teaching since 2013.

## Benefits for students
- Students work in a browser on any device with no software to install.
- Students can write code, notebooks, and LaTeX in one place.
- Students can work together and see an edit history.

## Benefits for teachers
- Teachers can open a student's files and comment on the work.
- Each student gets a separate project automatically.
- Teachers can turn off the AI coding agents for students.

## Benefits for schools
- The official overview suggests about 20 to 30 USD per month per course for an instructor license. A free tier was not confirmed.
- The site works on Chromebooks and needs only a browser.
- The policy says the service is not directed at children under 16. Schools should check suitability for younger students.

## Getting started
- [ ] Open the CoCalc site and read the official teaching guide.
- [ ] Create an instructor account.
- [ ] Check the minimum age rule of 16 against your students.
- [ ] Ask IT to review the vendor terms and data use.
- [ ] Create a project for the course and upgrade it.
- [ ] Turn off the AI integration for students.
- [ ] Add TAs and enroll students from an email list.
- [ ] Test a first assignment with one student account.

## Where is the AI?
The site promotes AI coding agents and code help that run in the vendor's cloud. Instructors can turn the AI off for students. Students who have the AI on use it to ask for code help and then test the code themselves. The platform also supports notebook work in many languages.

## Privacy and safety
Every student needs an account, and the internet is needed at all times. The vendor collects account details, course enrollment logs, and project content. Enrollment logs are kept 13 months. The policy names Stripe, HubSpot, Salesloft, and Zendesk, and Google Analytics runs only with consent. It says content is scanned by automated security tools and is not used to train third party models. The policy says the services are not directed at children under 16. It does not name COPPA or FERPA. Some features use cloud AI agents. A teacher should check school policy for under 16 students and decide whether to turn off the AI features before students sign in.

## Ideas by subject
### computer_science
1. Write a short Python program in a notebook and share it with a partner.
2. Review a partner's code and leave a comment on one line.
3. Use the edit history to find where a bug first appeared.
4. Run a notebook cell by cell and explain each result.
5. Compare Python with R for the same small task.

### math
1. Use Sage to solve an equation and check the answer by hand.
2. Plot a function in a notebook and describe its shape.
3. Typeset a short proof in LaTeX.
4. Test a formula with ten different values and chart the results.
5. Write a short notebook that explains one math idea with a graph.

### science
1. Load a data set in a notebook and graph one variable.
2. Fit a line to measured data and discuss the fit.
3. Simulate a simple physical system with a short program.
4. Compare two data sets and write a conclusion.
5. Share a notebook report with a partner for review.
