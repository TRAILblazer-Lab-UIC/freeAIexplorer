## Overview
Classroom 50 is a free open source alternative to GitHub Classroom from the Fifty Foundation, the nonprofit behind Harvard's CS50. Per search results, it supports individual and group assignments, starter code repos, autograding, feedback, and roster management. It includes a tool to import classrooms from GitHub Classroom. It requires a GitHub organization on the Team or Enterprise plan.

## Benefits for students
- Students receive starter code in their own repository.
- Students get feedback from autograding.
- Students learn the tools that professional programmers use.

## Benefits for teachers
- Teachers manage rosters and assignments in one place.
- Autograding saves marking time.
- Johns Hopkins support documentation lists it as the recommended replacement for GitHub Classroom.

## Benefits for schools
- The software is free.
- It needs a GitHub Team or Enterprise organization.
- Verified educators may qualify for GitHub Education benefits, per a search result.

## Getting started
- [ ] Find Classroom 50 from the Fifty Foundation.
- [ ] Set up a GitHub organization with owner access on the Team or Enterprise plan.
- [ ] Configure Classroom 50 for the organization.
- [ ] Ask IT and the privacy lead to review GitHub accounts for students.
- [ ] Import classrooms from GitHub Classroom if you have any.
- [ ] Create a starter code repo for a first assignment.
- [ ] Test with one student account.

## Where is the AI?
Classroom 50 has no AI. It builds the skills of version control and testing, as students save their work and run checks. It also builds debugging habits.

## Privacy and safety
Teachers and students need GitHub accounts, and the internet is needed throughout. Student identity and code repositories are held by GitHub, which is a third party. The research read no Classroom 50 privacy policy and did not fetch the official site. Classroom 50 was newly launched in 2026. A teacher should check the GitHub age rules and school policy before assigning student accounts.
