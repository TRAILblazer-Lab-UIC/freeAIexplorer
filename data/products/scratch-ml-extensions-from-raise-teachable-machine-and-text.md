## Overview
MIT RAISE publishes Scratch 3 extensions for AI. They include Teachable Machine, Text Classifier, PoseBlocks, Affectiva, and speech and robot blocks. The extensions run in a RAISE-hosted fork of the Scratch editor. Middle school students trained a text classifier in blocks and used it in their own projects.

## Benefits for students
- Students train image, pose, and text models and use them in Scratch.
- Students try body, hand, and face tracking blocks.
- Students add speech to text and text to speech to a project.

## Benefits for teachers
- The Dancing with AI curriculum supports the blocks.
- The code is open source under the MIT license.
- A SIGCSE 2021 paper covers middle school use.

## Benefits for schools
- The tools are free.
- No install is needed, but the internet is used throughout.
- Some extensions need a webcam or microphone.

## Getting started
- [ ] Open the RAISE Playground editor in a browser.
- [ ] Add an extension, such as Text Classifier.
- [ ] Review the Dancing with AI curriculum.
- [ ] For Teachable Machine blocks, train a model first at Google's Teachable Machine site.
- [ ] Check that devices have a webcam or microphone for tracking and speech blocks.
- [ ] Allow camera or microphone access in the browser.
- [ ] Test one project before class.

## Where is the AI?
The AI includes image classification, pose estimation, face tracking, text classification, and speech recognition. Some parts run in the browser and some use outside services such as Google's Teachable Machine. Students train a model, add it to a block project, and then test how it behaves.

## Privacy and safety
No account is needed, and the internet is used throughout. The research did not review the extensions' data handling. Teachable Machine models are fetched from Google when a model URL is used. The research did not confirm where training data goes for Teachable Machine or for the speech and text blocks. It found no privacy policy for the RAISE Playground. A teacher should check which services each extension calls before students use it.

## Ideas by subject
### computer_science
1. Train a text classifier on two kinds of sentences and use it in a Scratch game.
2. Train an image model with Teachable Machine and load it into Scratch.
3. Build a project that reacts to a pose using the body tracking blocks.
4. Test a model with new examples and note where it fails.
5. Add speech to text to a project and test it with different voices.
