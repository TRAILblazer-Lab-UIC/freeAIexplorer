## Overview
Crumble software programs the Crumble Controller. Crumble Code runs in a USB-capable desktop browser such as Chrome or Edge. It can be installed as a Progressive Web App for offline use. Desktop installers exist for Windows, Mac and Linux.

## Benefits for students
- Students program with blocks.
- Students test code on a real board over USB.
- Students can work offline after the install.

## Benefits for teachers
- The software is free on as many machines as needed.
- The latest version listed is 1.7.4 from 24 June 2025.
- Teachers can use the browser version with no install.

## Benefits for schools
- It works on Windows, Mac, Linux and Chromebook.
- Chromebook schools may use the legacy app until February 2027. Chrome Apps are being discontinued by Google.
- The software needs a Crumble Controller.

## Getting started
- [ ] Open Crumble Code in Chrome or Edge on a desktop computer.
- [ ] Download the Windows, Mac or Linux installer if a local install is needed.
- [ ] Install Crumble Code as a Progressive Web App for offline use.
- [ ] Connect a Crumble Controller by USB cable.
- [ ] Run a first program that lights an LED.
- [ ] Plan for the legacy ChromeOS app ending in February 2027.
- [ ] Check the privacy information for the browser version.

## Where is the AI?
Crumble software has no AI. Students build block programs that the controller runs. Students build skills in sequencing and logic.

## Privacy and safety
No account is needed. The software runs as a local install or in a desktop browser over USB. The research did not read a privacy policy. Data collection is not confirmed. The browser version needs the internet to load and can be installed for offline use. A teacher should read the Crumble privacy information. The browser version works on a desktop browser only and not on mobile.
