## Overview
BASIC-256 is a free programming environment for beginners that started in 2007. It shows a code editor, a text output area, and a graphics window on one screen. Students write traditional BASIC programs with loops, subroutines, and drawing commands. Built-in tutorials teach each idea through exercises.

## Benefits for students
- Students see their code, their text output, and their drawing in one place.
- Students can add graphics and sound commands to make programs feel playful.
- Students learn loops and subroutines in a plain, readable language.

## Benefits for teachers
- The built-in tutorials give students exercises to work through at their own pace.
- The simple layout makes it easy to show the link between a line of code and its result.
- The tool suits teachers who already know some programming.

## Benefits for schools
- The software is free.
- It runs on the computer after installation. Student work stays on the device.
- IT may need to approve the install on managed machines. Chromebook support is not confirmed.

## Getting started
- [ ] Download the installer from SourceForge.
- [ ] Ask IT to approve the install on managed computers.
- [ ] Install BASIC-256 on each Windows, Mac, or Linux computer.
- [ ] Open the built-in tutorials and work through the first exercise yourself.
- [ ] Run a short program that prints text on the screen.
- [ ] Add a drawing command and watch the graphics window.
- [ ] Share the first tutorial with students and let them try it.

## Where is the AI?
BASIC-256 has no AI. It builds the skill of sequencing. Students must put commands in the right order. It also builds logic through loops and subroutines.

## Privacy and safety
No account is needed. The program runs on the device and the research found no documented student data collection. The research found no privacy policy. The language has network functions. Programs a student writes could use the network. The internet is needed for the download. A teacher should confirm the install source with IT before students use it.

## Ideas by subject
### computer_science
1. Write a BASIC program that prints a short greeting and the student's name, as a first step in the built-in tutorials.
2. Use a loop to draw a row of shapes in the graphics window.
3. Break a drawing into a subroutine and call it three times with different positions.
4. Add a sound command to a program and explain which line makes the sound.
5. Swap programs with a partner and describe in words what the partner's code does.
