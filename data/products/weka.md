## Overview
Weka is open source machine learning software built in Java. It has a graphical workbench for classification, clustering, and data preparation. The University of Kent says it is widely used for teaching, research, and industry. It runs as a desktop application on Windows, macOS, and Linux.

## Benefits for students
- Students run real machine learning methods without writing code.
- Students can compare how different methods handle the same data.
- Students learn to prepare data before analysis.

## Benefits for teachers
- The graphical interface is easy to demonstrate.
- Kent uses Weka on student computers in its School of Computing and Business School.
- Teachers can reuse datasets across many lessons.

## Benefits for schools
- Weka is free under the GNU General Public License.
- It runs on the local computer, and data stays there by design.
- IT approval is needed on locked-down machines.

## Where is the AI?
Weka uses machine learning methods for classification and clustering. It runs on the local computer. Students load a dataset, choose a method, and read the results. They then change settings and compare the outcomes.

## Privacy and safety
No account is needed, and the internet is used only for setup. Weka is a local desktop application, and data stays on the computer by design. The research did not find a privacy policy or a data transmission statement. This is not confirmed in vendor text. A teacher should check the datasets before class. Sample data should not hold personal details about real people.

## Ideas by subject
### computer_science
1. Load a sample dataset and run a classifier. Then describe what it predicted.
2. Compare two classification methods on the same data.
3. Use clustering on a small dataset and describe the groups it finds.
4. Clean a messy dataset with the preprocessing tools and note what changed.
5. Plan a short class talk on a university use of Weka.

### math
1. Calculate the accuracy of a classifier from its results table.
2. Plot two attributes and describe the pattern between them.
3. Compare the groups from a clustering run with groups you made by hand.
4. Test how the amount of training data changes the accuracy.
5. Find an outlier in a dataset and explain how it affects the result.
