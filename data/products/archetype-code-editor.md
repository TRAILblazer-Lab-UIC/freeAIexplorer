## Overview
Archetype Code Editor is a Chrome OS code editor built on the Monaco editor from VS Code. It runs natively without Crouton or Crostini and works offline. Features include multiple cursors, a minimap, code folding, a directory browser and Prettier formatting. The listing says it is in beta. The last update on the store was January 23, 2021.

## Benefits for students
- Students can write code on a Chromebook without a Linux container.
- Students can work offline.
- Students use features found in professional editors.

## Benefits for teachers
- Installation is one step from the Chrome Web Store.
- The editor shows a directory browser for project files.
- Users gave it a 4.7 rating from 26 ratings.

## Benefits for schools
- The editor is free for personal use per the listing.
- Terms for school use are not stated.
- The last update was in 2021, and users reported SFTP save and file open bugs.

## Getting started
- [ ] Install the editor from the Chrome Web Store.
- [ ] Ask IT to allow the extension on school Chromebooks.
- [ ] Open a folder with the directory browser.
- [ ] Write a short test file.
- [ ] Try Prettier formatting.
- [ ] Test offline use.
- [ ] Check the terms for school use with the developer.

## Where is the AI?
The editor has no AI. Students build skills in text coding and debugging. They write, format and save their own code.

## Privacy and safety
No account is needed and the editor works offline. The Chrome Web Store listing says the developer has not provided information about how data is collected or used. The research found no independent review. The editor is a beta that has not been updated since 2021. A teacher should check the terms for school use and confirm that the app still runs on school Chromebooks.
