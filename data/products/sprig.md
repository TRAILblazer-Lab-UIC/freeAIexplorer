## Overview
Sprig is an open source handheld game console and web game editor from Hack Club. Games are written in JavaScript with built-in sprite, sound, and map editors. Games run on the device or in the online editor. The site lists over 800 games made by teenagers.

## Benefits for students
- Students write real JavaScript to make games.
- Students draw sprites and build maps in the editor.
- Students can share games in a gallery.

## Benefits for teachers
- The editor opens in a browser with little setup.
- A gallery of over 800 games gives ideas.
- The console is built around a Raspberry Pi Pico.

## Benefits for schools
- The editor is free and open source.
- To get a console, a student submits an original game to the gallery.
- The console ships disassembled.

## Getting started
- [ ] Open the Sprig editor in a browser.
- [ ] Browse the gallery for ideas.
- [ ] Write a short game yourself.
- [ ] Decide whether students will use accounts.
- [ ] Ask IT to confirm that the site is open.
- [ ] Plan how a student can earn a console.

## Where is the AI?
The vendor does not describe any AI. Students write JavaScript code. They build logic and sequencing skills as they code game rules.

## Privacy and safety
An account is optional, and the internet is needed at all times. The site has a log in link, but the page does not explain accounts or how games are saved. The research reviewed no privacy policy, and the materials do not state what data is collected. A teacher should read the privacy terms and check what the gallery shows about student work before students share games.
