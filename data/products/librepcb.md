## Overview
LibrePCB is a free, open source design suite for electronics. It has a schematic editor, a board editor, and a library editor. It runs on Windows, macOS, and Linux. Students draw a circuit, lay out a board, and export files for fabrication.

## Benefits for students
- Students see how a circuit idea becomes a real board layout.
- Students learn the tools that electronics makers and engineers use.
- Students produce files that a board maker can build.

## Benefits for teachers
- Teachers get a free tool with no usage limits.
- The program fits high school electronics and engineering courses.
- Teachers can use the command-line tool for automated checks and exports.

## Benefits for schools
- The software costs nothing.
- It runs on a desktop or laptop and needs no cloud account.
- Administrator rights may be needed on school computers. Plan time with IT.

## Getting started
- [ ] Download the installer for your system from the LibrePCB website.
- [ ] Ask IT for administrator rights if the computer is managed.
- [ ] Install the program and open it.
- [ ] Create a new project and draw a simple schematic with a battery, resistor, and LED.
- [ ] Open the board editor and place the parts on a board.
- [ ] Run the checks and fix any errors.
- [ ] Export the fabrication files. The vendor calls these output jobs.

## Where is the AI?
LibrePCB has no AI. The vendor describes no AI features. It builds skills in logic and design. Students plan a circuit, connect parts in order, and check the design against rules.

## Privacy and safety
No online account is required, and the official site says the software can be used fully offline. The integrated library manager and the PCB fabrication service are optional online features. The site says nothing about telemetry, and no privacy policy page was read. A teacher should check where students save project files. A teacher should also remember that there is no Chromebook version.

## Ideas by subject
### engineering
1. Draw a schematic for a battery, switch, resistor, and LED and explain what each part does.
2. Lay out the circuit on a small board and check that all parts are connected.
3. Run the design checks and fix each error that the program reports.
4. Export the fabrication files and list what each file is used for.
5. Redesign a board to make it smaller and compare the two layouts.

### cte
1. Follow the steps from schematic to board to fabrication files and write the workflow as a checklist.
2. Make a custom part in the library editor and add it to a project.
3. Design a simple flashlight circuit as a mock client job.
4. Review a classmate's schematic and write feedback on how clear it is.
5. Use the library manager to find parts and list the ones a project needs.
