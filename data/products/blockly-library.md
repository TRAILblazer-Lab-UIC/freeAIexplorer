## Overview
Blockly is an open source library for developers who build visual programming editors with drag-and-drop blocks. The Raspberry Pi Foundation maintains it, with Google support. It offers APIs, code generators, and integrations. It powers many block-based coding platforms. It is a developer component and is not a classroom tool for students on its own.

## Benefits for students
- Older students can study how a block editor is built.
- Students can see how blocks turn into code.
- Students can build a small editor as an advanced project.

## Benefits for teachers
- Teachers can show how familiar block tools work inside.
- The library includes accessibility support.
- The docs at docs.blockly.com give a starting point.

## Benefits for schools
- The library is free and open source.
- It needs a developer to add it to a web app.
- IT may need to help with any hosting.

## Getting started
- [ ] Read the docs at docs.blockly.com.
- [ ] Decide whether a ready-made tool would serve the class better.
- [ ] Ask a developer or IT to add the library through npm or a script include.
- [ ] Build a small test editor with a few blocks.
- [ ] Try a code generator for one language.
- [ ] Check where the test editor stores any student work.
- [ ] Share the test editor with a small group of older students.

## Where is the AI?
Blockly has no AI. It builds the skill of understanding how a program is structured. Students also practice logic as they design the blocks.

## Privacy and safety
The library runs in the browser and the research found no accounts in it. Data handling depends entirely on the host application that embeds it. The vendor materials do not describe any app built with it. A teacher should check where any app built on Blockly stores student work.
