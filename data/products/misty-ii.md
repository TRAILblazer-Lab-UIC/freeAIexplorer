## Overview
Misty II is a programmable personal robot. Its functions are exposed through HTTP APIs and web socket messages and can be used from many languages. The docs describe a web-based Python editor that runs code on the robot, Blockly, and a C# SDK. The site mentions face, object, and speech recognition. Misty is part of Furhat Robotics after a January 2022 acquisition.

## Benefits for students
- Students program a robot that moves and talks.
- Students can use Blockly or Python.
- Students can try face, object, and speech recognition.

## Benefits for teachers
- The web-based Python editor runs code on the robot.
- Several languages work through the API.
- A teacher needs advanced skills.

## Benefits for schools
- A 2023 Furhat lab bundle listed a Misty II at 3995 USD. The current price was not found.
- The robot and a computer or phone must share a network.
- IT will likely need to help with the network.

## Where is the AI?
The site mentions face, object, and speech recognition. The vendor does not say where the recognition runs. Students write programs that react to what the robot sees and hears. They can use the API to build their own behaviors.

## Privacy and safety
The materials do not state which accounts students need or whether the internet is needed. The pages fetched do not address privacy or cloud dependence. Speech and vision features may use cloud services, which the research did not verify. The robot has a camera and a microphone. A teacher should check what the robot records and where it sends data. A teacher should also set rules before students test face recognition.
