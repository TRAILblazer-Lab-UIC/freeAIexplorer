## Overview
Robocode is a programming game. Students write a bot, pit it against others in an arena, and refine it. Classic Robocode is the original Java platform that runs bots on a local computer and needs a JDK. Robocode Tank Royale is a newer version with local and networked battles over WebSocket. It has APIs for Python, Java and JVM languages, .NET, and TypeScript or JavaScript.

## Benefits for students
- Students write code and watch their bot fight.
- Students refine a bot after each battle.
- Students choose among languages in Tank Royale.

## Benefits for teachers
- The site points to The Book of Robocode and a My First Robot tutorial.
- Battles give a clear way to compare code.
- Teachers need some Java or Python knowledge.

## Benefits for schools
- The software is free.
- Classic Robocode runs on the local computer.
- IT will likely need to install a JDK.

## Getting started
- [ ] Find Robocode on its official site and read the tutorials.
- [ ] Ask IT to approve a JDK install on managed computers.
- [ ] Install a current JDK.
- [ ] Download and run Classic Robocode.
- [ ] Follow the My First Robot tutorial.
- [ ] Run a first battle against a sample bot.
- [ ] Try Tank Royale with an advanced group for other languages.

## Where is the AI?
Robocode has no AI features. It builds an AI-related skill, which is logic. Students write rules that decide how a bot moves, aims, and fires. That practice is a base for how programs make decisions.

## Privacy and safety
No account is needed, and the internet is used only at setup. Bots and battles stay on the device. Tank Royale supports networked battles. A teacher should check the network settings before students battle across computers.

## Ideas by subject
### computer_science
1. Follow the My First Robot tutorial and write a bot that moves and fires.
2. Change one rule in the bot and describe how battles change.
3. Add a rule that reacts when the bot is hit.
4. Compare two classmates' bots and discuss what made one win.
5. Write a short log of the changes you made after each battle.
