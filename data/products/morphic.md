## Overview
Morphic is a small free app for Windows and Mac. It adds a toolbar that helps people find and use accessibility features already built into the computer. A Santa Clara University page says it enlarges text, zooms, adjusts color and contrast, and reads selected text aloud. Morphic for Organizations lets libraries and schools make shared computers accessible.

## Benefits for students
- Students enlarge text and change color and contrast.
- Students can hear selected text read aloud.
- Students find settings with one toolbar.

## Benefits for teachers
- Custom MorphicBars can be built on the Morphic Customization website.
- AT-on-Demand lets assistive technology users run their own tools on any Morphic computer.
- The toolbar is easy to teach.

## Benefits for schools
- Morphic, custom MorphicBars, and organizational use are listed as free.
- Organizations can deploy it on shared computers.
- IT will likely install it.

## Getting started
- [ ] Download Morphic for Windows or Mac.
- [ ] Ask IT to install it on a test computer.
- [ ] Open the toolbar and try the text and contrast settings.
- [ ] Try the read aloud feature.
- [ ] Look at the Morphic for Organizations option for shared computers.
- [ ] Check the privacy details with IT. The materials were not found.

## Where is the AI?
The vendor does not describe any AI. The tool helps students use accessibility settings that are already on the computer.

## Privacy and safety
Accounts are optional, and registration is needed on the Morphic Customization website to make custom MorphicBars. The materials do not state what data the app collects or whether the internet is needed. The privacy policy covers the website only and says it does not govern the Morphic product. Website data includes form details, IP address, cookies, and analytics. A teacher should ask IT to review the privacy details and decide whether students need accounts for custom bars.
