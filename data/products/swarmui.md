## Overview
SwarmUI is a modular web interface for AI image generation. It was formerly called StableSwarmUI. It can install ComfyUI as its backend and shows the raw workflow graph. It supports image models such as Stable Diffusion and Flux, and some video and audio models. It suits high school art and media classes with technical help.

## Benefits for students
- Students turn text prompts into images and see results in minutes.
- Students can try several models and compare the results.
- Advanced students can open the workflow graph and see each step.

## Benefits for teachers
- The browser interface is easy to learn after setup.
- Teachers can show how image generation works step by step.
- Setup is advanced and needs IT help.

## Benefits for schools
- The software is free and uses the MIT license.
- It can run on a school server for many users, per a directory listing.
- A strong GPU computer or server is the main cost, and IT must decide on content filtering.

## Getting started
- [ ] Find the SwarmUI repository on GitHub.
- [ ] Ask IT to approve the install and a content filtering plan.
- [ ] Run the install script on Windows or Linux. On a Mac, clone the project and launch it.
- [ ] Open the interface at localhost port 7801.
- [ ] Download a model separately and read its license.
- [ ] Test a classroom safe prompt.
- [ ] Go offline and confirm images still generate.

## Where is the AI?
The AI is a set of image generation models, and some can make video. They run on the local machine or a school server. Students write prompts, review the images, and adjust settings to guide the result. The software is in beta.

## Privacy and safety
No account is needed. The internet is used to install and download models. Local runs keep prompts and images on the machine or school server. The README mentions optional cloud GPU hosting and has no privacy policy or telemetry statement. The research found no safety filter documented. A teacher should set filtering and review prompts before students use it. Models carry their own licenses and content risks.
