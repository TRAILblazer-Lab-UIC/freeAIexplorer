## Overview
GeoDa is a free, open source desktop program for learning spatial data science. It was developed by Luc Anselin and team. It has a graphical interface for exploring spatial data, checking for spatial patterns, and running basic spatial regression. Linked maps and charts show the results.

## Benefits for students
- Students see data on a map and in a chart at the same time.
- Students can select points on one view and watch them highlight in the other.
- Students practice clustering methods such as k-means and hierarchical clustering.

## Benefits for teachers
- The program is built as a graphical introduction for people who are not GIS specialists.
- It reads shapefiles, GeoJSON, CSV, and spreadsheets.
- It suits an advanced high school data unit.

## Benefits for schools
- The program is free and the code is open source.
- No account is needed, and the program opens files on the device.
- It runs on Windows, macOS, and Linux but not as a native Chromebook app.

## Getting started
- [ ] Download the installer for your system from the GeoDa site.
- [ ] Ask IT to approve the install.
- [ ] Install GeoDa on a teacher computer and a few lab machines.
- [ ] Open a sample shapefile and look at the linked map and chart.
- [ ] Import a CSV table that has coordinates.
- [ ] Try a cluster map on a simple dataset.
- [ ] Plan a short lesson around one local dataset.

## Where is the AI?
The vendor says AI is optional here. The program includes clustering and dimension reduction tools such as k-means, hierarchical clustering, and PCA. These run on the local computer. Students use them to group places with similar data and then explain the groups in their own words.

## Privacy and safety
No account is needed and the program runs locally. The site shows no telemetry statement, and the research did not confirm whether the app sends any. Basemaps may load map tiles from the internet. Data files stay on the device. A teacher should check that any dataset students load does not contain personal information. A teacher should also ask IT whether the app contacts any server.

## Ideas by subject
### social_studies
1. Map the median income of local neighborhoods and describe the pattern.
2. Compare a map of two variables and write about a possible link.
3. Use a cluster map to find regions with similar traits and name each region.
4. Load a historical dataset and see how places changed over time.
5. Present one finding about your community with a map and a chart.

### math
1. Select points on a scatter plot and find them on the map.
2. Read a spatial regression result and explain what a coefficient says.
3. Compare the mean of a variable for two clusters.
4. Create a histogram for one variable and describe its shape.
5. Explain what it means for nearby places to have similar values.

### science
1. Map a set of environmental readings and look for hot spots.
2. Use clustering to group sites by water quality or air readings.
3. Run PCA on a dataset and describe which variables matter most.
4. Compare a cluster map with a field observation.
5. Write a short report that states a question, a method, and a finding.
