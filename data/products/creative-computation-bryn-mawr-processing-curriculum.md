## Overview
Creative Computation is a CS1 curriculum from Bryn Mawr College that teaches programming through visual media in Processing. Topics include fractals and L-systems, image processing, emergent systems, cellular automata, and data visualization. The authors report that instructors adapted it for high school Pre-AP CS, AP CS Principles, and AP CS A.

## Benefits for students
- Students learn to program by making art.
- Students explore patterns such as fractals and cellular automata.
- Students see results in images and visualizations.

## Benefits for teachers
- The course materials repository is free to view.
- Instructors have adapted the course for high school classes.
- The notes name the authors, which helps teachers find support.

## Benefits for schools
- Materials are free to view and Processing is free.
- A textbook exists, and the notes list it as Processing 2.
- Processing installs on Windows, Mac, and Linux and needs the internet only for setup.

## Where is the AI?
This curriculum has no AI. It builds skills in logic, data, and pattern spotting. Students write code that draws and visualizes patterns.

## Privacy and safety
Processing runs locally as a desktop editor, and the research did not read the course site fully. The research found no account requirement and no student data collection, but no privacy policy was reviewed. The internet is needed for setup. A teacher should check that school devices allow installing Processing and review its terms before class.

## Ideas by subject
### computer_science
1. Write a Processing sketch that draws a shape and changes its color.
2. Use a loop to draw a pattern of circles.
3. Build a simple animation with variables.
4. Debug a sketch with a typo.
5. Adapt a sketch from the course and explain the changes.

### visual_arts
1. Create a piece of generative art with code.
2. Draw a fractal tree and vary its angles.
3. Process a photo with a filter you write.
4. Choose a color palette and apply it across a sketch.
5. Show the art and explain the code behind it.

### math
1. Draw a fractal and describe how it repeats.
2. Run a cellular automaton and describe the pattern.
3. Use coordinates to place shapes at set points.
4. Chart a small data set with a visualization.
5. Compare two rules and describe the different results.
