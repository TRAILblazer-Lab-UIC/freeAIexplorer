## Overview
LunaSim is a lightweight, open source tool for system dynamics modeling. Students build stock and flow diagrams in the browser. It has a graphical editor, JavaScript equations, numerical simulation, and custom charts and tables. Students at Poolesville High School in Maryland built it as a free replacement for commercial software.

## Benefits for students
- Students model how a system changes over time.
- Students write equations and see the results as charts and tables.
- Students can use it on Windows and Chromebooks.

## Benefits for teachers
- The tool opens in a browser in minutes.
- It was used by over 60 students in a 9th grade computer science course, per the developers.
- Teachers can link models to science and math topics.

## Benefits for schools
- The tool is free.
- No install is needed, and the app can be hosted on any static web host.
- The GoJS library needs a license for commercial use.

## Getting started
- [ ] Open lunasim.org in a modern browser. It redirects to phs-smcs.github.io/LunaSim.
- [ ] Add a stock and a flow to the canvas.
- [ ] Add a variable and write a simple equation.
- [ ] Run the simulation.
- [ ] Open the chart and the table of results.
- [ ] Change one value and run it again.
- [ ] Test the page on a Chromebook before class.

## Where is the AI?
LunaSim has no AI. It builds skills in modeling and data. Students predict how a system will change and compare the prediction to the simulation.

## Privacy and safety
No account is mentioned in the README. It is a static web app. The research found no privacy policy. The materials do not state whether the internet is needed after the page loads, whether models are saved on the device, or whether anything is sent elsewhere. A teacher should test the tool offline and check where student models are saved.

## Ideas by subject
### science
1. Model the water in a pond with stocks for water and flows for rain and evaporation.
2. Build a predator and prey model and watch how the populations change.
3. Model the spread of an illness in a school.
4. Change one input and explain what the model shows.
5. Compare a model to real data and describe where they differ.

### math
1. Write an equation for a flow and graph the result.
2. Compare linear and exponential growth in one model.
3. Read values from a table and sketch the matching graph.
4. Test how a small change in a rate affects the result.
5. Explain what a stock and a flow mean in math words.

### computer_science
1. Write a JavaScript equation for a flow.
2. Debug a model that gives an unexpected result.
3. Plan a model on paper before building it.
4. Use variables and influences to connect parts of a model.
5. Present a model and describe its rules to the class.
