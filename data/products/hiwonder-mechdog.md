## Overview
MechDog is an ESP32 based quadruped robot dog. The documentation covers programming in Scratch with the WonderCode editor, in Python, in Arduino, and with micro:bit MakeCode. Lessons include motion control, voice interaction, AI vision games, and action editing. The vendor does not state a grade range. The extract places it at grades 3 to 8.

## Benefits for students
- Students program a walking robot dog with blocks.
- Students can move on to Python or Arduino later.
- Students try voice and vision lessons with add-on modules.

## Benefits for teachers
- A phone app controls the dog for quick demos.
- Several programming paths fit different classes.
- The documentation page is very long. Teachers should pick a few lessons.

## Benefits for schools
- Prices were not retrieved. Several kit tiers exist.
- WonderCode runs on Windows. Mac support is not stated.
- IT will likely need to install WonderCode and a USB serial driver.

## Getting started
- [ ] Find the MechDog documentation on the Hiwonder site.
- [ ] Ask IT to install WonderCode and the CH340 USB driver on a Windows PC.
- [ ] Charge the battery.
- [ ] Add the MechDog extension in WonderCode.
- [ ] Choose the COM port and connect the controller by USB.
- [ ] Download a first program to the dog.
- [ ] Try the phone app.

## Where is the AI?
AI is optional. The voice interaction and AI vision games need add-on modules. The vendor does not say where the AI runs. Without the add-ons the robot has no AI, but students still build sequencing and logic skills by programming its motion.

## Privacy and safety
No account is needed and the internet is used at setup only. Programs are sent to the controller over USB. The research did not review the data terms of the phone app or the add-on modules, and no privacy policy was reviewed. The vendor does not say where the voice and vision features run. A teacher should check the app permissions. A teacher should also decide whether to use voice modules in class.

## Ideas by subject
### computer_science
1. Program the dog in Scratch to walk, turn, and sit in order.
2. Edit a motion so the dog waves.
3. Switch one project from blocks to Python and compare them.
4. Use a loop to repeat a dance routine.
5. Plan a group show in which several dogs follow one script.

### engineering
1. Assemble the dog and check each leg joint.
2. Test how battery level changes the dog's walking.
3. Measure how far the dog walks in ten steps.
4. Design a course with a ramp and test the dog.
5. Explain how the four legs balance the body.
