## Overview
The M5GO IoT Kit has SKU K006 and is built around the M5GO controller, an ESP32 dual core board with a 2 inch screen, speaker, microphone, 10 RGB LEDs, motion sensors and a battery. The kit adds six units, LEGO compatible bricks and connectors, Grove cables and a USB-C cable. It can be programmed in UiFlow blocks, Arduino IDE, ESP-IDF or PlatformIO. The docs describe it as STEM education for students of all ages.

## Benefits for students
- Students program a device with a screen and sensors.
- Students use units such as a temperature sensor and a motion sensor.
- Students can start with blocks and move to code.

## Benefits for teachers
- The kit offers block and text programming options.
- The LEGO compatible mounts help with builds.
- The teacher learning curve is advanced.

## Getting started
- [ ] Find the kit on the M5Stack site and check the current model.
- [ ] Buy the kit and a computer with USB.
- [ ] Ask IT to install M5Burner or the Arduino IDE.
- [ ] Connect the controller by USB-C.
- [ ] Flash the UiFlow firmware through M5Burner.
- [ ] Open UiFlow and build a first block program.
- [ ] Review the M5Stack privacy terms before students sign in.

## Where is the AI?
The vendor does not describe any AI in the kit. The device follows the code that students write. Students build skills in sensors, data and logic with the environment, motion and light units.

## Privacy and safety
The materials do not state which accounts students need or what data is collected. Programs run on the device, which has 2.4 GHz Wi-Fi. The docs describe a cloud based UIFlow WebIDE for pushing code over the network. The research read no privacy policy. The M5Stack privacy policy URL tried returned a 404. A teacher should check the UiFlow account terms and whether the school network allows the tools.
