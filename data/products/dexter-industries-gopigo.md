## Overview
GoPiGo is a Raspberry Pi robot car kit for learning to code. Students program it with Bloxter, a Blockly based block language, or with Python in Jupyter Notebooks. It has encoder motors, sensor ports, servos, and camera support. The Dexter Industries page says GoPiGo has moved to GoPiGo.io, where it is sold under Modular Robotics.

## Benefits for students
- Students can start with blocks and move to Python.
- Students use distance, light, color, and motion sensors.
- Students program the robot from a browser.

## Benefits for teachers
- Free built-in lessons are included.
- Nothing needs installing on the student device.
- Hood College used it to teach Python and open source programming.

## Benefits for schools
- GoPiGo.io lists the kit at 199 USD without a Raspberry Pi.
- The older Dexter page lists a full kit at 229 USD and a five-kit set at 1,190 USD.
- Prices differ between the two sites.

## Where is the AI?
AI is optional. The robot can reach a cloud vision service for image tasks. The rest of the robot runs on the Raspberry Pi. Students program the camera and sensors and can add a vision call to extend their project.

## Privacy and safety
No account is needed for the robot, and the internet is used mainly for setup. The robot runs on a local Raspberry Pi and makes its own Wi-Fi network. The vendor says advanced users can connect to Google's Cloud Vision API, which would send images to Google. Bloxter.com lets users share programs online. No privacy policy was found. A teacher should check any cloud vision service before students use it. GoPiGo.io lists ages 13 and up, and a teacher should confirm that with the vendor.

## Ideas by subject
### computer_science
1. Write a Bloxter program that drives the robot in a square.
2. Rewrite the same program in Python in a Jupyter Notebook.
3. Read a sensor value and print it on screen.
4. Make the robot stop when it senses an obstacle.
5. Compare block code and Python for the same task.

### engineering
1. Assemble the robot and list its parts.
2. Test the distance sensor at several ranges and chart the results.
3. Tune the motor speed and measure how far the robot travels.
4. Design a bumper for the front of the car.
5. Turn a robot into a rover for a science mission.
