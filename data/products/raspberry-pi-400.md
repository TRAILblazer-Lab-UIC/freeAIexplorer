## Overview
The Raspberry Pi 400 is a complete computer built into a keyboard. It has a quad-core 64-bit processor, 4GB of RAM, a 40-pin GPIO header, dual display output, and wireless networking. The personal computer kit adds a mouse, a power supply, a cable, and an SD card preloaded with Raspberry Pi OS. Students use it as a desktop for programming, and the GPIO header allows physical computing projects.

## Benefits for students
- Students get a real computer that they can program.
- Students can build circuits through the GPIO header.
- Students use the same Raspberry Pi OS tools that many classrooms use.

## Benefits for teachers
- The kit comes with the parts for setup.
- The preloaded SD card cuts setup work.
- Teachers should check HDMI cabling in classrooms.

## Benefits for schools
- The cost is low. The Pi 500 launch article says the price was cut to USD 60, or USD 80 as a kit.
- The computer needs its own monitor.
- The Pi 500 is its successor.

## Getting started
- [ ] Get the Raspberry Pi 400 kit from a Raspberry Pi reseller.
- [ ] Check that each classroom has a monitor with HDMI.
- [ ] Insert the preloaded SD card.
- [ ] Plug in the monitor, mouse, and power supply.
- [ ] Boot the computer and follow the setup screens.
- [ ] Set a strong password for the user account during setup.
- [ ] Without the kit, flash Raspberry Pi OS onto an SD card using Raspberry Pi Imager.

## Where is the AI?
The Raspberry Pi 400 has no AI. It builds an AI-related skill, which is working with sensors and logic. Students wire parts to the GPIO header and write code that reads them. That practice shows how computers sense and respond.

## Privacy and safety
No account is needed. The computer runs Raspberry Pi OS locally, and the maker does not collect usage data from the device. The internet is needed to update the system or install packages. The Raspberry Pi privacy policy covers the website, orders, and services such as Connect, and it does not address children or school accounts. A teacher should set a strong password and check that the school network allows updates. A teacher should also check wiring rules before students use the GPIO header.
