## Overview
Webots is an open source desktop application for simulating robots. Cyberbotics has developed it since 1998. It includes many sample robots from wheeled to industrial arms and drones. Programs can be written in C, C++, Python, Java, MATLAB, or through ROS.

## Benefits for students
- Students test robot code in a simulator without hardware.
- Students try many sample robots.
- Students write real code in Python, C, or C++.

## Benefits for teachers
- The simulator is used in university robotics courses.
- Teachers can open sample worlds to start.
- It runs on Windows, macOS, and Linux.

## Benefits for schools
- The download is free. Paid support plans start at CHF 500 per year.
- No robot hardware is needed.
- Each computer needs a graphics card for 3D rendering, and IT will install it.

## Getting started
- [ ] Find Webots from Cyberbotics.

- [ ] Run a sample robot.
- [ ] Change a line of Python code and rerun.
- [ ] Pick one world for a first class activity.

## Where is the AI?
Webots has no AI of its own. It simulates robots that run the code students write. Students build skills in logic and sensor data.

## Privacy and safety
No account is needed and the internet is used only at setup. Webots is a local desktop install. The research did not read a privacy policy. A teacher should test the graphics needs on a school machine. A teacher should also check what the paid support plan involves before buying.
