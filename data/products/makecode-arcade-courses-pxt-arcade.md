## Overview
The courses page of the MakeCode Arcade project lists classroom courses and short lessons. The courses include AP Computer Science Principles, a full-year Introduction to Computer Science, and Code a Carnival for grades 5 to 12. It also lists two TinkerGen GameGo courses and three short lessons. The first two courses need an Educator Verified GitHub account to download.

## Benefits for students
- Students can follow a full-year path in game-based coding.
- Students in grades 5 to 12 can try the Code a Carnival activities.
- Students can start with a short lesson.

## Benefits for teachers
- A teacher can pick a course for AP CSP or intro CS.
- Short lessons Cherry Pickr, Dance Party, and BlockOut fit one class.
- Code a Carnival has modular activities.

## Benefits for schools
- The courses are free. A GameGo device is a separate purchase.
- The project is open source under the MIT license.
- A teacher must verify a GitHub educator account for two courses.

## Getting started
- [ ] Open the courses page of the MakeCode Arcade project.
- [ ] Choose a course or a short lesson.
- [ ] Verify a GitHub educator account for AP CSP or Intro CS.
- [ ] Download the materials.
- [ ] Open the editor in a browser and test a lesson.
- [ ] Plan the course across the year.
- [ ] Order GameGo devices only if you choose those courses.

## Where is the AI?
These courses have no AI. The vendor describes no AI features. Students write code with blocks. They build skills in logic, events, and sequencing.

## Privacy and safety
An account is optional for students. The page says two courses need an Educator Verified GitHub account to download. Code a Carnival needs no verification. GameGo courses are free after login on the TinkerGen site. The materials do not state what student data is collected. The research did not read a privacy policy for student data handling inside Arcade. A teacher should check the privacy terms for MakeCode, GitHub, and TinkerGen.

## Ideas by subject
### computer_science

2. Create a Code a Carnival game and add a score.
3. Plan a game on paper and then build it.
4. Test a classmate's game and write one improvement.
5. Compare how a block program and a JavaScript program do the same job.
