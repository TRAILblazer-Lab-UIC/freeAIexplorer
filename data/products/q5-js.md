## Overview
q5.js is an open source JavaScript graphics library for creative coding. It describes itself as beginner friendly graphics powered by WebGPU. It works with much of p5.js code and has Python support, interactive learn pages, and a Spanish translation of the API. It has no dependencies and is about 140 KB minified.

## Benefits for students
- Students draw shapes and animations with a few lines of code.
- Students can learn from interactive learn pages in the browser.
- Spanish speakers can use the translated API.

## Benefits for teachers
- Teachers can start with the q5 Learn pages.
- The library works with addons such as p5.sound, ml5.js, and q5play.
- Teachers who know p5.js can reuse that knowledge.

## Benefits for schools
- The library is free and open source.
- It runs in the browser on Chromebooks, Windows, Mac, and Linux.
- Work stays on the device after setup.

## Getting started
- [ ] Open the q5js.org Learn pages in a browser.
- [ ] Check that the school browsers support WebGPU.
- [ ] Try a first sketch on the learn page.
- [ ] Add the library to an HTML file with a script tag.
- [ ] Use a code editor of your choice for longer projects.
- [ ] Test whether sketches still run on browsers without WebGPU.
- [ ] Read the note that q5.js is not affiliated with the Processing Foundation.

## Where is the AI?
q5.js has no AI. It builds an AI-related skill, which is pattern spotting. Students use loops and numbers to make repeating designs. That practice helps them see patterns in data.

## Privacy and safety
No account is needed. The library runs in the browser on the device. A page that loads it from a CDN needs the internet. Student sketches are stored wherever the teacher chooses. No privacy policy was found. The vendor materials do not say whether sketches work without WebGPU. A teacher should test the browsers on school devices before class.
