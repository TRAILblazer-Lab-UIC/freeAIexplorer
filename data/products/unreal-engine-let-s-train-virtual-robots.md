## Overview
This is a five lesson learning path for ages 13 and up that uses Blueprint visual scripting in Unreal Engine. Students program virtual robots from the Robotics Learning Kit. Lessons cover robot vehicles and sensors, sumo robots, a line following delivery bot, and collision avoidance. Each lesson has a lesson plan and a student guide.

## Benefits for students
- Students program virtual robots with visual blocks.
- Students build sumo and line following robots.
- Students practice robot sensors and decisions.

## Benefits for teachers
- Each lesson has a lesson plan and a student guide.
- Lesson 2 is listed at one hour.
- No physical robots are needed.

## Benefits for schools
- Notes and search summaries describe the lessons as free.
- Each computer needs to be able to run Unreal Engine.
- IT will likely need to install the software.

## Where is the AI?
The lessons have no AI. Students use Blueprint scripting to decide how a virtual robot reacts to its sensors. They build skills in logic and sensor data.

## Ideas by subject
### computer_science
1. Use Blueprint nodes to make a virtual robot drive forward.
2. Add a sensor check that makes the robot turn.
3. Build a decision that picks left or right.
4. Change a value and observe the effect.
5. Debug a Blueprint that makes the robot miss its target.

### engineering
1. Design a sumo robot in the lessons and test it in a match.
2. Tune a line following bot until it stays on track.
3. Compare two sensor choices for the same task.
4. Test collision avoidance and record each crash.
5. Plan a delivery route and test the bot on it.
