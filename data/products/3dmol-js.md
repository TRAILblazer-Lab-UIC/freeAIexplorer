## Overview
3Dmol.js is an object-oriented JavaScript library for visualizing molecular data in web pages. Viewers can be embedded with a few lines of code, used through a URL interface, or used in Jupyter notebooks. The project also has a learning environment in which an instructor shares a session so students see the same molecular view. The documented classroom use is a college organic chemistry recitation.

## Benefits for students
- Students can rotate and inspect molecules in 3D.
- Students can click atoms in a shared structure to answer questions.
- Students who code can embed a viewer in their own page.

## Benefits for teachers
- The site has a Teach section for classroom use.
- A shared session lets a teacher show one view to the whole class.
- The tool is developer oriented. Some web or code skill helps.

## Benefits for schools
- The library is free and uses a BSD-3-Clause license.
- It runs in a browser with WebGL on Chromebooks, Windows, Mac and Linux.
- A school may host its own server for shared sessions. The documented classroom use is college level.

## Getting started
- [ ] Open the 3Dmol.js site and find the hosted viewer.
- [ ] Check that a student browser supports WebGL.
- [ ] Try the declarative URL interface to load a molecule.
- [ ] Read the Teach section for the learning environment.
- [ ] Start a shared session and test it with a few students.
- [ ] Ask IT before hosting your own server.
- [ ] Note that the site says some documentation has moved.

## Where is the AI?
3Dmol.js has no AI. Students build skills in reading 3D structures and in basic web code. They look at molecules from many angles and answer questions about them.

## Privacy and safety
No accounts are described. The viewer runs in the browser. Shared class sessions use a hosted server that holds anonymous clicked-atom responses until the instructor disconnects, according to the 2020 paper. The research found no privacy policy. The hosted server's logging and retention are not documented. A teacher should decide before class whether to use the free hosted server or a school server.
