## Overview
This is a guide for teachers and professionals who work with students with visual impairments. It covers getting to know the board, sound alternatives, LED visibility, tactile learning, screen reader coding, and MakeCode adaptations. Linked resources include a text tour, a tactile diagram, keyboard navigation, cut-out block cards with optional braille, and unplugged activities. The page says MakeCode became screen reader accessible as of summer 2026.

## Benefits for students
- Students learn the board through touch and sound.
- Students can code with a screen reader.
- Students can use unplugged activities to learn coding ideas.

## Benefits for teachers
- A full text tour describes the board in words.
- Printable block cards support tactile coding.
- A feedback address is on the page at accessibility@microbit.org.

## Benefits for schools
- The guides are free. Boards and accessories are paid.
- A tactile graphics machine is needed to raise the diagram.
- Teachers should review the guides in advance.

## Getting started
- [ ] Find the accessibility guides on the micro:bit site.
- [ ] Read the guides before class.
- [ ] Print the tactile resources and the block cards.
- [ ] Use a tactile graphics machine to raise the board diagram.
- [ ] Load a welcome program onto each micro:bit.
- [ ] Try MakeCode with a screen reader and keyboard.
- [ ] Send feedback to the accessibility address.

## Where is the AI?
These guides have no AI. The vendor describes no AI features. Students build skills in sequencing and logic through touch and sound.

## Privacy and safety
The materials do not state which accounts students need or where data goes. The guides use a browser and a board. The software named is MakeCode, the micro:bit Python Editor, and HumanWare KeyCode. The research read no privacy policy. A teacher should check the MakeCode privacy terms and review each student's access needs with their support team.

## Ideas by subject
### special_ed
1. Explore the board with the tactile diagram and name each part.
2. Use the text tour to describe the board to a partner.
3. Sort cut-out block cards into a program order.
4. Use sound output in place of the LED display.
5. Run a program and describe what the board does.

### computer_science
1. Write a program with a screen reader and keyboard.
2. Use block cards to plan a program before coding.
3. Make a sound alert for a button press.
4. Test a program with another student and share feedback.
5. Complete an unplugged activity on sequencing.
