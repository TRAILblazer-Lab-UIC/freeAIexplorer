## Overview
Gazebo is an open source 3D robotics simulator that models physics, rendering and sensors such as cameras and laser range finders. It is often paired with ROS 2 and used in robotics competitions and research. Users test robot designs and control code in simulated worlds without hardware. It suits advanced high school students and runs as a desktop program.

## Benefits for students
- Students test robot code in a simulated world.
- Students work with sensors such as cameras and lidar.
- Students see tools used in real robotics research.

## Benefits for teachers
- The Gazebo getting started page gives install steps.
- Long-term support releases stay stable for years. Jetty is supported through May 2031.
- The simulator needs no robot hardware.

## Benefits for schools
- Gazebo is free.
- The software installs locally and keeps student work on the device.
- The tool has a steep learning curve and needs IT help.

## Getting started
- [ ] Find Gazebo at the official Gazebo site and open the getting started page.
- [ ] Ask IT to install it on an Ubuntu or macOS computer.
- [ ] Check that the computer has a GPU that can render 3D.
- [ ] Choose a current release. Gazebo Classic ended in January 2025.
- [ ] Install a matching ROS 2 release for ROS 2 work.
- [ ] Skip Windows unless IT accepts the experimental support.
- [ ] Run a sample world.

## Where is the AI?
Gazebo has no AI. It simulates physics and sensor data. Students build skills in sensors and testing by running the same code in a simulated world.

## Privacy and safety
No account is needed and the internet is used only at setup. Gazebo is a local desktop install, and the documentation shows no student data collection. The research did not review a privacy policy for the software. A teacher should confirm the hardware and operating system before planning a lesson. Gazebo is not a Chromebook tool.

## Ideas by subject
### engineering
1. Open a sample world and describe how the robot is built.
2. Change a robot's wheel size and observe how it moves.
3. Add a camera sensor and view its output.
4. Test a robot design in a competition style world.
5. Write a short report on what the simulation showed that a real test could not.

### computer_science
1. Run a sample robot in a simulated world.
2. Write control code that drives the robot to a goal.
3. Read lidar data and describe what it shows.
4. Connect Gazebo to ROS 2 and send a command.
5. Debug a program that makes the robot collide with a wall.
