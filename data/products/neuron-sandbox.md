## Overview
Neuron Sandbox is a browser tool for exploring how a single linear threshold unit gives answers. Students adjust weights and a threshold until every row of an input and output table is correct. It has modes for solving weights, solving outputs, and solving a decision boundary for two-input problems. The instructions page says it suits upper elementary through undergraduate students.

## Benefits for students
- Students see how weights and a threshold decide an answer.
- Students get hints when they are stuck.
- Students practice with decision boundary sliders for two-input problems.

## Benefits for teachers
- Teachers can build custom problems without coding and save them to a file.
- The instructions page links worksheets and a teaching slide deck.
- The page links an EAAI-25 paper for background.

## Benefits for schools
- The tool is free and the code is open source.
- It runs in a web browser on Chromebooks, Windows, Mac, and Linux.
- No account is needed, and the internet is used only to load the page.

## Getting started
- [ ] Find the Neuron Sandbox page and read the instructions.
- [ ] Open the page in a browser on a student device.
- [ ] Try one problem in each mode.
- [ ] Download the worksheets and the teaching slides.
- [ ] Build a custom problem in Edit Mode and save it to a file.
- [ ] Test the audio on your browser. Some browsers do not support it.
- [ ] Plan one class period for a first session.

## Where is the AI?
The tool has no AI of its own. It is a simulation of one artificial neuron that follows fixed rules. Students build a key AI idea by hand, which is how weights and a threshold turn inputs into an output. The tool runs in the browser on the student's own device.

## Privacy and safety
No account is needed, and the page describes no data collection. Models are saved to and loaded from the user's computer or a URL. The research found no privacy policy and did not confirm offline use after the page loads. A teacher should confirm that saved problem files are kept in a safe place. Some browsers do not support the audio.

## Ideas by subject
### computer_science
1. Solve for the weights that make an AND table correct.
2. Solve for the threshold that makes an OR table correct.
3. Use the solve for outputs mode and explain how each output was found.
4. Build a custom problem for a partner to solve.
5. Explain how one neuron is a building block of a larger network.

### math
1. Move the decision boundary sliders until two groups of points separate.
2. Write an inequality that matches a solved neuron.
3. Graph a decision boundary on paper and compare it with the sandbox.
4. Find two different sets of weights that solve the same table.
5. Explain how changing a weight moves the line on the graph.
