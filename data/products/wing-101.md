## Overview
Wing 101 is a free, simplified Python editor aimed at beginners and self study. It has a focused editor and Python shell. It includes the same debugger as Wing Pro with breakpoints, stepping, and variable watching. It suits high school students.

## Benefits for students
- Students use a clean editor made for beginners.
- Students can step through code and watch variables.
- Students can follow a free book and video course.

## Benefits for teachers
- The page lists a free companion book and video course, Python Programming Fundamentals by Kent D. Lee.
- The editor has no license key, sign up, or nag screens.
- The debugger helps teachers show how code runs.

## Benefits for schools
- It is free for any purpose, including classrooms.
- It runs on Windows, macOS, and Linux but not on Chromebooks.
- IT may need to approve the install.

## Getting started
- [ ] Download the installer for your operating system from the Wing site.
- [ ] Ask IT to approve the install on managed computers.
- [ ] Install it on each computer.
- [ ] Open the editor and run a short program in the Python shell.
- [ ] Set a breakpoint and step through a loop.
- [ ] Read the first chapter of the companion book.
- [ ] Share a simple setup guide with students.

## Where is the AI?
This tool has no AI. The editor runs the code that students write. Students build logic and debugging skills as they step through programs.

## Privacy and safety
Wing 101 runs on the computer and needs no account. The download page states there is no sign up, email collection, or license requirement. The research did not review the privacy policy or the license agreement. The internet is needed only to download it. A teacher should read the license agreement and check that school computers support the version for their system.
