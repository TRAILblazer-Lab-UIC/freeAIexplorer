## Overview
This kit is built around the Nezha Pro expansion board and has over 500 building blocks. It includes a voice recognition module and a gesture recognition sensor. The retailer lists ages 7 to 14. Students build models from 16 guided cases and program them to respond to spoken commands and hand movements.

## Benefits for students
- Students build moving models and see how transmission mechanics work.
- Students make a model react to their voice and their hand.
- Students move from simple builds to AI programming activities across the 16 cases.

## Benefits for teachers
- The 16 guided cases give a clear order of lessons.
- Block coding keeps programming approachable for new learners.
- Versions with and without a micro:bit let a teacher reuse boards the school already owns.

## Benefits for schools
- Little Bird lists the kit at 321 AUD without a micro:bit. The version with a micro:bit was out of stock.
- The sensors are add-on modules that run on the device.
- The listing does not name the programming environment. IT should confirm the editor before purchase.

## Where is the AI?
The kit has a voice recognition module and a gesture recognition sensor. The vendor does not say where the recognition runs. The modules attach to the model and likely work on the device. This is not verified. Students program the model to react to words and hand movements.

## Privacy and safety
The materials do not state which tools or accounts students need, and no account is listed. The listing does not say where voice and gesture recognition happen or whether any data is transmitted. The vendor privacy policy covers website orders only. A teacher should check which editor the kit uses and whether it needs a login. A teacher should also check whether the voice module sends audio anywhere.

## Ideas by subject
### engineering
1. Build the first guided case and explain how the transmission moves the parts.
2. Redesign one model to move faster or lift more.
3. Test two block layouts and record which one is stronger.
4. Add the gesture sensor to a model and place it where it works best.
5. Sketch a new machine that uses voice control and present it to the class.

### computer_science
1. Program the model to act when the voice module hears a command.
2. Test the gesture sensor and list which hand movements it detects well.
3. Write block code that gives a different action for each gesture.
4. Predict what happens in a noisy room and then test it.
5. Finish the last guided case and explain the AI programming step in your own words.
