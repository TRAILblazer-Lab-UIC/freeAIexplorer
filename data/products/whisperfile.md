## Overview
whisperfile is a single file speech to text tool built on whisper.cpp. It uses the same packaging as llamafile, a project from Mozilla.ai. It transcribes and translates audio files and runs on Windows, macOS, Linux, and BSD. Usage is by command line and needs technical skill. It suits a teacher or an older student who codes.

## Benefits for students
- Students can transcribe an audio file with one program.
- Students can translate speech in an audio file.
- Students learn how a command line tool works.

## Benefits for teachers
- There is nothing to install beyond the one file.
- The same file runs on many operating systems.
- Teachers can use it to teach about packaging AI models.

## Benefits for schools
- The tool is free and open source.
- Audio is expected to be processed on the school computer. The docs were not read.
- IT will likely need to approve running the file.

## Getting started
- [ ] Find the whisperfile download in the llamafile project.
- [ ] Ask IT to approve running the executable.
- [ ] Download the file.
- [ ] On Windows, rename the file to end in .exe.
- [ ] Open a command line in the folder with the file.
- [ ] Run it on a short audio file.
- [ ] Go offline and test again.

## Where is the AI?
The AI is the Whisper speech recognition model, packaged with its runtime in one file. It runs on the device. Students give it an audio file and read the text it returns. They can then check the result against what they heard.

## Privacy and safety
No account is needed. The internet is used only at setup. The Mozilla.ai page says llamafile models run entirely on the device with no cloud or data sharing. That page does not mention whisperfile. The research infers that audio stays on the computer. The whisperfile documents were not read. A teacher should have IT scan the downloaded executable and watch its network behavior before students run it.
