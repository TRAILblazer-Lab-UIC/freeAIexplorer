## Overview
The Adafruit PyBadge is a credit card sized board with a 160x128 color screen, eight game console style buttons, five NeoPixel LEDs and a buzzer. It uses an ATSAMD51J19 microcontroller at 120MHz. Students can program it with block based MakeCode Arcade, with CircuitPython, or with Arduino. Programs load over USB and run on the board.

## Benefits for students
- Students make games that play on a real handheld.
- Students can start with blocks and move to text code.
- Students can build projects at home because the MakeCode Arcade editor works without a board.

## Benefits for teachers
- A lesson called Making a Name Tag in MakeCode Arcade is available.
- Three coding options let teachers choose a level.
- MakeCode Arcade works in Chrome per Adafruit guides.

## Benefits for schools
- A single board costs 34.95 USD and an order of 100 costs 27.96 USD each.
- A battery costs 6.95 USD extra.
- Code runs on the board and the dossier lists no data collected.

## Getting started
- [ ] Buy the board from Adafruit.
- [ ] Open MakeCode Arcade in Chrome.
- [ ] Connect the board by USB.
- [ ] Drag a game file onto the bootloader drive.
- [ ] Try the name tag lesson.
- [ ] Add CircuitPython or Arduino for older students.
- [ ] Test the board on a school computer first.

## Where is the AI?
The board has no AI. Students build skills in logic and sequencing as they code buttons, sprites and scores. They learn how a game reacts to input.

## Privacy and safety
The board stores programs on the device, has no network radio, and needs no account. Students can program it with the MakeCode Arcade web editor in a browser. The research did not review that editor's data practices. The research found no privacy policy for the board. The internet is used at setup. A teacher should check the MakeCode Arcade terms and confirm that USB drives work on school computers.

## Ideas by subject
### computer_science
1. Build a MakeCode Arcade name tag that shows a student's name.
2. Write code that moves a sprite with the arrow buttons.
3. Add a score that goes up each time a sprite touches a coin.
4. Use the buzzer to play a sound when a goal is reached.
5. Rewrite a simple game in CircuitPython.

### engineering
1. Test the accelerometer and use it to tilt a character.
2. Set the five NeoPixels to show a game status.
3. Design a game controller layout using the eight buttons.
4. Add a sensor through the JST port.
5. Compare how battery power changes how you use the board.
