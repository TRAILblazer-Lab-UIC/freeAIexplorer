## Overview
microStudio is a free browser game engine for 2D games. Users write code in microScript, JavaScript, Python, or Lua, and draw sprites and maps in the same tool. A guest can start without an account. An account allows saving, teams, and publishing.

## Benefits for students
- Students code and draw in one place.
- Students choose from several languages, including Python.
- Students export a finished game to HTML5 in one click.

## Benefits for teachers
- A guest can start with no sign up.
- The interface is available in several languages, including Spanish and French.
- Teams let students work together on one game.

## Benefits for schools
- The tool is free.
- A standalone offline app exists for Windows, Mac, Linux, and Raspberry Pi.
- Schools can self-host the server with Node.js.

## Getting started
- [ ] Open microstudio.dev and start as a guest.
- [ ] Decide whether students will create accounts to save work.
- [ ] Download the standalone app for offline work.
- [ ] Ask IT about self-hosting the server with Node.js.
- [ ] Try the code, sprite, and map editors with a small game.
- [ ] Export a game to HTML5 and test it.

## Where is the AI?
This tool has no AI. It builds the skills of coding, logic, and design. Students practice writing rules for how a game reacts to input.

## Privacy and safety
A guest needs no account. An account is needed to save projects online, work in teams, or publish. Projects saved online are stored on the microstudio.dev server. The internet is needed at all times in the browser version. The site says it uses no third party tracking scripts. The research did not read a separate privacy policy. Deleting an account removes projects permanently. A teacher should decide whether accounts are allowed and consider the self hosted option or the offline standalone app to keep data at school.
