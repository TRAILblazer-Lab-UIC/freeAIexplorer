## Overview
Lightbot: Code Hour is a free puzzle game made for the Hour of Code. It has 20 levels. Players guide a robot to light up tiles using commands. Students learn sequencing, procedures, loops, and conditionals without typing code.

## Benefits for students
- Students learn core coding ideas through play.
- Students can tap and drag commands with no typing.
- Students get a clear goal in every level.

## Benefits for teachers
- Teachers can run a full Hour of Code activity with it.
- Younger grades engage quickly.
- A co-player may help children under 8.

## Benefits for schools
- The game is free. The paid follow-on app has 50 levels.
- No account is needed.
- Teachers install the app on each device from the App Store, Google Play, or Amazon.

## Getting started
- [ ] Find Lightbot: Code Hour in the App Store, Google Play, or Amazon.
- [ ] Check the device needs iOS 5.1.1 or later, or macOS 11 on Apple silicon.
- [ ] Install the app on each device.
- [ ] Play the first levels yourself.
- [ ] Pair younger students with a partner.
- [ ] Use the multiple save slots so each student keeps a place.
- [ ] Use the educator resources for an Hour of Code plan.

## Where is the AI?
Lightbot has no AI. Students give the robot commands in order. They build skills in sequencing, loops, and logic. Later levels need procedures. Students learn to reuse a set of steps.

## Ideas by subject
### computer_science
1. Solve the early levels by planning the full command list before tapping run.
2. Use a loop to shorten a long list of repeated commands.
3. Build a procedure and call it more than once in one level.
4. Explain a solution to a partner and ask them to find any mistakes.
5. Act out a level on the floor with a classmate as the robot.

### math
1. Count the steps needed to reach a tile and check the count against the solution.
2. Predict the path the robot will take and test the guess.
3. Compare two solutions and decide which uses fewer commands.
4. Describe the robot's turns using left and right and quarter turns.
5. Write the steps for a level as a short list and look for a repeated pattern.
