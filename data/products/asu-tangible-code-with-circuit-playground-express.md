## Overview
This is Lesson 1 of a Tangible Code series on the ASU STEM Teachers site. It introduces students to the parts and components of the Adafruit Circuit Playground Express board. Students then start to code it. The official page could not be read. This summary is based on a search listing.

## Benefits for students
- Students learn the parts of a real board.
- Students take their first steps in coding it.
- Students see code change lights and sound.

## Benefits for teachers
- The lesson is the first in a series.
- The board is commonly coded in Microsoft MakeCode.
- MakeCode courses map to CSTA standards.

## Benefits for schools
- The lesson plan is free.
- Boards are bought separately and one search result lists a Code.org pack at 350 USD.
- IT may need to help with software and USB.

## Where is the AI?
The lesson has no AI. Students build skills in sequencing and sensors. They tell the board what to do and see the result.

## Privacy and safety
The board runs code on the device. The research did not confirm which coding editor the lesson uses. MakeCode runs in a browser and stores projects locally. The materials do not say whether an account or the internet is needed. The official page could not be read. A teacher should check the editor, any saved projects, and whether the internet is needed.

## Ideas by subject
### computer_science
1. Write a block program that lights one NeoPixel.
2. Add a button that changes the light color.
3. Use a loop to repeat a light pattern.
4. Test a program in the simulator before loading it.
5. Describe in words what each block does.

### engineering
1. Find and name the main parts on the board.
2. Test which sensors respond to light, sound or touch.
3. Match each part to a job in a project.
4. Plan a simple device using three board parts.
5. Draw a labeled diagram of the board.
