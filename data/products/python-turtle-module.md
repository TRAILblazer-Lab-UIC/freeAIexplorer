## Overview
The turtle module is Python's turtle graphics library. It follows drawing tools introduced in Logo in 1967. Students control a turtle that moves on screen and draws a line as it goes. The documentation calls it an educational tool with instant visible feedback.

## Benefits for students
- Students see each command draw a line at once.
- Students use pen, color, and fill commands to make art.
- Students can add mouse and keyboard events to make games.

## Benefits for teachers
- The module ships with Python. No separate install is needed.
- An Australian Digital Technologies Hub lesson plan covers move and turn commands.
- The turtledemo viewer gives teachers ready examples.

## Benefits for schools
- The tool is free and open source.
- Student work stays on the computer.
- IT may need to install Python on managed computers.

## Getting started
- [ ] Find Python on the official Python site and download the installer.
- [ ] Ask IT to approve the install on managed computers.
- [ ] Install Python, which includes tkinter on Windows and macOS.
- [ ] Add a Tk package on Linux systems that package it separately.
- [ ] Run import turtle in a short script.
- [ ] Open the turtledemo viewer to see sample programs.
- [ ] Try the Digital Technologies Hub lesson plan with one class.

## Where is the AI?
The turtle module has no AI. It builds an AI-related skill, which is sequencing. Students give the turtle steps in order and see the result. That practice is the base of every algorithm.

## Privacy and safety
No account is needed, and the internet is used only at setup. Code and drawings stay on the device. The module is not available natively on Chromebooks. A teacher should plan for a browser editor that provides a replacement.
