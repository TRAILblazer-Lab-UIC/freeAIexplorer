## Overview
TurtleBot4Lessons is a GitHub repository of classroom friendly lessons, projects, and tutorials for the TurtleBot 4 robot. Content is organized into units that hold lessons, projects, and question banks. The README says the work is in progress and lessons may be incomplete. A third party listing shows the last update in August 2022.

## Benefits for students
- Students work through lessons on a real mobile robot.
- Students try projects that build on the lessons.
- Students practice ROS 2 programming.

## Benefits for teachers
- Question banks help teachers check student learning.
- Installation guides and tutorials are in the repository.
- Python tools help make slides.

## Benefits for schools
- The lessons are free under a CC BY 4.0 license.
- A TurtleBot 4 robot is needed and no price was read.
- Setup takes days and needs IT.

## Getting started
- [ ] Find the TurtleBot4Lessons repository on GitHub.
- [ ] Read the README and note that it says the work is in progress.
- [ ] Get a TurtleBot 4 robot.
- [ ] Ask IT to set up a ROS 2 computer.
- [ ] Check the Ubuntu and ROS 2 versions the current software needs.
- [ ] Work through the installation folder.
- [ ] Try the first unit yourself.

## Where is the AI?
The lessons have no AI. They teach students to program a robot that follows the code they write. Students build skills in sensing and logic.

## Privacy and safety
The lessons are files in a public GitHub repository. The pages do not describe data collection and do not state whether an account or the internet is needed. The work runs on the robot and a ROS 2 computer. The repository may be inactive since 2022. Check which Ubuntu version the lessons need. The README tested on Ubuntu 20.04.

## Ideas by subject
### engineering
1. Follow an installation tutorial and set up the TurtleBot 4.
2. Work through one lesson and record what the robot did.
3. Try a project from the repository and report the results.
4. Compare the robot's sensors and say what each one detects.
5. Plan a short mission for the robot and test it.

### computer_science
1. Work through a ROS 2 lesson and explain the code.
2. Write a short program that sends a drive command.
3. Use a question bank to check what you learned.
4. Change a value in a tutorial and observe the effect.
5. Debug a lesson example that does not run as written.
