## Overview
Tiny:bit Pro is a micro:bit robot car paired with a K210 AI camera module. Students program the car in MakeCode blocks and the K210 module in MicroPython. Listings mention QR code detection, face recognition, mask detection, and color following. An Android or iOS app or an infrared remote can control it.

## Benefits for students
- Students build a car and teach it to see.
- Students use blocks for the car and Python for the camera.
- Students try QR code and color following projects.

## Benefits for teachers
- MakeCode runs in a browser, which keeps installs light.
- Yahboom offers a code repository for the kit.
- Evidence is retailer based. Teachers should test the kit first.

## Benefits for schools
- Search snippets show 139 AUD at one store and 205.99 USD at RobotShop with a micro:bit.
- The micro:bit board is not included in some versions.
- The AI runs on the car. IT needs little network work.

## Getting started
- [ ] Find the Tiny:bit Pro on the Yahboom site or a retailer.
- [ ] Check that the kit includes a micro:bit. Some versions do not.
- [ ] Assemble the car.
- [ ] Program the car in MakeCode in a browser.
- [ ] Flash MicroPython to the K210 module with Yahboom tools.
- [ ] Test the infrared remote or app control.
- [ ] Run one vision example, such as color following.

## Where is the AI?
The K210 module runs the AI on the device. It handles face recognition, QR code detection, mask detection, and color tracking. Students write MicroPython code that uses what the module sees. They then pass results to the car in MakeCode.

## Privacy and safety
No account is needed and the internet is used at setup. The vision module is described as a self contained on device processor. MakeCode is a separate web service, and the research did not review its data practices. The Yahboom store policy covers customers only, and the phone app practices were not reviewed. A teacher should check the phone app permissions and decide who may be in front of the camera for face tasks.

## Ideas by subject
### computer_science
1. Write a MakeCode program that drives the car in a square.
2. Use color tracking to make the car follow a colored card.
3. Scan a QR code and make the car react with a chosen move.
4. Compare block code for the car with Python code for the camera.
5. Test face recognition and list what makes it fail.

### engineering
1. Assemble the car and test each sensor.
2. Adjust the camera bracket angle and compare views.
3. Test the ultrasonic sensor at three distances.
4. Build a course for the car to follow with colored lines.
5. Write a short assembly guide for another team.
