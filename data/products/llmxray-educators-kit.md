## Overview
The LLMxRay Educators Kit is a curriculum of nine modules for teaching AI and machine learning. Students use local models through Ollama and the LLMxRay inspector. Modules run from What Is a Token to What Words Cost. Each module lasts 45 to 120 minutes and is rated Beginner, Intermediate, or Advanced.

## Benefits for students
- Students see tokens, temperature, and context limits in action.
- Students test how AI can make false statements.
- Students compare models and tool use.

## Benefits for teachers
- Each module has a hands-on exercise and a stated level.
- The page names courses such as Introduction to AI and ML, NLP, Data Science, and AI Ethics.
- Teachers can install on each machine or run one shared Ollama server.

## Benefits for schools
- The kit is free.
- Models run locally. Student prompts stay on school hardware.
- The minimum is 8 GB of RAM with 1B to 3B models. 16 GB and a GPU with 6 GB or more are recommended.

## Getting started
- [ ] Find the LLMxRay Educators Kit and read the module index.
- [ ] Ask IT to approve Ollama and LLMxRay.
- [ ] Install Ollama and pull a small model on each machine or on one shared server.
- [ ] Run LLMxRay with npx or Docker.
- [ ] Try the first module, What Is a Token, yourself.
- [ ] Check the hardware against the 8 GB minimum.
- [ ] Plan the module times and pick the level that suits the class.

## Where is the AI?
The AI is a language model run through Ollama on a student machine or a school server. LLMxRay lets students look inside the model's work. Students change settings, read the output, and study how the model behaves, which extends their own understanding of language models.

## Privacy and safety
No account is needed, and the internet is used for setup. The page states that all data stays on the student's machine. It also describes a shared Ollama server option and does not say where data is stored in that setup. A repository summary says LLMxRay stores data in browser IndexedDB. The research found no privacy policy. Only the index page was read. A teacher should decide whether students use a shared server and check the module pages directly.

## Ideas by subject
### computer_science
1. Enter a sentence and count how the model splits it into tokens.
2. Change the temperature setting and compare three replies to one prompt.
3. Ask the model a question it cannot know and note whether it makes something up.
4. Fill the context window and watch what the model forgets.
5. Compare two models on one task and write a short evaluation.
