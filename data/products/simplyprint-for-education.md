## Overview
SimplyPrint for Education is a cloud platform for managing classroom 3D printers. Teachers approve prints, organize students into classes, and set quotas for each student. Students design in Tinkercad, export to SimplyPrint, and slice in the browser. Submissions go to a shared print queue.

## Benefits for students
- Students send designs to a real printer through a shared queue.
- Students can slice in a browser on Chromebooks and iPads.
- Printing can require a safety course first.

## Benefits for teachers
- Teachers approve each print and set quotas.
- Classes keep student work organized.
- Single sign-on works with Google, Microsoft, or SAML.

## Benefits for schools
- A Classroom tier is listed at 199 dollars a year for 2 printers and 30 students.
- A School tier is listed at 499 dollars for more printers.
- The vendor says 200 or more institutions use it. IT should handle setup.

## Getting started
- [ ] Open the SimplyPrint for Education page.
- [ ] Check that your printers are on the list of supported brands.
- [ ] Ask IT to review the privacy terms and single sign-on.
- [ ] Create an organization and connect the printers.
- [ ] Set up sign-in with Google, Microsoft, or SAML.
- [ ] Create classes and set quotas.
- [ ] Add the safety course before students print.

## Where is the AI?
The vendor claims an optional AI feature that detects print failures. It runs in the vendor's cloud. The vendor does not describe it further. Teachers can use it to watch prints while students focus on the design.

## Privacy and safety
Every user needs an account, and the internet is needed at all times. The service stores user accounts, uploaded models and print activity, and the exact fields are not confirmed. The vendor claims it is FERPA and COPPA aligned, has signed the SDPC student data privacy agreement and is hosted in the EU. The research did not read the privacy policy. An optional failure detection feature runs in the vendor cloud. A teacher should ask the vendor for a data list and check how student data is handled.
