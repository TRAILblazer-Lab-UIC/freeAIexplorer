## Overview
RoboBlocky is a block coding environment built on Google Blockly for learning programming, robotics, Arduino and math. Blocks generate C++ code that runs in Ch to control virtual robots in RoboSim. The same code can also drive physical Linkbot and Lego Mindstorms robots or an Arduino. It includes nearly 500 ready made activities and teacher class management.

## Benefits for students
- Students code virtual robots in a browser.
- Students see the C++ that their blocks make.
- Students can use the same code on real robots.

## Benefits for teachers
- Nearly 500 activities are ready to use.
- Teachers can add student accounts for classes and grading.
- An activity portal supports sharing.

## Benefits for schools
- The tool is free to access.
- The full curriculum is for licensed instructors and their students.
- It needs the internet at all times.

## Getting started
- [ ] Open the RoboBlocky site in a modern browser.
- [ ] Try a virtual Linkbot activity.
- [ ] Decide whether to register as a teacher.
- [ ] Add student accounts only if the school approves them.
- [ ] Ask about the curriculum license.
- [ ] Pick one activity from the C-STEM curriculum.
- [ ] Run it with the class.

## Where is the AI?
The tool has no AI. It builds skills in sequencing, logic and text code. Students see how blocks turn into C++.

## Privacy and safety
The tool works in the browser and needs the internet at all times. Accounts are optional, and a teacher adds student accounts. The page describes no data collection and links only to a general university privacy policy. The official page is an archived copy. A teacher should check the privacy terms before adding student accounts.

## Ideas by subject
### computer_science
1. Drag blocks to move a virtual Linkbot and read the C++.
2. Change one block and find the changed line of code.
3. Use a loop to drive a square.
4. Add a condition that reacts to an obstacle.
5. Share an activity in the portal after teacher approval.

### math
1. Use RoboBlocky Math from the C-STEM curriculum to graph a robot's path.
2. Drive the robot a set distance and measure the result.
3. Code turns at set angles and name each angle.
4. Compare predicted and measured distances.
5. Write an equation for a straight drive.

### engineering
1. Test a virtual robot path and record how close it gets.
2. Plan a route and code it in steps.
3. Compare the virtual run with a real robot if the school has one.
4. Improve a program after a failed test.
5. Document the program for another group.
