## Overview
LaserWeb generates G-code from DXF, SVG, bitmap, JPG, and PNG files for laser cutters and CNC mills. It can also control a connected machine. It supports Grbl, Smoothieware, and Marlin firmware. The server part can run on a Raspberry Pi, and a hosted demo works without machine communication.

## Benefits for students
- Students turn a drawing file into machine instructions.
- Students can try the hosted demo with no machine.
- Students see the path a tool will follow.

## Benefits for teachers
- The tool accepts common file types.
- Teachers can use the demo to teach before a machine is ready.
- A forum post describes new users failing to get USB detected. Teachers should plan setup time.

## Benefits for schools
- The software is free. A laser or CNC machine is a separate cost.
- It runs on Windows, macOS, and Linux.
- Laser and CNC use needs safety approval.

## Getting started
- [ ] Install LaserWeb from the GitHub releases page, or run the server on a Raspberry Pi.
- [ ] Ask IT and your safety lead for approval.
- [ ] Try the hosted demo first.
- [ ] Open an SVG file and view the toolpath.
- [ ] Connect the machine and check that the USB port is detected.
- [ ] Test on scrap material with an adult present.
- [ ] Save job files in a school folder.

## Where is the AI?
LaserWeb has no AI. It turns files into toolpaths by fixed rules. Students build sequencing and design skills as they plan how a machine will cut a shape.

## Privacy and safety
No account is described, and the internet is used for setup. No privacy statement was found. Local operation is inferred from the install based design, and the hosted demo's data handling was not checked. A laser or CNC machine needs adult supervision and safety gear. A teacher should get safety approval before any student use.
