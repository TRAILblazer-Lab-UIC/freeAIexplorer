## Overview
Ozobot Evo is a pocket-sized, screen-free robot for PreK-5. Students code it with Color Code markers on paper or with Ozobot Blockly over Bluetooth. Ozobot Ari is a newer touchscreen robot for grades 3-8 with Python and an AI block that uses a large language model. Bit is the original Ozobot, and Ozobot now calls remaining units legacy Bit robots.

## Benefits for students
- Young students code with markers and paper and need no device.
- Older students move to Blockly and Python.
- Students see their code run on a real robot.

## Benefits for teachers
- The free Ozobot Classroom has about 700 lessons.
- Students need no accounts.
- Ozobot sells a K-2 Math Fluency classroom kit built for Evo.

## Benefits for schools
- Evo entry kits cost 175 USD. A 6-bot classroom kit costs 999 USD and an 18-bot kit costs 2990 USD.
- Ari entry costs 250 USD. The store page showed every product as sold out on the access date.
- Evo needs Bluetooth 4.2 or newer and Ari needs Wi-Fi.

## Getting started
- [ ] Find Ozobot Evo on the Ozobot store and check stock.
- [ ] Unbox and charge the robot.
- [ ] Calibrate the robot on the surface.
- [ ] Draw Color Codes with markers on white paper.
- [ ] Or open OzoBlockly and pair over Bluetooth.
- [ ] Create a free teacher account in Ozobot Classroom.
- [ ] Calibrate again as the surface or lighting changes.

## Where is the AI?
AI is optional. Only Ari has an AI block that uses a large language model. The vendor does not say where it runs. Evo and Bit have no AI, but students build sequencing and logic skills with Color Codes and blocks.

## Privacy and safety
Students need no accounts, and Evo works with no internet. The privacy policy lists name, email, address, birthday, and IP address collected at registration, purchase, or site use. For children under 13 it says the only data collected is a parent email, and it also says it collects nothing from them. The policy does not mention FERPA, and the website uses Google advertising cookies. The research did not read the separate AI privacy policy or the Evo app data practices. A teacher should read the policy and review the Ari AI block before student use.

## Ideas by subject
### computer_science
1. Draw a Color Code path on paper and predict what Evo will do.
2. Use OzoBlockly to make Evo follow a line and change color.
3. Add a loop to repeat a pattern.
4. Debug a Color Code that sends the robot the wrong way.
5. Trade programs with a partner and explain each step.

### math
1. Use the K-2 Math Fluency kit to practice number facts on a robot path.
2. Draw a line of set length and check how long Evo takes.
3. Build a path that makes a square and count the turns.
4. Compare two routes and tell which is shorter.
5. Skip count along a track with marked stops.
