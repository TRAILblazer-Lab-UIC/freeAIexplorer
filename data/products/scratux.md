## Overview
Scratux provides free open source Linux binaries of Scratch Desktop, formerly the Scratch Offline editor. Packages exist for Debian and Ubuntu, Raspbian, Arch, Fedora, Alpine, AppImage, and Snap. Students use the Scratch block editor on a computer without a browser. It is unofficial and licensed BSD-3-Clause.

## Benefits for students
- Students use the familiar Scratch block editor.
- Students can work offline after the install.
- Students run Scratch on Linux computers.

## Benefits for teachers
- Teachers get a Scratch editor for Linux classrooms.
- The tool needs no account.
- The learning curve matches Scratch itself.

## Benefits for schools
- The software is free and open source.
- Student work stays on the device.
- IT must install it and may need to review its unofficial status.

## Getting started
- [ ] Find the Scratux project site and choose a package for your Linux distribution.
- [ ] Ask IT to review the unofficial status of the project.
- [ ] Download the package or run the fetch and build scripts.
- [ ] Install it on one test computer.
- [ ] Note that the README fetches version 3.10.2 while the site lists 3.29.1.
- [ ] Open a Scratch project and save it to check that it works.
- [ ] Consider Raspberry Pi packaging for Scratch Desktop on Raspberry Pi OS.

## Where is the AI?
Scratux has no AI. It packages a block editor for Linux computers. Students build sequencing and logic skills with Scratch blocks. They learn to plan the order of steps in a program.

## Privacy and safety
No account is needed, and the internet is used at setup. The app is a local build of Scratch Desktop, and projects stay on the device. The research found no privacy policy. It did not check which extensions use the network. A teacher should ask IT to confirm the package source before installing it. A teacher should also keep online extensions off for students.
