## Overview
This is a free online course listed on AI4K12. It introduces probability and expected reward and then the Q-learning algorithm. Students apply it to solving mazes and playing tic-tac-toe. It runs as a Jupyter notebook in the browser and targets high school students with basic coding knowledge and math through Algebra 2.

## Benefits for students
- Students see how a program learns by trial and reward.
- Students use real Python in a notebook.
- Students apply math ideas to a working AI.

## Benefits for teachers
- The course is described as light on Python.
- It uses two clear examples, a maze and a game.
- It is listed by AI4K12.

## Benefits for schools
- The course is free.
- It runs in a browser with no install.
- The listing points to loislab.org, and the setup details are not confirmed.

## Ideas by subject
### computer_science
1. Run the maze example and watch the agent learn the path.
2. Change the reward for the goal and see what happens.
3. Train the program to play tic-tac-toe against itself.
4. Describe in your own words what a Q value stores.
5. Add a wall to the maze and test the program again.

### math
1. Compute the expected reward of a simple game with two outcomes.
2. Compare probabilities for two choices and pick the better one.
3. Track how the reward changes over many trials.
4. Predict which path in the maze earns the most reward.
5. Make a chart of the program's scores over time.
