## Overview
Phaser is a free open source 2D game framework for HTML5 games. Games run in desktop and mobile browsers. Students write JavaScript. The project lists over 700 tutorials, over 2,000 code examples, and a free book.

## Benefits for students
- Students make real games that run in a browser.
- Students practice JavaScript in a project they care about.
- Students can learn from a very large library of examples.

## Benefits for teachers
- Endless Studios lists Phaser as a natural fit for web development courses where students already know some JavaScript.
- The examples give teachers many starting points.
- Phaser is a framework for experienced coders. It needs teacher skill.

## Benefits for schools
- The software is free and open source.
- Games run in any modern browser, including on Chromebooks.
- It needs a code editor and a teacher or IT person to set it up.

## Getting started
- [ ] Find Phaser on its official site and read the README.
- [ ] Check that students already know some JavaScript.
- [ ] Choose a setup. You can use npm, the project generator, or a CDN such as jsDelivr.
- [ ] Ask IT to approve a code editor and Node.js for the npm route.
- [ ] Build one example game yourself first.
- [ ] Version 4.2.1 is current per the README. Use matching examples.
- [ ] Give students a simple starter project.

## Where is the AI?
The vendor does not describe any AI in Phaser. The framework runs games in the browser using Canvas and WebGL. Students build logic and sequencing skills as they code how a game responds to a player.

## Privacy and safety
No account is needed. The framework runs in the browser, and the repository does not mention telemetry. The internet is used for setup and for loading from a CDN if you choose that route. The research could not read the phaser.io site. Its policy was not reviewed. Student games stay on the device until students publish them. A teacher should check where students publish their games before they share them.
