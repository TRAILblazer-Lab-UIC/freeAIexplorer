## Overview
Quest, now called Quest Viva, is a platform for creating text adventure games and interactive fiction. No programming is required, and a scripting language is available for more advanced logic. It runs as a desktop app for Windows, macOS, and Linux and as a browser web app. TeachersFirst lists it for grades 5-12.

## Benefits for students
- Students write stories that readers can play.
- Students add images, sounds, and embedded video.
- Students can build games with no code.

## Benefits for teachers
- TeachersFirst lists it as a way to create interactive fiction.
- Teachers can use it for English writing projects.
- The scripting language lets advanced students add logic.

## Benefits for schools
- The tool is free.
- It runs in a browser or as a desktop app with no account.
- Finished games can be hosted on any website.

## Getting started
- [ ] Open the web app at play.questviva.com or download the app from questviva.com.
- [ ] Try the web app on a Chromebook. Use there is likely but not tested.
- [ ] Build a short test game with two rooms.
- [ ] Add an object and a simple choice.
- [ ] Preview the public games before sharing them, as TeachersFirst advises.
- [ ] Plan how students will save and share their games.
- [ ] Try the scripting language with an advanced group.

## Where is the AI?
Quest has no AI. It builds an AI-related skill, which is logic. Students design branches where each choice leads to a new result. That practice teaches how a program follows rules.

## Privacy and safety
No account is needed for the desktop app, and the internet is used at setup. Games stay on the device unless students host them. The research did not read the privacy policy of the browser web app. The older online editing and sharing site offered accounts, and the research could not confirm that it still exists. Public games on that site are made by the general public. A teacher should preview any public game before students play it.

## Ideas by subject
### ela
1. Use TeachersFirst as a guide and write an interactive story with three endings.
2. Plan the rooms and choices on paper before building them.
3. Write vivid descriptions for each room.
4. Trade games with a partner and write feedback on the story.
5. Rewrite a scene from a class book as an adventure.

### theater_media
1. Add images and sounds that set the mood of each room.
2. Embed a short video clip that plays at a key moment.
3. Design the opening scene to hook a player.
4. Test a game with a classmate and note where players get lost.
5. Host a finished game and present it at a class showcase.
