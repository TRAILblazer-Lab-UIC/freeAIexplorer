## Overview
Code & Go Robot Mouse is a screen-free programmable toy mouse named Colby. Children plan a path with coding cards. They then press the arrow buttons on the mouse's back to program up to 40 steps and press GO. The set is made for ages 4 to 9.

## Benefits for students
- Students plan a path and see it run.
- Students match coding cards to the buttons by color.
- Students practice sequencing with no screen.

## Benefits for teachers
- Setup takes minutes with batteries and a flat grid.
- The set includes 30 coding cards, 22 maze walls and 10 double-sided maze cards.
- A reviewer ran it as a kindergarten group activity.

## Benefits for schools
- The activity set costs about 55 to 70 USD, but this was not verified on a vendor page.
- APH publishes tactile booklets and a braille-ready guide for visually impaired learners.
- No account, internet or app is needed.

## Getting started
- [ ] Buy the activity set from the maker or a seller.
- [ ] Insert 3 AAA batteries.
- [ ] Lay out the grid pieces and maze walls on a flat surface.
- [ ] Press CLEAR before each new sequence.
- [ ] Show the class how a card matches a button.
- [ ] Let pairs plan a path to the cheese.
- [ ] Download the APH guide for accessible materials.

## Where is the AI?
Code & Go Robot Mouse has no AI. The mouse follows exactly the steps that children enter. Students build skills in sequencing, planning and debugging.

## Privacy and safety
The mouse is controlled only through its onboard buttons, and the APH guide mentions no companion app. It needs no account and no internet, and it collects no student data. A teacher should test each mouse before class. One 2021 review reported a mouse that did not work correctly.

1. Plan a path to the cheese with coding cards and then program it.

3. Fix a sequence that bumps into a wall and explain the change.

5. Build a maze for a partner and challenge them to solve it.

### special_ed
1. Use the tactile booklets to plan a route by touch.
2. Read the braille-ready guide and follow its first activity.
3. Match raised coding cards to buttons on the mouse.
4. Work with a partner to build a path and take turns entering steps.
5. Describe the route aloud as the mouse follows it.
