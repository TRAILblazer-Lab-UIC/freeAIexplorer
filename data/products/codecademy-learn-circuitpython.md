## Overview
This Codecademy course teaches CircuitPython with the Circuit Playground Express board. It was made with Adafruit. Part 1 covers setup and NeoPixel lights with a Bike Light project. Part 2 covers sensors, audio, and capacitive touch, with 808 Drum Machine and Plant Care projects.

## Benefits for students
- Students program a real board and see lights and sounds respond.
- Students learn from browser lessons with quizzes.
- Students finish three projects.

## Benefits for teachers
- Codecademy lists the course at about 2 hours and a beginner level.
- The lessons guide students step by step.
- A GitHub repo for the course exists.

## Benefits for schools
- Codecademy lists free and paid plans, and the notes could not confirm which one covers this course.
- Each student or group needs a Circuit Playground Express and a USB cable.
- Accounts are needed, and data goes to Codecademy.

## Getting started
- [ ] Find the Learn CircuitPython course on Codecademy.

- [ ] Create a Codecademy account.

- [ ] Build the Bike Light project.

## Where is the AI?
This course has no AI. It builds skills in sensors and logic. Students read light, sound, and touch inputs and write code that responds.

## Privacy and safety
Students need Codecademy accounts, and the account data and progress go to Codecademy. The internet is needed at all times, and the code runs on the board once copied over. The research did not review the privacy policy or the student account age policy. A teacher should check the Codecademy age rules and privacy policy before students sign up.

## Ideas by subject
### computer_science
1. Write a program that lights NeoPixels in a pattern.
2. Use a loop to make the lights chase around the board.
3. Read a sensor value and print it.
4. Change a variable to speed up or slow down the lights.
5. Explain each line of the Bike Light code to a partner.

### engineering
1. Build the Bike Light and decide where it would go on a bike.
2. Test the board's light sensor in a dark room.
3. Create the 808 Drum Machine and improve one sound.
4. Use capacitive touch to trigger an action.
5. Build the Plant Care project and decide what it should report.
