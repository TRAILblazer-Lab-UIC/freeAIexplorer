## Overview
ArduBlock is a block based programming tool for Arduino. Its blocks follow the Arduino Language Reference and lead students toward C or C++. It is a small Java file that runs as a tool in the Arduino IDE. The tool is largely unmaintained.

## Benefits for students
- Students build Arduino programs from blocks.
- Students see the generated code and move toward text.
- Students program real boards.

## Benefits for teachers
- The block names match the Arduino reference.
- The tool needs no accounts.
- It builds basics before C or C++.

## Benefits for schools
- The tool is free.
- The SourceForge edition was last updated on 2016-11-25.
- A 2019 reviewer could not install it on Windows 10. IT should test first.

## Getting started
- [ ] Install the Arduino IDE.
- [ ] Download the ardublock-all.jar file.
- [ ] Ask IT to copy the jar into the IDE tools folder.
- [ ] Test the install on one computer before a lesson.
- [ ] Connect an Arduino board by USB.
- [ ] Build a blink program from blocks and upload it.
- [ ] Consider ArduBlockly, a separate Apache 2.0 project.

## Where is the AI?
This tool has no AI. It turns blocks into code by fixed rules. Students build sequencing and logic skills as they connect blocks to control a board.

## Privacy and safety
ArduBlock runs on the computer and needs no account. The research found no student data collection but reviewed no privacy policy. The internet is needed at setup. A teacher should test the install on current computers. Reviewers report trouble on current Windows.

## Ideas by subject
### computer_science
1. Build a blink program from blocks and view the generated code.
2. Add a button block that changes an LED.
3. Compare the block program with the Arduino code it makes.
4. Use a loop block to make a pattern.
5. Rewrite a block program in text code.

### engineering

2. Add a sensor and read its value.
3. Build a simple alarm with a buzzer.
4. Test a circuit and note what happens.
