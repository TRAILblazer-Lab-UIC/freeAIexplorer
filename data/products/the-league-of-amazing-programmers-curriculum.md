## Overview
The LEAGUE is a San Diego nonprofit that teaches Python and Java to students in grades 5 to 12. Its open curriculum site lists Python courses, a Java sequence from Level 0 to Level 5, micro:bit and motor courses, and a GitHub Pages portfolio course. Python Introduction runs in the browser on Trinket and states grades 6 to 8. It uses turtle graphics.

## Benefits for students
- Students learn real Python and Java.
- Students draw with turtle graphics in the first course.
- Students can later try micro:bit and motor courses.

## Benefits for teachers
- The courses are free to read.
- Python Introduction needs only a browser.
- Courses in development include robots and MakeCode Arcade.

## Benefits for schools
- The curriculum is free.
- The micro:bit and motor courses need hardware.
- No installation is needed for the Python Introduction course.

## Getting started
- [ ] Find the LEAGUE curriculum site.
- [ ] Open the Python Introduction course in a browser.
- [ ] Try the first lesson yourself on Trinket.
- [ ] Pick the course that fits your class from the list.
- [ ] Plan micro:bit boards if you want a hardware course.
- [ ] Check what the site says about accounts before students start.
- [ ] Look at Java Level 0 for advanced students.

## Where is the AI?
The curriculum has no AI. Students write Python and Java and the computer runs their code exactly as written. They build skills in logic and in reading and fixing code.

## Privacy and safety
The curriculum site needs no account and the courses need the internet at all times. Data flow depends on the tool in each lesson, such as Trinket, MakeCode, or Tinkercad. The research did not review those tools. It did not check student accounts on Trinket. The materials do not state what data the courses collect or where student work goes. Check how Trinket saves student work before class.
