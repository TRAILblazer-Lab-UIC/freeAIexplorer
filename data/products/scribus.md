## Overview
Scribus is free open source desktop publishing software for page layout and typesetting. Users build newsletters, flyers, forms, and reports from text and image frames. It exports print-ready and interactive PDFs. It runs on Windows, macOS, and Linux.

## Benefits for students
- Students lay out real pages with text and image frames.
- Students export PDFs with forms and hyperlinks.
- Students practice design choices such as color and layout.

## Benefits for teachers
- The software is easy for students to start using.
- It suits newsletters, flyers, and class reports.
- Some reviewers call the interface dated.

## Benefits for schools
- The software is free and cross platform.
- It suits school labs with desktop computers.
- IT approval may be needed on managed devices.

## Getting started
- [ ] Download the installer for Windows, macOS, or Linux from the Scribus site.
- [ ] Ask IT to approve the install on managed devices.
- [ ] Install Scribus on one test computer.
- [ ] Create a one-page flyer with a text frame and an image frame.
- [ ] Export the flyer as a PDF.
- [ ] Note that Scribus cannot open InDesign or Quark files.

## Where is the AI?
Scribus has no AI. It is a layout tool. Students build skills in organizing information and spotting patterns in page design.

## Privacy and safety
No account is needed, and the internet is used to download. Scribus is a local desktop application and files stay on the computer. The research found no telemetry in the sources read but did not verify this in the code. It read no privacy policy. A teacher should ask IT to review the install and check that students save work to a folder that the school backs up.
