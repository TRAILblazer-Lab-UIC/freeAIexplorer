## Overview
This lesson explains how a computer sees. It covers image recognition through feature extraction, object detection, and classification. It mixes unplugged and online steps. The page lists the Year 3-4 band and a CC BY 4.0 license.

- Students describe features and learn that computers use features to sort images.
- Students see an image as pixels in the CS Field Guide pixel viewer.
- Students test AutoDraw, Quick, Draw!, and Google Vision AI labels.

The AI is image recognition, which includes feature extraction, object detection, and classification. The online tools run in vendors' clouds, and the paper tasks run in the classroom. Students predict what a tool will say, test it, and compare the result with their own idea.

## Ideas by subject
### computer_science
1. Describe an animal using only features and ask a partner to guess it.
2. Play Quick, Draw! and note when the AI guesses right.
3. Open an image in the pixel viewer and describe what the computer sees.
4. Upload a sample image to Google Vision AI and read the labels and confidence.
5. Explain how a computer could sort animals by features.

### science
1. Sort animal cards by features and record the groups.
2. Run the feature-based classification experiment and write down the results.
3. Compare a human classification with the one the class built.
4. Test which features separate two similar animals.
5. Explain why scientists use features to classify living things.

### math
1. Zoom into an image and count the pixels in a small area.
2. Compare image sizes by pixel count.
3. Make a table of animal features and tally the matches.
4. Calculate the percentage of cards sorted correctly.
5. Explain why a higher confidence number does not always mean a right answer.
