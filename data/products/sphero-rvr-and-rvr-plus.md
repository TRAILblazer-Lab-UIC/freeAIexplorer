## Overview
RVR+ is a programmable rover for grades 6 to 12. It has a color sensor, light sensor, IR, gyroscope, and accelerometer. A 4-pin UART expansion port connects third-party hardware such as a Raspberry Pi or micro:bit. Students start with blocks in the Sphero Edu app and can move to JavaScript, Python, or the public Sphero SDK.

## Benefits for students
- Students start with blocks and grow into JavaScript and Python.
- Students drive a rover with real sensors.
- Students can add a Raspberry Pi or micro:bit for bigger projects.

## Benefits for teachers
- The Sphero Edu web app runs in a browser with no download.
- Teachers can move students up from blocks as skills grow.
- The rover has a removable rechargeable battery with about 2 hours of play.

## Benefits for schools
- RVR+ lists at 339 USD each.
- Class packs list at 4068 USD for 12 robots and 6102 USD for 18 robots.
- Accounts are optional.

## Getting started
- [ ] Find RVR+ on the Sphero site.
- [ ] Charge the robot.
- [ ] Open the Sphero Edu web app or install the app.
- [ ] Pair the rover over Bluetooth.
- [ ] Try a first block program.
- [ ] Skip accounts at first to limit what Sphero stores. The app still sends usage data for analytics.
- [ ] Check Chromebook support on your devices before a class set.

## Where is the AI?
RVR+ has no AI. The rover follows the code students write and reads its sensors. Students build sequencing and sensor data skills.

## Privacy and safety
Accounts are optional, and users can program and finish lessons without logging in. Account data goes to Sphero only if an account is created. Sphero help says abstracted usage data may go to Amplitude, Google, Apple and Amazon for analytics, and the robots store no personal information. Children 13 or younger need a parent, guardian or educator to set up an account. The help page does not mention FERPA. A teacher should decide whether to create accounts and should read the privacy page first.

## Ideas by subject
### computer_science
1. Build a block program to drive the rover through a course.
2. Rewrite the same program in JavaScript or Python.
3. Use a loop to repeat a movement pattern.
4. Write code that reacts to a color sensor reading.
5. Debug a program that sends the rover off course.

### engineering
1. Connect a Raspberry Pi or micro:bit through the expansion port and test it.
2. Design a mount that carries a small load on the rover.
3. Test how the battery holds up over a set of runs.
4. Plan a course and measure how well the rover finishes it.
5. Compare two designs for the same task.

### science
1. Use the light sensor to measure brightness along a path.
2. Use the color sensor to sort colored objects on the floor.
3. Record accelerometer readings during a run and graph them.
4. Predict how far the rover rolls at a set speed and test it.
5. Test how a surface changes the rover's speed.
