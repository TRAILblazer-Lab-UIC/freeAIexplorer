## Overview
Code Studio is the Code.org platform for free computer science courses and Hour of Code activities for K-12. It offers tools such as App Lab, Game Lab, and Web Lab. It also has activities including Dance Party, Minecraft, AI for Oceans, and Flappy Code. Students can try activities without signing in.

## Benefits for students
- Students can start an Hour of Code activity with no sign-in.
- Students can code in blocks and text across many grade levels.
- Students try AI activities such as AI for Oceans.

## Benefits for teachers
- Teachers create sections and add students by rostering, picture login, or secret words.
- Sign-in options include Google, Microsoft, Facebook, Clever, and ClassLink.
- Teacher tools show student progress.

## Benefits for schools
- The platform is free and the code is open under a custom license.
- It runs in a browser on Chromebooks and computers.
- The materials do not state a minimum age. Check how younger students will sign in.

## Getting started
- [ ] Open studio.code.org and try an Hour of Code activity.
- [ ] Create a teacher account.
- [ ] Ask IT to review the CodeAI privacy policy.
- [ ] Create a section for your class.
- [ ] Add students by rostering, picture login, or secret words.
- [ ] Assign a course or activity.
- [ ] Check which activities use the AI tutor before students start.

## Where is the AI?
The platform has AI literacy activities such as AI for Oceans and an AI tutor in some programming units. Free text can go to outside language model providers. The vendor does not name them in the policy. Students use the tutor for hints and then write their own code.

## Privacy and safety
Accounts are optional for Hour of Code activities and are needed for sections. The vendor collects display name, username, age, US state, progress, a one way email hash, and IP address. It also collects code, projects, and free text entries, and AI tutor queries may be processed and stored. The 2026 policy refers to CodeAI and says the nonprofit is not subject to COPPA but takes extra steps. It says it may use third party language model providers without naming them. The research did not confirm a Student Privacy Pledge. A teacher should review the policy with the school and decide whether students sign in.

## Ideas by subject
### computer_science
1. Finish an Hour of Code activity and explain the main idea to a partner.
2. Play AI for Oceans and describe how the training data changed the result.
3. Build a small game in Game Lab.
4. Make a web page in Web Lab.
5. Use the AI Foundations curriculum to try one AI lesson.

### math
1. Use a coding activity to draw shapes and find the angles.
2. Change a number in a program and see how the picture changes.
3. Use variables to count points in a game and check the total.
4. Predict the output of a loop and then run it to check.
5. Graph the scores in a game and describe the pattern.

### music
1. Make a loop in Music Lab and play it back.
2. Add a second sound and change its timing.
3. Change the tempo and describe the feeling of the new version.
4. Share a track with a partner and ask for one change.
5. Explain how code repeats a beat.
