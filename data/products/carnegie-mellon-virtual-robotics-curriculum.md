## Overview
This is a set of browser-based robotics courses with a simulated robot. The 2021 announcement describes Introduction to Programming with Virtual LEGO EV3, which has five units and over 70 virtual environments. The index page also lists courses for a generic virtual robot and virtual SPIKE Prime. Students use block coding in grades 6 through 12.

## Benefits for students
- Students code a simulated robot with no physical kit.
- Students use a sensor dashboard to find problems in their code.
- Students move from Getting Started to Search and Rescue.

## Benefits for teachers
- Progress is tracked and code is saved automatically on CS2N.
- Teachers assign seats through CS2N groups.
- The course can run alone or alongside a physical EV3.

## Benefits for schools
- It works on Chromebooks, Windows PCs and Macs with no install.
- The 2021 announcement listed 9 USD for one license on sale and 12 USD regular. Prices may have changed.
- Licenses are non-transferable per-learner seats. LEGO has retired the EV3 platform.

## Where is the AI?
The vendor does not describe any AI in these courses. Students write block programs for a simulated robot that runs in the browser. Students build skills in sequencing, sensors and logic.

## Privacy and safety
Each student needs a CS2N account, and the internet is needed throughout. CS2N stores the name, email, username, account settings, course activity, saved code, and progress. The policy says it does not sell or rent personal information. It says users under 13 may provide information only with consent from a parent, guardian, school, district, or teacher where the law allows. That is a data rule and not a minimum age. Google Analytics runs only after a user accepts it. The policy does not name COPPA and does not say where data is stored. A teacher should read the CS2N privacy policy before assigning seats.

## Ideas by subject
### computer_science
1. Complete the Getting Started unit and describe what each block does.
2. Use the sensor dashboard to find why a program fails.
3. Write a program that stops the robot at a wall.
4. Compare two programs for the same task and pick the shorter one.
5. Explain a finished program to a partner using the correct terms.

### engineering
1. Solve a Search and Rescue challenge in the virtual environment.
2. Test a robot plan in two environments and record the results.
3. Plan a robot task on paper before coding it.
4. Redesign a program after a failed run and describe the change.
5. Share a best solution with the class and explain the steps.
