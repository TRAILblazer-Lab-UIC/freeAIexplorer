## Overview
IMLD is an educational tool for learning machine learning through pictures of data, decision surfaces, and algorithm results. Users can make, import, and export datasets as CSV files. They train and test algorithms and watch the steps. The tool began as a Java applet for graduate students. It suits college and advanced older students.

## Benefits for students
- Students see how an algorithm splits data into groups.
- Students create their own datasets and test them.
- Students watch the steps of an algorithm one at a time.

## Benefits for teachers
- A user guide from Temple University authors covers the tool.
- The guide lists several kinds of algorithms, including neural network and gradient boosting.
- A web version and a Python version are both offered.

## Benefits for schools
- The download is free and the code is open source.
- A standalone Python 3 version runs on Windows, Mac, and Linux.
- IT help is likely needed to install it.

## Getting started
- [ ] Find the IMLD project page at the ISIP site.
- [ ] Ask IT to approve the download of the imld.tar.gz package.
- [ ] Install Python 3 on one computer.
- [ ] Run the package and open the window.
- [ ] Try the web version from the Run menu on the project page.
- [ ] Generate a small dataset and train one algorithm.
- [ ] Export a CSV file and open it in a spreadsheet.

## Where is the AI?
The AI is a set of classic pattern recognition algorithms. The vendor describes both a local version and a web version that uses a client and server. Students train an algorithm on one dataset and test it on another. They can then change the data and compare how each algorithm responds.

## Privacy and safety
No account is needed for the standalone version, and the internet is used for setup. The web version is a client and server application. Data typed or loaded there is handled by the project's server, and its data handling and retention are not documented. No privacy policy was found. A teacher should use the standalone version or check the web version before students upload any data.

## Ideas by subject
### computer_science
1. Generate two groups of points and train one algorithm on them.
2. Compare a simple algorithm with a neural network on the same data.
3. Watch the steps of an algorithm and describe each one.
4. Test the trained model on separate Eval data and record the errors.
5. Export a dataset as a CSV and explain each column.

### math
1. Plot two groups of points and predict where a boundary line will fall.
2. Compare a straight boundary with a curved one.
3. Add noise to a dataset and measure the change in errors.
4. Describe the shape of each decision surface in words.
5. Count the errors on the Eval data and compute the percent correct.
