## Overview
Coddy Arduino Playground is a simulated Arduino Uno that runs in a web browser. Students write Arduino code and test it with simulated parts. Search snippets mention a distance sensor, a serial monitor, and libraries such as Servo and LiquidCrystal. Details come from snippets only. The Coddy pages could not be read directly.

## Benefits for students
- Students can try Arduino code without a physical board.
- Students can read sensor values on the serial monitor.
- Students can test servo and display code in a safe space.

## Benefits for teachers
- Teachers can demonstrate Arduino ideas with only a browser.
- A simulator avoids lost parts and broken wires.
- Teachers can pair it with a separate course, which Coddy sells at a price the notes did not find.

## Benefits for schools
- The playground is listed as free and needs no install.
- The listing says no account is needed.
- Coddy says it is not affiliated with Arduino.

2. Print the value of a variable to the serial monitor.
3. Change a delay and describe how the blink changes.
4. Use a loop to count from one to ten on the serial monitor.
5. Debug a sketch that has a missing semicolon.
