## Overview
Artie 3000 is a drawing robot that holds a marker and draws the paths students program. It has its own built-in Wi-Fi server. Students join the robot's network and open a link in a browser to write block code. The kit includes activity cards, and retailers list it for ages 7 and up.

## Benefits for students
- Students see their code turn into a real drawing on paper.
- Students follow activity cards that give them a first project.
- Students learn by testing a path and adjusting the blocks.

## Benefits for teachers
- Setup takes minutes after the batteries go in.
- The coding page opens in a browser. There is no separate app to install.
- The activity cards give teachers a ready starting point.

## Benefits for schools
- Retail listings showed prices of about 54 to 69 USD, and prices vary by retailer.
- The robot needs 4 AA batteries and markers.
- The robot needs no internet connection.

## Getting started
- [ ] Buy Artie 3000 from a retailer or from Educational Insights.
- [ ] Insert 4 AA batteries and load a marker.
- [ ] Power on the robot.
- [ ] Join the robot's Wi-Fi network from a computer or tablet.
- [ ] Open the provided link in a browser.
- [ ] Follow the first activity card.
- [ ] Test with the devices your students use. A reviewer tested only an iPhone.

## Where is the AI?
Artie 3000 has no AI. The robot draws exactly what the blocks tell it to draw. Students build the skill of sequencing, which means putting commands in order to make a shape.

## Privacy and safety
The robot makes its own Wi-Fi network and needs no internet connection. The materials do not say whether any account is needed or what data is collected. A search snippet says Mozilla Privacy Not Included rated it somewhat creepy in November 2023, and the research could not read that page. The research read no vendor privacy policy because the site returned an error. A teacher should check the Mozilla review and the vendor policy. A teacher should also test the coding page on student devices.

## Ideas by subject
### computer_science
1. Write block code that draws a square and follow the first activity card.
2. Change one number in a program and predict how the drawing will change.
3. Use a repeat block to draw a shape with equal sides.
4. Debug a program that draws the wrong shape.
5. Trade programs with a partner and run each other's code.

### visual_arts
1. Program Artie to draw a simple pattern and add color with a marker change.
2. Design a border for a poster and plan the path before coding.
3. Compare a hand drawn line with a robot drawn line.
4. Make a drawing from repeated shapes.
5. Display the robot drawings in a class gallery with a short note about each program.
