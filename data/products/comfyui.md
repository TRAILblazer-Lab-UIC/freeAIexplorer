## Overview
ComfyUI is an open source node based interface for diffusion models that generate images, video, and audio. Users connect nodes into workflows that can be saved as JSON. It runs on the local machine. The README says it can run large open models on as little as 4 GB of VRAM. It was released in January 2023 and is now maintained by Comfy Org.

## Benefits for students
- Students see each step of a diffusion pipeline as a node.
- Students can build and save their own workflows.
- Students can make images, video, and audio.

## Benefits for teachers
- A desktop app exists for Windows and macOS.
- A portable Windows build is also offered.
- Community custom nodes add more features.

## Benefits for schools
- The software is free.
- A capable GPU is the main cost and model files are large.
- IT approval is needed for downloads and custom nodes.

## Getting started
- [ ] Find ComfyUI on its official site or public code page.
- [ ] Ask IT to approve the install on a teacher managed computer.
- [ ] Install the desktop app or the portable build.
- [ ] Download model files while online.
- [ ] Review any custom nodes before installing them.
- [ ] Load a simple workflow and make one image.
- [ ] Go offline and test again.

## Where is the AI?
The AI is a set of diffusion models that make images, video, and audio. They run on the local computer and use its graphics card. Students connect nodes, write prompts, and view the results. They change the graph to see how each part shapes the output.

## Privacy and safety
No account is needed, and the internet is used for setup. The README says the software runs fully offline, and prompts and outputs stay on the device. Optional paid partner API nodes call outside services and can be turned off. The README has no telemetry statement. Custom nodes are third party code, and Wikipedia reports that a malicious extension was found in June 2024. The tool is not designed for schools, and image models can produce inappropriate content. A teacher should use a teacher managed machine, review prompts, and ask IT to approve any custom nodes.
