## Overview
iNZight is a free data exploration platform from the University of Auckland. It was first designed for high school students. Users pick variables, and the tool chooses suitable graphs, summaries, and tests. Students explore real data and read what the pictures show.

## Benefits for students
- Students make graphs with point and click and no coding.
- Students see the tool choose a graph that suits the type of data.
- Students can open the R script behind each analysis and begin to read code.

## Benefits for teachers
- Teachers can focus lessons on questions and meaning, with few menus to learn.
- The tool covers multivariate data, time series, and models for older students.
- Each analysis produces an editable R script that teachers can use as an extension.

## Benefits for schools
- The software is free and the code is open.
- A Windows desktop app and a browser version called Lite are both offered.
- The vendor lists no IT involvement.

## Getting started
- [ ] Go to inzight.nz and download the Windows installer, or open lite.inzight.nz in a browser.
- [ ] Ask IT to run the installer on a test machine.
- [ ] Load a small data file with a few columns.
- [ ] Pick one variable and look at the graph the tool chooses.
- [ ] Pick a second variable and compare the new graph.
- [ ] Open the R script for one analysis and read it together.
- [ ] Remove any student data from shared machines when the lesson ends.

## Where is the AI?
iNZight has no AI. Its rules for choosing a graph are fixed and based on the type of each variable. Students build data skills by choosing variables, reading graphs, and checking what the summaries say.

## Privacy and safety
No account is needed. The desktop app runs locally and keeps files on the computer. Lite is a hosted web app, and the pages read did not say whether uploaded datasets are kept or sent to a server. No privacy policy was found. A teacher should use sample data and no student personal data in Lite.

## Ideas by subject
### math
1. Pick a survey data set and describe the shape of one numeric variable.
2. Compare two groups using a graph the tool chooses and write one sentence about the difference.
3. Explore two numeric variables and describe the pattern in a scatter plot.
4. Collect class data on a simple topic and load it into iNZight.
5. Read the R script from one analysis and explain what each line does.

### science
1. Load a data set from a science experiment and describe the main pattern.
2. Compare results from two groups and decide if the graph supports a claim.
3. Explore a time series, such as daily temperature, and describe the trend.
4. Change one variable at a time and note how the graph changes.
5. Write a short report with two graphs and a conclusion.
