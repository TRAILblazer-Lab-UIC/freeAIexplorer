## Overview
The TurboWarp Packager converts a Scratch project into a standalone HTML file or an app for Windows, macOS, or Linux. It suits middle and high school students who have finished a Scratch project and want to share it. Students load a project, choose an output, and download the result.

## Benefits for students
- Students can turn a finished Scratch project into a file that others open without Scratch.
- Students can share a game with family by sending one HTML file.
- Students see how a project becomes a real app.

## Benefits for teachers
- The tool is free and needs no account.
- The steps are short. Load a project, pick an output, and download.
- Teachers can package class projects for a showcase on lab computers.

## Benefits for schools
- The tool costs nothing and the code is open source.
- The tool runs in the browser or on the computer. The research did not confirm that files are never uploaded.
- No IT help is needed for the web version. The vendor updates it about monthly.

## Getting started
- [ ] Open the TurboWarp Packager in a web browser, or use TurboWarp Desktop under File, Package project.
- [ ] Visit the site once and let the large runtimes download. They are cached for later use.
- [ ] Load a Scratch project file.
- [ ] Choose an output such as an HTML file, a zip, or an app.
- [ ] Download the result and test it on a school computer.
- [ ] Download the standalone HTML version from GitHub releases for fully offline use.
- [ ] Read the licence note. Packaged output may include runtimes licensed separately.

## Where is the AI?
This tool has no AI. It packages projects with fixed rules. Students still build a useful skill. They practice sequencing and logic in the Scratch projects they package.

## Privacy and safety
The tool runs in the browser or on the computer and no account is needed. The shared TurboWarp policy says packager settings and cached downloads are stored in the browser. Packager Extras may contact servers to check for updates. The docs read do not state whether project files are uploaded. The discovery note says conversion happens in the browser. Creators of packaged projects must write their own privacy policy. Check the license terms of packaged output before students share apps outside school.
