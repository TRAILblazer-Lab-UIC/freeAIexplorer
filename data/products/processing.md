## Overview
Processing is a free open source graphics library and sketchbook for learning programming in a visual context. It uses a simplified form of Java. It runs on macOS, Windows, Linux, and Raspberry Pi. Students write short programs that draw shapes, animation, and interactive art.

## Benefits for students
- Students see a drawing from only a few lines of code.
- Students can add sound, video, and hardware through libraries.
- Students learn skills that carry to other languages.

## Benefits for teachers
- Wikipedia names Processing as designed for teaching visual programming to beginners.
- A large community shares examples.
- The text coding approach needs teacher practice.

## Benefits for schools
- The software is free and open source.
- It runs on the local computer.
- IT will likely need to approve the install. It does not run on Chromebooks without Linux support.

## Getting started
- [ ] Download Processing 4.5.7 from the official site.
- [ ] Ask IT to approve the install on Windows, Mac, Linux, or Raspberry Pi computers.
- [ ] Unzip or install the program.
- [ ] Open the sketchbook and press the run button on an example.
- [ ] Change a number and run again.
- [ ] Try the alternate modes such as Python if you want them.
- [ ] Save sketches in a class folder.

## Where is the AI?
The vendor does not describe any AI in Processing. It draws what students tell it to draw. They build sequencing and pattern spotting skills as they use loops and variables.

## Privacy and safety
No account is needed. The internet is used for setup and for adding libraries. The software runs locally and student sketches stay on the device. No privacy policy was read, and offline use is assumed from the desktop design. A teacher should check which libraries students add.

## Ideas by subject
### computer_science
1. Write a sketch that draws a circle, then add a loop to draw ten.
2. Use a variable to change the size of a shape.
3. Make a shape follow the mouse.
4. Fix a sketch that shows a blank window.
5. Explain a classmate's sketch line by line.

### visual_arts
1. Create a pattern with repeated shapes.
2. Make an interactive piece that changes color when you click.
3. Use random values to make a unique artwork each time.
4. Recreate a favorite artwork using only shapes.
5. Write a statement about how code shaped your art.
