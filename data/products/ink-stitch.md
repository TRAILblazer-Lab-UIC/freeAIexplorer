## Overview
Ink/Stitch is an open-source machine embroidery design platform built as an extension for Inkscape. Users draw or import vector art in Inkscape, set stitch parameters such as length, density, and fill type, and export a stitch file such as PES. The official site offers tutorials, sample files, a user manual, and a community forum. It suits high school students with access to an embroidery machine.

## Benefits for students
- Students turn their own drawings into stitched designs.
- Students learn how stitch length, density, and fill change the result.
- Students make a physical product from a digital file.

## Benefits for teachers
- Tutorials, sample files, and a user manual are available.
- A university eTextiles lab documents using it with a lab embroidery computer.
- A community forum is available for questions.

## Benefits for schools
- The software is free.
- An embroidery machine is a separate cost.
- IT must install Inkscape and the extension separately.

## Getting started
- [ ] Install Inkscape from inkscape.org.
- [ ] Install the Ink/Stitch extension separately from inkstitch.org.
- [ ] Ask IT to approve both installs.
- [ ] Note that macOS installs may need extra steps.
- [ ] Draw a simple shape and set stitch parameters.
- [ ] Export the file in the format the machine needs.
- [ ] Transfer the file to the embroidery machine, often by USB.

## Where is the AI?
Ink/Stitch has no AI. It builds design and process skills. Students plan a stitch path and test how settings change the result. It runs on the local computer.

## Privacy and safety
No account is needed, and the internet is used for setup. The software runs as a local extension, and the official site does not describe any account or data collection. No privacy policy or telemetry statement was found. This is not confirmed from a policy. A teacher should set safety rules for the embroidery machine. A teacher should also plan for large designs, which can take several minutes to convert.
