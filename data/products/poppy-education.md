## Overview
Poppy Education was a French programme of activities for the Poppy Ergo Jr, a low-cost 6-servo robot arm with 3D-printed parts. Poppy robots can be programmed with Snap!, Python or a REST API. Search results report more than 30 French lycees equipped with the Ergo Jr by 2018. The official domain poppy-education.org redirected to an unrelated page when fetched.

## Benefits for students
- Students build and program a robot arm.
- Students can use Snap! blocks or Python.
- Students work with an open design.

## Benefits for teachers
- A French programme of activities exists for the arm.
- Documentation and a forum are described.
- The arm uses open code and hardware.

## Benefits for schools
- Servos cost about 20 each per the wiki and a kit has six.
- Current prices were not found.
- Official materials could not be read. IT and teachers must plan the build.

## Getting started
- [ ] Look for the Poppy documentation and check which sites are still active.
- [ ] Build or buy an Ergo Jr arm.
- [ ] Gather six XL-320 servos and 3D-printed parts.
- [ ] Set up the controller board with the Poppy software.
- [ ] Connect to the arm and open Snap!.
- [ ] Try a first move.
- [ ] Read the documentation in French or English.

## Where is the AI?
The vendor does not describe any AI. Students build sequencing and logic skills as they program the arm. They also learn how servos turn code into motion.

## Privacy and safety
The materials do not state whether accounts or the internet are needed. They also do not state what data is collected. The official domain could not be read. A teacher should check which Poppy site is current and what terms apply.

## Ideas by subject
### computer_science
1. Use Snap! blocks to move the arm to three positions.
2. Write a short Python program for the same moves.
3. Use a loop to repeat a movement.
4. Compare the blocks and the Python code.
5. Record a move sequence and play it back.

### engineering
1. Assemble the six-servo arm and test each joint.
2. Study how 3D-printed parts hold the servos.
3. Test the reach of the arm and record it.
4. Improve a part and print a new one.
5. Document the build in English or French.
