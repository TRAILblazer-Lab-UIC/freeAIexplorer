## Overview
A PE teacher post describes a four level Pathways and Levels unit for K-2. Students follow printed pathway maps using locomotor skills and then draw and code their own maps. In the last level they draw a paper path for an Ozobot and perform the coded skills in a matching obstacle course. The post was written by Elizabeth Bolger in November 2022.

## Benefits for students
- Students learn coding ideas with their whole bodies.
- Students take turns as programmer and computer.
- Students improve a design after they test it.

## Benefits for teachers
- The unit fits into a PE class with little prep.
- The setup is printing maps and gathering gym equipment.
- The post is a teacher blog that is hosted by PHE America.

## Benefits for schools
- The lesson is free to read.
- The school needs Ozobot robots and common gym gear such as poly spots, cones, and hoops.
- No internet or accounts are needed.

## Getting started
- [ ] Find the post called Coding Pathways with Ozobots in PE on the PHE America site.
- [ ] Print the pathway maps.
- [ ] Gather poly spots, cones, and hoops.
- [ ] Charge the Ozobots.
- [ ] Set out markers for drawing paths.
- [ ] Start with students following straight, zigzag, and curved pathways.
- [ ] Move on to the programmer and computer pair roles.
- [ ] Finish with the Ozobot path and the matching obstacle course.

## Where is the AI?
This lesson has no AI. Students write paths and move like a robot following them. They build sequencing skills as they order each step of a path.

## Privacy and safety
The post names no apps or accounts, and no internet is needed. The Ozobot reads drawn lines and codes. The research did not check the post for other software and found no student data collection. The activity is physical. A teacher should check the gym floor and keep the pathways clear of tripping hazards.

## Ideas by subject
### health_pe
1. Follow a straight, zigzag, or curved pathway using a locomotor skill.
2. Rebuild a Mario movement map as a gym obstacle course.
3. Perform the coded skills from a partner's map.
4. Walk the course as the computer while a partner reads the code.
5. Revise the course after a test run and make it safer or more fun.

### computer_science
1. Draw a pathway map and label each move with a simple code.
2. Act as the programmer and give a partner clear step-by-step directions.
3. Find a mistake in a code path and fix it.
4. Draw a paper path for an Ozobot and predict how it will run.
5. Compare the robot's run with the class obstacle course.
