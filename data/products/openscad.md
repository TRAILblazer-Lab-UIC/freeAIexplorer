## Overview
OpenSCAD is free software for making solid 3D objects by writing a script. The script combines shapes such as spheres, boxes, and cylinders with union, difference, and intersection. It suits high school students who already like coding. Students write code to build exact shapes from mathematical relationships.

## Benefits for students
- Students see how numbers and code control the size and position of a shape.
- Students can change one value in the script and watch the whole design update.
- Students can export a finished design for a 3D printer.

## Benefits for teachers
- The software has a tutorial, a cheat sheet, and a user manual.
- Teachers can link geometry and coding in a single project.
- The learning curve for teachers is steep. Plan time to practice first.

## Benefits for schools
- The software is free and the source code is open.
- Everything runs on the local computer after the first download.
- IT will likely need to approve the install on managed machines.

## Getting started
- [ ] Download OpenSCAD from openscad.org.
- [ ] Ask IT to approve the install on a few Windows, Mac, or Linux computers.
- [ ] Remember that tablets and Chromebooks cannot run it.
- [ ] Read the tutorial and the cheat sheet before class.
- [ ] Build a simple box and a cylinder and combine them with union.
- [ ] Try the TADA 2D Intro activity, which is labeled Advanced.
- [ ] Point students who prefer drag and drop to Tinkercad.

## Where is the AI?
OpenSCAD has no AI. It builds a useful AI-related skill, which is writing precise instructions that a computer follows exactly. Students practice logic and sequencing as they describe a shape in code.

## Privacy and safety
No account is needed, and the program runs on the local computer. The internet is used to download the software. The research found no privacy policy and no telemetry statement. A teacher should check where students save and share their script files.

## Ideas by subject
### math
1. Write code to create 2D shapes from the mathematical relationships in the TADA 2D Intro activity.
2. Change one length in a script and describe how the area of the shape changes.
3. Build a regular polygon by calculating its corner points.
4. Use a variable to scale a design and record the results in a table.
5. Compare two shapes made with union and difference and explain what each operation does.

### engineering
1. Design a small part for a 3D printer, such as a bracket or a stand, and export it.
2. Write a parametric phone holder and adjust one value to fit different phones.
3. Combine boxes and cylinders to model a simple machine part.
4. Test a printed part and revise the numbers in the script.
5. Document a design with comments so a classmate can change it.

### computer_science
1. Write a short script that makes a box and a sphere and describe each line.
2. Use a variable to control the size of a whole design.
3. Debug a script with a missing bracket and explain the fix.
4. Trade scripts with a partner and predict the shape before running them.
5. Compare writing shapes in code with building shapes by dragging in Tinkercad.
