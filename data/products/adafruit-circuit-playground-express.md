## Overview
The Circuit Playground Express is a round board with an ATSAMD21 processor. It has 10 NeoPixels, an accelerometer, a thermistor, a light sensor, a microphone, a speaker, infrared send and receive, and 7 touch pads. Students program it with MakeCode blocks or JavaScript, CircuitPython, the Arduino IDE or Code.org CS Discoveries. It appears as a USB drive when plugged in.

## Benefits for students
- Students use lights, sound and motion without wiring.
- Students can start with blocks and move to text code.
- Students see their code change a real device.

## Benefits for teachers
- The teacher guide recommends starting with MakeCode blocks.
- Four programming options let teachers grow with the class.
- Adafruit sells classroom sets and kits.

## Benefits for schools
- A single board costs 24.95 USD and a 100 board order costs 19.96 USD each.
- Educator discounts are available.
- Student projects stay on the board and the computer, and a teacher may need to install software.

## Getting started
- [ ] Buy boards from Adafruit or a reseller.
- [ ] Plug a board into a computer with a microUSB cable.
- [ ] Open MakeCode in a browser.
- [ ] Download a small program and copy it to the board drive.
- [ ] Test the lights and sensors.
- [ ] Try CircuitPython or Arduino later for older students.
- [ ] Check Chromebook support first since it was not confirmed on the pages read.

## Where is the AI?
The board has no AI. It builds skills in sensors, logic and sequencing. Students read a sensor value and then decide what the lights or sound should do.

## Privacy and safety
The board stores and runs code on the device and needs no account. Setup downloads software from the web. Browser tools such as MakeCode and Code.org need the internet and have their own privacy policies. The research did not review those policies. The research found no privacy policy for the board. A teacher should check the privacy terms of the browser tool chosen for class.

## Ideas by subject
### engineering
1. Build a light meter that changes the NeoPixel color with the room light.
2. Use the thermistor to make a simple temperature alert.
3. Test the accelerometer by making a shake detector.
4. Use alligator clips to link a touch pad to a fruit or foil.
5. Design a wearable badge that shows a message with lights.

### computer_science
1. Write a MakeCode program that lights each NeoPixel in order.
2. Use a button to start and stop a light pattern.
3. Create a program with a loop and a condition.
4. Send a message between two boards with infrared.
5. Rewrite a block program as CircuitPython code.
