## Overview
LM Studio is a desktop app for macOS, Windows, and Linux. It downloads open models from Hugging Face and runs them on the user's own computer. It has a chat window, offline chat with attached documents, and a local server. Students and teachers use it to chat with a model, compare models, or point other tools at a local API.

## Benefits for students
- Students can chat with an AI model that runs on their own machine.
- Students can compare different open models.
- Students can ask questions about attached documents offline.

## Benefits for teachers
- The chat window looks like other chat tools.
- Teachers can test models before class.
- The local server connects other tools through an OpenAI compatible API.

## Benefits for schools
- The free tier costs $0 and runs local models.
- Paid cloud tiers are optional and cost $20 to $100 per month.
- IT may need to approve installs, and models are several gigabytes each.

## Getting started
- [ ] Find the LM Studio website and download the installer.
- [ ] Ask IT to approve the install on a trial computer.
- [ ] Check for 8 GB RAM, 20 GB free disk, and an AVX2 processor or Apple Silicon.
- [ ] Install the app. Chromebooks are not supported.
- [ ] Search for a small model inside the app and download it.
- [ ] Stay on the free tier and skip the optional cloud products.
- [ ] Go offline and test a chat.

## Where is the AI?
The AI is an open language model that runs on the computer. It handles chat, document questions, and speech transcription. Students ask questions and read the answers. They then check the answers against other sources and use them to shape their own work.

## Privacy and safety
No account is needed to run local models, though the homepage shows a Create account link and the page does not say if it is required. The policy says local messages, chat histories, and documents are not transmitted from the system. It says the app has no telemetry or user specific tracking. Update checks send the app version, OS, and IP address, which the CDN logs. Model searches and downloads are logged anonymously. Optional paid cloud features process requests under zero data retention terms. The homepage now promotes the Bionic agent, which includes cloud services. The policy does not mention COPPA or FERPA. A teacher should check that students use the local chat app, and that the local server is not open to the school network.
