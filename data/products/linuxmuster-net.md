## Overview
linuxmuster.net is an open source package for running a school network. Teachers and service providers develop it, and a non-profit association coordinates maintenance. It includes LINBO for synchronized workstation imaging and a web interface for teaching and administration. Schools install it on their own server.

## Benefits for students
- Students log in to a school network that stays the same on every computer.
- Computers can be reset to a clean state.
- Students may work on Ubuntu or Windows workstations.

## Benefits for teachers
- A web interface supports teaching and administration.
- Teachers can follow the classroom setup from one place.
- The website text is German first, but English is offered.

## Benefits for schools
- The software is free. Support comes by email, forum, and hotline.
- Everything runs on the school's own server.
- IT administration expertise is needed, and setup can take days.

## Getting started
- [ ] Find the installation guide on the linuxmuster.net website.
- [ ] Plan a physical or virtual server.
- [ ] Ask an experienced administrator to install the package.
- [ ] Set up LINBO to image a test workstation.
- [ ] Create teacher and student accounts.
- [ ] Review the default settings and change any default passwords.
- [ ] Test a full login on a student workstation.

## Where is the AI?
The vendor describes no AI. It is network software. Students can build skills in networks and systems when an administrator shows them how a lab is managed.

## Privacy and safety
The software is installed on a school controlled server, and accounts are needed. The site does not describe the accounts, and it offers no hosted service. User data presumably lives on that server, but the materials do not confirm it. No privacy policy was read, and the research did not learn whether any online service is used. A teacher or administrator should check the data and retention settings.
