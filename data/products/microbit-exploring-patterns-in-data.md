## Where is the AI?
The lesson has no running AI program. It teaches that data can be sorted by patterns and rules, which is how classification works. Students sort cards by hand and talk about how a machine might do the same. They build skills in pattern spotting and in data.

## Ideas by subject
### computer_science
1. Sort the cards into groups and name the pattern in each group.
2. Swap cards with another pair and sort them with their rules.
3. Find a card that fits two groups and tell how a machine might decide.
4. Compare the way you sorted with the way a machine might sort.
5. Write a rule that a machine could follow to sort the cards.

### math
1. Find the number pattern in a set of cards and predict the next one.
2. Group cards by shape, size, or count and record the totals.
3. Make a table of how many cards fall in each group.
4. Test whether two rules give the same groups.
5. Create a new set of cards that follows one rule.
