## Overview
Vosk is an offline open source speech recognition toolkit. It has models for more than 20 languages and dialects. It has code bindings for Python, Java, Node.js, and other languages. Students install it with pip and use it from code.

## Benefits for students
- Students build a program that understands speech.
- Students can try other languages.
- Students practice real Python with audio.

## Benefits for teachers
- Small models are about 50 MB each.
- Third-party tutorials show it on Raspberry Pi with a USB microphone.
- It supports streaming recognition and speaker identification.

## Benefits for schools
- The toolkit is free.
- It works offline after the setup downloads.
- The README says audio stays on the device. IT will likely need to help with the install.

## Getting started
- [ ] Find the Vosk site and read the installation guide.
- [ ] Ask IT to prepare a Python environment.
- [ ] Run pip3 install vosk.
- [ ] Download a language model.
- [ ] Connect a microphone.
- [ ] Write a short script that reads audio from the microphone or a file.
- [ ] Go offline and test the script.

## Where is the AI?
The AI is a speech recognition model. It runs on the local device, on a computer or a Raspberry Pi. Students send audio from a microphone or file and read the text that comes back. They can then use that text in their own programs.

## Privacy and safety
No account is needed, and the internet is used only for setup downloads. The README and site state that recognition works offline on the local device. No privacy policy was found, and no telemetry was documented on the pages read. The vendor does not document accuracy for children's voices. A teacher should test the models with student voices before planning a project.
