## Overview
Escuelas Linux is an educational Linux distribution for preschool through high school. It is based on Bodhi Linux. It bundles educational software such as TuxPaint, GCompris, TuxMath, Scratch, and GeoGebra, plus LibreOffice, GIMP, Krita, and browsers. It was developed for Spanish-speaking schools and added English.

## Benefits for students
- Students get games and tools for math, art, and coding in one place.
- Students from preschool to high school find something suited to them.
- Students can try the system live from a USB drive.

## Benefits for teachers
- Classroom tools can reset apps and the desktop.
- An optional Developer Pack adds Android Studio, Eclipse, NetBeans, and others.
- Both Spanish and English are supported.

## Benefits for schools
- The system is free. Downloads are hosted on SourceForge.
- It needs at least 512 MB RAM and 40 GB disk. Both 32-bit and 64-bit editions exist.
- IT staff handle lab deployment.

## Getting started
- [ ] Find the Escuelas Linux download on SourceForge.
- [ ] Ask IT to approve a test install.
- [ ] Download the ISO file.
- [ ] Write the ISO to a USB drive and try it live.
- [ ] Install it on one test computer.
- [ ] Try the reset tools for the desktop and user apps.
- [ ] Choose the 32-bit or 64-bit edition for your older machines.

## Where is the AI?
Escuelas Linux has no AI. It builds skills in using an operating system and learning software. Students learn files, windows, and apps on a Linux desktop.

## Privacy and safety
No account is needed and the internet is used only at setup. Work stays on the computer. No privacy policy was found and the materials do not say what data the system collects. The system includes Chrome and Chromium, which have their own data practices. A teacher should ask IT how the browsers are set up before students go online. Chromebook use is not described.

## Ideas by subject
### math
1. Play TuxMath and record the score for each round.
2. Use GeoGebra to draw a triangle and measure its angles.
3. Practice counting and shapes with a GCompris game.
4. Compare two math games and say which one helped more.
5. Make a graph of scores over a week.

### computer_science
1. Build a short Scratch project that moves a character.
2. Explore the Linux desktop and list its main parts.
3. Use the reset tool to restore a desktop and describe what changed.
4. Try the Developer Pack with a teacher and name one tool in it.
5. Write a guide for a classmate on opening an app.

### visual_arts
1. Draw a picture in TuxPaint.
2. Paint a layered scene in Krita.
3. Edit a photo in GIMP.
4. Compare the same idea drawn in two different apps.
5. Display the finished work and write a short note about it.
