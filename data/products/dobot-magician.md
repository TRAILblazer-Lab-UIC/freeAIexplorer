## Overview
Dobot Magician is a 4-axis desktop robot arm with a 500 g payload and swappable tools. The retailer page lists pick and place, writing and drawing, laser engraving, and 3D printing. Beginners use block-based coding. Advanced users can move to Python, Lua, or Dobot SDKs.

## Benefits for students
- Students program a real robot arm.
- Students try several tools such as a claw, a pen, and a laser.
- Students move from blocks to text code.

## Benefits for teachers
- An Educational Version bundles DobotLab software and tool kits.
- Dobot says its education products serve K12 through research.
- An optional Vision Kit adds machine vision.

## Benefits for schools
- The price is about 1,000 to 2,000 USD.
- SCAN UK lists 876.98 pounds for the basic arm and 1,121.99 pounds for the Educational Version.
- IT will likely need to install the software.

## Where is the AI?
AI is optional. The Vision Kit adds machine vision to the arm. The vendor does not say where the AI runs. Students use the camera to help the arm find an item and then place it. Without the Vision Kit the arm has no AI. It still builds sequencing and logic skills.

## Privacy and safety
No account is needed for the arm, and the internet is used mainly for setup. The Dobot policy says the DobotLab and DobotLink education software collect no personally identifiable information. The policy also says face and ID features of other products send encrypted images to a third party cloud service, and data collected in mainland China is stored there. The research did not confirm where the optional vision kit AI runs. A teacher should check the vendor terms for any vision add-on. A teacher should also set clear safety rules because the arm moves with force.

## Ideas by subject
### engineering
1. Use the pen tool to draw a shape and measure its accuracy.
2. Test the payload limit with different small items.
3. Compare the claw and the suction tool for the same task.
4. Design a part to carry with the arm.
5. Plan a small assembly line that uses the arm.

### cte
1. Program a pick and place task that sorts items by color.
2. Use the laser tool to engrave a design on a safe material.
3. Try the 3D printer tool and review the print.
4. Write a work plan for a task and carry it out with the arm.
5. Explain how a robot arm helps in a factory.

### computer_science
1. Build a block program that moves the arm to four points.
2. Add a loop to repeat a pick and place.
3. Move the same program to Python.
4. Debug a program that drops an item.
5. Compare block code with text code for the same task.
