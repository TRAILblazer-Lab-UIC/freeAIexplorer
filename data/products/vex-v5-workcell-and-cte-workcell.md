## Overview
The V5 Workcell is a desktop sized model of an industrial robotic arm built from VEX V5 parts. The VEX article calls it a smaller, safer, and more cost effective industrial robot model. Students build the arm, add conveyors and sensors, and program them in VEXcode V5. The CTE Workcell is a separate VEX product aimed at career and technical education.

## Benefits for students
- Students build a five axis arm that works like an industrial robot.
- Students add conveyors and sensors to make an automation lab.
- Students program in blocks and see the code in C++ or Python.

## Benefits for teachers
- Step by step build instructions guide the work.
- A bumper switch can act as an emergency stop.
- VEX recommends one robot for every three students.

## Benefits for schools
- The CTE Workcell is listed at 2,499.99 USD in a search snippet. The V5 Workcell price was not confirmed.
- VEXcode V5 is free.
- Setup takes days and IT will install the software.

## Getting started
- [ ] Find the V5 Workcell or CTE Workcell on the VEX site.

- [ ] Add the conveyors and sensors.
- [ ] Test the bumper switch emergency stop.
- [ ] Note that the V5 Workcell STEM Labs were reported as archived.

## Where is the AI?
The workcell has no AI. The arm follows the program that students write. Students build skills in sequencing, sensors, and logic.

## Privacy and safety
The research lists no account for the robot, and the internet is used only at setup. The privacy policy for VEXcode V5 was not read, and the materials do not say what data VEXcode collects. A teacher should read that policy before students use the software. A teacher should also check that students keep hands clear of the arm and test the emergency stop before each class.

## Ideas by subject
### engineering
1. Build the five axis arm from the instructions and test each joint.
2. Add a conveyor and sensor and plan how parts will move.
3. Swap the end of arm tool and compare how it picks up an object.
4. Test the emergency stop and explain why it matters.
5. Compare the workcell with a real factory robot in a short report.

### cte
1. Run a mock automation line that moves parts from a conveyor to a bin.
2. Map the steps of a factory task and match each step to a robot action.
3. Write a safety checklist for working near a robot arm.
4. Interview a local manufacturer about how robots help their work.
5. Present how the workcell could fit a career path in automation.

### computer_science
1. Write a block program that moves the arm to a set spot.
2. Open the code viewer and compare the blocks to the C++ or Python.
3. Use a sensor to start the conveyor.
4. Add a loop that repeats a pick and place move.
5. Debug a program that drops the part.
