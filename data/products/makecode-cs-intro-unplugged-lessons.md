## Overview
This is a roughly 14 week introductory computer science course for grades 6 to 8. It is built around the micro:bit and MakeCode. Each lesson includes a 30 minute unplugged activity, a 45 to 60 minute micro:bit activity, and a project. The course is written for teachers new to computer science.

## Benefits for students
- Students learn ideas such as algorithms and binary with unplugged activities first.
- Students then program a micro:bit.
- Students finish with an independent final project.

## Benefits for teachers
- The course has 13 lessons with an assessment rubric.
- Each lesson lists CSTA standards alignment.
- The course is written for teachers new to computer science.

## Benefits for schools
- The course materials are free.
- Micro:bit boards are needed for the programming parts and are sold separately.
- A teacher may need IT help to set up the editor and the boards.

## Getting started
- [ ] Find the MakeCode CS Intro course home page.

- [ ] Print the unplugged materials for Lesson 1.

- [ ] Follow it with the micro:bit activity.

## Where is the AI?
This course has no AI. It builds algorithms, binary, and programming skills. Students plan on paper and then code a micro:bit.

## Privacy and safety
The unplugged parts run on paper. The MakeCode editor runs in a web browser, and the materials do not say how the internet is used or what data is collected. The course page does not state account requirements. The page links to Microsoft terms and privacy, and the research did not review that policy. A teacher should check the MakeCode terms and decide how students save their projects.

## Ideas by subject
### computer_science
1. Do the binary unplugged activity and explain how a computer stores numbers.
2. Write an algorithm on paper and then code it on a micro:bit.
3. Debug a micro:bit program that does not work.
4. Use the assessment rubric to review your own project.
5. Plan and build an independent final project.

### engineering
1. Design a micro:bit project that solves a classroom problem.
2. Build a prototype with a micro:bit and test it.
3. Use the accelerometer to make a motion-based device.
4. Improve a design after a test.
5. Present the final project and explain the design choices.
