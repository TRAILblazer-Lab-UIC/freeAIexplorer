## Overview
This is a browser-based interface that runs on your own computer for Stable Diffusion image generation. It offers text-to-image, image-to-image, inpainting, outpainting, and upscaling. It needs Python, git, downloaded model files, and a capable graphics card. It suits advanced high school students and art or technology teachers.

## Benefits for students
- Students turn written prompts into images.
- Students can edit part of an image with inpainting.
- Students can explore LoRA files and other advanced options.

## Benefits for teachers
- The tool gives a close look at how image generation works.
- A college computational art course used it for text-to-image, Dreambooth training, and ControlNet posing.
- Extensions let teachers add features as students grow.

## Benefits for schools
- The software is free and the code is open.
- The README describes local generation on the school's own machine after setup.
- The setup is heavy and IT approval is likely needed.

## Getting started
- [ ] Find the project's GitHub page and read the README.
- [ ] Ask IT to approve the install on one computer with a good graphics card.
- [ ] Install Python 3.10.6 and git.
- [ ] Download or clone the release.
- [ ] Download a model checkpoint file.
- [ ] Run the launcher and open the local web page.
- [ ] Go offline and test a short prompt.

## Where is the AI?
The AI is a Stable Diffusion image model that runs on the local graphics card. Students write a prompt, look at the images, and change their words or settings to steer the result. They can also add model add-ons such as LoRA files to change the style.

## Privacy and safety
No account is needed and the internet is used at setup. The README describes local generation and does not mention telemetry. Model files come from sites such as CivitAI, which may host unfiltered content. Extensions are third party code. The research found no privacy policy. A teacher should know that image models can make inappropriate pictures. A teacher managed machine and prompt review are advised.
