## Overview
IDLE is Python's Integrated Development and Learning Environment. It is a Tk based editor and interactive shell with syntax coloring, auto-completion, call tips, a debugger, and search. It is bundled as an optional part of Python installers. Students write and run Python scripts on a local computer.

## Benefits for students
- Students write code and see results in the same window.
- Students can test a line in the shell before adding it to a script.
- Syntax color and call tips help them read code.

## Benefits for teachers
- It installs with Python. There is no separate tool to find.
- It has a multi-window editor and a debugger.
- Warminster School students launch it on school computers to write Python scripts.

## Benefits for schools
- It is free.
- It runs offline on Windows, Mac, and Linux.
- It needs Tcl/Tk, and IDLE may be missing from some Python installs.

## Getting started
- [ ] Download Python from the official Python site.
- [ ] Ask IT to install Python on school computers and include IDLE.
- [ ] Launch IDLE from the Start menu or with python -m idlelib.
- [ ] Check that Tcl/Tk is present if IDLE does not open.
- [ ] Type a print statement in the shell.
- [ ] Save a script and run it from the editor.
- [ ] Note that the debugger is described in the docs as incomplete and somewhat experimental.

## Where is the AI?
IDLE has no AI. It builds text coding skills. Students write, run, and fix Python by reading error messages. It runs on the local computer.

## Privacy and safety
No account is needed, and the internet is used for setup. The documentation says the connection between its processes is not externally visible and no data is sent to or received from the internet. Preferences are stored locally in an .idlerc folder. The documentation has no telemetry statement. A teacher should set a folder for student files and prepare a sample script for the first lesson.
