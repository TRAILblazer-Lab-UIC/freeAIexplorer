## Overview
JASP is free statistical software with a point and click interface. It runs as an offline desktop app. The site has a Teaching section with a data library, a video library, resources, and workshops. Students load data, pick an analysis, and read the results.

## Benefits for students
- Students run analyses with menus and no code.
- Students can practice on datasets from the Teaching section, which a search snippet says holds over 50.
- Students can try Bayesian and frequentist methods, according to a practitioner review.

## Benefits for teachers
- The Teaching section has videos, resources, and workshops.
- Search results show an open textbook, Statistics with JASP, and an OpenIntro lab series.
- The interface is easy for teachers to learn in about an hour.

## Benefits for schools
- The software is free and the code is open on GitHub.
- It runs on the desktop and needs the internet only for setup.
- IT may need to approve the installer.

## Getting started
- [ ] Download the installer from jasp-stats.org.
- [ ] Ask IT to approve and install it on a test machine.
- [ ] Check that the installer matches your operating system. The site page did not list them.
- [ ] Open a dataset from the Teaching data library.
- [ ] Run one descriptive analysis.
- [ ] Watch one video from the video library.
- [ ] Plan one short lesson before you share it with students.

## Where is the AI?
JASP has no AI. It runs statistical methods that students choose. Students build data skills by picking a method, running it, and reading the output.

## Privacy and safety
No account is needed, and the internet is used for setup. The privacy policy covers the website, forum, and newsletter and not the desktop software. It states that no user data is collected via the JASP software. The website uses Matomo analytics and Mailchimp for the newsletter, and forum accounts need a username and email. A teacher should keep student data files on school machines.

## Ideas by subject
### math
1. Open a dataset from the Teaching library and describe each variable.
2. Make a plot and describe its shape.
3. Compare two groups and report the difference in plain words.
4. Run a simple test and explain what the result says.
5. Watch a video from the library and repeat the analysis on your own data.
