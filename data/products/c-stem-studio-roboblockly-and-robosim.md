## Overview
C-STEM Studio is a UC Davis platform that bundles RoboBlockly block coding, the RoboSim virtual robot simulator and the Ch C and C++ interpreter. It supports virtual and physical Linkbot and LEGO Mindstorms NXT and EV3 robots. It is listed for grades 4 through 12. Students write block programs and watch virtual robots run them.

## Benefits for students
- Students move from blocks to C code with the same robot.
- Students practice in a simulator before using a physical robot.
- Students meet math ideas through robot tasks.

## Benefits for teachers
- Wikipedia says RoboBlockly includes Common Core aligned math activities.
- Block programs produce Ch code that can run on real or virtual robots.
- Math-ICT curriculum materials are part of the package.

## Benefits for schools
- The software is described as free. The full curriculum may need licenses, which was not verified.
- RoboBlockly runs in a modern browser and the desktop version runs on Windows, Mac and Linux.
- The simulator needs no robot hardware.

## Getting started
- [ ] Open RoboBlockly in a browser to try it.
- [ ] Ask IT to download C-STEM Studio for desktop use with Ch.
- [ ] Confirm the license terms for the full curriculum with the vendor.
- [ ] Run a first block program on a virtual robot in RoboSim.
- [ ] Check whether accounts are offered and what they store.
- [ ] Add physical robots only after the simulator work goes well.
- [ ] Plan extra setup time for any physical robots.

## Where is the AI?
C-STEM Studio has no AI. Students write programs and the virtual or real robot follows them. Students build skills in sequencing, loops and logic.

## Privacy and safety
It is not confirmed whether accounts are needed. The research could not read the official site or its privacy policy and did not review data handling. Wikipedia mentions an Activity Portal where users share projects, which suggests some online accounts or hosting. The materials do not state what student data is collected or where it goes. The research did not confirm how much the internet is needed beyond setup. A teacher should read the privacy terms and check what an account or the Activity Portal would store.

## Ideas by subject
### computer_science
1. Build a block program that drives a virtual robot in a square.
2. View the Ch code that the blocks produce and describe what it says.
3. Add a loop to shorten a long program.
4. Change one value in the C code and predict the robot move.
5. Debug a program that sends the robot off the path.

### math
1. Use the robot to draw angles and measure each turn.
2. Plot a path on a coordinate grid and drive the robot along it.
3. Compute how far the robot travels for a given wheel turn.
4. Compare two routes by length and choose the shorter one.
5. Use the Common Core aligned activities to explore geometry with the robot.

### engineering
1. Design a simulated robot challenge and share it with a partner.
2. Test a program in RoboSim and refine it before a physical test.
3. Record how changing speed affects the path.
4. Plan a task for a robot and list the steps in order.
5. Compare how a virtual robot and a real robot behave.
