## Overview
CodeSkulptor3 is a browser-based Python 3 environment with Code, Output, and Frames panels. It implements a subset of Python 3 plus three libraries named SimpleGui, SimpleMap, and SimplePlot. It is featured in the Coursera course Fundamentals of Computing from Rice University. Students type code and run it in the browser.

## Benefits for students
- Students can start coding without an install or account.
- Students can build simple graphics and plots.
- Students can work together through collaborative editing sessions.

## Benefits for teachers
- Teachers share code by saving to a URL or downloading a file.
- The tool has an input prompt and an error dialog.
- Teachers can use the Rice course materials as a model.

## Benefits for schools
- The tool is free to use.
- It runs in any web browser, including on Chromebooks.
- The internet is needed at all times.

## Getting started
- [ ] Open the CodeSkulptor3 website in a web browser.
- [ ] Type a short Python program and run it.
- [ ] Try a SimpleGui example that draws on a canvas.
- [ ] Save a program to a URL and reopen it.
- [ ] Try a collaborative session with a partner.
- [ ] Read the documentation for the supported subset of Python 3.
- [ ] Check the site privacy information before students use it.

## Where is the AI?
This tool has no AI. It runs Python that students write. Students build skills in logic and data as they plot and draw.

## Privacy and safety
The page shows no sign in, and the internet is needed at all times. The research found no privacy policy. Saved programs and collaboration sessions are presumably stored on the CodeSkulptor server, but the research did not confirm this. The materials do not state what data is collected. A teacher should check how saved programs are stored and remind students to avoid personal information in code.
