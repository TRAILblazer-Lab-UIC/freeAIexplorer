## Overview
This is a low-cost microcontroller board family. The original Pico uses the RP2040 chip. Pico W adds Wi-Fi and Bluetooth, and Pico 2 uses the newer RP2350 chip. Boards load programs by dragging a file over USB. Students use them for physical computing such as LEDs, sensors and buggies.

## Benefits for students
- Students program a tiny computer with MicroPython.
- Students build projects with LEDs, sensors and buggies.
- Students see their code run on a real board.

## Benefits for teachers
- A Hampshire after-school club built motorised buggies over about six sessions.
- Essex students aged 12 to 14 revisited Python subroutines and libraries.
- Teacher claims in the maker article are opinions.

## Benefits for schools
- Prices run from 4 USD for the Pico to 7 USD for the Pico 2 W. Headers soldered cost about 1 USD more.
- Programs run with no internet.
- The 2022 article advises asking school IT to install Thonny.

## Getting started
- [ ] Buy a Pico from the Raspberry Pi product page or a reseller.
- [ ] Ask IT to install Thonny.
- [ ] Hold the BOOTSEL button while plugging in the board.
- [ ] Flash the MicroPython firmware.
- [ ] Write and run a short program.
- [ ] Add a breadboard and an LED.
- [ ] Check that you have a micro USB cable.

## Where is the AI?
The boards have no AI. They build skills in text coding, sensors and logic. Students read inputs and write code that changes outputs.

## Privacy and safety
The board runs on the device and needs no account or internet. The materials document no student data collection. Pico W and Pico 2 W can use Wi-Fi and Bluetooth. A teacher should decide whether students may turn those on and check the school network rules.

## Ideas by subject
### computer_science
1. Write MicroPython that blinks the onboard LED.
2. Make a function that flashes a pattern and call it three times.
3. Use a library to read a sensor.
4. Revisit subroutines by splitting a long program into parts.
5. Debug a program that never lights the LED.

### engineering
1. Build a small buggy as in the Hampshire club.
2. Wire an LED and a button on a breadboard.
3. Test a sensor and record how it responds.
4. Compare two board models and note the differences.
5. Document a project so another class can repeat it.
