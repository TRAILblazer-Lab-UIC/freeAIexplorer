## Overview
PuppyPi is a Raspberry Pi based quadruped robot dog from Hiwonder. Vendor descriptions say vision uses OpenCV. Newer kits add an AI large model with voice interaction, a lidar option, and a robotic arm attachment. Kits come with different Raspberry Pi boards. The vendor does not state a grade range, and the kit suits advanced high school students.

## Benefits for students
- Students run Python and ROS examples on a real robot.
- Students try camera vision and object tracking.
- Students in newer kits can talk with the robot through a language model.

## Benefits for teachers
- Provided Python and ROS examples give a starting point.
- A teacher can pick the kit variant that fits the class.
- The product changed from a plain OpenCV dog to a ChatGPT enabled one. Check the variant before buying.

## Benefits for schools
- Retailer listings range from about 950 USD to about 1510.
- The language model features likely need an API and extra setup.
- Those features likely send data to a vendor cloud.

## Where is the AI?
The AI includes computer vision, object tracking, and in newer kits language model dialogue and voice interaction. Vision runs on the device. The language features likely use a vendor cloud service. Students write code that acts on what the robot sees and says.

## Privacy and safety
The materials do not say whether an account is needed or whether the internet is required. Vision is described as running on the robot. The ChatGPT features call an outside model service. Voice, text, and camera content may go to a third party when those features are used. The research did not confirm whether an API key is needed. No privacy policy was reviewed. A teacher should check which kit variant is bought and keep the chat features off until the data flow is clear.
