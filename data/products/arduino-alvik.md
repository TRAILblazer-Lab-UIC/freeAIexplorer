## Overview
Alvik is a wheeled educational robot built on an Arduino Nano ESP32. It has a distance sensor, a color sensor, a gyroscope, and line follower sensors. Students can program it with blocks in mBlock, with MicroPython, or with Arduino C. Arduino labels learning resources 7 and up for blocks and 12 and up for MicroPython.

## Benefits for students
- Students can start with blocks and move to text code.
- Students use real sensors to make a robot react.
- Students can add LEGO Technic parts.

## Benefits for teachers
- Alvik education resources include two project lessons.
- The mBlock web platform works on Chromebooks, Windows, and Mac per Arduino.
- A classroom example had students at Acera School code Alvik robots to draw shapes and spirals and model planets.

## Benefits for schools
- The Arduino store lists 126.88 EUR including VAT.
- Charging uses the included 18650 battery.
- Account use is optional and the data flow is mixed.

## Where is the AI?
This robot has no AI. It runs the program students upload. Students build sensor and logic skills as they use distance and line readings to steer.

## Privacy and safety
Robot code runs on the board. The mBlock web platform and Arduino cloud tools are online. Accounts are optional and the research did not find whether mBlock block coding needs one. The materials do not say what student data is collected. Arduino policy offers Junior Accounts under 14 and Restricted Accounts for ages 14 to 17. It requires parental consent under 18. Arduino is owned by Qualcomm and data may move between countries. A teacher should check the Arduino and mBlock account terms before students sign in.

## Ideas by subject
### computer_science
1. Write blocks that move Alvik forward and turn.
2. Use the line sensors to follow a path.
3. Make the robot stop when the distance sensor sees an object.
4. Move from a block program to the same program in MicroPython.
5. Debug a program that turns too far.

### engineering
1. Attach a marker and have the robot draw a shape.
2. Test the distance sensor at several distances and record the results.
3. Build a LEGO Technic add on and test it.
4. Model planets with robot paths and explain the plan.
5. Compare sensor readings on two surfaces.
