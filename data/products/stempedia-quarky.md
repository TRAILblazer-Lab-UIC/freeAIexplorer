## Overview
Quarky is a robot board that students code in PictoBlox with blocks or Python. It connects to a computer over USB or Bluetooth, and Wi-Fi is not required. Students drive motors and servos, follow lines, and build robots such as an obstacle avoider or a gripper. School bundles list classes 3 to 12.

## Benefits for students
- Students code a real robot and see it move.
- Students choose blocks or Python as their skills grow.
- Students can build several robot types from the same board.

## Benefits for teachers
- Stage Mode runs scripts live, which is good for demonstrations.
- Upload Mode sends a program to the board so it runs on its own.
- Mobile devices connect through the Board and Connect buttons.

## Benefits for schools
- A review listed the Quarky Innovator Kit at 129.99 USD. Other kit prices were not confirmed.
- Windows, Mac, Linux, iOS, and Android are listed. Chromebook support was not confirmed.
- IT should help with installing PictoBlox and uploading firmware.

## Getting started
- [ ] Order a Quarky kit from STEMpedia.
- [ ] Install PictoBlox on a teacher computer. Ask IT for help.
- [ ] Upload the firmware to the board before first use.
- [ ] Connect over USB or Bluetooth.
- [ ] Open the Robot extension and test a motor.
- [ ] Try Stage Mode and then Upload Mode with a short program.
- [ ] Decide whether students need PictoBlox accounts, and review the data first.

## Where is the AI?
The documentation does not describe any built-in AI on the board. AI comes from PictoBlox projects, such as object tracking and pose mimicking. These are optional add-ons. Students extend the robot by pairing it with a machine learning project.

## Privacy and safety
The materials do not state where the data goes or whether the internet is needed. PictoBlox accounts collect a username, profile picture and age. Users 16 and older also give an email, country, date of birth and gender, and users under 16 give a guardian email. The STEMpedia policy says it does not knowingly collect information from children under 13, which is a data rule and not a minimum age. The research did not confirm whether Quarky AI projects use cloud services. A teacher should check the account rules and let students work without accounts when possible.

## Ideas by subject
### computer_science
1. Program the board to drive forward, turn, and stop in a set pattern.
2. Use the line following blocks to make a robot trace a path.
3. Compare a Stage Mode program and an Upload Mode program and describe the difference.
4. Switch a block program to Python and run it again.
5. Pair the robot with a PictoBlox pose project and test how it mimics a movement.

### engineering
1. Assemble the line follower build and test it on a taped track.
2. Add a gripper and test how well it picks up light objects.
3. Build the obstacle avoidance version and measure the stopping distance.
4. Compare a mecanum wheel build with a standard wheel build.
5. Document the wiring and build steps for another team.
