## Overview
Make Wonder is the teacher platform for Dash robots, with pre-built lessons, activities and a dashboard. Blockly is the drag-and-drop coding app for younger students. Dash can also be coded in JavaScript for older students. Virtual Dash is an on-screen robot for classes that share fewer physical robots. The site lists standards-aligned coding courses for grades K to 8.

## Benefits for students
- Students code Dash with drag-and-drop blocks.
- Students can use Virtual Dash on screen.
- Older students can try JavaScript.

## Benefits for teachers
- Teachers can create up to 35 student profiles and track progress.
- Pre-built lessons cover coding, math and science.
- Courses are standards aligned for grades K to 8.

## Benefits for schools
- Apps and some content are free. A Make Wonder subscription adds premium lessons.
- Hardware prices rose on Oct 9 2025 because of tariffs, and Dash was listed at 189.99 USD.
- Wonder Workshop assets were bought by MORAVIA Education, and the FAQ says teacher and student logins and tools are unchanged.

## Getting started
- [ ] Find Make Wonder and the Blockly app on the Wonder Workshop site.
- [ ] Install the Blockly app or open the web app in Chrome.
- [ ] Try Virtual Dash with no robot.
- [ ] Sign up for a Make Wonder subscription if you want class profiles.
- [ ] Review the privacy policy before adding student profiles.
- [ ] Add students and track progress.
- [ ] Pair a Dash robot over Bluetooth for physical coding.

## Where is the AI?
The vendor does not describe any AI in Make Wonder. Dash follows the blocks or code that students write. Students build skills in sequencing and logic.

## Privacy and safety
Student data goes to the vendor cloud, hosted on Amazon Web Services. The vendor collects a child profile with username, birth date and gender. It also collects program names and solutions, time in app, device and robot diagnostics, and IP address. Teachers can link usage to student names. Accounts are optional, and the teacher subscription gives class profiles. The policy says it complies with COPPA and the robots have no cameras. It says it does not collect kids' voices or images. It uses Google Analytics on its sites. Classroom data is private to the classroom by default, and schools can request deletion. The research did not confirm which features need the internet. A teacher should read the privacy policy and use as little student detail as possible.

## Ideas by subject
### computer_science
1. Use Blockly to make Dash drive to a spot on the floor.
2. Use a repeat block to make Dash draw a shape.
3. Try Virtual Dash and compare it with the real robot.
4. Debug a program that sends Dash the wrong way.
5. Try the same task in JavaScript with older students.

### math
1. Use Dash to measure distance in steps and compare them.
2. Program Dash to travel a set number of units.
3. Draw shapes and count their sides.
4. Use the Math Activities in the platform.
5. Graph how far Dash goes at different speeds.

### science
1. Use the Science Activities in the platform.
2. Test how Dash's speed changes over a ramp.
3. Predict where Dash will stop and then check.
4. Record observations in a chart.
5. Present the results to the class.
