## Overview
LLM Hub is an app for running AI models on a phone or computer. It does chat, image, video, and music generation. It is available on Android and iOS, with a desktop version for Windows, macOS, and Linux. Users download models from Hugging Face or import them.

## Benefits for students
- Students can try chat, translation, transcription, and image tools in one app.
- Students can see how local models differ in size and quality.
- Students can use it on phones they already have.

## Benefits for teachers
- A teacher can demonstrate on-device AI without an account.
- The app offers an agent and a chat with memory.
- Teachers can use it to teach about model sizes.

## Benefits for schools
- The app is free for noncommercial use. Commercial use needs a paid license from the author.
- The project says inference is on-device and needs no account.
- The macOS desktop build requires macOS 26 or later.

## Getting started
- [ ] Install the app from Google Play, the App Store, or the GitHub desktop release.
- [ ] Check that the device can run the model you plan to use.
- [ ] Open Settings and choose Download Models.
- [ ] Download one small model while on Wi-Fi.
- [ ] Turn off web search, which uses the network.
- [ ] Test a short chat after going offline.
- [ ] Try the translator or transcriber with a short sample.

## Where is the AI?
The AI is a set of models for chat, images, video, music, speech to text, and text to speech. They run on the device. Students use them to chat, translate, transcribe, and create, and then review the results as they build their own work.

## Privacy and safety
No account is needed. The policy says the app does not collect personal information, conversation data, usage statistics, or device identifiers. It also says there is no third party analytics. Models are downloaded from Hugging Face. Web search and similar features need the internet. The policy that the research read mentions Android only. The Windows installers are not code signed. A teacher should check which models and features students turn on and confirm the policy covers the platform in use.
