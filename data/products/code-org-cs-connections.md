## Overview
CS Connections offers free modules that teach computing through language arts, math, science, social studies, and music. Week-long modules for grades 3 to 8 use 45-minute lessons. Two hour-long lessons suit grades 2 to 12. Students code in Sprite Lab with blocks in a browser.

## Benefits for students
- Students use coding to make poems, maps, music, and models.
- Students learn with block coding in Sprite Lab.
- Students connect coding to the subjects they already study.

## Benefits for teachers
- A free teacher account gives lesson plans, slides, and progress tracking.
- A self-paced teacher learning module is available.
- The modules map to Common Core, NGSS, and CSTA standards.

## Benefits for schools
- The modules are free for anyone to teach.
- Ideally each student has a computer, and a projector helps.
- Optional student accounts store progress and projects on the vendor's cloud.

## Getting started
- [ ] Find CS Connections on the Code.org website.
- [ ] Browse the module list and pick one that fits your subject.
- [ ] Create a free teacher account.
- [ ] Read the lesson plan and slides.
- [ ] Try the Sprite Lab project yourself.
- [ ] Arrange one computer per student and a projector.
- [ ] Decide whether students will use accounts.

## Where is the AI?
This curriculum has no AI. It builds skills in sequencing and events with block code. Students tell sprites what to do and see the result.

## Privacy and safety
Student accounts are optional and store progress, code, and projects. Without accounts only the IP address is collected. Data goes to the vendor cloud, and the internet is needed throughout. The policy says it does not sell personal data or show ads. It says the nonprofit is not subject to COPPA but takes extra steps such as hashed student emails. It treats school directed accounts as student records and lets service providers process data under contract. A teacher should read the Code.org privacy policy before creating student accounts.

## Ideas by subject
### computer_science
1. Complete the Hello World lesson and change one sprite behavior.
2. Make a sprite respond to a key press.
3. Use the Poem Art lesson to draw a design from words.
4. Trace the code in a partner's project and explain it.
5. Add a new event to a finished project.

### ela
1. Code an interactive poem that shows mood and tone.
2. Choose images and words that match the feeling of a poem.
3. Make a book cover that responds to a click.
4. Read a partner's poem project and describe the tone.
5. Revise a poem project after feedback.

### science
1. Simulate a marine ecosystem and change one animal population.
2. Model an animal adaptation and test how it helps survival.
3. Predict what happens in the simulation and then run it.
4. Compare two simulation runs and explain the difference.
5. Present a model and list what it leaves out.

### social_studies
1. Code an interactive map with labels for key places.
2. Add a click that shows facts about a location.
3. Build a time capsule project about a community.
4. Trade maps with a partner and test them.
5. Explain which map choices help a viewer understand the place.

### music
1. Use the Coding with Music module to make a beat.
2. Change the tempo and describe the effect.
3. Make a sprite dance in time with a song.
4. Combine two sounds with a button press.
5. Share a music project with the class and explain the code.
