## Overview
Yanshee is a humanoid robot about 15 inches tall with 17 servos, a gyroscope, and a programmable Raspberry Pi. UBTECH calls it an open source platform. It offers face, image, and voice recognition. The package aims at high school and university and includes 60 course hours.

## Benefits for students
- Students program a humanoid with Blockly or with text code.
- Students try face, image, and voice recognition.
- Students can grow from blocks to Python, C/C++, Java, or Perl.

## Benefits for teachers
- The package includes 60 course hours.
- The Yanshee app offers Blockly for a gentle start.
- The Raspberry Pi controller lets advanced students go further.

## Benefits for schools
- The vendor lists no price and tells visitors to contact UBTECH.
- The code is open source.
- The vendor does not say whether the internet is needed.

## Where is the AI?
The AI provides face, image, and voice recognition. The vendor does not say where it runs. Students use Blockly or text code to make the robot react to what it sees and hears. They can then extend those reactions with their own programs.

## Privacy and safety
The page does not describe connectivity or data handling and the UBTECH privacy page the research tried returned an error. The materials do not state whether an account or the internet is needed or where data goes. The robot offers face, image, and voice recognition. ## Ideas by subject

1. Build a Blockly program that makes the robot wave when it sees a face.
2. Write a Python script that reads a sensor value from the robot.
3. Test voice commands and record which ones the robot understands.
4. Combine two actions into one routine and run it.
5. Compare a Blockly program with its Python version.

### engineering
1. Study the 17 servos and label what each one moves.
2. Use the gyroscope reading to describe when the robot is tilting.
3. Tune a walking routine so the robot stays upright.
4. Design a simple stage show for the robot with a timed routine.
