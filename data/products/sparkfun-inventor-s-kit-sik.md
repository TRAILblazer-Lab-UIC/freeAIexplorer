## Overview
The SparkFun Inventor's Kit is an Arduino-compatible beginner kit. It has five projects named Light, Sound, Motion, Display, and Robot. They hold 16 circuits that progress from blinking an LED to an object-avoiding robot. SparkFun recommends it for ages 10 and up.

## Benefits for students
- Students build 16 circuits that grow from simple to complex.
- Students write Arduino sketches to control lights, sounds, and motors.
- Students finish with a robot that avoids objects.

## Benefits for teachers
- A spiral-bound guidebook and an online Experiment Guide give step by step help.
- A search snippet says the kit needs no soldering.
- Teachers can pace the five projects across a unit.

## Benefits for schools
- Retail price is 99.95 USD, with volume tiers down to 84.96 USD for 100 or more.
- The kit works with Windows, Mac, and Linux computers.
- IT will likely need to install the Arduino software and the RedBoard Qwiic driver.

## Getting started
- [ ] Find the SparkFun Inventor's Kit on the SparkFun site.
- [ ] Ask IT to install the Arduino software on student computers.
- [ ] Install the driver for the RedBoard Qwiic.
- [ ] Open the online Experiment Guide.
- [ ] Build the first circuit and blink the LED.
- [ ] Work through the Light project before moving on.
- [ ] Keep a parts list so pieces do not get lost.

## Where is the AI?
The kit has no AI. Students write Arduino code that reads sensors and controls parts. They build skills in logic and in reading sensor data.

## Privacy and safety
No account is needed and the internet is used at setup. The board is programmed over USB from a local computer. The research described no cloud component and reviewed no privacy policy. A teacher should check that students handle small parts and motors with care. Independent classroom evidence was not found.

## Ideas by subject
### engineering
1. Build the first circuit from the guidebook and make an LED blink.
2. Wire a light sensor and record how its readings change near a lamp.
3. Build the motion circuit and test how fast the motor spins.
4. Draw each circuit before building it and compare the drawing to the build.
5. Finish the robot project and test how well it avoids objects.

### computer_science
1. Upload the blink sketch and change the delay to see the result.
2. Write a sketch that plays a short tune with the buzzer.
3. Read a sketch line by line and explain it to a partner.
4. Use an if-then rule in code to react to a sensor reading.
5. Debug a sketch with a deliberate error in it.

### science
1. Test which materials let a circuit work and which do not.
2. Use a light sensor to measure brightness in different parts of the room.
3. Explain how a motor turns electricity into motion.
4. Predict a sensor reading and then check it with the kit.
5. Record data from a sensor and graph it.
