## Overview
TranslateLocally is a free desktop app for neural machine translation. The user downloads a language pair model and then translates text on the computer. It is built on the Marian and Bergamot engines. It runs on Linux, Windows, and Mac and suits students in grades 6 to 12.

## Benefits for students
- Students can translate short passages between language pairs.
- Students can work offline after the model downloads.
- Students can compare the machine result with their own work.

## Benefits for teachers
- The app is simple to start and use.
- Teachers choose which language pairs to download.
- A browser extension can share the same models.

## Benefits for schools
- The desktop app is free.
- Translation stays on the school computer.
- IT will likely need to install the app. The Chrome extension is free for personal use, and commercial use needs the company.

## Getting started
- [ ] Find the downloads page for TranslateLocally.
- [ ] Ask IT to approve the install.
- [ ] Download the desktop app for your system.
- [ ] Start the app and download at least one language pair.
- [ ] Translate a short sentence to test it.
- [ ] Go offline and test again.
- [ ] Check that the computer's processor supports SSE4.1 for the browser translator.

## Where is the AI?
The AI is a neural machine translation model. It runs on the device after the language pair downloads. Students type or paste text and read the translation. They then compare it with their own work and fix errors.

## Privacy and safety
No account is needed. The site says text is processed entirely on the device and is never transmitted, retained, or stored. These are the company's claims. The site counts model downloads and keeps server logs temporarily if it malfunctions. It does not use cookies. The internet is used to download models. Check that the official domain, which redirects to private.mt, is the source of the download. Tell students that translations can be wrong.
