## Overview
Poppy Ergo Jr is a small low-cost robot arm with six degrees of freedom. It uses six XL-320 Dynamixel servos and simple 3D-printed parts. It can be programmed with Snap!, Python or any language that uses its REST API. A French conference paper from 2018 reports more than 30 lycees equipped with the kit.

## Benefits for students
- Students build a real robot arm.
- Students program with Snap! blocks or Python notebooks.
- Students work from a browser.

## Benefits for teachers
- Documentation and a forum exist in French and English.
- Poppy Education provides teaching content, but the education site is reported to be French only.
- The design is open source.

## Benefits for schools
- Servos cost about 20 each per the wiki. No full kit price was verified.
- It runs on a Raspberry Pi.
- IT or a teacher must flash the image.

## Getting started
- [ ] Find the Poppy Ergo Jr documentation.
- [ ] Build or buy the arm.
- [ ] Gather a Raspberry Pi and six XL-320 servos.
- [ ] Flash the Poppy system image to the Raspberry Pi.
- [ ] Connect from a browser.
- [ ] Open Snap! or a Python notebook.
- [ ] Run a first move.

## Where is the AI?
The arm has no AI. It builds skills in sequencing, logic and control. Students plan joint moves in order and test them.

## Privacy and safety
The arm works on a local Raspberry Pi and no vendor cloud is documented. No account is needed and the internet is used at setup. The official site could not be fetched. No privacy policy was reviewed. The materials document no student data collection. A teacher should check the Pi's network setup with IT and keep fingers clear of the servos.

## Ideas by subject
### computer_science
1. Move the arm to a position with Snap! blocks.
2. Write a Python notebook that moves two joints.
3. Use a loop to repeat a wave.
4. Compare the Snap! version with the Python version.
5. Share a program with a partner and explain it.

### engineering
1. Build the six-servo arm from the parts.
2. Test the reach and record what the arm can pick up.
3. Strengthen a weak 3D-printed part and test again.
4. Map each servo to one joint.
5. Write a short build guide for another class.
