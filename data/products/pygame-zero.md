## Overview
Pygame Zero is a way to make games in Python without boilerplate. It lets teachers teach basic programming without explaining the Pygame API or writing an event loop. Built-in objects such as screen, Actors, clock, music, and keyboard are ready to use. Students write a script and run it with the pgzrun command.

## Benefits for students
- Students make a working game from a short script.
- Students use Actors, sounds, and images without extra setup.
- Students see quick results that keep them motivated.

## Benefits for teachers
- The tool removes the event loop, which is a hard idea for beginners.
- A quick guide and tutorials are available.
- It is preinstalled on Raspberry Pi OS.

## Benefits for schools
- The software is free and open source.
- Games run on the local computer with no account.
- IT will likely need to install Python and Pygame.

## Getting started
- [ ] Find Pygame Zero on its official site and read the quick guide.
- [ ] Ask IT to approve the install on a test computer.
- [ ] Install Python on the computer.
- [ ] Run pip install pgzero in a terminal.
- [ ] Open an editor such as Mu or IDLE.
- [ ] Save a short script and run it with pgzrun.
- [ ] Check that Pygame installs cleanly on the school Python version.

## Where is the AI?
Pygame Zero has no AI. It builds an AI-related skill, which is logic. Students write rules that decide what happens when a key is pressed or two objects touch. That practice is a base for how programs make decisions.

## Privacy and safety
No account is needed. The internet is used for the pip install. Games and code stay on the device. No privacy policy was found. The tool is not a Chromebook app. A teacher should check that the install works on the school's Python version before the lesson.
