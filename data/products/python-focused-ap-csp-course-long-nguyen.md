## Overview
This is a Python version of AP Computer Science Principles, made by teacher Long Nguyen. It has a course outline, lecture notes, slides, and starter and exemplar projects. The official page now says the course moved to 1729math.com. Slides, labs, and PDFs are still free. It is written for grades 9-12.

## Benefits for students
- Students learn the AP CSP topics through Python code.
- Students work from starter projects and see exemplar projects.
- A search snippet describes a unit where students build a program that recognizes handwritten digits with a neural network.

## Benefits for teachers
- Slides, labs, and lecture notes are ready to use.
- A course outline shows the sequence.
- The neural network unit detail comes from an older version of the page.

## Benefits for schools
- The materials are free.
- No accounts are needed and little IT work is expected.
- The teacher must choose a Python environment for students.

## Where is the AI?
The AI is optional. A search snippet describes a neural network unit for handwritten digits. The vendor does not say where the AI runs. Students would write Python code, train the network, and test how well it recognizes digits.

## Privacy and safety
No account is needed, and the internet is used to reach the course files. The materials are static pages and files. The research did not find a data statement for the course, and the course page has moved to a new site that was not read. The student coding environment is up to the teacher and was not documented. A teacher should check that environment for its own accounts and data rules.

## Ideas by subject
### computer_science
1. Write a Python program from the starter project and change one feature.
2. Use lists and loops to process a small dataset.
3. Build the handwritten digit program from the neural network unit and test it.
4. Compare your program with the exemplar project and note the differences.
5. Explain in your own words how the network learns from examples.
