## Overview
Sphero says Blueprint Robotics is designed for grades 8 through 12. It has a prebuilt swerve drive base with click-together parts and plug-in electronics. Students program in Blueprint Studio by dragging code pieces or by writing Python. The curriculum covers motion control, systems thinking, and CAD.

## Benefits for students
- Students build and drive a real swerve drive robot.
- Students can start with blocks and move to Python.
- Students learn CAD and systems thinking through the lessons.

## Benefits for teachers
- The curriculum lives on Sphero Central.
- Competition and challenge activities give a clear goal for a unit.
- The prebuilt base cuts build time.

## Benefits for schools
- The official page lists no price.
- A reseller lists one kit for 3 students with pre-orders shipping in summer 2026.
- IT will likely need to install Blueprint Studio.

## Getting started
- [ ] Find the Blueprint Robotics kit on the Sphero site or a reseller.
- [ ] Ask about price and shipping before ordering.
- [ ] Ask IT to install Blueprint Studio on a computer.
- [ ] Build the base from the click-together parts.
- [ ] Open the lessons on Sphero Central.
- [ ] Drive the robot with a first block program.
- [ ] Try the Python option with advanced students.

## Where is the AI?
The kit has no AI. The robot follows the blocks or Python code that students write. They build skills in motion control and logic.

## Privacy and safety
An account is optional and the internet is used at setup. The research did not find data practices for Blueprint Studio. The Sphero Edu privacy page says its apps can be used anonymously, but the research did not confirm that it covers Blueprint Studio. A teacher should check Sphero's privacy details before students create accounts. No independent review was found.

## Ideas by subject
### engineering
1. Build the swerve drive base and explain how each wheel module turns.
2. Use CAD to design an add-on part for the robot.
3. Test the robot on a course and note where it drifts.
4. Compare the robot's drive to a standard two wheel drive.
5. Plan a challenge entry and list the parts needed.

### computer_science
1. Drag code pieces in Blueprint Studio to drive the robot in a square.
2. Rewrite a block program in Python and compare the two.
3. Write a program that moves the robot to a marked spot.
4. Add a loop to repeat a movement pattern.
5. Debug a program that sends the robot the wrong way.
