## Ideas by subject
### computer_science
1. Encode a short message with a shift cipher and trade it with a partner to decode.
2. Explain why a message needs a key.
3. Use the teacher presentation to learn how public-key encryption works.
4. Crack a coded message by testing every shift.
5. Discuss why websites need encryption.

### math
1. Shift each letter by a set number and write the result.
2. Use a number line to track a shift that wraps past Z.
3. Explain a shift as adding a number and wrapping around.
4. Count how many shifts are possible in a 26 letter alphabet.
5. Try a small modular arithmetic problem with clock numbers.
