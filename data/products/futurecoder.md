## Overview
futurecoder is a free interactive Python course for complete beginners. Students write and run code in an in-page editor and shell. Three debuggers show how code executes. Friendly error messages replace raw tracebacks. Stuck students can use Parsons problems and gradual solution hints.

## Benefits for students
- Students write real Python in the browser.
- Students see how code runs step by step.
- Students get hints when they are stuck.

## Benefits for teachers
- Friendly error messages cut down on confusion.
- Debuggers include Python Tutor, Snoop, and Bird's Eye.
- Parsons problems give a gentle start.

## Benefits for schools
- The course is free. Donations are invited.
- It needs only a modern browser and no install.
- Chromebook support was not checked directly.

## Getting started
- [ ] Open futurecoder.io in a browser.
- [ ] Start the course and try the first steps.
- [ ] Test the course on a student device.
- [ ] Check whether an account is needed to save progress.
- [ ] Read the site terms with your school.
- [ ] Plan which lessons to cover each week.

## Where is the AI?
The vendor does not describe any AI in futurecoder. The course builds sequencing and debugging skills. Students write steps in order and fix what breaks.

## Privacy and safety
The site is always online and code runs in the browser. The materials do not state which accounts students need or what data is collected. The research found no privacy policy. The project repository contains Firebase configuration files. Progress may be stored in a cloud database, but this was not confirmed. A teacher should open the site and check how progress is saved. A teacher should also check for terms before students use it.

## Ideas by subject
### computer_science
1. Write a first line of Python that prints a message.
2. Use the debugger to follow how a loop runs.
3. Fix an error and read the friendly message.
4. Solve a Parsons problem by ordering lines of code.
5. Write a short program that asks for a name and replies.
