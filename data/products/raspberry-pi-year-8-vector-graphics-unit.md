## Overview
This is a six-lesson Key Stage 3 unit for Year 8, ages 12-13. Learners design graphics with vector editing software. The lessons are tailored to Inkscape, which is open source and cross-platform. They cover shapes, paths, an open project, and how vector images are stored as SVG markup. The page is part of the archived curriculum.

## Benefits for students
- Students build icons and images from shapes and paths.
- Students see how an image is stored as SVG markup.
- Students finish with a showcase of their own work.

## Benefits for teachers
- The unit includes an overview, a rubric, and a summative assessment.
- Lesson plans and slides are available after login.
- Teachers can use other vector editors with the unit.

## Benefits for schools
- The unit and Inkscape are free.
- Inkscape runs on Windows, macOS, and Linux.
- IT will likely need to install Inkscape.

## Where is the AI?
The unit has no AI. It builds an AI-related skill, which is understanding how data describes an image. Students see that a picture can be stored as text and numbers. That idea helps them think about how computers represent information.

## Privacy and safety
An account is optional and is used to download the lesson plans. The internet is used only at setup. Student work stays on the computer. A teacher should check the curriculum site's terms for the teacher login.

## Ideas by subject
### visual_arts
1. Design an icon from basic shapes, as in the Get into shapes lesson.
2. Join shapes into new forms with path tools.
3. Create a set of icons that share one style.
4. Choose a topic for an open project and plan it with a sketch.
5. Present a finished design at the showcase and explain your choices.

### computer_science
1. Open an SVG file in a text editor and find a shape in the markup.
2. Change a number in the markup and describe what happens.
3. Compare a vector image with a photo and list how they are stored.
4. Zoom into both and explain what you see.
5. Write the markup for a simple rectangle by hand.
