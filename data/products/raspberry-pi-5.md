## Overview
The Raspberry Pi 5 is a single board computer with a 2.4GHz quad-core Arm Cortex-A76 processor and 1GB to 16GB of RAM. It has USB ports, Gigabit Ethernet, Wi-Fi, Bluetooth, dual 4K HDMI outputs, a 40-pin GPIO header, and camera and display connectors. It runs Raspberry Pi OS. Students use it as a desktop or as the brain of electronics projects.

## Benefits for students
- Students use a fast computer for programming and projects.
- Students connect cameras, displays, and sensors.
- Students learn how real hardware fits together.

## Benefits for teachers
- The board supports many project types.
- Teachers need to buy extra parts.
- Power supply mismatch is a common issue.

## Benefits for schools
- The product page showed USD 305 for the 16GB model and no price for smaller ones.
- Each unit needs a 27W USB-C power supply, a microSD card, a micro HDMI cable, and a display.
- A case or cooler is also needed.

## Getting started
- [ ] Get the Raspberry Pi 5 from a Raspberry Pi reseller.
- [ ] Buy the 27W power supply, a microSD card, and a micro HDMI cable.
- [ ] Buy a Pi 5 case or active cooler. The Pi 4 case does not fit.
- [ ] Flash Raspberry Pi OS to the microSD card with Raspberry Pi Imager.
- [ ] Insert the card and connect the keyboard, mouse, monitor, and power.
- [ ] Boot the board and set a strong password for the user account.
- [ ] Run a first Python script to check that everything works.

## Where is the AI?
The Raspberry Pi 5 has no AI. It builds an AI-related skill, which is working with sensors. Students connect parts and write code that reads and controls them. That practice shows how computers sense and respond.

## Privacy and safety
No account is needed. The board runs software locally, and the maker collects no usage data from it. Data lives on the microSD card unless a teacher adds networked services. The internet is needed to update the system or install packages. The Raspberry Pi privacy policy does not address children or school accounts. A teacher should set a strong password and review wiring rules. A teacher should also check that students use the right power supply.
