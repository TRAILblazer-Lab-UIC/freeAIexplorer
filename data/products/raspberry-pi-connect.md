## Overview
Raspberry Pi Connect is a remote access service. A user reaches a Raspberry Pi through a web browser at connect.raspberrypi.com. It offers screen sharing, a remote shell, and remote updates through a client on the Pi. A school use case in the announcement is students developing software remotely on a set of Pis.

## Benefits for students
- Students can work on a Pi from another computer.
- Students use a browser for screen sharing and a remote shell.
- Students can reach their code from home.

## Benefits for teachers
- Connect for Organisations adds roles, device tags, an audit log, and a management API.
- Optional two-factor authentication is available.
- Teachers can update many Pis from one place.

## Benefits for schools
- A free personal account covers one user.
- Connect for Organisations is reported at USD 0.50 per device per month with a four week free trial, per a search snippet.
- The Pi and the viewing browser both need internet.

## Getting started
- [ ] Find Raspberry Pi Connect at connect.raspberrypi.com and read the setup page.
- [ ] Ask IT and school leaders to review the privacy terms before linking student Pis.
- [ ] Create a Raspberry Pi ID.
- [ ] Sign in on a Pi that runs Raspberry Pi OS Bookworm or later.
- [ ] Link the device and open connect.raspberrypi.com.
- [ ] Create an organisation account for a class set of Pis.
- [ ] Turn on required two-factor authentication for the organisation.

## Where is the AI?
Raspberry Pi Connect has no AI. It builds an AI-related skill, which is working with remote systems. Students learn that code can run on one machine while they control it from another. That practice helps them understand cloud services.

## Privacy and safety
An account tied to a Raspberry Pi ID is required, and the internet is needed at all times. The privacy policy says Connect collects device metadata, connection logs, and account configuration. Connection metadata may be kept to route traffic through a relay. Session metadata may be kept for operations and security auditing. The documentation says sessions are encrypted end to end. The policy does not address children or school accounts. A teacher should decide who owns the accounts and who can see each Pi.
