## Overview
Ren'Py is an open source visual novel engine that combines text, images, and sound into interactive stories. It uses an easy script language and Python for more complex games. It supports visual novels and life simulation games. Projects can run on Windows, macOS, Linux, Android, iOS, and HTML5 in beta.

## Benefits for students
- Students write branching stories with pictures and sound.
- Students learn a simple script language and then add Python.
- Students can export their games to many devices.

## Benefits for teachers
- Documentation is available in English, Japanese, and Chinese.
- Over 8,000 works have been made with it.
- No documented school use was found.

## Benefits for schools
- The software is free, including commercial use.
- It runs on Windows 10 and later, macOS 10.13 and later, and Linux.
- IT will likely need to install it.

## Getting started
- [ ] Download the SDK from renpy.org.
- [ ] Ask IT to approve the install on managed computers.
- [ ] Unzip the SDK and run the launcher.
- [ ] Create a new project from the launcher.
- [ ] Write a short scene with two choices.
- [ ] Add one background image and one sound.
- [ ] Check Chromebook support before class. It was not confirmed.

## Where is the AI?
Ren'Py has no AI. It builds an AI-related skill, which is logic. Students design branches in which each choice leads to a new scene. That practice shows how a program follows rules.

## Privacy and safety
No account is needed, and the internet is used at setup. The engine runs locally and no privacy policy was found. Games that students export and publish could contact the internet, depending on what they build. A teacher should review stories and images before students share them. A teacher should also check the rights to any art or sound that students add.

## Ideas by subject
### ela
1. Write a short branching story with two endings.
2. Plan the choices on paper as a map before you code them.
3. Write dialogue that shows each character's voice.
4. Add images and sound that fit the mood.
5. Trade games with a partner and write a note on the story.

### computer_science
1. Use the script language to show a line of dialogue and a menu of choices.
2. Store a variable that tracks a choice and use it later in the story.
3. Add a few lines of Python to keep a score.
4. Fix a broken script by reading the error message.
5. Export a game and test it on a second device.
