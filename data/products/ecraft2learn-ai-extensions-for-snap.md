## Overview
This is a set of AI libraries for the Snap! block programming environment. It was built so children and non-expert programmers can make AI programs. The libraries cover speaking, listening, seeing, words, neural nets, nearest neighbors, and style transfer. Students drag blocks to build programs that talk, listen, and recognize images.

## Benefits for students
- Students build AI programs with blocks and need no typed code.
- Students use a camera and microphone to train and test their own ideas.
- Students work with speech blocks in more than 100 languages.

## Benefits for teachers
- Each library has an example project.
- Chapter guides exist for teachers.
- Documented studies used the blocks with ages 7 to 17.

## Benefits for schools
- The software is free to use.
- It runs in a web browser and needs no install.
- Some blocks call cloud services such as OpenAI, AI21, and Cohere. Those services need API keys that may cost money.

## Getting started
- [ ] Open the eCraft2Learn AI page in a web browser.
- [ ] Read the chapter guides for teachers.
- [ ] Import one library or sample project into Snap!.
- [ ] Test the camera and microphone on the classroom computer.
- [ ] Use a computer with a GPU for the vision and machine learning demos.
- [ ] Register API keys only for the cloud blocks you plan to use.
- [ ] Keep API keys away from students and store them in a safe place.

## Where is the AI?
The AI is a mix of blocks. Many run in the browser on the local computer, and some call vendor cloud services. The blocks handle speech output, speech recognition, image recognition, neural net training, word embeddings, and style transfer. Students snap these blocks into their own programs to make a project respond to a voice or a picture.

## Privacy and safety
The tool needs the internet at all times, and the site has no privacy section. The materials do not say whether accounts are needed or what student data is collected. Blocks that use cloud services send content to those companies, and the site does not list which blocks work offline. A teacher should check which blocks call a cloud service before students use a camera or microphone.
