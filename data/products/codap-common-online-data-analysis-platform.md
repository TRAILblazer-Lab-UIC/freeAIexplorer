## Overview
CODAP is a free data science web app from the Concord Consortium. Students drag data onto a canvas and build graphs, tables, and maps by dragging. Selections stay linked across every view. The site says it is designed for grades 5 to 14 in any subject.

## Benefits for students
- Students explore data by dragging, with no formulas to type.
- Students see a selection light up in the graph, table, and map at once.
- Students can bring in their own data from files, spreadsheets, or URLs.

## Benefits for teachers
- Plugins bring in census, weather, and sensor data.
- Teachers can link to shared documents for a class to open.
- The tool fits math, science, and social studies.

## Benefits for schools
- CODAP is free and needs no account.
- It runs in a modern web browser on Chromebooks, Windows, Mac, and Linux.
- Students can save to the local device or to an optional Google Drive.

## Getting started
- [ ] Open codap.concord.org in a web browser.
- [ ] Load the site online once. The notes say this is needed before offline mode.
- [ ] Drop in a small data file or paste data from a spreadsheet.
- [ ] Drag an attribute onto a graph and watch it update.
- [ ] Try a plugin for census, weather, or sensor data.
- [ ] Save a document to the device.
- [ ] Choose a shared link only after reading where Concord stores shared documents.

## Where is the AI?
This tool has no AI. It helps students handle data and spot patterns in graphs. Students decide what to plot and what the pattern means.

## Privacy and safety
No account is needed, and the internet is needed throughout. The policy says Concord collects no personal information in this mode. Documents save to the local device, and saving to Google Drive falls under Google's policy. A document shared by link is stored on Concord's server with no user information attached. The policy does not mention analytics, COPPA, or FERPA. A teacher should check that shared data sets hold no student names.

## Ideas by subject
### math
1. Drag a data set onto a graph and describe the shape of the data.
2. Compare the mean and median of a data set and explain the gap.
3. Build a scatter plot of two measures and describe the trend.
4. Collect class data on arm span and height and graph it.
5. Filter a data set to a group and see how the graph changes.

### science
1. Import weather data with a plugin and graph the temperature over time.
2. Collect sensor readings from an experiment and plot them.
3. Compare two groups from an experiment and describe the difference.
4. Look for a pattern in rainfall data and write a claim with evidence.
5. Select points on a graph and find the same rows in the table.

### social_studies
1. Load census data and map population by area.
2. Compare two regions with a graph and write a short summary.
3. Graph a change over decades and describe the trend.
4. Sort a data table by one attribute and note what stands out.
5. Pose a question about a community and choose the data to answer it.
