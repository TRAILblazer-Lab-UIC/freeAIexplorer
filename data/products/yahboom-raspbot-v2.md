## Overview
Raspbot V2 is a Mecanum wheel robot car for Raspberry Pi 5 sold by Yahboom. Tutorials cover motor control, line tracking, ultrasonic obstacle avoidance, OpenCV, MediaPipe, and basic ROS2. It has a 2DOF camera gimbal. Yahboom positions it for beginners and STEM classrooms.

## Benefits for students
- Students drive a robot that moves in any direction.
- Students code vision tasks such as color and face recognition.
- Students control the car from a phone app or JupyterLab.

## Benefits for teachers
- Tutorials in Python, OpenCV, MediaPipe, and ROS2 Humble are provided.
- A code repository supports the course.
- Independent reviews are thin. Teachers should try it first.

## Benefits for schools
- Search snippets show versions near 336 USD and 562 USD at one retailer. Boards are sold separately in some listings.
- The code is open source.
- The GitHub repo was last pushed in August 2025. The maintenance label may lag.

## Where is the AI?
The car can recognize QR codes, colors, faces, and license plates with OpenCV and MediaPipe. Yahboom says only the Superior version supports AI large model and voice interaction. The vendor does not say where that part runs. Students write Python code that uses what the camera sees.

## Privacy and safety
No account is needed and the internet is used at setup. The vision tutorials run on the Raspberry Pi. The large model feature on the Superior version may call an outside service, but no page read documents this. The Yahboom store policy covers customers only and does not address children. A teacher should check the phone app permissions and review the Superior version's AI features before enabling them.

## Ideas by subject
### computer_science
1. Run the line tracking tutorial and change the speed in the code.
2. Detect a colored card with OpenCV and make the car follow it.
3. Test face recognition and record when it makes mistakes.
4. Edit a JupyterLab notebook to change how the car responds.
5. Write the steps the car follows to avoid an obstacle.

### engineering
1. Assemble the chassis and test each Mecanum wheel.
2. Drive sideways and diagonally and record how the car moves.
3. Set up a course and tune the obstacle distance.
4. Test the camera gimbal angles for the best view.
5. Write a build log that another class could follow.
