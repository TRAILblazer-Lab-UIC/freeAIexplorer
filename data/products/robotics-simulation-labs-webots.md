## Overview
This is a set of nine sequential labs plus a bonus robot soccer challenge for the Webots simulator and Python. The labs target an introductory course on wheeled mobile robots for electrical engineering students. Topics include line following, odometry, PID go-to-goal, trajectory tracking and Dijkstra path planning. Templates and solutions are provided. The labs were written to replace practical sessions during COVID-19 restrictions.

## Benefits for students
- Advanced students work on real robotics topics.
- Students write Python in a simulator.
- Students can read Jupyter notebooks without Webots.

## Benefits for teachers
- Templates and solutions are provided.
- Lab 1 covers setup.
- The labs run in sequence.

## Benefits for schools
- The labs are free and Webots is open source.
- No robots need to be bought.
- IT must install Webots R2022a or later and Python 3.

## Getting started
- [ ] Find the labs on GitHub and read Lab 1.

- [ ] Plan which labs fit your course.

## Where is the AI?
The labs have no AI. They build skills in text coding, control and path planning. Students write Python that steers a simulated robot.

## Privacy and safety
Webots and Python run on the local computer according to the project repository. The materials do not state whether accounts or the internet are needed. They also do not state what data is collected. The research did not find a privacy policy. A teacher should check that the university level of the labs fits the class before use.

## Ideas by subject
### engineering
1. Follow Lab 1 to set up the Webots robot simulator.
2. Build a line follower and record how well it tracks.
3. Measure how far the robot drives with odometry.
4. Tune a PID go-to-goal and compare settings.
5. Plan a path with Dijkstra's method on a small map.

### computer_science
1. Write a Python state machine for the robot.
2. Read the Jupyter notebook for a lab and explain each part.
3. Use a loop to read sensor data.
4. Compare your code with the provided solution.
5. Take on the bonus robot soccer challenge in a team.
