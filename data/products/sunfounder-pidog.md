## Overview
PiDog is a Raspberry Pi robot dog with 12 servos, a camera, an ultrasonic sensor, touch sensors, a sound direction sensor, and an IMU. Its documentation has a Python track and an AI section. The AI section covers offline Vosk speech recognition, local Ollama chat, and online LLMs. It is a hobbyist and maker kit for older students.

## Benefits for students
- Students build a four-legged robot and bring it to life with code.
- Students try offline speech recognition and local chat.
- Students use many sensors in one project.

## Benefits for teachers
- The documentation offers a Python track and an AI track.
- The robot supports app control for demonstrations.
- The docs are written for makers. Teachers should expect a learning curve.

## Benefits for schools
- The kit is listed at 179.99 USD without the Raspberry Pi.
- The standard version supports Pi 3B+, 4B, and Zero 2W. The V2 supports Pi 3, 4, 5, and Zero 2W.
- Batteries may not ship internationally. IT should plan ahead.

## Getting started
- [ ] Find the PiDog kit and its documentation on the SunFounder site.
- [ ] Choose a supported Raspberry Pi. The standard version does not work with the Pi 5.
- [ ] Plan for batteries, which may not ship internationally.
- [ ] Assemble the dog and calibrate the servos.
- [ ] Install the modules on the Pi.
- [ ] Run the demos one at a time.
- [ ] Use the offline Vosk and Ollama options first and leave online LLMs off.

## Where is the AI?
The AI includes speech recognition, text to speech, LLM chat, and voice and video recognition. Vosk and Ollama run on the Pi itself. Online LLMs run in a company's cloud. Students write Python code to connect a voice or chat tool to the dog's movements.

## Privacy and safety
No account is needed and the internet is used at setup. Vosk and Ollama run offline on the Pi. Online options such as OpenAI text to speech and online LLMs send data to those providers when enabled. The docs do not state internet needs directly. The SunFounder privacy policy covers the website and orders and does not mention kits or children. A teacher should keep the online features off and tell students when the microphone and camera are active.

## Ideas by subject
### computer_science
1. Write Python code that makes the dog sit, stand, and wave.
2. Use the touch sensor to trigger a movement and explain the logic.
3. Try offline speech recognition and record which words it hears correctly.
4. Run a local chat model and compare its answers with a trusted source.
5. Plan a voice command routine for the dog and write its steps in order.

### engineering
1. Assemble the 12 servos and test each leg movement.
2. Calibrate the servos and record the settings.
3. Test the ultrasonic sensor and set a safe stopping distance.
4. Compare walking speed on two floor surfaces.
5. Write a troubleshooting guide for common build problems.
