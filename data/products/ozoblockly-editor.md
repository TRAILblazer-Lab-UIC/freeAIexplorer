## Overview
OzoBlockly is Ozobot's browser-based block coding tool, built on Google's Blockly. It has five skill levels from beginner to master. The Ozobot Editor supports Evo, Ari, and ORA. The store page says Ari supports Python and an AI block that uses a large language model. The tool lists K-12.

## Benefits for students
- Students code with blocks in five steps of growing skill.
- Students see their code run on a real robot.
- Students on Ari can try Python.

## Benefits for teachers
- The editor is free.
- Ozobot Classroom provides lessons.
- No student account is needed, per the FAQ.

## Benefits for schools
- The editor is free. A robot is needed to run programs.
- It runs in a modern browser, and IT has little to install.
- The editor needs the internet at all times.

## Getting started
- [ ] Open the OzoBlockly editor in a modern browser.
- [ ] Charge an Ozobot robot.
- [ ] Pair an Evo by Bluetooth or connect an Ari by Wi-Fi.
- [ ] Pick the beginner level.
- [ ] Load a first program on the robot.
- [ ] Explore the Ozobot Classroom lessons.
- [ ] Check the AI block before you use it with students.

## Where is the AI?
AI is optional. The only AI listed is a block on Ari that uses a large language model. The vendor does not say where it runs. Without it, the editor has no AI, but students still build sequencing and logic skills with blocks.

## Privacy and safety
The editor needs no student account, per the FAQ, and it needs the internet at all times. The Ozobot privacy policy says it does not knowingly collect personal information from children under 13. That is a data rule and not a minimum age. The policy also says it does not sell personal information. The research did not read the separate AI privacy policy and could not confirm where the AI block sends data. A teacher should read both policies and check the AI block before student use.
