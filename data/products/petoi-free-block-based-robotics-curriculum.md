## Overview
Petoi offers a free project-based robotics curriculum for the Bittle robot dog. It uses Petoi Coding Blocks, a Scratch-like drag-and-drop environment, and the Skill Composer in the Petoi Desktop App. Topics run from robotics basics through servo control, sensors and creative projects. Lesson plans are included for teachers.

## Benefits for students
- Students program a robot dog with blocks.
- Students design robot skills visually with the Skill Composer.
- Students try projects with PIR, touch, light and infrared sensors.

## Benefits for teachers
- Lesson plans and video tutorials are included.
- The page covers K-12 and college.
- A University of Colorado Boulder team used the blocks in a grades 9-12 STEM academy.

## Benefits for schools
- The curriculum is free, but the robot must be bought.
- Bittle is 289 USD and Bittle X V2 is 319 USD on the page. A sensor pack is 44 USD.
- IT needs to install the Petoi Desktop App.

## Getting started
- [ ] Find the free curriculum on the Petoi site.
- [ ] Buy a Bittle and a sensor pack if you need one.
- [ ] Ask IT to install the Petoi Desktop App.
- [ ] Read the lesson plans for the first topic.
- [ ] Connect the robot to the app.
- [ ] Try the Coding Blocks with a simple move.
- [ ] Plan a class around one lesson.

## Where is the AI?
The vendor does not describe any AI. Students build sequencing and logic skills as they program the robot. They also learn how sensors feed a program.

## Privacy and safety
The materials do not state whether accounts or the internet are needed. They do not state what data is collected. No privacy policy was found. A teacher should check the Petoi app terms with IT before use. Reviews note short battery life and calibration issues. Plan time to charge and calibrate.

## Ideas by subject
### computer_science
1. Drag Coding Blocks to make Bittle walk and sit.
2. Use the Skill Composer to design a new move.
3. Add a sensor block so Bittle reacts to touch.
4. Use a loop to repeat a dance.
5. Present the program and explain each block.

### engineering
1. Test how servo angles change a Bittle pose.
2. Use the PIR sensor to build a motion greeter.
3. Calibrate the robot and record what changed.
4. Design a trick with the light sensor.
5. Document a creative project and share it.
