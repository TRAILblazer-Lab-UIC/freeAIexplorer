## Overview
These are public Scratch class pages made by teachers who combine world language learning with coding. The linked page is a class called 702 LOTE, a Language Other Than English course. Students learn Spanish and use coding to show what they know. No single curriculum was found. The pages serve as examples.

## Benefits for students
- Students practice vocabulary by building games and projects.
- Students use blocks to show what they know in a new language.
- Students see examples from other classes.

## Benefits for teachers
- The class pages are viewable without an account.
- Teachers can borrow ideas from Spanish and French examples.
- A teacher can request a Scratch Teacher Account to make a class.

## Benefits for schools
- Scratch is free.
- Students use a browser on a Chromebook or computer.
- Teacher accounts and student accounts may need approval from IT.

## Getting started
- [ ] Open the 702 LOTE class page on Scratch and look at the examples.
- [ ] Request a Scratch Teacher Account.
- [ ] Create a class and add students.
- [ ] Ask IT to approve student accounts.
- [ ] Choose a vocabulary list in Spanish or French.
- [ ] Ask students to build one small project with the vocabulary.

## Where is the AI?
These class pages have no AI. Scratch is a block coding tool. Students build sequencing and event skills as they program a vocabulary game.

## Privacy and safety
Viewing the class page needs no account. Joining a class needs Scratch accounts, and the Scratch usernames and projects are stored with the vendor. The internet is needed at all times. The research did not read the privacy policy. A teacher should check school rules before creating student accounts and should review public projects.

## Ideas by subject
### world_languages
1. Study the Spanish vocabulary projects in the 702 LOTE class and list the words shown.
2. Code a matching game in which a student picks the right Spanish word for a picture.
3. Build a project that says a vocabulary word aloud when a sprite is clicked.
4. Create a French vocabulary quiz with a score.
5. Present a vocabulary game to a partner and ask them to play it.

### computer_science
1. Build a project in which a sprite responds to a click, using an event block.
2. Use a variable to keep a score in a vocabulary game.
3. Use a loop to repeat a set of quiz questions.
4. Test a classmate's game and report one bug.
5. Remix a game by adding a new level.
