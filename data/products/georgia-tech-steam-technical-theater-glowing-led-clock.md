## Overview
This unit runs for 9 to 12 weeks in grades 9 to 12. Students build a glowing LED clock as a prop for the play These Shining Lives. They draw clock images in Vectr, test LED buttons, and help fabricate and finish the prop. The driving question asks how to bring engineering and coding into a theater production.

## Benefits for students
- Students join art, coding, and building in one project.
- Students code LED buttons on a micro:bit in MakeCode.
- Students see their work used in a real production.

## Benefits for teachers
- The lesson package is a ready plan for a full semester.
- Teachers need fabrication, CNC, and finishing skills.
- The unit links the theater and technology teachers in one project.

## Benefits for schools
- The costs are for parts and materials. No prices are listed.
- The unit needs woodworking tools and a CNC router.
- It builds a lasting prop for the school stage.

## Where is the AI?
This unit has no AI. It builds logic and sensor skills. Students code buttons and lights to respond to inputs. The code runs on the micro:bit and the tools run in a browser.

## Privacy and safety
No accounts are listed. The page names MakeCode and Vectr, which are web tools, and the research did not review their privacy policies. The micro:bit code runs on the device, but the web tools need the internet when students use them. The materials do not list any student data collection. A teacher should read the MakeCode and Vectr privacy terms and check how students save files. A teacher should also plan shop safety rules for the CNC router and woodworking tools.

## Ideas by subject
### theater_media
1. Design the look of a clock prop for These Shining Lives.
2. Build the clock for a school production and light it on stage.
3. Write a short note about how the prop supports the story.
4. Test the prop under stage lights and adjust the glow.
5. Present the finished prop to the cast and crew.

### engineering
1. Fabricate the clock face with a CNC router.
2. Test LED buttons and record which ones work.
3. Finish the prop and list each step in order.
4. Solve a wiring problem and explain the fix.
5. Improve a first design after a trial.

### computer_science
1. Code an LED button on a micro:bit in MakeCode.
2. Make the lights change in a repeating pattern.
3. Debug a program that lights the wrong button.
4. Add a second behavior triggered by a button press.
5. Explain the program to a classmate block by block.

### cte
1. Practice safe woodworking steps on a prop part.
2. Use CNC routing to cut a shape from a drawing.
3. Sand and finish a prop surface.
4. Make a materials list for the build.
5. Write a work plan that assigns tasks to the team.
