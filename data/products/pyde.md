## Overview
Pyde is a single-file Python IDE that runs entirely in the browser. It runs Python 3.12 through Pyodide with a CodeMirror editor. Students can draw with turtle graphics, make p5.js sketches, and solve Parsons puzzles. The README says it is built for teaching.

## Benefits for students
- Students write and run Python without installing anything.
- Students draw with turtle graphics and p5.js sketches.
- Students solve Parsons puzzles by putting lines of code in order.

## Benefits for teachers
- Teachers can share a Parsons puzzle as a link.
- Students can download and upload .py files.
- The editor auto-saves work in the browser.

## Benefits for schools
- The tool is free and needs no install or account.
- It works on Chromebooks, Windows, Mac, and Linux.
- Code runs inside the browser on the student's own device.

## Getting started
- [ ] Open the hosted Pyde page or download index.html from the Pyde repository.
- [ ] Open the page in a modern browser while online so the libraries load once.
- [ ] Run a short print program to test the editor.
- [ ] Try a turtle graphics example on the canvas.
- [ ] Make a Parsons puzzle and copy its share link.
- [ ] Show students how to download their .py file to keep a copy.
- [ ] Remind students that auto-save lives in that browser only.

## Where is the AI?
Pyde has no AI. It builds an AI-related skill, which is sequencing. Parsons puzzles ask students to put lines of code in the right order. That skill helps them read and plan any program.

## Privacy and safety
No account is needed. Code runs in the browser and stays on the device. Work is saved in browser local storage, and shared programs are encoded in the page address. The page loads p5.js from a CDN when needed. That third party server sees the request. The research did not confirm where the Pyodide files come from. The README states there is no server and no backend, and no analytics were mentioned. The only source found is the project repository. A teacher should test the page before class.
