## Overview
This activity series is part of the TADA! curriculum from the Washington State School for the Blind. Learners write OpenSCAD code to build precise 2D shapes, combine them, and move, rotate, and mirror them. Designs are exported as SVG files for tactile printing. The page labels the series Advanced and does not state a grade range.

## Benefits for students
- Students write code to make exact shapes and learn how geometry moves.
- Students practice translate, rotate, and mirror moves.
- Students can print their designs for touch.

## Benefits for teachers
- A school for the blind designed the activities for tactile math.
- The page links to a programming book and a 27 video tutorial playlist.
- Tinkercad is offered as a drag and drop option for teachers who prefer it.

## Benefits for schools
- The activity pages and OpenSCAD are free.
- Tablets, iPads, and Chromebooks are not supported. OpenSCAD runs on Windows, Mac, or Linux.
- A tactile printer or a 3D printer is needed, and the companion books cost extra.

## Getting started
- [ ] Find the TADA! OpenSCAD activities on the Washington State School for the Blind site.
- [ ] Ask IT to install OpenSCAD on a Windows, Mac, or Linux computer.
- [ ] Watch the video introduction.
- [ ] Work through Section A, Making 2D Shapes in OpenSCAD.
- [ ] Confirm that you have access to a tactile printer or 3D printer.
- [ ] Export a shape as an SVG file and test a print.
- [ ] Look at the Tinkercad option as an alternative.

## Where is the AI?
The activities have no AI. Students write OpenSCAD text code that draws shapes. They build the skill of precise instructions and logic.

## Privacy and safety
The page mentions no accounts or data collection. It does not state which tools need the internet. The research did not read the TADA! site privacy terms. OpenSCAD is described as a free program that runs on the computer. Tinkercad is offered as a visual option. Check the privacy terms of Tinkercad before students use it.

## Ideas by subject
### math
1. Write code for a square and change its side length.
2. Use translate, rotate, and mirror to move a shape and describe the result.
3. Combine two shapes to make a new shape and name its parts.
4. Build a shape that has a line of symmetry and prove it with the mirror move.
5. Print a shape and explain its properties by touch.

### special_ed
1. Print a tactile shape and trace its edges with your fingers.
2. Compare two printed shapes and describe how they differ.
3. Work with a partner to plan a shape in words before you code it.
4. Describe a printed design to a classmate.
5. Choose a shape for a tactile math poster.

### computer_science
1. Write OpenSCAD code for a 2D shape and read it back line by line.
2. Find a typing mistake that stops a shape from drawing.
3. Reuse a code block to make a pattern.
4. Compare the code view with the Tinkercad view of the same shape.
5. Explain what each line of your program does.

### engineering
1. Design a shape for a tactile map and export it as SVG.
2. Test a printed shape for clarity and fix the design.
3. Choose line widths that are easy to feel.
4. Plan the steps from code to print.
5. Present your design process to the class.
