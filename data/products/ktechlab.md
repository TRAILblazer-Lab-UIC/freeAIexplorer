## Overview
KTechlab is an IDE for microcontrollers and electronics. It has a visual circuit editor, simulation with an oscilloscope and probes, and a built-in debugger. PIC logic can be written in assembly, Microbe, C or visual FlowCode. It can upload assembly to a PIC through a hardware programmer. The KDE page lists installation only for Linux.

## Benefits for students
- Students draw a circuit and watch it run in the simulator.
- Students read signals with an oscilloscope and probes.
- Students write PIC code in FlowCode, C or assembly.

## Benefits for teachers
- The simulator lets students test a circuit before they wire one.
- The built-in debugger helps students find mistakes.
- The program is free and open source.

## Benefits for schools
- KTechlab costs nothing.
- It needs a Linux computer and IT help.
- A hardware programmer is needed only to upload to a physical PIC.

## Getting started
- [ ] Find KTechlab on the KDE site.
- [ ] Ask IT to install it from the distribution package manager or Discover on a Linux computer.
- [ ] Open the circuit editor.
- [ ] Build a simple circuit with a battery and an LED.
- [ ] Run the simulation.
- [ ] Add the oscilloscope to read a signal.
- [ ] Buy a hardware programmer only if students will upload to a real PIC.

## Where is the AI?
KTechlab has no AI. It simulates circuits and runs the code that students write. Students build skills in logic and sensors by tracing how a signal moves through a circuit.

## Privacy and safety
No account is needed, and the internet is used for setup. The research reviewed no privacy policy, and the behavior is inferred from the app type and not stated by the page. A teacher should know that PIC chips are older microcontrollers. The last tagged release is from 2020, and no independent classroom use was found.

## Ideas by subject
### engineering
1. Build a simple LED circuit and run the simulator.
2. Add a resistor and observe how the circuit changes.
3. Use the oscilloscope to read a signal and sketch the result.
4. Place a probe in a circuit and explain the reading.
5. Compare a simulated circuit with a real one on a breadboard.

### computer_science
1. Build a FlowCode program that blinks an LED.
2. Convert the same task into a short Microbe program.
3. Use the debugger to step through a program.
4. Change a delay value and describe the result.
5. Write a plan for a traffic light and then code it.
