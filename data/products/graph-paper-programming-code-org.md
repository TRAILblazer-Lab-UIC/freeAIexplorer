## Overview
This is an unplugged lesson in Code.org's CS Fundamentals Course D. Students write instructions for a partner to draw a picture on a 4x4 grid. It introduces algorithms and programs through pixel-style drawing. The core lesson runs about 55 minutes with an optional 10-minute assessment.

## Benefits for students
- Students learn what an algorithm and a program are.
- Students see how exact instructions must be.
- Students prepare for later programming and debugging lessons.

## Benefits for teachers
- The lesson includes a worksheet, an assessment, and an unplugged video.

This lesson has no AI. Students write a list of exact steps for a partner to follow. They build sequencing skills.

## Ideas by subject
### computer_science
1. Write a set of commands for a partner to draw a simple shape on a 4x4 grid.
2. Follow a partner's commands and compare the result with the plan.
3. Find the command that caused a wrong drawing and fix it.
4. Shorten a program by using fewer commands.
5. Explain the difference between an algorithm and a program in your own words.

### visual_arts
1. Plan a pixel picture on a 4x4 grid.
2. Color the squares to make a simple design.
3. Describe your design to a partner with commands only.
4. Compare your drawing with your partner's drawing of it.
5. Display the pictures and talk about the patterns.
