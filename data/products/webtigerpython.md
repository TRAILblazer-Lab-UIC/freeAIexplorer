## Overview
WebTigerPython is a browser based Python IDE for K-12 education from ETH Zurich. It runs Python 3.11 in the browser using Pyodide. Students need no local software. Code can be exported as MicroPython or sent over WebUSB to micro:bit and Calliope mini boards and to Maqueen and Calli:bot robots. No sign-up or login is required.

## Benefits for students
- Students write Python in a browser with no install.
- Students draw with turtle graphics and plot with matplotlib.
- Students can send code to a micro:bit or robot.

## Benefits for teachers
- Teachers can share programs by encoding the code in the URL.
- The paper says it works with existing Swiss textbooks.
- Setup takes minutes.

## Benefits for schools
- The editor is free.
- It runs on Chromebooks, Windows, Mac, and Linux.
- No IT work is needed.

## Getting started
- [ ] Find WebTigerPython in a modern browser.
- [ ] Run a first Python program.
- [ ] Try turtle graphics.
- [ ] Share a program through its URL.
- [ ] Use Chrome or Edge on a computer or Chromebook to send code to a board over WebUSB.
- [ ] Note that WebUSB does not work on iOS.
- [ ] Test a micro:bit or robot before class.

## Where is the AI?
WebTigerPython has no AI. The editor runs the Python that students write. Students build skills in logic and in reading and fixing code.

## Privacy and safety
No account or login is needed, and the internet is used to load the editor. Code runs in the browser. Shared programs are encoded in the link with no database. A teacher should tell students not to put personal details in code they share. The site has a privacy statement that mentions data collection, cookies, and analytics, but its contents could not be read. The developers' paper reports counting about 500 users a day by IP address, which means some server logging exists. A teacher should read the privacy statement before use.
