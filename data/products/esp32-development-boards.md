## Overview
ESP32 is a family of Wi-Fi and Bluetooth microcontrollers made by Espressif Systems. Many companies sell development boards built on these chips. Students program them with a graphical tool called UIFlow, the Arduino IDE, or C with ESP-IDF. This entry covers the chip family and its education resources.

## Benefits for students
- Students build real devices with sensors, lights, and wireless links.
- Students can start with graphical programming and move to code.
- Optional libraries add voice and vision features.

## Benefits for teachers
- The Espressif education page links a teaching book, a study plan, and project courses.
- Several programming tools suit different skill levels.
- Teachers can pick boards from many makers.

## Benefits for schools
- Common boards cost about $5 to $15 by an estimate in the batch notes. The vendor page lists no prices.
- Programs run on the board with no account needed.
- IT must install tools and USB drivers, and the setup may take days.

## Getting started
- [ ] Find the Espressif education page and read the study plan.
- [ ] Buy one board and a USB cable.
- [ ] Install the Arduino IDE with ESP32 board support.
- [ ] Install USB drivers if the computer does not see the board.
- [ ] Upload a simple blink sketch over USB.
- [ ] Try UIFlow if you buy an M5Stack kit.
- [ ] Add one sensor and read its values.

## Where is the AI?
The AI is optional. Espressif offers libraries for voice recognition, vision, and deep learning that run on the board. Students can add these libraries to a project to make a device that hears a word or sees an object. The base boards work with no AI.

## Privacy and safety
No account is needed and the internet is used to install tools such as board support packages. The board runs the uploaded program locally. Data leaves the device only if a project uses Wi-Fi or Bluetooth services chosen by the programmer. The research did not review a privacy policy for the hardware. A teacher should check any project that uses Wi-Fi or Bluetooth and see where it sends data.

## Ideas by subject
### computer_science
1. Write a program that blinks a light in a pattern.
2. Read a sensor and print the values to the screen.
3. Build a program that makes a decision from a sensor reading.
4. Compare block programming in UIFlow with typed code.
5. Follow a lesson from the Espressif study plan.

### engineering
1. Wire a sensor and a light to a board on a breadboard.
2. Design a small alarm that reacts to light or motion.
3. Test how far the Bluetooth signal reaches.
4. Document a build with a diagram and a parts list.
5. Improve a first design after testing it.
