## Overview
Flowgorithm is a free flowchart-based programming tool for Windows. Students build a flowchart, run it, and can translate it into source code in other languages. Wikipedia lists export to 19 languages, including Python, Java, JavaScript, C++, and C#. It was created at Sacramento State University and puts the algorithm ahead of language syntax.

## Benefits for students
- Students build a flowchart and run it.
- Students see their plan as code in another language.
- Students focus on the algorithm.

## Benefits for teachers
- It fits the early weeks of an introductory programming course per a search snippet.
- Export to many languages helps show how one plan becomes code.
- It is freeware.

## Benefits for schools
- It is free but not open source.
- It runs only on Windows. It does not run on Chromebooks and a Mac needs workarounds.
- IT approval may be needed for installation.

## Getting started
- [ ] Find the Flowgorithm developer site.
- [ ] Ask IT to approve installation.
- [ ] Download the Windows installer.
- [ ] Install it on one test computer.
- [ ] Build a short flowchart and run it.
- [ ] Export the flowchart to Python or Java.
- [ ] Roll out to other Windows computers.

## Where is the AI?
Flowgorithm has no AI. It builds sequencing and logic skills. Students plan the steps of a program and test them.

## Privacy and safety
No account is needed and flowcharts stay on the computer. The research did not read a privacy policy. The official site could not be fetched because of an expired certificate. The facts come from Wikipedia, search snippets, and sweep notes. The internet is used at setup to download the installer. A teacher should download Flowgorithm from a source IT trusts. A teacher should also check that students use Windows computers.
