## Overview
darktable is a free open source photography workflow application and raw developer. It offers non-destructive, scene-referred raw editing and a library for managing photo collections. It suits photography and art classes. Reviewers describe a steep learning curve.

## Benefits for students
- Students edit photos without changing the original file.
- Students learn how professional photographers process raw images.
- Students manage a collection of their own photos.

## Benefits for teachers
- The tool is a good fit for photography and art classes.
- It runs on Windows, Mac, and Linux.
- Reviewers suggest RawTherapee as a friendlier free option.

## Benefits for schools
- The software is free under GPL-3.0.
- No account is needed.
- Managed computers may need IT approval, and Chromebook support is not confirmed.

## Getting started
- [ ] Download darktable from darktable.org.
- [ ] Ask IT to approve the install on managed computers.
- [ ] Import a folder of sample photos.
- [ ] Try one basic edit and see that the original stays unchanged.
- [ ] Browse the library tools.
- [ ] Plan extra time. Reviewers say the learning curve is steep.
- [ ] Test RawTherapee if darktable feels too hard.

## Where is the AI?
This tool has no AI. It builds skills in data and pattern spotting. Students compare edits and read the image data that guides each choice.

## Privacy and safety
No account is needed. The program runs on the device, and photos are edited locally with originals left unmodified. The internet is needed for setup. The homepage does not mention telemetry or a privacy policy, and the research did not check the source code for telemetry. A teacher should check that students use only photos they have permission to edit.
