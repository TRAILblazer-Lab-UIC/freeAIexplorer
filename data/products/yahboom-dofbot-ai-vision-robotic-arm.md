## Overview
DOFBOT is a desktop robotic arm with five joints and a gripper. It is built around a camera and a Jetson Nano or other boards. CNX Software lists demos for gesture recognition, color interaction, visual positioning, garbage sorting, and face tracking built on OpenCV. Students in high school run it from Jupyter Lab with Python 3.

## Benefits for students
- Students program a real arm that sees with a camera.
- Students run demos such as gesture recognition and garbage sorting.
- Students read and change Python code in notebooks.

## Benefits for teachers
- Notebooks give a clear sequence of demos.
- Android and iOS apps offer a simple way to move the arm.
- Newer versions add large model and 3D depth camera features.

## Benefits for schools
- In 2023 CNX Software listed 289 dollars with a VGA camera and 481 dollars with a Jetson Nano.
- Newer versions cost more.
- The internet is needed only for setup, and IT will likely need to help flash the system image.

## Getting started
- [ ] Find the DOFBOT on the Yahboom store, which redirects to yahboom.store.
- [ ] Choose a version and confirm the board, with a Jetson Nano B01 recommended.
- [ ] Assemble the arm.
- [ ] Ask IT to flash the system image.
- [ ] Connect to the arm over the network.
- [ ] Open Jupyter Lab in a browser.
- [ ] Run the gesture recognition notebook first.

## Where is the AI?
The AI is a set of camera based vision programs built on OpenCV. They cover gesture recognition, face tracking, object sorting, and visual positioning. They run on the board in the arm. Students read the notebooks, change the code, and extend the demos with their own tasks.

## Privacy and safety
No account is needed and the internet is used only for setup. CNX Software says the original model processes data locally. Newer AI large model versions may use outside services, and the research did not check this. The materials do not say what student data is collected. A teacher should confirm which version the school buys. A teacher should also check where the camera points and set a clear work zone around the arm.

### computer_science
1. Run the color interaction demo and change the color it looks for.
2. Test the gesture recognition demo with five different hand signs.
3. Read a notebook and explain each step in plain words.
4. Change the sorting demo to sort a new group of objects.
5. Compare how face tracking works in bright and dim light.

2. Measure how far the arm can reach.
3. Test how the gripper holds objects of different shapes.
4. Design a small sorting table for the arm.
5. Adjust the camera position and compare results.
