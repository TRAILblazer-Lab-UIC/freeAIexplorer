## Overview
Intro to Computational Media with p5.js is a high school computer science curriculum from the NYC DOE CS4All academics team. Version 1.0 has five units, from drawing and variables through functions and abstraction. It also prepares students for AP Computer Science Principles. Students write p5.js code to draw, respond to the mouse, and animate.

## Benefits for students
- Students see their code produce pictures right away.
- Students build skills in variables, loops, arrays, and functions through creative projects.
- Students get a path toward AP Computer Science Principles.

## Benefits for teachers
- The curriculum includes teacher lessons, student worksheets, and projects.
- Teachers can pick from several editors, including Open Processing, CodePen, and Repl.it.
- An AP CSP companion guide is in draft.

## Benefits for schools
- The curriculum is free.
- It runs in a browser. The vendor lists no install.
- Version 2.0 is under construction and aims to match New York State computing standards.

## Getting started
- [ ] Open the GitBook curriculum for Intro to Computational Media.
- [ ] Read the unit list and pick the first unit, Drawing, Variables, Random.
- [ ] Follow the links to Peblio for the lessons and projects.
- [ ] Choose an editor for student code, such as Open Processing or CodePen.
- [ ] Ask students to create accounts only after checking the editor's rules.
- [ ] Try the first worksheet yourself before class.
- [ ] Save student sketches in the editor you chose.

## Where is the AI?
This curriculum has no AI. Students write code that follows exact steps. That builds the logic and sequencing skills that sit under every later AI topic.

## Privacy and safety
The curriculum page does not say whether Peblio or the other editors need accounts or where student work is stored. The answer depends on the editor a class picks. A local p5.js install may run without the internet, but that was not verified. No privacy policy was read. A teacher should read the privacy terms of the chosen editor and of Peblio before students sign in.

## Ideas by subject
### computer_science
1. Work through the Drawing, Variables, Random unit and write a sketch that draws shapes with variables.
2. Use loops and arrays to draw a repeating pattern, then change one value and describe the result.
3. Build a sketch that responds to the mouse, using the Respond and Draw unit.
4. Break a long sketch into functions and name each one clearly.
5. Pair up and review each other's code with a short checklist, using the AP CSP companion guide for ideas.

### visual_arts
1. Draw a self portrait from basic shapes and color variables.
2. Use random values to make a generative art piece and print the best result.
3. Animate a simple character that moves across the canvas, using the Motion and Animation unit.
4. Load an image or media file and change it with code.
5. Hold a class gallery where each student explains the code behind their artwork.
