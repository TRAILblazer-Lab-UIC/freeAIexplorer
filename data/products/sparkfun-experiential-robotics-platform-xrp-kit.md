## Overview
The XRP kit is a wheeled robot controlled by a Raspberry Pi RP2350B board with Wi-Fi and Bluetooth. It has two motors with encoders, an ultrasonic distance sensor, a line sensor, and a servo. Students assemble the robot and then code it over USB-C. SparkFun says it is programmed with Blockly, Python, and WPILib.

## Benefits for students
- Students build a real robot and then bring it to life with code.
- Students can start in Blockly and move to Python.
- Students use sensors to make the robot react to lines and distance.

## Benefits for teachers
- A free WPI curriculum comes through OpenSTEM and an Education Hub.
- Teachers can start students with blocks and grow into text code.
- The code editor runs in the browser on a computer.

## Benefits for schools
- SparkFun lists the kit at 119.95 USD.
- Educators and FIRST teams can request a discount account. The amount is not stated.
- The controller design is open source in KiCad and the plastic parts are in Onshape.

## Getting started
- [ ] Find the XRP kit on the SparkFun site.
- [ ] Request an Educator account for a discount.
- [ ] Gather batteries and a USB-C cable.
- [ ] Assemble the chassis with the build guide.
- [ ] Add the batteries and connect to a computer over USB-C.
- [ ] Open the code editor and run a first Blockly program.
- [ ] Open the XRP Education Hub and pick a first lesson.

## Where is the AI?
The XRP kit has no AI. The robot runs the code that students write and reads its sensors. Students build skills in sequencing, logic, and sensor data.

## Privacy and safety
No account is needed and the internet is used at setup. The XRP site links a privacy policy that the research did not read. The research did not confirm whether the code editor needs the internet or an account. The materials do not state what data the software collects. The robot has a Wi-Fi and Bluetooth board. A teacher should check the editor's privacy details and school network rules before students use it.

## Ideas by subject
### computer_science
1. Write a Blockly program that drives the robot in a square.
2. Convert a working Blockly program to Python and compare the two.
3. Use the line sensor to program the robot to follow a taped path.
4. Use the distance sensor to stop the robot before a wall.
5. Debug a classmate's program and explain the fix.

### engineering
1. Assemble the robot from the guide and test each motor and sensor.
2. Measure how far the robot travels in a set time and record the data.
3. Add a servo task such as pushing an object off a table.
4. Design a challenge course and test how well the robot handles it.
5. Compare the robot's real path to the path planned on paper.
