## Overview
Bitsbox is a coding site where children aged 6 to 12 type a modified version of JavaScript to build apps and games. Each level introduces a concept such as variables, functions, or loops. Teachers can buy printed project books with an educator guide. It also powers the STEMscopes Coding program from Accelerate Learning.

## Benefits for students
- Students type real code and see an app respond.
- Students meet one new idea at each level.
- Students can use printed project books away from the screen.

## Benefits for teachers
- Teachers can create student accounts in bulk from a CSV file.
- An educator guide comes with the printed project books.
- A free Hour of Code lesson called Yak Attack is available.

## Benefits for schools
- The Coding Project Book set of 10 books plus an educator guide costs 299.95 USD.
- STEMscopes Coding was listed in 2021 at 3.95 USD per student.
- The tool runs on the vendor cloud. IT may need to allow bitsbox.com and firebase.com.

## Getting started
- [ ] Try the free online sample apps at bitsbox.com.
- [ ] Choose a curriculum, then request a quote or order the books.
- [ ] Ask IT to allow bitsbox.com and firebase.com.
- [ ] Create student accounts in bulk from a CSV file.
- [ ] Review the data the vendor collects before students sign in.
- [ ] Run the Yak Attack Hour of Code lesson as a first class.
- [ ] Give students a project book and let them start at level one.

## Where is the AI?
Bitsbox has no AI. It builds the skill of writing instructions in order, which is sequencing. Students also learn logic through variables, functions, and loops.

## Privacy and safety
Student work goes to the vendor cloud and the internet is needed throughout. Accounts are optional. The vendor collects a parent email, child name, address for purchased products, username, password, birth date for age checks, and IP addresses. The children's privacy policy says Bitsbox follows COPPA and gets parental consent first. It says resellers and partners may collect information under their own policies. The main privacy page returned 404 and hosting location is not stated. A teacher should review this list with the school privacy lead before using student accounts.
