## Overview
py5 is a Python version of Processing for creative coding. Students write sketches that draw graphics and animations. It works in Jupyter notebooks or in a Python editor and connects to tools such as NumPy, Matplotlib, and Pillow. It suits older students who already know some Python.

## Benefits for students
- Students see their code turn into shapes and animations right away.
- Students use real Python tools that they can carry into other projects.
- Students can move on from Scratch with the Learn Python with py5 worksheets.

## Benefits for teachers
- The tool offers five sketch styles. Teachers can start simple and move up.
- Tutorials and reference documentation are available.
- Jupyter kernels let teachers run sketches in a notebook.

## Benefits for schools
- The software is free and open source.
- Student work stays on the local computer.
- The install needs Python and Java. IT will likely need to help.

## Getting started
- [ ] Find the py5 documentation site and read the install page.
- [ ] Ask IT to approve a Python install and a Java install on a test computer.
- [ ] Install Python 3.10 or newer.
- [ ] Install Java 17 or newer on a computer with a display.
- [ ] Run pip install py5 in a terminal.
- [ ] Add the optional Jupyter extras if you want notebooks.
- [ ] Run a first sketch that draws a circle.
- [ ] Try the Learn Python with py5 worksheets with one small group.

## Where is the AI?
py5 has no AI. It builds an AI-related skill, which is working with data in code. Students use NumPy and Matplotlib to turn numbers into pictures. That practice is a base for later data work.

## Privacy and safety
No account is needed. The internet is used for the pip install and the Java download. Sketches and files stay on the computer. No privacy policy was found. The tool is not a Chromebook app. A teacher should check that the school can install Python and Java on student machines.

## Ideas by subject
### computer_science
1. Work through a Learn Python with py5 worksheet that moves from Scratch to Python.
2. Write a sketch that draws a row of circles with a loop.
3. Change a variable and watch how the picture changes.
4. Use NumPy to make a list of numbers and draw each one as a bar.
5. Split a sketch into functions and explain what each function draws.

### visual_arts
1. Draw a simple scene with shapes and colors written in code.
2. Animate a shape across the screen and describe the motion.
3. Create a pattern of repeated shapes and change its color scheme.
4. Use Pillow to open an image and draw over it.
5. Design a small generative artwork and write a short artist statement.
