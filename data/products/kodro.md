## Overview
Kodro is an offline-first robot design and coding simulator. Students assemble a robot, program it in Python or blocks, and watch it run in a visual test world with live sensors. It includes 24 lessons mapped to the UK computing curriculum and a lesson authoring studio for teachers. The README lists ages 5 to 16.

## Benefits for students
- Students build and test a robot with no hardware.
- Students choose blocks or Python.
- Students watch live sensor readings as the robot runs.

## Benefits for teachers
- The scheme of work has 24 lessons.
- A lesson authoring studio lets teachers write their own.
- The simulator works in a browser with no install.

## Benefits for schools
- Kodro is free and the code is open.
- It needs the internet at first load only.
- IT has little to do for the browser version.

## Getting started
- [ ] Open the hosted Kodro app in a browser.
- [ ] Load it once while online.
- [ ] Check that it opens again offline.
- [ ] Build a first robot with students.
- [ ] Start the first of the 24 lessons.
- [ ] Ask IT about the Windows executable if you prefer it.
- [ ] Install Ollama only if you want the optional local AI assistant.

## Where is the AI?
The AI is optional. The assistant helps with coding questions and uses a local Ollama model. It runs on the school computer. Students can ask it for hints and then fix their own code.

## Privacy and safety
No account is needed, and the README states no mandatory network call for the core paths. The internet is needed at first load. The optional assistant talks only to an Ollama model on localhost. Cloud models are an explicit bring your own key connected mode. No formal privacy policy was found, and the project is very new. A teacher should keep the connected mode off. A teacher should also check that students use the assistant for hints and then write their own code.

## Ideas by subject
### computer_science
1. Start the first lesson in the scheme of work and program the robot to move forward.
2. Write the same program in blocks and in Python and compare them.
3. Use a sensor reading to make the robot stop before a wall.
4. Ask the optional assistant for a hint and explain the fix in your own words.
5. Write a new lesson in the authoring studio for a younger class.

### engineering
1. Assemble a robot from the parts list and test it in the world.
2. Move a sensor to a new spot and compare the readings.
3. Change the robot design to reach a goal faster.
4. Record test results in a simple table.
5. Explain which design change helped most.
