## Overview
This Programming Historian tutorial was published on 2021-12-04 by Gabi Kirilloff of Texas Christian University. Students build a six-passage text game called First Day in the Office using passages, links, and choices. They then add variables and conditionals, CSS styling, and images or sound. It uses Twine 2.3.12 with the Harlowe 3.2 format.

## Benefits for students
- Students build a playable text game step by step.
- Students learn variables and conditionals in a creative setting.
- Students add style, images, and sound.

## Benefits for teachers
- The tutorial is peer reviewed and detailed.
- It includes assignment ideas for history, composition, and other courses.
- Examples range from a grade 9 level project to college.

## Benefits for schools
- Twine and the tutorial are free.
- Twine runs in a browser and on Windows, Mac, Linux, and Chromebooks.
- IT has little to do. The desktop version is recommended for images and sound.

## Getting started
- [ ] Find the Programming Historian tutorial on interactive fiction with Twine.
- [ ] Open Twine in a browser or install the desktop version.
- [ ] Build the six-passage First Day in the Office game.
- [ ] Export stories to a file at the end of each session. Browser storage can be lost.
- [ ] Use the desktop version for images and sound.
- [ ] Pick an assignment idea for your course.
- [ ] Plan how students will save and share their files.

## Where is the AI?
This tutorial has no AI. It builds logic and writing skills. Students use variables and conditions to change a story based on choices. Twine runs in the browser or on the computer.

## Privacy and safety
The lesson text does not say whether Twine needs an account. The browser version stores work only in the browser cache. Students can lose it and should export with Publish to File. The author never requires students to publish games and cites the risk of online harassment. The research did not read a Twine privacy policy. A teacher should have students export their files and review stories before sharing them.

## Ideas by subject
### ela
1. Build the First Day in the Office game from the tutorial.
2. Write a new story with at least three passages and two choices.
3. Add a variable so earlier choices change later text.
4. Style a passage with CSS and describe the effect.
5. Trade stories with a partner and write feedback on each choice.

### social_studies
1. Build a game about a historical figure facing a hard choice.
2. Add a variable that tracks how the figure's reputation changes.
3. Include a source quote in a passage and cite it.
4. Make two endings that show different possible outcomes.
5. Present the game and explain what the history behind it shows.
