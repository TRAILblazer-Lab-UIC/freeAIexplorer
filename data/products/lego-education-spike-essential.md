## Overview
SPIKE Essential is a LEGO Education robotics set for younger students, built around a small hub. The SPIKE App offers block coding and interdisciplinary lessons. The product page marks the set as retired, with company sales ending June 30 2026. LEGO names LEGO Education Science and Computer Science and AI as replacements.

## Benefits for students
- Students build small models and code them with blocks.
- Students learn through playful lessons.
- Students save projects on the local device.

## Benefits for teachers
- Teacher resources stay available until June 30 2031.
- The SPIKE App gets bug fixes and compatibility updates through June 30 2031.
- The set is eligible for FIRST LEGO League through the 2027-2028 season.

## Benefits for schools
- The official page lists no price. The set is now resale only.
- New sets can no longer be bought from LEGO.
- Spare parts are stocked for two years after the last sale.

## Getting started
- [ ] Check the LEGO Education page for the retirement notice.
- [ ] Find a set through a resale source or use sets the school already owns.
- [ ] Install or open the SPIKE App on a Bluetooth capable device.
- [ ] Pair the hub.
- [ ] Open the SPIKE Essential lessons in Teacher Resources.
- [ ] Run the first lesson.
- [ ] Plan for the replacement lines before buying more.

## Where is the AI?
SPIKE Essential has no AI. The models follow the block code students write. Students build skills in sequencing and sensors.

## Privacy and safety
The SPIKE App privacy policy says the app needs no account or login. Written or coded work and voice recordings are stored only on the device. Anonymous app performance data may be gathered in some regions and can be turned off in Settings. The app reads the device IP address to reach LEGO servers for update checks and region. The policy does not mention COPPA. A teacher should check that the school devices support Bluetooth. A teacher should also note that the app gets no new features after June 30 2026.

## Ideas by subject
### computer_science
1. Code the hub to make a model move.
2. Use a repeat block to shorten a program.
3. Add a sensor block and test the response.
4. Fix a program that sends a model the wrong way.
5. Explain a block program to a partner.

### engineering
1. Build a small model from the lesson and test it.
2. Change one part and compare how the model works.
3. Sketch an improvement before building it.
4. Test a model against a goal and record the result.
5. Present a finished model and explain each part.

### math
1. Count wheel turns and use the number to estimate distance.
2. Measure how far a model travels and compare it with the prediction.
3. Use a timer block to measure how long a run takes.
4. Compare two programs by their results.
5. Graph the results of several runs.
