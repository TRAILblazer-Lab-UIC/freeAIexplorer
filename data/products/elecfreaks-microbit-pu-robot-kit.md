## Overview
The ELECFREAKS PU Robot is a desktop humanoid robot that walks, turns, kicks and dances. A second micro:bit works as a handheld controller. An ultrasonic sensor lets the robot detect obstacles. Students program it with Microsoft MakeCode blocks and can move on to JavaScript and Python. The retailer recommends it for ages 8 and up.

## Benefits for students
- Students program a robot that moves like a person.
- Students can start with blocks and later try JavaScript or Python.
- Students use a handheld controller to drive the robot.

## Benefits for teachers
- The kit works with the MakeCode editor in a browser.
- The ELECFREAKS wiki has a page for the PU Robot kit.
- The robot can serve as a demonstration for a whole class.

## Benefits for schools
- The product pages state no data transmission. The vendor policy covers website orders only.
- Core Electronics lists the robot at 260 AUD with GST. The two micro:bit V2 boards and batteries cost extra.
- The battery runs 20 to 30 minutes per charge. Plan for charging time.

## Getting started
- [ ] Buy the PU Robot kit from a retailer that carries ELECFREAKS products.
- [ ] Buy two micro:bit V2 boards. Version 1 boards do not work with the extension.
- [ ] Build or unpack the robot.
- [ ] Charge the 400 mAh battery by micro USB.
- [ ] Add 2 AAA batteries to the remote.
- [ ] Open the MakeCode editor in a browser and add the ELECFREAKS extension.
- [ ] Flash a first program over USB.

## Where is the AI?
The PU Robot has no AI. It follows the code that students write. Students build skills in sensors and logic by using the ultrasonic sensor to react to obstacles.

## Privacy and safety
No account is needed for the robot, and it runs programs on the micro:bit boards. The internet is used to open the MakeCode editor, which is a Microsoft web tool whose policy the research did not read. The ELECFREAKS policy dates from 2014 and covers website orders only. It does not mention children or product data. The product pages do not state any data transmission. A teacher should read the MakeCode privacy terms and check the batteries before students use the robot.

## Ideas by subject
### computer_science
1. Program the robot to walk forward and turn using MakeCode blocks.
2. Use the second micro:bit to send commands from a handheld controller.
3. Read the ultrasonic sensor and make the robot stop before an obstacle.
4. Convert a block program into JavaScript and compare the two views.
5. Write a dance routine as a list of steps and then code it.

### engineering
1. Test how far the robot walks in one charge and record the result.
2. Place an obstacle and measure the distance at which the robot reacts.
3. Compare walking on carpet and on a smooth floor.
4. Sketch an improvement to the robot and explain the reason for it.
5. Design a short obstacle course and tune the program to finish it.
