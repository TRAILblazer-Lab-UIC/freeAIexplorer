## Overview
Hedy is a free open source gradual programming language for classrooms. Learners start with very little syntax and add concepts level by level toward Python. It runs in the browser with no installation. The vendor lists ages 10 and up. Teachers can use built-in lesson plans and author custom lessons.

## Benefits for students
- Students start with simple commands and add more rules at each level.
- Students can use the interface in 47 languages.
- Students move toward real Python.

## Benefits for teachers
- Teacher accounts are free and allow classes.
- Built-in lesson plans are included.
- Teachers can write custom lessons.

## Benefits for schools
- The tool is free and open source.
- It runs in the browser and on Chromebooks.
- Offline Hedy runs on Windows, macOS, and Ubuntu for schools with weak internet.

## Getting started
- [ ] Open hedy.org in a web browser.
- [ ] Create a free teacher account.
- [ ] Set up a class and share the class link.
- [ ] Read the built-in lesson plans.
- [ ] Try Level 1 yourself before class.
- [ ] For offline use, ask IT to download Offline Hedy from the releases page.
- [ ] Choose between the individual host mode, where teachers cannot see work, and the single host mode, where they can.

## Where is the AI?
Hedy has no AI. It builds programming skills. Students learn syntax step by step and see how a program turns into Python. The online version runs in the browser and the vendor's cloud, and the offline version runs on a school host.

## Privacy and safety
The hosted site collects a username and may collect country, birth year, gender, email, project content including unshared projects, and usage data. Users under 16 must give a parent or guardian email. Data may be stored with providers in or outside the EEA, including the US. Deleting an account hides it, and full removal needs an email request. The policy does not describe teacher access, and the research found no COPPA or FERPA statement. Offline Hedy stores teacher, student, and submission data in a local file on the school host. A teacher should read the privacy policy and consider the offline build.
