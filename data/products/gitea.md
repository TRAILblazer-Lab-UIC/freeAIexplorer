## Overview
Gitea is a lightweight self-hosted Git service with pull requests, code review, issues, kanban boards, and built-in CI. A school runs it on its own server for student repositories. Computer science departments at the college level use it for assignments. It suits high school students in advanced coding courses.

## Benefits for students
- Students learn the same Git workflow that professional programmers use.
- Students practice pull requests and code review.
- Students keep their repositories on a school server.

## Benefits for teachers
- Teachers can hand out and collect assignments through repositories.
- A professor moved assignment distribution and submission to Gitea with a permissions group per class.
- Issues and kanban boards help teachers track project work.

## Benefits for schools
- The open source edition is MIT licensed with unlimited users and repositories.
- Gitea Enterprise is listed at $9.5 and $19 per user per month.
- Approved non-profit schools can apply for a no-cost Enterprise license for 12 months.

## Getting started
- [ ] Find Gitea on its official site and read the install guide.
- [ ] Ask IT to plan a server or virtual machine for it.
- [ ] Have IT install Gitea and set up a database such as SQLite, MySQL, or PostgreSQL.
- [ ] Change the default administrator password and review the sign-up settings.
- [ ] Create teacher and student accounts.
- [ ] Apply to the education program with a staff application if the school wants the Enterprise license.
- [ ] Test one sample repository with a few students first.

## Where is the AI?
Gitea has no AI. It builds version control and teamwork skills. Students track changes and review each other's code. It runs on a school server.

## Privacy and safety
Accounts are required. A school that hosts Gitea keeps accounts, repositories, issues, and commits on the server it runs. Gitea Cloud is a managed alternative that would place data with the vendor. The research did not read a Gitea privacy policy. The internet is needed at setup. A teacher should confirm with IT whether the school self-hosts, who can see student repositories, and how long they are kept. The education program is not automatic and gives community support only.
