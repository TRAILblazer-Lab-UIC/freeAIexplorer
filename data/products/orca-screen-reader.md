## Overview
Orca is a free open source screen reader for the Linux desktop. It reads the screen aloud, sends it to a braille display, or does both. It suits blind or low vision students who use Linux computers. It works with applications that support AT-SPI.

## Benefits for students
- Students can hear what is on the screen through speech.
- Students with a braille display can read the screen in braille.
- MathML support lets students read math on supported pages.

## Benefits for teachers
- Many Linux desktops include Orca already.
- A learn mode and a preferences dialog help teachers set it up.
- Teachers can adjust speech and braille options for each student.

## Benefits for schools
- The software is free and the code is open.
- It runs on the local computer and needs no internet.
- IT will likely need to help with Linux setup.

## Getting started
- [ ] Check whether your Linux distribution already includes Orca.
- [ ] Ask IT to confirm the desktop supports AT-SPI.
- [ ] Open the preferences dialog and pick a voice and speed.
- [ ] Use learn mode to practice the keys.
- [ ] Connect a braille display if the student has one. It is optional.
- [ ] The README describes a meson build from source for schools that need it.
- [ ] Let the student practice with a familiar application.

## Where is the AI?
The vendor does not describe any AI in Orca. It turns screen text into speech and braille using fixed rules. It helps students who are learning keyboard navigation and listening skills.

## Privacy and safety
No account is needed, and the internet is not needed. The program runs on the local computer. The README has no privacy statement. Where speech data goes depends on the speech engine the user configures. A teacher should check the speech engine setting and check that the chosen applications work well with Orca before a student depends on them.

## Ideas by subject
### special_ed
1. Practice reading a short web page with speech and describe what was easy to follow.
2. Navigate a document using only the keyboard and Orca.
3. Adjust the speech speed and pick the setting that works best.
4. Use learn mode to name the keys that move between windows.
5. Read a math page with MathML support and explain one equation aloud.
