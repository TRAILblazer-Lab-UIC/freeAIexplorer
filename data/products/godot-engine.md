## Overview
Godot is a free open-source game engine for 2D, 3D, and XR projects. Scripting is available in GDScript, C#, and C++. Games export to desktop, mobile, and web. The latest stable release is 4.7.2 from August 2026. It suits high school students who want to program games.

## Benefits for students
- Students build real games with a professional engine.
- Students learn GDScript, which looks like Python.
- Students can export games to share.

## Benefits for teachers
- A New Zealand Year 11 programming course built its Godot unit around Godot 4 tutorials.
- A resource called Godot Engine in the Classroom from KidsCanCode is available.
- Outschool lists intro classes for ages 11 to 16.

## Benefits for schools
- The software is free.
- It needs no installer. Teachers download it and run it.
- It runs offline on Windows, Mac, and Linux.

## Getting started
- [ ] Download the editor from godotengine.org.
- [ ] Ask IT to allow it on school computers.
- [ ] Unzip it and run it. It needs no installer.
- [ ] Follow a Godot 4 tutorial to make a first scene.
- [ ] Read the Godot Engine in the Classroom resource.
- [ ] Decide how students save and back up projects.
- [ ] Test one lesson on a student computer before class.

## Where is the AI?
Godot has no AI. It builds programming skills. Students write scripts that control characters and game rules. It runs on the local computer.

## Privacy and safety
No account is needed to use the editor. The internet is used for setup and for Asset Library requests. The privacy policy says the only personal data the editor collects comes from Asset Library requests, such as engine version, search query, selected assets, and IP address. It says these are not stored beyond abuse protection logs. The policy does not describe editor telemetry. Website accounts need a username and email. A teacher should check which version students use and decide whether students may use the Asset Library.

1. Follow a Godot 4 tutorial to build a simple platformer.
2. Write a GDScript function that moves a character with the arrow keys.
