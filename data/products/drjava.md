## Overview
DrJava is a lightweight Java development environment built at Rice University. It is designed for introductory programming courses. Students write, compile, and run Java programs in one simple window. The project site lists drjava-beta-2019-220051 as the current release.

## Benefits for students
- Students write and run Java in a simple editor.
- Students avoid a heavy toolset on their first programs.
- Students learn a text language used in many later courses.

## Benefits for teachers
- The tool is built for introductory programming courses.
- It comes as a single jar file that is easy to hand out.
- It costs nothing to use.

## Benefits for schools
- The software is free.
- It runs on the student's own computer and needs no accounts.
- IT must install a Java runtime. Search results say Java 8 works.

## Getting started
- [ ] Open the DrJava project download page.
- [ ] Ask IT to install a Java 8 runtime on one test computer.
- [ ] Download the jar file from the download page.
- [ ] Open the jar file and write a short program that prints a message.
- [ ] Compile and run the program.
- [ ] Share the jar file with other computers once the test works.

## Where is the AI?
DrJava has no AI. It builds sequencing and logic skills through Java code. Students plan the steps of a program and then test them.

## Privacy and safety
No account is needed, and the program runs on the computer. No privacy policy was found, and no account or cloud service appears in any source. The drjava.org domain now shows an unrelated blog. The official site could not confirm the details. The internet is used for the download. A teacher should check which Java version the school computers use and get the download from the real project site. Chromebook support is not documented.
