## Overview
Llama 3.2 1B and 3B are small text models from Meta with open weights. They download at about 1.3 GB and 2.0 GB through Ollama. Both have a 128K context window. Teachers and older students can run them locally and chat with them.

## Benefits for students
- Students can study how a language model runs on their own computer.
- Students can chat with the model in eight supported languages.
- Students can compare the 1B and 3B sizes.

## Benefits for teachers
- A single command downloads and starts a model in Ollama.
- Teachers can show a live model without an account.
- The small size suits a classroom demo.

## Benefits for schools
- The models are free to download.
- Text can stay on the school device and not go to a cloud service.
- IT will likely need to approve the install. The vendor does not confirm exact memory needs.

## Getting started
- [ ] Ask IT to approve Ollama on a test computer.
- [ ] Install Ollama from its official site.
- [ ] Check that the computer has enough memory for a 1.3 to 2.0 GB model file.
- [ ] Run ollama run llama3.2:1b to download the small model.
- [ ] Stay online for the first download.
- [ ] Go offline and test a few short prompts.
- [ ] Try ollama run llama3.2 for the 3B model.
- [ ] Review the Llama 3.2 Community License with school leaders.

## Where is the AI?
The AI is a small language model that generates text and chat replies. It runs on the local device in a runtime such as Ollama. Students write prompts and read the replies. They then judge the answers and test the limits of a small model.

## Privacy and safety
These are model weights. They are not a service. No account is needed, and the internet is used for the download. The weights collect no data themselves. Data handling depends on the runtime used. The research found no privacy policy. The download from Meta may need acceptance of the license, which the research did not verify. A teacher should check how the chosen runtime stores chat history and review replies for accuracy.
