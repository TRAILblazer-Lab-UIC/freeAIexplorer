## Overview
The Science Buddies Raspberry Pi Projects Kit holds eight projects that combine electronics and programming. All activities use Scratch for coding. It comes in a Complete version with the Raspberry Pi and a Circuit Building Kit with only the electronics. Students build circuits and write Scratch programs to control them.

## Benefits for students
- Students connect real circuits to code they write themselves.
- Students use Scratch, which many already know.
- Students work through eight projects that build on one another.

## Benefits for teachers
- Science Buddies publishes a best practices guide for classroom and out-of-school use.
- The guide comes from a year of testing with Purdue WIEP and girlSPARC.
- Project instructions are online and the kit includes a custom SD card image.

## Benefits for schools
- The price was not confirmed. Check the Science Buddies store.
- The Complete kit includes the Raspberry Pi.
- Each setup needs a monitor, keyboard, and mouse.

## Getting started
- [ ] Find the kit on the Science Buddies store and check the price.
- [ ] Choose the Complete kit or the Circuit Building Kit.
- [ ] Read the Getting Started guide for the kit.
- [ ] Use the SD card image that ships with the kit.
- [ ] Do not overwrite that image with one from raspberrypi.org.
- [ ] Connect a monitor, keyboard, and mouse to the Pi.
- [ ] Try the first project yourself before class.

## Where is the AI?
The kit has no AI. Students write Scratch programs that read inputs and switch parts on and off. They build skills in logic and sensing.

## Privacy and safety
The kit runs on the Raspberry Pi with Scratch, and the internet is used at setup. The project instructions are hosted online on the Science Buddies site. An account is optional. The research read no privacy statement and did not check whether the supplied SD card image sends data out. A teacher should check the Science Buddies privacy details before students make accounts.

## Ideas by subject
### computer_science
1. Write a Scratch program that turns an LED on and off in a pattern.
2. Change one block in a project and describe how the circuit reacts.
3. Plan a project on paper, then code it in Scratch.
4. Trade projects with a partner and fix any bugs in the code.
5. Add a loop to a working program to repeat an action.

### engineering
1. Build a circuit from the project guide and test that each part works.
2. Draw the circuit before building and compare the drawing to the finished build.
3. Work in a group to share building and coding roles over several days.
4. Find a loose wire or wrong connection and explain the fix.
5. Add one new part to a project and plan how to wire it.

### science
1. Predict what a circuit will do, build it, and compare the result to the prediction.
2. Record which parts make the circuit work and which parts break it.
3. Explain in a few sentences how electricity moves through the project.
4. Test the same circuit with a changed part and note the difference.
5. Keep a lab notebook that records each project and what was learned.
