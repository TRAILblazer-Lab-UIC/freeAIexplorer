## Overview
This camera sensor works with VEX V5 and EXP robots. It detects 2D and 3D objects, colors, color combinations, and AprilTag IDs. It includes two pretrained object detection models. Students in grades 6 to 12 code it in VEXcode.

## Benefits for students
- Students add vision to a robot they already know.
- Students code object and AprilTag detection.
- Students see how pretrained models find objects.

## Benefits for teachers
- Carnegie Mellon Robotics Academy offers teacher training on the sensor.
- The AI Vision Utility guides setup.
- The sensor builds on VEX tools that many teachers already use.

## Benefits for schools
- One search snippet of the VEX store shows a price of 95.49 dollars.
- VEX states that images and video stay on the student device and no personal information is collected. This has not been audited.
- The sensor works with no internet connection.

## Getting started
- [ ] Find the AI Vision Sensor on the VEX site and confirm it fits a V5 or EXP Brain.
- [ ] Attach the sensor to the Brain.
- [ ] Install VEXcode on a Windows or Mac computer.
- [ ] Open the AI Vision Utility and configure the sensor.
- [ ] Test the pretrained models on a few objects.
- [ ] Set up a color or color code in the utility.
- [ ] Print an AprilTag and test it with a short program.

## Where is the AI?
The AI is a pair of pretrained object detection models on the sensor. It also reads colors and AprilTags. The AI runs on the robot hardware. Students write code that reacts to what the sensor sees and extend the robot's skills.

## Privacy and safety
The sensor runs on the robot and needs no account or internet. VEX says images and video stay on the student device and no personal information is collected. This is a vendor statement that has not been independently audited. The VEX privacy policy could not be read. A teacher should check that the camera points at the game field and not at faces.

## Ideas by subject
### computer_science
1. Write code that makes a robot drive toward a detected object.
2. Compare color detection with the pretrained object models.
3. Use an AprilTag ID to choose which action the robot takes.
4. Test detection in bright and dim light and record the results.
5. Explain in a short note how the pretrained model finds objects.

### engineering
1. Mount the sensor on a V5 or EXP robot at a good height.
2. Test how far away the sensor can find an object.
3. Design a robot that lines up with an AprilTag.
4. Redesign the mount to reduce shaking and compare detections.
5. Build a short obstacle course that uses color codes.
