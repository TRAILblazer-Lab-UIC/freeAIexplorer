## Overview
Blockly Games is a series of educational games that teach programming to children with no prior experience. The eight games are Puzzle, Maze, Bird, Turtle, Movie, Music, Pond Tutor, and Pond. They move from block shapes through loops, conditionals, equations, and functions to JavaScript text code. The games are self-paced and can be downloaded for offline use.

## Benefits for students
- Students learn at their own pace.
- Students move from blocks to real JavaScript in the Pond games.
- Students get quick feedback from each level.

## Benefits for teachers
- Teachers can use the games for independent practice.
- BrainPOP Educators offers a lesson plan that uses Blockly Maze as a coding primer.
- Teachers need very little setup.

## Benefits for schools
- The games are free.
- They run in a browser, and Chromebooks are listed as supported.
- A downloadable copy can run offline.

## Getting started
- [ ] Open blockly.games in a browser.
- [ ] Play the Maze game yourself.
- [ ] Read the BrainPOP Blockly Maze lesson plan.
- [ ] Download the offline copy from the About page if needed.
- [ ] Open index.html to test the offline copy.
- [ ] Check the site privacy terms. The vendor materials do not state them.
- [ ] Assign one game as independent practice.

## Where is the AI?
Blockly Games has no AI. It builds the skills of logic and sequencing, through loops and conditionals. Students also practice reading and writing text code.

## Privacy and safety
No accounts exist. The About page does not address data collection or privacy. The research did not confirm whether progress stays only in the browser. The internet is used at setup and the games can run offline from a downloaded copy. A teacher should check the privacy terms or use the offline copy.

## Ideas by subject
### computer_science
1. Solve the first Maze levels and explain the block order, as in the BrainPOP lesson.
2. Use a loop in Maze to shorten a long path of blocks.
3. Draw a shape in Turtle with a repeat block.
4. Compose a short tune in Music with blocks.
5. View the JavaScript in Pond Tutor and describe how it matches the blocks.
