## Overview
MagicaVoxel is a free voxel editor and renderer by ephtracy. Students build 3D models from cubes, much like a virtual Lego set. They can export files for 3D printing. Pinnguaq offers a free classroom module, and a New Zealand school resource uses it on school computers.

## Benefits for students
- Students build 3D art from simple blocks.
- Students see their models rendered with light and color.
- Students can export a model for 3D printing.

## Benefits for teachers
- The tool is easy to learn.
- Pinnguaq offers a free module for 3D pixel art.
- Printing can be slow. One guide reported about eight hours for a print.

## Benefits for schools
- The software is free.
- It runs on Windows and macOS.
- A school may need IT approval for an unsigned freeware download.

## Getting started
- [ ] Download MagicaVoxel from the official site.
- [ ] Ask IT to approve and install it.
- [ ] Open the program and place a few cubes.
- [ ] Try the color palette and the render view.
- [ ] Follow the Pinnguaq module for a first project.
- [ ] Export a small model as a ply file.
- [ ] Check the file in your 3D print software before a long print.

## Where is the AI?
MagicaVoxel has no AI. It builds spatial thinking and pattern skills. Students plan a shape and build it one cube at a time.

## Privacy and safety
The program runs on the device and needs no account. The internet is used for download. The research found no privacy policy. The official site page that was fetched had only navigation text. The materials do not state what data the program collects. The site copyright ends in 2021. Update status is unknown. A teacher should check where students save files.
