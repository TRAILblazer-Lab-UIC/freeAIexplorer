## Overview
BEAPER Nano is an open learning board built around an Arduino Nano ESP32. The Education Starter setup has four LEDs, four pushbuttons and a piezo beeper. A robot setup adds a motor driver, servo headers, line sensors and a sonar header. It suits high school students who are ready to build and code.

## Benefits for students
- Students work with real through-hole electronics.
- Students write code that lights LEDs and reads buttons.
- Students can grow the board into a small robot.

## Benefits for teachers
- Five introductory Arduino C/C++ activities are on GitHub.
- The code and hardware are open source.
- MicroPython test programs are included.

## Benefits for schools
- The maker's store lists the bare board at 8 USD.
- No account is needed and the programs run on the board after setup.
- The research found no documented student data collection.

## Getting started
- [ ] Find the BEAPER Nano maker repository on GitHub and read the page.
- [ ] Order the board from PCBWay, either bare or assembled.
- [ ] Ask IT to help install the Arduino IDE.
- [ ] Gather an Arduino Nano ESP32 and a USB cable.
- [ ] Solder the parts or use an assembly service.
- [ ] Download the five activities from GitHub.
- [ ] Run the first activity and light one LED.

## Where is the AI?
BEAPER Nano has no AI. The board runs the program that students write and load. Students build skills in sequencing, logic and sensor input.

## Privacy and safety
No account is needed and programs run on the board. The research found no documented student data collection. The ESP32 has WiFi and the author plans WiFi activities, which would send data over a network. The internet is used at setup. A teacher should keep WiFi off unless a lesson needs it. A teacher should also plan for soldering safety.

## Ideas by subject
### engineering
1. Solder the board and test each LED and button with a simple program.
2. Draw a circuit diagram of the board and label each part.
3. Build the robot setup and test the motor driver.
4. Add line sensors and describe how the robot sees a path.
5. Plan an upgrade to the board and sketch the changes.

### computer_science
1. Run the first of the five Arduino activities and describe the result.
2. Write a program that turns the four LEDs on in a pattern.
3. Use the pushbuttons to control the piezo beeper.
4. Compare the Arduino C/C++ code with a MicroPython test program.
5. Debug a program that has a wrong pin number.
