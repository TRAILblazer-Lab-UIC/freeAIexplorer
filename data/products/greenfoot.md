## Overview
Greenfoot is an educational development environment for Java and Stride. Students create actors that live in worlds and build 2D games and simulations. It includes project management, auto-completion, and syntax highlighting. Java.com describes it as suitable for students from age 13 through college.

## Benefits for students
- Students see their code move characters on the screen.
- Students learn Java or Stride in a visual setting.
- Students can publish projects to an online gallery or keep them offline.

## Benefits for teachers
- A teacher resource area called Greenroom offers materials.
- It shares an editor with BlueJ.
- Auto-completion and syntax highlighting help students write correct code.

## Benefits for schools
- The software is free.
- It runs on Windows, Mac, and Linux.
- IT will likely need to approve the install on each computer.

## Getting started
- [ ] Download Greenfoot from its official site.
- [ ] Check that computers use a 64-bit CPU and OS for version 3.6.0 and later.
- [ ] Use Windows 10 or 11, macOS 11 or later, or Ubuntu or Debian.
- [ ] Ask IT to approve and install it.
- [ ] Open a sample scenario and run it.
- [ ] Visit the Greenroom instructor area for resources.
- [ ] Decide whether students publish to the gallery or stay offline.

## Where is the AI?
Greenfoot has no AI. It builds programming skills. Students write methods that control actors and test them in a world. It runs on the local computer.

## Privacy and safety
No account is needed and the internet is used for setup. Projects stay on the device unless students publish them to the online gallery. The download page has no data collection statement and the research found no privacy policy. The research did not review the data handling of the gallery. A teacher should decide whether gallery publishing is allowed and check the gallery terms first.
