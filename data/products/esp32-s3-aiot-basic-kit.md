## Overview
The ESP32-S3 AIoT Basic is a learning board built around an ESP32-S3 core with vector extensions for machine learning. Nine modules sit on one board, including a button, buzzer, LED, light sensor, LCD screen, microphone, SD slot, audio amplifier, and camera. Students program it in blocks with Aily Blockly or in C and C++.

## Benefits for students
- Students use sensors, a screen, and a camera with no breadboard.
- Students can start with blocks and move to typed code.
- Students try basic AI and IoT projects.

## Benefits for teachers
- Tutorials cover sensors, audio, display, camera, Bluetooth, and Wi-Fi.
- The board works with the Arduino IDE, ESP-IDF, and Aily Blockly.
- Teachers can use one board per student or group.

## Benefits for schools
- The Tindie listing shows $29 for the mainboard only.
- The board ships from China, typically within 1 to 2 weeks.
- The installation guide and example code are on a Chinese language site. IT or a teacher may need translation help.

## Where is the AI?
The vendor describes basic AI and IoT projects and AI teaching demos. The board runs them on the device, using the camera and microphone. Students write or build programs that react to what the sensors pick up. The materials give few details about what each AI demo does.

## Privacy and safety
The materials do not state which tools or accounts students need. They also do not say whether any demo uses the internet. The board has Wi-Fi and Bluetooth. Data handling depends on the code that students run. No privacy policy was found. The Tindie page says the board works with XiaoZhi AI teaching demos, and the research did not verify whether those use a cloud service. A teacher should test each tutorial first and check whether it connects to an online service.

## Ideas by subject
### computer_science
1. Build a Blockly program that sounds the buzzer when the light sensor reads dark.
2. Show a sensor reading on the LCD screen.
3. Move one Blockly project into C code and compare them.
4. Take a photo with the camera and save it to the SD card.
5. Test a voice demo and describe what it hears.

### engineering
1. Test the light sensor in three rooms and chart the values.
2. Combine the button, LED, and buzzer into a simple alarm.
3. Draw a diagram of how the modules connect to the core board.
4. Power the board by USB-C and note what happens to the screen.
5. Plan an IoT project that uses Wi-Fi for a school task.
