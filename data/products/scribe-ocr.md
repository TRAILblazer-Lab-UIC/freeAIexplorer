## Overview
Scribe OCR is a free open source web app for recognizing text in images and PDFs. It uses Tesseract engines through the Scribe.js library. The README says the whole program runs in the browser and sends no data to a remote server. Users proofread the text and export to PDF, DOCX, TXT, HTML, Markdown, XLSX, and other formats.

## Benefits for students
- Students turn scans and photos of pages into editable text.
- Students proofread low-confidence words marked in red.
- Students can add a searchable text layer to a PDF.

## Benefits for teachers
- No account and no install are needed.
- Teachers can digitize handouts and historical documents.
- Many export formats fit different class tools.

## Benefits for schools
- The app is free.
- It runs in a modern browser, including on Chromebooks.
- Files stay on the device. An optional AWS Textract mode sends requests to AWS and can add charges.

## Getting started
- [ ] Open scribeocr.com in a browser.
- [ ] Drag in an image or a PDF.
- [ ] Let the page finish recognizing the text.
- [ ] Review the words marked in red.
- [ ] Fix the errors in the proofreading view.
- [ ] Export to the format you need.
- [ ] Leave the AWS Textract mode off.

## Where is the AI?
The AI is optical character recognition from Tesseract, which reads the shapes of letters in an image. It runs in the browser on the device. Students check the output and fix mistakes, and the corrected text becomes their own digital document.

## Privacy and safety
No account is needed, and the internet is used to load the page. The README says the whole program runs in the browser and sends no data to a remote server. The optional AWS Textract mode sends requests from the browser to Amazon using the user's own credentials. The research found no privacy policy. A teacher should keep the AWS Textract option off and check scans for personal details.
