## Overview
Argos Translate is an open source translation library written in Python. It can run as a code library, a command line tool, or a graphical app. Language packs are downloaded for each translation direction. It suits older students and teachers who are comfortable with the command line.

## Benefits for students
- Students can translate text without an internet connection after setup.
- Students can see how a machine translation tool works from the inside.
- Students can try pairs such as Spanish to English and English to French.

## Benefits for teachers
- The tool is free and open source.
- Teachers can show how a translation can pivot through a middle language.
- A graphical version is available from a separate project for users who dislike the command line.

## Benefits for schools
- The software costs nothing.
- The project describes offline use after the language packs download.
- IT may need to approve Python tools, and the language packs need disk space.

## Getting started
- [ ] Find Argos Translate on its public code repository.
- [ ] Ask IT to approve Python tools on one computer.
- [ ] Install Python and run pip install argostranslate.
- [ ] Install the language packs for the pairs your class needs.
- [ ] Add argostranslategui if you want the graphical version.
- [ ] Test a short sentence in each direction.
- [ ] Go offline and test again.

## Where is the AI?
The AI is a machine translation model built with OpenNMT. It runs on the local computer. Students type or paste text, read the translation, and judge how well it fits. They can use the Python library to build small translation scripts of their own.

## Privacy and safety
No account is needed. The internet is used to download the tool and the language packs. Translation runs on the device after the packs are downloaded, according to the project description. The research found no privacy policy for the library. A teacher should check how much disk space the language packs need before installing a full set.

## Ideas by subject
### world_languages
1. Translate a short paragraph from English into the class language and mark each error.
2. Compare a direct translation with a pivot translation through English.
3. Write a sentence with an idiom and discuss how the tool handles it.
4. Translate a news headline and then back again to see what changed.
5. Build a list of words that the tool often gets wrong and explain why.

### computer_science
1. Install the Python library and translate one sentence with three lines of code.
2. Write a script that translates a text file line by line.
3. List which language packs are needed for a pivot from Spanish to French.
4. Measure how long the tool takes for short and long passages and graph the results.
5. Explore the command line tool and write a short help sheet for classmates.
