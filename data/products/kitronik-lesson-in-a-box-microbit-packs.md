## Overview
Lesson in a Box packs are classroom bundles that combine micro:bit accessories with lesson plans. The collection page lists packs such as Simple Robotics, The Environment, Craft and Code, Visual Computing, and a Primary Computing Pack. The vendor lists ages 8 and up and 11 and up. Students build and code the projects in each pack.

## Benefits for students
- Students work with real parts in each project.
- Students try robotics, environment sensing, craft, or visual computing.
- Students use MakeCode in a browser.

## Benefits for teachers
- A retailer snippet says each pack includes a USB drive with lesson summaries, setup guidance, code examples, and a UK and US curriculum guide.
- The Kitronik blog says non specialist teachers can deliver the lessons, which is vendor marketing.
- Teachers set up each pack before class.

## Benefits for schools
- Pack prices run from 285 GBP to 600 GBP.
- Whether the micro:bit is included was not confirmed.
- Packs need a computer with a USB port.

## Getting started
- [ ] Find the Lesson in a Box collection on the Kitronik site.
- [ ] Pick one pack that fits your grade band.
- [ ] Ask the vendor if the micro:bit is included.
- [ ] Order the pack and extra micro:bits as needed.
- [ ] Open the USB drive and read the lesson summaries.
- [ ] Run one lesson on your own first.
- [ ] Plan storage for the parts.

## Where is the AI?
The packs have no AI. Students code devices that follow exact steps. They build sensor, logic, and sequencing skills as they link inputs to outputs.

## Privacy and safety
No account is needed for the packs. Programs load onto the micro:bit over USB from a local computer. MakeCode is a web editor whose data handling was not reviewed, and the Kitronik privacy page returned a 404. The research found no description of student data collection. A teacher should check the MakeCode terms and check that each pack lists its parts and batteries.

## Ideas by subject
### computer_science
1. Work through a lesson from the Primary Computing Pack and describe what the program does.
2. Build a program that reacts to a button press.
3. Use a loop to repeat a pattern on the display.
4. Plan a short program on paper before coding it.
5. Test a program with a partner and fix one bug.

### engineering
1. Build a simple robot from the Simple Robotics pack.
2. Test how it moves and change one part.
3. Add a sensor so the robot reacts to its surroundings.
4. Compare two designs and note which works better.
5. Present the robot and describe each part.

### science
1. Use The Environment pack to measure a condition in the classroom.
2. Record readings at two times of day and compare.
3. Make a chart of the readings.
4. Predict how a reading will change and test it.
5. Write a short report about what the data shows.
