## Overview
The Micro:bit Club Kit is a loan kit in the Hawaii STEM Pre-Academy Toolkit for Teachers Lending Library. It holds 10 BBC micro:bit V2 boards with cables, battery packs, quick start guides and safety leaflets. The page says it introduces middle school students to computer science. Educators in Hawai'i borrow it and do not buy it.

## Benefits for students
- Students hold a real board and see their code run on it.
- Students can try linked lesson ideas from NASA JPL, Code.org, Microsoft Hacking STEM and Technocamps.
- Students can work in pairs or small groups with 10 boards.

## Benefits for teachers
- The kit arrives with cables, batteries and quick start guides in one box.
- Linked lessons come with standards connections.
- Teachers can try the boards before the school buys any. The loan length was not found.

## Benefits for schools
- The page lists no fee, but the borrowing fee was not found.
- The micro:bit board has no vendor cloud.
- Pickup and drop-off happen at the STEM Pre-Academy offices.

## Getting started
- [ ] Find the Hawaii STEM Pre-Academy Toolkit for Teachers Lending Library and create an educator account.
- [ ] Check that the kit is available for the dates you need.
- [ ] Use the program's contact form for any eligibility question.
- [ ] Borrow the kit and collect it from the STEM Pre-Academy offices.
- [ ] Read the quick start guides and the safety leaflets.
- [ ] Test one board with a computer that has a USB port.
- [ ] Pick one linked lesson, such as Coding a Radio Message for Space from NASA JPL.

## Where is the AI?
The kit has no AI. Students build sequencing and logic skills as they program the boards. They also learn to spot patterns in how a program reacts to button presses and sensors.

## Privacy and safety
The kit works on the device and needs no account or internet to run a program. A lending library login is needed to borrow the kit. The page does not describe data handling. Programming uses a separate editor such as MakeCode or the Python Editor, and those editors have their own privacy terms. Lesson links point to third party sites with their own terms. A teacher should read those terms before students open the links.

## Ideas by subject
### computer_science
1. Code a radio message between two boards, following the NASA JPL lesson linked on the kit page.
2. Program a button press to show a pattern on the LED display.
3. Write a short program that counts steps or clicks and shows the total.
4. Trade boards with a partner and find the bug in each other's code.
5. Design a small game for the LED grid and teach it to another pair.

### engineering
1. Follow the Touchdown Lander lesson from NASA JPL and test the lander design.
2. Build a simple alarm with the board and a battery pack.
3. Change the design after a test and write down what improved.
4. Plan how to power the board from the battery pack for a long project.
5. Write a short safety checklist using the safety leaflet.

### science
1. Use the linked NASA JPL space lessons to connect code to space science.
2. Send a coded radio message and describe how signals carry information.
3. Record readings from the board and compare them across the class.
4. Predict what the lander code will do and then test the prediction.
5. Write a short report on how a space mission uses small computers.
