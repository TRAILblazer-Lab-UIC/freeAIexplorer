## Overview
Mini Micro is a virtual retro computer for programming in MiniScript. It has graphics, sprites, sound, and a built-in code editor. It runs as a desktop app on Mac, Windows, and Linux. A WebGL template lets it run in a browser.

## Benefits for students
- Students code on a computer that boots straight to a prompt.
- Students make sprites, tiles, text, and sound.
- Students learn a small, readable language.

## Benefits for teachers
- The editor and language come in one download.
- The system disk source on GitHub is public.
- Teachers who know programming can explore the whole system.

## Benefits for schools
- The download page does not state a price. The discovery note says free, which was not confirmed.
- The build in the download page was v1.2.6 from November 2025.
- IT may need to approve the install.

## Getting started
- [ ] Download the archive for your system from miniscript.org.
- [ ] Extract it completely into a folder and delete the archive.
- [ ] Run the program on a test computer.
- [ ] Ask IT for approval to install on school machines.
- [ ] Try the built-in editor with a short program.
- [ ] Check the WebGL browser version if installs are blocked.

## Where is the AI?
This tool has no AI. It builds the skills of writing code, using variables, and controlling graphics. Students see how a program drives a screen.

## Privacy and safety
No account is needed, and the internet is used at setup. Mini Micro runs as a downloaded desktop app. The research found no privacy statement. The pages read described no account or cloud feature. A teacher should confirm the price and license on the download page and test the app before class.
