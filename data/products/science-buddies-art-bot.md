## Overview
This is a Science Buddies build project where students make a small robot with a motor, a battery, and markers for legs. Off-center weight on the motor shaft makes the robot wobble across paper and draw. The project asks how the attached weight changes the robot's movement. The Science Buddies pages returned an error. ## Getting started
- [ ] Find the Build an Art Bot project on Science Buddies.
- [ ] Gather a small DC motor, batteries, markers, and a cup or similar body.
- [ ] Gather craft supplies.
- [ ] Hot-glue an off-center weight to the motor shaft. An adult should do the hot gluing.
- [ ] Attach the markers as legs.
- [ ] Place the robot on paper and switch it on.
- [ ] Change the weight and test again.

## Ideas by subject
### engineering
1. Build the art bot from a motor, battery, and markers.
2. Change the position of the weight and test the drawing.
3. Redesign the legs to make a larger pattern.
4. Try a quadruped version with four legs.
5. Write a short build guide for another team.

### science
1. Predict how heavier weight will change the drawing.
2. Test three weights and record each drawing.
3. Compare the patterns and describe the differences.
4. Measure the size of each drawing with a ruler.
5. Explain how off-center weight makes the robot wobble.
