## Overview
EduBlocks is a free tool from Anaconda that teaches text languages such as Python and HTML through drag-and-drop blocks. Each block is one line of code. The text editor updates as students add blocks. A Classrooms feature lets teachers create assignments, track progress, and grade work.

## Benefits for students
- Students move from blocks to real Python lines.
- Students see the text code change as they drag blocks.
- Students can also build HTML pages.

## Benefits for teachers
- Classrooms let teachers assign work and share a class code.
- Teachers can track progress and grade work.
- A free Python curriculum has six lessons and an end-of-unit exam.

## Benefits for schools
- The tool and the Python curriculum are free.
- It runs in a browser, which suggests Chromebook use.
- The policy lists social login and analytics tools, which a school should review.

## Getting started
- [ ] Open the EduBlocks site in a browser.
- [ ] Read the privacy policy with your school.
- [ ] Create a classroom on the Classrooms page.

- [ ] Try the first lesson of the free Python curriculum.
- [ ] Decide whether students sign in with a social login or another method.

## Where is the AI?
EduBlocks has no AI. It builds sequencing and logic skills. Students stack blocks in order and see the matching text code.

## Privacy and safety
The site is always online, and an account is optional for saving work or using Classrooms. The policy lists contact details, credentials, usage data, and analytics from cookies and Heap. Sub-processors include Google, Microsoft, Firebase, Heap and Trinket.io for code execution, and servers are in the United States. The policy says it adheres to COPPA and that children under 13 may use it only with a parent or guardian. The policy does not mention FERPA. A teacher should check the privacy policy and the parent rule before students sign in.
