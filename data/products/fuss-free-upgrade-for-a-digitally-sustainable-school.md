## Overview
FUSS is a Debian-based GNU/Linux distribution for managing school computer networks. It covers a server, school clients, and a standalone desktop. The Province of Bolzano owns the copyright and finances it. Version 13 came out in April 2026 on Debian 13. Schools in South Tyrol use it, and the EU catalogue lists 33 administrations.

## Benefits for students
- Students use a managed Linux desktop.
- Students can use the same tools at home and at school.
- Refurbished laptops can run it.

## Benefits for teachers
- Teachers get a desktop that IT manages for them.
- It is available in English, German, French, Spanish, and Italian.
- It is a network project and not a classroom app.

## Benefits for schools
- The download is free for anyone.
- It is community maintained by volunteers with a technology partner, Truelite Srl.
- An IT administrator must install the server and then the clients.

## Getting started
- [ ] Find the FUSS project site and read the documentation.
- [ ] Ask the IT administrator to plan the server and clients.
- [ ] Download the Debian 13 based release.
- [ ] Install the server first.
- [ ] Install the clients.
- [ ] Test the standalone desktop mode.
- [ ] Use refurbished laptops for a pilot lab.

## Where is the AI?
FUSS has no AI. It builds skills in using a managed computer network. Students learn about accounts, files, and shared resources.

## Privacy and safety
The school server holds any user accounts locally. The research did not document the account model or what student data the software handles. The website sets no cookies, and the privacy PDF covers the website only. The internet is used at setup. A teacher should confirm with the administrator what the server stores and who can see it.
