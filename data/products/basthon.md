## Overview
Basthon is a browser sandbox that runs code on the student's own machine. It offers a console and a notebook for Python, SQL, OCaml, JavaScript, XCAS, C, and R. It is the engine behind Capytale, a platform used by the Academy of Paris for secondary students. Students write and run short programs without installing anything.

## Benefits for students
- Students can start coding in a few minutes in a browser.
- Students can try several languages in the same simple setting.
- Students can use a notebook to mix code and notes.

## Benefits for teachers
- Teachers can share coding activities by code through Capytale in the Academy of Paris.
- The notebook lets teachers combine instructions and runnable code.
- The XCAS option adds computer algebra for math lessons.

## Benefits for schools
- The tool is free and open source.
- Nothing needs to be installed, which lowers the IT load.
- Code runs in the browser on the student's machine. Chromebooks are listed as supported.

## Getting started
- [ ] Open basthon.fr in a modern browser.
- [ ] Choose a language console or notebook.
- [ ] Note that the interface is French first.
- [ ] Test the English option before class.
- [ ] Run a short Python program in the console.
- [ ] Try a notebook with one code cell and one note cell.
- [ ] Share the page with students and set a small first task.

## Where is the AI?
Basthon has no AI. It builds the skill of writing and testing code in small steps. Students also practice reading error messages.

## Privacy and safety
No account is needed and the code runs in the browser on the student's own machine. The research did not verify that the internet is needed only for setup. The pages read say nothing about data handling. Capytale stores activities and is a separate service. A teacher should check the privacy terms of Basthon and Capytale and the English availability before classroom use.

## Ideas by subject
### computer_science
1. Run a Capytale style activity by writing a short Python program that a teacher shares by code.
2. Write a Python console program that asks a question and prints a reply.
3. Run the same small task in Python and in JavaScript and compare the code.
4. Use a notebook to explain each step of a program in plain sentences.
5. Write a SQL query on a small table and describe the result.

### math
1. Use the XCAS option to expand and factor an expression, and write down what changed.
2. Write a Python loop that lists the first ten square numbers.
3. Plot a small set of values in a notebook and describe the pattern.
4. Use code to test a guess about even and odd numbers.
5. Solve an equation with XCAS and check the answer by substitution.
