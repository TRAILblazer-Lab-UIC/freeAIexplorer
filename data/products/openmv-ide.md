## Overview
OpenMV IDE is the desktop editor used to program and debug OpenMV cameras in MicroPython. The download page lists version 5.1.1 for Windows, macOS, and Linux. Students write scripts, view the camera feed, and run examples. Some examples load machine learning models onto the camera. The editor is only useful with an OpenMV camera.

## Benefits for students
- Students see the live camera feed as they code.
- Students run example scripts and then change them.
- Students can load a TensorFlow Lite model onto the camera.

## Benefits for teachers
- A quick start guide walks through installation.
- The editor is free to download.
- A teacher needs comfort with code.

## Benefits for schools
- The download page shows no price. A camera must be bought.
- It needs Windows 7 or later, macOS Ventura or later, or Ubuntu 22.04 or later.
- Chromebooks are not listed.

## Getting started
- [ ] Find the OpenMV download page.
- [ ] Ask IT to install the editor for your operating system.
- [ ] Connect an OpenMV camera by USB.
- [ ] Open an example script.
- [ ] Run the script and view the feed.
- [ ] Update the camera firmware if the editor asks.
- [ ] Try an example that loads a model.

## Where is the AI?
AI is optional. The editor can load TensorFlow Lite models onto a connected camera. The AI runs on the camera and not in the editor. Students pick an example, run it, and then change what the camera does with the result.

## Privacy and safety
No account is needed, and the internet is used at setup. The research found no privacy policy on the download page or in the docs. The materials do not say whether the editor sends telemetry. A discovery note mentioned optional Edge Impulse training, and the research could not confirm it. A teacher should ask IT to check network activity, check school policy on installing software, and decide what the camera may see.
