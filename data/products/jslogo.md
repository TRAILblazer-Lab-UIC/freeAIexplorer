## Overview
jsLogo is a Logo interpreter that runs in a web browser. The page has Run, Stop, and Clear controls and a drawing canvas. The README says it implements a subset of UCBLogo. Students type Logo commands and watch a turtle draw.

## Benefits for students
- Students see a drawing appear from each command they type.
- Students can use the reference, examples, and command history on the page.
- Students can download their drawing or procedure library.

## Benefits for teachers
- The page needs no install.
- It includes examples and a language reference.
- An optional TogetherJS link supports collaboration.

## Benefits for schools
- The tool is free and the code is open.
- It runs in a modern browser on Chromebooks, Windows, Mac, and Linux.
- IT has nothing to install.

## Getting started
- [ ] Open the jsLogo page in a browser.
- [ ] Type a short command, such as one that moves the turtle forward.
- [ ] Press Run and then Clear.
- [ ] Open the examples and run one.
- [ ] Check the reference for the commands students need.
- [ ] Note that the README lists undocumented differences from UCBLogo.
- [ ] Plan for internet access. The page does not say whether it works offline.

## Where is the AI?
jsLogo has no AI. It follows each command exactly. Students build sequencing and logic skills as they plan the steps that draw a shape.

## Privacy and safety
No account is needed, and the page needs the internet. The page does not say whether the library, history, or drawings are stored or sent anywhere. It links a TogetherJS collaboration feature whose data sharing is not described. No privacy policy was found. A teacher should test the optional TogetherJS link before use and tell students not to share links that show personal information.

## Ideas by subject
### computer_science
1. Type commands that draw a square.
2. Use a repeat command to shorten the square code.
3. Write a procedure for a shape and call it several times.
4. Read an example from the page and predict what it will draw.
5. Debug a program with a partner and fix the mistake.

### math
1. Draw a triangle and find the turn angles that close the shape.
2. Draw a regular polygon with each side length the same.
3. Change the side length and describe the effect on the drawing.
4. Draw a pattern that repeats with a turn each time.
5. Test how many turns bring the turtle back to the start.
