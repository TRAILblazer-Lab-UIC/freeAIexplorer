## Overview
miniBloq is an open source graphical programming tool for Multiplo, Arduino and other robots. Students drag blocks together and the tool writes C/C++ code in Arduino syntax. A 2014 project post says it also supports text coding in C/C++ and Python. The newest blog post found is from October 2016. The project appears largely dormant.

## Benefits for students
- Students see the generated code beside their blocks.
- Students move from blocks toward real text code at their own pace.
- Students program real Arduino-compatible robots.

## Benefits for teachers
- Teachers can show the link between blocks and text code on one screen.
- SparkFun and Hackaday describe it as a drag-and-drop route into Arduino.
- The tool runs on Windows and Linux.

## Benefits for schools
- The download is free and the boards are bought separately.
- The code is open source.
- IT may need to approve the install and the USB drivers.

## Getting started
- [ ] Download the installer from the project blog download page.
- [ ] Ask IT to approve the install and USB drivers.
- [ ] Install it on a Windows or Linux computer.
- [ ] Connect an Arduino-compatible board by USB.
- [ ] Build a short block program.
- [ ] Upload it to the board.
- [ ] Look at the generated code window with students.

## Where is the AI?
The vendor describes no AI. The tool builds sequencing and logic skills. Students also learn how a block program turns into text code.

## Privacy and safety
The tool runs on the device and needs no account. The internet is used at setup. Programs are written on the computer and uploaded to a board over USB. The project blog does not mention privacy practices or accounts, and the research found no privacy policy. The project looks dormant, with no release since 2015. A teacher should test the software on a school machine first.

## Ideas by subject
### computer_science
1. Build a block program that blinks an LED and read the generated C++ code.
2. Change one block and find the matching line in the code.
3. Write a program with a loop and a condition.
4. Compare the block version with a text version of the same program.
5. Explain to a partner how the tool turns blocks into code.

### engineering
1. Program an Arduino-compatible robot to drive forward and stop.
2. Add a sensor and make the robot react to it.
3. Test the robot, record what went wrong and fix the program.
4. Draw a wiring plan before connecting parts.
5. Compare two robot designs and choose one.
