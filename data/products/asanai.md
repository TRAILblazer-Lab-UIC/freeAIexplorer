## Overview
asanAI is a no-code machine learning toolkit that runs in the browser. Users build a neural network by choosing layers from a panel. They train it on their own images, CSV files, or tensor data. The project describes itself as beta.

## Benefits for students
- Students see the network structure as they build it.
- Students can train a model on their own images or camera stream.
- Students can inspect a model with explainability tools such as GradCam.

## Benefits for teachers
- The tool needs no code to start.
- Models can be exported as Python code for students who are ready for more.
- Teachers can demonstrate weight matrices and layers on a projector.

## Benefits for schools
- The tool is free and the code is open.
- The README says data stays on the computer.
- It works offline after one visit while online.

## Getting started
- [ ] Open the asanAI toolkit in a modern browser while online.
- [ ] Let the page load fully so it can work offline later.
- [ ] Try a built-in example and train it.
- [ ] Upload a few images and test a prediction.
- [ ] Allow the webcam only if a teacher has approved camera use.
- [ ] Go offline and confirm the toolkit still opens.
- [ ] Remember that the project is beta and may change.

## Where is the AI?
The AI is a neural network that students design and train. Training and prediction run in the browser on the local computer. Students pick layers, train on their own data, and read the results. They can then use GradCam to see which part of an image the model used.

## Privacy and safety
No account is needed and the internet is used for the first visit. The README says user data stays on the computer. The research found no separate privacy policy. The hosted toolkit address was not confirmed in the pages read. The software is beta. A teacher should test the tool on school browsers before class and make sure students do not use photos of classmates without permission.
