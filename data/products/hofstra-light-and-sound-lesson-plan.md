## Overview
This Hofstra unit is called Interactive Light and Sound Show Design. It runs about eight days for grades 7 and 8. Students design, build and program a show that reacts to motion using distance sensors. The unit teaches if-else logic to control LEDs and sound by distance range. The pages fetched showed only titles and dates. Details come from search snippets.

This unit has no AI. The show follows the if-else rules students write. Students build skills in logic and sensors by choosing what the lights and sound do at each distance.

## Ideas by subject
### theater_media
1. Design an interactive light and sound show that reacts to a visitor's motion.
2. Pick a mood for the show and choose colors and sounds to match.
3. Sketch the show as a storyboard with each distance range.
4. Present the show to another class and collect feedback.
5. Compare two designs using the rubric.

### computer_science
1. Write if-else code that changes an LED color by distance range.
2. Add a sound that plays at one distance range.
3. Test the program by moving a hand in a box.
4. Fix a program that turns the wrong light on.
5. Explain the if-else rules in plain words to a partner.
