## Overview
MediaPipe Studio is a browser tool from Google for trying and benchmarking MediaPipe tasks. The tasks cover vision, text, and audio work, such as image classification, object detection, hand landmarks, and gesture recognition. Users can supply their own test images, audio clips, or model files. It is aimed at developers. Student use suits an advanced computing class.

## Benefits for students
- Students can try gesture, image, and audio models in a browser.
- Students can test their own pictures and sounds.
- Students see model output visualized.

## Benefits for teachers
- Demos open in minutes with no install.
- Teachers can show how a model reads a hand or an object.
- The tool also benchmarks model output.

## Benefits for schools
- The tool is free.
- Google documentation says the demos run locally in the browser using WebGL, WebGPU, and WebAssembly.
- No install is needed, but the page needs a modern browser.

## Getting started
- [ ] Find MediaPipe Studio through Google's developer pages.
- [ ] Open the Studio page in a current browser.
- [ ] A Google sign-in may be requested. Ask IT whether it is allowed.
- [ ] Pick a task, such as gesture recognition.
- [ ] Load a sample input before using a webcam.
- [ ] Check the webcam and microphone permissions with IT.
- [ ] Try a task with your own test image.

## Where is the AI?
The AI is a set of MediaPipe models for vision, text, and audio tasks. Google documentation says they run locally in the browser. Students load an input, run a task, and read the results. They then test new inputs to learn how the model behaves.

## Privacy and safety
Google documentation says all inputs are processed locally on the device. The page is hosted by Google and loads from Google servers. The internet is always needed. A fetch of the Studio URL was redirected to a Google sign in page. The research did not confirm whether a Google account is required. The research found no education specific privacy statement such as COPPA or FERPA. The general Google privacy policy is linked. A teacher should check whether images, audio, and webcam feeds leave the device, and should test with sample inputs first.
