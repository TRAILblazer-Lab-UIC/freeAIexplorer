## Overview
TurboWarp Desktop is an offline desktop editor for Scratch 3 projects. It compiles projects to JavaScript for faster running. It adds dark mode, addons, custom extensions, and a built-in packager. It runs on Windows, macOS, and Linux. It is not affiliated with the Scratch Team.

## Benefits for students
- Students can build Scratch projects offline.
- Projects run faster than in the standard editor.
- Students can work from local files.

## Benefits for teachers
- The editor is compatible with Scratch 3.
- The packager exports to HTML, zip, or desktop apps.
- Dark mode and addons add options.

## Benefits for schools
- The software is free and the code is open.
- It runs on Windows 10 or later, macOS 12 or later, and Linux x86 or ARM. It is not available on Chromebooks.
- School IT may need to approve the install.

## Where is the AI?
TurboWarp Desktop has no AI. Students snap blocks together and the compiler runs them faster. They practice logic and sequencing.

## Privacy and safety
No account is needed and projects stay in local files. The policy says the desktop app checks for updates. Rich Presence is optional and off by default. Loading a Scratch project by ID shares the ID with TurboWarp. Cloud variable data is public. The policy does not mention COPPA or FERPA. Update any version before 1.17.0 and check whether the school filter blocks the TurboWarp domains.
