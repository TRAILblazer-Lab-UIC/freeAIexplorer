## Overview
VSCodium is a community built, MIT licensed version of the VS Code source. It is built without Microsoft's branding, telemetry, or gallery settings. The site says telemetry is disabled in the builds. It suits advanced high school students who write text code.

## Benefits for students
- Students use a professional code editor.
- Students can install extensions from the Open VSX registry.
- Students gain skills used in real software work.

## Benefits for teachers
- The editor suits text programming courses.
- Telemetry is turned off in the builds.
- Teachers need some comfort with editors and extensions.

## Benefits for schools
- The software is free.
- It runs on Windows, macOS, and Linux.
- Some proprietary VS Code extensions do not work. IT may need to approve and install it.

## Getting started
- [ ] Download VSCodium from GitHub releases or use a package manager such as winget, Homebrew, or Snap.
- [ ] Ask IT to approve the install on school computers.
- [ ] Install it on each computer.
- [ ] Open the extensions panel and install tools from Open VSX.
- [ ] Check that the language extensions your class needs are available.
- [ ] Test a short program.
- [ ] Share a short guide with students.

## Where is the AI?
This tool has no AI. It is a text editor with add on tools. Students build logic and sequencing skills as they write and debug text code.

## Privacy and safety
VSCodium runs on the computer and needs no account. The VSCodium site and README state that telemetry is disabled. Extensions that students install may still send their own telemetry or use cloud services, and they come from open-vsx.org. No privacy policy was found. The internet is needed at setup and for extensions. A teacher should check that extensions students install come from trusted publishers.
