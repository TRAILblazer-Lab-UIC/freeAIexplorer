## Overview
These kits use the Nezha expansion board, which clips onto a BBC micro:bit. The Nezha Inventor's Kit V2 has over 400 building blocks, motors and sensors. Themed Nezha Pro kits cover sports, space science and ocean topics. Students build a model and program it in a micro:bit editor.

## Benefits for students
- Students build a model from bricks and then make it move.
- Students use sensors such as ultrasonic, crash and line tracking.
- Students choose a themed kit that matches a topic they like.

## Benefits for teachers
- The kits program in block code over USB.
- Themed kits connect robotics to sports, space and ocean topics.
- A separate Joystick:bit kit adds wireless control.

## Benefits for schools
- Shop sale prices ran from 149 USD for the Inventor's V2 to 239 USD for the Sports kit.
- The micro:bit is sold separately in some versions.
- The vendor policy covers website orders only.

## Getting started
- [ ] Choose a kit from the ELECFREAKS collection page.
- [ ] Check whether the kit includes a micro:bit. Buy one if it does not.
- [ ] Confirm the micro:bit version. The materials do not verify V1 or V2 support.
- [ ] Build the model from the bricks.
- [ ] Attach the micro:bit to the Nezha board.
- [ ] Open a micro:bit editor. The web MakeCode editor needs internet access. Install an offline editor for offline use.
- [ ] Program the model over USB.

## Where is the AI?
These kits have no AI. The models follow the block code students write. Students build skills in sensors and logic by making a model react to a distance or a line.

## Privacy and safety
No account is needed, and the kits run on the micro:bit. The web editor needs the internet unless an offline editor is installed. The vendor policy dates from 2014 and covers website orders only. It does not mention children or product data. The research did not review the editor's data practices. A teacher should confirm the micro:bit version before buying and check which editor students use.

## Ideas by subject
### engineering
1. Build the starter model and list each motor and sensor it uses.
2. Test a model on a ramp and record how it performs.
3. Redesign one part of a model to make it faster or steadier.
4. Choose a themed kit and build a model that fits its topic.
5. Write a short build report with a labeled sketch.

### computer_science
1. Program a motor to run for a set time.
2. Use an ultrasonic sensor to make the model stop near a wall.
3. Use a line tracking sensor to follow a taped path.
4. Write a program that responds to a crash sensor.
5. Trade programs with a partner and explain each block.
