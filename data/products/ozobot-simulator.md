## Overview
The Ozobot Simulator is a free browser tool that lets teachers without an Evo test programs. The Classroom overview says it is linked from the Ozobot site. Ozobot Classroom is a free web app with about 700 standards-aligned lessons. Teachers create a free account there.

## Benefits for students
- Students can test block programs on screen.
- Students can practise before they use a real robot.
- Students see the result of a program right away.

## Benefits for teachers
- Teachers can try lessons with no robot at hand.
- The simulator is linked to the Ozobot Classroom lessons.
- It opens in a browser in minutes.

## Benefits for schools
- The simulator is free per the Classroom page.
- It needs only a modern browser.
- IT work is not expected.

## Getting started
- [ ] Open the Ozobot site and find the link to the simulator.
- [ ] Use a modern browser.
- [ ] Create a free Classroom account for lessons.
- [ ] Open a lesson and run it in the simulator.
- [ ] Check what the simulator shows and what it does not show.
- [ ] Plan a class session with the simulator.

## Where is the AI?
The vendor does not describe any AI. Students build sequencing and logic skills as they write block programs. They also test and fix their code.

## Privacy and safety
The simulator needs the internet at all times. The research did not read the simulator page and could not confirm whether it needs a login. The materials do not state what data is collected. The Classroom pages list COPPA and FERPA certifications. The Ozobot privacy policy says it does not knowingly collect personal information from children under 13. That is a data rule and not a minimum age. A teacher should read the Ozobot privacy terms before students use it.

## Ideas by subject
### computer_science
1. Build a block program and run it in the simulator.
2. Predict the robot's path before pressing run.
3. Change one block and describe the new path.
4. Use a loop to shorten a long program.
5. Compare the simulator result with a classmate's.

### math
1. Code a square and count the turns and sides.
2. Measure the distance of a path and compare predictions.
3. Name the angles used in a turn.
4. Make a pattern with repeating moves.
5. Pair the simulator with a math lesson from Ozobot Classroom.
