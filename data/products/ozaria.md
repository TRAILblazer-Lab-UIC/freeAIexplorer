## Overview
Ozaria is a story-driven computer science course from the CodeCombat team. Search results say it launched in 2019 as a classroom-only product with a teacher dashboard. Discovery notes list grades 4 to 9 with block then text coding, but this was not verified. The ozaria.com page returned only a title when checked.

## Benefits for students
- Students learn coding through a story.
- Students move from block coding toward text coding, according to discovery notes.
- Students work in a browser with no install.

## Benefits for teachers
- A teacher dashboard shows student code and progress, according to search results.
- Teachers create a free educator account and add students.
- Clever sign-in was listed in 2022.

## Benefits for schools
- The first chapter is free, according to discovery notes.
- Pricing for later chapters was not found.
- The vendor cloud holds student accounts. Schools should review the terms.

## Getting started
- [ ] Find Ozaria through the CodeCombat team and confirm it is still available.
- [ ] Ask the vendor about current pricing for chapters after the first.
- [ ] Ask IT to review the privacy terms before students sign in.
- [ ] Create a free educator account.
- [ ] Add students to a class.
- [ ] Try the first chapter yourself before class.
- [ ] Check the teacher dashboard to see student progress.

## Where is the AI?
The vendor does not describe any AI in Ozaria. The materials say only that it teaches coding through a story. Students build sequencing and logic skills as they write code to move through chapters.

## Privacy and safety
Student accounts are required, and the course runs in the vendor cloud with an internet connection at all times. The research found a Common Sense privacy evaluation and a link to the Ozaria privacy policy, and a note that Ozaria signed a California Student Data Privacy Agreement. The research did not read those documents or confirm what student data is collected. The current status of the product is unclear. A teacher should read the privacy policy and the Common Sense evaluation and confirm that the school may use it with students.

## Ideas by subject

1. Play the first chapter and write a short note on what each code block does.
2. Compare how two partners solved the same level.
3. Explain a challenge to a classmate using plain words.
4. Change a line of code and predict how the story character will act.
5. Write a story plan for a short game and list the commands it would need.
