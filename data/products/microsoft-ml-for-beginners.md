## Overview
This is a free, MIT licensed 12-week curriculum on classic machine learning. It has 26 lessons and 52 quizzes. It uses Python with Scikit-learn and notebooks, and many lessons have R versions. Nine units cover regression, classification, clustering, language, time series, and reinforcement learning. It is written for beginners but at a university intro level.

## Benefits for students
- Students work with real data and real Python tools.
- Students take quizzes and finish a challenge and an assignment in each lesson.
- Students can read it in more than 50 translations.

## Benefits for teachers
- The lessons are ready to teach in order.
- Teachers can run the quiz app locally.
- The course works for advanced high school classes.

## Benefits for schools
- The course is free.
- Students can run it on a local computer or in GitHub Codespaces.
- IT help is likely needed for the Python setup.

## Getting started
- [ ] Find the ML-For-Beginners repository on GitHub.
- [ ] Clone it, or use sparse checkout to skip the translations.
- [ ] Ask IT to install Python and the lesson dependencies.
- [ ] Open the first lesson notebook.
- [ ] Try the quiz app locally.
- [ ] Consider Codespaces to avoid a local install, and check its account rules first.
- [ ] Plan the 12 weeks across a term.

## Where is the AI?
The AI is classic machine learning with Scikit-learn. It runs on the local computer. Students write and run code that learns from data, then check the results and change the settings. Deep learning is in a separate Microsoft course.

## Privacy and safety
No account is needed for local use. Code runs locally with Python, and the internet is used at setup. Optional GitHub Codespaces needs a GitHub account and runs in Microsoft's cloud. The quiz app can be run locally or deployed to Azure. The research found no privacy policy. A teacher should check the account rules before students use GitHub Codespaces.

## Ideas by subject
### computer_science
1. Run a notebook that predicts a number from data and read the output.
2. Train a classifier and compare its guesses with the true labels.
3. Group data with clustering and describe each cluster.
4. Complete a lesson quiz and review the missed answers.
5. Try the challenge in one lesson and present your solution.

### math
1. Fit a line to data with regression and read the slope.
2. Plot errors from a model and describe the pattern.
3. Group points into clusters and measure the distances.
4. Forecast a time series and compare it with the real values.
5. Explain what a good prediction looks like in numbers.
