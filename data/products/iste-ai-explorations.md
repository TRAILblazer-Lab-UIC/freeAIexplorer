## Ideas by subject
### computer_science
1. Run an unplugged activity that sorts items by rules and describe the rules.
2. Build a simple chatbot and test it with five questions.
3. Make a simple game and explain one AI idea inside it.
4. Compare your chatbot with a classmate's chatbot.
5. Write a plan to improve one project.

### social_studies
1. Read the ethics guide and list two fair uses of AI.
2. Debate one case where AI could harm a group.
3. Write a class code for responsible AI use.
4. Interview an adult about how AI changes their work.
5. Create a poster on AI and fairness.
