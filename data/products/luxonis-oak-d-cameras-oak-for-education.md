## Overview
Luxonis OAK cameras are smart cameras that run neural network inference and stereo depth on the camera and send results to a host over USB or Ethernet. The OAK-D line adds stereo depth, and OAK 4 is the newer generation. Software includes the DepthAI API, the oakctl command line tool, OAK Viewer, and open examples. The listed education page did not describe an education program when fetched.

## Benefits for students
- Students code with the DepthAI API and see neural network results.
- Students get depth data from a stereo camera.
- Students can start with open example apps.

## Benefits for teachers
- OAK Viewer shows results without much code.
- The software is open source.
- The materials aim at grade 9 and up with coding experience.

## Benefits for schools
- The store lists OAK-1 from $219, OAK-D Lite at $269, OAK-D S2 at $329, and OAK-D Pro at $429. OAK 4 models run $949 to $1,149.
- No education discount was found.
- The camera needs no account and the internet is used only at setup. Chromebook support was not confirmed.

## Getting started
- [ ] Choose a camera model on the Luxonis store.
- [ ] Gather a host computer or single board computer with USB or Ethernet.
- [ ] Ask IT to approve the DepthAI software.
- [ ] Install DepthAI and OAK Viewer on the host.
- [ ] Connect the camera.
- [ ] Run an example app.
- [ ] Edit the example code with a small change.

## Where is the AI?
The AI is object detection, depth estimation, and neural network inference. It runs on the camera itself. Students read the output on a host computer and write code to use the results in their own projects.

## Privacy and safety
No account is needed and the internet is used for setup. Inference happens on the camera, and frames go to the connected host. The research found no vendor cloud requirement on the pages read. The research reviewed no privacy policy. Newer OAK 4 and app tooling may add cloud features that the research did not examine. A teacher should check where the camera points and who appears in the video.
