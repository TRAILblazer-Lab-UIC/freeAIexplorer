## Overview
KidBright32 is an ESP32 board that the Thai Ministry of Education distributes to schools to boost STEM education. It has WiFi and Bluetooth. Students program it with the KidBright IDE, a block language inspired by Scratch, or with the Arduino core for ESP32. Courses and lessons are published in Thai.

## Benefits for students
- Students program a real board with blocks.
- Students can move on to Arduino code later.
- Students use sensors on the board.

## Benefits for teachers
- The block language is inspired by Scratch.
- The Thai Ministry of Education uses the board for grades 6-12.
- The learning content is in Thai. Teachers who do not read Thai need other materials.

## Benefits for schools
- Coverage from 2018 priced the board at 600 Baht, about 18 USD.
- Availability outside Thailand is unclear.
- IT must install the IDE on each computer.

## Getting started
- [ ] Find the KidBright32 pages and the IDE download.
- [ ] Check that you can buy a board where you live.
- [ ] Ask IT to install the IDE on a test computer.
- [ ] Connect the board with a USB cable.
- [ ] Build a short block program and upload it.
- [ ] Check the English materials. The lessons are in Thai.
- [ ] Plan a first lesson with a simple sensor.

## Where is the AI?
KidBright32 has no AI. Students program the board with blocks that follow exact steps. They build sequencing, sensor, and logic skills as they link inputs to outputs.

## Privacy and safety
No account is needed, and no privacy policy was found. The board can use WiFi. Projects may reach the internet if students write code to do so. The research did not confirm whether the IDE needs the internet. Some KidBright resources including the IDE are closed source. A teacher should check the IDE source before installing it.

## Ideas by subject
### engineering
1. Read a sensor on the board and show the value on the display.
2. Build a small device that reacts to light.
3. Test the board with a battery and a case.
4. Compare two sensor readings in different places.
5. Design a simple device for a school need.

### computer_science

2. Use a loop to repeat a pattern.
3. Add a button that starts the pattern.
4. Compare the block code to Arduino code for the same task.
5. Debug a program with a partner.
