## Overview
Zorin OS Education is a free education edition of the Zorin OS Linux system, currently version 18.1. It bundles apps for math, science, geography, languages, and music, plus coding tools such as TurboWarp, GDevelop, Fritzing, and LibreCAD. It includes Veyon for teachers to monitor and control student screens. Zorin says it runs on computers as old as 15 years.

## Benefits for students
- Students find coding and design tools already installed.
- Students use learning apps for many subjects.
- Older computers can run the system.

## Benefits for teachers
- Veyon lets teachers monitor, control, and share screens.
- Kolibri offers offline learning content on a local network.
- Setup takes days and needs IT support.

## Benefits for schools
- The system is free.
- Old computers can be reused.
- Zorin Grid fleet management is listed as Coming Soon.

## Getting started
- [ ] Download the Education edition from the Zorin site.
- [ ] Write it to a USB drive.
- [ ] Ask IT to test it on one computer first.
- [ ] Install it on each computer. It replaces or sits beside the current system.
- [ ] Have IT set up Veyon for classroom control.
- [ ] Decline the optional hourly census ping in the installer or remove it afterward.
- [ ] Try the preinstalled coding tools.

## Where is the AI?
This system has no AI. It bundles apps that follow fixed rules. Students build sequencing and logic skills with the preinstalled coding tools such as TurboWarp.

## Privacy and safety
The system runs on the computer and needs no account. The policy says it may send an hourly census ping with the number of users, an anonymous installation indicator, the OEM batch, and the OS version. Error reports are sent only when a user chooses. No student data is described, and the policy does not address children or minors. Veyon lets teachers see and control student screens. A teacher or IT lead should decline the census ping in the installer or remove it with sudo apt remove zorin-os-census, and decide how Veyon will be used.
