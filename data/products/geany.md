## Overview
Geany is a lightweight text editor with basic IDE features. It supports more than 50 programming languages and has a plugin system. It suits high school students who are learning text-based languages. A university computing service lists it for managed Windows and Linux workstations.

## Benefits for students
- Students write real code in a plain editor.
- Students can switch between many programming languages in one tool.
- The editor starts fast on older computers.

## Benefits for teachers
- Themes can be customized for readability.
- Plugins add version control, spell checking, and project organization.
- One editor covers many courses.

## Benefits for schools
- The software is free.
- It has a small footprint and runs on modest hardware.
- IT can deploy it through managed tools on Windows, Mac, or Linux.

## Getting started
- [ ] Find Geany on its project site.
- [ ] Download the installer or use a Linux package manager.
- [ ] Ask IT to deploy it on managed computers.
- [ ] Open the editor and pick a color theme.
- [ ] Create a short program in the language your class uses.
- [ ] Try the plugins that add project organization.
- [ ] Test the build and run tools on one computer first.

## Where is the AI?
Geany has no AI. It builds text coding skills. Students type each line of code and read errors. It runs on the local computer.

## Privacy and safety
No account is needed. The internet is used only for setup, and files stay on the device. Geany is a local desktop editor and the research did not read a privacy policy. No documented K-12 use was found. A teacher should test the editor with a sample lesson first. A teacher should also set up where students save their files.
