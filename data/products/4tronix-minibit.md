## Overview
The MiniBit is a small ready built two wheel robot for the BBC micro:bit. It has two motors, four FireLEDs, and a pen holder between the wheels. It works with micro:bit V1 and V2. A MakeCode extension gives blocks for motors and LEDs.

## Benefits for students
- Students program a small robot that can draw with a pen.
- Students see their blocks move real wheels.
- Students can add parts such as an ultrasonic sensor.

## Benefits for teachers
- The robot is ready built. Only the wheels need pushing on.
- Pins 0, 1, and 2 work with croc clips.
- MakeCode blocks keep the first lesson simple.

## Benefits for schools
- The MiniBit is listed at 28.80 GBP including VAT at The Pi Hut.
- The micro:bit, batteries, and breakouts cost extra. Breakouts cost 5 to 10.20 GBP each.
- Only a retailer page was readable for this research.

## Getting started
- [ ] Buy the MiniBit, a BBC micro:bit, and 3 AA batteries.
- [ ] Push on the wheels and add the batteries.
- [ ] Place the micro:bit in the robot.
- [ ] Open MakeCode in a browser and add the MiniBit extension.
- [ ] Write a program that drives forward.
- [ ] Download it to the micro:bit over USB.
- [ ] Add a pen to the holder and test a drawing.

## Where is the AI?
This robot has no AI. It runs the program students write. Students build sequencing and logic skills as they plan each move.

## Privacy and safety
The robot has no accounts or cloud service. The research found no student data collection by the robot. Students write code in the MakeCode web editor and download it to the micro:bit. The research did not review the MakeCode editor's own privacy terms. No 4tronix privacy policy was found. A teacher should check the MakeCode terms and confirm that school computers can reach the editor.

## Ideas by subject
### computer_science
1. Write blocks that drive the robot in a square.
2. Use a loop to shorten the square program.
3. Make the LEDs flash as the robot turns.
4. Predict a path and then run it.
5. Debug a program that drifts off course.

### engineering
1. Attach a pen and test how the robot draws a shape.
2. Adjust the program to draw a closed shape.
3. Compare two pens or two pen heights.
4. Measure the error in a drawing and suggest a fix.
5. Add an optional sensor and describe what it adds.
