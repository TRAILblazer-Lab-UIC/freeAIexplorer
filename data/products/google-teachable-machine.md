## Overview
Teachable Machine is a web tool for training image, sound, and pose classifiers without writing machine learning code. Students gather examples with a webcam, a microphone, or uploads. They train a model with one click and test it in the browser. The README calls it an experiment and says it is not an official Google product.

## Benefits for students
- Students train a real model in minutes.
- Students see how more examples change the results.
- Students can export a model to use in Scratch or p5.js.

## Benefits for teachers
- It has no install and no account.
- It is easy to demonstrate to a whole class.
- Teachers can save projects to Google Drive if they choose.

## Benefits for schools
- The tool is free.
- Training and testing happen in the browser on the device.
- Schools may need to allow the site through the web filter.

## Getting started
- [ ] Find the Teachable Machine website.
- [ ] Ask IT to allow the site through the web filter.
- [ ] Open it in a modern browser.
- [ ] Allow camera or microphone access when asked.
- [ ] Start an image project with two classes.
- [ ] Train the model and test it.
- [ ] Skip the Google Drive save option to keep work on the device.

## Where is the AI?
The AI is a classifier built with TensorFlow.js. It learns from the examples that students give it, using transfer learning. It runs in the browser on the local device. Students collect examples, train, test, and then fix weak spots by adding more examples.

## Privacy and safety
No account is needed to train and test. The page and libraries load from Google. The internet is needed at the start. A 2019 Google blog says examples stay on the device and training runs in the browser. Saving to Google Drive needs a Google account and sends project data to Google. The research could not read the site FAQ. It did not confirm retention or model hosting upload terms. A teacher should decide whether to allow the Drive save. A teacher should also check that students do not record classmates without permission.
