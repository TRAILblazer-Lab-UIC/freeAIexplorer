## Overview
WeScheme is a free, cloud based programming environment for Scheme and Racket in a web browser. Programs compile to run on the browser's JavaScript engine and can be shared. It is used with the Bootstrap curriculum, which offers a WeScheme version of its Algebra course. Students write functional programs.

## Benefits for students
- Students start coding at once without logging in.
- Students write programs in a functional language.
- Students can share finished programs by link.

## Benefits for teachers
- The Bootstrap Algebra course links coding to math.
- The editor needs only a browser.
- Teachers can have students log in only to save.

## Benefits for schools
- The service is free.
- It runs in a modern browser.
- Saving needs a Google sign in, which sends data to the vendor.

## Where is the AI?
This tool has no AI. The editor compiles and runs the code that students write. Students build logic and function skills as they write programs that match math ideas.

## Privacy and safety
Students can code without logging in, and the internet is always needed. Saving requires logging in with a Google account. The vendor stores saved programs for logged in users for up to 10 years and deletes them on request. It also records browser, computer type, OS, and ISP information and may analyze aggregate data with services such as Google Analytics. Name and email are collected only if given voluntarily. The policy does not mention children, minors, COPPA, or FERPA. A teacher should decide whether students will log in at all.

### computer_science

3. Share a program link with a partner and ask them to read the code.
4. Fix a program that gives the wrong answer.
5. Build a small game using functions only.

2. Graph the output of a function and describe the pattern.
3. Compare two functions and decide which grows faster.
4. Translate a word problem into a function.
5. Check a function by hand and by program.
