## Overview
GPT4All is a free, open source desktop chat app from Nomic. It runs language models locally on Windows, macOS, and Linux. A feature called LocalDocs lets the model answer from files and folders on the computer. A GPU is not required.

## Benefits for students
- Students can chat with an AI that runs on their own computer.
- Students can ask questions about their own files with LocalDocs.
- Students see how model choice affects answers.

## Benefits for teachers
- The app has a simple graphical chat window.
- Teachers can show a private chat that does not use the cloud.
- LocalDocs can help teachers search class notes.

## Benefits for schools
- The app is free and the code is open source.
- It runs on older hardware, such as an Intel Core i3 2nd Gen.
- Models are several GB each, and IT may need to approve the install. Chromebooks are not supported.

## Getting started
- [ ] Download the installer from the GPT4All site.
- [ ] Ask IT to approve the install.
- [ ] Run the installer and accept the terms.
- [ ] Download at least one language model while online.
- [ ] Do not add API keys for hosted models. They send data out.
- [ ] Go offline and test a chat.
- [ ] Try LocalDocs with a folder of class notes.
- [ ] Delete chat history after use on shared computers.

## Where is the AI?
The AI is a language model that handles chat and document question answering. It runs on the local computer. Students ask questions, read the answers, and check them against the source files. The app can also connect to hosted models through API keys, and that would send data out.

## Privacy and safety
No account is needed and the internet is used for setup. A University of British Columbia page says chats with downloaded models never leave the device. It says app analytics and prompt sharing are opt in at installation. Chat history is stored on the device in a format that is not necessarily encrypted. LocalDocs files are copied into a database that is not encrypted. Using an API key model sends prompts to that provider. A teacher should leave API keys out, decline analytics, and clear chat history on shared computers. UBC notes that instructors cannot require a tool without a privacy impact assessment unless an alternative exists.
