## Overview
UBMP4 is a low-cost development board built around a Microchip PIC16F1459 microcontroller. A high school computer technology teacher designed it for high school students. It has built-in pushbuttons, LEDs, a piezo beeper, and light and infrared sensors. Beginners can start without a breadboard. Students program it in C or assembly and drag a compiled .hex file onto the board's USB drive.

## Benefits for students
- Students start with buttons and LEDs already on the board.
- Students program in C, a language used in industry.
- Students drag a file onto a USB drive to load code.

## Benefits for teachers
- The mirobo.tech site offers free lessons with 5 introductory activities, 4 project starters, and 5 advanced coding topics.
- A USB bootloader means no separate programmer is needed.
- The board was designed for high school classes and maker spaces.

## Benefits for schools
- The price was not stated on the pages read. Bare PCBs, kits, and assembled boards are offered.
- Hardware and code are open source.
- MPLAB Xpress runs in a browser, which works on Chromebooks.

## Getting started
- [ ] Find the UBMP4 board and lessons on mirobo.tech.
- [ ] Buy a board or kit.
- [ ] Solder the kit if you bought one.
- [ ] Install MPLAB X, or use MPLAB Xpress in a browser.
- [ ] Compile a first .hex file.
- [ ] Drag the file onto the board's USB drive.
- [ ] Work through the first introductory activity.

## Where is the AI?
The board has no AI. It runs the C code that students write. Students build skills in logic and sensor data.

## Privacy and safety
The board runs programs locally and has no wireless features. No account is needed with the MPLAB X desktop IDE and the internet is used at setup. The cloud based MPLAB Xpress would involve a Microchip account, and the research did not review its privacy terms. The research found no privacy policy for mirobo.tech. Choose the desktop IDE if the school wants to avoid accounts. Supervise any soldering of kits.

## Ideas by subject
### engineering
1. Use the built-in LEDs and buttons to test how a circuit responds.
2. Follow an introductory activity from mirobo.tech and record the results.
3. Measure light with the light sensor and note the readings.
4. Solder a kit board and test each part.
5. Plan a project from the project starters and build it.

### computer_science
1. Write a C program that blinks an LED and drag it onto the board.
2. Change the timing in the program and watch the effect.
3. Use a pushbutton to start the beeper.
4. Read a program and explain each line.
5. Debug a program that does not light the LED.
