## Overview
This free online course is for educators and volunteers who support learners, usually aged 7 to 14, moving from Scratch to Python. It has three modules on transferring skills, exploring the limits of Scratch, and developing Python skills. The course takes 3 to 6 hours and ends with a certificate. Participants should already have experience with both languages.

## Benefits for students
- Learners move from blocks to text code with a guided path.
- Learners keep the thinking skills that they built in Scratch.
- Learners use the online Code Editor for most activities.

## Benefits for teachers
- The course earns a certificate on completion.
- It uses Scratch 3 and Python 3.
- Teachers in England can reach it through the Teach Computing site for NCCE certification, per a search snippet.

## Benefits for schools
- The course is free after login.
- It runs in a browser on Chromebooks, Windows, Mac, and Linux.
- The page shows a 2025 Raspberry Pi Foundation copyright and states no open license.

## Getting started
- [ ] Find the Moving from Scratch to Python course on the Raspberry Pi Foundation Training Hub.
- [ ] Ask IT to review the Training Hub login and privacy terms.
- [ ] Create a free Training Hub login.
- [ ] Start Module 1 on transferring skills.
- [ ] Open Scratch 3 and the online Code Editor in a browser.
- [ ] Finish Module 2 and Module 3.
- [ ] Plan 3 to 6 hours across several days.

## Where is the AI?
The course has no AI. It builds an AI-related skill, which is moving from blocks to text code. Learners see that the same logic works in two languages. That step prepares them for text-based work such as data and machine learning.

## Privacy and safety
An account is needed, and the internet is needed at all times. The course runs in the vendor's cloud. The materials do not state what data the Training Hub keeps. A teacher should check the account terms and the Code Editor rules before learners sign in.

## Ideas by subject
### computer_science
1. Take a Scratch project and rebuild one of its scripts in Python, as Module 1 suggests.
2. List what Scratch does well and where it hits limits.
3. Write a Python loop that repeats an action five times.
4. Compare a Scratch variable with a Python variable.
5. Add a new feature to a Python program in the online Code Editor.
