## Overview
LibreSprite is a free pixel art and animation editor. It is a fork of the last open source version of Aseprite. Students draw sprites using layers, frames, and palettes. They preview the animation as they work.

## Benefits for students
- Students draw pixel by pixel and learn to plan an image carefully.
- Students make short animations with frames and onion skinning.
- Students can follow older Aseprite tutorials. The interface is similar.

## Benefits for teachers
- The tool is free and easy to learn.
- Teachers can use it with students from grades 3 to 12.
- Reviewers say it lags behind newer Aseprite features, but the core tools are enough for class.

## Benefits for schools
- There is no cost for the software.
- It runs on the device and needs no account.
- The research notes that installation may make deployment harder in some classrooms. Ask IT early.

## Getting started
- [ ] Download the build for your operating system from the LibreSprite project site.
- [ ] Ask IT to install it on school computers.
- [ ] Open the program and create a small canvas, such as 32 by 32 pixels.
- [ ] Draw a simple character on one layer.
- [ ] Add a second frame and change the character slightly.
- [ ] Turn on onion skinning and play the animation preview.
- [ ] Try a browser tool such as Piskel for younger students who need something simpler.

## Where is the AI?
LibreSprite has no AI. The vendor describes no AI features. It builds sequencing skills. Students put frames in order and see how small changes create motion.

## Privacy and safety
No account is needed, and the internet is used for download and setup. The desktop editor saves files locally. The official page links an Online section whose contents were not shown, and no privacy policy was found. A teacher should check where students save files. Shared lab computers may clear them.

## Ideas by subject
### visual_arts
1. Draw a self-portrait in pixel art using a limited palette of four colors.
2. Create a tile that repeats and test it with the tiled drawing mode.
3. Design a character on layers with separate parts for hair and clothes.
4. Draw a landscape and compare how colors change the mood.
5. Redraw a famous painting as pixel art and explain the choices.

### theater_media
1. Make a four-frame walking animation and play it in the preview.
2. Use onion skinning to draw a bouncing ball that speeds up and slows down.
3. Design an animated title card for a class video.
4. Create a short looping animation for a school event poster.
5. Plan an animation on paper first, then build it frame by frame.
