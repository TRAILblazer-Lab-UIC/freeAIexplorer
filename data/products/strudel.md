## Overview
Strudel is a web-based live coding environment that brings the TidalCycles pattern language to JavaScript. Alex McLean and Felix Roos started it in 2022. Users write short code patterns in the browser to make music with built-in samples and synths. It suits students in grades 6 to 12.

## Benefits for students
- Students hear their code turn into music right away.
- Students learn rhythm patterns through a short notation called mini-notation.
- Students can follow a guided workshop covering first sounds, notes, effects, and pattern functions.

## Benefits for teachers
- A guided workshop is available in English and German.
- A paper reports teaching Strudel to girls aged 10 to 15.
- An Italian middle school study introduced live coding to students aged 11 to 14.

## Benefits for schools
- The tool is free and the code is open source.
- Nothing is installed and no account is needed.
- It runs in a browser with audio output, including on Chromebooks.

## Getting started
- [ ] Open strudel.cc in a browser.
- [ ] Check that the computer has working audio. Headphones help in a shared room.
- [ ] Work through the guided workshop yourself.
- [ ] Try the first sounds and change one note.
- [ ] Review the privacy terms of the site. The research did not confirm them.
- [ ] Plan a short first lesson on one pattern.
- [ ] Ask students to save their code in a document.

## Where is the AI?
Strudel has no AI. Students type short code patterns that the browser turns into sound. They practice pattern spotting and learn how a few lines of text can repeat and change.

## Privacy and safety
No account or install is needed. The REPL runs in the browser, and sample banks load from the network. The internet is likely needed when sounds load. The research did not confirm offline use. It found no privacy policy, and the materials do not say whether the site collects data. A teacher should check the site's privacy terms and plan where students store their code. A teacher should also set a volume rule for a shared room.

## Ideas by subject
### music
1. Write a one-line pattern and listen to the rhythm it makes, following the first sounds in the workshop.
2. Change the notes in a pattern and describe how the mood shifts.
3. Layer a drum pattern and a melody and balance their volume.
4. Add an effect and describe what it does to the sound.
5. Perform a short live coding set for the class.

### computer_science
1. Write a pattern in the code editor and predict the sound before you run it.
2. Use a pattern function to repeat or reverse a rhythm.
3. Find a mistake in a pattern that stops it playing and fix it.
4. Compare two code patterns that sound the same and explain which is shorter.
5. Explain to a partner how a line of code becomes a beat.
