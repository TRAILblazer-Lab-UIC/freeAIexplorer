## Overview
This Google Sites collection pairs California computer science standards with other subjects at each grade level, including PE and arts. The grade 3 PE page has an unplugged Fitness Circuit Algorithms activity and a plugged lesson that codes an interactive fitness trainer in Scratch. Other pages cover dance coding in Scratch and ScratchJr. The lessons cite California PE and CS standards for grades K-6.

## Benefits for students
- Students learn algorithms by moving their bodies.
- Students code characters that exercise and dance.
- Students can start with an unplugged lesson and move to a screen.

## Benefits for teachers
- Each grade page offers both unplugged and plugged lessons.
- Pre-made code templates give extra support.
- PE and arts teachers can teach computer science in their own classes.

## Benefits for schools
- The lessons are free.
- Unplugged lessons need only cones and paper.
- Plugged lessons need devices and the internet.

## Getting started
- [ ] Open the Google Sites collection and choose a grade level page.
- [ ] Pick the unplugged or the plugged lesson.
- [ ] Gather cones, paper, or devices.
- [ ] Look at the code templates for extra support.
- [ ] Note that some lesson design tools may sit behind a button that needs a login.
- [ ] Check which Scratch or ScratchJr account students will use.
- [ ] Teach the unplugged lesson first.

## Where is the AI?
These lessons have no AI. They build the skills of sequencing and algorithms, as students plan the order of exercises and dance moves. Loops and timers add logic.

## Privacy and safety
The lessons are public Google Sites pages, and the internet is needed throughout. The materials do not state what accounts or data the lessons need. The plugged lessons use Scratch or ScratchJr, and the research did not check the data flow of those tools. Only the grade 3 PE page was read directly. A teacher should check the privacy terms of the coding tool and the login behind the lesson design button.

## Ideas by subject
### health_pe
1. Brainstorm four or five exercises with a partner and write an algorithm for a fitness circuit, as in the grade 3 lesson.
2. Run a partner's circuit by following only the written steps.
3. Add a loop to a circuit to repeat one exercise.
4. Code a character in Scratch that leads a fitness routine.
5. Compare the paper circuit with the coded one and explain a difference.

### computer_science
1. Write an algorithm for a fitness circuit with no devices.
2. Code an interactive fitness trainer in Scratch using loops and timers.
3. Debug a partner's dance code.
4. Use a template and change one block.
5. Explain what a loop does in a dance.

### visual_arts
1. Code a short dance sequence for a digital character in Scratch.
2. Design a costume for a character before coding it.
3. Choose a backdrop that fits a dance style.
4. Match movements to a count of beats.
5. Show the dance to the class and describe the choices.
