## Overview
Scilab is free and open source software for numerical computation. It has hundreds of math functions, a programming language, and 2D and 3D graphics. It includes Xcos, a graphical editor for modeling and simulating systems. It suits older students in advanced math and engineering courses.

## Benefits for students
- Students plot math functions in 2D and 3D.
- Students build and run models with block diagrams in Xcos.
- Students practice a language similar to MATLAB.

## Benefits for teachers
- Scilab Enterprises has published teacher booklets for French high school math and engineering.
- Scilab tutorials are available.
- The teacher learning curve is advanced.

## Benefits for schools
- The software is free and open source.
- Everything runs on the computer after installation.
- It runs on Windows, Linux, and macOS but not on Chromebooks.

## Getting started
- [ ] Download the installer from scilab.org.
- [ ] Ask IT to approve the install on school machines.
- [ ] Install Scilab on one test computer.
- [ ] Work through a Scilab tutorial.
- [ ] Plot a simple function to check that graphics work.
- [ ] Open Xcos and build a small model.

## Where is the AI?
Scilab has no AI. It is a tool for numbers, plots, and simulations. Students build data skills as they compute, plot, and model.

## Privacy and safety
No account is needed. Scilab is a desktop application that computes on the local computer, and the internet is used at setup. The research found no student data collection but did not read the website privacy policy. A teacher should check that the install is approved before students use it.

## Ideas by subject
### math
1. Plot a function in 2D and describe its shape.
2. Create a 3D plot of a surface and rotate it to look for patterns.
3. Write a short script that computes a list of values and graph the result.
4. Solve a system of equations with a built-in function and check the answer by hand.
5. Compare a data table with a fitted curve and discuss how well it matches.

### engineering
1. Use the Scilab and Xcos teaching booklet to build a simple block diagram model.
2. Simulate a system in Xcos and change one setting to see the effect.
3. Model a basic control loop and plot the output.
4. Write a script that simulates a falling object and graph the speed.
5. Present a model to the class and explain each block.
