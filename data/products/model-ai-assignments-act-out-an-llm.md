## Overview
In this unplugged activity, students act as a large language model and generate a sentence from a prompt. The class starts with a prompt and a first token. Students vote on the next token from a small bank. This introduces tokens and next word prediction. The core activity takes no more than 15 minutes for grades 5 to 12.

## Benefits for students
- Students learn what a token is.
- Students see how a sentence grows one word at a time.
- Students take part in a class vote that models a language model.

## Benefits for teachers
- The download has classroom slides and a facilitator guide.
- The core activity is short.
- Variants compare the output with a real LLM or add transformers and attention.

## Benefits for schools
- The PDFs are free.
- The activity needs no devices, accounts, or internet.
- No student data is collected.

## Where is the AI?
The activity has no running AI program. The class acts as a large language model that picks the next token by vote. Students see how each choice builds on the last. An optional variant compares the class sentence with output from a real LLM using the same prompt.

## Privacy and safety
The core activity runs on paper, and the research found no account needs, no internet need, and no student data collection. The optional comparison enters the class prompt into a real LLM. That step sends the prompt to the LLM provider, and the research did not review any provider. A teacher should check school rules and the provider's terms before using a real LLM.

## Ideas by subject
### computer_science
1. Vote on the next token from the bank and watch the sentence grow.
2. Change one token and see how the rest of the sentence changes.
3. Explain to a partner what a token is.
4. Compare the class sentence with the sentence a real LLM gives for the same prompt.
5. Describe where the class vote is like a real language model and where it is not.

### ela
1. Build a sentence word by word from a prompt and read it aloud.
2. Edit the class sentence into a smooth one.
3. Make a new bank of words for a different prompt.
4. Compare two class sentences and tell which reads better.
5. Write a short paragraph that explains how a sentence is made one word at a time.
