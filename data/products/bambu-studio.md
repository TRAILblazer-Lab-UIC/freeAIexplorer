## Overview
Bambu Studio is free software that slices 3D models for Bambu Lab printers. It reads 3MF, STL, STEP, SVG, OBJ and AMF files and supports multicolor painting. It suits middle and high school makerspaces that own a Bambu Lab printer. Students load a model, set it up on a plate, and send it to print.

## Benefits for students
- Students see how a digital model becomes layers of a real object.
- Students can paint a model in several colors before printing.
- Students learn project-based work with plates and print settings.

## Benefits for teachers
- The printer profiles are tuned for Bambu printers. Teachers spend less time on settings.
- Teachers can monitor and control a printer from the software.
- A plate can go to several printers at once.

## Benefits for schools
- The software costs nothing. Printers are bought separately.
- It runs on Windows, macOS and Linux.
- Accounts are optional. Printing from an SD card keeps files off the cloud.

## Getting started
- [ ] Download Bambu Studio from the Bambu site or from GitHub.
- [ ] Ask IT to install it on the lab computers.
- [ ] Decide on SD card printing or the optional networking plugin.
- [ ] Choose cloud accounts only after reading the privacy policy.
- [ ] Open a sample model and pick the printer profile.
- [ ] Slice the model and review the preview layer by layer.
- [ ] Print a small test object first.

## Where is the AI?
Bambu Studio has no AI. It is a slicer that students run on a desktop computer. Students build skills in planning, sequencing and spatial reasoning as they prepare a print.

## Privacy and safety
Accounts are optional and the internet is needed at setup. Cloud print jobs can send 3D model files and printing information to Bambu, according to a search snippet of the privacy policy. The research did not read the policy. The core app works without the optional networking plugin, which uses closed libraries, and prints can start from an SD card. A forum post describes a school that would not approve Studio over privacy concerns. A teacher should check how shared logins work in a school lab.

### engineering
1. Slice a classroom design and compare the print time at two layer heights.
2. Print a part for a school project and measure how well it fits.
3. Test the strength of a part printed with two different infill settings.
4. Paint a model in multiple colors and explain the design choice.
5. Plan a plate of several parts and decide the best order to print them.

1. Prepare a product prototype for printing as part of a fabrication pathway unit.
2. Run a mock print shop where students slice and print requests from classmates.
3. Document each step from file to finished part in a short guide.
4. Compare a printed part to its design file and list any differences.
5. Estimate the material use for a job and write a simple cost note.
