## Overview
Balabolka is a freeware text-to-speech program for Windows. It reads text aloud with voices installed on the system through Microsoft SAPI. It can read the clipboard, extract text from documents and save speech as audio files. Users adjust rate and pitch and can fix pronunciations with a substitution list.

## Benefits for students
- Students can hear text read aloud.
- Students who find print hard to read can listen instead.
- Students can proofread by listening.

## Benefits for teachers
- The program reads documents and the clipboard.
- Teachers can save speech as audio files.
- The University of Kent suggests it for people who find print hard to read.

## Benefits for schools
- The program is free.
- It works offline on a Windows computer.
- IT needs to install it and any extra voices.

## Getting started
- [ ] Download Balabolka from the official site.
- [ ] Ask IT to install it on Windows computers.
- [ ] Check that at least one SAPI voice is installed.
- [ ] Install extra voices separately if wanted.
- [ ] Paste text and press play.
- [ ] Adjust rate and pitch.
- [ ] Save a sample as an audio file.

## Where is the AI?
Balabolka uses text-to-speech with voices installed on the device. The vendor does not describe any other AI. The voices come from the computer. The research did not evaluate cloud voices. Students listen to text and use what they hear to improve their writing.

## Privacy and safety
No account is needed and the program runs locally with voices installed on the computer. The research found no privacy policy on the official page. Data handling depends on the voices chosen. The research did not evaluate cloud voices. The materials do not say what data the software collects. A teacher should check which voices are installed and confirm that none send text to a cloud service. The program is Windows only.
