## Overview
Klangmeister is a browser based live coding environment for music. Users write ClojureScript that is compiled in the browser and plays through the Web Audio API. Synthesis comes from CLJS Bach and composition from the Leipzig library. It suits advanced students who already know code.

## Benefits for students
- Students hear their code play right away.
- Students learn a new language through music.
- Students shape sound by writing code.

## Benefits for teachers
- The tool needs no install and runs in a browser.
- A Habr review says it works best in Chrome.
- Writing music needs ClojureScript knowledge. Teachers rate it advanced.

## Benefits for schools
- The tool is free and the code is open.
- The internet is needed for setup only.
- The last repository push was in January 2020. Updates may be rare.

## Getting started
- [ ] Open Klangmeister in Chrome.
- [ ] Check that the browser has Web Audio.
- [ ] Run one of the sample pieces.
- [ ] Change one note and play it again.
- [ ] Read about the Leipzig library for composing.
- [ ] Use headphones in class.
- [ ] Plan a first lesson with a short melody.

## Where is the AI?
Klangmeister has no AI. It plays what the code says. Students build pattern spotting and sequencing skills as they write loops and rhythms.

## Privacy and safety
No account is needed, and the internet is used to load the tool. The README describes compilation and synthesis in the browser. No privacy policy exists on the repository, and the research did not test the demo. A teacher should test the tool in the school browser before class.

## Ideas by subject
### music
1. Run a sample piece and describe the rhythm and pitch.
2. Change the notes to make a new melody.
3. Write a four beat pattern and loop it.
4. Layer two parts and describe how they fit.
5. Perform a short live coded piece for the class.

### computer_science
1. Read a short ClojureScript snippet and predict the sound.
2. Change a value in the code and describe the change.
3. Write a function that plays a scale.
4. Use a loop to repeat a pattern.
5. Debug a piece that does not play.
