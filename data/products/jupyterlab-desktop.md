## Overview
JupyterLab Desktop is a standalone application that launches JupyterLab on the computer. It bundles its own Python environment. There is no separate pip setup. Students open notebooks and folders by double click or drag and drop. It can also connect to a JupyterLab server that is already running.

## Benefits for students
- Students open a notebook with a double click.
- Students get Python without a separate install.
- Students keep each project in its own folder.

## Benefits for teachers
- Teachers skip the pip step.
- A jlab command line launcher is available.
- Teachers can connect to a local or remote JupyterLab server.

## Benefits for schools
- The software is free and the code is open.
- It runs on Windows 10 or 11, macOS 12 or later, and several Linux versions.
- Installing on school machines may need admin rights. The brief says it may be easier than pip, but that was not verified.

## Getting started
- [ ] Download the installer for your operating system.
- [ ] Ask IT for admin rights or help with the install.
- [ ] Run the installer.
- [ ] Open the app and choose a working folder.
- [ ] Create a notebook and run a short Python cell.
- [ ] Note that only prebuilt extensions are supported.
- [ ] Keep student notebooks in a folder on the school drive.

## Where is the AI?
JupyterLab Desktop has no AI. It runs the code that students write. Students build data and coding skills by running cells and reading the output.

## Privacy and safety
No account is needed, and the internet is used for setup. Notebooks are saved on the local device. The repository page does not mention telemetry or update checks, and the research did not confirm either. Connecting to a remote server sends work to that server. A teacher should check where students save their folders and take care with remote connections.
