## Overview
QGIS Cloud is a web service from Sourcepole for publishing QGIS projects as web maps. A plugin uploads projects and data to hosted PostGIS databases. The free plan makes published maps accessible to anyone. The paid Pro plan limits access.

## Benefits for students
- Students share a finished map as a web page.
- Students see how their data becomes an online map.
- Students work toward a real audience.

## Benefits for teachers
- Teachers can publish class maps without running a server.
- The plugin connects to QGIS desktop.
- A support FAQ mentions an Education Plan of about 10 accounts, but it is three years old.

## Benefits for schools
- A free plan exists. A search snippet says it is for non-commercial use with one 50 MB database.
- Pro prices were not found.
- Maps on the free plan are public. Schools should review what students upload.

## Getting started
- [ ] Find QGIS Cloud on the Sourcepole site and read the plan details.
- [ ] Ask IT and school leaders to review the privacy terms.
- [ ] Sign up for an account.
- [ ] Install the QGIS Cloud plugin in QGIS.
- [ ] Create a database for a test project.
- [ ] Publish a map that holds only public data.
- [ ] Check what students upload before they publish.

## Where is the AI?
QGIS Cloud has no AI. It builds data skills. Students store data in a database and show it on a map. That practice teaches how data moves from a source to a display.

## Privacy and safety
An account is needed, and the internet is needed at all times. Uploaded map data and account details go to the vendor. All maps published on the free plan are public to anyone. The research did not review a privacy policy and did not find where the servers are hosted. A teacher should check every file before students publish it.
