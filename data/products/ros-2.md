## Overview
ROS 2 is a set of open source software libraries and tools for building robot applications. It is used mainly in university and professional robotics. Advanced high school students could use it on a school computer. No K-12 curriculum was found.

## Benefits for students
- Students learn the same robot software that professionals use.
- Students write robot programs in Python or C++.
- Students follow beginner command-line tutorials at their own pace.

## Benefits for teachers
- Beginner tutorials give teachers a ready starting point.
- Simulation and visualization tools let a class test robot code without a robot.
- Teachers with Linux skills can build an advanced elective around it.

## Benefits for schools
- The software is free. A compatible robot is a separate cost.
- Setup happens once online, and the work runs on the local computer after that.
- IT approval and staff with Linux skills are likely needed.

## Getting started
- [ ] Find the ROS 2 documentation and pick a current distribution.
- [ ] Ask IT to approve an install on one computer that can run Ubuntu Linux.
- [ ] Install the chosen ROS 2 distribution following the official steps.
- [ ] Work through the beginner command-line tutorials yourself first.
- [ ] Try the Python client library, rclpy, with a short example.
- [ ] Open a simulation or visualization tool and explore it.
- [ ] Choose one or two advanced students to try the tutorials.

## Where is the AI?
ROS 2 has no AI of its own. It is a toolkit for robot software that runs on the local computer. Students build skills in logic and in how a robot program is structured.

## Privacy and safety
ROS 2 is installed on the local computer and has no student accounts. The internet is used at setup. The research did not verify whether the toolkit sends any data. The official documentation sites blocked the research fetch. The license and platforms are unconfirmed. A teacher should check that the install comes from the official sources and ask IT to review what the toolkit sends.

## Ideas by subject
### computer_science
1. Work through the beginner command-line tutorials and write down what each command does.
2. Write a short Python program with rclpy that sends a message.
3. Compare how Python and C++ client libraries handle the same simple task.
4. Run a simulated robot and change its code to alter its behavior.
5. Explain in a short report how separate programs in a robot talk to each other.

### engineering
1. Study how a robot system splits into small parts that work together.
2. Use a visualization tool to view robot sensor data and describe what it shows.
3. Run a simulated robot and note how its design affects its movement.
4. Plan the software parts needed for a simple delivery robot.
5. Research how professional robotics teams use ROS 2 and share findings with the class.
