## Overview
MiniWorldMaker is a Python library built on pygame. Students create 2D mini worlds and games with a few lines of code. The documentation names Greenfoot as the model for the framework. It supports tile based and pixel based worlds, animations, sound, built-in GUI elements, SQLite save and load, and a physics engine.

## Benefits for students
- Students write real Python and see a result on screen.
- Students learn objects by placing actors in a world.
- Students can add sound, animation, and physics.

## Benefits for teachers
- The documentation is in English and German.
- The Greenfoot style model suggests an objects first approach.
- Tutorials are part of the documentation.

## Benefits for schools
- The library is free.
- It needs Python 3 and pygame on Windows, Mac, or Linux.
- Chromebooks would need a Linux environment.

## Getting started
- [ ] Install Python on a test computer.
- [ ] Install the package from PyPI with pip.
- [ ] Open any Python editor and write a first world.
- [ ] Ask IT to approve the install on student machines.
- [ ] Read the documentation and tutorials.
- [ ] Plan for internet access at install time.

## Where is the AI?
This library has no AI. It builds the skills of writing code and using objects. Students practice modeling things in a world with rules.

## Privacy and safety
It is a local Python library installed with pip, and no account is needed. The internet is used at install time. The documentation describes no telemetry. The docs link an Impressum, which is a legal notice, and the research found no privacy policy. A teacher should check that Python and pygame install on school devices before class.
