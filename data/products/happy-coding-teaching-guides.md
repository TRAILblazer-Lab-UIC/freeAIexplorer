## Overview
The Happy Coding semester guide is a 15-week plan for an introductory coding course for students who have never coded. It maps weekly topics to free tutorials in either p5.js or Processing. The author suggests about 25 percent lecture, 25 percent worked example, and 50 percent lab time. It is aimed at high school and up.

## Benefits for students
- Students draw, animate, and work with images through code.
- Students move from calling functions to libraries and open projects.
- Students can pick a browser path or a desktop path.

## Benefits for teachers
- The plan lists 15 weekly topics with lab ideas for each week.
- p5.js is recommended for easy sharing and for most beginners.
- Processing suits students heading to AP Computer Science A.

## Benefits for schools
- The guides and tutorials are free.
- p5.js runs in a web browser. The Chromebook claim was not tested.
- Processing needs a desktop install.

## Getting started
- [ ] Find the Happy Coding semester guide online.
- [ ] Choose p5.js or Processing for your class.
- [ ] For p5.js, open the p5.js web editor in a browser.
- [ ] For Processing, ask IT to install the desktop app.
- [ ] Try the Week 1 Calling functions tutorial.
- [ ] Plan the class time at 25 percent lecture, 25 percent worked example, and 50 percent lab.
- [ ] Decide how students save and share their sketches.

## Where is the AI?
These guides have no AI. They build programming skills. Students use functions, loops, and variables to make drawings and animations. The code runs in the browser or on the computer.

## Privacy and safety
The guides do not state whether student accounts are needed. The p5.js editor can run in a browser and Processing runs on the device. The internet is needed for setup. A teacher should check whether students need an account to save work in the p5.js editor and where files are stored.

## Ideas by subject
### computer_science
1. Call a drawing function to put a circle on the canvas.
2. Use a variable to change the size of a shape.
3. Write a loop that draws a row of shapes.
4. Make a shape react to the mouse.
5. Build a small open project and present it.

### visual_arts
1. Draw a self-portrait using basic shapes in code.
2. Animate a shape across the canvas.
3. Load an image and change its colors with code.
4. Make a pattern that repeats with small changes.
5. Write a short artist statement for a coded piece.
