## Overview
Create With Code is a Python editor that runs in a web browser. It includes a micro:bit simulator and a Raspberry Pi GPIO simulator. It is designed for students and teachers who are learning Python. No physical micro:bit is needed.

## Benefits for students
- Students write Python with syntax highlighting.
- Students test micro:bit code in a simulator.
- Students try Raspberry Pi GPIO ideas with no hardware.

## Benefits for teachers
- No accounts are needed.
- Teachers can open the site in minutes.
- A version can run from a local copy of the repository.

## Benefits for schools
- The tool is free and the repository is licensed GPL-3.0.
- It works on Chromebook, Windows, Mac and Linux in a browser.
- The repository holds partial source only and the save and share features are not in it.

## Getting started
- [ ] Open the Create With Code website in a browser.
- [ ] Try a short micro:bit program in the simulator.
- [ ] Try the Raspberry Pi GPIO simulator.
- [ ] Ask IT to clone the repository for local use if needed.
- [ ] Check that the local version has no save or share feature.
- [ ] Have students copy their code to a file to keep it.
- [ ] Plan a first lesson that blinks an LED.

## Where is the AI?
Create With Code has no AI. Students write Python and the simulators run it in the browser. Students build skills in text coding, logic and sensors.

## Privacy and safety
No account is needed for the client side version, and it has no save or share features. The editor runs in the browser, and the research did not confirm whether the page needs the internet after it loads. The full version at create.withcode.uk lets users save and share code, and the research did not read its privacy handling. No privacy policy was found. A teacher should check which version students use and remind them to save code to a file.

## Ideas by subject
### computer_science
1. Write a Python program that shows a message on the micro:bit simulator.
2. Use a button in the simulator to change what the display shows.
3. Light a virtual LED with the Raspberry Pi GPIO simulator.
4. Write a loop that repeats a pattern on the display.
5. Debug a program that a partner wrote and explain the fix.
