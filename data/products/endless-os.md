## Overview
Endless OS is a free, open source operating system built for offline use. It is Debian based with a GNOME desktop and a read-only root file system. It comes with LibreOffice, GIMP, Inkscape, Blender, Audacity, Godot, learning games, and a large offline content library. The foundation says it runs on low-cost and older hardware.

## Benefits for students
- Students get creative and coding tools without needing the internet.
- Students can explore a large offline library.
- Students can use older computers.

## Benefits for teachers
- Office, art, audio, and game tools are already installed.
- The read-only file system helps keep the system stable.
- Learning games are included.

## Benefits for schools
- The system is free.
- A fetched article says free download is limited to five hundred computers a year without arrangement.
- IT staff must install it. Reviews note thinly documented school policy controls.

## Where is the AI?
Endless OS has no AI. It builds skills in using an operating system and creative tools. Students learn files, windows, and software on a Linux desktop.

## Privacy and safety
No account is needed and the system can run offline after install. Work stays on the computer. The page read does not describe privacy or telemetry, and no privacy policy was confirmed. Some web app wrappers, such as Duolingo, do not work offline, and online features use the vendor's or third parties' services. A teacher should ask IT about telemetry and about the school policy controls, which reviews describe as thinly documented.
