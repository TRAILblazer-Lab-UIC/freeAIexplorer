## Overview
Tracker is a free and open source video analysis and modeling tool for physics education. It is built on the Open Source Physics Java framework. Students track objects in video to get position, velocity, and acceleration data. They can build kinematic and dynamic models and compare them to the video. Installers exist for Windows, macOS, and Linux.

## Benefits for students
- Students turn a video of real motion into graphs and numbers.
- Students build models and compare them to the video.
- Students use curve fitting to find the rule behind the motion.

## Benefits for teachers
- It is designed for introductory physics labs and lectures.
- A Library Browser holds classroom tested videos and tracker files.
- A Singapore study had teachers use it in lessons.

## Benefits for schools
- The software is free and open source.
- Installers include their own Java VM.
- IT will need to install it on each computer.

## Getting started
- [ ] Download the installer for your operating system. Version 6.3.5 is listed for Windows and macOS.
- [ ] Ask IT to install it on a test computer.
- [ ] Open a video from the Library Browser.
- [ ] Track one object across the frames.
- [ ] Export the data and fit a curve.
- [ ] Record your own video for a lab.
- [ ] Plan a first lab using a classroom tested video.

## Where is the AI?
Tracker has no AI. It offers manual and automated object tracking that students set up and check. They build skills in data and modeling.

## Privacy and safety
No account is needed and the internet is used at setup. The app runs on the computer and videos stay on the device. The research found no privacy policy. The Library Browser can fetch online collections, which uses the internet. Review any video that shows students before it is shared. Ask IT whether to block the Library Browser.

## Ideas by subject
### science
1. Track a ball thrown in a video and find its velocity.
2. Compare the acceleration of two falling objects.
3. Film a cart on a track and analyze its motion.
4. Check a tracker model against the video and explain the difference.
5. Write a lab report using data from Tracker.

### math
1. Fit a curve to position data and name the type of curve.
2. Read the slope of a graph as velocity.
3. Compare a linear and a quadratic fit.
4. Use the Model Builder to match a graph.
5. Explain what the fit tells you about the motion.
