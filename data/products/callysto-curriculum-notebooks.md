## Overview
Callysto curriculum notebooks are Jupyter notebooks that help K-12 teachers add computational thinking to math, science, social studies, and humanities courses. The GitHub repo has folders for Arts, English Language Arts, Health, Languages, Mathematics, Science, Social Studies, and Technology Studies. Notebooks can serve as assignments or as interactive textbooks. Background code is hidden so teachers need little coding.

## Benefits for students
- Students work with real data and code in a subject they already study.
- Students can run and change code inside the notebook.
- Grade 6 students analyzed climate data and government spending with Callysto.

## Benefits for teachers
- Hidden code means teachers need little programming.
- A teacher training manual is available.
- Notebooks fit existing courses.

## Benefits for schools
- The materials are free and open source.
- The Callysto Hub is a free hosted workspace.
- Over 750 Canadian teachers were trained since 2018, per one account.

## Getting started
- [ ] Open the Callysto curriculum notebooks repo on GitHub.
- [ ] Pick a subject folder.
- [ ] Sign in to the Callysto Hub and clone the repo.
- [ ] Or install Jupyter on a school computer and download the notebooks.
- [ ] Read the teacher training materials linked from the repo.
- [ ] Ask the vendor about the Hub privacy terms.
- [ ] Run one notebook yourself before class.

## Where is the AI?
The vendor does not describe any AI. The notebooks build the skill of working with data, as students run code, view charts, and draw conclusions. Some notebooks may include data science content.

## Privacy and safety
Students use the Callysto Hub in the cloud, which is hosted through Syzygy and Cybera, and the internet is needed throughout. Accounts are listed as optional for teachers. The research did not read the Hub privacy terms, and the materials do not say what student data is collected. Batch notes say a local Jupyter install keeps data on the machine, but the page does not explain this. A teacher should check the Hub privacy terms or ask IT about running Jupyter on a school server.

## Ideas by subject
### math
1. Analyze a data set in a notebook and report the average.
2. Graph a pattern and describe it, as grade 6 classes did with climate data.
3. Change a number in a notebook and predict the chart.
4. Compare two data sets and state a conclusion.
5. Explain a notebook chart to a partner.

### science
1. Run a science notebook and record how a variable changes a result.
2. Plot temperature data from a local station.
3. Test a hypothesis with a notebook simulation.
4. Compare two sets of measurements.
5. Write a short lab summary from the notebook output.

### social_studies
1. Analyze government spending data and describe the biggest category.
2. Chart population data for a region.
3. Compare two maps built from data.
4. Ask a question about a data set and find an answer.
5. Present a finding with a chart.

### ela
1. Count word use in a short text with a notebook.
2. Compare two authors by sentence length.
3. Build a chart of the most common words in a poem.
4. Explain what the word counts suggest.
5. Write a short report from the results.

### computer_science
1. Read the code in a notebook cell and say what it does.
2. Change a Python value and rerun the cell.
3. Fix an error in a short notebook program.
4. Write a short cell that prints a message.
5. Explain how a notebook mixes notes and code.
