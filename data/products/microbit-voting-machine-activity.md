## Overview
A 2019 Teachers First blog post suggests this voting machine for a government or elections unit. The linked MakeCode project uses voter micro:bits that send yes or no votes by radio to a dashboard micro:bit. The blog calls it a way to bring coding into social studies. The post gives no grade level.

## Benefits for students
- Students see how a vote moves from one device to a tally.
- Students build a working model of an election.
- Students connect coding to a civics topic.

## Benefits for teachers
- The project links coding to a government or elections unit.
- The blog gives only a suggestion. The teacher plans the lesson.
- The build is on MakeCode, which has an online editor.

## Benefits for schools
- The code is free to use.
- The project needs several micro:bit boards.
- IT help is limited to a teacher install.

## Getting started
- [ ] Find the Teachers First blog post and open the MakeCode link.
- [ ] Gather several micro:bit boards.
- [ ] Open the voter and dashboard programs in MakeCode.
- [ ] Flash one board with the dashboard program.
- [ ] Flash the other boards with the voter program.
- [ ] Test a few votes before class.
- [ ] Plan a short lesson on voting and fairness.

## Where is the AI?
This project has no AI. It builds skills in logic and in sending data between devices. Students see how a program counts and displays results.

## Privacy and safety
No account is needed. The pages read do not discuss data handling, and they did not require a sign in. The internet is used at setup, and the votes move by radio between boards. The research read no privacy policy for this item. A teacher should check the MakeCode privacy terms. A teacher should also decide what students vote on and keep the topics classroom safe.

## Ideas by subject
### social_studies
1. Hold a mock class election with the voter boards and read the tally on the dashboard.
2. Compare a paper ballot with the micro:bit vote and list one strength of each.
3. Discuss why an election needs a way to count votes fairly.
4. Vote on a school choice and write a short report on the result.
5. Research how a government counts votes and compare the steps to the project.

### computer_science
1. Describe how a voter board sends a yes or no by radio.
2. Change the program so a vote needs a second button press.
3. Add a message on the dashboard that shows the total.
4. Test the system with ten votes and check that the count is right.
5. Explain how a program stores a number and adds to it.
