## Overview
Bitbloq is an online platform for programming, robotics, 3D design and app development. Its robotics tools come in Jr for beginners, Robotics for intermediate users and Advanced for Arduino code. It runs fully online with no install and the site lists Chrome and Chromebooks as compatible. Students program boards such as Arduino UNO.

## Benefits for students
- Students can start in blocks and move up to Arduino code.
- Students can work with no account.
- Students can connect a board and watch their code run.

## Benefits for teachers
- Teacher accounts manage classrooms and exercises.
- The tool offers three levels for different ages.
- The site is available in English and Spanish.

## Benefits for schools
- It is free to use with no account. Paid accounts exist and the official page lists 100 EUR per year or 11.99 EUR per month.
- It needs only a browser, which keeps IT work light.
- The official offline desktop app is no longer actively developed. A community fork keeps it running.

## Getting started
- [ ] Open bitbloq.cc in a browser.
- [ ] Try a Jr or Robotics project with no account.
- [ ] Decide whether to create a teacher account to manage a class.
- [ ] Read the privacy terms before students sign in.
- [ ] Connect an Arduino board by USB.
- [ ] Upload a first program that blinks an LED.
- [ ] Check which parts are still in alpha or beta before planning lessons.

## Where is the AI?
Bitbloq has no AI. Students drag blocks or write Arduino code and the board follows it. Students build skills in logic and sequencing.

## Privacy and safety
Accounts are optional and are meant for teachers. Students need not register. The official page says accounts save documents online. Saved projects then live on the vendor's servers. The privacy policy could not be fetched and the research did not review the terms. Work online needs the internet at all times. A teacher should read the privacy terms and use the no account option when it meets the class need.

## Ideas by subject
### computer_science
1. Build a block program that blinks an LED and then change the timing.
2. Move from blocks to Arduino code and compare the two views.
3. Write a program that reacts to a button press.
4. Debug a program that a partner wrote and explain the fix.
5. Plan a short program on paper and then build it in Bitbloq.

### engineering
1. Build a simple robot with an Arduino UNO and test its motors.
2. Use the 3D design tool to model a case for a board.
3. Test two ways to mount a sensor and choose the better one.
4. Draw a wiring plan before building a circuit.
5. Present the finished robot and describe each design choice.
