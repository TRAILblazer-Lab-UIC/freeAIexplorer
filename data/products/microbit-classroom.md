## Overview
micro:bit classroom is a free web tool for live coding lessons with the BBC micro:bit. A teacher creates a session, picks the MakeCode or Python editor, and shares a link. The teacher sees student code in real time. Neither teachers nor students register accounts. The support pages describe it as in Beta.

## Benefits for students
- Students join with a link and a name.
- Students get help while they code.
- Students can use the MakeCode or Python editor.

## Benefits for teachers
- The dashboard shows each student's code live.
- Sessions can be saved and resumed.
- A class report can be downloaded.

## Benefits for schools
- The tool is free.
- It runs in a browser and needs no install.
- Student names and code are exchanged between teacher and students during a session.

## Getting started
- [ ] Open classroom.microbit.org in a browser.
- [ ] Name a session and choose an editor.
- [ ] Pick starter code.
- [ ] Share the link or code with students.
- [ ] Keep the teacher window open for the whole session.
- [ ] Use Chrome or Edge to send code to a device.
- [ ] End the session when done. Ending it removes all students.

## Where is the AI?
The tool has no AI. The vendor describes no AI features. Students write micro:bit programs and teachers review them. Students build skills in sequencing and logic.

## Privacy and safety
No sign in is needed. Student names, code, and related information pass between teacher and students through a Foundation web service on Amazon Web Services and a third party messaging service from Pusher. The policy says the data is sent over HTTPS. It says Pusher cannot read student names or code, and the Foundation does not retain message content. A session cookie is removed when the session ends. Local storage is the default for saved work. The policy asks children under 13 to get consent from a parent or guardian. That is a consent rule and not an age limit. The research did not confirm how names are handled in saved reports. The internet is always needed, and the teacher must stay online. A teacher should check the privacy terms and tell students to use a first name.
