## Overview
This is an introductory Arm Learning Path with an estimated 45 minute reading time. Users set up Ollama on a Raspberry Pi 5, test GPIO pins with an LED, and build a smart home assistant. Natural language requests become actions on connected devices through a terminal or a FastAPI web dashboard. The path is designed to run without cloud services. It assumes Python and basic electronics skills and reads as an adult technical guide.

## Benefits for students
- Students run a language model on a small computer.
- Students wire an LED and control it with plain language.
- Students see how local AI keeps data on the device.

## Where is the AI?
The AI is a local large language model that runs through Ollama on the Raspberry Pi. It turns natural language requests into actions on connected devices. Students type a request, watch the LED respond, and then change the script to add new commands.

## Privacy and safety
No account is needed. The internet is used at setup to install Ollama and download models. The path is designed to run without cloud services, and requests and device data stay on the Pi. The page does not name a specific model. A teacher should review the script before students run it. A teacher should also set rules for which devices the assistant may control.
