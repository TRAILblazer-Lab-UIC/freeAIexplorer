## Overview
Pishi.ai is a web-based educational platform that offers a custom version of Scratch 3 with AI extensions. The help page lists FaceMesh, HandPose, PoseNet, Image Trainer, Object Detection, Google Teachable Machine import, Speech Recognition, an AI ChatBot, an AI Image Generator, Translate, and Text to Speech. The site says no installation or registration is needed. It is available in English, Arabic, Persian, Spanish, and Simplified Chinese.

## Benefits for students
- Students start a project in a browser in minutes.
- Students use their webcam for face, hand, and body projects.
- Students can work in a language that fits them.

## Benefits for teachers
- No installation or registration is needed.
- Help pages and extension guides are provided.
- The site is community developed and not affiliated with the Scratch Team.

## Benefits for schools
- The site is free.
- IT has little to install.
- Projects may not load in standard Scratch because of the custom extensions.

## Getting started
- [ ] Open pishi.ai in a browser.
- [ ] Start a Scratch project.
- [ ] Read the help page for the extensions.
- [ ] Add a FaceMesh or HandPose extension.
- [ ] Allow the webcam and test it.
- [ ] Check which extensions use the cloud.
- [ ] Save student projects to the device.

## Where is the AI?
The extensions cover face, hand, and body detection, image training, object detection, speech recognition, a chatbot, image generation, translation, and text to speech. Some likely run in the browser and some use cloud services. Students add the blocks and build projects that respond to a camera or a voice.

## Privacy and safety
No registration is needed and the site needs the internet at all times. The privacy policy says the site uses Google Analytics 4 through Google Tag Manager and a few cookies. It may collect anonymous usage events, such as which extensions load. It says those events do not include student names, chat messages, prompts, or generated content. The chatbot, image generator, and translation extensions likely send data to outside services, and the research did not confirm where. A teacher should check which extensions use the cloud before students use cameras, voices, or personal text.

3. Import a Google Teachable Machine model into a project.

2. Use Text to Speech to hear the phrase aloud.

4. Use Speech Recognition to check pronunciation of simple words.
