## Overview
This UNL TechEdge Hour of Code 2021 activity rewrites Lewis Carroll's Jabberwocky as an interactive p5.js piece. The poem has four parts. In each part, students find a clue near the top of the screen and interact with it to move through the poem. A toolbox offers more ways to play with p5.js, a JavaScript library for creative coding.

## Benefits for students
- Students read a poem in an interactive form.
- Students solve clues to move through each part.
- Students explore p5.js ideas in a toolbox.

## Benefits for teachers
- The activity opens with a link and needs no install.
- It fits the Hour of Code.
- The page lists K-12 as the grade range.

## Benefits for schools
- The activity is free.
- It runs in any browser.
- IT work is minimal.

## Where is the AI?
This activity has no AI. It builds skills in reading, interaction, and creative coding. Students see how code can shape a reading experience.

## Privacy and safety
The page mentions no accounts, and the internet is needed at all times. The activity is hosted on a personal site of its creator. The materials do not say what data the page collects, and the research did not open the activity page. A teacher should open the page first, check that it works on school devices, and ask IT to review the host site.

## Ideas by subject
### ela
1. Read Jabberwocky and list the made up words.
2. Play the interactive piece and describe how it changes the reading.
3. Explain the clue in each part and what it shows about the poem.
4. Write a short summary of the poem in plain words.
5. Compare reading the poem on paper and on screen.

### computer_science
1. Explore the toolbox and try one p5.js idea.
2. Describe how a clue on the screen responds to a click.
3. Predict what a change to the code would do.
4. Sketch an interactive version of another short poem.
5. Explain how code can add motion to text.
