## Overview
Kodu Game Lab is a 3D game development environment that teaches basic programming principles. Students build terrain, add characters, and program behavior with a visual tile language that reacts at once. It began as a Microsoft Research project for Xbox 360 and was ported to PC. The desktop build 1.6.18.0 runs on Windows and is in the Microsoft Store.

## Benefits for students
- Students see their game change right away.
- Students build both the world and the rules.
- Students practice cause and effect in code.

## Benefits for teachers
- The Kodu site has classroom resources.
- A New Zealand middle school embedded Kodu game development in regular classes to study engagement.
- The tool is easy for teachers to learn.

## Benefits for schools
- The download is free.
- It runs on Windows only. Chromebooks and Macs are not supported.
- IT can use the MSI, which needs a separate XNA Framework 4.0 install.

## Getting started
- [ ] Get Kodu from the Microsoft Store or download KoduSetup.EXE.
- [ ] Ask IT to use the MSI and install XNA Framework 4.0.
- [ ] Check that computers have DirectX 9.0c and .NET Framework 4.0 or higher.
- [ ] Open Kodu and build a small world.
- [ ] Add a character and a simple rule.
- [ ] Skip the Worlds area on the home page, which held placeholder content.
- [ ] Plan a short first lesson.

## Where is the AI?
Kodu has no AI. Students program behavior with tiles that follow fixed rules. They build logic and sequencing skills as they decide what happens when a character sees something.

## Privacy and safety
No account is needed, and the download page describes a local installer. No privacy policy was read. The status of the community sharing site is not stated. A teacher should check that students save games in a school folder and should not rely on the community worlds site.
