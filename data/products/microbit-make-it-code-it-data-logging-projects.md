## Overview
This 2022 news post introduces data logging projects for the micro:bit V2. The movement data logger records accelerometer readings ten times a second while worn on a shoe or leg. Students then open the MY_DATA file on the board and graph it. They use the peaks to set a threshold for a personal step counter. The projects are rated Intermediate.

## Benefits for students
- Students log real data from their own movement.
- Students graph the data and spot patterns.
- Students design a personal step counter from evidence.

## Benefits for teachers
- The project links coding, science, and math.
- A spreadsheet app is suggested for extension work.
- The post does not state a grade level.

## Benefits for schools
- The lessons are free. A micro:bit board is a paid purchase.
- The data stays on the board.
- A battery pack is needed for walking.

## Getting started
- [ ] Open the Movement data logger project.
- [ ] Flash the MakeCode project to a micro:bit V2.
- [ ] Attach a battery pack.
- [ ] Log data while walking.
- [ ] Plug in by USB and open MY_DATA.
- [ ] Graph the data in a table or spreadsheet.
- [ ] Use the peaks to set a step counter threshold.

## Where is the AI?
This project has no AI. Students log data and use a threshold rule. They build skills in data and pattern spotting.

## Privacy and safety
No account is needed, and the internet is used at setup. Accelerometer readings stay in the MY_DATA file on the board until a teacher copies them to a computer. New code or pressing A and B together erases them. The research read no privacy policy for this item. A teacher should check where students save the data files and who can see them.

## Ideas by subject
### computer_science
1. Flash the data logger to a micro:bit.
2. Read the MY_DATA file and describe what each column means.
3. Write a step counter that adds one for each peak.
4. Test the counter against a hand count.
5. Change the threshold and see how the count changes.

### science
1. Log walking data and compare it with running data.
2. Graph the data and find the peaks.
3. Explain what each peak means in the movement.
4. Test the logger on a shoe and on a leg.
5. Share findings in a short lab report.

### math
1. Read values from the graph and find the highest point.
2. Choose a threshold and justify it from the data.
3. Count peaks in a time interval and find the rate.
4. Compare the mean of two data sets.
5. Predict how many steps occur in a minute.
