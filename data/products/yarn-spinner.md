## Overview
Yarn Spinner is a set of tools for writing and delivering game dialogue. Writers build branching stories in a screenplay like language. A game engine then plays the story with simple APIs. It works with Unity, Godot, and pre release Unreal Engine, and a free browser tool is at try.yarnspinner.dev.

## Benefits for students
- Students write branching dialogue like game writers.
- Students can test their story in a free browser tool.
- Students link writing to real game code.

## Benefits for teachers
- The education page lists narrative design courses, visual novel programs, and beginner game jams.
- A VS Code extension helps with writing scripts.
- Setup is technical. Teachers may want support.

## Benefits for schools
- Core engines are free, including for coursework.
- Paid Yarn Spinner Plus and add ons exist. Institutional and per seat licenses are quoted.
- IT must install a game engine and the Yarn Spinner package.

## Getting started
- [ ] Open try.yarnspinner.dev to see a script run in the browser.
- [ ] Choose an engine such as Unity 2022.3 or later, or Godot 4.6 or later.
- [ ] Ask IT to install the engine and the Yarn Spinner package.
- [ ] Install the VS Code extension for writing scripts.
- [ ] Write a short scene with two choices.
- [ ] Contact hello@yarnspinner.dev for paid features.
- [ ] Share a sample script with students.

## Where is the AI?
This tool has no AI. The scripts follow the branches that writers create. Students build logic and sequencing skills as they plan choices and outcomes.

## Privacy and safety
Yarn Spinner runs on the computer and needs no account. The research did not review a privacy policy or the browser tool at try.yarnspinner.dev. The internet is needed at setup. A teacher should check the browser tool before students use it. A teacher should also review student dialogue for age appropriate content before it is shared.
