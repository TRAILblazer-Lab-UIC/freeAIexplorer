## Overview
This teaching concept covers decision tree learning for K-12. It pairs an unplugged start with hands-on machine learning and a look at social effects. Students build a decision tree by hand from a small dataset. They then train a model on the same data in the Orange data mining tool and compare the results.

## Benefits for students
- Students learn how a decision tree sorts data by building one with their own hands.
- Students compare their paper tree with a tree that software builds.
- Students try the method on real datasets in a project phase.

## Benefits for teachers
- The unplugged first step builds understanding before any software.
- The unit includes a reflection on how AI shapes society.
- The paper that describes it is free to read on arXiv.

## Benefits for schools
- The paper is free, and the license for Orange was not checked.
- Orange is described as running on the device. The research did not confirm offline use.
- IT will likely need to install Orange.

## Getting started
- [ ] Find the paper on arXiv and read the description of each phase.
- [ ] Prepare a small dataset that students can sort by hand.
- [ ] Ask IT to install the Orange data mining tool on student computers.
- [ ] Check the Orange license terms for your school.
- [ ] Run the hand-built tree activity first.
- [ ] Train a tree in Orange on the same data and compare the two trees.
- [ ] Plan a project with a real dataset.
- [ ] Note that the monkey dataset details were not confirmed from the paper.

## Where is the AI?
The AI is a decision tree model that learns to classify items from training data. It runs on the device in Orange, which students use after they build a tree by hand. Students compare both trees and then apply the method to their own data.

## Privacy and safety
Orange is described as running on the device, but the research did not read the paper in full. Whether Orange runs fully offline and how it handles data are unconfirmed. The materials do not state which tools or accounts students need. No privacy policy was found. A teacher should check Orange and its install source. A teacher should also review any real dataset before students use it.

## Ideas by subject
### computer_science
1. Build a decision tree by hand from a small dataset and test it on new examples.
2. Train a tree in Orange on the same data and compare it with the hand-built tree.
3. Change one item in the dataset and see how the tree changes.
4. Pick a real dataset and plan which question the tree should answer.
5. Write a short reflection on who could be affected by a tree that makes mistakes.
