## Overview
The micro:bit Python Editor is a web editor for writing MicroPython programs for the BBC micro:bit. It has a simulator, a reference with drag and drop snippets, autocomplete, an Ideas tab with starter projects, and error highlighting. Students save their work as Python or HEX files. It works inside micro:bit classroom for live lessons.

## Benefits for students
- Students test code in the simulator before they load it onto a board.
- Students get help from autocomplete, snippets, and error highlighting.
- Students can read the interface in several languages, including Spanish and French.

## Benefits for teachers
- The editor opens in a browser with no sign in and no install.
- The micro:bit classroom tool lets a teacher run a live lesson and save the whole class's code.
- The site offers a six lesson series called First lessons with Python and the micro:bit.

## Benefits for schools
- The editor is free, and the source code uses an MIT license.
- A board is an extra cost.
- The page lists Chrome and Edge for sending code to a board over WebUSB.

## Getting started
- [ ] Open python.microbit.org in a browser.
- [ ] Try the simulator with a starter project from the Ideas tab.
- [ ] Connect a micro:bit by USB and choose Send to micro:bit in Chrome or Edge.
- [ ] Download the HEX file and drag it to the board in other browsers.
- [ ] Ask students to save their code as a Python file.
- [ ] Try the six First lessons with Python and the micro:bit.
- [ ] Check which micro:bit version your boards use.

## Where is the AI?
This tool has no AI. It builds the skill of writing text code in Python, which is a base for later work with data and AI. Students practice sequencing and logic. They also practice reading error messages.

## Privacy and safety
No account is needed. The Foundation policy says python.microbit.org is hosted by the Foundation and is subject to server logs and Google Analytics cookies. Google stores anonymised IP addresses in the US, and cookies last up to two years. The policy says names, ages, and emails are not stored in cookies. The page describes no upload of student code. The research did not confirm full offline use after the first load. A teacher should check whether the school allows analytics cookies and which browsers support WebUSB.
