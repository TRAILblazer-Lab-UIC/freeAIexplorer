## Overview
Hob is a free, open source desktop app that runs open-weight AI models on the user's own computer. It can answer questions about documents and help fill out PDFs. The launch article names Gemma 4 and gpt-oss as the local models. Hob picks a model that fits the computer.

## Benefits for students
- Students can ask questions about a dense document and get a plain answer.
- Students see how an AI works on their own machine.
- Students can get help filling out a PDF form.

## Benefits for teachers
- The chat window is simple.
- Hob picks a model that fits the computer, which saves setup choices.
- Teachers can read long documents more quickly.

## Benefits for schools
- The app is free and the code is open source.
- The launch article says conversations, files, and results stay on the device.
- IT will likely need to approve the install. The Mac build needs Apple silicon and Chromebooks are not supported.

## Getting started
- [ ] Download the installer from the GitHub release for macOS, Windows, or Linux.
- [ ] Ask IT to approve the install.
- [ ] Run the installer and open the app.
- [ ] Let the model download while online.
- [ ] Turn off web search and the MCP connectors.
- [ ] Go offline and ask a question about a sample document.
- [ ] Test the PDF filling feature on a practice form.

## Where is the AI?
The AI is a set of open-weight language models such as Gemma and gpt-oss. They run on the local computer. Students ask questions about a document and check the answers against the text. Optional web search and MCP connectors send data out and can be disabled.

## Privacy and safety
No account is needed, and the internet is used for setup. The launch article says conversations, files, and generated content stay on the device. Optional web search and MCP connectors send queries out when enabled. A teacher should keep both off and check that before students use it. The app is about three weeks old, the launch article comes from the vendor side, and no independent review was found.
