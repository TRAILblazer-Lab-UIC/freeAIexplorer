## Overview
TI-Codes offers coding lessons from Texas Instruments for the TI-84 series graphing calculators. The page lists four tracks. These are a Start Here track of short beginner lessons, TI-Innovator projects with the Hub and Rover, a next step track for students with experience, and resources on programming logic. TI Basic is the main language, and search results also show Python activities for the TI-84 Plus CE.

## Benefits for students
- Students code on the calculator they already use in math class.
- Students move from short beginner lessons to harder projects.
- Students can control the TI-Innovator Hub and Rover.

## Benefits for teachers
- Short beginner lessons fit a class period. A sub page lists 10 minute activities.
- The activities cover math coding on tools students already have.
- TI Connect CE is a free download to transfer files.

## Benefits for schools
- TI Connect CE is free. Activity prices and TI-Innovator hardware prices are not given.
- The calculator is a separate cost.
- The TI-Innovator Hub needs a LaunchPad Board or the Rover.

## Where is the AI?
The lessons describe no AI. Students write TI Basic or Python code that runs on the calculator. They build logic and sequencing skills.

## Privacy and safety
The page does not say whether accounts or the internet are needed. It links a Software Sign-In to license management. The activities run on the calculator. TI Connect CE is a computer download that transfers programs. Calculator work probably runs offline, but the page does not say so. The research did not review any privacy terms. Check what TI Connect CE needs and read its privacy terms.

## Ideas by subject
### math
1. Write a short program that finds the area of a rectangle from two inputs.
2. Code a calculator program that solves a quadratic equation.
3. Add a loop that checks several values in a row.
4. Compare the program's output with a hand calculation.
5. Explain how a formula becomes a line of code.

### computer_science
1. Complete a Start Here lesson in TI Basic.
2. Add an if statement to a program.
3. Find and fix an error in a program.
4. Try a next step lesson on programming logic.
5. Describe in words what a program does, line by line.

### engineering
1. Connect the TI-Innovator Hub and make an LED light up.
2. Program the Rover to drive a short path.
3. Change a number in the code and watch the Rover change.
4. Sketch the path before you write the code.
5. Test and improve a Rover program over three tries.
