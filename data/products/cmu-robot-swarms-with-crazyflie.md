## Overview
This is a three-unit course on Crazyflie 2.1+ micro-drones. Unit 1 covers assembly, the Crazyflie Client and test flights. Unit 2 covers assisted flight with the Flow Deck, state estimation and PID tuning. Unit 3 covers Ultra-Wideband localization, waypoint navigation, synchronized trajectories and multi-drone behaviors.

## Benefits for students
- Students build and tune real micro-drones.
- Students learn how drones estimate where they are.
- Students program several drones to work together.

## Benefits for teachers

- It follows a clear path from assembly to swarm flight.

## Ideas by subject
### engineering
1. Assemble a Crazyflie and complete a test flight.
2. Tune one PID setting and describe the change in flight.
3. Compare flight with and without the Flow Deck.
4. Plan a safe flight area and list the rules.
5. Test the Ultra-Wideband positioning and record how close the drone gets to a point.

### computer_science
1. Write a waypoint list for one drone to follow.
2. Program two drones to move in a synchronized pattern.
3. Read position data and describe what each value means.
4. Change a trajectory in code and predict the new path.
5. Debug a multi-drone program that sends one drone off course.
