## Overview
MENACE is a machine learning device built from 304 matchboxes. Donald Michie first made it in 1960. Each box shows a noughts and crosses position and holds colored beads that stand for moves. The machine draws a bead at random to pick a move. It removes the beads after a loss, adds three of each used bead after a win, and adds one after a draw.

## Benefits for students
- Students watch a machine learn from wins, draws, and losses.
- Students can try a virtual MENACE that plays or watches games.
- Students see bead counts change in a graph.

## Benefits for teachers
- The online simulator has a random opponent and a perfect opponent.
- Teachers can build the physical machine for a vivid demonstration.
- The page lists no classroom lesson plan.

## Benefits for schools
- The website is free.
- A physical version needs 304 matchboxes and beads, and the cost is not stated.
- The online simulator runs in a browser.

## Where is the AI?
The machine has no running AI program in the physical version. The virtual version runs in the browser. MENACE shows reinforcement learning, where moves that win become more likely. Students play, watch the bead counts, and see the machine improve over many games.

## Privacy and safety
The page shows no sign in, and the materials do not state which accounts students need. The online simulator source code is on GitHub per the page. The research did not check whether the simulator sends any data. The research read no privacy policy. A teacher should open the site first and check what it asks of visitors before students use it.

## Ideas by subject
### computer_science
1. Run the virtual MENACE against a perfect opponent and describe what happens.
2. Run it against a random opponent and compare the results.
3. Read the bead count graph and explain what a rising count means.
4. Explain to a partner why a win adds three beads and a loss removes a bead.
5. Plan how to build a small version with fewer boxes.

### math
1. Count the beads in one matchbox and find the chance of each move.
2. Work out how the chances change after a win.
3. Work out how the chances change after a loss.
4. Estimate the number of games MENACE needs to learn a position.
5. Graph the number of beads over time from your own games.
