## Overview
This is a project for school STEM clubs to build and program a small robot arm. The parts are laser cut from plywood. The author chose plywood because it is quicker than 3D printing and most design and technology departments have laser cutters. The arm can be programmed in Python or controlled by a joystick.

## Benefits for students
- Students build a working robot arm from plywood parts.
- Students program the arm in Python or steer it with a joystick.
- Students use common parts that are easy to replace.

## Where is the AI?
The robot arm has no AI. It follows the Python code or the joystick moves that students provide. Students build skills in motion control, sequencing and logic.

## Ideas by subject
### engineering
1. Cut the plywood parts and assemble the arm.
2. Test the joints and record how far each one moves.
3. Compare two ways to mount the arm and choose the better.
4. Design a gripper or a pointer for the arm.
5. Present the finished arm and explain each part.

### computer_science
1. Control the arm with a joystick and describe the moves.
2. Write a Python script that moves the arm to a set spot.
3. Program a short sequence that picks up a light object.
4. Change one value in the code and predict the result.
5. Debug a script that sends the arm too far.
