## Overview
Gnumeric is a free open-source spreadsheet described as fast and accurate. Its manual includes a Statistics menu with descriptive statistics, sampling, and parametric and non-parametric hypothesis tests. The latest version listed is 1.12.62 from September 2026. It suits high school students in statistics.

## Benefits for students
- Students run real statistical tests from a menu.
- Students work with large data sets without slowdowns.
- Students practice descriptive statistics and sampling.

## Benefits for teachers
- The Statistics menu removes the need for extra add-ons.
- An instructor at Concordia University College of Alberta reported using it in an introductory statistics course.
- Manuals and tutorials are available.

## Benefits for schools
- The software is free under GPL version 2 or 3.
- It runs on the local computer after install.
- Only Linux availability was confirmed. IT should check Windows and Mac options.

## Getting started
- [ ] Find Gnumeric on its project site.
- [ ] Ask IT to install it from a Linux distribution package.
- [ ] Check with IT whether Windows or macOS versions exist. The vendor materials did not confirm them.
- [ ] Open a small sample data set in the spreadsheet.
- [ ] Find the Statistics menu and run a descriptive statistics summary.
- [ ] Read the manual page on hypothesis tests.
- [ ] Test one lesson on a single computer first.

## Where is the AI?
Gnumeric has no AI. It builds data skills. Students summarize data and test claims with real statistical methods. It runs on the local computer.

## Privacy and safety
No account is needed and the internet is used only for setup. Gnumeric is a local spreadsheet and the research did not read a privacy policy. Spreadsheet files stay on the device. The evidence is mostly manuals and tutorials. A teacher should test the tool before class and decide where students save files.

## Ideas by subject
### math
1. Enter class survey data and compute the mean and median.
2. Draw a random sample from a data set and compare it with the full set.
3. Run a simple hypothesis test and explain the result in plain words.
4. Make a chart of two groups and describe the difference.
5. Compare a parametric and a non-parametric test on one data set.
