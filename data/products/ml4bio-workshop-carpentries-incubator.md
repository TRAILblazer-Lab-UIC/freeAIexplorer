## Overview
ML4Bio is a beta workshop from the Carpentries Incubator. It teaches machine learning to biologists who have no machine learning background. Learners use point-and-click software with no coding. The material was written for adults and would need adaptation for high school.

## Benefits for students
- Students learn samples, features, and train and test sets with a real T-cell example.
- Students compare decision trees, random forests, logistic regression, and neural networks.
- Students see how overfitting happens and how to measure a model.

## Benefits for teachers
- The workshop has seven episodes and an instructor guide.
- An all-in-one page puts the whole lesson in one place.
- The teacher does not need to write code.

## Benefits for schools
- The workshop is free and the code is open source.
- It runs on Windows, Mac, and Linux laptops.
- IT will need to install the software, and the lesson takes about 5 hours.

## Getting started
- [ ] Find the ML4Bio workshop on the Carpentries Incubator site.
- [ ] Read the Setup page and the instructor guide.
- [ ] Ask IT to install the workshop software on a laptop.
- [ ] Download the lesson data files while online.
- [ ] Test the software on one laptop before class.
- [ ] Review the T-cell example and decide what to adapt for high school students.
- [ ] Plan about 5 hours of class time across several days.

## Where is the AI?
The AI is a set of machine learning models that students train and test in the workshop software. The models run on the local computer. Students pick features, train a model, and judge how well it works on new data.

## Privacy and safety
No account is needed. The internet is used at setup to install the software and download the data files. The workshop says it runs on point and click software that the research did not fully review. The research did not confirm that all work stays on the local computer. The lesson is labeled beta. A teacher should read the episodes first and check how the software handles data files.

## Ideas by subject
### science
1. Classify T-cells using the sample data and describe which features matter most.
2. Split the data into train and test sets and explain why the split is needed.
3. Compare a decision tree with logistic regression on the same data.
4. Look for signs of overfitting and describe what causes it.
5. Read a short machine learning paper and list what the researchers measured.

### computer_science
1. Build a decision tree in the software and trace one sample through it.
2. Train a random forest and compare its results with a single tree.
3. Try a neural network and note how its results differ.
4. Measure a model with the evaluation tools and explain each number.
5. Present a short summary of which model worked best and why.
