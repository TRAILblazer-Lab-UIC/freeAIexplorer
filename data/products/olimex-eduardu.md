## Overview
eduArdu is an open source hardware educational board based on the ATmega32U4, the same chip as the Arduino Leonardo. It has an 8x8 LED matrix, a joystick, six Makey-Makey style buttons, a buzzer, an RGB LED and an IR transmitter and receiver. It also has sensors for ultrasound distance, light, motion, temperature and sound. Students program it with the Arduino IDE or Snap4Arduino.

## Benefits for students
- Students get many sensors and outputs on one board.
- Students can code in blocks with Snap4Arduino or in text with the Arduino IDE.
- Students build real projects with a joystick and a matrix display.

## Benefits for teachers
- Demo examples are on GitHub.
- The board needs little extra wiring.
- Variants such as the BotKit add servo motors and wheels.

## Benefits for schools
- The store lists 15 EUR, which may apply only to the base board.
- The hardware and code are open source.
- IT needs to install the Arduino IDE or Snap4Arduino.

## Getting started
- [ ] Order the board from the Olimex store.
- [ ] Ask IT to install the Arduino IDE or Snap4Arduino.
- [ ] Select Arduino Leonardo in the Arduino IDE.
- [ ] Connect the board by USB.
- [ ] Load a demo example from GitHub.
- [ ] Upload it and test a sensor.
- [ ] Try the same idea in Snap4Arduino.

## Where is the AI?
The board has no AI. It builds skills in sensors, logic and data. Students read values from light, sound and motion sensors and decide how the program responds.

## Privacy and safety
The board works on the device. No account is needed and the internet is used only at setup. The materials document no student data collection. A teacher should check that the computers can run the Arduino IDE. Chromebook support was not confirmed.

## Ideas by subject
### computer_science
1. Load a demo from GitHub and explain what each line does.
2. Draw a picture on the 8x8 LED matrix with code.
3. Use the joystick to move a dot across the matrix.
4. Write the same program in Snap4Arduino and in the Arduino IDE.
5. Add a new sensor reaction and test it.

### engineering
1. Use the ultrasound sensor to build a distance alarm.
2. Use the motion sensor to build a room watcher.
3. Plan a project that uses three sensors and one output.
4. Test the light sensor in different rooms and record the numbers.
5. Add servos and wheels in the BotKit variant and test a drive.
