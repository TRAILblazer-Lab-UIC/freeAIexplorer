## Overview
Visual Studio Code is a free source code editor from Microsoft. It is used for writing, debugging, and testing code. It runs on Windows, macOS, and Linux, and in a browser at vscode.dev. Extensions add functions, and the site now promotes AI agent features.

## Benefits for students
- Students use the same editor that professional programmers use.
- Students can write code in many languages.
- The browser version works on a Chromebook.

## Benefits for teachers
- One editor can serve many text programming courses.
- Extensions add language support.
- Teachers can choose which extensions are installed.

## Benefits for schools
- The editor is free.
- Telemetry can be set to off with a setting.
- AI features use the vendor cloud. Schools should decide whether to allow them.

## Getting started
- [ ] Find Visual Studio Code on the Microsoft site or open vscode.dev.
- [ ] Ask IT to approve and install it on each computer.
- [ ] Set telemetry.telemetryLevel to off.
- [ ] Choose which extensions are installed.
- [ ] Decide whether to turn off the AI features.
- [ ] Open a sample project and test it.
- [ ] Check that the computers meet the system requirements.

## Where is the AI?
The editor itself has no AI. Optional features add code completion, chat, and AI coding agents built on Copilot and other model providers. These features run in the vendor's cloud. Students can ask them for help, and teachers should decide how much help is allowed.

## Privacy and safety
No account is needed for the editor, and the internet is needed at setup. VS Code collects crash reports, error telemetry, and usage data. Users can set telemetry.telemetryLevel to off, but the setting does not control extensions, which may collect their own data. The research did not find the default telemetry level and did not read the Microsoft privacy statement. AI features such as Copilot need a separate sign in and send code context to cloud model providers. A teacher should work with IT to set telemetry and extension rules. VSCodium is a telemetry-free build of the same source.
