## Overview
This is a free web page that describes an unplugged coding game. A grid of playing cards is taped to the floor. Toys form a maze from start to finish. One person plays the robot and the other gives code instructions. The easy version gives one instruction at a time. The hard version writes the whole algorithm first and then debugs it.

## Benefits for students
- Students take turns as the robot and the programmer.
- Students see why exact instructions matter.
- Students practice debugging when the robot ends up in the wrong spot.

## Benefits for teachers
- The page describes an easy and a hard version of the game.
- Setup uses a deck of cards, painter's tape and small toys.
- The page is partly affiliate-linked. Read it with that in mind.

## Benefits for schools

## Getting started
- [ ] Find the Teach Your Kids Code coding card game page.
- [ ] Gather a deck of cards, painter's tape and small toys.
- [ ] Tape a grid of cards to the floor.
- [ ] Place the toys to make a maze from start to finish.
- [ ] Choose one child to play the robot and one to give instructions.
- [ ] Start with the easy version of one instruction at a time.
- [ ] Move to the hard version where the full algorithm is written first.

## Where is the AI?
This game has no AI. It builds an AI-related skill, which is writing and debugging instructions. The robot follows only what the programmer says.

## Privacy and safety
The game runs on cards and floor tape and needs no accounts. The page does not say signup is required for this activity. An email form on the page is for a separate set of worksheets, and the page sells that printable set. The page is partly affiliate-linked. The internet is used only to read the page. Skip the email form unless your school approves it. Check that the taped grid is safe to walk on.

## Ideas by subject
### computer_science
1. Play the robot and follow a partner's one-step commands through the maze.
2. Write a full algorithm for the maze before running it.
3. Run the algorithm, find the bug and fix it.
4. Swap roles and give instructions on a new maze.
5. Add an obstacle and rewrite the instructions to get around it.
