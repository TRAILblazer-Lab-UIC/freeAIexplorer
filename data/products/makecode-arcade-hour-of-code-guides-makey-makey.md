## Overview
A December 2023 post from JoyLabz announced two Hour of Code guides. They pair Makey Makey controllers with MakeCode Arcade games. In the first, students code a tag chase game. In the second, students build a Fruit Catcher style game with falling objects, collision, and scoring.

## Benefits for students
- Students play a game with a controller they built.
- Students design characters and backgrounds.
- Students code velocity and collision events.

## Benefits for teachers
- The guides give a clear one-hour plan.
- Handmade Makey Makey controllers use alligator clips.
- The guides suit grades 3 to 8.

## Benefits for schools
- The guides are free.
- Makey Makey hardware is sold separately.
- The editor runs in a browser. IT load is small.

## Getting started
- [ ] Find the JoyLabz post and the two guides.
- [ ] Gather Makey Makey boards and alligator clips.
- [ ] Open MakeCode Arcade in a browser.
- [ ] Add the Makey Makey extension.
- [ ] Build the tag game from the first guide.
- [ ] Connect the Makey Makey and test the controls.
- [ ] Move to Fruit Catcher if time allows.

## Where is the AI?
These guides have no AI. Students code game rules and wire a controller. They build skills in sequencing, events, and logic.

## Privacy and safety
The materials do not state whether accounts are needed or where data goes. Games are built in the MakeCode Arcade web editor. The research did not open the individual lesson pages. The editor needs the internet at setup. A teacher should check the MakeCode privacy terms and supervise the use of alligator clips and cables.

## Ideas by subject
### computer_science
1. Code a sprite that moves with the arrow keys in a game of tag.
2. Make a second sprite chase the first one.
3. Create a Fruit Catcher with fruit that falls from the top.
4. Add a score that goes up on each catch.
5. Change the speed of the falling fruit and test the game.

### engineering
1. Build a controller from alligator clips and a touch object.
2. Test the controller and fix any loose connection.
3. Design a controller that fits a player's hand.
4. Compare a keyboard and a handmade controller.
5. Draw a plan of the wiring before building it.
