## Overview
AERobot is a low cost robot for introductory programming and robotics. It suits primary or middle school students. It moves with vibration motors and uses infrared sensors to detect obstacles, light, and lines. Students program it with a free graphical environment over USB.

## Benefits for students
- Students program a robot with simple blocks.
- Students use sensors to detect lines, light, and obstacles.
- Students see a multicolor LED respond to code.

## Benefits for teachers
- Sample activities are listed on the project site.
- The robot charges over USB.
- The graphical environment is free.

## Benefits for schools
- The robot can be built for about 10 USD.
- The hardware and software are open source.
- It needs a Windows computer with USB. IT must install drivers.

## Getting started
- [ ] Find the AERobot project site and the software page.
- [ ] Ask IT to install the drivers and the graphical environment on a Windows computer.
- [ ] Connect the robot by USB to charge it.
- [ ] Open the graphical environment and write a short program.
- [ ] Send the program to the robot.
- [ ] Try a sample activity from the project site.
- [ ] Check where to buy or build robots. Seeed Studio sells assembled kits.

## Where is the AI?
This robot has no AI. It follows the program students send. Students build sensor and logic skills as they use infrared readings to make choices.

## Privacy and safety
The robot connects to a computer over USB and needs no account. The project page describes no accounts or cloud service. The research found no privacy policy. The old aerobot.org address now serves an unrelated page. The project page is on GitHub Pages. The internet is used at setup. A teacher should confirm where the Windows software is downloaded from and ask IT to approve the driver install.

## Ideas by subject
### computer_science
1. Write a program that makes the LED change color.
2. Make the robot move forward and stop at a set time.
3. Use a sensor to turn when something is ahead.
4. Try a sample activity from the project site.
5. Debug a program that does not run.

### engineering
1. Test how the robot moves on different surfaces.
2. Use the infrared sensors to follow a line and record the results.
3. Place obstacles and measure how the robot reacts.
4. Compare light readings in bright and dim spots.
5. Suggest one change to the robot and explain why.
