## Overview
LibreKitten is described in Scratch forum threads as a mod of Scratch and TurboWarp that can also act as a web server. Its developer calls it alpha. Blocks may change. The official site page fetched showed only the title. Running a server instance involves cloning the VM with git and installing Node.js and pnpm.

## Benefits for students
- Students use block coding that looks like Scratch.
- Students can explore server blocks.
- Students may learn how a program can answer requests.

## Benefits for teachers
- It is free, per forum posts.
- It suits older students who know Scratch.
- Setup details were not confirmed, and teachers rate it advanced.

## Benefits for schools
- The project is free and the code is open.
- A server instance needs a server admin.
- The tool is in alpha and may change.

## Getting started
- [ ] Find the LibreKitten forum thread and the official site.
- [ ] Read the latest release notes. Forum notes mention versions 0.9.0 and 0.10.0.
- [ ] Ask IT before you run a server instance.
- [ ] Install git, Node.js, and pnpm on a test machine.
- [ ] Clone the VM with git.
- [ ] Test the blocks yourself first.
- [ ] Wait for a stable release before class use.

## Where is the AI?
The vendor does not describe any AI. Students use blocks to write code that follows exact steps. They build logic and sequencing skills, and the server blocks add a view of how a web server responds.

## Privacy and safety
No privacy information was found. The materials do not state which tools or accounts students need or where student projects are stored. Server features mean projects may send and receive network data. A server instance would send data through a machine that the school runs. A teacher should check with IT before any student use. A teacher should also test the alpha tool for stability.
