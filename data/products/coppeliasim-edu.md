## Overview
CoppeliaSim is a cross-platform robot simulator used to prototype, test and validate robotics systems. The Edu edition is free for students, teachers and professors at schools and universities. Objects can be controlled by scripts, plugins or remote clients in Python, Lua, C/C++, Java, JavaScript, MATLAB and Octave. It suits advanced high school and college robotics.

## Benefits for students
- Students test robot code with no physical robot.
- Students use five physics engines, sensors and motion planning.
- Students write code in Python or Lua.

## Benefits for teachers
- A Northwestern course uses CoppeliaSim scenes from the Modern Robotics textbook.
- The simulator offers kinematics, vision and proximity sensors.
- ROS interfaces are available for advanced work.

## Benefits for schools
- The Edu edition is free for education. It is not for companies.
- The research found no account needed, and the internet is needed only at setup.
- IT approval may be needed on managed computers.

## Getting started
- [ ] Go to the CoppeliaSim site and download the Edu installer for your operating system.
- [ ] Check the supported versions, such as Windows x86_64 and macOS 13 or later.
- [ ] Accept the educational terms.
- [ ] Ask IT to approve and install it on managed computers.
- [ ] Open a sample scene and run it.
- [ ] Try the Northwestern CoppeliaSim introduction.
- [ ] Plan extra time because the learning curve is steep for younger students.

## Where is the AI?
CoppeliaSim has no AI. It runs on the local computer and simulates robots that follow the scripts students write. Students build skills in kinematics, sensors and programming.

## Privacy and safety
No account is needed to download, but users must accept the educational license terms first. The app runs on the local computer, and the research found no student data collected. The research did not review a privacy policy. A teacher should check that the Edu license fits the class. The research found the Edu rules for students under 18 stated inconsistently. The app does not run on a Chromebook.

## Ideas by subject
### engineering
1. Open a robot arm scene and describe how each joint moves.
2. Compare how two physics engines change a falling object.
3. Add a proximity sensor to a robot and record its readings.
4. Plot a robot trajectory and compare it to the plan.
5. Use the motion planner to find a path around an obstacle.

### computer_science
1. Write a Python script that moves a simulated robot.
2. Read a sensor in code and print its value.
3. Compare a Lua script with a Python script for the same task.
4. Control the simulator through a remote API client.
5. Debug a script that sends the robot into a wall.
