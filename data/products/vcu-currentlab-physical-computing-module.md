## Overview
This CurrentLab module has students critique digital games as art. Students look at how the mode of interaction shapes the audience experience. The module recommends child friendly physical computing tools such as MaKey MaKey. Instructors have run units with 16 students sharing two kits.

## Benefits for students
- Students try new ways to control a game.
- Students think about how interaction changes the experience.
- Students share kits and work in teams.

## Benefits for teachers
- The module is free.
- Most CurrentLab modules need only Game Maker software.
- A free webcam based alternative exists on Windows.

## Benefits for schools
- A MaKey MaKey kit costs about $49.95. Two kits can serve 16 students.
- A teacher must install the software and set up the kits.
- A search summary says the module uses a CC BY-NC-SA 4.0 license.

## Getting started
- [ ] Find the Making and Moving in the Real World module on the CurrentLab site.
- [ ] Buy at least two MaKey MaKey kits or choose the webcam option.
- [ ] Install Game Maker on a teacher computer.
- [ ] Test the kit with a simple game.
- [ ] Plan groups of about eight students per kit.
- [ ] Read the module and note the discussion questions.
- [ ] Check whether accounts or the internet are needed. The materials do not say.

## Where is the AI?
The materials describe no AI. The controllers send simple signals to the computer. Students build sensor and logic skills as they connect objects to game actions.

## Ideas by subject
### visual_arts
1. Critique a digital game as an art piece and describe its visual choices.
2. Compare a keyboard controlled game with a game played with a MaKey MaKey.
3. Sketch a new controller design for a favorite game.
4. Write a short artist statement about how interaction shapes the audience.
5. Present a game and explain what the audience feels.

### theater_media
1. Play a game with an unusual controller and describe the audience experience.
2. Stage a short performance in which the audience uses a physical controller.
3. Compare how two modes of interaction change the story.
4. Design a set of objects that act as buttons for a scene.
5. Review a classmate's game and give feedback on the interaction.
