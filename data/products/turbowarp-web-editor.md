## Overview
TurboWarp is a mod of Scratch that runs projects faster and adds dark mode and addons. The web editor runs in a browser and loads and saves projects as local files. It suits students in grades 3 to 12 who already know Scratch blocks. It is not affiliated with the Scratch Team.

## Benefits for students
- Projects run faster, which helps large games and animations.
- Students can change the stage size and frame rate.
- Students can try extensions from the extension gallery.

## Benefits for teachers
- The editor looks like Scratch 3. Students need little new training.
- No account is required.
- Teachers can use dark mode and addons to suit different learners.

## Benefits for schools
- The tool is free and the code is open source.
- It runs in a modern browser on Chromebooks, Windows, Mac, and Linux.
- Some school web filters block the domain. IT may need to allow it.

## Getting started
- [ ] Open turbowarp.org in a modern browser.
- [ ] Ask IT to allow the domain. Forum reports say some school filters block it.
- [ ] Load a Scratch project from a file on the computer.
- [ ] Try the addons and dark mode in the settings.
- [ ] Save the project back to a local file.
- [ ] Test the faster run speed on a larger project.
- [ ] Teach students to keep a copy of each project in a shared drive.

## Where is the AI?
This tool has no AI. The compiler turns blocks into faster code by fixed rules. Students build sequencing and logic skills as they snap blocks together.

## Privacy and safety
No account is needed and the editor needs the internet. Projects load and save as local files. The site logs IP addresses for abuse prevention and stores a random username in the browser. The policy says anonymous view counts and daily user statistics may be logged. Cloud variable data is public and project IDs and usernames may be logged for 14 days. Some extensions and project loading go through Scratch services and docs search uses Algolia. The policy does not mention COPPA or FERPA. Check that the school filter allows the site.
