## Overview
This page offers about 30 block-editor lessons for the micro:bit. They are grouped under Science, Technology, Engineering, and Math. Each lesson teaches one block idea. Students use the MakeCode simulator or a micro:bit board.

## Benefits for students
- Students learn one coding idea at a time.
- Students use sensors, such as acceleration, to measure the world.
- Students can test code in the simulator before using a board.

## Benefits for teachers
- Lessons include Night Light, Zoomer, Spinner, Dice Roll, and Guess the Number.
- The lessons are sorted by subject.
- Some lessons need headphones, fruit, or a second micro:bit.

## Benefits for schools
- The lessons and the simulator are free. Micro:bit boards are a paid purchase.
- The editor runs in a browser.
- Chromebook support is inferred and not stated on the page.

## Getting started
- [ ] Open the lesson page in a browser.
- [ ] Pick one lesson, such as Dice Roll.
- [ ] Run it in the simulator.
- [ ] Connect a micro:bit by USB if you have one.
- [ ] Download the code to the board.
- [ ] Check the extra items a lesson needs.
- [ ] Test a Chromebook before class.

## Where is the AI?
These lessons have no AI. The vendor describes no AI features. Students write block programs. They build skills in sensors, logic, and data.

## Privacy and safety
The page does not describe data handling. The micro:bit site says elsewhere that micro:bit classroom needs no accounts. The research did not read the MakeCode privacy statement. The materials do not confirm whether student data is collected. The editor runs in the browser, and the internet is used for setup. A teacher should check the MakeCode privacy terms and that students save programs to a place the class can find.

## Ideas by subject
### computer_science
1. Build the Dice Roll lesson and change it to a coin flip.
2. Use a variable to count button presses.
3. Add a loop to make an icon blink.
4. Use an if block to react to a button.
5. Explain a program to a partner in plain words.

### science
1. Build Zoomer to measure force with the accelerometer.
2. Make a Night Light that turns on in the dark.
3. Test the Glowing Pendulum and record what happens.
4. Compare readings from two trials.
5. Write what the sensor data tells you about the experiment.

### math
1. Code a Guess the Number game with a hidden number.
2. Use a variable to keep a score.
3. Add a loop to repeat a count.
4. Track the score over five rounds and find the average.
5. Change the range of the hidden number and test it.

### engineering
1. Build the Spinner and test its fairness.
2. Make a thermometer with the Temperature lesson.
3. Fix a program that does not respond to a button.
4. Use conditionals to change a device's behavior.
5. Improve a design and test it again.
