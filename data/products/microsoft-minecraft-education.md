## Overview
Minecraft Education is Microsoft's game-based learning version of Minecraft for schools. Students sign in with a school Microsoft account. It includes the Code Builder coding tool and a library of lessons and worlds. Students build, explore, and code inside the game.

## Benefits for students
- Students learn coding inside a game world.
- Students open lessons and worlds from the library.
- Students use a school account they already know.

## Benefits for teachers
- Code Builder gives a direct path from play to coding.
- The lesson and world library saves planning time.
- Worlds back up to the signed-in user's OneDrive when closed.

## Benefits for schools
- Eligible schools pay about 5 US dollars per user per year, and some Microsoft 365 Education plans include it.
- The IT administrator assigns licenses through Microsoft 365 Education.
- The app runs on Windows, Mac, Chromebook, and iOS.

## Getting started
- [ ] Ask the school IT administrator to assign licenses through Microsoft 365 Education.
- [ ] Check device versions against the official system requirements.
- [ ] Download the app and sign in with a school account.
- [ ] Open Code Builder and try a short coding task.
- [ ] Review the privacy terms with IT. The materials were not fully read.
- [ ] Decide how student worlds will be stored in OneDrive.

## Where is the AI?
The vendor materials do not describe any AI. The tool teaches coding with Code Builder. It builds sequencing and logic skills, which students use to control events in the game.

## Privacy and safety
Students and teachers need a school Microsoft account, and the internet is needed at all times. World files back up to the signed in user's OneDrive on close, and the device must be online for backup. Cloud backup can be turned off in settings. The research could not read the Minecraft Education privacy page or support article. The standard Microsoft data protection terms were not verified. The facts here are thin and come mostly from search snippets. A teacher should ask IT to review the terms and account settings before use.
