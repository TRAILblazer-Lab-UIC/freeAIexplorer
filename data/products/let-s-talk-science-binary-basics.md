## Ideas by subject
### computer_science
1. Count in binary using the activity materials.
2. Show a number in binary and have a partner read it.
3. Encode a short message in binary.
4. Explain how binary stores different kinds of information.
5. Compare the Dots and Binary Beads activities.

### math
1. Count from 0 to 15 in binary and write each number.
2. Find the pattern in the columns of a binary count.
3. Add one to a binary number and describe what changes.
4. Compare a binary number with its everyday number.
5. Write a number puzzle in binary for a classmate.
