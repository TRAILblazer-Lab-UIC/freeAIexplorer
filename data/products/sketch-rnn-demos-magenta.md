## Overview
These are interactive web experiments built on sketch-rnn, a neural network trained on millions of doodles from the Quick, Draw! game. The main demo predicts how a partial doodle might continue. Other demos show several endings, morphing between two drawings, and doodles that mimic a finished drawing. The page says the demos work best in a desktop browser.

## Benefits for students
- Students draw and watch the network continue their sketch.
- Students see how two drawings can blend together.
- Students learn that a model predicts what comes next.

## Benefits for teachers
- There is nothing to install and there is no account.
- The demos make a quick class demonstration.
- The demo is from 2017 and may be less maintained than the library.

## Benefits for schools
- The demos are free.
- A model of about 5 MB downloads once, and about 100 models cover different categories.
- Drawings stay on the device. No IT work is needed.

## Where is the AI?
The AI is a recurrent neural network that generates drawings stroke by stroke. It runs in the browser on the device. Students draw part of a doodle, see the network finish it, and use the result to talk about prediction.

## Privacy and safety
No account is needed. The internet is used to load the page and download the model, and the model then runs in the browser. The page does not describe analytics or data handling. The research did not review the hosting site's policy. A teacher should check the host site's policy, test the page before class and confirm whether it works offline.

## Ideas by subject
### computer_science
1. Start a doodle and watch how the network finishes it, then describe the pattern.
2. Draw the same start twice and compare the predicted endings.
3. Pick different categories and see how the model changes its drawing.
4. Explain in a sentence how the network can predict the next stroke.
5. Find a drawing the network completes badly and guess why.

### visual_arts
1. Begin a sketch of an animal and see how the model completes it.
2. Morph two drawings and describe the stages in between.
3. Draw a single stroke and keep the best prediction as a starting point.
4. Redraw a model doodle by hand and add your own style.
5. Compare your drawing with a model version and discuss what is different.
