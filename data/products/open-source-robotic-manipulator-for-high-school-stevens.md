## Overview
This is a design project for a low-cost, lightweight robot arm made for high school students. A high school researcher built it with a university faculty member and a Ph.D. student. The package has CAD files for 3D printing, an assembly guide, wiring diagrams, documented low-level controllers, and a bill of materials. Students print, wire, and program the arm themselves.

## Benefits for students
- Students build a real robot arm from printed parts and common electronics.
- Students learn how servos, wiring, and Arduino code work together.
- Students see that a high school researcher made the original design.

## Benefits for teachers
- The files, parts list, and wiring diagrams are all in one place.
- The project suits an advanced club or an engineering elective.
- The paper was accepted to the ASEE Zone 1 Conference.

## Benefits for schools
- The design files are open source, but the vendor does not state a license.
- A search snippet reports a build cost of about 170 to 317 USD in 2022 prices. The dollar figure is not on the GitHub page.
- A 3D printer and an Arduino setup are required, and IT may need to help with software installs.

## Getting started
- [ ] Find the project's GitHub repository and read the files that come with it.
- [ ] Download the CAD and STL files and the Arduino sketch.
- [ ] Check the bill of materials and order the servos and hardware.
- [ ] Print the parts on a school 3D printer.
- [ ] Assemble the arm by following the assembly guide.
- [ ] Wire the electronics by following the wiring diagrams.
- [ ] Install the Arduino software and upload the controller code.
- [ ] Test each joint slowly before students use the full arm.

## Where is the AI?
This project has no AI. The arm runs low-level controllers on an Arduino board. Students build skills in sequencing and control logic as they decide how each joint should move.

## Privacy and safety
The design is a local hardware project with Arduino controllers. The research found no account needs and no student data collection, but the paper does not discuss data handling. The internet is used to download the files. A teacher should check the printed parts and the wiring before students power the arm.
