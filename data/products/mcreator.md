## Overview
MCreator is an open source desktop tool for making Minecraft mods. Students use visual procedure blocks or Java code. Mods are created, stored, and compiled on the computer. Outschool classes teach it to ages 9 to 13 for Minecraft Java Edition.

## Benefits for students
- Students make mods for a game they already enjoy.
- Students can start with blocks and move to Java.
- Students test their work right away.

## Benefits for teachers
- The tool has an education workshops page.
- No account is needed.
- Few formal school curricula were found. Teachers plan their own lessons.

## Benefits for schools
- The software is free, with optional paid supporter options.
- Testing needs Minecraft Java Edition.
- IT approval is likely needed.

## Getting started
- [ ] Download the installer from the MCreator site.
- [ ] Ask IT to approve the install.
- [ ] Check that the computer can run Minecraft Java Edition.
- [ ] Stay online for the first run. The installer fetches Gradle and Minecraft files.
- [ ] Make a new workspace and a new block.
- [ ] Build and test the mod in Minecraft.
- [ ] Try a simple procedure with visual blocks.

## Where is the AI?
MCreator has no AI. The vendor describes no AI features. Students write rules for blocks and items. They build skills in logic and sequencing.

## Privacy and safety
The education page says no account, email, or login is needed, and an account is only for publishing to the community site. That comes from a search snippet. Mods are stored and compiled on the device. The internet is used at setup. The privacy page returned a 403 and was not read. The website is partly ad supported. A teacher should keep students off the community site unless the school approves it. A teacher should also check that the school allows Minecraft Java Edition and where students save mods.

## Ideas by subject
### computer_science
1. Create a new block with a custom texture and add it to the game.
2. Use a procedure block to give an item a new action.
3. Change a number in the code and test the effect.
4. Switch from a visual block to Java and compare the two.
5. Share a mod with a partner and ask for feedback.
