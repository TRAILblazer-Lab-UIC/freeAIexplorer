## Overview
Otto DIY is an open-source biped robot with a 3D-printable body built around an Arduino board. The official DIY page lists the Arduino IDE as the programming route and also has a block-coding download heading. The site states the DIY design is not ideal for young children and that teachers need robotics skills. Official DIY kits are reported to be discontinued.

## Benefits for students
- Students print, build and program a walking robot.
- Students use real servos and an ultrasonic sensor.
- Students see how code turns into movement.

## Benefits for teachers
- Open 3D files and manuals are on Printables.
- The robot can be a long project for an advanced class.
- The HP Otto line is described as backward compatible with the DIY code.

## Benefits for schools
- A discovery note estimates 40 to 60 USD for printing and parts.
- Parts must come from third parties because official kits are gone.
- Maintainers warn that unofficial kits can contain counterfeit parts.

## Getting started
- [ ] Find the Otto DIY page and download the 3D files and manuals.
- [ ] Ask whether the school has a 3D printer or buy printed parts.
- [ ] Source an Arduino Nano, servos and an ultrasonic sensor.
- [ ] Print the body and assemble the robot.
- [ ] Install the Arduino IDE on a computer.
- [ ] Upload the example code.
- [ ] Test walking on a flat table.

## Where is the AI?
Otto DIY has no AI. It builds skills in sequencing, sensors and logic. Students write code that turns distance readings into movement.

## Privacy and safety
The robot runs on its own board, and the site says Bluetooth and app control are not supported. No account is needed, and the internet is used at setup. The site documents no student data collection, and the research read no privacy policy. A teacher should buy parts from trusted sellers and supervise any 3D printer use.

## Ideas by subject
### engineering
1. Print the body parts and assemble the robot.
2. Test how the servos move the legs and record the results.
3. Fix a leg that drags and describe the fix.
4. Compare two print settings and pick the stronger part.
5. Document the build with photos and notes.

### computer_science
1. Upload a walking program with the Arduino IDE.
2. Change the step length in the code and watch the result.
3. Use the ultrasonic sensor to make the robot stop near a wall.
4. Add a dance sequence with a loop.
5. Explain each part of the code to a partner.
