## Overview
Blot is an open source two-axis pen plotter with a browser editor for programming generative art in JavaScript. The editor has a vector drawing library and a split view of code and preview. Students write code that produces line drawings. The free machine offer through Hack Club has ended, but the online editor still works without a machine.

## Benefits for students
- Students see their code turn into line art on screen.
- Students can send finished art to the plotter for a real pen drawing.
- Students can browse a gallery of art that other people submitted.

## Benefits for teachers
- A sample lesson plan with puzzles is available.
- A session can run as one day of about 50 minutes or span several weeks.
- A workshop for about 300 middle school students combined math with Blot.

## Benefits for schools
- The editor is free.
- The free machine offer has ended and a current machine price was not found.
- The editor needs a constant internet connection.

## Getting started
- [ ] Open the Blot online editor from the Hack Club site.
- [ ] Follow the getting started guide.
- [ ] Run the first lesson plan with the class.
- [ ] Ask students to save and share their art. An account is optional.
- [ ] Browse the gallery of submitted art for ideas.
- [ ] Look into buying or building a plotter. The machine must be obtained separately.
- [ ] Review the Hack Club community rules before students join the Slack, which is for teens only.

## Where is the AI?
Blot has no AI. It draws exactly what the JavaScript code says. Students build skills in logic and pattern spotting by using loops and math to make shapes repeat.

## Privacy and safety
The editor needs the internet at all times. An account is optional, and the lesson plan mentions an optional cloud account for saving work. The research found no privacy policy and the materials do not say what data the site collects. Gallery submission uses a public GitHub pull request. A teacher should check the account terms before students sign in and tell students that gallery entries are public. A teacher should also know that the community Slack is for teens only.

## Ideas by subject
### computer_science
1. Run the first lesson puzzle and describe what each line of code draws.
2. Use a loop to draw a row of repeated shapes.
3. Change a number in a program and predict the new drawing.
4. Fix a program that draws a broken shape.
5. Share a finished drawing in the gallery with a short note about the code.

### visual_arts
1. Create a line drawing from a few simple shapes in code.
2. Explore how repeating and rotating a shape makes a pattern.
3. Compare a generated drawing with a hand drawn one.
4. Plan a poster design and build it in the editor.
5. Plot a finished piece on the machine and mount it for display.

### math
1. Use coordinates to place the start of each line.
2. Draw a polygon and count its sides and angles.
3. Use a formula to make a spiral and describe the pattern.
4. Test how changing a size value scales a shape.
5. Explain the math behind a repeating pattern in a short write-up.
