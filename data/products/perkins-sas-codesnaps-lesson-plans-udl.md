## Overview
SAS CodeSnaps is an app where students arrange code blocks and use a tablet to guide a Sphero robot. SAS worked with Perkins to add braille to the blocks. Blind, low vision, and sighted students can work in one activity. The SAS page links Perkins lesson ideas that follow Universal Design for Learning, printable braille block files, and a teacher webinar.

## Benefits for students
- Students who read braille and students who read print share the same coding task.
- Students handle physical blocks to build a program.
- Students watch the Sphero follow the program they built.

## Benefits for teachers
- Perkins lesson ideas follow Universal Design for Learning.
- A webinar is offered for teachers of students with visual impairments.
- Printable braille block files are available.

## Benefits for schools
- The lessons and app are listed as free.
- The school needs an iPad and a Sphero robot. The Sphero price was not checked.
- Braille blocks need a label maker or a tactile graphics machine.

## Getting started
- [ ] Find the SAS CodeSnaps page and the linked Perkins lesson ideas.
- [ ] Install the CodeSnaps app on an iPad.
- [ ] Pair a Sphero robot with the iPad.
- [ ] Print the braille block files or label blocks with a braille labeler.
- [ ] Watch the teacher webinar.
- [ ] Try one Sphero City activity yourself.
- [ ] Run a short coding club activity with a small group.

## Where is the AI?
This lesson has no AI. Students arrange blocks in order and the robot follows them. They build sequencing skills by planning the order of each move.

## Privacy and safety
The materials do not state whether students need an account. They do not say what data the app collects. The research lists the internet as needed at setup only but did not verify this. A teacher should check the app's privacy details with the school before use.

## Ideas by subject
### special_ed
1. Build a short block program together using braille and print labels.
2. Read the braille on each block and say what move it gives the robot.
3. Work in a mixed pair to guide the Sphero through a simple course.
4. Describe the robot's path aloud as it moves.
5. Swap roles with a partner and rebuild the program from memory.

### computer_science
1. Arrange code blocks to move a Sphero to a goal.
2. Predict the robot's path before running the program.
3. Fix a block program that sends the robot the wrong way.
4. Add one block to make the course harder and test it.
5. Explain how the order of the blocks changes the result.
