## Overview
Ollama is a command line tool and background service that runs open-weight large language models on the user's own computer. It has its own API and works with OpenAI-style clients. It offers Python and JavaScript libraries and a desktop app. Many school setups pair it with a web chat front end such as Open WebUI.

## Benefits for students
- Advanced students can run a language model on a school computer.
- Students can use Python or JavaScript to call a local model.
- Students learn how a model is served to other apps.

## Benefits for teachers
- Carleton College runs Ollama with Open WebUI on lab PCs so people can use language models without cloud processing.
- A county office IT director proposed the same pair for multilingual tutors.
- Local models need no account.

## Benefits for schools
- Local use is free.
- Hardware to run models is the real cost.
- A server install needs a server administrator, and setup takes days.

## Getting started
- [ ] Find the Ollama download for your operating system.

- [ ] Install Ollama and pull a small model while online.
- [ ] Check the computer has enough RAM or GPU for the model.
- [ ] Ask IT to leave cloud models off.
- [ ] Pair Ollama with a web chat front end such as Open WebUI.
- [ ] Go offline and test a short chat.

## Where is the AI?
The AI is an open language model that answers chat and writes text. It runs on the local computer or a school server. Students use a chat front end or code to send prompts and read replies, then build on those answers in their own work.

## Privacy and safety
Local models need no account, and the policy says Ollama does not collect or access prompts that run locally. Newer versions offer optional cloud models. A cloud model needs an account and sends prompts to Ollama's servers. The policy also lists account details, device and IP data, and limited usage data for account features. The research saw no COPPA or FERPA statement. A teacher should ask IT to keep cloud models off and check the model name students use.
