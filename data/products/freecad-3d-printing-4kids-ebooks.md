## Overview
This is a series of kids ebooks by Peter Phelps that teach FreeCAD modeling for 3D printing. In Volume 1 children model two robot toys in the Part workbench. Topics include the 3D Cartesian coordinate system, Boolean operations, print-in-place tolerances, and exporting and checking STL files. Volumes 2 and 3 cover pendants and personalized text.

## Benefits for students
- Students learn by building a robot toy.
- Students learn coordinates and Boolean operations.
- Students export and check an STL file.

## Benefits for teachers
- Projects teach while doing.
- Volumes cover robots, pendants, and text.
- Each ebook is a PDF.

## Benefits for schools
- Each ebook costs 1.99 USD. FreeCAD itself is free.
- A 3D printer is needed to print the models.
- IT should help install FreeCAD.

## Getting started
- [ ] Buy and download the Volume 1 PDF.
- [ ] Ask IT to install FreeCAD.
- [ ] Install FreeCAD on a test computer.
- [ ] Follow the first robot project.
- [ ] Export an STL file and check it for errors.
- [ ] Print the model if a 3D printer is available.
- [ ] Buy Volume 2 or 3 for further projects.

## Where is the AI?
These ebooks have no AI. They build spatial and design skills. Students use coordinates and shapes to plan a model.

## Privacy and safety
FreeCAD runs locally and no account is needed to use it. The adult buyer buys and downloads each ebook from Payhip, and the research did not review Payhip checkout data. The internet is used to buy the ebooks and install FreeCAD. The materials describe no student data collection. A teacher should buy the ebooks and check the purchase terms with the school. A teacher should also set a safety plan for 3D printer use.

## Ideas by subject
### engineering
1. Model the first robot toy from Volume 1.
2. Place parts using the 3D Cartesian coordinate system.
3. Use a Boolean operation to cut a hole.
4. Test print-in-place tolerances with a small joint.
5. Design a pendant and export its STL file.
