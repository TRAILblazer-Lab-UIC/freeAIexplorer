## Overview
Mistral AI publishes open-weight language models that can be downloaded and run locally. The docs list Mistral Small 4 and Ministral 3, with 3B, 8B, and 14B sizes, under Apache 2.0. Local runtimes such as Ollama, llama.cpp, and LM Studio offer quantized builds. These models are aimed at developers and teachers.

## Benefits for students
- Advanced students can run and compare open models.
- Students see how model size affects speed and answer quality.
- Students can study a model that they run on their own device.

## Benefits for teachers
- Several models use the Apache 2.0 license.
- Sizes run from 3B to 119B total parameters.
- Quantized versions let small models run on a laptop.

## Benefits for schools
- The weights are free. Hardware to run them is the main cost.
- Prompts stay on the device after download.
- IT approval may be needed for the runtime.

## Getting started
- [ ] Find the model list in Mistral's documentation.
- [ ] Ask IT to approve a runtime such as Ollama or LM Studio.
- [ ] Install the runtime on one test computer.
- [ ] Download a small quantized model while online.
- [ ] Choose an instruct or newer model for any student use.
- [ ] Go offline and test a few prompts.
- [ ] Check that the computer has enough memory for the model.

## Where is the AI?
The AI is a text generation language model that runs on the local device. Larger models need a GPU. Students and teachers write prompts, read replies, and compare models. Base models such as Mistral-7B-v0.1 have no moderation.

## Privacy and safety
No account is needed, and the internet is used for the download. Running downloaded weights locally keeps prompts on the device. The weights collect no data themselves. Mistral's hosted API and Le Chat are separate services that the research did not review. The research found no privacy policy. No child safety review of these models was found. A teacher should choose instruct or newer models for student use and check each model's license. A teacher should also review replies. Base models have no moderation.
