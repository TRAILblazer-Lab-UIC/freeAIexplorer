## Overview
MicroBlocks is a free blocks programming language for physical computing, inspired by Scratch. Students click a block and it runs at once on a connected board, with sensor values shown live. It supports the micro:bit, Calliope mini, Circuit Playground Express and about 50 other boards. It runs in Chrome or Edge or as a desktop app.

## Benefits for students
- Students see a block run the moment they click it.
- Students watch live sensor graphs as they test ideas.
- Students can leave a program on the board and run it without a computer.

## Benefits for teachers
- The tool is free and works with many boards.
- Activity cards and guided activities help teachers start.
- Teachers can use the same tool with boards the school already owns.

## Benefits for schools
- The software costs nothing. The project asks for donations and boards cost extra.
- The code is open source.
- The internet is needed only at setup.

## Getting started
- [ ] Open the browser version in Chrome or Edge, or download the desktop app for Windows, macOS, Linux or Chromebook.
- [ ] Ask IT to install the app and approve USB access where needed.
- [ ] Connect a supported board with a USB cable.
- [ ] Install the MicroBlocks firmware from the menu.
- [ ] Click a block and watch the board respond.
- [ ] Try an activity card with the class.
- [ ] Save a program to the board and test it without a computer.

## Where is the AI?
MicroBlocks has no AI. It builds skills in sequencing, logic and sensor data. Students read live graphs and learn to spot patterns in the readings.

## Privacy and safety
The software runs on the device and in the browser, and no account is needed. The official page says the website stores no personal information and uses anonymous cookies for short term internal statistics. The research found no separate privacy policy. The software's own data collection was not documented. Boards with Wi-Fi can use HTTP or IoT libraries if a project builds that in. A teacher should check the software settings and the school's browser rules before class.

## Ideas by subject
### computer_science
1. Click a block to blink an LED and describe what the board did.
2. Write a program that reacts to a button press.
3. Use a loop to repeat a light pattern.
4. Save a program to the board and run it away from the computer.
5. Compare two ways to write the same program and pick the shorter one.

### science
1. Watch the live sensor graph for light in the room and describe the changes.
2. Record temperature readings across a school day and chart them.
3. Predict how a sensor will react to a hand wave and then test it.
4. Compare readings from two boards in different spots.
5. Write a short data report from a graph.
