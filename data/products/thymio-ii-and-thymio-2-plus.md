## Overview
Thymio is an open source educational robot designed at EPFL with ECAL and produced by the nonprofit Mobsya. It has two independently driven motors, many LEDs, touch-sensitive keys, an accelerometer, a microphone, and speakers. It ships with six pre-programmed modes. EPFL says it suits contexts from primary school to university.

## Benefits for students
- Children can play with the six built-in modes before any coding.
- Students can program it visually, with blocks, or with text code.
- Students use sound, touch, and motion sensors.

## Benefits for teachers
- Ready-to-use learning activities are available.
- The software runs in English, French, German, and Italian.
- One robot supports many grade levels.

## Benefits for schools
- The thymio.org page shows no price. Wikipedia describes Thymio II as in the 100 euro range.
- Hardware and software are open source.
- Apps run locally and need no internet in class.

## Getting started
- [ ] Find the Thymio page and the ready-to-use activities.
- [ ] Ask IT to install Thymio Suite on a computer.
- [ ] Connect the robot by USB or with the wireless dongle.
- [ ] Try the six built-in modes first.
- [ ] Choose a programming language in Thymio Suite.
- [ ] Use Thymio Suite Mobile on a tablet on the same Wi-Fi as the computer.
- [ ] Test the wireless dongle before a class set.

## Where is the AI?
Thymio has no AI. The robot runs the program it is given and its built-in behaviors. Students build skills in sequencing, logic, and sensor data.

## Privacy and safety
No account is needed. The Mobsya privacy policy says the Thymio Suite applications run only on your computer or tablet. It says Mobsya systems process no usage or connection data from them. The thymio.org website uses analytics cookies with consent. Thymio Suite Mobile needs the computer version on the same Wi-Fi network. The research did not verify the offline dongle mode. Check that the wireless dongle and the mobile app work on the school network.

## Ideas by subject
### computer_science
1. Try each of the six built-in modes and describe what each one does.
2. Program a simple event with visual icons in VPL.
3. Move from icons to blocks and compare the two.
4. Read a short text program and explain what it does.
5. Debug a program that makes the robot spin forever.

### engineering
1. Use the touch keys and sensors to build a robot that reacts to its surroundings.
2. Test how the motors move the robot on different floors.
3. Plan a robot task such as following a line and test it.
4. Use the microphone to start the robot with a clap.
5. Improve a robot's design after a failed test.
