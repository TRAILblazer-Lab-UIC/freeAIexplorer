## Overview
Berkeley Logo, also called UCBLogo, is a Logo interpreter written by Brian Harvey with students. It is mostly text based and draws with turtle graphics. It is available for Windows, macOS, and Linux. Students type Logo commands and watch the turtle draw.

## Benefits for students
- Students learn text code in a gentle language.
- Students see their commands drawn by a turtle.
- Students can follow the three Computer Science Logo Style books.

## Benefits for teachers
- The distribution includes a manual and source code.
- The companion books give a deep path for advanced students.
- Setup takes about an hour.

## Benefits for schools
- The software is free.
- It runs on the computer. The pages read documented no network features.
- IT may need to approve and install it. Chromebook support is not documented.

## Getting started
- [ ] Download the installer for Windows, macOS, or Linux from the official site.
- [ ] Ask IT to approve the install on school computers.
- [ ] Install it on each computer.
- [ ] Read the manual and try a first command that draws a square.
- [ ] Look at the license. The official page names none, but GitHub reports GPL-3.0.
- [ ] Plan a first lesson using the turtle.
- [ ] Share the Computer Science Logo Style books with advanced students.

## Where is the AI?
This tool has no AI. The interpreter runs the commands students type. Students build sequencing and logic skills as they write procedures.

## Privacy and safety
UCBLogo is a local desktop interpreter and needs no account. The research found no privacy policy and the pages read documented no network features. The internet is used to download it. Check that school computers can run the version for their system.

## Ideas by subject
### computer_science
1. Type commands to draw a square and then a triangle.
2. Write a procedure for a shape and call it many times.
3. Use repeat to draw a flower of petals.
4. Add a variable to change the size of a shape.
5. Write a recursive procedure and describe the pattern it makes.
