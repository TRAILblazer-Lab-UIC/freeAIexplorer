## Overview
The Pro-Bot Online Emulator is a free browser tool for practicing Pro-Bot programming. Students use arrow keys and numbers as on the physical robot, with GO, Clear, Home, and pen controls. The Menu lets students write procedures and use special commands. Sound and light sensors do not work in the emulator.

## Benefits for students
- Students practice the same commands they would use on the real Pro-Bot.
- Students draw shapes with a virtual pen.
- Students write their own procedures and save them.

## Benefits for teachers
- The emulator opens in a browser in minutes.
- Teachers can prepare lessons without a robot in hand.
- The Pro-Bot Lessons curriculum is available as a paid add-on.

## Benefits for schools
- The emulator is free.
- It runs on Chromebooks, Windows, and Mac computers.
- No IT work is needed.

## Getting started
- [ ] Find the Pro-Bot Online Emulator on the Terrapin site.
- [ ] Open it in a browser on one student device.
- [ ] Try arrow keys and numbers to move the on-screen Pro-Bot.
- [ ] Press GO and watch the robot run the commands.
- [ ] Try the virtual pen and draw a square.
- [ ] Open the Menu and write a short procedure.
- [ ] Use Save and Load to keep a procedure in the Downloads folder.

## Where is the AI?
The emulator has no AI. The on-screen robot runs exactly the commands students enter. Students build sequencing skills and learn how procedures reuse a set of steps.

## Privacy and safety
The emulator page mentions no sign-in and no privacy policy. The tool needs the internet. The research did not confirm whether the page runs fully in the browser with no server requests. The materials describe no student data collection but do not say where data goes. Save writes files to the local Downloads folder. Check Terrapin's privacy details and browser requirements before class.

## Ideas by subject
### computer_science
1. Enter arrow keys and numbers to drive the virtual Pro-Bot in a square.
2. Write a procedure in the Menu and run it more than once.
3. Change a number in a program and predict what the robot will draw.
4. Save a procedure, reload it later, and improve it.
5. Find a bug in a classmate's command list and fix it.

### math
1. Draw a square and a rectangle and record the turns and distances used.
2. Predict the angle for a turn and test it with the robot.
3. Draw a triangle and find the turns that close the shape.
4. Measure the distance the robot moves in units and compare two paths.
5. Draw a design with the pen and describe the shapes in it.
