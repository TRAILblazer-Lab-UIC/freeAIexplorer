## Overview
Pro-Bot is a car-shaped floor turtle robot that needs no assembly. It has a keypad on the back with a Bee-Bot mode and a Logo mode. An LCD shows each command. It holds a pen and draws as it moves. A free Pro-Bot Online Emulator runs in any browser.

## Benefits for students
- Students program the robot by pressing keys.
- Students see each command on the LCD.
- Students draw shapes with the pen.

## Benefits for teachers
- The robot needs no assembly.
- Pro-Bot Lessons provides classroom activities.
- Turtle Tuesdays weekly challenges are offered.

## Benefits for schools
- The robot costs 149.95 USD. Bundles run from 262.90 USD to 799.95 USD.
- Pro-Bot Lessons is a school-wide site license.
- Terrapin Logo for USB programming is a separate license.

## Where is the AI?
The robot has no AI. It builds skills in sequencing, logic and procedures. Students also use subprocedures and a main program.

## Privacy and safety
The robot works on its own. No account or internet is needed. The materials document no student data collection. The Terrapin privacy page returned 404. No policy was reviewed. The online emulator and Pro-Bot Lessons are separate products that the research did not review. A teacher should check the age range. Terrapin states none and a third party guide lists age 7 and up.

## Ideas by subject
### computer_science
1. Enter a keypad program and predict where the robot will go.
2. Switch from Bee-Bot mode to Logo mode and compare.
3. Write a subprocedure and call it in a main program.
4. Use the emulator to test a program before a robot run.
5. Use the sensors to start the robot with a sound.

### math
1. Draw a square and count the turns.
2. Measure how far the robot moves for each unit.
3. Use turns to draw a triangle and name the angles.
4. Predict a path on grid paper and test it.
5. Compare two shapes by their sides and turns.
