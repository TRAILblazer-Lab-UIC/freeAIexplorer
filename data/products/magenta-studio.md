## Overview
Magenta Studio is a set of MIDI tools built on Magenta models. The tools are Continue, Groove, Generate, Drumify, and Interpolate. The current 2.0 release is a Max for Live device that runs inside Ableton Live. Students pick MIDI clips and the tools extend or change melodies and drum patterns.

## Benefits for students
- Students extend a melody they started.
- Students turn a melody into a drum pattern.
- Students blend two clips to hear the middle ground.

## Benefits for teachers
- Each tool does one clear job.
- The tools work with clips that students already know how to make.
- Older 1.0 standalone apps exist but are no longer actively maintained.

## Benefits for schools
- The tools are free and open source.
- The 2.0 device needs Ableton Live 10.1 Suite or newer, which is paid software, or an older Live with a Max 8 license.
- IT must install Live and the device.

## Getting started
- [ ] Find the Magenta Studio page and download the .amxd file.
- [ ] Ask IT to install Ableton Live with Max for Live.
- [ ] Confirm the version is Live 10.1 Suite or newer.
- [ ] Drag the .amxd file onto a MIDI track.
- [ ] Open a short MIDI clip and run Continue.
- [ ] Test the other four tools with the same clip.
- [ ] Save student projects on the local drive.

## Where is the AI?
The AI is a set of Magenta models for music. They continue clips, create new ones, add human timing to drums, turn melodies into drum patterns, and blend clips. The vendor does not say where the models run. Students start with their own MIDI ideas and then edit what the tools return.

## Privacy and safety
No account is needed. The README describes a local server inside Node for Max, with the interface talking to Ableton Live. The pages read do not state whether model inference is local or remote. The research did not confirm the claim of local MIDI processing. The research found no privacy policy. A teacher should test the device offline to see whether it works and ask IT to check its network use.

## Ideas by subject
### music
1. Write a four bar melody and use Continue to extend it.
2. Use Drumify to turn the melody into a drum pattern.
3. Apply Groove to a stiff drum clip and describe the new feel.
4. Blend two melodies with Interpolate and name the result.
5. Pick the best generated clip and explain how you would edit it.
