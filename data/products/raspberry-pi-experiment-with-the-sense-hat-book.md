## Overview
This MagPi Essentials e-book introduces the Raspberry Pi Sense HAT add-on board, its sensors, and its LED matrix. Chapters cover getting started, a digital magic 8-ball, a reaction game, and Sense HAT data logging. It adds background on the Astro Pi mission. The PDF is free, but the Sense HAT hardware is a separate purchase.

## Benefits for students
- Students build a magic 8-ball and a reaction game.
- Students log data from real sensors.
- Students learn about the Astro Pi mission.

## Benefits for teachers
- The projects follow a clear chapter order.
- The book is free to download.
- Teachers need strong comfort with Python and Raspberry Pi setup.

## Benefits for schools
- The PDF is free.
- A Raspberry Pi and Sense HAT are bought separately.
- An emulator is mentioned in a search result, but the book page does not confirm it.

## Getting started
- [ ] Find the Experiment with the Sense HAT book on the Raspberry Pi site and download the PDF.
- [ ] Read the Getting started chapter.
- [ ] Set up a Raspberry Pi with a Sense HAT.
- [ ] Ask IT for help if the Pi needs a network.
- [ ] Try the digital magic 8-ball project first.
- [ ] Build the reaction game next.
- [ ] Finish with the data logging chapter.

## Where is the AI?
The book has no AI, and it is not an AI lesson. It builds an AI-related skill, which is working with sensor data. Students log readings and look for patterns in them. That practice supports later work with data.

## Privacy and safety
No account is needed, and the internet is used only to download the PDF and set up the Pi. Data stays on the device. The vendor materials list no student data collection. A teacher should check that students handle the hardware with care.

## Ideas by subject
### computer_science
1. Build the digital magic 8-ball and show an answer on the LED matrix.
2. Create the reaction game and change its difficulty.
3. Write code that shows a message on the LED matrix.
4. Log readings to a file and open the file in a spreadsheet.
5. Debug a project by reading the error message and fixing the line.

### science
1. Log the temperature in a classroom over a day.
2. Compare readings in two rooms and graph the results.
3. Record readings near a window and away from it.
4. Write a claim about the data and support it with the log.
5. Read the Astro Pi chapter and list the data that astronauts could collect.
