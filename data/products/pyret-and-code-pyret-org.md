## Overview
Pyret is a programming language designed for programming education. The code.pyret.org editor lets students write and run it in a web browser. Built-in features include tables, image values, example blocks, testing, and reactors for interactive simulations. The Bootstrap curricula for grades 6 to 12 use it.

## Benefits for students
- Students write code and see images and results at once.
- Students write examples and tests as part of every program.
- Students use tables and reactors to build data work and simple simulations.

## Benefits for teachers
- The Bootstrap curricula give teachers ready lessons for grades 6 to 12.
- The editor needs no install.
- Bootstrap says teachers often use school Google accounts or a shared class login.

## Benefits for schools
- The tool is free and open source.
- It runs in a browser on Chromebooks, Windows, Mac, and Linux.
- School Google Workspace policy may affect sign in. IT should review it.

## Getting started
- [ ] Open code.pyret.org in a browser.
- [ ] Ask IT whether school Google sign in is allowed for this site.
- [ ] Decide between school Google accounts and a shared class login.
- [ ] Sign in with a Google account so files can be saved.
- [ ] Write a first program that draws an image.
- [ ] Try an example block and a test.
- [ ] Look at the Bootstrap curricula for a lesson sequence.

## Where is the AI?
Pyret has no AI. It builds an AI-related skill, which is working with data. Students build tables and write tests that check results. That practice helps them judge whether any program gives a correct answer.

## Privacy and safety
A Google account is needed to save files, and the internet is needed at all times. Search snippets say program contents are stored in the student's Google Drive and not on Pyret servers. They also say the server keeps file IDs for published programs and some usage logs for debugging. The listed privacy policy is described as a generic template from 2017, and the research did not read it directly. A teacher should check the school's Google Workspace policy and avoid shared class Google logins.

## Ideas by subject
### computer_science
1. Follow a Bootstrap lesson and write a first Pyret program.
2. Write an example block before the function and describe what it checks.
3. Build a table of class data and answer a question from it.
4. Make an interactive animation with a reactor.
5. Find a bug by reading a failed test and fix it.

### math
1. Use a Bootstrap algebra lesson to write a function that matches a rule.
2. Test a function with several inputs and compare the outputs to hand calculations.
3. Use exact rational arithmetic to compare a fraction with a decimal result.
4. Build a game where the position of a shape depends on a formula.
5. Make a table of values for a function and describe the pattern.
