## Overview
PixiEditor is a free open source 2D editor for pixel art, vector art, painting, and frame by frame animation. It also has a node graph for procedural art and a brush engine. It runs as a desktop app and works offline. The site states a no AI position.

## Benefits for students
- Students can try pixel art, vector shapes, and painting in one app.
- Students make frame by frame animations.
- Students can explore procedural art with the node graph.

## Benefits for teachers
- The interface is easy for most teachers.
- The tool works offline.
- Version 2.1 adds an extension browser.

## Benefits for schools
- The software is free. Donation tiers of 5 to 50 USD per month are optional.
- It is also sold on Steam and the Microsoft Store.
- IT will likely need to approve the install.

## Getting started
- [ ] Download the desktop app from the site, Steam, or the Microsoft Store.
- [ ] Ask IT to approve the install on Windows, Mac, or Linux computers.
- [ ] Turn off Discord Rich Presence in settings on any computer that has Discord.
- [ ] Draw a small sprite with the pixel perfect pen.
- [ ] Add frames and play the animation.
- [ ] Review the crash report behavior with IT.
- [ ] Save work in a class folder.

## Where is the AI?
The site states a no AI position. PixiEditor has no AI. Students build skills in pattern spotting and logic. The node graph shows how connected steps can build an image.

## Privacy and safety
No account is needed and the program works offline. Crash reports with the OS, hardware, and app configuration are sent automatically to the vendor after a crash. The research did not confirm an opt out. The website uses Umami analytics. Discord Rich Presence is on by default and shows document size, layer count, and elapsed time publicly. It can be turned off in settings. Purchase accounts use an email address, and Steam ownership is checked through Steamworks. A teacher should check the crash report and Discord settings with IT.
