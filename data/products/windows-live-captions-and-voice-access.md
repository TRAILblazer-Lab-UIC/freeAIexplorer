## Overview
Live captions is a Windows 11 accessibility feature that shows captions for audio playing on the device. Voice access lets users control the PC by voice. Both use on device speech recognition. Students in grades 3 to 12 can use them to follow audio and to control the computer without a mouse.

## Benefits for students
- Students see captions for any audio on the computer.
- Students can control Windows by voice.
- Live captions can translate between languages.

## Benefits for teachers
- The features are built into Windows 11.
- Captions work on videos and meetings with no setup per file.
- An optional profanity filter is available.

## Benefits for schools
- The features come with Windows 11 at no extra cost.
- Per Microsoft, audio, voice data, and captions never leave the device.
- IT may need to allow the language file downloads.

## Getting started
- [ ] Find live captions in the Windows 11 accessibility settings.
- [ ] Ask IT to allow the language file download.
- [ ] Turn on live captions and accept the consent prompt.
- [ ] Choose a caption language.
- [ ] Turn on the profanity filter if you want it.
- [ ] Try voice access and let it download its language files.
- [ ] Test both features offline.

## Where is the AI?
The AI is on device speech recognition. It turns spoken audio into captions and spoken commands into actions. It runs on the Windows computer. Students use the captions to follow what they hear and use voice access to control their work.

## Privacy and safety
No account is needed. The internet is used to download language files at first use, and the feature asks for consent. Microsoft says audio, voice data, and captions never leave the device, are not shared with Microsoft, and are not saved. The microphone is off by default. The research read only Microsoft sources and did not fetch the voice access page itself. A teacher should check that the computers run Windows 11 and tell students that captions can contain errors.

## Ideas by subject
### special_ed
1. Turn on live captions and watch a short video with the sound low.
2. Open an app by voice with voice access.
3. Dictate a short message using voice commands.
4. Compare captions to the spoken words and note mistakes.
5. Explain to a classmate how each feature helps.

### world_languages
1. Play a video in another language and read the live captions.
2. Compare the translated captions with the spoken words.
3. Listen to a short passage and write your own captions first.
4. Note words the captions got wrong and look them up.
5. Practice a phrase and see how the captions show it.
