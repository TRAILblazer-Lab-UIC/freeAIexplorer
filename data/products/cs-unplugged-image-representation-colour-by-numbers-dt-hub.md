## Overview
This offline activity shows how a black and white image is built from pixels, each stored as a 0 or 1. Students colour a grid using the codes. They then write a coded message so a partner can recreate an image. The Digital Technologies Hub lists it for Years 5 to 6 and links to the CS Unplugged site for the full activity.

## Benefits for students
- Students see how a computer stores a picture.
- Students practice decoding and encoding with a partner.
- Students work with binary codes on a grid.

## Benefits for teachers
- The Hub links the activity to AC9TDI6K04 on binary data representation.
- A grade 3-5 lesson plan uses coloured cards for on and off pixels.
- The activity is short and easy to set up.

## Benefits for schools
- The activity is free.
- The Hub lists it under a CC BY-NC-SA 4.0 license.
- It needs only printed grids and colouring pencils.

## Where is the AI?
This activity has no AI. It builds an understanding of data, which is how a computer stores an image as 0s and 1s. Students encode and decode a picture by hand.

## Privacy and safety
The activity runs on paper, and the Hub page mentions no login. The research found no student data collected. No privacy policy was read. The internet is used to open and print the activity. The Hub page lists no downloads itself. A teacher should open the linked CS Unplugged page to get the materials, and the research did not fetch that page.

## Ideas by subject
### computer_science
1. Colour a grid using a code of 0s and 1s to reveal a hidden image.
2. Write a coded image for a partner to decode.
3. Explain how a pixel is stored as a 0 or a 1.
4. Find a mistake in a code and fix the picture.
5. Compare a coded picture with a smooth drawing and discuss the difference.

### math
1. Read rows of numbers and colour the squares to match.
2. Count the squares of each color in a finished grid.
3. Find a pattern in the rows of a code.
4. Write the code for a simple shape on a grid.
5. Use symmetry to plan an image before you write its code.
