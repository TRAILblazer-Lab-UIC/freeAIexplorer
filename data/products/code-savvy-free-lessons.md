## Overview
Code Savvy lists five free lessons. They are Coding for a Cause for Scratch in K-5, Talking with Computers for ScratchJr in K-2, CS + Me for Scratch in 3-8, Plan a Program for unplugged use in 5-12, and Algorithmic Art with p5.js in 6-12. Only Plan a Program is unplugged. Each lesson links to a Google Form for access.

## Benefits for students
- Students can choose lessons that fit their grade, from K to 12.
- Students try block coding in Scratch and ScratchJr.
- Older students make generative art with p5.js.

## Benefits for teachers
- A teacher can pick one lesson and request the plan through a form.
- A search result says Plan a Program teaches planning with flowcharts and pseudocode.
- The lessons span many grade bands.

## Benefits for schools
- The lessons are listed as free.
- The unplugged lesson needs only paper.
- The Scratch and p5.js lessons need browsers on student devices.

## Getting started
- [ ] Find the Code Savvy free lessons page.
- [ ] Choose the lesson that fits your grade band.
- [ ] Fill in the Google Form for that lesson to receive the plan.
- [ ] Read the plan before class.
- [ ] Ask IT to allow the Scratch, ScratchJr, or p5.js tools for the lessons that use them.
- [ ] Print any materials for Plan a Program.
- [ ] Try the lesson with a small group first.

## Where is the AI?
These lessons have no AI. They build coding and planning skills such as sequencing, flowcharts, and pseudocode. Students plan a program on paper or build one in a block tool.

## Privacy and safety
The materials do not say what data the Google Form collects. They also do not state which accounts students need for the coding tools. A teacher should check the form, the plan, and the tool terms before students sign in anywhere. The unplugged lesson keeps student work on paper.

## Ideas by subject
### computer_science
1. Plan a program on paper with a flowchart before you build it.
2. Write pseudocode for a short task and trade it with a partner.
3. Build a Scratch project that supports a cause you care about.
4. Make a ScratchJr scene where characters talk with a computer.
5. Explain your plan and your finished program to a classmate.

### visual_arts
1. Create generative art with p5.js and change one number to see the result.
2. Plan a pattern on paper and then code it.
3. Compare two versions of an art program and describe the difference.
4. Choose colors for a code-made design and explain the choice.
5. Share your art with the class and describe the steps you used.
