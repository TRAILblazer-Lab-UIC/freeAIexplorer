## Overview
Scratch Desktop is the downloadable offline version of the Scratch block editor. Projects are saved as local .sb3 files. The Scratch Wiki says it runs on Windows and macOS, and that Android and Chromebook apps also exist. Students make games, animations, and stories with blocks.

## Benefits for students
- Students can code with no sign-in.
- Students can work without a steady connection.
- Students keep projects as files on the device.

## Benefits for teachers
- The editor is the same block style teachers already know.
- No accounts need to be managed.
- Some extensions, such as text to speech and translate, need the internet.

## Benefits for schools
- The software is free and the source is on GitHub under AGPL-3.0.
- It needs about 400 MB on Windows and 230 MB on macOS.
- School IT may need to approve installs.

## Getting started
- [ ] Download the installer from the Scratch site.
- [ ] Ask IT to approve the install.
- [ ] Check the system needs. Windows 10, macOS 10.13, or Chrome OS 6.0 and later are listed by the Scratch Wiki.
- [ ] Install it on one computer first.
- [ ] Save a test project as an .sb3 file.
- [ ] Test whether Chromebook support works. Forum posts disagree.
- [ ] Note that TurboWarp and browser app options are unofficial.

## Where is the AI?
Scratch Desktop has no built-in AI. The optional text to speech and translate extensions use online services and need the internet. Students build skills in sequencing, loops, and logic that help them understand how AI programs are written.

## Privacy and safety
No account is needed, and projects are saved as local files. The internet is used at setup. The text to speech and translate extensions call online services. The online Scratch privacy policy applies if a user signs in or uses those extensions. The research could not read the policy text. The offline claims come from the discovery notes. A teacher should leave online extensions off for students who should stay fully offline.

## Ideas by subject
### computer_science
1. Build a simple game with a sprite that moves on key presses.
2. Use a loop to draw a repeating pattern.
3. Add a variable that keeps score.
4. Swap projects with a partner and find one bug.
5. Save the project as an .sb3 file and reopen it later.

### visual_arts
1. Draw a new sprite in the paint editor.
2. Make a short animation by switching costumes.
3. Design a backdrop for a story scene.
4. Add sound effects and match them to the action.
5. Create a title screen for a class animation.

### ela
1. Tell a short story with two sprites and dialogue.
2. Add a narrator who speaks at the start of each scene.
3. Retell a class reading as an animation.
4. Write a script where two characters answer each other.
5. Share the story and ask a partner to explain the plot.
