## Overview
This project page has learners code a micro:bit rover to avoid obstacles, using block coding or Python. It teaches sense, think and act in a robotic system. Learners then pick a challenge such as obstacle avoidance or light seeking. The page is aimed at teachers or upper level students new to robotics.

## Benefits for students
- Students build a rover and see sense, think and act in one machine.
- Students choose a challenge, such as obstacle avoidance or light seeking.
- Students can code in blocks or in Python.

## Benefits for teachers
- The project gives a clear structure for a robotics unit.
- The content is free.
- Teachers can pick blocks or Python to match the class.

## Benefits for schools
- The content costs nothing. The cost of parts was not checked.
- The rover base needs a 3D printer and a laser cutter or shop tools.
- Setup can take days.

## Getting started
- [ ] Find the project page from MIT K12 Maker and read the parts list.
- [ ] Source two hobby motors, a micro:bit V2, a motor board, three photoresistors and an HC-SR04 distance sensor.
- [ ] Print and cut the base.
- [ ] Wire the sensors to the board.
- [ ] Load the starter code.
- [ ] Test the rover on a small course.
- [ ] Let students pick a challenge.

## Where is the AI?
The project has no AI. It builds skills in sensing, logic and sequencing. Students write rules that turn sensor readings into actions.

## Privacy and safety
The rover runs its own code on the device. The page names no accounts and states no student data collection. The research did not review the block coding editor that students may use, and the page does not name it. A teacher should check that editor's account and data terms. Shop and 3D printer safety rules also need a check before students use the tools.

## Ideas by subject
### engineering
1. Build the rover base and test how it drives.
2. Mount the distance sensor and measure how close the rover gets to a wall.
3. Compare two sensor positions and pick the better one.
4. Change the wiring layout and test again.
5. Write a build log that another team could follow.

### computer_science
1. Code the rover to turn when the distance sensor sees a wall.
2. Compare the block version with the Python version of the same program.
3. Add a light seeking mode with the photoresistors.
4. Debug a rover that spins in circles.
5. Draw a flowchart of the sense, think and act loop.

### science
1. Explain sense, think and act using the rover as an example.
2. Test how well the distance sensor works on soft and hard surfaces.
3. Compare how the photoresistors read light in bright and dim spots.
4. Record sensor numbers during a run and chart them.
5. Predict how the rover will behave and then test the prediction.
