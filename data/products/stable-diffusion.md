## Overview
Stable Diffusion is a family of models that make images from text prompts. The weights can be downloaded and run on a computer with a graphics card. A separate web interface such as AUTOMATIC1111 is needed to use it. It suits high school art and media classes with an adult guiding the setup.

## Benefits for students
- Students turn written ideas into images within minutes.
- Students learn how prompt wording changes a picture.
- Students can test many versions and pick the strongest.

## Benefits for teachers
- Teachers can show how an image model is run on a local machine.
- Different versions and interfaces let teachers choose the level of control.
- Setup is advanced and suits a teacher with technical help.

## Benefits for schools
- The weights are free. The license varies by version. IT should read the terms.
- Images are made on the school computer, and no cloud account is needed.
- Wikipedia reports that content restrictions can be bypassed. Schools need their own filtering and policy review.

## Getting started
- [ ] Find the Stable Diffusion model and a web interface such as AUTOMATIC1111 from their project pages.
- [ ] Ask IT to approve the install and the content filtering plan.
- [ ] Use a computer with a dedicated GPU. DataCamp recommends at least 6 GB of VRAM.
- [ ] Install Python and Git.
- [ ] Clone the web interface and download a model from Hugging Face.
- [ ] Read the license for the chosen model version.
- [ ] Launch the local server and test it with a classroom safe prompt.
- [ ] Go offline and confirm that images still generate.

## Where is the AI?
The AI is a latent diffusion model that makes an image from a text prompt. It runs on the local computer, using its GPU. Students write prompts, review the images, and change their wording to steer the result. The same models can also be adapted by training, which is advanced work.

## Privacy and safety
No account is needed to run the models locally, and prompts and images stay on the machine. The internet is used at setup to download software and models, and Hugging Face and GitHub accounts may be used for those downloads. Hosted Stability AI services have separate terms that the research did not review. Wikipedia reports that the training data contained private and sensitive information. The research found no built in child safety filter. A teacher should set up filtering and review prompts before students use the tool.

## Ideas by subject
### visual_arts
1. Write a prompt in the style of a painter you studied and compare it with the real work.
2. Generate three versions of one scene and explain which composition works best.
3. Use a model picture as a sketch idea and then draw your own version by hand.
4. Change one word in a prompt and describe how color and mood shift.
5. Make a class gallery with a label that says each image was made with AI.

### theater_media
1. Generate concept images for a set design in a school play.
2. Build a storyboard for a short film from five generated frames.
3. Make a poster for a class production and write the prompt beside it.
4. Compare a generated character design with a hand drawn one.
5. Discuss how to credit AI made images in a student media project.
