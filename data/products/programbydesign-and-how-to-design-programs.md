## Overview
ProgramByDesign is the outreach project of the PLT Racket group, formerly called TeachScheme. Its materials center on the free textbook How to Design Programs and the design recipe. Students build programs in DrRacket, including animations and reactive systems. The Materials page also lists Bootstrap for middle school, Picturing Programs, and a follow-up book on moving to Java.

## Benefits for students
- Students learn a clear method for planning each program.
- Students build animations and reactive programs.
- The design recipe carries to other languages such as Java, according to search results.

## Benefits for teachers
- The textbook is free online.
- The materials list extra exercises through htdp-plus.
- The curriculum is demanding. Teachers need time to prepare.

## Benefits for schools
- All materials are free online.
- DrRacket runs on Windows, Mac, and Linux.
- IT will likely need to approve the install.

## Getting started
- [ ] Open the ProgramByDesign Materials page.
- [ ] Read the first chapters of How to Design Programs.
- [ ] Ask IT to approve DrRacket on school computers.
- [ ] Download and install DrRacket.
- [ ] Try the design recipe on one small problem.
- [ ] Look at Bootstrap for middle school classes.
- [ ] Add extra exercises from htdp-plus.

## Where is the AI?
The vendor does not describe any AI in these materials. Students write programs in DrRacket by following the design recipe. They build logic and sequencing skills.

## Privacy and safety
No account is needed. The internet is used to download and read the materials. DrRacket is a desktop program and student programs stay on the computer. No privacy policy was found. A teacher should check where students save their work.

## Ideas by subject
### computer_science
1. Apply the design recipe to a short function and explain each step.
2. Write test examples before you write the code.
3. Build a simple animation in DrRacket.
4. Compare your solution with a partner's and discuss the differences.
5. Describe how the design recipe could apply in Java.

### math
1. Write a function for a math rule and test it with examples.
2. Use a Bootstrap activity to link code with algebra.
3. Graph the output of a function you wrote.
4. Explain how a function in code matches a function in math.
5. Check your function with three inputs and record the results.
