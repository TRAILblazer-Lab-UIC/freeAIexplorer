## Overview
Ultralytics YOLO is a family of real-time computer vision models. It comes as one Python package and command line tool. It supports object detection, segmentation, classification, pose estimation, and tracking. Students install it with pip and run models on images, video, or a webcam.

## Benefits for students
- Students see a model find objects in a live video.
- Students can train a model on their own images.
- Students practice real Python with a professional tool.

## Benefits for teachers
- Pre-trained models work right after install.
- Documentation and learning resources are available.
- It suits high school students who write Python.

## Benefits for schools
- The code is free under AGPL-3.0.
- Commercial use needs a paid Enterprise License.
- It runs on the school computer after setup. IT should plan the install.

## Getting started
- [ ] Find the Ultralytics YOLO documentation.
- [ ] Ask IT to install Python 3.8 or newer.
- [ ] Run pip install ultralytics.
- [ ] Turn off telemetry in the settings.
- [ ] Load a pre-trained model such as yolov8n.pt.
- [ ] Stay online for the first run. The model weights download once.
- [ ] Test the model on a photo before using a webcam.

## Where is the AI?
The AI is a set of computer vision models. They run on the local computer, using the processor or an optional graphics card. Students load a model, run it on images or video, and read the results. They can also train it on their own labeled images.

## Privacy and safety
No account is needed and the internet is used for setup and the first model download. Inference runs on the local computer and images and video stay on the device. The policy says the open source packages collect anonymized usage analytics and crash reports by default. These can be disabled. The policy says the services are not directed at children under 13, which is a data rule and not a minimum age. Turn telemetry off before class. Check any webcam use and tell students when the camera is on.
