## Overview
Code Master is a single player logic board game from ThinkFun with 60 puzzles for ages 8 and up. Players place path tiles and action tiles in order to guide an avatar to crystals and a portal. The levels run from beginner to expert. Reviewers describe it as teaching the logic of running a program and not real coding.

## Benefits for students
- Students solve 60 puzzles that rise in difficulty.
- Students plan a sequence of tiles before they test it.
- Students build logical reasoning on their own.

## Benefits for teachers
- The game needs no setup beyond opening the box.
- Single player puzzles suit a quiet center.
- Reviewers disagree on how much it teaches about coding. A teacher can discuss that with students.

## Where is the AI?
This game has no AI. It builds sequencing and logic, which are skills used in programming. Students order tiles like lines of a program.

## Privacy and safety
The game is a physical board game. No student data is collected. It needs no account and no internet. A teacher should check that the pieces stay together. The box has many small tiles. The vendor materials read do not describe other safety steps.

## Ideas by subject
### computer_science
1. Place path tiles and action tiles in order to guide the avatar to a crystal.
2. Predict where the avatar ends before you test the sequence.
3. Fix a sequence that misses the portal by changing one tile.
4. Explain your solution to a partner in plain words.
5. Move from a beginner puzzle to an expert puzzle and note what changes.

### math
1. Count the tiles in a solution and look for a shorter one.
2. Use logic to rule out tile orders that cannot work.
3. Record the number of tries each puzzle takes.
4. Work backward from the portal to plan the path.
5. Compare two solutions to the same puzzle and decide which is better.
