## Overview
Rocksi is a robot simulator that runs in a modern web browser. Students program a simulated robot arm with Blockly blocks. A 3D view shows the arm moving. The author built it so a class of 20 to 40 students can work with a robot without buying hardware for each one.

## Benefits for students
- Students see a 3D robot arm move as soon as they run their blocks.
- Students practice programming a robot arm with familiar drag-and-drop blocks.
- Every student gets a robot of their own on a tablet or laptop.

## Benefits for teachers
- Teachers can run a whole class on one lesson without any robot hardware.
- Tutorial videos load inside the tool and give students a place to start.
- The tool needs no installation on student devices.

## Benefits for schools
- The tool is free.
- It runs on tablets, iPads, and laptops.
- A school can build and host its own copy with Node.js 18 or later. That task would go to IT.

## Getting started
- [ ] Find the Rocksi project on GitHub and read its README.
- [ ] Note that the README says the rocksi.net address is outdated.
- [ ] Ask IT to build a school-hosted copy with Node.js 18 or later.
- [ ] Open the hosted copy in a modern browser on one student device.
- [ ] Run one tutorial video and try a short block program yourself.
- [ ] Check that the 3D view works on the tablets and laptops students will use.
- [ ] Give students a simple first goal, such as moving the arm to a target.

## Where is the AI?
Rocksi has no AI. The robot only does what the student blocks say. Students build sequencing skills as they order the blocks and test the result.

## Privacy and safety
The tool runs in the browser and the page needs the internet at all times. It fetches its assets at runtime from the host. The README does not describe accounts or data collection, and the research found no privacy policy. The materials do not state where any data goes. A teacher should check the host of the copy students use. IT can confirm whether the school's own copy sends anything outside the school.

## Ideas by subject
### computer_science
1. Program the simulated arm with Blockly blocks to move from one point to another.
2. Build a block sequence that picks up an object and moves it to a new spot.
3. Swap two blocks in a working program and predict how the arm will move.
4. Find and fix a bug in a block program that a classmate wrote.
5. Write a short program that repeats a motion using a loop block.

### engineering
1. Watch the 3D arm and describe how its joints bend to reach a target.
2. Test how far the arm can reach and record the limits in a table.
3. Compare two block programs for the same task and pick the smoother one.
4. Design a sequence of moves that keeps the arm clear of an obstacle in the scene.
5. Discuss why engineers test a robot in a simulator before they use real hardware.
