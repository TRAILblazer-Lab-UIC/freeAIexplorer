## Overview
Students build, program and race a model car around a track, and the fastest car that finishes without derailing wins. The MathWorks page lists outcomes in embedded software with NXP parts, motor controller design and camera interfacing to follow a guide line. It links to the NXP Cup, tracks, GitHub documentation and an exercise book from Rose-Hulman. The page is aimed at college and teacher-led classroom competitions.

## Benefits for students
- Students race a car they programmed.
- Students write embedded code in MATLAB and Simulink.
- Students use a camera to follow a line.

## Benefits for teachers
- GitHub documentation guides the setup.
- A track designer app helps build a track.
- A Rose-Hulman exercise book is linked.

## Benefits for schools
- The page gives no price.
- The kit is bought from NXP, and MATLAB needs a license.
- The project needs IT help and several days of setup.

## Where is the AI?
The vendor does not describe any AI in the kit. The car follows the embedded code that students write and reads a camera image. Students build skills in sensors, feedback and logic.

## Privacy and safety
The materials do not say whether accounts are needed or what data is collected. The page does not address software licensing or data. MATLAB normally needs a MathWorks account license, and the research did not confirm this for the kit. The research read no privacy policy. A teacher should check the license terms before students use the software. A teacher should also set a safe space for race testing.

## Ideas by subject
### engineering
1. Build the car and list each part.
2. Design a track and test it with the car.
3. Tune the motor controller and record lap times.
4. Compare two camera settings and describe the effect.
5. Hold a class race and write a design review.

### computer_science
1. Read the exercise book example and run it in MATLAB.
2. Write code that steers the car toward a guide line.
3. Change a speed value and test the lap.
4. Debug a program that leaves the track.
5. Explain the code to a teammate.
