## Overview
This community hosted edition of the open source Trinket browser coding platform is run by Strive Math in Singapore. It is not the original trinket.io service, which shut down. Code can be edited and run without logging in. Accounts let users save and share projects and let educators create courses and track progress. Every feature is free.

## Benefits for students
- Students can write and run Python, HTML, Java, and more in the browser.
- Students can code without an account.
- School created accounts use a generated username with no real name.

## Benefits for teachers
- Educators can create courses and track progress.
- Teachers can create school accounts for students.
- Former trinket.io users can import an exported account zip.

## Benefits for schools
- Every feature is free with no paid plans or trials.
- It works in any web browser, including on Chromebooks.
- The original trinket.io shut down on 2026-08-31. Founders warned that a community version might not be maintained.

## Getting started
- [ ] Open the Strive Math community site in a browser.
- [ ] Try writing code without an account.
- [ ] Read the privacy policy before you create accounts.
- [ ] Create a teacher account and a course.
- [ ] Create school accounts for students.
- [ ] Former trinket.io users should import their export zip. Content was not moved automatically.
- [ ] Back up your class code files in case the site changes.

## Where is the AI?
The site has no AI. Students write code in a text editor and run it in the browser. They practice logic, sequencing, and debugging as they fix their own programs.

## Privacy and safety
Accounts are optional and the internet is needed at all times. The site stores a username, a hashed password, saved code, courses, and submissions. School accounts use a generated username and placeholder email with no real name. The policy says it follows COPPA and that schools give consent for students under 13. Named third parties include Vercel, Supabase, DigitalOcean, Sentry, and Google. Code for Python 3, Java, R, and Pygame runs on external servers. Providers mainly store data in the United States. Check the policy and the site's long term support.
