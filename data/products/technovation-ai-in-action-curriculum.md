## Overview
Technovation AI in Action is a nine module curriculum. Students build AI based apps for community problems. The lesson read here has students train a model in a Jupyter notebook with Python and scikit-learn. They then load the model into a Streamlit web app.

## Benefits for students
- Students build and deploy a working AI app.
- Students learn preprocessing, classification, and regression.
- Students study bias, overfitting, and underfitting.

## Benefits for teachers
- The curriculum includes modules on responsible building and pitching.
- A search snippet says the curriculum is free to access.
- The lesson names Teachable Machine as an easier alternative.

## Benefits for schools
- The curriculum is free per a search snippet.
- Students need several accounts. IT may need to approve them.
- Students write Python. The load is high for beginners.

## Getting started
- [ ] Find the Technovation AI in Action curriculum on the Technovation site.
- [ ] Create Technovation and Kaggle logins. A GitHub login is optional.
- [ ] Set up Visual Studio Code with Python or open GitHub Codespaces.
- [ ] Download the notebook from Google Drive.
- [ ] Download the datasets from Kaggle.
- [ ] Run the notebook once yourself.
- [ ] Plan about 60 minutes for Activity 1 and 45 minutes for Activity 2.

## Where is the AI?
Students train a scikit-learn model on a Kaggle stroke prediction dataset. The training runs in a notebook, either on a school computer or in the cloud. Students then load the exported model into a Streamlit app that predicts from user input. They evaluate the model for bias and overfitting.

## Privacy and safety
Students need a Technovation login and a Kaggle account to download datasets. The notebook sits in Google Drive. Coding runs in Visual Studio Code on the device or in GitHub Codespaces online. The internet is always needed. MachineLearningForKids can be tried without an account, but unsaved work is lost. The research did not read Technovation's privacy terms. The stroke dataset is health related. Check each service's terms before students sign up.

## Ideas by subject
### computer_science
1. Train a scikit-learn model in the notebook and record its accuracy.
2. Load the exported model into a Streamlit app and test it with new inputs.
3. Change a preprocessing step and observe the effect on results.
4. Find a sign of overfitting and describe how to reduce it.
5. Design an app idea that helps a community problem.

### math
1. Compare classification and regression and give an example of each.
2. Calculate model accuracy from counts of right and wrong predictions.
3. Plot the training data and describe patterns that you see.
4. Explain how overfitting and underfitting appear on a graph.
5. Test how the sample size changes the model results.
