## Overview
This resource page comes from the MIT Edgerton Center K-12 Maker Lab. It covers physical computing, where code reads sensors and controls outputs such as motors, speakers, and lights. It covers Arduino and micro:bit. Students build and code small devices such as a light sensing theremin, a compass, and a plant watering machine.

## Benefits for students
- Students build real devices that sense and respond.
- Students can start with the micro:bit from about grade 4.
- Students can move to the Arduino Garden from about grade 6 and Arduino from grade 10.

## Benefits for teachers
- The page gives grade guidance for each platform.
- It links an Arduino Garden build guide and micro:bit projects from teacher workshops.
- It links to outside Arduino and micro:bit tutorials.

## Benefits for schools
- The resources are free.
- Boards, wire, breadboards, and batteries are extra, and prices were not checked.
- The micro:bit MakeCode editor works on Chromebooks. The desktop Arduino IDE does not.

## Getting started
- [ ] Open the MIT K12 Maker physical computing page.
- [ ] Pick a platform, either micro:bit or Arduino.
- [ ] Order boards, jumper wire, alligator clips, and AA battery packs.
- [ ] Use MakeCode in a browser for the micro:bit.
- [ ] Install the desktop Arduino IDE, which is the free route.
- [ ] Plan advance fabrication for the Garden projects.
- [ ] Use an AA battery pack for servo motors. The micro:bit 3V output barely powers them.

## Where is the AI?
This resource has no AI. It builds skills with sensors, outputs, and logic. Students learn how code reads a sensor and then controls a motor or a light.

## Privacy and safety
Arduino code runs on the board. The micro:bit code is written in the browser based MakeCode editor, which the research did not review. The materials state no student data collection and list no accounts. A teacher should check the MakeCode editor's account, saving, and data terms before students use it. Wiring and battery use also need a check before students power a project.

## Ideas by subject
### engineering
1. Build a plant watering machine and test how well it works.
2. Make a doorbell that sounds when a button is pressed.
3. Build a light sensing theremin and tune it by ear.
4. Design a garden character with the Arduino Garden guide.
5. Test a servo motor with a battery pack and record what changes.

### computer_science
1. Write code that reads a light sensor and shows the number.
2. Program a compass on the micro:bit.
3. Use an if statement style rule to start a motor at a set reading.
4. Compare the MakeCode blocks with the Arduino text code for one project.
5. Debug a project that does not respond and describe the fix.
