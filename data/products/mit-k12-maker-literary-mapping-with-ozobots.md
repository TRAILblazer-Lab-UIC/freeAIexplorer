## Overview
This is a grade 5 project that pairs the novel Esperanza Rising with Ozobot Bit robots. Small groups locate and label the six stops of the character journey on a poster size map of Mexico and California. They mark the route with red, blue, black and green markers. They then program an Ozobot to trace it. OzoBlocky is optional for more advanced coding.

## Benefits for students
- Students bring a story to life with a robot.
- Students learn map skills and geography.
- Students practice color codes and optional block coding.

## Benefits for teachers
- The project links ELA, social studies and coding.
- A class used it in a unit on migration.
- Similar Ozobot lessons exist for Huck Finn and Knuffle Bunny.

## Benefits for schools
- The project is free.
- Schools must have Ozobot Bit robots. The research did not check a price.
- The color marker version needs no internet.

## Getting started
- [ ] Find the Literary Mapping With Ozobots project from MIT K12 Maker.
- [ ] Print the poster size map.
- [ ] Gather red, blue, black and green markers.
- [ ] Have one Ozobot Bit for each group.
- [ ] Read the novel with the class.
- [ ] Have groups label the six stops.
- [ ] Mark the route and let the robot trace it.

## Where is the AI?
This project has no AI. It builds an AI-related skill, which is sequencing with color codes. Students draw a route that the robot reads and follows.

## Privacy and safety
The Ozobot follows lines on paper, and the research found no account needs and no student data collection for the marker version. The optional OzoBlocky editor was not reviewed. A teacher should check the OzoBlocky data terms before students use it. Keep robots on flat tables.

## Ideas by subject
### ela
1. Read Esperanza Rising and list the six main stops of the journey.
2. Write a short note about each stop.
3. Retell the story by following the Ozobot along the map.
4. Describe how the setting affects the characters.
5. Write a new journey for a character of your own.

### social_studies
1. Find Mexico and California on a poster map.
2. Mark the route of the journey with colored markers.
3. Discuss why people migrate.
4. Measure the distance between stops.
5. Compare the route with a modern map.

### computer_science
1. Draw a route with color codes for the Ozobot.
2. Test the robot and fix any gap in the line.
3. Use color codes to change speed or direction.
4. Try OzoBlocky to program the route.
5. Explain to a partner how the robot reads the colors.
