## Overview
This camera sensor works with VEX IQ 2nd generation robots. It supports color code detection, AI detection of classroom game objects, and AprilTag detection. Students in grades 3 to 8 code it in VEXcode IQ or Visual Studio Code. It only works with IQ 2nd generation Brains.

## Benefits for students
- Students give a robot a sense of sight.
- Students code detection of game objects and AprilTags.
- Students can use blocks first and text code later.

## Benefits for teachers
- The sensor fits the VEX IQ kits that many classes already own.
- It runs in VEXcode IQ on Windows, Mac, Chromebook, or browser.
- A teacher can start with color codes before using AI detection.

## Benefits for schools
- One search snippet of the VEX store shows a price of 89.99 dollars.
- VEX states that images and video stay on the student device and no personal information is collected. This is a vendor statement.
- No internet is needed.

## Getting started
- [ ] Find the VEX IQ AI Vision Sensor on the VEX site.
- [ ] Check that the school has a VEX IQ 2nd generation Brain.
- [ ] Attach the sensor to the Brain.
- [ ] Open VEXcode IQ in a browser or on a computer.
- [ ] Set up a color code and test it.
- [ ] Try AI detection of a game object.
- [ ] Test an AprilTag with a short program.

## Where is the AI?
The AI detects classroom game objects with a model on the sensor. It also reads color codes and AprilTags. The AI runs on the robot hardware. Students write code that uses what the sensor reports and extend the robot's moves.

## Privacy and safety
The sensor runs on the robot and needs no account or internet. VEX says images and video stay on the student device and no personal information is collected. This is a vendor statement, and the research found no independent review. No privacy policy link was recorded for the sensor. A teacher should check that the camera points at the field and confirm the robot has a 2nd generation Brain.

## Ideas by subject
### computer_science
1. Write blocks that drive a robot toward a detected game object.
2. Create a color code and use it to choose a path.
3. Read an AprilTag and show its ID on the Brain screen.
4. Test detection at three distances and record the results.
5. Explain in a short note how the sensor tells two objects apart.

### engineering

2. Adjust the mount height and compare detections.
3. Build a robot that stops in front of an AprilTag.
4. Design a small field with colored targets.
