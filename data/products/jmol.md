## Overview
Jmol is a free, open source viewer of molecular structures. It is made for chemistry and biochemistry students, educators, and researchers. The desktop app needs Java and runs on Windows, Mac, and Linux. JSmol is the browser version that needs no Java.

## Benefits for students
- Students rotate and inspect 3D molecule models.
- Students see shapes that a flat drawing cannot show.
- Students can use the browser version on a Chromebook.

## Benefits for teachers
- A published handbook and wiki tutorials explain how to use it.
- Teachers can use scripting to set up a view.
- Teachers can embed JSmol in a web page or in Moodle.

## Benefits for schools
- The software is free and the code is open.
- Browsers have dropped the old Java applet. JSmol is the usual choice.
- IT may need to install Java and the desktop app.

## Getting started
- [ ] Go to the Jmol site and choose the desktop app or a JSmol page.
- [ ] For the desktop app, ask IT to install Java and Jmol.
- [ ] For JSmol, open a page that embeds it in a browser.
- [ ] Load a small molecule such as water.
- [ ] Rotate it and try the display options.
- [ ] Read one wiki tutorial.
- [ ] Prepare a short list of molecules for the class.

## Where is the AI?
Jmol has no AI. It draws structures from data files. Students build pattern spotting skills as they compare shapes and bonds across molecules.

## Privacy and safety
No account is needed, and the internet is used for setup. The project page says the viewer runs locally in Java or in the browser. No privacy policy was found. This is not confirmed from a policy. A teacher should check the source of any JSmol page before students open it.
