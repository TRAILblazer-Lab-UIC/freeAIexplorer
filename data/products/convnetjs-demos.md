## Overview
ConvNetJS is a JavaScript library with demos that train neural networks inside a web page. The demos include MNIST and CIFAR-10 image classification, 2-D classification, 1-D regression, an autoencoder, deep Q learning, and a network that paints an image. The AI4K12 listing calls it a browser demo for all ages. Students watch a network learn in real time.

## Benefits for students
- Students see a neural network improve as training runs.
- Students can try toy problems such as sorting points on a 2-D plane.
- Students connect the idea of training to something they can watch.

## Benefits for teachers
- The demos open in a browser with no setup.
- A teacher can lead a walkthrough on a projector.
- The pages have little explanatory text. Teachers should plan the talking points.

## Benefits for schools
- The demos are free and the code is open.
- Training runs in the browser with no install and no GPU.
- Chromebooks, Windows, Mac, and Linux computers all work.

## Getting started
- [ ] Find the ConvNetJS demos page in a web search.
- [ ] Open the page in a modern browser.
- [ ] Start with the 2-D classification demo.
- [ ] Press the training controls and watch the results change.
- [ ] Try the MNIST demo to see image classification.
- [ ] Prepare short notes for the class because the pages explain little.
- [ ] Try the demos once before class to check the school network loads them.

## Where is the AI?
The AI is a neural network that trains inside the browser on the student's own device. The demos cover image classification, regression, and reinforcement learning. Students change settings and watch the network respond. They use what they see to explain how a model learns from data.

## Privacy and safety
No account is needed. The training runs on the device, and the materials do not describe any student data being sent away. The demos need an internet connection to load. A teacher should preview each demo because these research pages have little explanation for students.

## Ideas by subject
### computer_science
1. Train the 2-D classification demo and describe how the dividing line changes over time.
2. Run the 1-D regression demo and explain what the curve is trying to fit.
3. Watch the MNIST demo and list which digits the network confuses.
4. Compare two training runs with different settings and record the differences.
5. Draw a simple diagram of a network and label the input, hidden, and output layers.
