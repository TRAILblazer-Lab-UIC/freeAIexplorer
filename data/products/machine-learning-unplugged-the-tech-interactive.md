## Overview
Machine Learning Unplugged is a 45 minute lesson from The Tech Interactive for grades 4 to 12. Groups of 3 to 4 play wildlife conservationists. They use printed Data Set Cards to refine and test a classification algorithm. The Part 2 cards are held back until later. An optional Advanced Programmers section uses Teachable Machine on a computer.

## Benefits for students
- Students build and test a classification rule with real-looking data.
- Students see why a rule needs testing on new cards.
- Older students can try Teachable Machine as an extension.

## Benefits for teachers
- The download has a lesson plan PDF and an answer key.
- The lesson lists CSTA standards across several grade bands.
- A revised handout for beginning programmers is offered.

## Benefits for schools
- The downloads are free.
- The core lesson needs only printing.
- No computers, accounts, or internet are needed for the core lesson.

## Where is the AI?
The core lesson has no running AI program. Groups build and test a classification algorithm by hand using training data. The optional extension uses Teachable Machine, a web tool. Students can train a model on a computer. Students see how data shapes a model and how testing shows its errors.

## Privacy and safety
The core lesson runs on paper, and the materials mention no account. The materials describe no student data collection. The research read no privacy policy for this item. The optional Teachable Machine section needs a computer and the internet, and the research did not review its data flow. A teacher should check Teachable Machine rules at school before using it.

## Ideas by subject
### computer_science
1. Sort the Data Set Cards and write a rule that classifies each animal.
2. Test the rule on new cards and count the mistakes.
3. Refine the rule and test it again.
4. Open the Part 2 cards and see whether your rule still works.
5. Explain to a partner how training data and testing improve a classification algorithm.

### science
1. Play a wildlife conservationist and group animals by observed features.
2. Explain which features helped most to tell the animals apart.
3. Discuss how scientists use data to protect wildlife.
4. Compare your classification with a classmate's and resolve any differences.
5. Make a field guide page from your final rule.
