## Overview
mBot2 is a buildable coding robot with an aluminum chassis, the CyberPi controller, two encoder motors, an ultrasonic sensor, and a color sensor. Students program it in mBlock with Scratch style blocks that convert to Python with one button. Code uploads over USB or Bluetooth. Core Electronics lists the Starter kit for ages 8 and up.

## Benefits for students
- Students build the robot with bolts and then program it.
- Students move from blocks to Python with one button.
- Students can try speech recognition and voice synthesis.

## Benefits for teachers
- mBlock works as an app, a desktop install, or in a browser.
- A reviewer recommends USB for classes of 20 to 30 robots.
- AI blocks are optional.

## Benefits for schools
- The Makeblock site listed mBot2 at 120 USD.
- Rover kits and the AI Camera cost more.
- Cloud AI blocks need Wi-Fi.

## Where is the AI?
AI is optional. The robot offers speech recognition and voice synthesis, and a retailer says speech recognition uses the internet. Machine vision needs an optional camera. Some AI runs on the device and some in a vendor cloud. Students add AI blocks to their programs and test the results.

## Privacy and safety
Accounts are optional and the internet is needed at setup. Core driving and block coding run on the device. A retailer listing says speech recognition, voice synthesis, account cloud broadcast, and Google Sheets upload use the internet. The research did not confirm which AI blocks need the cloud or whether an mBlock account is needed. The Makeblock policy says it does not knowingly collect data from children under 13. That is a data rule and not an age limit. The policy does not address AI or voice cloud services. A teacher should check the privacy terms before students use the microphone.

## Ideas by subject
### computer_science
1. Write a block program that drives the robot in a square.
2. Press the one-button switch to Python and read the code.
3. Use the ultrasonic sensor to stop the robot before a wall.
4. Try speech recognition and list which words it catches.
5. Change a loop count and predict the new path.

### engineering
1. Build the chassis and check each bolt.
2. Test the encoder motors by driving a set distance.
3. Compare the color sensor on light and dark surfaces.
4. Run a line course and tune the speed.
5. Design a maze and test the robot in it.
