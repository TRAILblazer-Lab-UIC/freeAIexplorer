## Overview
The Agentic AI module is part of LLMs Unplugged. It takes 20 minutes and turns the hand-built model into an agent. Each punctuation token becomes a tool call, which is a real text message sent to a real person. Generation resumes when the reply arrives. The modules table lists ages 7 and up and booklet and cutouts as materials.

## Benefits for students
- Students see how an AI agent can ask for outside help.
- Students use a model they built earlier.
- Students get real replies from real people.

## Benefits for teachers

- It builds on a model the class already made.

## Where is the AI?
The module has no running AI program. It shows how an agent works by letting the paper model call for outside help. Students treat each punctuation token as a tool call. They build skills in thinking about how AI systems act in the world.
