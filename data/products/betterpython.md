## Overview
BetterPython is a Python editor that runs entirely in the browser using a MicroPython interpreter. It has syntax highlighting, several files, and three themes. Students write and run Python code on their own device. After the first load it keeps working offline.

## Benefits for students
- Students can write and run Python with no install.
- Students can keep several files in one project.
- Students can save files to their own computer and load them again.

## Benefits for teachers
- Teachers can open the page and start a lesson in minutes.
- The three themes help students who prefer light or dark screens.
- Teachers can host a copy for a stable setup.

## Benefits for schools
- The tool is free and open source.
- It can be installed as a progressive web app.
- A school can self-host it by copying the src folder to a static web server.

## Getting started
- [ ] Open the hosted BetterPython page in a modern browser.
- [ ] Run a short print program to test it.
- [ ] Load the page once online, then test it offline.
- [ ] Install it as a progressive web app on a test device.
- [ ] Ask IT about hosting a copy of this single-developer project.
- [ ] Copy the src folder to a static web server for a school copy.
- [ ] Show students how to save and load files on the computer.

## Where is the AI?
BetterPython has no AI. It builds the skill of writing logic in code, such as loops and conditions. Students also practice debugging by reading the output.

## Privacy and safety
No account is needed and the code runs in the browser. The README says the site is static, nothing is sent to a remote server, and no third party cookies are used. Those are the developer's own statements. The internet is needed for the first load and clearing the browser cache removes offline use. A teacher should consider a school hosted copy. A single developer maintains the project.
