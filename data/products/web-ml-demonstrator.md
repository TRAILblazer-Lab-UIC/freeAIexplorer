## Overview
Web ML Demonstrator is a machine learning teaching tool that runs in the browser with no web server. It has two apps. The Experimenter lets users upload CSV datasets and run machine learning experiments. The Visualizer shows how different algorithms learn on two dimensional datasets. It suits older high school students.

## Benefits for students
- Students run real machine learning methods on a CSV file.
- Students watch algorithms such as k nearest neighbors and decision trees learn.
- Students compare methods on the same data.

## Benefits for teachers
- The tool covers algorithms including naive Bayes, SVM, random forest, and a neural network.
- Teachers can open the HTML files with no install.
- The algorithms are written in JavaScript for teaching.

## Benefits for schools
- The tool is free and open source.
- It works with no internet after download.
- A teacher will need to download the files, and IT may need to approve it.

## Getting started
- [ ] Find the Web ML Demonstrator repository on GitHub.
- [ ] Download the repository.
- [ ] Open the HTML files in a browser.
- [ ] Try the Visualizer with a simple 2D dataset.
- [ ] Prepare a small CSV file for the Experimenter.
- [ ] Ask IT to approve the download if needed.
- [ ] Note that the hosted demo link in the README returns 404.

## Where is the AI?
The AI is a set of classic machine learning algorithms that run in the browser. They include k nearest neighbors, naive Bayes, SVM, decision trees, random forest, linear models, and a neural network. Students upload data, choose a method, and see how well it learns. The algorithms are not tuned for speed.

## Privacy and safety
No account is needed and no internet is needed once the files are downloaded. The repository has no privacy statement. It says the tool runs entirely in the browser, and it does not describe uploaded CSV files as being sent anywhere. The hosted demo in the README returned an error. Run the files locally. A teacher should check any CSV file for personal information before students upload it. The project is a small single author effort with no independent review.
