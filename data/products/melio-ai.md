## Overview
Melio.ai is a hackathon project that aims to teach coding through music. A search summary of the Devpost page says it runs a model called GPT-OSS 20B locally through Ollama. The Devpost page returned an error. These details come from search results only. It is a prototype and not a maintained classroom product.

## Benefits for students

- The project describes coaching on code.
- Core functions may work with no internet.

## Benefits for teachers

## Benefits for schools

## Where is the AI?
The AI is the GPT-OSS 20B language model, which runs locally through Ollama per the search summary. Students would ask a coding question and read the coaching. The team reports about 5 tokens per second on a 16 GB machine.

## Privacy and safety
The materials do not state which accounts students need. A search summary of a Devpost page says core functions work with no internet. The page itself could not be read, and the claims are self reported by the team. The research found no privacy policy. A teacher should check the repository for data handling before any student use. A teacher should also treat it as a prototype.

## Ideas by subject
### computer_science
1. Write a short program and ask the coach for a hint.
2. Compare the coach's hint with the explanation from a classmate.
3. Fix a bug with a hint and describe the steps you took.
4. Time how long the local model takes to reply and discuss why.
5. Write a list of questions a coding coach should answer well.

### music
1. Describe a rhythm in steps that a program could follow.
2. Write a loop that repeats a beat pattern.
3. Compare a coded pattern with a pattern clapped by hand.
4. Plan a short song as a list of coded steps.
5. Explain how music and code both use repeating patterns.
