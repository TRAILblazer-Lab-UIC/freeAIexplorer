## Overview
OBS Studio is free open source software for video recording and live streaming. Users build scenes from window captures, images, text, browser windows, webcams, and capture cards. It has an audio mixer with filters, scene transitions, Studio Mode, and hotkeys. A plugin and scripting API is also included.

## Benefits for students
- Students produce videos and live shows.
- Students learn to manage scenes, audio, and transitions.
- Students practice broadcast skills.

## Benefits for teachers
- Teachers can record lessons and screen demos.
- Recordings save to local files.
- The tool supports streaming to RTMP services.

## Benefits for schools
- The software is free.
- It runs on Windows, macOS, and Linux but not on Chromebooks.
- IT may need to approve the install.

## Getting started
- [ ] Download OBS Studio from obsproject.com.
- [ ] Ask IT to approve the install on managed devices.
- [ ] Connect a webcam or capture device.
- [ ] Set a recording folder.
- [ ] Build a scene with a window capture and a webcam.
- [ ] Test the audio mixer.
- [ ] Check the macOS version. The official site lists macOS 13.

## Where is the AI?
This tool has no AI. It builds skills in media production and in planning a sequence of scenes. Students practice timing and layout.

## Privacy and safety
No account is needed, and recordings stay on the computer unless the user streams. The internet is used at setup. The privacy policy lists collected data that includes performance analytics, crash and network data, IP address, and device type. The policy does not clearly separate website data from in-app data. The research could not tell whether the desktop app sends crash or telemetry data. A teacher should ask IT to check network settings and set rules for what students record and stream.
