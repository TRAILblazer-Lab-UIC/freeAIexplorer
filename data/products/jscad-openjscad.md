## Overview
JSCAD is a set of tools for making parametric 2D and 3D designs with JavaScript. Users write a .js file and drag it into the modeling window. The window shows the model and exports it in formats such as STL, 3MF, OBJ, and SVG. It suits older students who already know some code.

## Benefits for students
- Students change a number in the code and watch the model change.
- Students export a file that a 3D printer can use.
- Students practice real JavaScript through a design task.

## Benefits for teachers
- The online app needs no install.
- The same tool works as an online app, a command line tool, or npm packages.
- The tool is rated advanced for both students and teachers.

## Benefits for schools
- The software is free and the code is open.
- It runs in a modern browser on Chromebooks, Windows, Mac, and Linux.
- A 3D printer is needed to print the exports.

## Getting started
- [ ] Open openjscad.xyz in a browser.
- [ ] Load one of the example designs.
- [ ] Change one number in the code and see the result.
- [ ] Write a short .js file and drag it into the window.
- [ ] Export an STL file.
- [ ] Ask IT to install Node.js only for the self hosted version.
- [ ] Note that the homepage promotes a V3 beta and its examples link to v2.

## Where is the AI?
JSCAD has no AI. Students write code that follows exact steps. They build logic and sequencing skills and learn to use variables to control a shape.

## Privacy and safety
No account is needed, and the internet is used for setup. Designs are loaded as local files according to the page description. The official page does not say whether designs leave the browser, and no privacy policy was found. A teacher should check which version the class uses. The homepage and the examples differ. A teacher should also supervise 3D printer use.

## Ideas by subject
### engineering
1. Design a simple part, such as a bracket, by writing its size in variables.
2. Change a variable to resize the part and check the fit.
3. Export an STL file and print the part.
4. Make a design that others can adjust with a few numbers.
5. Test the printed part and revise the code.

### computer_science
1. Write a JavaScript file that makes a cube and a cylinder.
2. Use a loop to repeat a shape in a row.
3. Create a function that builds a shape from a size.
4. Fix a broken design file by reading the code.
5. Share a design file and explain each part to a partner.
