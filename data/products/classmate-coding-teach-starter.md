## Overview
Classmate Coding is a Teach Starter resource with eight activities across four stages. Students use coding tiles such as move forward and turn left to direct a classmate or the teacher through a task. A loop tile repeats instructions a set number of times. Later cards cover IF, THEN, and ELSE tiles for decisions. The resource listing says Grades 4-6.

## Benefits for students
- Students program a real person and see each instruction run.
- Students move from simple moves to loops and decisions.
- Students master each stage before they move on.

## Benefits for teachers
- The activity cards get harder step by step.
- No computer is needed.
- Teachers print and cut the tiles and cards.

## Benefits for schools
- Teach Starter is a subscription site, and pricing for this resource was not found.
- The activity needs only paper and printing.
- No devices are needed in class.

## Where is the AI?
This resource has no AI. It builds sequencing, loops, and conditional logic. Students use IF, THEN, and ELSE tiles to make decisions in a program.

## Privacy and safety
The activity runs on paper. Student work stays in the room. The pages read do not state whether an account is needed. A teacher should check the site terms before downloading. The internet is used only to get the resource. A teacher should also set rules for moving safely when students direct a classmate.

## Ideas by subject
### computer_science
1. Direct a classmate across the room using only move forward and turn left tiles.
2. Add a loop tile to shorten a long set of instructions.
3. Write an IF, THEN, ELSE rule and test it on a classmate.
4. Debug a program that sends the classmate to the wrong spot.
5. Trade programs with another pair and run each other's code.
