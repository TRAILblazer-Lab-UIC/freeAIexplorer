## Overview
Python Tutor is a free online compiler and visual debugger. Students write code in a web browser and step through it to see variables, objects, data structures, and stack frames. It supports Python, Java, C, C++, and JavaScript. Teacher Mode is also free.

## Benefits for students
- Students see exactly what each line of code changes.
- Students find mistakes by stepping through a program.
- Students can try several languages in one place.

## Benefits for teachers
- Teacher Mode is free.
- Teachers can embed visualizations in web pages.
- The tool fits introductory programming and data structure lessons.

## Benefits for schools
- The tool is free and needs no install.
- It runs on any device with a browser and internet.
- Code is sent to the vendor server. Schools should review the privacy terms.

## Getting started
- [ ] Open the Python Tutor website in a browser.
- [ ] Ask IT to confirm the school network allows the site.
- [ ] Review what the site logs before students use it.
- [ ] Paste a short sample program and step through it.
- [ ] Tell students not to put personal information in their code.
- [ ] Try Teacher Mode to see what it offers.
- [ ] Embed one visualization in a class page.

## Where is the AI?
Python Tutor has no AI. It builds an AI-related skill, which is tracing logic. Students follow data as it changes from step to step. That skill helps them understand how any program reaches a result.

## Privacy and safety
No account is needed, but the internet is needed at all times. The policy says submitted code, options, interactions, and IP addresses are logged on the vendor server and may be analyzed for research. It says no personally identifiable information is collected, and it tells users not to share confidential information. Google services are used for analytics and ads. The research found no retention period and no FERPA or COPPA statement. A teacher should check the school's rules on student data and keep personal details out of code.

### computer_science

2. Predict the output of a function and then check it by stepping through.
3. Watch a list change as items are added and describe the new shape.
4. Trace a recursive function and draw the stack frames.
5. Fix a buggy program by finding the step where the value goes wrong.
