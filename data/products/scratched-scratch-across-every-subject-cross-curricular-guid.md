## Overview
This is a PDF called the Scratch Cross-Curricular Integration Guide, posted by Carlos Leon in 2016. It links to ScratchEd and community resources for ELA, math, science, fine arts, and social studies. Each section lists overview resources, narrower lessons, and example student projects. The guide is a link collection and the linked material varies in age.

## Benefits for students
- Students use Scratch in many subjects.
- Students see examples such as book reports and a multiplication game.
- Students make projects that show what they know.

## Benefits for teachers
- One PDF points to resources for five subjects.
- Sections cover grades 3-8 and 6-12.
- Teachers can pick links that fit their class.

## Benefits for schools
- The guide is free.
- No account is needed to read it.
- Linked pages need internet access, and some may be out of date.

## Getting started
- [ ] Find the Scratch Cross-Curricular Integration Guide PDF.
- [ ] Open the PDF and choose one subject section.
- [ ] Follow the links and check that each page still works.
- [ ] Try one linked project in Scratch.
- [ ] Ask IT to confirm Scratch is open on school devices.
- [ ] Plan one cross-curricular lesson.

## Where is the AI?
The guide has no AI. Scratch is a block coding tool. Students build sequencing and logic skills as they code projects for different subjects.

## Privacy and safety
The guide is a PDF of links, and it needs no account. The linked projects mostly live on the Scratch website. The research did not review the Scratch privacy policy or the data handling of other linked sites. A teacher should check each linked page and the school rules on Scratch accounts before students use them.

## Ideas by subject
### ela
1. Build an interactive book report in Scratch with a sprite that retells the plot.
2. Code a short story with dialogue between two characters.
3. Create a vocabulary game for words from a class text.
4. Add narration to a poem project.
5. Present a project and explain how it shows the story.

### math
1. Build a multiplication game that checks each answer.
2. Code a project that draws shapes with equal sides.
3. Create a quiz on fractions with a score.
4. Use a variable to count steps and show a pattern.
5. Test a classmate's game and report any wrong answers.

### science
1. Build a project that shows the life cycle of a plant.
2. Code a model of the water cycle with moving sprites.
3. Create a quiz about animals and their habitats.
4. Animate the phases of the Moon.
5. Present a science project and explain each step.

### social_studies
1. Create a map project that gives a fact at each click.
2. Code a timeline of events from a unit.
3. Build a short animation about a historical person.
4. Make a quiz about a state or country.
5. Present a project and tell the class where the facts came from.

### visual_arts
1. Design a sprite costume and code it to change colors.
2. Draw a pattern with the pen blocks and repeat it with a loop.
3. Create an animated greeting card.
4. Build an interactive gallery of student drawings.
5. Explain the art choices in a finished project.
