## Overview
Jupyter Notebook and JupyterLab are notebook environments for Python and other languages. They are installed on a computer with pip, conda, mamba, or Homebrew. They open in a web browser served from the student's own computer. Students mix code, output, and text in one document.

## Benefits for students
- Students see the result of each code cell right below it.
- Students write notes next to their code.
- Students learn a tool that is widely used for data science.

## Benefits for teachers
- A notebook can hold a lesson, code, and questions in one file.
- Many language kernels are supported.
- Teachers can pick the classic Notebook view or the JupyterLab view.

## Benefits for schools
- The software is free and the code is open.
- Everything runs on the student's own computer after setup.
- IT may need to approve the install on managed lab machines.

## Getting started
- [ ] Install Python on a test computer.
- [ ] Run pip install jupyterlab or pip install notebook. Conda and Homebrew also work.
- [ ] Launch it with jupyter lab or jupyter notebook.
- [ ] Open a new notebook and run a short Python cell.
- [ ] Add a text cell with a heading.
- [ ] Ask IT to approve the install on lab machines.
- [ ] Save student notebooks on the computer or a school drive.

## Where is the AI?
Jupyter has no AI. It runs code that students write. Students build data skills by loading data, running code, and reading the output.

## Privacy and safety
No account is needed, and the internet is used for setup. The install page does not discuss data collection. The notebook server runs locally and saves notebooks as files on the device. Packages come from PyPI or conda during setup, and third party extensions a class installs may behave differently. A teacher should check where students save notebooks.

## Ideas by subject
### computer_science
1. Run a few lines of Python and read the output below the cell.
2. Write a short program that prints a table of numbers.
3. Mix a text cell and a code cell to explain a program.
4. Debug a broken cell with a partner.
5. Share a finished notebook as a mini lesson.

### science
1. Load a small data file and print its first rows.
2. Make a plot of a measurement over time.
3. Calculate the average of a set of readings.
4. Write a text note that explains what the plot shows.
5. Repeat the analysis with new data and compare the results.
