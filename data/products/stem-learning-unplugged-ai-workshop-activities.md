## Overview
This STEM Learning resource is described as a set of unplugged AI workshop activities. Two are a generative AI art activity and a monster recognition cards activity. In the monster activity students build a feature database and test it. Each workshop is said to have teaching notes, a classroom presentation and printable materials.

## Ideas by subject
### computer_science
1. Build a feature database for the monster cards and list each feature.
2. Test a partner's database by guessing a monster from its features.
3. Find a monster that the database often confuses and explain why.
4. Add a new feature and check whether accuracy improves.
5. Explain how classification works using the monster example.

### visual_arts
1. Try the generative AI art activity and describe the steps a machine follows.
2. Draw a monster from a list of features written by a classmate.
3. Compare two drawings made from the same instructions.
4. Write a prompt that could guide an art generator and sketch the result by hand.
5. Discuss who deserves credit for art made from instructions.
