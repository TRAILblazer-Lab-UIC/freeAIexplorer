## Overview
The FIRST Tech Challenge Class Pack is a classroom curriculum for grades 7 to 12 that FIRST describes as mapped to state and national standards. Units use a guiding question and a real-world product, with knowledge checks and interactive physics labs. Students build and program a competition style robot using the REV Control Hub based kit. The REV hardware is bought separately.

## Benefits for students
- Students build and program a competition style robot.
- Students learn physics ideas through interactive labs.
- Students answer a guiding question in each unit.

## Benefits for teachers
- The curriculum comes with knowledge checks and labs.
- A search snippet says it is offered in English and Spanish.
- Teachers can use it for class time or a robotics team.

## Benefits for schools
- The REV hardware is not included with Class Pack registration.
- The kit is bought through the FIRST Dashboard in the US and Canada or from REV Robotics elsewhere.
- The kit price and programming environment need to be verified before use.

## Getting started
- [ ] Find the FTC Class Pack on the FIRST website and register.
- [ ] Buy the REV Control Hub based kit separately.
- [ ] Ask IT about the software needed for programming.
- [ ] Set up the Control Hub.
- [ ] Set up the Driver Station.
- [ ] Review the first unit and its guiding question.
- [ ] Try one lab before assigning it to students.

## Where is the AI?
This curriculum has no AI. Students program a robot controller to drive and act. They build skills in logic and sensing as they write the code.

## Privacy and safety
The materials do not state which accounts students need. They do not say what student data is collected. A teacher should check the FIRST registration terms and any badge accounts with school leaders. The listed Tallo badges come from a search snippet. A teacher should also review safety rules for a competition-size robot.

## Ideas by subject
### engineering
1. Answer a unit's guiding question by sketching a robot design.
2. Build a drivetrain from the kit and test its speed.
3. Compare two designs for the same task and pick one.
4. Test a mechanism and record where it fails.
5. Present the final robot and explain the design choices.

### computer_science
1. Program the Control Hub to drive the robot forward.
2. Add a turn to the program and test the angle.
3. Write a short autonomous routine for a simple field task.
4. Fix a program that makes the robot drift.
5. Compare two versions of the code and explain which works better.

### science
1. Use an interactive physics lab to explore force and motion.
2. Predict how added weight changes the robot's speed.
3. Measure the robot's travel over a set time.
4. Graph the results of a test run.
5. Explain the results using the lab's physics ideas.
