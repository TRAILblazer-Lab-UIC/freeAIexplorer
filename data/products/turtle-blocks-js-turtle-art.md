## Overview
Turtle Blocks is a Logo inspired block programming tool. Students snap blocks together and a turtle draws art on the screen. It has a low floor for beginners and extra features for math and computer science. The official address now redirects to Music Blocks, and the Turtle Blocks JS repository is marked deprecated.

## Benefits for students
- Students see their code turn into drawings right away.
- Students practice shapes, angles, and patterns.
- Students can move on to sensors and math blocks.

## Benefits for teachers
- A guide and tutorials are included in the repository.
- The blocks are simple. A new teacher can learn them quickly.
- One tool serves art, math, and coding lessons.

## Benefits for schools
- The tool is free and the code is open source.
- It runs in a browser or from local files on Chromebooks, Windows, Mac, and Linux.
- Student work stays on the device and no account is needed.

## Getting started
- [ ] Open the hosted site, which redirects to Music Blocks, or download the repository from GitHub.
- [ ] For local use, open the index.html file in a browser.
- [ ] Use Chrome for best results. The tool also works in Firefox, Opera, and Safari.
- [ ] Read the Turtle Blocks Guide in the repository.
- [ ] Try a first program that draws a square.
- [ ] Save student work to a local file.
- [ ] Check whether the redirect to Music Blocks changes your lesson plans.

## Where is the AI?
This tool has no AI. The turtle follows each block exactly. Students build sequencing and pattern spotting skills as they repeat and change blocks.

## Privacy and safety
No account is needed. The README says it runs in a browser on the client side and can run from local files. The research read no privacy policy. The repository is deprecated and the official address now leads to Music Blocks. The internet is needed to open the site. Check which address the school uses and ask IT to review it.

## Ideas by subject
### computer_science
1. Build a square with blocks and then use a repeat block to shorten the code.
2. Draw a star and explain each turn in the program.
3. Use a sensor block to change the drawing and describe what happened.
4. Swap programs with a partner and predict what each one will draw.
5. Debug a program that draws the wrong shape.

### math
1. Draw regular polygons and record the turn angle for each one.
2. Explore how the number of repeats changes the shape.
3. Use math blocks to calculate side lengths and test them.
4. Draw a spiral and describe the pattern in the numbers.
5. Compare two programs that draw the same shape and decide which is shorter.

### visual_arts
1. Create a colorful pattern with repeated shapes.
2. Change the pen color and size to make a layered design.
3. Draw a mandala that has rotational symmetry.
4. Plan a design on paper and then code it with the turtle.
5. Display class designs in a gallery and talk about the choices.
