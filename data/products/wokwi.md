## Overview
Wokwi is a browser based simulator for microcontroller projects, including Arduino boards, ESP32, and Raspberry Pi Pico. Students write code and simulate circuits without physical hardware. Wokwi Classroom is a paid plan aimed at universities, colleges, and technical institutions. Independent reviews describe the main tool as code first, with no breadboard view.

## Benefits for students
- Students test code on virtual boards with no hardware.
- Students write Arduino and MicroPython code.
- Students can try again as often as they like.

## Benefits for teachers
- Teachers open wokwi.com and start in minutes.
- An account can save projects.
- Reviews note it lacks teacher management compared with Tinkercad Circuits.

## Benefits for schools
- The docs say it is free for personal use. Commercial users need a paid plan.
- The Classroom plan is 30 EUR per student per semester with a minimum.
- Students need only a browser.

## Where is the AI?
Wokwi has no AI. The simulator runs the code that students write. Students build skills in logic and sensor data.

## Privacy and safety
Account data goes to the vendor. It includes name and email, a profile photo and ID from Google or GitHub sign in, shared projects, analytics, and IP addresses. Data is stored mainly in the US on Google Cloud, and the policy says Wokwi does not sell user information. The policy says the service is not directed at users under 13. The research did not confirm whether saving projects needs an account and did not read the terms of service. A teacher should check the under 13 statement and school policy before students sign in.

## Ideas by subject
### engineering
1. Run a sample circuit and describe what each part does.
2. Add an LED to a project and test it.
3. Compare two boards for the same task.
4. Simulate a sensor and record its readings.
5. Plan a small device and check it in the simulator.

### computer_science
1. Write an Arduino program that blinks an LED in the simulator.
2. Change the delay and observe the result.
3. Write a MicroPython program on a Pico.
4. Add a button and write code that reacts to it.
5. Debug a sketch that does not run.
