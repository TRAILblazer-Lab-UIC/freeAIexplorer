## Overview
This is an online course from the Raspberry Pi Foundation on FutureLearn. Learners build a robot buggy and control it with a Raspberry Pi. They connect motors, add sensors and write Python algorithms. The course also looks at how robotics affects society. Teachers are named as an intended audience.

## Benefits for students
- Older students and adults build a buggy from parts.
- Learners write Python to control motors and sensors.
- Learners think about the social effects of robotics.

## Benefits for teachers
- The course suits people with little or no physical computing experience.
- Teachers are named as an intended audience.
- Listings give 5 to 12 weeks, depending on the source.

## Benefits for schools
- Listings did not state a price. A free tier is described in a search summary.
- Each learner needs their own Raspberry Pi 3B, 3B+ or 4 and buggy parts.
- The free GitHub mirror says the course is no longer available there.

## Where is the AI?
The course has no AI. It builds skills in text coding, sensing and algorithms. Learners write Python that guides the buggy.

## Privacy and safety
A FutureLearn account is needed to enroll. The official course page could not be read. Account rules, privacy terms, and cost are unconfirmed. A GitHub mirror says the course is no longer available. The Raspberry Pi code runs on the learner's own device. A teacher should read the FutureLearn terms and age rules. Learners need to be old enough for the platform.

## Ideas by subject
### computer_science
1. Write a Python program that drives the buggy forward.
2. Add a sensor and make the buggy stop near an object.
3. Write an algorithm for a simple maze.
4. Test the algorithm and note each failure.
5. Explain the algorithm to a partner in plain words.

### engineering
1. Connect the motors to the Pi and test them.
2. Add a distance sensor and check its readings.
3. Compare two buggy layouts and pick one.
4. Write a short report on how robots affect jobs.
5. Document the build with photos and notes.
