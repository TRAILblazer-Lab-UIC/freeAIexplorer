## Overview
Robot Virtual Worlds is a simulator for programming virtual VEX and LEGO robots with ROBOTC. A 2022 Frontiers paper describes it as proprietary, Windows only and needing installation. Licenses are sold as annual or perpetual seats.

## Benefits for students
- Students program virtual robots in text code.
- Students test VEX and LEGO designs without hardware.
- Students practise ROBOTC.

## Benefits for teachers
- A class can work with fewer physical robots.
- VEX and LEGO editions exist.
- Teachers can test code before a robot run.

## Benefits for schools
- Annual licenses were 89 USD for one seat, 249 USD for 6 seats and 499 USD for 30 seats per a search snippet.
- Resellers show other prices.
- IT must install it on Windows computers.

## Getting started
- [ ] Find Robot Virtual Worlds and choose the VEX or LEGO edition.
- [ ] Check current prices with the vendor.
- [ ] Buy a license.
- [ ] Download the software with the emailed license IDs.
- [ ] Ask IT to install and activate it on Windows computers.
- [ ] Run a sample program.
- [ ] Plan the first class task.

## Where is the AI?
The vendor does not describe any AI. Students build skills in text coding, sequencing and logic. They write ROBOTC for a virtual robot and test the result.

## Privacy and safety
The software runs on a Windows computer and the internet is needed at setup. License IDs and passwords arrive by email. The materials do not state whether student accounts are needed or what data is collected. The research did not review a privacy policy because the official page could not be read. A teacher should ask IT to check the license activation terms before class.
