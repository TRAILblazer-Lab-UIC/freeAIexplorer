## Overview
The Bit:Bot XL and Bit:Bot Pro are ready assembled wheeled robots that carry a BBC micro:bit. Both have line following sensors, addressable LEDs, and motors. The Pro adds wheel sensors for driving set distances and angles and an infrared receiver. Students program them with the Microsoft MakeCode Bit:Bot extension.

## Benefits for students
- Students program a robot that moves and senses.
- Students can build line following projects.
- Students can use the Pro to drive exact distances and turns.

## Benefits for teachers
- The robots arrive ready assembled.
- Blocks in MakeCode make the first program simple.
- Expansion options add ultrasonic, OLED, and LED matrix parts.

## Benefits for schools
- The XL is listed at 44.10 GBP and the Pro at 42.90 GBP including VAT at The Pi Hut.
- The micro:bit and 3 AA batteries are extra.
- The original Bit:Bot is retired and replaced by the XL.

## Getting started
- [ ] Buy the robot, a BBC micro:bit V1 or V2, and 3 AA batteries.
- [ ] Open MakeCode in a browser.
- [ ] Add the BitBot extension.
- [ ] Write a short program that drives forward and stops.
- [ ] Download the code to the micro:bit over USB.
- [ ] Test the line following sensors on a taped track.
- [ ] Plan a place to charge or swap batteries.

## Where is the AI?
This robot has no AI. It follows the code students download. Students build sensor and logic skills as they use line sensors to decide where the robot goes.

## Privacy and safety
The robot has no accounts or cloud service. The research found no student data collection by the robot. Students write code in the MakeCode web editor and download it to the micro:bit. The research did not review the MakeCode editor's own privacy terms. No 4tronix privacy policy was found. A teacher should check the MakeCode terms and confirm that school computers can reach the editor.

## Ideas by subject
### computer_science
1. Write a program that drives the robot in a square.
2. Use the line sensors to follow a black line.
3. Make the LEDs show a pattern when the robot turns.
4. Add a buzzer tune when the robot reaches the end.
5. Debug a program that leaves the track.

### engineering
1. Build a track and test how fast the robot can follow it.
2. Compare the line sensor readings on light and dark surfaces.
3. Use the Pro to drive a set distance and measure the error.
4. Design an obstacle course for the robot.
5. Record test results in a table and improve the design.
