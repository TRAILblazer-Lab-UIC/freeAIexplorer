## Overview
Clean Python Editor is one small HTML file that opens in Chrome or Microsoft Edge. Students write Python 3, press Run or Ctrl+Enter, and see the output. It supports input() and has no adverts. The Tes listing aims it at Computing students aged 14 to 16.

## Benefits for students
- Students can start coding as soon as the file opens.
- Students can answer input() prompts, which makes simple programs interactive.
- Students can save work in the browser or download a .py file.

## Benefits for teachers
- The tool is a single 32 KB file that is easy to share.
- Teachers can send it through Teams, OneDrive, Google Classroom, email, or a shared drive.
- Students use Download .py to hand in their work.

## Benefits for schools
- The download is free and lists at 0 GBP on Tes.
- Nothing needs installing, and code runs in the browser on the device.
- An administrator may need to allow the Pyodide CDN.

## Getting started
- [ ] Download the HTML file from the Tes listing for Clean Python Editor.
- [ ] Open the file in Chrome or Microsoft Edge.
- [ ] Type a short program and press Run to test it.
- [ ] Ask IT to allow the Pyodide CDN. The listing says an administrator may need to do this.
- [ ] Share the file with students through Teams, OneDrive, Google Classroom, email, or a shared drive.
- [ ] Show students how to save in the browser and how to use Download .py.
- [ ] Collect the downloaded .py files as the submitted work.

## Where is the AI?
This tool has no AI. It runs the Python that students write. Students build skills in sequencing and logic as they write and test programs.

## Privacy and safety
No account is needed, and the Tes listing says saved programs stay on that browser and computer. The Python engine loads from a CDN each time the file opens. The research did not confirm whether the engine is cached for offline use. School networks may need to allow the Pyodide CDN. The listing states no other data practices. A teacher should confirm the live listing before sharing it. A teacher should also check that saved browser work stays on a device that students can reach again.
