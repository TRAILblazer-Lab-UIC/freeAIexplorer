## Overview
Maker's Pet Loki is an open-source 200 mm 3D-printable home pet robot that works with the Kaia.ai robotics software platform. It uses an Arduino ESP32 microcontroller and a 360 degree laser distance sensor for room mapping. Mapping and self-driving use ROS 2. Design files are in Fusion 360 and the PCB is in KiCad. The repository offers assembly, firmware and 3D printing guides.

## Where is the AI?
The vendor does not describe any AI. The robot uses a laser sensor and ROS 2 for mapping and self-driving. Some features are listed as work in progress.

## Privacy and safety
No accounts are needed. The robot and a computer run by the user run the software. The open source project has no privacy policy. The research did not check whether the Kaia.ai platform sends data online. The materials do not say whether the internet is required. A teacher should ask IT to review the Docker setup and the network behavior before running it. Keep the laser sensor away from eyes and follow its safety notes.
