## Overview
Pure Data is a visual dataflow programming language created by Miller Puckette in the 1990s. Users connect graphical objects with cords to control audio and other media. It is open source and has a large community that builds extensions. It suits older students in music technology or computing electives.

## Benefits for students
- Students build sound tools by wiring objects together on screen.
- Students hear changes in real time as they patch.
- Students learn how data and control flow through a system.

## Benefits for teachers
- The software is free and runs on Windows, macOS, and Linux.
- Community extensions let teachers add video through GEM or networking through FUDI.
- A university sound design course uses it, which gives teachers a model to follow.

## Benefits for schools
- The software costs nothing and works offline after the first download.
- Student projects stay on the computer.
- IT may need to approve the install on managed computers.

## Getting started
- [ ] Get the installer for your operating system from the Pure Data site.
- [ ] Ask IT to approve the install on managed computers.
- [ ] Install Pure Data on one test machine.
- [ ] Check that the computer has working audio output.
- [ ] Plug in a microphone or audio interface for projects that need sound input.
- [ ] Build one simple patch that makes a tone and share it with students.
- [ ] Plan extra time because the learning curve is steep for audio theory.

## Where is the AI?
Pure Data has no AI. It builds an AI-related skill, which is thinking in flows of data. Students see how a signal moves from one object to the next. That kind of sequencing helps them understand how larger systems process information.

## Privacy and safety
No account is needed, and the internet is used for setup. Student patches and recordings stay on the device. No privacy policy was found, and the official site could not be read. Patches can use networking objects, which send data only if the author builds that in. A teacher should check that microphones are used only for class projects and review any patch that uses networking.

## Ideas by subject
### music
1. Study how an MIT sound design course uses Pd vanilla, then build a simple synthesizer of your own.
2. Patch together a tone generator and change its pitch with a slider.
3. Record a short sound with a microphone and change it with an effect patch.
4. Build a simple drum pattern and adjust its tempo while it plays.
5. Compose a short piece from patched sounds and explain each object you used.

### computer_science
1. Build a patch that sends a number through three objects and describe what each object does.
2. Compare a visual patch with a line of text code that does the same job.
3. Connect objects to make a counter and trace how the data moves.
4. Use the FUDI protocol idea to explain how two programs can send messages to each other.
5. Debug a broken patch by following each cord and finding the wrong connection.
