## Overview
Racket is a programming language and DrRacket is its editor. DrRacket includes five teaching language levels for the How to Design Programs curriculum. Error checks aim at beginner mistakes. Students write programs and test them with check-expect.

## Benefits for students
- Students get clear error messages that fit beginner mistakes.
- Students test each function with check-expect.
- Students can see arrows from names to their definitions.

## Benefits for teachers
- The Bootstrap curriculum teaches algebra through game programming and can run in DrRacket.
- The site names Program by Design for high school teachers.
- The teaching levels let teachers add ideas in steps.

## Benefits for schools
- The software is free and open source.
- It runs offline after the install.
- IT may need to approve it on managed computers.

## Getting started
- [ ] Download the installer from download.racket-lang.org.
- [ ] Replace older Windows installers and macOS builds 8.12 to 9.3 with new downloads. A 2026 signing key change makes this needed.
- [ ] Ask IT to approve the install on managed computers.
- [ ] Install DrRacket on a test computer.
- [ ] Choose a teaching language level in the language menu.
- [ ] Write a small function and a check-expect test for it.
- [ ] Look at the HtDP teaching language documentation.

## Where is the AI?
Racket has no AI. It builds an AI-related skill, which is logic. Students write small functions and test each one. That practice is a base for building reliable programs.

## Privacy and safety
No account is needed, and the internet is used at setup. Programs stay on the device. No privacy policy was reviewed. A snapshot build machine was compromised around August 10, 2026. The team found no altered installers and replaced the binaries. A teacher should confirm that IT installs a fresh download.

## Ideas by subject
### computer_science
1. Write a function and test it with check-expect as the HtDP teaching levels teach.
2. Use the arrows in DrRacket to trace a name to its definition.
3. Build a function that draws an image from a number.
4. Write three tests for a function before you write the function.
5. Compare two language levels and describe what each one allows.

### math
1. Follow a Bootstrap lesson and write a function that matches an algebra rule.
2. Make a game where the position of a character follows a formula.
3. Test a function with several inputs and compare to hand calculations.
4. Change a number in a formula and describe how the game changes.
5. Explain a function in words and in code.
