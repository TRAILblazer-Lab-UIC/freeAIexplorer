## Overview
Picotron is a fantasy workstation from the maker of PICO-8. It is a self-contained creative environment for making and sharing Lua apps, games, and tools. It has a 480x270 64-color display and a Lua 5.4 virtual machine. It includes editors, a tabbed desktop, and a synthesizer.

## Benefits for students
- Students can build apps, games, and tools in one place.
- Students use bundled code, sprite, and sound editors.
- Projects export as stand-alone HTML or binaries.

## Benefits for teachers
- The tool is advanced and best for experienced teachers.
- Search results found no classroom coverage or independent reviews.
- Teachers should try it fully before class.

## Benefits for schools
- It costs 19.99 USD through itch.io, with a Lexaloffle key and future updates.
- No education license is mentioned on the page.
- IT will likely need to approve the install.

## Getting started
- [ ] Buy Picotron through itch.io and download the desktop build.
- [ ] Ask the vendor about a school license. None is mentioned.
- [ ] Ask IT to approve the install on Windows, Mac, or Linux.
- [ ] Open the editors and explore the desktop.
- [ ] Write a small Lua program.
- [ ] Save a cartridge as a p64 file or a png image.
- [ ] Export a project to HTML to share.

## Where is the AI?
The vendor does not describe any AI in Picotron. Students write Lua code that runs on its virtual machine. They build logic and sequencing skills.
