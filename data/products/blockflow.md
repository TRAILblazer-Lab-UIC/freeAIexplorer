## Overview
BlockFlow is a fork of the Scratch editor that adds configurable project files. The files control the editor, limit the available blocks, and embed step-by-step tutorials with text, images, and video. A visual generator builds the files without writing JSON. A player mode hides the editor.

## Benefits for students
- Students see only the blocks needed for the task.
- Students follow tutorials inside the editor.
- Students can open a finished project in full-screen player mode.

## Benefits for teachers
- Teachers can limit toolbox categories and blocks.
- A generator page builds project files without code.
- Teachers can embed a lesson in their own web page.

## Benefits for schools
- The tool is free and open source.
- It must be self-hosted, and that needs server skills.
- Where student projects are stored depends on the host page.

## Getting started
- [ ] Find the BlockFlow project and its tagged release.
- [ ] Ask IT to host the release zip called dist-embedded.zip on a web server.
- [ ] Extract it into a directory that the server shares.
- [ ] Embed it in a page by iframe.
- [ ] Use the generator page to build a project file.
- [ ] Decide where student projects will be saved.
- [ ] Test with a small group before a class.

## Where is the AI?
BlockFlow has no AI. It builds the skill of sequencing and logic through Scratch blocks. Limiting the blocks lets students practice one idea at a time.

## Privacy and safety
The README describes no built in accounts or storage service. The host page decides where student projects are saved. The research found no privacy policy and did not confirm whether the internet is needed. A teacher should ask IT how projects are saved and who can see them. The project is at an early stage.
