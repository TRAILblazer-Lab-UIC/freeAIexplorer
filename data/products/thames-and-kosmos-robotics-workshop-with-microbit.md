## Overview
This is a 248-piece kit with snap-together parts for building 14 motorized robots. It includes a micro:bit, two ultrasonic sensors, one servo motor, two direct-drive motors, and a rechargeable lithium-ion battery. Students program the robots with MakeCode, which starts with blocks and moves to Python and JavaScript. The kit lists ages 8 and up.

## Benefits for students
- Students build 14 different motorized robots.
- Students start with blocks and grow into Python and JavaScript.
- Students work through 20 experiments.

## Benefits for teachers
- A 32-page manual guides each build.
- MakeCode is web based and works on a tablet or PC.
- A classroom bundle is also sold.

## Benefits for schools
- The kit costs 279.95 USD from Thames & Kosmos, Target, and STEMfinity.
- The classroom bundle price was not read.
- The editor needs the internet. Check the school network.

## Getting started
- [ ] Find the kit from Thames & Kosmos or a retailer.

- [ ] Run a first experiment.

## Where is the AI?
The kit has no AI. The robots run the code students write. Students build skills in sequencing, logic, and sensor data.

## Privacy and safety
No account is needed but the internet is needed at all times for the web based MakeCode editor. The research did not read the MakeCode privacy policy. The materials do not state what data the editor collects. Whether projects save locally or to an account depends on MakeCode. Check the MakeCode privacy details and the school network before class. The micro:bit may be absent from some versions of the kit, which was not verified.

## Ideas by subject
### engineering
1. Build one of the 14 robots from the manual and test it.
2. Compare two robot models and describe how they move differently.
3. Use the ultrasonic sensor to stop a robot near a wall.
4. Change a part of a model and record the effect.
5. Plan a new robot design on paper from the parts list.

### computer_science
1. Write MakeCode blocks to drive a robot forward and back.
2. Use a sensor reading in a block program.
3. Switch a block program to Python and compare them.
4. Add a loop to repeat a movement.
5. Debug a program that makes the robot spin the wrong way.
