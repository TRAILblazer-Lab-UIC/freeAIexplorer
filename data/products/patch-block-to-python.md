## Overview
Patch is a web based environment meant to bridge students from Scratch to Python. Its layout resembles Scratch, but a Python text editor replaces the blocks. It runs on the Scratch VM and uses Pyodide so Python can control Scratch sprites. A 2025 ASEE paper describes it as work in progress.

## Benefits for students
- Students keep the familiar stage and sprites from Scratch.
- Students write real Python to move sprites.
- Students see how a block such as move 10 maps to the Python function move(10).

## Benefits for teachers
- A function palette with an Add to Editor button helps students find commands.
- Availability is unconfirmed. Keep a backup plan.

## Benefits for schools

## Where is the AI?
The vendor does not describe any AI in Patch. It runs Python in the browser to control sprites. Students build sequencing and logic skills as they turn block ideas into text code.

## Privacy and safety
The materials do not state which tools or accounts students need. They do not say where student work goes. A teacher should check the site terms, any sign-in step, and where projects are saved before using it with students.
