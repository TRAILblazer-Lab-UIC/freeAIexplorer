## Overview
Logisim.app is a browser port of the Logisim digital logic simulator, based on Logisim 2.7.2. The original Java program runs in the browser through CheerpJ. The authors say no install, sign-up, or Java is needed. Students build circuits such as adders, multiplexers, and a 32-bit ALU.

## Benefits for students
- Students open the tool in seconds and start building.
- Students see how a computer works from simple gates up to an ALU.
- Students can use it on a Chromebook, tablet, or phone, as the authors say.

## Benefits for teachers
- The example circuits give ready demos.
- Teachers can open and save files through browser tools.
- It lacks the features of Logisim-evolution. Check that it covers the lesson.

## Benefits for schools
- The tool is free, and the authors say it always will be.
- No install is needed. IT load is low.
- The internet is needed every time the tool is used.

## Getting started
- [ ] Open logisim.app in a modern browser.
- [ ] Load the example adder circuit.
- [ ] Change the inputs and watch the outputs.
- [ ] Build a small circuit with an AND gate and two inputs.
- [ ] Save the file using the browser.
- [ ] Reopen the file to confirm it saved.
- [ ] Test the page on a Chromebook before class.

## Where is the AI?
Logisim.app has no AI. The vendor describes no AI features. It builds logic skills. Students connect gates and trace how inputs produce outputs.

## Privacy and safety
No account is needed. The authors say everything runs in the browser and that no user data or files reach their servers. Nobody independently verified this claim. The site gives no privacy policy. The site must be loaded from the internet each time. A teacher should check where students save their files.

## Ideas by subject
### computer_science
1. Open the example adder and trace how it adds two bits.
2. Build a multiplexer and describe how it picks one input.
3. Explore the 32-bit ALU and list the jobs it can do.
4. Create a circuit that compares two bits and shows if they match.
5. Draw the circuit on paper first and then build it in the tool.

### engineering
1. Design a small circuit that controls a light with two switches.
2. Test the circuit with all input combinations and write a results table.
3. Find a wiring mistake in a broken circuit and fix it.
4. Save the circuit and share the file with a partner.
5. Explain how the circuit could be built with real parts.
