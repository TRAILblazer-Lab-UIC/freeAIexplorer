## Overview
AI Lab is a Code.org browser tool for training machine learning models on tabular datasets. Students choose a label, choose features, train the model, evaluate and test it, and save it. The saved model can be imported into App Lab for a simple app. It appears in the CS Discoveries AI and Machine Learning unit.

## Benefits for students
- Students go through the five steps of building a model.
- Students use charts to judge which features help.
- Students test with held back data and think about bias.

## Benefits for teachers
- The steps are clear and guided.
- Models can be used in App Lab apps.
- Students can work signed in or signed out.

## Benefits for schools
- The tool is free.
- It runs in a browser on Chromebooks, Windows, Mac, and Linux.
- App Lab works best on a desktop or laptop.

## Getting started
- [ ] Open the lesson in Code Studio.
- [ ] Create a teacher section if you want students signed in.
- [ ] Try the tool yourself with a sample dataset.
- [ ] Have students pick a label and features.
- [ ] Train, evaluate, and test the model.
- [ ] Save the model and answer the documentation questions.
- [ ] Import the model into App Lab.

## Where is the AI?
The AI is a machine learning classifier that students train on a table of data. The tool runs in the browser and uses the vendor's cloud. Students pick data, train the model, test it, and then build an app that uses it. They also discuss bias.

## Privacy and safety
With an account, Code.org collects display name, username, age, US state, progress, code, and uploaded content. Signed out use collects only an IP address, but progress is not saved. The data goes to the vendor, and the internet is needed at all times. The policy says student emails are stored only as a one way hash and data is not sold. It says the nonprofit is not subject to COPPA but adds protections. It also says student data may be FERPA education records. The pages do not say whether model training runs in the browser or on a server. A teacher should decide whether students sign in. A teacher should also review the district data agreement.

## Ideas by subject
### computer_science
1. Train a model to predict a label from survey data and report its accuracy.
2. Remove one feature and see how the accuracy changes.
3. Test the model with data held back and explain the gap.
4. Look for a bias in the data set and suggest a fix.
5. Import the saved model into App Lab and build a small app.
