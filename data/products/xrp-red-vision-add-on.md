## Overview
The Red Vision Kit for XRP adds a 2 inch touchscreen and a small color camera to the XRP robot. It runs a MicroPython port of OpenCV for live image processing, object detection, and contour detection. Older students code it in MicroPython. The kit costs 119.95 USD, and an XRP kit is needed separately.

## Benefits for students
- Students see live camera images on a screen on the robot.
- Students code real computer vision with OpenCV.
- Students build the kit with no soldering.

## Benefits for teachers
- The kit plugs into the XRP Control Board.
- The code is open source.
- The page does not mention machine learning, which keeps the focus on classic vision.

## Benefits for schools
- The kit is 119.95 USD each, with volume discounts.
- The work happens on the robot and needs no internet after setup.
- IT should help install the MicroPython package.

## Getting started
- [ ] Find the Red Vision Kit on the XRP site.
- [ ] Make sure the school has an XRP Control Board or a Raspberry Pi Pico.
- [ ] Plug the display and camera into the board.
- [ ] Load the MicroPython Red Vision package.
- [ ] Run an example that shows live camera images.
- [ ] Try the contour detection example.
- [ ] Test the full setup before students use it.

## Where is the AI?
The page does not describe any machine learning. The kit uses classical computer vision with OpenCV to find objects and contours. It runs on the robot. Students learn how a camera can find shapes with code, which builds a base for AI vision later.

## Privacy and safety
No account is needed and the internet is used only at setup. Image processing runs on the board, and the product page mentions no networking or cloud service. The vendor lists no student data collection, and no privacy policy was found. A teacher should still decide who may be in front of the camera.
