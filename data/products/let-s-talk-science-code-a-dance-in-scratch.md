## Overview
Code a Dance in Scratch is a volunteer hands on activity from Let's Talk Science. Learners code a dance in Scratch and build pattern recognition skills. They also learn about repetition and events. They work alone or in groups of two to three.

## Benefits for students
- Students make a sprite dance to music.
- Students practice repetition and events.
- Students can work alone or in small groups.

## Benefits for teachers
- Discussion prompts ask whether clicking the sprite could start the dance.
- Other prompts ask whether loops could simplify the code.
- An appendix has sample dance code.

## Benefits for schools
- The activity page and Scratch are free.
- Learners need a device with Scratch.
- IT has nothing to install if Scratch runs in the browser.

## Getting started
- [ ] Find the Code a Dance in Scratch page on the Let's Talk Science site.
- [ ] Read the safety precautions that the page points to.
- [ ] Open the appendix with the sample dance code.

- [ ] Note that the activity is aimed at volunteers. A facilitator may be assumed.

## Where is the AI?
The vendor does not describe any AI. Learners write code with blocks that follow exact steps. They build pattern spotting skills as they find the moves that repeat in a dance.

## Privacy and safety
The research could not fetch the activity page. The tool choice of Scratch online or Scratch Desktop was not confirmed. A teacher should check the Scratch account rules before class. A teacher should also read the safety precautions.

## Ideas by subject
### computer_science
1. Code a sprite to do three dance moves in order, as the activity describes.
2. Use a loop to repeat a move.
3. Add an event that starts the dance on a click.
4. Compare your code to the sample dance code in the appendix.
5. Show your dance to a group and explain the pattern.
