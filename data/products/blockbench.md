## Overview
Blockbench is a free, open source low-poly 3D model editor. It supports cuboid and mesh modeling, texturing, and animation. A built-in plugin store adds tools, export formats, and model generators. Students build and texture simple 3D models in a web app or a desktop app.

## Benefits for students
- Students build simple 3D models from blocks.
- Students paint textures directly on their models.
- Students can animate a model they made.

## Benefits for teachers
- The web app opens in a browser with no install.
- The tool is widely used for Minecraft style models.
- Teachers can add plugins for extra formats.

## Benefits for schools
- The tool is free for any type of project.
- No account is needed.
- Installing the desktop app may need IT help. The web app needs none.

## Getting started
- [ ] Open the Blockbench web app in a browser.
- [ ] Download the desktop app from the Download page if needed.
- [ ] Make a simple cube model and paint it.

- [ ] Check with IT before adding any plugins.
- [ ] Note that Blockbench lists a minimum age of 13.
- [ ] Choose a first project, such as a simple tool or animal.

## Where is the AI?
Blockbench has no AI. It builds the skill of spatial thinking, as students shape and test forms. It also builds pattern spotting through repeated shapes and textures.

## Privacy and safety
No account is needed. The policy says it does not knowingly collect personally identifiable data and may collect anonymized usage data such as installation counts. The optional Model Sharing feature stores the shared model on the vendor side. The policy says it does not knowingly collect information from children under 13. The home page embeds a Sketchfab viewer that uses Sketchfab cookies. A teacher should turn off Model Sharing and review any plugins before students install them.
