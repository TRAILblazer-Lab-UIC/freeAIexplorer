## Overview
MicroCode is an icon based programming tool for the BBC micro:bit V2. The editor, compiler, and runtime live on the board. A child can program with only an Arcade shield accessory and no computer. Users build When-Do rules and edit 5 by 5 images with cursor controls.

## Benefits for students
- Students program with icons and need no typing.
- Students can code away from a computer.
- Students can control a two-wheeled rover robot.

## Benefits for teachers
- The When-Do rules are easy to read and explain.
- A web version connects over WebUSB.
- Teachers can teach rule based thinking to young students.

## Benefits for schools
- The software is free.
- A micro:bit V2 is required, and an Arcade shield is sold separately. The shield price was not found.
- The Microsoft repository was archived in August 2025, and a continued repository exists under microbit-apps.

## Getting started
- [ ] Find the MicroCode project and the continued microbit-apps repository.
- [ ] Confirm that your boards are micro:bit V2. V1 is not supported.
- [ ] Flash the MicroCode program to a board.
- [ ] Slot the board into an Arcade shield.
- [ ] Or open the web app at microbit-apps.github.io/microcode-classic in a WebUSB browser.
- [ ] Try one When-Do rule before class.
- [ ] Ask IT to check Chromebook support. It is likely but not stated.

## Where is the AI?
This tool has no AI. It builds the skill of writing rules in a When-Do form, which is a simple kind of logic. Students also practice editing small images.

## Privacy and safety
No account is needed. The Microsoft Research article says the editor, program, compiler, and runtime live in the micro:bit V2 memory, and the standalone version needs no internet. It does not describe any built in data collection. The web app version is hosted on GitHub Pages, and the research did not read its privacy terms. The research found no privacy policy. The Microsoft repository is archived. A teacher should note that the tool may change under the new maintainers.
