## Overview
Machine Learning for Kids is a free website where students train machine learning models on text, numbers, images, or sounds. They use the models in Scratch, Python, or App Inventor projects. It has about two dozen projects with teacher guidance and student worksheets. Dale Lane at IBM created it, and the site has more than 20 interface languages.

## Benefits for students
- Students train a model and use it in a project they build.
- Students can work in Scratch, Python, or App Inventor.
- Students use the site in many languages.

## Benefits for teachers
- Each project has a worksheet and teacher guidance.
- Teachers can create managed class accounts.
- Students can try projects without saving.

## Benefits for schools
- The site is free.
- It runs in a browser, including on Chromebooks.
- Data storage terms should be checked with the maintainer before use with student data.

## Where is the AI?
The AI trains classifiers for text, numbers, images, and sounds. The training runs in the vendor's cloud. Students collect examples, train a model, test it, and then use it in a Scratch, Python, or App Inventor program. They can add more examples to improve it.

## Privacy and safety
The site needs the internet at all times and runs on a vendor cloud that includes IBM Watson. Accounts are optional and the research did not confirm who needs one. The privacy page returned only navigation. A search snippet of the help page says schools act as data controller, student accounts store only a username, and IBM Watson is asked to opt out of using training data. The same snippet says no project data is stored on the site's servers. A deployment document lists PostgreSQL and Cloud Object Storage for student project data, which conflicts with that claim. Image and sound handling was not confirmed. A Common Sense review is reported paused and removed, and its note on personalised ads was not verified. A teacher should read the data terms and use managed accounts with anonymous usernames.

## Ideas by subject
### computer_science
1. Train a text model to sort messages into two groups and test it.
2. Build a Scratch game that reacts to a model's answer.
3. Train an image model with a webcam and find one input that fools it.
