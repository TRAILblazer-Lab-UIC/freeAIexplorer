## Overview
VEX IQ 2nd generation is a snap together robotics platform used in classrooms and competition. Students code with VEXcode IQ in blocks or text. Carnegie Mellon Robotics Academy offers a curriculum on movement, sensors, loops, conditionals, and autonomous behavior. An optional IQ AI Vision Sensor adds object and AprilTag detection.

## Benefits for students
- Students build robots that snap together without tools.
- Students learn loops, sensors, and conditionals with a real robot.
- Students can add vision to detect objects.

## Benefits for teachers
- The VEX Library lists grades 5 to 8.
- CMU provides a curriculum plus onsite and online training.
- VEXcode IQ has a browser version at codeIQ.vex.com.

## Benefits for schools

## Where is the AI?
The AI is optional. The IQ AI Vision Sensor detects objects and AprilTags, and it runs on the device. Students use its readings in their code. Without the sensor, the kit has no AI.

## Privacy and safety
The materials do not state which accounts students need. The internet is used at setup. The VEX software privacy policy could not be read. A search snippet says some apps are directed to children under 13 and that Google Analytics is used. VEX says sensor images stay on the student device, which is a vendor claim. A teacher should read the policy and confirm what student account rules apply.

## Ideas by subject
### computer_science
1. Follow the CMU curriculum to program the robot to drive a set distance.
2. Use a loop to make the robot trace a square.
3. Add a sensor condition so the robot stops before an obstacle.
4. Compare block code and text code for the same task.
5. Add the AI Vision Sensor and make the robot react to an AprilTag.

### engineering
1. Build a robot that snaps together and test its movement.
2. Add an arm or claw and test it with a light object.
3. Compare two wheel designs on the same surface.
4. Redesign a robot to turn more smoothly.
5. Write a short build log that a teammate could follow.
