## Overview
Local GPT is an Obsidian plugin that runs AI actions on selected note text. Actions include continue writing, summarize, and fix grammar. It connects to Ollama or other compatible endpoints through the separate AI Providers plugin. It can use linked notes and PDFs as context if an embedding provider is configured. It lists desktop and mobile platforms.

## Benefits for students
- Students can fix grammar or summarize text inside their own notes.
- Students can add custom actions.
- Students can use linked notes and PDFs as context.

## Benefits for teachers
- A right-click menu makes the actions easy to find.
- The plugin supports vision models.
- Teachers can pair it with a local Ollama model.

## Benefits for schools
- The plugin is free and open source.
- Obsidian itself and any cloud provider have their own terms.
- It needs Ollama running separately, and IT must help with setup.

## Getting started
- [ ] Find Local GPT in the Obsidian community plugins.
- [ ] Ask IT to approve Obsidian, Ollama, and the plugins.
- [ ] Install Obsidian and Ollama on a test computer.
- [ ] Install the AI Providers plugin and Local GPT.
- [ ] Configure Ollama as the provider and pull a model.
- [ ] Keep any cloud provider turned off.
- [ ] Test the summarize and fix grammar actions on a sample note.

## Where is the AI?
The AI is a language model that continues, summarizes, and fixes text in a note. It can run on the local computer through Ollama, or it can use a cloud provider that the user sets up. Students use the actions to improve their own writing and then edit the results.

## Privacy and safety
No account is needed, and the internet is used at setup. With a local Ollama model, notes stay on the device. A cloud provider would receive note text, and the README says nothing about how providers handle data. Community actions are downloaded from the network. The research did not review Obsidian's own terms. A teacher should check which provider is configured and keep it local.
