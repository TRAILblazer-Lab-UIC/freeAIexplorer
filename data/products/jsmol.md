## Overview
JSmol is an HTML5 and JavaScript version of the Jmol molecular viewer. It embeds interactive 3D molecule viewers in web pages without Java. It works on tablets and phones as well as computers. Students rotate and inspect molecular structures in the browser.

## Benefits for students
- Students rotate molecules on a Chromebook, tablet, or phone.
- Students need no software install.
- Students can see structures pulled from outside databases.

## Benefits for teachers
- Teachers embed a model in a class page and students open the link.
- A review article suggests JSmol for students who cannot install desktop software.
- Embedding needs some HTML and JavaScript knowledge.

## Benefits for schools
- The software is free and the code is open.
- It runs in a modern browser on many devices.
- A teacher or web admin handles the setup.

## Getting started
- [ ] Download JSmol from the Jmol project site.
- [ ] Ask your web admin to host the files.
- [ ] Embed one structure in a web page.
- [ ] Open the page on a student device and test it.
- [ ] Check that the page loads on tablets and Chromebooks.
- [ ] Read the Jmol wiki for display options.
- [ ] Share the page link with students.

## Where is the AI?
JSmol has no AI. It displays structures from data files. Students build pattern spotting skills as they compare shapes across molecules.

## Privacy and safety
No account is needed, and the internet is used for setup. The SourceForge page does not describe data collection by JSmol itself. The viewer can optionally fetch structures from external database providers. A school can host a page that embeds it, but local hosting steps were not confirmed. No privacy policy was found. A teacher should check any outside database that a page connects to.
