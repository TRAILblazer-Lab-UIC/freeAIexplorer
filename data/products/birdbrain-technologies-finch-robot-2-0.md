## Overview
Finch Robot 2.0 is a small wheeled robot designed at Carnegie Mellon for computer science education. It senses light, obstacles, sound, lines and compass heading. It also has LEDs, a buzzer and a pen mount for drawing. Students in grades K through college code it in FinchBlox, BirdBlox, Snap!, MakeCode, Python or Java.

## Benefits for students
- Students start with icon blocks and move up to Python or Java.
- Students use real sensor readings to guide the robot.
- Students can draw with the pen mount and see their code on paper.

## Benefits for teachers
- Self-paced tutorials and activities exist, such as maze navigation and marker-based art.
- The vendor offers a Finch 2.0 Snap! programming course.
- Students can work alone or in groups of one or two.

## Benefits for schools
- The robot works with Chromebook, Windows, Mac, Linux, iOS, Android and Fire OS.
- No account is needed and the internet is needed at setup.
- The vendor advertises a battery that lasts over 7 hours. The official page lists no price and a retailer listed one unit at 180 USD.

## Getting started
- [ ] Buy Finch Robot 2.0 from BirdBrain Technologies or a reseller.
- [ ] Insert a micro:bit in the tail of the robot.
- [ ] Flash the BirdBrain firmware over USB.
- [ ] Charge the robot and pair it by Bluetooth.
- [ ] Open Snap! or another editor in Chrome or Edge.
- [ ] Run a first program that lights the LEDs.
- [ ] Test the sensors with a short program before class.

## Where is the AI?
Finch Robot 2.0 has no AI. The robot runs the code that students write on a connected device. Students build skills in sensors, logic and sequencing.

## Privacy and safety
No account is needed and a Snap! cloud account is optional. The BirdBlox app policy says the app is directed to children under 13 and lists Bluetooth and sensor permissions. It says BirdBrain in Pittsburgh processes the data. It does not mention COPPA by name. That policy may not cover every BirdBrain product. A teacher should read the policy for the editor the class will use.

## Ideas by subject
### computer_science
1. Work through a self-paced tutorial in FinchBlox and describe each new block.
2. Program the robot to navigate a maze built from books and boxes.
3. Write a program that reads the light sensor and changes the LED color.
4. Translate a block program into Python and compare the two.
5. Debug a classmate's line-following program and explain the fix.

### engineering
1. Design a marker holder setup and draw a shape with the pen mount.
2. Build a course with obstacles and tune the robot to finish it.
3. Test how the sensors react to different surfaces and record the results.
4. Add a brick adapter attachment and describe what it adds.
5. Plan and test a design challenge for a partner group.
