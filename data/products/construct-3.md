## Overview
Construct 3 is a 2D game maker that runs in the browser. Users build games with visual event sheets and can add JavaScript. The homepage says it works offline after loading. Scirra sells seat-based educational subscriptions that students use with access codes.

## Benefits for students
- Students build games with visual logic.
- Students can add JavaScript when ready.
- A Simplified UI mode trims advanced features for younger students, per a search snippet.

## Benefits for teachers
- Teachers can distribute access codes to students.
- The editor works offline after loading.
- Event sheets show game logic clearly.

## Benefits for schools
- A free edition has limits, and a search snippet says educational organizations may use it in lessons.
- Paid educational subscriptions are seat-based.
- Educational access codes collect no personally identifiable information.

## Getting started
- [ ] Open the Construct 3 editor in a web browser.
- [ ] Try the free edition and note its limits.
- [ ] Decide whether the school needs paid seats.
- [ ] Buy seats and distribute access codes if needed.
- [ ] Load the editor online once before using it offline.
- [ ] Try the Simplified UI mode with younger students.
- [ ] Note that student accounts under an educator license need only an email, and the minimum age is 16.

## Where is the AI?
This tool has no AI. It builds skills in logic and events. Students decide what happens when a player acts and see the result in the game.

## Privacy and safety
Access codes collect no personally identifiable information. Student accounts under an educator license need only an email. The policy says users must be 16 or older to create an account without parental consent. It says students under 16 on educator assigned licenses need parent or guardian consent. Files shared with educators are kept on Scirra servers for up to 72 hours, and servers are primarily in the USA on Microsoft Azure. Google Drive saves go directly between the browser and Google. The policy says it does not sell information. A teacher should check the consent rule and use access codes for younger students.
