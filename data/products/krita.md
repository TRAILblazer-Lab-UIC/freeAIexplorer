## Overview
Krita is a free and open source digital painting program made by artists. It is licensed under the GNU GPL and costs nothing. Students use it to make illustrations, comics, character designs, and collage art. The core program has no AI features.

## Benefits for students
- Students paint, draw, and make comics on a computer.
- Students can make illustrated storybooks.
- Students can use a drawing tablet if one is available.

## Benefits for teachers
- The tool is easy to learn.
- The K20 Center lesson Ink Me Up uses Krita.
- Teachers can pair it with writing projects.

## Benefits for schools
- The program is free. The site asks for donations.
- The privacy statement says it collects no user data.
- Installation needs permission on managed devices.

## Getting started
- [ ] Download Krita from krita.org.
- [ ] Ask IT to install it on school computers.
- [ ] Check Chromebook support, which was not confirmed.
- [ ] Open the program and choose a document size or template.
- [ ] Try a few brushes and layers.
- [ ] Add a drawing tablet if you have one.
- [ ] Save student work in a school folder.

## Where is the AI?
The core program has no AI. Students use brushes and layers to make their own art. They build design and sequencing skills as they plan a picture in steps.

## Privacy and safety
No account is needed, and the program works offline. The privacy statement says Krita does not access, collect, use, share or transmit personal information or user data. Network use is limited to two optional features, the newsfeed and the G'Mic plugin downloading filter definitions. A teacher should check where students save their work. A teacher should also set rules for any images students copy.

1. Paint a landscape with layers for the sky, land, and objects.
2. Design a character and draw it in three poses.
3. Make a short comic strip with four panels.
4. Build a collage from photos and paint over it.
5. Share work in a class gallery and explain the tools used.

4. Illustrate a poem with one picture.
