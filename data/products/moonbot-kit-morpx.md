## Overview
MoonBot is a robot kit from Morpx that builds three robots from one kit. Its main sensor is a vision sensor with a deep learning pipeline. The sensor can detect colors, lines, people, faces, and specific images. Students program it in Scratch. IEEE Spectrum covered it in November 2018 during its Kickstarter campaign at 149 USD.

## Benefits for students
- Students build three different robots from one kit.
- Students program with Scratch.
- Students use a camera sensor that can detect faces, colors, and lines.

## Benefits for teachers
- It needs only a screwdriver and basic Lego-style building skill.
- The board is Arduino-like and expandable.
- Scratch is familiar to many teachers.

## Benefits for schools
- The Kickstarter price in 2018 was 149 USD.
- Availability after the 2018 campaign is unconfirmed, and no later coverage was found.
- Check with the maker before planning a purchase.

## Where is the AI?
The AI is a vision sensor with a deep learning pipeline. It detects faces, colors, lines, and image patterns. The materials do not say where it runs. Students use Scratch blocks to react to what the sensor finds.

## Privacy and safety
The materials do not state which tools or accounts students need. The research found no privacy information and did not learn whether the vision sensor works locally. A teacher should ask the maker about software, accounts, and data. A teacher should also confirm that the kit can still be bought.

## Ideas by subject
### computer_science
1. Write a Scratch program that reacts to a detected color.
2. Make the robot greet a face it detects.
3. Test line detection on a taped path and record the results.
4. Compare face detection with color detection and list one difference.
5. Create a flowchart of how the sensor's result changes the robot's action.

### engineering
1. Build the first of the three robots.
2. Rebuild the kit as a second robot and compare the designs.
3. Test the robot on a taped course and time it.
4. Adjust the sensor angle and see how detection changes.
5. Write a short build log for each robot.
