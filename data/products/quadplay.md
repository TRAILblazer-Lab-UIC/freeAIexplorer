## Overview
quadplay is a free fantasy console for creating and playing retro style 2D video games. It has a web IDE and runs on laptops, tablets, phones, and Raspberry Pi arcade machines. Full example games ship with source code, and short examples show single features. The project is now maintained by Shmuel Ravensky.

## Benefits for students
- Students write code to make a real game.
- Students learn from full example games with source code.
- Students can play their games on many devices.

## Benefits for teachers
- A manual and examples support lesson planning.
- Short feature examples work well for demonstrations.
- The web IDE needs no install.

## Benefits for schools
- The tool is free.
- It runs in a browser with no account.
- Chromebook use is not confirmed.

## Getting started
- [ ] Find quadplay on its GitHub page and read the README.
- [ ] Open the web IDE in a browser on a test device.
- [ ] Run one full example game.
- [ ] Read the source code of a short feature example.
- [ ] Change one value and run the game again.
- [ ] Test the web IDE on a Chromebook before planning class use.
- [ ] Download the Windows or macOS and Linux install if the web IDE is blocked.

## Where is the AI?
quadplay has no AI. It builds an AI-related skill, which is logic. Students write rules that control a character and a score. That practice shows how programs make decisions.

## Privacy and safety
No account is needed. The editor runs in the browser, and a local install is also offered. The internet is used at setup. Games run on the device. No privacy policy was found. The original address returned a 404 error. A teacher should check that the current page is the one the maintainer lists.

## Ideas by subject
### computer_science
1. Read the source of a full example game and describe how the main loop works.
2. Change a speed value in a short example and watch what happens.
3. Write code that moves a sprite with the controls.
4. Add a score and show it on the screen.
5. Fix a bug in a game by reading its code.

### theater_media
1. Design a simple retro game about a school event.
2. Draw sprites and choose colors for a retro look.
3. Write the story and goal for a short game.
4. Test a classmate's game and give two notes on how it feels to play.
5. Present the game to the class and explain the design choices.
