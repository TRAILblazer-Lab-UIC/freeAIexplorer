## Overview
F1TENTH is an open-source platform for 1/10 scale autonomous racing cars. The project now uses the name RoboRacer. A teaching paper describes modules that run from basic reactive methods to advanced planning, with racing competitions in place of exams. The documented deployments are university courses, and a search result lists a high school team that competes in the series.

## Benefits for students
- Students build a real autonomous car and tune it.
- Students test perception, planning, and control in labs.
- Students can join international racing competitions.

## Benefits for teachers
- The GitHub organization holds system drivers, a simulator, lab templates, and a course kit.
- The free online instructions guide the car build.
- Labs can start in the simulator before students use the car.

## Benefits for schools
- No total build cost was found. A university sheet listed a chassis at $300 to $500 and more for the battery and charger.
- The code is open source, and the car runs on its own computer.
- Setup takes days and needs IT support.

## Getting started
- [ ] Find the project at roboracer.ai, which replaces f1tenth.org.
- [ ] Read the build instructions and plan the parts list.
- [ ] Ask the vendor or the project community about a current parts source.
- [ ] Ask IT to help with Linux and the onboard computer.
- [ ] Build the car from the free online instructions.
- [ ] Install the system software. The internet is needed at setup.
- [ ] Run the early labs in the simulator.
- [ ] Move to the car after the simulator labs work.

## Where is the AI?
The AI includes perception, planning, control, and reinforcement learning. The AI is optional and runs on the car's onboard computer. Students write code in the labs, test it in the simulator, and then run it on the car.

## Privacy and safety
No account is needed and the internet is used only at setup. The car runs its software on an onboard computer. The research found no privacy policy for the project and did not check whether the website collects data. The documented use is at university level. A teacher should check the project website terms and set a clear test space for the car, which can drive at speed.

## Ideas by subject
### engineering
1. Build the car chassis and record the parts list.
2. Tune the car's steering and speed and measure lap time.
3. Test the car at several battery levels and chart the result.
4. Design a track and mark safe zones for testing.
5. Compare the car's design with a full size racing car and list three differences.

### computer_science
1. Run the simulator and watch a basic reactive method drive the car.
2. Write a simple wall-following program and test it in the simulator.
3. Compare a reactive method with a planning method and describe the difference.
4. Read about reinforcement learning in the lab material and explain it in a short note.
5. Log lap data from a test and find what slowed the car.
