## Overview
SuperCollider is a platform for audio synthesis and algorithmic composition used by musicians, artists, and researchers. It has an audio server called scsynth, a language called sclang, and an editor called scide with built-in help. It runs on Windows, macOS, and Linux and the current version is 3.14.1. It suits older, advanced students who want to code music.

## Benefits for students
- Students make and shape sound with code.
- Students can explore algorithmic composition, where rules create music.
- Advanced students can see how professional sound tools work.

## Benefits for teachers
- A built-in Getting Started tutorial supports teachers new to the tool.
- Nick Collins reports creative coding sampler sessions for ages 11 to 13 among twelve years of teaching.
- The learning curve is steep. Strudel or Sonic Pi are lighter options for school music coding.

## Benefits for schools
- The software is free and has been free software since 2002.
- It needs install rights on each computer.
- The code runs on the device and the internet is needed only at setup.

## Getting started
- [ ] Download the installer for each operating system from the SuperCollider site.
- [ ] Ask IT for install rights.
- [ ] Open the editor and follow the Getting Started tutorial.
- [ ] Run the first sound example and check the audio output.
- [ ] Try a short sound that changes over time.
- [ ] Compare it with Strudel or Sonic Pi for younger students.
- [ ] Plan a first lesson with a short code sample.

## Where is the AI?
SuperCollider has no AI. Students write code that tells the audio server how to make sound. They practice logic and pattern building through rules that create music.

## Privacy and safety
No account is needed, and the internet is used at setup. SuperCollider is a local desktop application. The research found no privacy policy, and the project site describes no data collection. A teacher should check that the install comes from the official site. A teacher should also set a volume rule for a shared room.

## Ideas by subject
### music
1. Run the first example in the Getting Started tutorial and describe the sound.
2. Change a number in the code to alter the pitch of a tone.
3. Build a short pattern of notes that repeats.
4. Create a sampler sound from a recording, as in the sessions for ages 11 to 13.
5. Perform a short piece made of code and explain how you built it.

### computer_science
1. Write a line of sclang and run it to hear the result.
2. Use a loop to play a series of notes.
3. Fix an error in a program that stops the sound.
4. Save a reusable function for a favorite sound.
5. Explain how the language and the audio server work together.
