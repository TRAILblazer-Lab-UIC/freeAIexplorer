## Overview
KAlgebra is a KDE graphing calculator for numerical, logical, symbolic, and analysis tasks. It plots results in 2D or 3D. KmPlot is a function plotter that handles cartesian, parametric, polar, implicit, and differential plots. Both are part of the KDE Education suite and run on Linux.

## Benefits for students
- Students see an equation turn into a graph.
- Students can try polar and parametric plots.
- Students can use a slider in KmPlot to change a parameter and watch the curve move.

## Benefits for teachers
- KmPlot can show integrals and derivatives.
- Both tools are free and need no account.
- The tools are easy for students and moderate for teachers.

## Benefits for schools
- The software is free and the code is open.
- The tools run offline on the device.
- The app pages list Linux install routes only. Chromebooks need a Linux container.

## Getting started
- [ ] Find KAlgebra and KmPlot on the KDE Education pages.
- [ ] Ask IT to install both from the Linux software center.
- [ ] Open KmPlot and plot a simple line.
- [ ] Add a slider to change one number in the equation.
- [ ] Open KAlgebra and plot a function in 3D.
- [ ] Save a graph to a school folder.
- [ ] Plan one short graphing lesson.

## Where is the AI?
These tools have no AI. They calculate and plot what students type. Students build skills in functions and data as they link an equation to its graph.

## Privacy and safety
No account is needed, and the tools run offline. KDE says its software generally does not send data from the device unless the user takes an explicit action. Telemetry is opt in and off by default. Some apps can check for updates, and those checks can be disabled. A teacher should check that the school computers run Linux. Windows and macOS availability was not confirmed. A teacher should also save student work to a shared school folder.
