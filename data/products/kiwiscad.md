## Overview
KiwisCAD is a free browser tool for wiring virtual circuits and simulating Arduino sketches. It offers more than 50 virtual components and a code editor with compile and simulation. It also has a live serial monitor, tutorials, and an example gallery. The site says it is free for students, teachers, and makers.

## Benefits for students
- Students test a circuit before they touch real parts.
- Students write Arduino code and see it run.
- Students can follow tutorials and examples.

## Benefits for teachers
- The tool runs in a browser with no install.
- The site says it runs on Chromebooks and tablets.
- Directory editors recommend it for beginners simulating Arduino projects.

## Benefits for schools
- The tool is free per the site.
- IT has nothing to install.
- It needs the internet at all times.

## Getting started
- [ ] Open the KiwisCAD site in a browser.
- [ ] Try an example from the gallery.
- [ ] Decide if students will use the optional account.
- [ ] Place a few components and wire them.
- [ ] Write a short sketch and run the simulation.
- [ ] Open the serial monitor.
- [ ] Remember that it does not offer SPICE or digital logic simulation.

## Where is the AI?
KiwisCAD has no AI. It simulates circuits and code by fixed rules. Students build logic and sensor skills as they predict what a circuit will do.

## Privacy and safety
The editor and simulation work without signing in, and the tool needs the internet at all times. An account is needed to save projects, build a gallery, and share. No privacy policy or developer identity was found. Data handling is not confirmed. The research did not learn whether student accounts need an email address. A teacher should check the site terms before students make accounts. A teacher should also have students use the tool without an account at first.
