## Overview
GinoBot is an assembled four-wheel robot with a built-in processor and snap-fit points for the Engino building system. It has three proximity sensors, two floor colour sensors and two encoder motors. Beginners program it with KEIRO visual programming and can test code in the ENVIRO simulator. Advanced users can use Python or C++ through micro:bit, Arduino or Raspberry Pi.

## Benefits for students
- Students start with visual blocks and move up to Python or C++.
- Students test code in a simulator before they run the robot.
- Students add parts with the Engino snap-fit points.

## Benefits for teachers
- The kit includes a digital curriculum and a teacher's guide.
- The robot arrives assembled. Setup is short.
- The robot connects by USB, Bluetooth or Wi-Fi.

## Where is the AI?
GinoBot has no AI. It follows the code students write and reads its sensors. Students build skills in sequencing and sensors.

## Privacy and safety
The materials do not say whether accounts are needed or whether the internet is used. They do not say what data is collected. The Engino privacy page showed only store content and no policy text. The shop uses Shopify checkout. A teacher should ask Engino about accounts, internet use, and data before students use KEIRO or ENVIRO. A teacher should also check which devices KEIRO supports.

## Ideas by subject
### computer_science
1. Build a KEIRO program that drives the robot in a square.
2. Test the program in ENVIRO and then on the real robot.
3. Use the proximity sensors to make the robot avoid a wall.
4. Use the floor colour sensors to stop on a colored mat.
5. Explain how the robot's behavior changed after a code edit.

### engineering
1. Attach a snap-fit part to the robot and describe its purpose.
2. Compare the simulator result with the real robot result.
3. Measure how far the robot travels in a set time.
4. Build a short obstacle course for the robot.
5. Sketch a change to the robot and list the parts needed.
