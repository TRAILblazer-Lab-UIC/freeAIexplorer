## Overview
Youth Code Jam offers free coding activities in English and Spanish, per a search summary of its CSforAll page. The activities have written step by step instructions with images. The organization says it uses Scratch in many activities and has translated 17 coding challenges into Spanish. The page itself returned an error. Activity titles and tools were not read.
