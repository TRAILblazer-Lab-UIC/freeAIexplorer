## Overview
NeuLog is a set of plug in sensor modules. Each module combines a data logger, flash memory, and a sensor. Sensors cover physics, chemistry, biology, environmental science, and robotics. They connect through a USB or Bluetooth module to a free application. The site claims use from elementary school through college.

## Benefits for students
- Students collect real data with a plug in sensor.
- Students see readings on a graph as they happen.
- Students explore many science topics with one system.

## Benefits for teachers
- A WiFi-201 web app needs no install.
- An HTTP based API works from Python, JavaScript, C, and Java.
- The software comes in English and Spanish.

## Benefits for schools
- The software is free, and the sensors are a paid purchase.
- The desktop apps run on Windows, Mac, and Linux.
- A USB driver is needed, and IT will likely install it.

## Getting started
- [ ] Buy sensors and a USB, Bluetooth, or WiFi-201 communication module.
- [ ] Download the NeuLog application and the USB driver.
- [ ] Connect the module and a sensor.
- [ ] Record a first reading and view the graph.
- [ ] Contact the vendor about Mac builds for High Sierra and Mojave.
- [ ] Try the WiFi-201 web app, which needs no download.

## Where is the AI?
This system has no AI. It builds data skills, such as logging readings and reading graphs. Students also practice using sensors.

## Privacy and safety
No account is needed, and the desktop apps run locally after install. The internet is used at setup. The research did not confirm whether the apps need the internet later. The privacy policy covers only the website and says nothing about the software or sensors. The WiFi-201 web app is online by design, and its data handling is not described. A teacher should test the USB driver on school computers before class and ask the vendor about the web app.
