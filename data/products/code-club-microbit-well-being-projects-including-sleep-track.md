## Overview
This Code Club path introduces the micro:bit through projects about well-being. One project is a sleep tracker that records how much a young person moves. Learners practice variables and use the accelerometer and LED display. The path is planned as six one-hour sessions, and starter code is in the MakeCode online editor.

## Benefits for students
- Students build a real device that senses movement.
- Students see their data on the LED display.
- Students link coding to topics such as relaxation and exercise.

## Benefits for teachers
- The path is planned in six one-hour sessions.
- Starter code in MakeCode saves planning time.
- Teachers can link the work to health and computing lessons.

## Benefits for schools
- The projects are free, but micro:bit boards are bought separately.
- Each learner or pair needs a board, a USB cable, and a computer with a browser.
- Work runs in the browser and on the board, and the internet is needed only for setup.

## Getting started
- [ ] Find the Introduction to micro:bit path on the Raspberry Pi projects site.
- [ ] Gather one micro:bit and one USB cable per learner or pair.
- [ ] Open the project in the MakeCode editor in a browser.
- [ ] Test the starter code on one board.
- [ ] Plan six one-hour sessions.
- [ ] Link teachers to the project pages. The official URL is only a blog tag page.
- [ ] Discuss with students what sleep data they are willing to share.

## Where is the AI?
This lesson has no AI. It builds skills in data and sensors. Students use the accelerometer to collect movement data and show it with code.

## Privacy and safety
No account is needed, and the code runs in the MakeCode browser editor and on the board. The internet is needed for setup. Sleep readings are held on the micro:bit. The research could not read the project page and used a blog post and a search snippet. It found no privacy policy for MakeCode. A teacher should remind students that sleep and movement data is personal and should be shared only by choice.

## Ideas by subject
### health_pe
1. Build a sleep tracker that counts movement during a rest period.
2. Compare the movement of a calm break and an active break.
3. Discuss how sleep affects a school day and write three tips.
4. Display a relaxation timer on the LED display.
5. Record movement during an exercise and describe what the numbers show.

### computer_science
1. Create a variable that counts movements and show it on the LED display.
2. Read the accelerometer and print a message when the board moves.
3. Change a threshold value and test how the tracker responds.
4. Use a button press to reset a counter.
5. Explain in words how the program stores and shows data.
